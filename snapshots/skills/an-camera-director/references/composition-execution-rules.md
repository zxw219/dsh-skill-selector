# 构图与分镜的扩展执行规则

继承[功能入口](../SKILL.md)的职责、任务对象和修改边界。仅按当前问题定位相关条目，不将清单全部设为日常必做。

1. 速度型观看以参照、真身与关键交会的实际占幅证明差速；固定外景、稳定主观也可成立。只修构图，不新增时间机制、动作或换档。
2. 剧情构图先继承原文知情顺序和当下状态，让关键证据、接收者与关系可读；不因漂亮取景提前揭示或移动世界位置，固定机位在同一真实观察点成立。只改构图。
3. 选镜前把观众立场、心理距离、期待编成主次/负空间/遮挡/焦点/尺度与起中落幅；主动用表现性方法，非必要双人站立全景禁用。只改观看构图，不补动作。
4. 多人构图先核当前镜的进入、主关系变化、次层/画外同期进程和出口，以层次/轮廓/留空交出协助与敌方来线。稳定身份/目标绑定，机位变化后重建屏幕方位；只改构图，不裁敌补造安全或距离，不强制全员同框或固定人数上限。
5. 已定手腿协同的观看需有髋膝、支撑/腾空、腿攻击端、目标与手部防线的必要关系，不能全程腰上施法CU。斜侧中全景读手引腿/腿引手，局部读接触或表情，邻镜接同次收腿与能力结果；实际腿技缺项交动作层，不为覆盖创造招式，固定/一镜边界保持。
6. 召唤动作与召唤物/大型作用体分别可给CU/ECU：前者读指节、腕肘与负载，后者读有效部位、形成边界、材料/受损。人物表情、小动作、情绪动作与反馈可独立承载投入或承受，不必每镜变招；局部写裁切、归属、相位和必要尺度，范围接同次运行，不固定每招镜序。只修覆盖，固定/一镜/无手势/瞬发保留。
7. 关键普通施法的指节/腕向、身体负载和作用结果也有实际读取，不能仅大招近景而小招远处甩掌。继承当前事件/资源，局部返回接同次进度，不强制每招手部教程；缺动作/机制交回所属层，只修获准覆盖。
8. 继承已定事件与信息顺序，沿整段观看发展安排主次与覆盖；邻镜/镜内交接接正在发生的状态、注意/理解与强调/节律。补本职责的可读关系、起中落幅和接入/接出，不重编能力/动作，不以漂亮端点或镜数证明整段分镜完成。
9. 打斗按拆招/防线、身体路线/落点、决定性咬合选择实际取景尺度和遮挡关系；近距、全身/范围与局部各读所需证据，切后接剩余相位。清楚承接的局部可直接切范围，不强制景别阶梯或禁90度侧视；只修观看/切点，不给动作凑招数或新增攻击。
10. 相关翻腾保留身体轴、来刃/对手与落点，局部读接触/脸读判断时邻段承接画外进程；不以镜头滚转替代角色旋转，不为构图改招式或胜负。
11. 场景/巨物/人物的观看关系承担速度和压力，镜尾按动作、图形、视线、遮挡、甩镜或声音连接交付实际切点与下一相位；镜内变化不当剪辑，不扩展生成/教程。
12. 取景继承已成立地标与动态空间出口，世界方位、人物自身左右与屏幕投影分开；人物/机位变化后按当时采用的关系/行进/攻击轴重判侧与切接，世界东侧不保证动态轴同侧。局部返回范围景接画外推进后的位置，可见过轴或明确重建合法，不永久锁甲左乙右。
13. 核实际剪辑而非只核标题：正文中的真实切镜各有独立镜头、包络与transition，同镜转焦/摇摄/阶段不误拆；沿同一次动作的剩余相位交接，不重放起手或命中。只修改本职责及获准边界。
14. 分镜从当次所需信息、可读观察位置/占幅与读取结束点产生，切后接已发展的事件；不把动作按时码拆段、换景别/焦段或加镜号当作完成。控制/判断细节和范围结果按本场需要交接，一镜到底用画内变化承担同一职责，不每法固定三镜。
15. 联用先守原角色类型、主战距离、持物与控制；法师/召唤/领域不默认近战或新增盾剑/晶甲，不因动作多样性而重定战法。施法动作、本体与法术/代理共享时间、释放后任务及所要求的领域/大型召唤要在正文兑现；本模块只补所属证据，不另导演。相容近身/术法防御仍可用，不给每角色强塞星体/荷花清单。
16. 只补本职责：关键施法/攻击细节按实际占幅可读，可主动选近景/特写，邻镜接同次身体、目标与结果；切点接相位与注意，不重放出招。力量由驱动/加速、抵抗或机制生效及后续任务成立，再用摄影声画增强；范围和质量保持。能力案例不构成类型闭集，原创从角色与战局产生，锁定能力不扩写，不设每招镜数或全库枚举。
17. 先明确观众要读的证据，再定取景与重点；远景不索取不可见微表情，近景不索取整片战场。
18. 构图检查起幅、决定性中段和落幅；主体或相机变化后重算银幕投影，保留世界位置与轴线。
19. 近远层、留空、轮廓、亮暗、焦点与地标按作用选用，不凑三分法、三层景或角度配额。
20. 真实切镜才建新镜头；连续移动中的景别变化不自动拆镜，不重复起手或命中。
21. 动作、胜负和表演节点已锁定时只组织可见性；确实拍不清则把具体冲突交回对应模块协调。
22. 释放画面继承已定技能的主形、作用与阶段，选当前源头/逼近/负载/结果的必要关系；静帧不叠全流程，巨物局部与人物参照同一事件，固定镜头不暗插特写。
23. 能力覆盖按当前证据选择成形、目标逼近、接触或结果视点；真实切镜与同镜取景变化分开，一次作用跨镜不能重复发生。
24. 尺度由当前地标和占幅关系建立，迎面通过接远去，局部接触接范围传播；反打重算投影，不将银幕变向误认世界折返。
25. 有威胁时组织人物当前空间、攻击侵入与可用出口，切点继承同一次作用；范围景以地标/层级接住人物后果，不套固定镜数。
26. 按技能机制读取触发、关键变化、接收端与后续任务；小技可看微变，大场面可看网络/环境/区域规则，不强制手特写或巨物三镜。
27. 继承已采用动作模块，以身体轮廓、攻击端/接触、支撑与目标关系读清本次差异；局部裁切由同次邻镜接必要身体过程。换角度不等于换动作，只改构图，不新增招式或取消锁定拍法。
28. 已有成年角色魅力、腿技或足部细节设计时，在本职责内继承实际衣装、相位、支撑、对象和出口；不因本规则新增身体动作、换装、特写或改变战法。保持当前格式，不把相关展示变成每场配额。
29. 成人魅力按本次形象选择眼神、胸肩/腰胯/腿线与衣料随动；接触、衣料抓扯、通道受限按来力/抓点/约束、形变、撤力恢复与剩余状态设计，区分透视变大和局部响应。成人身体互动展示采用双方自愿的非露骨表演；不将强迫脱衣色情化。抽帧观察不证明正常速度节奏、稳定物理、赤足或腿技，保持An声画分栏。
30. 舞蹈覆盖按轮廓、支撑或脸手表演相位选择机位/景别，在准备、展开、变化和回收中读清采用重点；特写与邻镜承接，不强制全身固定或镜数配额。
31. 高速交锋用近处来刃/地标、中景身体、后景目标建立动态纵深，避免无任务的同侧平列；巨型局部、环境参照与人物接同一次作用。
32. 来刃/交点/身体/目标/地标/出口的投影组成当前构图，攻击作用点、避线位置、落脚和相机落幅分开；近景与范围接同次作用，画幅变化后重算。
33. 提速沿同一条采用事件链完成本职责并回填原稿，不另造整场竞争草案或逐栏重复完整动作；已有有效决定只因新约束、具体矛盾或观看缺项才重开。联合复核满足要求即交付，修复只重查依赖范围，上游影响全场仍查全场，不限制必要修复轮次。保留必要设计、动作/技能密度、摄影/画质/物理/尺度与观看证据；不设字数/镜数上限。未测不报加速比例，文本通过不证明成片质量。
34. 涉及已定快战时只完成本职责的形体、表达、时间或检查；动作/施法、摄影和区域主峰的缺口给所属层具体证据与依赖建议，不借快战规则重编整场。明确禁用、原战法与合法保持继续继承，文本/ZIP不证明成片。
35. 各题材按观看任务选择镜头语言：文戏/情绪、悬念/揭示、人物关系、追逐/写实动作、奇幻战斗、巨物/灾变、舞蹈与氛围分别处理。特殊能力快战少固定、少慢移，固定主要用于明确艺术化、文戏/表演或用户锁定拍法；不以尺度/接触/传播自动放宽，也不将快战速度套给其他题材。联用只回填本职责，不重导演或强制所有模块必调。
36. 构图读运动中的轮廓、关系与结果，观众注意沿动作端/接触/新威胁交接；分镜静帧不等于整镜持姿，不强迫中心构图、等镜长或固定镜数。
37. 决定、局部原因、技能主形、关系、接收与新行动按当前注意交接，前景/焦点/尺度/斜向关系服务本场；正常实体画面可成为记忆主峰，不凑镜序或每击抽象化。
38. 局部读操作/受载、关系读路径/击退/保护位置；脚部区分落步、离地和蹬离。前景手臂/器具框住见证者与随后协同按实际前后层和注意选择，不凑每招覆盖套餐。
39. 先选观众的知情与等待，再选脸/手/术法/敌人/范围；特写真实占幅、轮廓、焦点与留空读清证据，切回接已发展的相位。按信息与力量关系切，不只匹配碎片/兵器，不等镜长/每招三镜；一镜到底用画内变化。
40. 动作/打斗的镜头包络和必要切点默认写到0.1秒；同镜可含多个相位，时间节点不等于新镜头。接触/受力与结果按观看收益覆盖，固定/一镜到底继续合法。
41. 明确特写用CU/ECU对象、实际裁切和细节兑现；构图检查起幅、中段、落幅的主次、轮廓、空处、纵深与参照。中心/三分/负空间/三角/框景等由实际对象组成，运动后重算投影；只回填构图/取景，不改角色事件。
42. 未被点名的构图与局部覆盖仍按本次观看任务主动选择，重要线索、微小变化、人物关系和尺度参照实际占幅可读；空处/框景/纵深随事件变化，不只添加名称。原固定/单镜和有意隐藏仍优先，只改取景与构图。
43. 仅舞蹈覆盖：按已编身体线条和双方回应选择同框、纵深与局部；中景读肩胸/动作手，宽景读完整旋转/支撑，特写读当前变化并接对方回应或下一相位。横屏间隙随动作发展，不固定平列；增加镜数或景别种类不证明美感，动作已成立仅缺覆盖时只修本职责。
44. 一镜交锋按来袭、接触、避线出口、回击通路与新威胁选当前可辨关系；同框足够就不强增景别，近看局部时仍有承接依据。只改占幅/层次/轮廓，不将未知光叠加当命中，不为构图改动作。
45. 多人连续段用原身份轮廓/服装主块/持物归属、进深和不同相位组织多线读取；转注意之前下一关系已有可定位位置，遮挡后用地标和轮廓接回。触点/器物近景按当前证据选占幅与清晰范围；只改构图读取，不新增动作或改造型，不要求全员每镜同框。
46. 能力作战按当前主体验与本功能职责取控制、作用、接收和范围的必要证据；保持有读取与出口，同次作用/本体/对手共用时间。能力战不自动慢化或高频化，只回填本功能获准变量，不因联用扩大为整场重设计，沿原模板交付。
47. 打斗构图继承人物与作用结果；无依据换位或受力结果给具体冲突，只换侧面的切镜按实际观看收益核，不一律列硬错。
48. 打斗分镜没有 blocking 和覆盖设计时，不靠增加镜头数量或漂亮角度补；先定空间、朝向、切点。
49. 必要作用、空间与结果按既定镜头和时间读取，可在镜内完成；镜数与样例时长不代替证据，短镜不靠切碎制造速度。
50. 构图先定注意与空间任务：偏心/负空间/前景遮挡/对角线/框中框/尺度对比按当前问题选，不堆三分法或随机Dutch。
51. 给决定性证据主读窗口，其他层同时间继续；同构回返和眼线回应按收益成立，不按变化项数判错。
52. 2D景别/构图按分层、视差、色块和剪影检查；真人机位规则只取观看职责，不硬搬。
