# 多参考绑定

沿用入口规定的真实标签、上游模板和职责，只在复杂映射需要时展开。

1. 为每个主要人物/道具建立稳定称呼和逐项映射，不写“图1至4分别定义四人”而不说明谁是谁。
2. 同一人物多个视图明确为同一人；一件道具多视图仍是一件。身份图不控制临时背景、站姿、排版或光向，除非用户同时锁定。
3. 多场景选当场实际活跃主体与素材，不把所有参考强制摆进每镜。原编号保持，不能按每场重新编号。
4. 归属区分初始持有与剧情交接。“只属于A”不能否定用户已定交给B；写清接触承托、放手和交接后的持有者。
5. 跨场景主角可在后台合并身份、服装、道具和声音来源；上游已锁定时不另交档案。

```text
@图片1定义A的身份和服装，背景及图上站姿不继承。
@图片2与@图片3是同一把剑的不同视图，定义结构和材质，全程仅一把实体剑。
@视频1只参考已批准的运镜节奏，不继承其中的人物或场景。
开场剑由A右手持有；到既定交接事件，B左手承托后A松手，后段由B持剑。
```

示例标签换成平台真实插入形式；没有视频或交接就删对应句，不能因此新造事件。
