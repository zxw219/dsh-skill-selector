# 关键帧、分镜格与白模

具体模式是否可用、画幅如何继承由当前平台配置决定；提示词声明职责不等于开启模式。首尾图比例冲突时指出并按已授权方式准备兼容资产，不静默裁掉关键身份或动作信息。

**首尾帧**：分别写首图的入口构图、主体/道具状态，尾图的出口；身份与风格图只能补允许属性，不能覆盖边界。中间过程仍要有因果与可达路线，不把两个不相容结果直接接起来。

**多关键帧**：明确真实图片顺序与每张的关键状态，人物、武器归属和环境变化连续。关键帧控制阶段顺序和状态意图，不保证每张逐像素重现或帧准确命中。

**分镜格**：说明阅读顺序、各格事件与近似构图；线稿、标注、排版和占位角色是否继承由职责决定。格数按素材可读性与界面能力，不把原包15格经验当通用硬上限。独立关键帧与格图按实际任务选用，不要求一律拆图。

**粗白模**：用简单几何表达路线、调度、相机和时间关系；逐一把几何对象对应到真实角色/道具，只继承明确职责，不带灰模外观。补当前最终场景、身份和视觉。

**细白模**：完整模型已提供结构和动作时保留这些关系，仅重绘获准的材质/角色/背景；不因换外观重排动作或机位。坐标轴、路径线和控制器可能被读成实体，实际资产制作时准备干净输出；只写提示词不自动改素材。

上游已有锁定稿时，引用白模只支持同一方案。素材和稿件冲突，返回具体冲突位置，不能让“白模强控制”静默覆盖用户事实。
