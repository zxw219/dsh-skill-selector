# 精准编译：少修辞、少术语、保留作用

本项目面向Seedance 2.5的成稿优先采用精准、精简表达。这是用户的工作方法要求，不作为官方对全部提示词的字数、词性或效果保证。继承上游时长、格式、剧情、动作、强度和素材职责。

## 保留能改变执行的内容

用明确的主体和动词组织句子，按当前歧义补对象、方向、条件和结果：`谁 → 做什么 → 作用于哪里/谁 → 发生什么变化`。方向已唯一时不重复写，瞬发不加无用阶段。因果接续仍需要的支撑、接触和出口不能为了短而省掉。

- **形容词**：删除同义赞美和无画面作用的程度词。颜色、薄厚、材质、速度关系或占幅在区分主体/主形、决定作用或观看时保留；优先写“掌缘遮住山门上方天空”，少写“极致震撼的宏大压迫”。
- **名词**：保留角色、作用物、目标与必要参照；同一对象统一一个名称。删掉同物异名、技法堆叠、软件/器材术语和未参与事件的新增物件。名词少不等于把“谁打谁”省成“爆发”。
- **镜头**：写必要起点、路径、触发与落点；当前只有一种合理理解时短写。用“相机沿桥侧跟移，A追近并掠过”替代无作用的拍摄术语串。
- **特效/质感**：保留能区分当前效果的形态修饰、运动比喻、主作用、关键材料变化和必要残留。“极薄的银白月牙斩”指定厚度、颜色与轮廓，“阴影被刀锋甩出来”指定介质感与运动；不能只为删形容词把它们压成“刀气”。比如“膜面凹陷，骨架弯曲后断裂”，不用再叠加风暴、雷电、粒子海与泛光来形容同一命中。用户已指定这些效果时保留并明确各自作用。
- **表演**：留下会改变人物判断与动作的可见行为；删全脸部位罗列。比如“她看向正在闭合的缺口，压低身体蹬离”，无需同时填所有情绪标签。

内部导演设计可以充分，提交正文只保留选定方案需要的指令。固定时长和既定模板继续有效，不把精准误解为取消分镜、只写一句或削弱动作与大场面。

## 参考与负面约束也要精准

作品名后限定借鉴对象，如“参考《影之刃零》的贴身兵器追压与快速攻防衔接”，再写本场双方实际如何追步、避线、卸力与接招；不靠“同款顶级战斗”让模型猜全部设定。没有参考视频时，不编造某秒某招的观察。角色特效仍服从本项目设计，不因提到游戏就自动继承衣装、招式、法术或胜负。

“杜绝慢吞吞”等用户要求可以保留，但正文须给出对应执行办法：攻方在守方撤步时追入，接触即卸开接招，相机与人物的相对距离持续变化。仅保留本场易偏离且尚需强调的限制，避免复制几十条禁令。慢镜、蓄势或静止属于用户意图时照常保留，不把精准等同全片匀速快打。

特效的写法与参考、负面约束的转译例见[战斗写法](../../an-workflow/references/combat-writing-patterns.md#7-把参考特效与负面约束编成指令)。共享规则放全局，镜内写触发后的变化，不重复整段效果词。

## 去重顺序

共享身份、风格、能力规则和声音范围放全局一次；阶段内描述变化。承接导演选定的角色战斗语言/特效体系、连续事件与当前模板，将行动、形态变化、对方响应和观看方式接续，保留有效修饰与运动比喻。已有或选用分栏时，S写触发与行动，fx-env写效果结果，sound写获准声音，transition写实际切换，各栏不再重发同一事件；不能为去重自动换掉模板。

优先删除：研究解释、同义形容、重复规则、同物异名、无作用术语、已经由相邻句唯一说明的关系。只在不会删除锁定内容或关键歧义时合并句子。不要靠固定字数、名词数、每段句数或毫秒时码冒充精准。

对一项修饰/名词/句子做删除检验：删后是否仍能唯一确定身份、动作、目标、路径、观看、材质区别、结果和承接？能则删；不能则保留或换成更直接的表达。不是每句话都补全八项。

## 调用与模式边界

| 当前输入 | 编译行为 | 核对重点 |
|---|---|---|
| 上游An稿，明确2.5 | 继承上游全部采用决定，仅一次适配真实标签/语法 | 不启用旧版独立默认时长、SCELA重创或类型模板 |
| 独立明确2.5 | 从真实输入补本任务必要设计，时长按内容/用户要求 | 不从平台上限反推必须填满，不虚构素材 |
| 2.0或未知版本 | 不使用2.5专属模式；回已选入口或中立表达 | 30秒、多参考、泛称即梦不判版本；本表不声明平台现时上限 |
| 局部编辑/只改音轨 | 唯一母版、范围、目标与保留项，按实际可用模式编译 | 不把替换变成新全场，画面/其他声轨保留按原请求 |
| 前补/后续/桥接 | 以源片对应首尾的真实状态建立边界 | 动作、相机、损伤、声音和未决作用承接，不强制停两秒 |

平台事实仍只从唯一配置源读取；执行依赖的功能需核当前接入端，方法对照不是功能开通或精确执行证据。

## 压缩后核对

确认主体与对象仍明确、指代不跨段漂移、左右/地标使用一致、动作前后能接上、主形与材料仍有区分、峰值结果保留、用户原词与模板未变。不要用压缩比例证明质量，不从文本精简推导视频更稳定或逐帧服从。

精准的目标是减少互相争抢或需要猜测的指令。生成未执行时按实际偏离修最早缺失条件，不能持续追加“精准、稳定、震撼”等要求。

分栏、时间阶段与共享分区是不同层次，可以同时使用。取消标题、合并动作效果声音或减少字数不构成模型质量证据；同一事件的文本对照见[分栏与精准复核](../../an-workflow/references/combat-writing-patterns.md#分栏阶段与精准分别判断)。已有模板内清除重复、补明指代和接触即可，不能把“少修辞”解释为必须取消分栏。

## 完整版参考转译后的删减检验

删除一条承接句前，检查是否仍能确定谁持续持物、哪只手可控、效果来自哪里、器具实体与扩展面的区别、接触后的目标/身体状态，以及恢复/换器具的窗口。材料相位改变时保留薄厚/透明度/刚性等有作用修饰，重复身份可去重。未知归属或机制不能靠平台编译补齐；源片PTS、120fps容器值和长形成时长不作为2.5执行保证。参考规则见[执行方法](../../an-workflow/references/narrative-combat-transfer.md)，只处理当前已选模式。

## 设计事实、平台事实与执行证据

编译前区分三类：用户/上游锁定的作品事实；目标接入端当前支持的功能与标签；提示词表达的设计目标。官方写法建议可帮助组织输入，但其中的示例节拍、镜数、开场/结尾结构和精简方案不覆盖用户模板或已采用事件。

局部编辑先确认唯一母版、范围、目标和保留项；后续接实际尾态，不能把编辑描述写成重拍全场。未确认接入端模式时不保证设置已存在，未实际生成不保证时间码、动作或文字被精确执行。
