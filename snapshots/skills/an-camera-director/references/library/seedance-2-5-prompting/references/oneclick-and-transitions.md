# 图片组片与两段桥接

模式可用性由平台当前配置确认；只要求普通视频或组图不能自动推断2.5功能。正文沿用上游格式，按需写以下信息。

**图片组片**：素材职责 → 实际顺序 → 每图需要的局部动作/视差 → 镜头衔接与节奏 → 共享视觉 → 已允许声音。风景与人物动作分别设计，不能给每张图都加相同推镜。音乐、贴纸、字幕和对白必须已有授权，不从原包旅游示例继承。

**过渡桥**：前片真实尾端 → 后片真实首端 → 触发动作/遮挡 → 相机路径 → 形/光/空间的变化 → 到达状态 → 已允许的声音承接。

先找两个边界已存在的形状、视线或运动关系，再选择前景遮挡、匹配形状、推进/后撤、转焦或经授权的形变。维持世界状态与运动惯性，不用突然静止再另起相机运动声称连续桥接；确实切镜时明确切镜。

桥生成与剪辑拼接不同。若要求两段原片保持完整且像素不变，保留原文件、独立生成桥并交后续剪辑；不声称在一条生成结果里把原片逐像素保留。用户只要提示词时不自动生成或剪辑。
