# 摄影与视觉锁

只细化上游缺失且当前任务确需的视觉字段，不自动增加器材、手持或音轨。

跨镜在已有全局栏锁一次媒介、主要色彩、明暗/高光、材质、必要颗粒和景深；每镜只写变化。共享器材风格不是所有镜头必须同一焦段、光圈或摄影机运动；剧情换光、转焦和局部图形重音可以有已定变化。

器材名称是风格意图，配可见描述；不把名称当真实设备模拟，不从T值推断“一米外必虚化”，景深同时依赖镜头、距离和成像条件。需要真实产品规格时再核验，未知则用等效视觉描述。

| 观看目标 | 可用描述 |
|---|---|
| 有机胶片观感 | 细颗粒、柔和高光滚降、适量高光光晕，保留材质细节 |
| 清洁商业质感 | 产品边界可辨、色彩忠于锁定资产、局部高光有层次 |
| 夜景宽银幕观感 | 经允许的椭圆散景/水平光晕，暗部仍有主体边界 |
| 手绘二维/刮刷 | 稳定轮廓、色层和笔触；不强塞实拍器材或光学散景 |
| 固定观察 | 相机不移动，动势来自主体；不混用默认手持微漂 |

低反差/抬黑与深黑/高反差不可同时作为同一全局目标。需要局部差异时写清区域和触发。全局视觉锁不决定表演、配乐、字幕或慢动作；这些由上游拥有。删除原包预设中未经用户允许的音乐、时间戳叠字和镜头抖动。
