# 大场面与冲击导演

让观众看清力量如何跨越空间、遇到抵抗、改变战场。可独立设计，也可给现有分镜工作流回填场面、效果与节奏；保留用户的时长、风格、角色能力、胜负、破坏限制与输出模板。


## 先守角色战法

先确定本场类型、主战距离、既有持物与发动/控制任务；法师、召唤师、领域术者的高速/美感来自相容施法、移位与法术协作，不默认拳肘腿或添加盾剑/护臂/晶甲。若缺角色适配、施法身体语言或本体与代理分工，定向读[角色战法与施法协同](../an-workflow/references/character-led-spell-combat.md)。联用只处理本职责，采用原角色机制；不全禁近身/防御，也不把领域、巨莲或星体塞给所有角色。
## 先锁住本场必须兑现的作用

用户明确要求大招、技能或震撼场面时，先继承本场已定能力与主峰任务，将必要作用锁到正文事件：哪一主形/规则改变哪片空间，对手在同一时间怎样承受、穿越或反制，改变后的战场怎样接下一行动。全局设定、技能数量上限和结尾一句“巨大爆炸”不算采用；本技能只补场面、尺度、后果和观看证据，不借此新增能力、胜负或重新编排整场战斗。

把主形、宏观介质与人物行动共同编排：范围变化在作用中越过已知参照，近处承受与远处传播属于同一次原因，人物继续争路、换支撑或处理既定威胁；不能先写一段无技能的推搡，再在 `fx-env` 追加震撼词。巨大、高能可以来自离体攻击、自主代理、领域规则或环境结构变化，不一律做成巨大实体道具，也不强制慢蓄力、即时破口与统一六拍。仅采用机制实际存在的阶段，保留单次终结、无破坏和瞬时作用的合法设计。

冲击先选符合媒介的决定性形体、力量方向与强弱节奏，再定需要的曝光及传播层次；不把每次碰撞都做成负片、白闪、鱼眼和抽帧的同一套餐。写实、风格化三维与二维采用各自相容表达，普通反馈与高潮靠实际负载、范围变化和后果分层；规模加强不等于所有接触同强度闪爆。

## 先定位缺口

“大、强、快、冲击帧多”是不同诉求，分别兑现。先从现有稿中找可见证据，缺哪项就修哪项：

| 用户反馈 | 优先改变的内容 |
|---|---|
| 特效很多但场面小 | 技能与已知地标的比例、跨区域传播、镜内逼近；让关键大效果在行动过程中展开，而非结尾一张废墟远景 |
| 场景很大但没有力量 | 作用面如何受压、失效和传递；破坏是否改变角色支撑、退路或攻击选择 |
| 满屏很亮但看不懂 | 主形、锋面、流向和受力对象；用明暗、阶段与遮挡组织高密度，不默认减弱特效 |
| 冲击帧看不见或只有一次 | 先设计可辨认的特殊造型画：剪影、正负形、抽象力线或粗笔触；再明确插入动作的相位、事件数量和每张曝光，不只写“很多冲击帧” |
| 加长冲击帧后像幻灯片 | 区分画张数量与每张曝光；长序列可切换多张不同设计的冲击画，穿插停留与急切。连续开裂、喷散本身不构成冲击帧定义 |

需要具体空间、巨物、破坏或效果主导编排时读 [规模与场面调度](references/scale-staging.md)。巨型压迫、巨神局部支配战场、法相天地/法天象地显化与巨型肢体作用时读 [巨型压迫与法相显化](references/giant-pressure-manifestation.md)，先落实观看尺度、操控和角色承受关系。冲击帧数量、可见时长或快慢节奏是重点时读 [冲击帧造型与曝光](references/impact-rhythm.md)。学习依据、维护与边界见 [研究记录](references/research-notes.md)，普通创作不必重复联网。

## 场景参与、巨型交互与记忆画面

场景只是爆炸背景、巨物只作一次撞击或宏大却不炫酷时，按[战斗体验设计](../an-workflow/references/combat-experience-design.md)先让本场结构/主形改变人物选择，再设计对方反制后巨型作用的变化和主峰关系。一次投射、局部显化与完整召唤分开；不强制召唤完整兽体，也不把狐首直撞当已完成丰富交互。冲击帧要有区别于普通效果的特殊形体和清楚进出，尺寸、亮度和短白闪不能充数；只修场面职责和当前获准依赖。

## 稿内设计

核心技能尚未设计或每次只是更大爆炸时，联用[技能、特效与释放画面创作](../an-workflow/references/ability-effect-authoring.md)先选实际任务与主形，再安排本页尺度、作用和观看；已有锁定方案只补适用关系，不重新定能力。

1. **确定主要场面事件。** 用动词写清一次关键变化，例如“推进的波面掀起桥板，迫使两人转到倾斜桥肋继续争夺通路”。选择本场最值得观看的主形与变化，不轮流堆火球、巨剑、法阵和陨石。用户有锁定内容时在原能力内放大表现，不擅自发明新能力或改胜负。
2. **建立尺度和压力。** 用角色、门洞、桥跨、楼层等已知物体作参照；安排效果跨越、遮挡或吞没参照的过程。人物要面对正在接近的具体危险，摄影同时让观众知道它占了多大空间、何时到达。巨大角色可以高速；不用全程慢动作证明体量。
3. **连接作用与后果。** 明确源点、有效边界、传播路线、承受对象、抵抗、改变与持续状态。结构破坏服从本场材质和作用，幻想规则可夸张但要一致。后果可以是海面/云层大范围位移、屏障变形或阵形改动，不强制摧毁建筑。
4. **安排观看与节奏。** 让主效果获得看清形成、逼近或破裂的实际镜内时间；必要时用同一事件的接触近景与扩展广景接力。宏观变化与人物高速选择共用时间，不把角色停住给特效摆造型。在关键动作附近插入特殊造型画，先设计形状、明暗和力量方向，再安排曝光与切换。长冲击序列可由多张冲击画组成，不能直接用一秒慢放爆炸替代。画内允许抽象化，进出序列的动作保持因果连续。
5. **编回正文并检查。** 场面初始关系进“画面”，动作与作用进 S 段，破坏/粒子进 fx-env，声音进 sound；独立时按用户指定格式交付。默认不输出内部表格、评分、推演菜单。

## 表现选择

- 效果主导时，先确定覆盖战场的主轮廓、运动和视觉峰值，再围绕它组织角色的进攻、穿越、截断与反制。不可仍写十几次小范围格挡，仅在 fx-env 附一句巨大爆炸。
- 先看宏观形体成立，再丰富碎片、雾、流体和电弧。大块受压变形、支撑失效和二次碰撞具有不同观看价值；不是所有东西同一时刻化成均匀粉尘。
- 取景可用近处参照和压顶威胁，也可用远景看传播路线。保持必要的边界、方向或标志性缺口；不要求每镜全形，也不让全片巨物无边界、人物无位置。
- 主峰应兑现前面的力量或战术累积。高强度请求可以开场即有规模，再通过作用方式、空间方向、视觉明暗和结果升级；不默认把大场面拖到最后两秒。
- 可用形状冲突制造审美：狭窄斜向切口对宽阔压来的波面、垂直坠落对横向冲刺、连续曲面被突然撕开。选与本场技能相容的关系，避免无用途花纹、随机旋转和统一圆球。
- 声音依授权表达接近、接触、结构断裂和余波，留层次；静音版本仍须凭画面成立。高音量、频闪和震屏不单独证明冲击力。

## 一次复核

- 删掉“震撼、史诗、巨大”，是否仍能指出参照物、跨越距离与主效果的变化？
- 去掉装饰粒子和配乐，是否仍看见受力、抵抗、失效及下一行动？
- 观众是否看到了扩展或崩解正在发生，而非白闪前完整、白闪后废墟？
- 角色是否仍主动攻击、闪避、拦截或抢路？跨镜后破坏和能力状态有没有复原？
- 冲击段是否写出具体特殊造型画、插入相位、曝光和画张关系，而不是普通效果动画慢放？抽象画面进出时的动作与结果是否接得上？
- 所有时间区间按成片时间计入一次；数量与时长是本片选择，不建立通用配额。

有成片时先正常速度看能否读到主作用和规模，再检查帧；只有提示词时报告文本设计与风险，不声称已获得成片效果。明确用户希望强化时可直接返工，不用研究或样片验收替代已授权的提示词交付。

## 与上游导演工作流的分工

An或用户当前选定的上游导演工作流管理剧情、状态、全片时间和声画模板；本技能回填场面、尺度、后果和冲击节奏。摄影管路径，动作管攻防，特效管材料与生命周期。外部MOKE MCP只提供按需资料；无上游时本技能仍可独立设计，不依赖外部检索。

## 规模、抵抗与后续任务的增量补强

规模保持现有参照、侵入/传播、抵抗与永久后果，在主峰后让人物/代理继续处理改变的通路或状态；不让所有人停住等宏观镜展示完。次级大尺度响应可以比本体普攻慢，两者共享同次原因而非整场慢放。静态压迫、纯展示、长冲击与用户锁定强度保留，不因修摆姿削小场面或改胜负。

## 高潮兑现与持续压力的参考学习增量

尺度主峰兑现人物选择或已建立的力量，局部负载交给同次范围反馈；持续受压可保持，大范围传播/后果与本体速度分别设计，保留强度、长冲击和纯展示，不强制翻盘。按需读[有关方法](../an-workflow/references/battle-excitement-direction.md)，联用只补本职责，不重导演。

## 完整版剧情攻防的执行增量

巨大尺度接有效危险部位，环境受扰与人/地标参照共同证明；负载近景接身体击退或结构传播。技能维持/破碎/存留形态帮助结果读取，保留已要求的大范围和质感；终击未展示结果时不自判胜负。具体关系按需读[剧情攻防执行方法](../an-workflow/references/narrative-combat-transfer.md)；仅回填本职责，不重新导演整场或强制读源报告。

## 最新学习的职责内执行

按[规模接力写法](../an-workflow/references/high-frequency-scale-writing.md)落实怪海入口/深度/近层威胁、巨型主形显露、首触/抵抗、范围结果和旧后果再利用。主峰与人物选择共用时间，按[信息覆盖](../action-camera-direction/references/information-led-coverage.md)交接人物端和大范围；不以满屏亮或一张废墟证明升级。
