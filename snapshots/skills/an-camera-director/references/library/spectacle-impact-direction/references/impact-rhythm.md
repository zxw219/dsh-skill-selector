# 冲击帧：特殊画面设计与曝光节奏

用于 impact frames 的设计和返工，尤其是“像慢动作、只是换色、看不出冲击帧”和“大量冲击帧、持续可以长”。先设计插入哪些特殊画面，再安排曝光与切换；不以特效展开的秒数代替冲击帧设计。研究依据与读取范围见 [研究记录](research-notes.md)。

## 核心区别

冲击帧在关键动作附近突然改变既有图像语言，以专门设计的图形画面强调力量、速度或情绪峰值。黑白反差、负片、极端剪影、变形、粗笔触、抽象爆形和限色都可用；它不被某一种颜色、固定帧数或接触类型穷尽。

| 手段 | 设计对象 | 与冲击帧的关系 |
|---|---|---|
| 冲击帧 | 某张特殊画的形状、明暗块、力量焦点及插入位置 | 可以是一张，也可以由不同设计画组成连续或间隔序列 |
| 打击停顿 / hit-stop | 动作在接触附近停留多久 | 可与冲击帧同用，普通姿势停住本身不等于冲击帧 |
| 慢动作 / 速度变化 | 动作时间如何伸缩 | 可以承载冲击帧，放慢碎裂过程不能直接改名为冲击帧 |
| 拖形 / smear | 高速姿态之间如何连接 | 可参与冲击造型，也可出现在没有命中的移动中 |
| 爆炸、碎裂、波面展开 | 效果形体如何运动和产生后果 | 大效果可持续很久，在关键阶段另插冲击帧 |

图形冲击可以暂时抽掉背景、改变局部比例、让人物化成笔触，甚至在序列中插入纯黑/白画。不要要求每张特殊画都像正常镜头一样保留完整人物、环境和接触几何；要求的是入口与出口的动作、作用点或主方向可承接，不让抽象插画承担实际换位或凭空命中的解释。

## 先画什么，再放多久

对选中的重音，在稿内确定以下决策，正文只保留会影响结果的部分：

1. **锚点**：强调接触前的压迫、实际命中、力量贯穿还是爆发/突破？按动作相位定位，不固定在碰撞之后。它强化哪一个已成立事件？
2. **特殊造型**：哪些纹理与背景要抽掉，留下什么剪影；受力部位怎样挤压、拉伸、截断或夸张；力量焦点在哪里。
3. **力量方向**：线条、尖楔、破口、笔刷和明暗边界指向本次运动。斜斩可用贯穿画幅的楔形，挤压可用向焦点收束的块面，爆发可用不均匀放射；不把任意网纹当力量。
4. **张与张的关系**：选择对比、反相、形状跳变或造型递进，不要求全部采用。下一张要改变观看感受，而非同一个慢镜头逐步调亮。
5. **曝光和退出**：每张画曝光多久，是否复用或留正常动作间隙；最后一张如何通过姿态、方向、作用点或形状匹配回到正常运动。

颜色反相是一种可用方法，不因简单就否定；是否有效取决于前后差异、焦点、时机和动作承接。复杂重绘也可能失焦，不以笔触数量判断好坏。

## 用户要求“大量”或“时间可以长”

分开设计**重音出现次数、不同设计画的数量、各画曝光的时长**。一张图曝光24格仍是一张设计画；十二个标签不证明实际生成了十二处冲击帧。

- 允许长序列时，以多个特殊画组成冲击序列：轮廓、正负形、力量笔触或局部抽象快速切换，关键造型按节奏短留，再突然恢复正常动作。长的是整个序列，不自动将同一张图拖长或让所有图形平滑演变一秒。
- 明确要长定格时照办，停顿与特殊画造型分别设计。不从“冲击帧通常短”推导出禁止长曝光，也不从“可以长”推导出每次必须长。
- 大量冲击可密集分布，按实际力度组织强弱和图形差异；不限制只给最后一击，也不每隔固定秒数插黑白帧凑数。
- 只说看不见时，先查触发、特殊画与常态的差异、造型是否被其它要求挤掉，再决定加曝光、加不同画或扩大表现；不要只改总时长。

## 帧、画与秒

帧是时间采样位置，设计画是视觉内容，曝光是这张画占用的时间格数。已知输出帧率时：秒数 = 曝光帧数 / 帧率。例如24fps示意中，三张各曝光1格的画共占0.125秒；这是算例，不是必须三张或最长0.125秒的通则。

未知平台或帧率时仍可设计“先哪张画、随后换什么、哪张稍留、怎样返回”，用相对曝光描述。用户指定总秒数则据此组织整个序列；给帧数示意要注明假定帧率，不当作平台保证。真正剪辑、逐帧制作或取得成片后才能核验精确执行。

## 原创局部示例

原场景：青白剑刃从左下切入右上方红色护盾，盾后人向右退。

错误：护盾在1秒内慢慢开裂，碎片持续喷出，整幅改成黑白；因为持续1秒，所以称作长冲击帧。

改为设计画序列（不是固定三张模板）：

- A：抽掉正常背景，黑色斜楔从左下切入；双方压成方向相对的极端剪影，盾面只留一条向内凹的白线。
- B：明暗骤变，白底上只留黑色锯齿裂形；人物轮廓部分断成粗笔触，裂形从接触处沿右上方向贯出。它是力量图形，不是盾真的变成墨水。
- C：限色青白切线穿过压扁的红色盾形，受击侧轮廓拉长；接回正常画面时对手已向右失衡，盾面留下真实破口，碎屑按正常效果动画继续。

每张特殊画可保持曝光，不要求单张内完成完整物理过程。长序列可增加互有差异的画或调整曝光，而不是把三条分别写成三段慢速爆炸。

## 编译与复核

先锁动作锚点，再锁特殊画，最后安排时间。正文可写：

S=…：剑锋切入盾面，插入冲击序列：黑底斜楔剪影 → 白底锯齿破口 → 青白切线与红色压缩盾形；中间画快切，关键剪影稍留，随后沿原斜斩方向恢复高速，对手向右滑退。

明确时长属于当前S段的子区间，不在镜头外重复累加。图形切换本身不要求新机位；真换摄影位置才另建镜头。fx-env管持续爆炸/碎裂，特殊画造型与切换写入主动作，不埋在全局形容词里。

- 去掉“冲击帧”标签，能指出特殊画长什么样、与常态差在哪里吗？
- 是否把换色慢镜头、普通停格或持续爆炸误当成多张设计画？
- 入口、力量图形和出口承接同一事件吗？抽象化之后有无凭空换位/命中？
- 画数、曝光和总占时是否分清，保留用户要求而不建立通用配额？
- 正常播放形成重音、逐帧可查对应画面吗？无成片只报告文本设计，不用时间轴检查替代视觉验收。
