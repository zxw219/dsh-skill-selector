# 规模与场面调度

本页用于效果主导、巨物压迫、跨战场技能与连锁破坏。所有例子都是可替换的原创设计，不是强制剧情。

## 先把画面中的“大”建立起来

数值、世界大小和画面冲击不同。写“千米剑气”后只拍手腕，观众仍无从感知尺度。选已经建立、可识别的参照，让它与效果发生可见关系：

- **总体跨度**：一道波面同时跨过多个已建立桥跨，近处桥塔与远处山门仍可辨；波头尚未越过终点，不只看到一个出框局部。
- **贴身压迫**：站在角色附近看巨物下缘越过屋顶，天空余隙不断收窄；角色在落点边缘抢出路。低角度并不等于把摄影机埋进地面。
- **距离被吞掉**：威胁依次越过地标，形体在画幅中变大；退移相机不要始终与它等速，使逼近永远停止。高速角色可沿参照穿行，不用连续瞬移省掉路径。
- **受影响介质**：水体、云层、沙面或林冠被主作用推动，变化跨越可见区域，显示大体量；无来源的远山同步炸开不能充当证明。

同一场可以在广景读全貌、在近处读局部负载。景别切换须指向同一个已建立形体和事件阶段，形体尺度不能在切镜间漂移。近大远小取决于相机与物体的位置关系，换焦段或写“超广角”不会独自改变透视。

范围与破坏已经很大但仍缺压顶感，或出现巨神、巨手、法相时，补读[巨型压迫与法相显化](giant-pressure-manifestation.md)：重点转向巨物局部占据人物空间、微小动作产生悬殊代价，以及近处抵抗与宏观作用的观看关系。

## 持续的场面事件

先画出“现在能走哪里、攻击能到哪里”，再决定大效果改变其中哪项。把下面的关系编成一段持续事件，而非必填六镜：

`源点/触发 → 主作用越过参照 → 抵抗或接收 → 局部失效向外传播 → 角色改招 → 新战场状态`

**接收端决定形体。** 厚墙被刺穿呈通道，薄屏障被顶压呈凹陷和裂口，成组桥板先失去支撑再倾转；不能任何攻击都变成同一个球形爆炸。持续束流的交界随双方控制变化，不无因固定在中点。离体弹体沿既定路线走，不能施术者转身就整条折回。

**连锁需要连接。** 被击断的桥肋承载桥板，桥板掉落撞上下一层回廊，回廊失效改变追击落点。这些连接先在场景中成立。非结构连锁可以是已设定阵法的传导、连通液体中的扰动，写明路径；不把“连锁”当所有远处物体同时爆炸的许可。

**用持续结果组织战术。** 退路断裂后改走倾斜支撑，盾面凹陷后改变拦截角度，尘浪遮挡让进攻者失去目标再依可见证据追踪。对手在效果传播期间仍抢攻、追击或干扰，不能等施术者播完技能动画。

**破坏和材料分工。** 先识别原有结构的整体运动，再让连接失效、块体分离和适用的次级碎屑随原因发生。石块不全变成细粉，金属可弯折、拉裂，烟尘从破坏区发出。大块可在后续碰撞时进一步碎裂；不要规定大块永远先落地或所有粒子统一消失。

## 特效主导的动作编排

先选主效果的形态和作用方式，再决定人物如何穿行、拦截与争夺源点。例如宽阔熔焰波面迫使剑客沿边界冲刺，反击切口从近处接触点向远处展开，刀客改变供能方向试图封闭缺口。双方选择与主效果的形态互相改变；不退化为轮流站桩发弹。

粒子细节服务主流向。宽波面可以有卷起的边缘、内部断层和被推行的物质；狭缝可以通过强明暗差从密集特效中读出。允许画面大部分由特效占据，但关键阶段至少保留能判断作用的边界、入口、人物剪影或地标。

高强度可以从开场就兑现。变化来自作用范围、推进方向、阻力与结果，不要求从微弱招式等比升级。主峰也不必是最大的发光球：整片地形开始倾转、天空中连续波面被贯穿、巨物失去支撑，可以有更鲜明的视觉记忆。

## 机位与美感

| 当前缺失的观看证据 | 可选机位与镜内变化 |
|---|---|
| 看不到横向覆盖 | 斜侧广景把角色、地标与远端放在一条可读传播线上，波头逐段越过参照 |
| 巨物像天上的图标 | 贴近已知参照的低位，巨物越过其上沿并遮掉一部分天空；保留落点或逃离方向 |
| 大场面像平面贴图 | 沿真实路径侧移，前景柱边、主作用和远处地标产生不同遮挡变化 |
| 一放大就丢失角色 | 在大形体边界、裂口或稳定明暗交界保留行动剪影；随后切回已知接触点 |
| 只看爆炸没有过程 | 留住冲击抵达、结构改变及形体扩张的连续阶段，先不要用甩镜遮掉主变化 |

横向铺满与纵向压顶可以产生不同感受，选与作用相符的构图。让大形体有方向、曲率和缺口，人物行动线与它形成对抗或穿越。大范围细节有主次，不能把“美感”写成均匀铺满发光花纹。

## 修复示例

弱：两人在桥上对砍，背后爆炸，最后拉远看到断桥。

改：交锋产生的刀浪沿桥面推进，接连削断承载两段桥板的外侧桥肋；斜侧广景保留两人、下沉桥跨与尚完整的山门。白衣趁桥板刚倾转时蹬离，黑甲以第二道刀浪追封落点；白衣在下降中以雷刃撕开封路波面的下缘，落到已建立的下一层回廊。失去支撑的桥跨随后砸断他们刚离开的回廊后段。主效果、被迫换路、连锁坍塌在同一时空延续。

这里的收益来自“正在变化的战场”，不是增加爆炸词。若用户锁定单层桥、不可破坏建筑、无飞行或结局不同，应改选相容的场面作用，不搬用例子。

## 不靠全场炸毁的宏观变化

| 已定机制允许的主变化 | 人物层怎样接入 | 结果持续什么 |
|---|---|---|
| 支撑结构倾转或局部失稳 | 争可用落面/通路，施术者继续处理源端压力 | 倾角、断接点与剩余承载不复原 |
| 流向改道、区域被分隔 | 角色利用已改变的路线或被迫改攻线 | 已变/未变区与正在传播的边界 |
| 巨型代理局部受损后改任务 | 本体接控制负载，代理剩余有效部位参与阻路/反制 | 损伤、归属和独立作用仍明确 |
| 空域或规则的层次改变 | 不同高度目标在同一时轴争有效作用区 | 只在已设规则内成立，不临时升级成全域时停 |

宏观层在发展时可以主读人物短攻，回范围接已经推进的角度/前沿；近处情绪或控制特写与其共用时间。每拍选主读，次层继续，不同时要求所有层完整展开。

## 边界例

- 写实巷战只强化武器接触与有限环境响应，不扩成毁城。
- 巨物可以只越过城墙产生遮光、风压和人群避让，不强制杀人或倒楼。
- 宇宙场景可以用已建立舰体、环带、轨道参照，不凭空加烟尘或空气声传播。
- 无破坏斗法可让水幕/云面偏转、光阵让出缺口，空间控制变化同样能形成大场面。

## 局部反制后的整体任务

先让已建立参照与主作用发生同一可见关系，再设计对手怎样干预当前控制或承载。断一处支撑后，剩余结构、重心或通路怎样改变，双方怎样利用新状态，沿同一事件继续；不能只把巨物当更大弹头。

局部、范围与人物承受分担证据。远处传播在近景期间继续，返回接当前形体和地形；规模不要求全部破坏，保持、避开、封路或失去控制都可以成为后果。
