# 巨型压迫与法相显化

适用于巨神、巨手、巨大法相、天体级敌人或跨山河的技能压制。普通远景、范围爆炸与巨型压迫分别设计；本页不要求所有战斗升到宇宙尺度。与[规模调度](scale-staging.md)共用场景，与动作和特效共用事件；研究范围见[来源记录](research-notes.md)。

## 把“大”变成角色正在承受的关系

巨型压迫的观看目标：角色和观众感到巨大形体占据自身所处空间，支配通路、视野或生存条件。有意志的巨大存在还能用注视和局部小动作强化这种悬殊；无意志巨物可以靠位置、体量和逼近成立。可选的主要关系是体量悬殊、空间被占、威胁逼近、选择收窄或抵抗负载；不要求每镜同时配齐，也不强制主角恐惧、败退或被压死。

先选巨物如何支配当前场面，再定规模。例如一根手指覆盖整处落脚区域，一只眼睛在云层后锁定人物，一只巨掌从两侧峰顶之上收拢退路；巨人只需小幅转腕，小人物已不得不跨越山门或改变逃离方向。规模成为不对等的动作关系，而非“大城市旁站着一个大人”。

### 摄影中最有用的几种证据

| 要让观众感到什么 | 画面关系 |
|---|---|
| 一个局部就超出人的世界 | 已知殿宇、山脊、人物与巨物的手指、眼或兵器局部同框；关节曲面、纹路或甲片继续延伸出框，能确认它属于同一巨物 |
| 头顶空间正在消失 | 贴近人物的视点保留地平线/山门，巨掌下缘侵入原有天空，明暗边界与可见余隙随事件变化；法相本身发光时可用遮挡和轮廓，不硬造黑影 |
| 正在逼近自己 | 威胁越过已知地标并增长占幅，机位与角色的退移不能始终抵消逼近；摄影可保持不动，让主形吞掉背景 |
| 远处的巨大与近处的危险是同一件事 | 全局尺度镜确认身体/局部与山河或行星关系，近处镜接同一作用部位、方向和阶段；不把宏观镜头拍成与人物无关的插画 |
| 极小反抗真的承受了重量 | 接触附近读到身体、兵器或屏障的受压变化；宏观镜看到相应巨物动作受阻、转向或反作用。只握拳摆姿不能证明挡住巨掌 |

不为每镜完整展示巨人而把它缩进画框。局部可以占满画面甚至遮去人物，但应在入口、间隙或退出有当前必要的尺度、身份与作用依据。只裁掉头脚、没有参照的放大特写，仍可能像普通人近景。双巨像对打也要保留山脊、云层高度、城池或本体等尺度依据，避免远景中的普通拳击。

巨物表面细节按观看尺度组织：大片曲面、甲片或山脊式结构给体量，局部纹路与反光给材质。能量法相可使用透空骨架、浓淡云体、剑群或层状辉光，其内部仍有主结构。金色和半透明都不是法相必填项，均匀泛光会吃掉体积。

## 《阿修罗之怒》可以迁移什么

本轮查阅主创访谈、官方30秒宣传片和Wyzen战斗实录的选定画面：巨大身体与行星曲面同框、巨指成为单独作用部位、巨指上空压向地表、小体量人物向上抵抗与宏观接触相互对应。这里提取观看关系，不复制其角色、神佛造型、剧情、QTE或精确曝光。

- **参照层级改变**：从人物/地形的参照转到行星，再回到人物的作用点，观众重新理解原来的世界只是对方动作下的一小处区域。需要改变认知时才用，不把每个技能机械放大到星球。
- **巨大存在以极小动作施压**：一根手指就形成灾变尺度的危险，压迫来自支配与悬殊；不一定要巨物全身挥舞、海量爆炸才能成立。
- **小者抵抗保留人格**：姿态、负载和决定性发力使小人物仍是事件中心；反击要作用于既定对象并产生可见改变，不凭空发明其足以毁星的能力。
- **高潮还可来自打法和情境**：主创访谈明确不只依靠更大尺寸，而要改变能力、战斗距离和情境。普通体量的快战、神通争夺或身体状态变化，也可以承接巨型场面后的高潮。

访谈观点、实际所见画面与这些原创转译分别记录。稀疏浏览不证明完整boss战节奏、速度、源帧数或音画效果。

## 修仙的法相：先选本项目机制

《西游记》第六回写二郎与悟空自身变大、兵器以山峰和擎天柱作比；第六十一回写巨牛与悟空巨身搏斗。原文使用“法天象地”。用户说“法相天地”时，先理解其要巨大力量显化的创作诉求；现代作品和用户世界观按各自设定，不建立全修仙通用的词义或能力规则，也不把文学法相等同佛教学派。

| 本场采用的形态 | 必须明确的关系 |
|---|---|
| 本体巨化 | 本体位置与身体尺度变化、服装/兵器的项目规则、脚下或悬浮状态；巨大身体本身是作用主体 |
| 本体处于巨像内部或与之重合 | 本体与巨像的位置关系、动作映射、巨像接触端；护体受损是否传给本体按设定处理 |
| 本体外显化巨大法相 | 显化位置、控制联系、有效区域、巨像动作与本体任务；若可离开源头，继承其独立运动规则 |
| 巨大象征/投影 | 可承担遮光、意志压迫或展示；若没有实体攻击权，不靠漂亮巨手追加抓握与碰撞 |

只补当前会改变动作或判断的关系，不把全套设定账本写进提示词。不是所有法相都缩小、透明或只在人物背后摆姿；也不是每个法相受损都让本体同步吐血。

### 显化与出招共享战斗时间

选有辨识力的形体变化：轮廓从云层或已设作用区域建立，肢体/武器穿过已知高度参照，材质与结构在运动中成立，随即取得具体作用。可由局部起势到全形，也可直接出现主形；不固定从脚到头拼装、不统一先画阵再站桩蓄力。

本体动作与法相动作有项目内关系。可以同步、经已定手诀驱动或由其独立任务控制；接触前要明确实际作用的是哪只巨手、哪段兵器或哪片区域。施术期间对手继续行动或被有因阻隔，不能等显化展示播完。

法相压迫要改变可用空间：巨手在山门两侧收拢，剑锋划过阵列形成隔断，身体挡住天光与出口，巨大指尖使屏障凹陷。破坏按设定发生；无破坏场景仍能用遮挡、领域边界、云体位移或阵形让路形成压力。瞬发攻击不硬加“缓慢下降”。

反制由能力与已建立机会决定：抵抗局部作用、穿过尚未闭合边界、切断已设供能联系、破坏控制条件或以另一法相改变受力。不要为大场面临时造唯一弱点，也不强迫所有小角色顶住巨掌反杀。

## 原创对照：天空中的装饰巨像 → 参与战斗的巨大存在

弱：修士身后出现万丈金色法相，遮天蔽日，巨掌拍下，天地震颤。

设计例（假设本项目允许外显实体法相和护山阵）：修士立在山门前，外显巨像的手腕从云层中伸出，掌下缘高过两侧山峰，指节间仍可见山门上空的窄缝。对手沿阵面冲向那道窄缝；修士收拢手指，巨像对应合掌，山门与对手一起进入掌影。机位留在对手附近，原来完整可见的天空被掌腹逐步挡住，护山阵在掌缘接触处凹陷，裂纹向相邻阵节点传递。对手按既定能力沿尚未闭合的缝隙抢出，巨像随控制改变手指角度继续封路；阵面损伤保留到下一段。

此例说明局部尺寸、操控、逼近、承受与选择的连接，不是默认剧情。身份、胜负、法相攻击权、静音、无破坏或固定机位等用户要求优先。

## 定向复核

只查采用项：有无与已知参照发生关系的巨物局部？威胁是否真正占据或逼近角色的空间？巨物小动作是否对应小者的大幅应对？局部接触与全局作用是不是同一事件？法相作用者、操控与本体负担有没有被混淆？最强效果是否保留材质和体积结构？

压迫可以持续、瞬发、静止凝视或反转；曝光、慢动作、声效和冲击画按该事件选择。巨型压迫本身不是冲击帧，满屏白闪也不代替巨大形体的建立。

## 巨大作用范围与巨大存在分开

大场面不只来自角色或法相变大，也可来自同一次局部作用延伸到整座城、山脉或云海。此时以既有地标建立参照，近处读负载，再用范围景读传播前缘和人物新位置；不把旧坑地当刚发生的破坏。跨场尺度蒙太奇与连续航路按项目目的分别成立。具体用户视频锚点及原创试写见[空战追击与尺度](../../an-workflow/references/aerial-pursuit-scale.md)，巨型存在仍保留本页的局部尺寸、空间支配和操控要求。
