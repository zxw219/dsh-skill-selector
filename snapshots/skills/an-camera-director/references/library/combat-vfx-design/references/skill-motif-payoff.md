# 技能母题与兑现：形体、人物与作用连接

用于技能炫酷但没有特点、成形/释放/后果像三个片段，或剧情型战斗的技能回收。沿已定角色战法与机制设计，不移植参考神器、配色和能力；与既有源头、传播、接触、结果、残留同用。

## 辨识来自形体与运动关系

从本次技能选择有辨识的主轮廓、介质/材料、空间组织与运动动词。薄切面、刚性阵列、卷合火流、受压曲面、分枝/聚拢、局部刻痕等按本场机制选择，形状应影响作用和人物操作。粒子、光晕和拖尾补主形，不所有技能换色光球，也不强制每招拥有新形状/新材质。

形成可以给出从局部到结构的可读变化：手/武器启动，形体聚拢/展开，方向/作用边界确定，进入释放或持续任务。角色身体开合、手势及支撑与变化对应，可读的长形成/仪式保留，必要窗口由距离、已有阻挡、同伴或在途威胁提供；对手按真实任务继续行动。

## 同一特征改变用法并得到回收

前面建立的标记、破口、残留、阵列或工具在后续可成为导向、封路、承力、协作或命中的条件；沿设定权限设计，不宣称所有失败都会有隐藏收益。一个能力通过条件、方向、控制或用法变化产生丰富度，不每镜重命名新技能。

协作要写实际输入与改变：一方封住哪条路线/承住什么，另一方借此击中哪里或完成什么；双色受光帮助归属，但同框两种光不等于机制合作。离体运行与本体各有任务，释放后人物可以追入/避线/改控或继续有作用的保持，法术不要求全程保留发射姿势。

## 主形穿过全场的生命周期

切到受击端继承同次源点/数量/路径/相位；接触重点可见局部偏转、受压、刺入/贴附、碎裂或既定非接触生效，之后承接目标/环境的新状态。强光可以有高潮，必要轮廓和结果由合适时刻/邻镜交付；不把白闪当全部交互。

发光体给皮肤、衣料、兵器、石面/地面和空气带来与位置/遮挡相符的局部照明，环境底色与双方能量归属保持。材料决定余波：碎块飞出后下坠/滚动、烟尘展开后遮挡、划痕冷却、液体受压再流回等按采用媒介设计，残留在后续行动中可见；无需每种材料/反馈全加。

局部技能与范围后果可不同节奏，宏观传播/坍塌不拖慢人物全部普攻。纯展示、没有代价/破坏、单能力与抽象媒介保持合法，参考中满屏规模不能被“保持清楚”统一削小。技能特点、身体美感、摄影与声学辨识共同服务本场主峰，事实观察、机制解释、新设计及生成验证分别报告。

## 材料转相、实体芯与准确归属

一个母题可由薄带/亮核发展为沿目标表面的厚包覆，再被目标主动挣动破成有体积碎块；阶段的厚度/透明度/刚性与裂解路径需相容，落地碎块留给后招。握持器具实体芯与扩展光面保持两层职责，收扩展不必消除实物。持续持物臂与空手源点分别确认；颜色和同框不能替代来源证据。协同连接的可见结构与当前设定的具体作用分开书写，未知增幅不写数值。源例按[执行方法](../../an-workflow/references/narrative-combat-transfer.md)回查，不强制同款媒介。
