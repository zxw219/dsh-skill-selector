# 原包案例迁移索引

案例由用户提供的1.1.1压缩包记录，本地没有原始出图批次，不把作者经验标为本次实测。

| 案例类型 | 可迁移方法 | 不自动继承 |
|---|---|---|
| 黑白/黑红刮痕束 | 负形补足轮廓、两档明暗、疏密代替灰膜 | 原身份、配色、零五官要求 |
| 武者与巨兽、巨首压镜 | 近远尺度参照、局部裁切、介质显力 | 实际体型、武器更换、仰角配额 |
| 石窟贯穿、巨刃劈开空气 | 缺席的笔带和断面错位、介质两侧分开 | 新增贯穿能力、绝对唯一灭点 |
| 熔岩/暗河或双人对轰 | 两侧相反力向、接触界面压缩、笔束长度梯度 | 势均力敌、自动换对比色 |
| 怒爆特写或站场静压 | 瞬间形体和将失稳支撑 | 强制爆炸、抹除所有身份锚点 |

复用先按入口选实体/抽象模式，再只读需要的结构、透视、笔触或配色参考。旧包中的实心带、恰好两值又多色值、无空场又贯穿留缝等冲突已由当前定义解决，不复制旧失败措辞。
