# 力学结构四式

一帧选择一个主读；次级反馈服务它，不凭选择改变既定攻防。

| 结构 | 主力向与形体 | 可见证据 |
|---|---|---|
| 爆点式 | 已定作用点向外放射，近点更紧、离点分叉 | 接触缝刚撕开，碎屑继承力向；小起因和大反馈可强化尺度 |
| 压伏式 | 同向压力挤压支撑或介质，源头可在画外 | 衣料、雾带、结构按同一力向改变；主体可仍在承压 |
| 贯穿式 | 沿既有攻击带形成错位和断面 | 断面两侧在该瞬间失去对齐；抽象模式可用笔痕缺席形成作用缝 |
| 对撞式 | 两股力从既定两侧抵达交界，界面压窄 | 笔束长度/密度及接触变形显示抵抗；谁压过谁由剧情决定 |

## 同一主结构的表现变体

| 变体 | 具体形体 | 使用边界 |
|---|---|---|
| 实体受压轮廓 | 接点附近压缩、远侧保留原形，衣物/材料朝同一方向受力 | 原材质和已定损伤保持，不能为冲击把身体永久换形 |
| 局部错位/裂形 | 既定裂缝两侧错开，碎片边缘仍能辨认来源 | 没有切断结果不擅自贯穿；裂形不等于全部炸碎 |
| 负形作用缝 | 获准抽象模式用留空或反相分开两股主形 | 只在峰值改变表现，退出回同次实体状态 |
| 刮刷/色彩抽离 | 主力向笔束与一两处身份锚，压低非重点颜色 | 需抽象风格许可，不将局部黑白推广全片 |
| 拖形回收 | 轮廓沿真实动势短时拉伸，再回到已推进的实体相位 | 成像表现不授予永久变形，握点和武器数量不断裂 |

多张序列例：先以受压轮廓读抵抗，再以已定裂缝的负形读失效，最后回实体接位移与碎片；若原结果只是挡住，就停在受压变化而不新增裂开。画张、曝光和转回方式按本片节奏决定，不要求三张或固定时长。文字形体设计不证明生成端做到了逐帧效果。

对撞不等于势均力敌；压伏不等于必须中心构图；爆点不等于必须把人物挤角落。位置继承上游。两股同色力量可用相反流向、粗细/密度和明度区分，不为区别强行换掉锁定能力颜色。

保留抽象笔束规则时，碰撞交界压成极窄密束但仍留断隙，不能再要求实心带。贯穿负形只负责展示已有切割，不自动赋予攻击贯穿能力。

## 峰值之前与之后的同次作用

先接上游的来力、触点、抵抗与既定结果，再选择峰值主要读受压、界面失效还是失衡。主力向与材料形变相容，反作用有对象，身份锚点和负形使画面仍可辨；同色对撞可用相反流向、密度或轮廓区分。

回到实体时接已经推进的位移与损伤，不再命中一次。较长图形保持、步进曝光或拖形只在所选媒介和节奏里设计，不把统一帧数写成平台保证，不把局部抽象扩散到全片。
