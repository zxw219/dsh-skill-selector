# 透视、尺度与汇聚中心

先继承已定机位、景别和轴线，再加强可用的近大远小。未锁定的独立图可选择贴地仰角、贴拳/贴刃广角或前景巨物裁切；不是每张图都必须极端仰拍。

主汇聚中心可在接触点、兵器纵深远端、主体支撑处或远端光/地标。几何边缘遵守空间透视，运动笔束遵守力向，二者可以投向不同位置。一个主读中心不等于全世界只有一个几何灭点；光源也不自动成为透视灭点。

裁切巨大前景形体并保留较小既有参照，可强化尺度。参照必须同框可辨，不能一边要求四边全裁掉，一边依赖已经看不见的外形来证明大小。实际体型、武器尺寸不随广角效果改变。

特写可用近端关节/刃面与远端递减作尺子；中景可让接触带和地形边缘组织同一个观看重点。抽象笔束通过近长远短、近疏远密辅助深度，但不能与所有笔束统一指向同一点或严禁一切透视线同时叠用。
