# 空气显力与刮刷笔束

厚空气来自相容介质的遮挡、受力形变和光传播变化，不靠统一灰膜。可选近层尘雾掩远侧、短尾碎屑被介质阻滞、刃面两侧被推开的空气带；不同时堆满所有装置。写实模式不能把空气任意写成硬边亮球。

硬边抽象模式的可复制模块：

```text
粗糙干底上的快速刮刷；笔痕由长短参差的平行细痕成束，边缘干净，两端收尖并分叉。密处仍留断隙，不合并为平涂实块。接触附近短密，向外长疏，主束沿受力方向展开，次级碎痕不机械整齐。暗形与亮重音分界清楚，不洇染。
```

只在本模式且笔触是主表现时把模块放前部，不把全部长模块塞入视频全局。刀具刚经过的介质形体可向两侧分开；碎晶须来自已设材料或能力，不能把原本烟尘无因改成晶体。

本模块统一采用可辨断隙：不再叠用“密到并实”“有实体的亮球”与“不成实心块”。用户选水墨、柔雾、实体色块时按该媒介另写，不借刮刷禁令否定它。
