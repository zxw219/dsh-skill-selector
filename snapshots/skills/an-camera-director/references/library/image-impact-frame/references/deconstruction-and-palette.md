# 参考解构与配色

参考按用户职责继承：身份图取必要身份；风格图取笔束/负形/边界；构图图取位置和尺度；能力图取已允许的形体与颜色。用户未要求改色时保留锁定配色。参考上的文字、无关人物和排版不带入。

黑底刮痕类抽象画可以把形体组织为几束未闭合痕迹，由负形补足；兵器与姿态承担辨识。为避免滑回写实，在这个模式下少写皮肤、汗珠和细部解剖，而用头部收束、持械轮廓和姿态。实体或身份特写仍保留必要五官与材质。

## 两档明暗与颜色数

- 黑白：只有黑底与亮笔，疏密造成灰的观看感，不加入灰雾颜料。
- 黑红：黑底、暗红形体和亮红锋面仍可组织成两档主明暗；明确暗红靠近黑、亮红接近高亮，红保持红，不另写白色爆点。它不是“恰好两个RGB值”。
- 锁定同色对撞：使用相反力向、短粗/长细笔束和明度区分，不强制两种色相。
- 锁定双色对撞：保持各自来源和接触边界，可共享暗底；局部接触不把整片混成第三种能力。
- 正相为暗底亮笔；反相为亮底暗笔。亮底由笔束疏密和负形组织，不铺成无信息的整屏死色板。

严格两色要求与多个颜色值冲突时，先服从用户明确两色并删多余色值；只要求高对比时用两档主明暗，不虚称像素级双色。不得在 Midjourney 负面参数里用 `grey` 同时否定被授权的实体灰雾或材质。
