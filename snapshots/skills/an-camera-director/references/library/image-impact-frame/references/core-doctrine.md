# 抽象冲击画核心口径

只用于抽象图形模式；实体模式遵守入口的媒介和动作约束。

1. 写瞬间：刃刚压开介质、两股力的界面开始变形、碎裂沿接触带初次展开。压迫可以是支撑即将失稳，不强造爆炸。
2. 满是动势覆盖，实是平涂堵塞。要求满屏时笔束/碎屑可达边缘，同时保留负形间隙和主事件辨识；狭窄贯穿缝是有用途的负形，不等于大面积无信息空场。
3. 两档主要明暗指暗形/亮重音的视觉层级，不等于恰好两种颜料、RGB值或两种能力。黑白严格双色时灰只由疏密观感产生；单色系用明度差与笔束形态区分；锁定多色时保留归属，不补第三种能力颜色。

硬边刮刷保持笔束间的缝，接触带可极密但仍裂开细缝。本模式不同时要求“任何部分不并实”与“交界并成实心带”。水墨洇染、渐变和柔雾只在用户选了相应媒介时采用。

编译自检：瞬间与方向成立；所选规则符合当前模式；满屏不抹平关键负形；主体与兵器有可辨主形；两档明暗未被全局泛光混成灰膜；没有同时要求疏/实、硬边/洇染、空缝/实带。检查的是画面含义，不用禁止单个词代替判断。
