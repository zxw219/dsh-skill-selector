# 动作模块库：从词汇到可接续的交锋

用于普通打斗编事件前的主动选招，以及“动作模组少、动作表很多但正文贫乏、反复挥砍格挡侧移”的返工。以下40条是原创影视编排结构，不是生成实测结果、武术教学或每场必须使用的配额。采用角色、兵器、能力、幅度、媒介、胜负和当前修改职责；模块编号只用于查库，不写进作品正文。按当前距离、接触、忙闲肢体与地形找不到合适组合时，取[出口检索与受阻分支](action-selection-index.md)，不先遍历全库。

## 先定位贫乏发生在哪层

| 层次 | 判断 | 本轮操作 |
|---|---|---|
| 储备 | 当前角色缺相容的具体结构，只有动词/招名 | 从下表取相关模块，再按本场事实展开 |
| 选用 | 已有结构，却一直选熟悉的斩刺挡退/伸掌 | 在编事件前采用身体、兵器关系或控制方式不同的候选；不先写完单调稿再补名单 |
| 组合 | 不同动作各演一次，之间复位、等候 | 前模块出口接后模块入口，准备与前一交锋重叠，对手同期变化 |
| 表达 | 设计中有动作，S正文只剩“激烈交锋” | 把实际进入、路径、回应、控制变化和收势写回原模板 |
| 执行/观看 | 提示词已明确，视频漏做或镜头没读到 | 对照源稿与成片最早偏离，分别修表达、观察或实际执行；无源稿不确定归因 |

用户已澄清“动作少”指旋转、翻滚、回旋踢、跳跃、扫堂腿等全身运动时，先在选用层确定身体轴、重心路线、高低与支撑的变化，再补攻击端。完整驱动的拳肘可以带动全身，但仅把拳换肘、刃换柄不能满足这次幅度和身法要求。具体身体过程用[自然动作采用](acrobatic-action-design.md#自然动作请求的采用门槛)；不要以模块名、攻击端数或镜头数量代替正文。

## 选用与组合

普通打斗在编时轴前就从本角色相容条目选实际接续，不以用户说“丰富”作为启动条件。先读已选模块的入口、双方操作与出口，再把前一模块造成的受限/余势作为后一模块条件。若最终攻击方式仍是同一路径反复伸掌/格挡，即使储备表很长也属于选用未兑现；从当前破限问题更换组合，而不是附加招名。修空间和资源时优先调整进入/释放/落点，不能为避错把所有相容大动作退回小步短挡。

先从角色战法和当前争夺选相容模块，再让它们参与事件设计。需要丰富时，候选之间要有真实差异：攻击部位、身体高度与支撑、兵器长度/接触关系、主动防法、持握/离手、近远距离或本体/代理分工中的相关变化。不同名字、颜色、镜头角度不是动作差异；不要求每段凑齐这些维度。

原创允许设计对手压力、场地和进退关系时，可把能发挥所选模块的条件一起编进事件；明确锁定的动作/场地不临时加攻击或障碍替花招找理由。用户要求丰富、幅度或特定大动作本身也是观看任务，不让连续性检查把所有相容候选都收缩成小步短挡。已采用动作有具体冲突，先修入口、净空、资源或接续；确实不相容再替换，不无因删成最熟悉的一招。

模块是“入口—双方操作—改变—出口”，而非单个动作名称。每次实际使用都填当前对手与位置，落空、受挡、受压和成功可以有不同出口。保留有作用的重复、纯兵器/纯远程、单技能、慢镜、定势、单人展示和固定一镜到底。

需要把近身、低位恢复和多向压力编成更丰富的实际组合时，读[接触、高低与支撑](contact-height-combinations.md)。这是原H/G/A与共享战局的展开分支，按前一拍状态选入口，不以增加模块总数或随机插入翻腾验收。

## 多样化攻击模组：攻击端差异门槛

用于“成片只剩挥拳/挥爪、同一攻击端同一轨迹反复、招名很多但身体过程同质”的选用层返工。模块已在库中却打出同质动作，说明选用缺门槛、验收缺证据；先过本节门槛，再按当前出口回上方各族取具体结构。本节并入上方选用与组合环节，按本次战法兑现差异即可，不必每场凑齐全部攻击端；纯兵器、纯远程、单能力与锁定战法按各自机制兑现，不必强塞拳肘膝腿。

### 攻击端枚举（判“不同”时以此为准）

一次攻击的攻击端指实际接触或作用对手的部位。判“换了攻击端”只认下表换行，换招名、换颜色、换镜头角度都不算：

拳心/拳背、掌根/掌缘、爪端与指刃、前臂、肘、肩、胯/髋、膝、腿（扫/踹/送/蹬）、足跟与足背、头/额、全身（撞/压/摔转/滚）、手中物（刃线/柄端/护手/盾缘）、离体代理（弹/线/网/域/召唤体）。

同一攻击端内部的变化记为轨迹、高度或接触方式变化，不记为新攻击端。

### 按出口选下一攻击端

从上一招的实际出口选下一类攻击端。每行都标明该模块入口已经成立的条件；入口条件尚未出现的模块，留到条件成立时再用：

### 差异门槛

先继承主战距离、持物、控制和用户的纯远程/单端等锁定。以下身体/混合快战检查主动防止挥臂循环；其他战法在其允许变量内核作用差异，不为数量改变角色。

1. 从上一招的真实出口主动比较相容的身体过程与攻击端；沿同端续招时，核轨迹、高度、触点、节律、用途与对手选择是否发展。换端不能消耗不存在的机会；同端持续压制、试探或积累负载可以成立，不按差异项数强迫对手换防法。
2. 身体/混合快战主动利用相容的上肢、下肢与全身作用，防止正文只剩挥臂。需要自然动作时先比较旋转、低位、翻滚、腾跃、借面和持械身法怎样从前招接入，按本场选择不同的身体路线；不把三种攻击端当作丰富度证明。锁定纯远程、持械、单端或持续控制时，在其允许变量内发展，不为端数改机制或强插腿技；持械也不因此退成斩刺挡退。
3. 根据真实来向轮换相容防法：偏转、卸力、截起手/截诀、让线、粘控、承压导走。重复防法若累积负载、被识破或服务持续压制可成立；只有输入、应对和出口空循环才回改。
4. 施法从选定、聚拢、开闭、接通、牵引、截断、交代理等相容操作选用。操作相同还核对象、约束、用途和对手新条件，不能只因同手势判同质，也不能仅换颜色放行。

四招一簇的实际读法（爪战角色）：甲爪勾被对方压住 → 顺势折臂转**肘**撞入 → 肘撞使其后仰换支撑，甲低扫其**新落脚** → 对方抬腿避开低扫、重心上浮，甲撑地侧翻绕到侧后接**爪刺**。这一簇覆盖爪端、肘、腿三个攻击端，含一次下肢，且每招的入口都来自上一招的出口。若四次爪挥的轨迹、应对与出口都一样，也没有累积负载或新任务，换招名仍是同质循环；同一爪端的持续撕开、试探后改线或反复争同一目标不能只凭攻击端相同判错。

### 多动作/高频请求的验收

先按用户所指的层次验收：高频看有效交会与相容接力；多攻击端看作用部位和防法是否发展；自然/全身动作看实际身体轴、重心路线、支撑、高低与轮廓。三者不能互相抵偿，不统一换算为每五秒三端、每三十秒四个动作或每簇一类编号。

从最终正文逐簇找实际过程：前招留下了什么身体/兵器状态，本次如何转体、降身、蹬离、翻滚或借面，对手如何追截/让线/承受，武器及空闲肢体在做什么，怎样接重/制动后进入下一任务。正文仍只有站立挥臂、接刃和一进一退，即使换足攻击端也未满足本次自然动作要求；返回选用和组合重编。旋身只写名称、起跳直接切到落地、滚一下后双方复位，同样不能靠计数放行。

动作差异可由不同身体过程，也可由同一路径的真实战术发展体现；转体不必整圈，跳跃不必空翻，扫腿与低位接重不都剪成脚部特写。复合动作按其完整过程读取，不拆成多个编号充数。单向压制若持续发展也可成立；若相同防法只重复后退，既没有解法变化，也没有积累或被利用的后果，就修推搡循环。纯持械、纯远程、单能力、慢镜和用户指定数量按原条件验，不将这次反馈变成所有打斗的配额。

### 爪与指刃的换端路径

爪端不是拳，也不是兵器：它没有柄和长度，靠勾、撕、刺、扯、压五种操作产生作用，并能在接触后持续回带。写爪战时让每一招落在其中一种操作上：

- **勾**：爪端指向回带，把对方防线带偏
- **撕**：单爪或双爪双向分力，拉开原本收拢的防线
- **刺**：指端直线送入，配合身位前压
- **扯**：抓住后拖拽，改变对方位置与支撑
- **压**：爪背或掌根下压，制造贴身低位

换端从这五类之间走，再跳到其他攻击端：勾→撕（同一只手两段）、刺→压（直线转下压）、爪→肘（近距折臂）、爪→膝（贴身低位）、爪→腿（拉远后替代）、双爪→单爪加术法（一只手转为施法，另一只手继续勾或压）。

写爪战时爪端动作必须可辨，以下三种写法会让它消失：写成挥拳（单点冲击、出手即收，回带与持续接触丢失）、写成挥刀（长弧挥砍、强调刃身长度）、写成纯光效（只剩火焰轨迹，看不见爪端动作）。

### 验收与分层归因

隐藏招名、颜色与特效词后读正文，核实际作用与对手新条件；差异可以来自攻击端，也可以来自同端连续作用的真实发展。只有输入、应对与出口的无作用循环才回选招层。正文已有好动作但取景裁掉下肢、接触或换线时，修所选景别、观察侧、遮挡和切点；证据已经可读而生成端未执行时，再依据实际片段修执行句或重试该段。观察层的问题不自动重编动作，未看实际片段不认证生成失效。

## W：兵器距离与接触变化

| 模块 | 当前入口与具体交锋 | 出口与约束 |
|---|---|---|
| W1 外引脱刃—内线回切 | 刃已交会，甲顺乙的外导收肘让刃滑离，换支撑带剑从新内侧回切；乙转胸缩短自己的刃路抢甲近线 | 脱刃后才自由回切；接短送、柄部动作或承压换侧，不每轮长弧挥完站正 |
| W2 长兵受压—收短—尾端接敌 | 枪/杖前端被压低，甲沿杆换握位置收短，尾端转到身体外侧处理乙贴入；乙收短攻线追握持端 | 同一根兵器、两手滑移与杆端路线连续；贴身处先接短护/尾击，退开后才恢复长距 |
| W3 兵器导离—柄/护手近击 | 甲导离当次来刃后已贴入，刃在身体外侧，柄/护手沿短路撞向乙可达部位；乙收臂或推肩打断贴入 | 不能刃还被夹住却独立抽柄；结果改变接触和支撑，接控臂、短刺或脱离，不预定击中 |
| W4 飞器折返—接握—近线回应 | 实体器物在外端，甲按既定规则召回，沿净空通道握住后把回收接成近线护/击；乙在折返期间逼甲接握位置 | 离手时不写手中第二把；接握前用相容身体或其他资源应对，不能用未回器物先格挡 |
| W5 长短相遇—争近端—再争外线 | 短方借已有侧路进入长兵内侧；长方收短换支撑追其近端，短方截追或被迫退出 | 贴入有实际路径，长方不自动失效；近端受控则续争控制，脱开才重建外端距离 |
| W6 双持分工—一端受压—自由端换线 | 甲一端接住当前来线，另一端沿体外可用通道进入；乙撤原交点改截自由端，甲两端随占用重分工 | 两件兵器实体和两只手连续；自由端也有净空/距离，不能两端同时穿身或共用一条被占路线 |
| W7 软器落空—收松张紧—另取路线 | 既有链/索状器物越过目标后受阻或松弛，甲移动控制端接回张力；乙在其回收中追源端或离开覆盖 | 真实长度、接触与张力成立才牵引；擦过不是缠牢，松端不能刚性格挡，受阻出口可放弃追索继续防守 |
| W8 重器受让—接余势—制动改任务 | 甲重器被乙让过，身体与器物仍沿原方向发展；甲用已有落脚/净空改变回收，乙追其恢复窗口 | 重不等于慢；没有制动/护线就承受受阻结果，不在大弧末端直接无代价反向 |
| W9 既有盾承压—盾缘转线—兵器接新窗 | 盾已在原装备中，甲承接一向负载时，乙改变来线；甲调整盾缘与身体支撑，兵器只利用真实腾出的通道 | 盾占手、遮挡和方向连续；不能因读此项新增盾或覆盖全场，盾受压时兵器不穿盾击出 |
| W10 持物脱手—争可达落处—恢复或换解 | 器物按已发生受力离手，甲先处理乙同期追入，再向实际落处/折返端操作；乙也能封路或改变落点 | 不能切镜捡回、复制第二件或临时加召回；拿不到就用既有资源继续，不预定恢复持械 |

持剑/御剑的特定路线还可按[25式剑招](cultivator-sword-techniques.md)取相容结构，本库不替换原名，也不让无剑角色自动持剑。

## H：手脚共同改变防线

| 模块 | 当前入口与具体交锋 | 出口与约束 |
|---|---|---|
| H1 直拳受截—弧线逼防—折臂入肘 | 甲的直拳被截，收肘时另一手从侧线进入；乙回护侧线并推甲肩，甲趁贴近将已折臂转为短肘任务 | 肘必须入距，推肩会改变它的落点；可接控臂、膝或脱开，不能三次攻击都宣告命中 |
| H2 上肢牵制—膝线进入—收腿续步 | 甲用相容上肢接触压住乙一条防线，支撑腿接重，另一膝向近距躯干进入；乙退髋/下压/推肩争空间 | 不是抬膝就命中；收腿、实际落脚和牵制是否滑脱接后招，持械/控法手不多出一只 |
| H3 侧向送腿—截追—折腿换位 | 乙追入，甲侧向支撑，腿沿目标来路送向可达躯干；乙格腿或绕侧，甲折回腿并落在新支撑位 | 当前腿路只截这一来向；接回护、外侧短击或被压接重，不能腿伸直悬停保护所有方向 |
| H4 牵上路—低扫新落脚—接触/扫空恢复 | 乙因上路压力换支撑，甲低腿弧扫向乙当时的新落脚；乙尝试收腿或移重，先后决定接触、受挡或扫空 | 追新位置；接触改变乙负载，扫空仍有甲的余势，双方接收腿/落步/受击恢复，不直接满状态反踢 |
| H5 直线逼迫—绕外弧线—收臂守新面 | 甲短直线逼乙封中路，另一端沿当前空侧弧线进入；乙转胸追外线，甲随受截回护新侧 | 弧线要有窗口和净空，不靠换拳名算变化；受截后肩胸/双手不恢复开局 |
| H6 腿线被托开—折腿换支撑—近端接应 | 甲腿攻被乙托离原线，甲先回收腿并找可达支撑；乙追甲承重阶段，甲自由上肢处理当前追入 | 腿没回就不计双脚承重；未接地可继续受压或按既定腾空动力应对，不保证落脚即反攻成功 |

明确纯兵器/纯远程不强塞拳肘膝腿；明确手脚并用时，腿只走路/起跳不算采用H模块。

## G：接触控制、摔转与倒地关系

| 模块 | 当前入口与具体交锋 | 出口与约束 |
|---|---|---|
| G1 贴臂入胯—承接重量—摔转或受阻 | 近身已有臂肩接触，甲屈膝入到相容胯侧支撑位置，以髋身承接乙近侧重量，转肩带其离开原足地支撑；乙撤脚、推肩或挣脱，抵抗决定能否摔转 | 支点、接触与重量转移明确；成功接乙落地与甲释放/追控，受阻接撞挤/松手/另一路，不凭一抓锁全身 |
| G2 肩胯挤入—移走身体—临时挡来向 | 甲与乙贴近且有落脚，肩胯挤压使乙身体进入第三人的当前攻击来向；乙仍反推，第三人收短或改侧 | 挡体只改变当时体积与来向；对手一挣脱/改高低便失效，接新多向压力 |
| G3 被抓住—转身卸接触—自由端回应 | 甲一臂或兵器受控，先随受力转肩/换支撑，利用真正空闲的肢体处理乙继续来击，再卸开原接触 | 被控端不能独立新攻；脱开后的朝向/距离不是初始架势，接近线反击或失衡恢复 |
| G4 倒地争支点—牵动近腿—站方撤脚 | 甲倒地但有可用手脚，围已有身体接触和地面支点改变乙近腿负载；乙抽腿或下压，甲的上身随受力转移 | 不把倒地写成无敌连续腿圈；可接翻身、起身或继续受压，第三人的可达攻击同期计算 |
| G5 控制滑脱—换承力点—短接触再争 | 甲原抓持被乙挣开，甲不能继续依赖旧控制，而以可用臂肩/兵器重新争一处真实接触；乙追其忙侧 | 新接触须重新到位，不能一抓永久锁全身；重新接不到就脱开/承压，不强制摔转 |
| G6 失去支撑—邻面接重—低位续防 | 当前足地/器物支撑失效，甲用已可达的台沿/地面与可用肢体接住部分重量；乙追其恢复位置 | 邻面真的可承力且在触及范围；原控制、持物和第三来向继承，未起身也能有有效下一任务 |

这里描述影视控制关系，不将具体关节伤害或招名当作成立依据。角色明确不允许身体接触时转用相容的术式控制。

## A：身法与恢复成为交锋的一部分

| 模块 | 当前入口与具体交锋 | 出口与约束 |
|---|---|---|
| A1 来力卸开—斜肩滚—接脚再起 | 原接触已释放，甲顺受力向可用侧降身肩滚；乙改低路追滚出位置，甲收腿接脚并回护再起 | 不是畅通追击中滚一下加速；滚势、忙闲手、持物和再起压力连续 |
| A2 越障翻腾—下降取向—落地续招 | 当前通路受阻，甲从可用支撑翻越已有障碍，武器走体外路；乙不等落地，前往真实下降区截击 | 下降前身体/武器取向，落脚接重进后招；幻想动力按锁定规则，不空中任意改质心 |
| A3 低扫逼近—空手撑地侧翻—抽手回护 | 低扫来时甲有空手和侧通道，空手承担短支撑，身体侧翻移出扫幅；乙转上路追落点 | 撑地手忙，另一持械/控制端任务相容；脚先接地再抽手，不双手持剑又双手撑地 |
| A4 真实借面—侧向旋身—回踢/回切受截 | 甲已接近可承力墙柱或既定作用面，接触改变动力，身体侧向旋过净空，攻击端进入新线；乙抢内线/下降区 | 借力、转背窗与可达目标都成立；可收腿制动、回护或被截，不强制每次整圈与命中 |
| A5 阶梯高差—改层争线—新面接重 | 双方已到阶梯/台边，甲沿可达踏面改变高度和来线；乙改目标高度或守住下一踏面 | 不默认高位必胜；台阶尺寸/落处和长器净空影响实际选择，切近后仍处于该高度 |
| A6 移动支撑—同速接入—离面续行 | 甲的既有支撑面正在滑动/倾转，甲调整接重并争离面路线；乙利用同一运动追其预计新位置 | 支撑面、甲乙各自运动分开推演，不能同时当地面固定又借它移动；跨距不够则改变出口或受阻 |

完整过程按[翻滚/空翻/旋转](acrobatic-action-design.md)展开，动作幅度按本场需要保留，不拿摄影旋转替代身体运动。

## F：施法操作与本体动作

| 模块 | 当前入口与具体交锋 | 出口与约束 |
|---|---|---|
| F1 回护中短诀—近距作用—移身接收 | 当次来线已处理，甲在回护/移身中完成已设短诀，作用端进入可达目标；乙截源端、离开作用区或以已有机制破解 | 短诀不是长仪式；本体操作、作用在途与接收分别连续，不仅更换掌光颜色 |
| F2 受压维持—变控改面—余波中转任务 | 甲正维持已设面/束，随乙新来线改变掌腕/器物与身体支撑，作用边界按既定规则改向；乙压控制端或绕边 | 只在规则允许范围内改形/向，不能任意新增反弹；解除后才释放忙手，残留依机制保留 |
| F3 飞器牵线—本体另路—控制被迫切换 | 单一飞器从甲外侧压乙当前防线，本体沿不同可达路接近；乙拨器并追本体，甲在维持/回收之间作真实切换 | 不是同时在手/远端/脚下；持控制手不可撑地，压力解除后不再计持续牵制 |
| F4 触承载物—布置生效—离位利用 | 既有触物术需要实际接触，甲在交锋中用可用手/器物接到已知面，撤离同时术式开始起效；乙追接触点或破该承载物 | 只用当前已设标记/节点/阵法规则；触物之前没有作用，不能为丰富临时新增便利法术 |
| F5 控制端被追—局部减载—兼容防护 | 甲持续控法的一端受乙追压，甲按已设机制缩小/改向/转交一部分作用，释放可用资源处理源端 | 缩减和交接不是自动能力；没有许可就保持忙手，用已有身体/代理应对或被打断，旧独立作用不随意消失 |
| F6 旧状态被识破—换用途—条件消费 | 甲原节点/附着被乙识破或绕开，甲只在既有规则内用其改变当前路径/负载或交给代理；乙可破载体继续拆解 | 真正利用旧状态，记录消费或保留；不临时授予标记万能追踪、传送与爆炸 |

无手势、念动、自主代理、触发被动等按自身机制表达，不每人强制掐诀/双掌，也不把相容本体动作删成站着发射。

## T：多人动作相互接入

| 模块 | 当前入口与具体交锋 | 出口与约束 |
|---|---|---|
| T1 引防负载—队友从既有外线进入 | 甲使乙防线承担明确负载，队友已在外侧进入/形成期间；乙改防，队友利用当时暴露线，另一敌人干预队友 | 利用者提前到位；不是甲打完才换队友，更不是两个人并排出招就算合作 |
| T2 接替来线—自由端转任务—接重恢复 | 接替者实际拦住当前威胁，原承担者才用释放的手/兵器进行攻击或救援；敌方换线争新暴露侧 | 原威胁真实交接、资源腾出与恢复连续；不能一句“掩护”让全敌停机 |
| T3 真实承力/托送—空中取向—承力端续防 | 队友或已设代理在真实接触处提供可用支撑，被托送者沿动力方向离开，攻击端另取目标；承力者接反作用、另一敌人攻其忙侧 | 需相容能力/身体条件与空闲资源；无托举依据不跳过跨度，不让提供支撑者同时全身自由 |
| T4 远端迫换路—近端封新出口—对手拆接力 | 远程作用改变乙可走区域，近战者在前一相位已接近新出口；乙改落点/反压或第三人拆远端源头 | 封的是同期新路线而非旧坐标；不预定闪避方向、必中特定出口或固定轮流攻击 |
| T5 原配合被拆—转交任务—重新形成窗口 | 敌方打断原牵制，利用者尚未进到旧窗口；原协助者先处理新威胁，另一人接可达任务，利用者据新状态改路/回护 | 不继续使用失效窗口；重组来自实际位置和资源，不一句“变阵”让全员换位 |
| T6 第二来向加入—限制一向—争另一出口 | 原交手者正在近身，第三方按自己目标介入，改变一方朝向/射线；受压者借已有遮挡或真实控制暂减一向压力 | 团队与三方互敌分别成立，第三人不自动变队友；处理一向后另一向仍推进，不平均轮流 |

多人使用沿[共享战局](team-combat-choreography.md)核全部关键人物，次要角色不停止；无需所有角色每段都采用新模块。

## 接续示例：出口提供入口

| 可采用组合 | 为什么能接 | 必须重编的条件 |
|---|---|---|
| W1→W3 | 刃滑离且追步形成贴身距离，柄部才可进入 | 剑仍被夹住/仍在长距，不能直接柄击 |
| W2→W1 | 杆端短护使接触脱开，身体/杆外弧恢复净空 | 杆仍贴身被抓时不自由转大圈 |
| H1→H2 | 臂部逼防使膝线可达，膝准备接在贴入里 | 对手已退远/控手互斥，先追入或换当前解法 |
| H2→G1→H4 | 收腿落脚接肩臂转控，对手换支撑才产生低扫目标 | 不把膝击、摔投、扫倒都默认成功 |
| G3→A1 | 抓持已卸开，来力与空侧提供滚出入口 | 仍被抓就不能凭空翻滚脱身 |
| F3→A1→W4 | 控器和滚动资源相容，敌方拨器后需回收，起身时接握回应 | 右手控器又撑地、飞器没回就手持格挡 |
| T1→W3/H2/F1 | 协助给出实际近距/操作窗口，利用者已到位 | 先开瞬间窗口再跨场赶来 |
| T2→T4 | 一向威胁被接替后，原承担者有可用资源接远近协作 | 交接并未实际发生/另一敌人已打断操作 |

这些是兼容候选，不是强制连招树。当前出口、对手反抗、武器资源和用户边界优先，不能机械串编号。

## 看实际采用，不看库的数量

有丰富要求时，沿最终S正文标出采用的模块：去掉编号和招名，仍能辨认不同的身体、武器或控制过程；不能整段只改左右方向的同一套“出招—短挡—侧移”。重复若仍承担同一种有效压迫可保留，贫乏处换成相容的不同解法，不强制零重复或统一招数。

选用、组合、表达各层修复，正文里的相位与观察必须接上。示例见[三条模块组合试写](../../an-workflow/assets/cases/action-module-combinations-20261014.md)。这些只经作者语义复核；动作排练、正常速度观感和生成兑现尚未验证。

## 选择、试探与受阻后的改招

从双方当前争取的优势选相容模块，再用对方确实可用的一种应对推演出口。对手改变了距离、承重、接触或控制资源后，后招相应改变；不能把成功版连招套在失物、受截或支撑失效上。

重复输入可以试探习惯、累积负载或逼出同一防法；下一次利用、继续压制或退出须有区别。相同攻击端仍可因目标、轨迹、触点、节律和应对形成章法。纯远程、持械或限定单端按允许变量发展，不能为了凑下肢与三端而改战法。动作已经丰富而成片仍像挥臂时，先分正文过程缺失、取景裁掉和生成未执行，不统一再加招名。
