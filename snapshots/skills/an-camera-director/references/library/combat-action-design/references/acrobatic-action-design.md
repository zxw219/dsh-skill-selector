# 翻滚、空翻、旋转：动作学习与编排

2026-10-12执行。用于影视、动画与AI视频原创设计；下列是文本编排选项，不是实练指导，也不是参考视频中已确认出现的24种动作。术语有流派差异，当前身体过程优先于名称。腾空并不天然免伤，镜头旋转也不证明身体已翻转。

## 动作怎样成为选择

先明确当前任务、双方同期路线和本段身体表现：可用旋转接余势、低位换线、滚出接重、起跳改层、回旋腿扩大攻击弧、借面反弹或持械翻身形成不同动作乐句。用途包括避线、抢位、卸力、反击、诱导和角色表演美感；表演美感须有可描述的身体轮廓、节奏或对手接收，不能只有“更炫酷”。比较延续原行动是检查选择的作用，不是要求所有动作服从最短路径。已有净空、支撑、动力只是可执行条件，采用后还要让身体过程与下一任务成立；有用途且相容就保留幅度，不为了“稳妥”全部改成小步。

**原创与锁定稿分开**：允许原创对抗、调度或场地时，先把能发挥所需动作的压力、支撑和空间条件一起设计，再推演双方应对；这属于编排。修改已锁定的事件、能力或场地时，不凭空添攻击/障碍为助手花招找理由；先修真实入口、净空、资源与接续，确实不相容再替换。用户已要求自然动作的丰富度，不能因旧草稿尚无对应威胁就放弃全部大动作。

追赶者在畅通路线中无来袭/障碍/控制或表演任务时，前滚会消耗接重与再起时间，不能自动写成加速追近；被追者为避上路来刃而滚出是另一任务，也须核滚动出口和追击者继续行动。确有来袭、低净空通道、受力恢复、既定身法机制或明确表演意图时可采用，核滚后目标已到何处、距离变化、面向/支撑及下一任务。用户锁定翻滚时在授权内成立这些条件，不能一刀切禁滚。最终复核涵盖所有实际采用的这类动作，不限于用户点名动作。

## 自然动作请求的采用门槛

用户明确“动作少”指旋转、翻滚、回旋踢、跳跃、扫堂腿等时，先编所需幅度和身法变化的全身动作链。可按本场战法取旋转（T01–T06、W01）、翻滚（R01–R06）、空翻/越障（F01–F06）、回旋/后踢/腾空腿（K01–K04）、低扫（模块库H4）、借墙/柱（F06/A4）或跳跃换层（A5/F05）；它们是开放候选，不是每场必须全选的菜单。拳、刀、肘、膝若由支撑、髋胸和重心共同驱动也可带动全身，问题是反复换攻击端仍没有本次要求的身体轴、路线、高低与支撑变化。

从当前出口选一个有差异的身体过程，把它接成一簇而非单独摆拍：`前招受力/余势→降身/转体/蹬离的实际路径→武器与空闲肢体任务→对手追截或接收→接重/制动→下一任务`。防守者的滚出、腾跃或低扫也可夺线、逼改防法或取得新支撑，不长期只负责向后退。连续一进一退但双方的身体路径、防法与机会关系没有发展，按同质循环返工；不强求每隔几秒换主动权。

正文验收不数招名：旋转是否能辨头/胸髋相对场地的转向；滚动是否经过肩背并接脚；腾跃是否有离地、空中路径和下降；低扫是否有重心下降、支撑与腿弧；带武器时刃路是否随身体且不穿身，落脚是否接上后招。一个复合动作可同时含多种变化，不拆编号充数；台阶换步、收腿或“旋身”一词本身不自动满足本次幅度要求。不设通用每30秒/每5秒数量线；固定机位只固定摄影，持械也不排除相容身法，纯远程、单招、慢镜按原任务实现。

## 执行校验（外部参考并入）

以下只并入方法，不装外部技能、不换模板。来源：MOKE `action-choreography-reference` 1.0.0（SKILL.md、`full-body-locomotion-grounding.md`、`weapon-body-dynamics.md`）。

- **地基**：按当前动作核支撑、重心路径、距离/角度、为什么现在、交会或近失、反应、制动/恢复和新状态。检查实际依赖，不逐招强塞全部字段；发现缺口先修动作，不加招名抵偿。
- **差异观察轴**：高度、攻击面、距离、支撑、兵器功能、身体路线、恢复方式与环境响应可帮助定位重复。差异看实际身体和对手选择怎样变化，不按“多数轴相同”机械判同招；同一轨迹可以承担试探、积累负载与利用，换颜色/名称则不自动改变动作。
- **身体领随与接地**：重心转移、脚髋胸头的领随顺序服从当前动作；可由头胸察觉先导转向，不套统一“脚→髋→胸→眼”。起跳的加载可与上一回收重叠，下降接关节压缩、接重和续步；跳跃/翻越保留起跳边、空中弧线与落点关系，不能只用近景藏掉身体路径。明确的超常动力按原机制成立。
- **兵器与身体**：重量/长度/握法/质量分布影响启动、加速、延展和制动；武器自由度、体外净空与忙闲手跨动作继承。重器可有滞后、过挥或补步，熟练/超常角色按既定动力控制，不把所有重器统一写慢；接触后果按实际负载可读，不规定每击两项环境反应。
- **节拍**：必要预载、爆发、峰值、延展与收势可以重叠、压缩或跨镜承接。用相邻动作的轻重、速度与方向差建立乐句，不统一每2–3秒造峰值，也不每招停稳再蓄力。MOKE `action-rhythm-editing` 1.0.0 `rhythm-map.md`仅取方法，旧样例秒数不作为通用验收。

当前动作需要的相位按关系展开：

`进入姿态/来势 → 支撑或已设动力 → 身体旋转方向与前进路线 → 攻击/控制端任务 → 对手同步应对 → 交会或落空 → 落地/接重/制动 → 下一招入口`

并非每招在正文写八个字段。短动作可一句连成，腾空/武器/持续施法多任务时才展开。动力、旋转轴、路径、目标、防法、落点和相机落幅不同，不能都写成“旋转突进”。准备可利用上一回收与接重，不每次站好再蓄力。

## 24种选项：身体过程、交锋用途与出口

| 编号/动作 | 可写出的身体与武器过程 | 对手/环境如何参与；后续 |
|---|---|---|
| R01 前滚/肩前滚 | 从低位沿斜向向前转过肩背，持械手把刃收在不穿身体的外侧；滚势朝可达完整地面推进 | 在上路扫弧已从头顶越过时取内距；对手改低线追出口，起身腿抢接并回护 |
| R02 后滚 | 接触先卸开，屈身向后滚过背部，双腿随身体回收，剑仍随持械手 | 摆脱原先近身覆盖但让出地面；对手踏进截再起，落脚护刃接侧步，不能后滚直接变敌后 |
| R03 侧滚 | 肩胸向空侧转低，身体横过侧背，实际离开斜下攻击体积 | 刀追原落点后改向新侧；滚出沿完整地面起身，画内地标证明换侧 |
| R04 斜入滚 | 原先远处斜冲在上刃到达前收低，肩滚越过浅障碍边而非滚穿刀 | 守方退距压低刃线，进攻者起身接短送/点发，进入不等于命中 |
| R05 受力卸开滚出 | 被顶压后先导离/脱刃，后脚接住再向可用侧肩滚 | 来力改变原姿态，追击方继续抢出口；不是仍被控制时凭空翻滚逃走 |
| R06 滚势起身 | 回收的腿找回踏点，躯干由低到高，护手/空手任务相容 | 起身过程中对手仍可低切，先回护再追入；“起身”不是恢复全新架势 |
| F01 前空翻 | 助步与蹬离后身体沿前翻方向越过可用障碍，收拢与展开对应空中路径；武器不穿身 | 对手在预计下降区抬刃迎击；下降前改剑线/身体取位，落脚接重继续，不无因空中刹住 |
| F02 后空翻 | 接触已脱开、后方有落点，起跳同时向后移并后翻；持械臂保持可读刃路 | 让过当前上路而后让出距离，对手追到下降区；展开前回护，落地接侧退或反切 |
| F03 侧空翻 | 从横向动力起身翻过身体侧面，沿侧通道穿越，飞行路径与身体旋转分开 | 对手压住原直通路后转向落点；落地转胸接原威胁，不因翻到画边失踪 |
| F04 侧手翻 | 原武器约束已解除，用可用空手承担支撑，身体从侧面跨越，持械手外置 | 低扫掠过原脚位，守方改上路追；另一脚接地后抽手回护，不能双手持剑同时双手撑地 |
| F05 翻越低栏 | 前冲跨栏与前翻可组合，躯干真实越过栏上方，脚清栏缘，武器路线独立可读 | 守方移到落点侧，不站着等演完；落点位于完整面，若落点已封必须已设计改线 |
| F06 墙面/柱面借力侧翻 | 先真实靠近可踏面，接触改变动力方向再侧翻离开；表面破损状态沿用 | 追击刃到达原侧面或截下降，角色沿新路径接重/护身；没有接触证据就不能写蹬墙 |
| T01 轴转回切 | 已脱开的外切带动髋胸转向，脚步换位使身体围当前纵向轴转，刃沿外弧回到新目标线 | 对手可以退层或抢内侧；转后制动接短刺，不能自由整圈穿过双方 |
| T02 低位旋身 | 躯干降低、支撑腿换向，回收腿沿低弧绕行，武器保持身体外侧 | 用于高刃越过后的回切或换侧；对手下压则不再靠低位解决，应护刃/退出 |
| T03 腾空转体 | 已有起跳/飞行动力，肩髋在空中变向，身体朝向改变但质心仍沿已设路走 | 空中刀/束追实际轨迹，角色可调整刃面或身体迎接落点；转体不自动横向瞬移 |
| T04 旋子式横向飞旋 | 影视化横向跃起，身体斜横展开并旋过一段侧向空域，双腿与胸髋形成可辨轮廓 | 需要侧向净空；对手转刀追离地线路，收腿到可达落点续步；名称不能代替完整身体路 |
| T05 斜向反转 | 上一转胸/切势在接重或已有外力后改向，回收身体打开另一侧 | 对手追原旋向才产生窗；没有接重/接触/既定动力不在空中任意逆转 |
| T06 空中拧身取向 | 躯干扭转让武器/掌面朝向同一目标，腿与髋仍沿下落路回收 | 利用在途技能逼出的侧面窗口；持续控制手不能中途换去撑地，落脚后解除剩余扭势 |
| K01 回旋踢 | 支撑/转髋带出弧形腿路，踢击端向当前可达目标展开再收回 | 对手退头/挡腿或改低线，踢后落脚接回护；腿光与衣摆不能代替真实弧线 |
| K02 转身后踢 | 先转肩髋对向，沿身后目标线送腿并回收，另一手/武器保留来刃防线 | 转背窗由当前偏转或距离提供，对手绕侧仍有威胁；收腿落步面对新侧 |
| K03 腾空旋风腿 | 已有助步跃起，空中腿随髋胸扫过目标线，收腿进入下降 | 对手退距或截落点，未接触就不写击飞；不用镜头滚转冒充腿完成旋转 |
| K04 跃起弧踢 | 沿明确前进路跳起，腿在空中弧形展开，对手头胸处在可达区 | 近身武器已被导开才采用，落地不强制跪姿，接重续步可接施法/护刃 |
| W01 旋身回斩 | 先让刃自由，转髋/换步沿外侧净空带回剑，刃路与身体转向相容 | 对手截内线或退到门侧；斩后不能重复起手，接短送/再导离 |
| W02 后翻反撩 | 上路接触脱开后向后翻移，剑随外侧手路线由低到高挑出，目标在可达区 | 对手缩刀追落点，角色以落地回护/侧步续切；不能剑穿腹再从背后冒出 |

24项覆盖地面翻滚、前后侧翻、借物、旋转、腿技及持械融合，组合仍按场景取舍。表中的几何与身体相位是文字设计，不是这些动作已经生成成功的证据。

## 八条已经写出的完整动作链

### A 上路追刀—侧滚换位—起身短送
守门者B横扫上路，A斜退半步让剑脱离接触，低身向廊东侧滚出，刀沿A旧肩位扫过；B转髋压低刀追滚动出口。A收腿让右脚接住完整地砖，剑从身体外侧回护短架追刀，再沿导开的刀背侧短刺逼B撤脚。全身斜侧读低身/滚动/落脚，真正接刃可短取手刃局部，切回剑已滑离。局部修正：不能从“剑被压住”直接滚出。

### B 低扫封路—前空翻越栏—下降导刃—落地追入
B把低扫压进A的地面通路，A在刀尚未到脚位前从完整踏点跃起前翻越过东侧低栏，刃收在身体外侧；B向A预期落点侧移并抬刀。A完成身体前翻后在下降中展开护剑斜导迎刃，双脚落在栏外完整段，屈膝接重立刻侧步取B外侧。斜侧全身保留栏、离地与下降，不在翻腾中只看脸；相机沿落点横移接B追刀，不滚转画面遮蔽前翻轴。

### C 压刃—脱开后翻—反撩受挡—落地换角
A剑被B压向胸下，A向外滑剑脱开，后脚抢接后方完好段；在上路追刀抵达前向后跃起翻移，持剑臂沿外侧回带再低上挑。B缩短刀线迎住撩锋并追落点。A在下降前收回护刃，落地屈膝侧步消掉后移速度，回切迫B重新面向A。相机侧向追退保留脚离地、头髋翻转及落脚，刃交会时落稳；后方缺口若尚未让出则本链不成立，先改进入条件。

### D 外切被避—旋身回切—对手截内—制动短刺
A外侧斜切被B退肩避开，剑完全自由，A借切势换脚转髋让刃沿外弧回切；B不等整圈完成，短刀朝A转身内侧刺入。A回护将剑面转到来刀线上，前脚接重缩停旋转，再短送逼B撤开。相机位于双方斜侧能读肩髋转向，必要短弧只打开叠影；不要两者同时整圈转，失去身体相对地标证据。

### E 柱边追击—踏柱侧翻—落点被封—护身滚出
B沿西侧追A，A从柱边实际接触完好柱面借力向廊中侧翻，B将刀线改向下降出口；A空中剑导开刀尖但落点已缩窄，落地先侧肩滚离追线再起身回护。柱面在踏离处有可读受力，原破口不能当完好踏点。相机横移露出踏点后跟下降，手持可因B追刀掠近侧避，但仍交付接重与滚出。

### F 近身导刀—弧踢迫退—收腿落步—追门
A短架把B刀导离胸路，双方进入腿的有效距离；A转髋以弧踢向B侧肩展开，B收肩退步、刀回低线，A收腿落脚同时回护接住追刀，空侧一步取门。全过程并不保证踢中。全身侧面取景读髋腿与B让线，若切足部特写邻镜必须承接刀位置，不能只拍腿造成无防线的空白。

### G 点发封低—术者腾空转体—下落点发—落脚换位
成年术者A的独立蓝点发封住B原低位退路，B右手持续弧束向A腰路扫来；A以已设掠步接起跳，空中转肩髋让束芯从外侧越过，质心仍朝栏外完整落点走。A用不承担持续控制的左手在下降中短点发，B右手弧束改线拦截、身体退向柱座。A落脚接重向门侧移，不能凭转体瞬移到B后方。这里不添加剑、盾或飞行。

### H 自主代理封出口—本体侧空翻—代理受阻改路
原创G中灵狐前爪压B东侧退路，A沿另一侧掠近；B用刀上挑挡开爪外缘，紫弧束追向A的地面横路。A借完整踏点侧空翻跨束，落地换侧点发；灵狐被柱挡住正面路径，收爪由破口压肩，B转向柱座承压。相机短收A全身翻越后迅速拉宽，保留灵狐/柱/B同一场地。代理受阻与本体翻越并行，不切回两人又站原位。

## 摄影如何读清武学动作

选择能读到当前轴、路径与交会的角度，斜侧或侧面常可比较头—肩髋—脚的翻转，正面可读来刃逼近，俯视可读换侧与落点；没有通用禁90°侧拍。保留场地竖线/地面，身体转与相机滚转才可区分。翻腾中可以特写局部，但邻段必须交付未完成的身体路与下降，不把翻滚剪成“低头→站敌后”。

手持可在近处来刃时侧避、起伏、滞后追回；动作关键读取窗口相机落稳。全身读形、局部读刃接触、脸读决定，任务各有收益，不要求每招三镜。拖尾只沿已经经过的身体/攻击端路径，弧形衣摆不代替转髋。

## 动作复核：用对手打断来查空窗

在转背、展开腿、腾空、换握、落地和再起处，先核对手已定的速度、感知/反应和这段世界进程，再用当时真实可用的刀/束检查当前出口：能否来得及转向、抵达，是否已被偏转/距离/环境阻止？速度型角色按[速度与相对时间](../../an-workflow/references/speedster-combat-direction.md)处理；普通人来不及追截可以成立，主观段播放数秒不替他增加反应时间。同级对手、此前已发出的攻击或既有范围威胁仍按可达性求交，不能靠“高速”抹去真实碰撞，也不为检验反制临时给普通敌人同速或新增能力。若既定条件确会打断，补获准条件或改链；保留相容极速与短促起停，不统一加长刹车或删掉大动作。真身、武器路径、落点和接重持续承接，近乎凝滞的世界不等于时停，省略展示不等于瞬移。受阻与命中并非每次都有，落空后继承余势和地面关系；固定静音、慢镜展示、纯剑和单一能力仍可成立，不硬插这些练习。

## 2026-10-25身体运动补学与采用

以下为公开一手文字资料的定向阅读，未观看其课程、排练或生成成片；将方法用于本页，具体战斗转译是本工作流的设计推论：

- [Wayne Gilbert：Body Mechanics Shot](https://www.animationmentor.com/blog/animation-tips-tricks-what-makes-or-breaks-a-good-body-mechanics-shot/)强调分析运动由什么驱动、身体各部位如何领随及预先移重，而不只比对某帧的位置。采用：动作检查沿驱动、重心和领随过程走；拳肘不因名称就被判作局部运动，翻腾也不因名称自动算完整全身动作。
- [Chris Hurtt：Anticipation](https://www.animationmentor.com/blog/anticipation-the-12-basic-principles-of-animation/)讨论预备的幅度、时机与后续动作相配，以及接收者不能在实际受击前开始反应。采用：快战允许上一回收承担下一预载，但不以短时间码取消必要加载；对手反应按接触/读取发生，不能提前配合。
- [Animation Mentor：Advanced Body Mechanics](https://www.animationmentor.com/animation-program/advanced-body-mechanics/)把动态身体运动、叙事、调度与构图共同用于动作段。采用：身体表现与美感也是设计目标，可以从原创阶段共同安排相容对抗和场地；连续性复核用于修入口、路线和接续，不把旋转腾跃一律压缩成最短路径。
