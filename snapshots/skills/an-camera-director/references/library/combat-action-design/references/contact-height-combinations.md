# 接触、高低与支撑：把模块编成动作组合

用于近身动作重复、腾挪脱离交锋、落地后重摆，或多人同一高度排队出招。下面是用户参考片段启发的编排结构，不是逐招复刻、已验证武术技术或每场配额。先继承角色战法、装备、能力、场地、强度与胜负，只采用相容部分。

## 接续的材料来自上一轮双方状态

取一个本场已有的入口：上路来击、膝线受截、对方降身、被推向桌沿、落地承重或多向斩击。选后招时读当下高度、支撑、接触、占用肢体和距离；同一拳换方向不自动变丰富，花招换了名字也不自动有用。把对手此时的反制一起写进组合。

| 可采用结构 | 双方接续与变化 | 采用前提、受阻出口与观看证据 |
|---|---|---|
| 上路压迫→降身→膝线受截→短支撑过身 | 甲连续压上路，乙降身进入甲近侧；甲抬膝，乙用可用前臂争膝线，随后在已伏低的身体上建立短接触，沿相容净空过身 | 不默认按一下就压住全身或对方自愿当跳台；支撑滑脱/对方立起会改变跨越，接撤手、失衡或原近线。明确受力点、离开接触和两脚接重。启发：V02约3.0–5.3秒 |
| 借竖直支撑→高位膝/腿→被截→收腿落步续攻 | 甲在已有可承力面附近建立支撑，将腿送入近线；乙争其腿/髋或推开躯干，甲收腿、松开支撑，在实际新落脚上接上肢动作 | 立柱在背景不等于手已握住；能承重、可用手和触及点都要明确。落地前不同时宣称全身自由。启发：V02约12.8–15.3秒，握点有遮挡，具体支撑设计是迁移补足 |
| 近身接触→移走支撑→桌沿承力→翻落恢复 | 甲在相容臂/躯干接触中使乙失去原支撑，乙先接到已有桌沿，再以可用手/身体争落地；甲在同期追入，乙从低位继续防线或起身 | 移动来自接触，桌沿须真实可达；普通推击不保证整个人飞起。原支撑未放、兵器/控法手忙时改变解法；桌沿破坏就更新承力面。启发：V03约3.0–5.0秒 |
| 贴身转控→横向摔转→撞物改变场地→低位接招 | 甲贴入换支撑，把接触转成横向移重；乙争抓持和落向，若撞到桌面，破裂/倾倒后的残留改变双方低位通路 | 能否摔转由承重、控制和抵抗决定；未移走重量不直接掀飞。碎板位置、可用地面和追压持续，不撞完重置家具。启发：V03约17.8–19.5及25.0–27.8秒，两个区间不是同一无切完整链 |
| 倒地受压→低位护线→换支撑起身→转身截追 | 乙倒地/单膝承重仍用自由端处理甲下压，移重到可用支点再起；甲追其新位置，乙将正在恢复的转体接成相容截追，收腿后继续 | 倒地不等于停机，也不默认立刻反踢成功；腿、支撑手和头部防线各有占用。第三人同期威胁继续，受阻可保持低位应对。启发：V02约19.0–22.2秒 |
| 两向斩线→降身/转体→低高转换→落脚处理新来线 | 两个威胁从各自角度形成；单方处理第一向后已转身/降身，第二向追新位置。按实际斩幅、支点与净空选择低身穿线、撑地侧翻、跃过低路或既定幻想位移，再接下降与续攻 | 不把所有攻击自动躲开，不让攻击者互相砍中代替有效夹击；第二人来向/到达有证据。腾空机制、带刃手路径和落脚成立；对方改高低可截出口。启发：V05约11.8–14.5秒 |

前三类可接原H/G/A模块，最后一类接一对多共享战局；编号不进入作品。源片中的模糊、物件穿插和夸张幅度不当作正确身体条件照抄。

## 同期丰富，不用恢复到开场再选招

身体进入、腿收回、手从支撑转回防线、兵器脱开、对手追入都可提供下一入口；在同一动作乐句内变高低、支撑和距离。大幅度并不天然出错，成立的借力、净空、动力与接续保留。角色不兼容身体接触/翻腾时，把相同争夺转为已设器物、作用面或控制变化，不能为了使用本页给角色新增拳脚能力。

多人的丰富可以来自不同战法和相位，而非人人翻一圈。近端实体动作、远端攻击、受压/恢复与接替在共享时间中相互改变；独立双线不硬称团队配合。动作结果交给[连续交锋观看](../../action-camera-direction/references/continuous-fight-handoffs.md)，只授权摄影时本页是继承信息。

## 验采用，不以库容量验收

去掉招名和镜头术语，实际正文仍能辨认接触怎样变化、哪里承力、谁改高度、哪里释放、对方如何反制及出口。只有“拳肘膝踢翻摔连用”仍需展开；已有清楚正文不再重述整份动作卡。参考时间与观察边界见[六条研究记录](../../an-workflow/references/six-reference-study-20261015.md)，仅抽帧不能认证正常速度观感或生成稳定性。
