# 连续交战：从对手的可用窗口编接续

适用于双人及多人实战，尤其召唤、蓄力、领域展开、击后恢复与切镜处。先继承角色能力、装备、目标和节奏；只改动作时提供观看所需事实，不新设机位。来源校准与原创练习见[学习记录](../../an-workflow/references/cinema-study-20261022.md)。

## 动作进入下一招之前，时间没有停

把“甲出招—乙接招—甲收招—乙反击”的轮次，改为共享的运动区间：甲的回收/控制尚在进行时，乙已经在让线、抢位、卸力或发动相容的反制；甲的下一准备也可藏在这次接重与转向中。重叠的是可兼容任务，不能同一只手既维持导引又独立抓枪，或在脚尚未落地时无支撑发力。

关键接口核上一拍的支撑、朝向、距离、接触、持物/控制、余势与在途状态；只追会改变后招的项。受阻就沿真实受阻出口重选，不能继续成功版连招。“借惯性”“迅速接上”须有具体重心转移、释放/滑脱、攻击线与可用肢体。

**改控也要有入口。** 下压改上拔、牵引改旋转、持续锁定改放手时，给看见/感到什么、何时改手势/支撑、作用端怎样续接；不能从前镜下压直接写后镜“仍在上提”。“仍/继续”只能指已成立的同一状态。决定结果的卡阻、杠杆与锁止还要给进入前的自由度、接触点/力向及加入约束后的区别；只写“被卡住”或枪杆弯曲不能证明几何成立，接触体本身怎样承受负载也要相容。只修动作时提供这些事实，不越权改镜头。

## 给对手一次真实的机会审查

在每次准备、显化、击后回收与人物反应处，代入对手当时可用的最直接有效行动：能贴近、断线、封步、攻击控制端、避开作用体还是抢目标？

- 能尝试：同一时间写出其路线/防线/操作，以及施术方怎样边完成当前任务边应对；反制不强制成功。
- 不能：此前已有可见的限制、有效距离、危险体积或资源占用，并持续进入本拍；不能临时说“被气势震住”让人停机。
- 主动延迟：必须有具体诱导目标、正在保持的防线和触发点；当前请求禁止打中停下来对峙时，不把策略等待写成双人站定对望。

镜头切走、景别变近、烟尘遮住和相机环绕都不改变这项审查。画外角色的行动预算计入同一时间，回接在当前相位；不能回到插镜前的位置等候。

## 召唤与持续控制的四条同期关系

1. **显化区间**：施术者的支撑/导引与敌人的进路同时推进。敌人看到的前兆决定其反应，不能在前兆出现前无因预知结果。
2. **起效交会**：作用体到达的区域与敌人当时位置吻合；反制可以改变形成路线、关节、源端、控制或目标条件，不只等巨物砸完。
3. **控制负担**：持续双手导引就保留双手与该任务；如要脱离，按已定机制承受停止/失控等后果。自主代理才允许本体放手另做事，不自动加自主。
4. **结果接续**：命中、受截或落空马上提供新任务。施术者改控/接重，对手借残留、位移或占用争下一窗口；不以“技能结束，双方重新站好”断开。

施术者可短暂站稳维持控制；成立原因是正在负载且对手/作用继续改变条件，不能靠摄影在动免责。不逼所有法师边施法边跑，也不以保持为由让对手站立欣赏。

## 重叠衔接的可用结构

| 当前出口 | 可接的任务关系 | 必须防止 |
|---|---|---|
| 兵器被拨向外线 | 沿已打开侧线进身、回收改线，或以另一可用端压住追击 | 刃仍被夹持就独立反挥；对手等其收完 |
| 防守造成躯干旋转 | 接重/转肩继续让线，同时用尚可用防线处理追压 | 无支撑空转；为展示加一次无因翻滚 |
| 一手持续维持控制 | 另一手或已允许的脚步处理当前威胁，控制端继续负担 | 控制手被写去抓人但远端仍照旧行动 |
| 双手持续控制且不可腾手 | 用相容步位/身体避线或作用体遮断；被迫放手就兑现机制后果 | 偷增第三只手、护盾、自动防御或新飞行能力 |
| 受击下沉/滑退 | 在已有支撑恢复、回护/避线/改控中呈现疼痛与判断 | 站直揉伤，敌人暂停，随后重新起跑 |
| 巨型攻击被局部卡住 | 控制者调整未受限部分/抽离，敌人利用占用处理下一目标 | 巨物每次切镜再成形；卡住一肢等于全部停时 |

## 验收

暂去相机、光效和“高速”词，逐关键窗口读双方能做什么、已在做什么、结果怎样改变下一招。稳定角力、被控、慢镜或固定机位按真实作用成立；不存在通用“每三秒换状态”硬指标。速度层次来自准备与爆发、碰撞与回收、读取与续压的关系；持续交战不等于全片匀速乱动。
