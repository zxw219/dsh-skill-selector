# 按当前出口选动作：距离、接触与受阻分支

用于编招前找相容组合、同一组动作反复出现、兵器差异不明显。与[模块库](action-module-bank.md)共用编号；这里按条件检索，库内标签不进入最终提示词。以下为原创影视编排，不是实战训练、动作捕捉或生成实测。

## 从当前限制进入

先取此刻真正限制选择的一两项：距离/高度、已有接触、可用肢体、兵器实体及运动、场地支撑。找到能解决该限制的模块，再将对手此时仍可做的应对代入；不从“想用空翻”反推一个临时威胁。

| 当前出口或限制 | 候选结构 | 下一步必须继承 |
|---|---|---|
| 刃刚滑离，对手仍在追入 | W1、W3；需改变长短关系时W5 | 刃路、空闲手、真实距离，不能远处柄击 |
| 长兵前端越过目标，近端受追 | W2、W5 | 杆端/持握改变及双方继续移动 |
| 双持一端被压住 | W6 | 被控端保持受限，自由端不穿过交叉兵器 |
| 已有软兵器落空或被截 | W7 | 实体长度、松紧、回收去处，不凭擦碰自动缠牢 |
| 重兵器被让过，动势尚未收回 | W8 | 继续的重心、制动条件、对手抢回收的威胁 |
| 上路被占，下盘或侧线出现机会 | H4、H5、H6 | 支撑、髋膝路线与收腿后的防线；不预定对手必被扫倒 |
| 接触刚被破坏，身体尚低/失衡 | G3、G5、G6、A1 | 未解除的控制、手与支撑、起身所需空间 |
| 阶梯/窄口限制长弧，双方已到边界 | A5、W5、W8 | 高差和净空的原位置；不靠切镜重新站平地 |
| 支撑面正在移动/失效 | A6、G6 | 面的实际速度/倾斜、触地次序与双方同期落点 |
| 持续法术占一手，源端正受压 | F2、F5 | 维持/变控/转交的既定规则，不能无因解放忙手 |
| 前招留下节点、附着或代理 | F4、F6 | 前置来源、消费或保留、对手能否破坏/绕过 |
| 协助失败或队友暂时不能利用 | T5、T6 | 原压力、利用者实际位置，不复制原窗口 |

没有相容候选时从原能力和实际出口原创一个结构，不强行套编号。纯远程、纯兵器、单招与指定动作继续按原边界选择。

## 兵器差异落在相遇关系

| 已有兵器条件 | 可发展的差别 | 需要被反制检验的限制 |
|---|---|---|
| 长对短 | 外端占线、收短追近端、重新获得距离 | 短方怎样真实进入；长方为何不能继续追线，不能只宣告贴身 |
| 双持 | 一端处理当前接触，另一端利用相容新线，或两端先后回收 | 两手不是两次无条件攻击；交叉、互遮与忙手连续 |
| 重兵器 | 以推进/负载迫防，落空后利用余势改任务或制动 | 不统一慢放；对手抢回收时须有实际处理或承担结果 |
| 软兵器/链状器物 | 伸展、受阻、松弛、再张紧与回收改变可用空间 | 没有接触/张力不自动牵引，长度不足不跨场；不是无限长光带 |
| 既有盾与单手兵器 | 盾缘与兵器的方向、负载和可用手形成转换 | 仅适用于原装备或已授权装备；盾不覆盖任意高度与所有方向 |
| 非人形/载人代理 | 支撑数量、转身半径、翼尾体积或承载约束改变入距 | 仅用已设结构与能力；头躲开不表示翼尾都避开，代理忙碌时乘者不任意改向 |

## 同一威胁，不同角色的解法

对手中路追入时，精准截击者可缩短来线后接短反制；强压者可让防线承受负载、继续争通路；灵活者可绕实际接触端改变观察/攻线。三者不必都做一次侧移或翻滚。选定角色习惯后，让失败和地形改变其解决方式；习惯是倾向，不是固定连招循环。

## 三条出口驱动的组合

**长兵对短刃，进入受阻**：长兵者的前端追住门外通路，短刃者先沿既有柱边接近；长兵者看见其进入便收短回带，尾端转向近线。短刃者不能直接穿过回带区，于是缩步截住尾端，另一手仍护原来线；长兵者在接触中换支撑争回端部空间。若尾端被控制，就沿W2受限出口继续争握持/脱开，不立即恢复整根自由大扫。由W5接W2或G3，结果由实际接触决定。

**双持一端受压，转线被识破**：甲右刃正在接住乙长刃，左刃从体外短路准备进入；乙不继续无条件压右刃，而是撤出交点、追甲左侧新来线。甲右手随接触释放回护，左刃缩线，脚下接重使两把兵器不交叉堵住胸前；接下来可以继续双持抢线，也可以被迫退出。不同之处在双端任务变更，不在多宣告一次命中。由W6接W1，受阻时不照搬原出口。

**低位恢复遇到第二来向**：甲倒地后以可用前臂处理乙的下压，足地接触和地标让其能转到侧卧；第二人已沿外侧接近，不能等甲起身。甲撤开原接触后将近脚接地，身体仍低着先面向新来线；乙同期追原低位出口。甲只有在两条来线被已有地形/队友短时隔开时才完成起身；否则继续低位防守或受压。由G4/G6接T6，不把“站起”作为自动成功结尾。

## 采用检查

比较的是实际解法：换模块后，对手的应对、己方资源或后续任务有没有变化？若只有左右、招名或角度不同，回到当前限制重新选；有用的重复仍保留。丰富要求不授权加武器/能力，不把40项库容量变成一场招数配额。
