# 修仙高级剑招：25式执行与战术转译

依据用户提供的《兵器技法资料库_修仙高级剑招专项》，保留25式原名与顺序。适用于确有持剑/御剑/剑阵机制的角色；先确定当前目标、剑实体数量、握持/离手控制、距离与空域，再从当前机会选招，不把全25式塞进一段。兵器动作、身体路线、剑气/阵、位移与目标、观看目的分别成立。

## 选招依据

| 招式（原顺序） | 可采用的执行结构与用途 | 成立条件和承接重点 |
|---|---|---|
| 天罡横旋 | 持剑外放横旋并推进，风轮式扫线/破围 | 净空、支撑与外圈刃路；对手可截入/退层，旋后接真实制动 |
| 九霄凌云 | 剑气阶或御剑连续拔高，占据高位 | 已设托举机制、各段高度与对手在形成时的行动；顶点保持按任务决定 |
| 逆鳞翻江 | 反手撤引、后翻下上挑斩，再接逆向撩割 | 来袭从何处让开、后翻净空与第二斩目标，不能翻完无因回原位 |
| 星河倒卷 | 螺旋剑气先收束路线，再外卷打开作用面 | 旋向、内外边界、控制端和对手被逼的新选择 |
| 流云追月 | 身法先行，多段折线追及并切换虚实斩路 | 每段真身路线和同期目标；残像不自动有伤害或瞬移权限 |
| 惊鸿三叠 | 直突、侧换线、斜上压落连成三段 | 前斩造成后斩窗口，接触可成功/被挡/落空，不预定必中要害 |
| 莲华绽放 | 八向剑路外扩封区，再回收护中线 | 攻守区域、有效剑气/实体剑分开；回收时敌方继续争线 |
| 龙渊潜行 | 低位剑尖贴地弧进，接近后骤然上扬 | 地面净空、身体和剑尖各自路径、上挑的可达目标 |
| 凤舞九天 | 空中多次变向蓄成回旋俯冲 | 已设空中动力，各转利用实际威胁/机会；九次为此招方案非所有空战配额 |
| 万剑归宗 | 收回散落剑气与灵息，聚细剑再压成一线 | 来源和收聚途径、形成时对手任务、窄线接收端；不全变爆炸 |
| 阴阳轮转 | 正反双轨护线与切线轮换 | 同一实体剑的路线连续，双轨来自已设作用体，不凭双色复制实体 |
| 断浪新潮 | 前浪压位、中浪切线、后浪封退接力 | 前后浪未决状态、接收空间与对手可用通路 |
| 百步穿杨 | 细线锁点，远距贯穿攻击 | 感知/瞄准依据、无遮挡射线与移动目标；远不自动必中 |
| 缥缈幻影 | 真身高速错位，残影诱导后切入 | 真实路线、落点和被骗的判断；速度幻踪不当实体分身 |
| 天外飞仙 | 高空长滑与俯冲压成长斩线 | 高度、入距、身体剑锋同向关系、俯冲后的接重/续攻 |
| 陨星坠地 | 剑尖聚核，人物携剑垂直坠击 | 坠落通道、目标/地面首触、反作用和冲击圈传播 |
| 盘龙缠身 | 龙形剑气绕有效部位困控，再收束穿攻 | 哪个部位受限、控制/抵抗、可用肢体与破解出口；不自动全身永久定住 |
| 回风拂柳 | 转腰外圈卸来力，内圈短反切 | 真实接触/偏转、脱开与对手回收窗口，反切不先复位 |
| 雪落无痕 | 轻细剑气分点下落，利用难察觉的空隙 | 点位来源、下落通路、感知范围与反应；轻静不自动无敌必中 |
| 乾坤一掷 | 旋身掷出实体剑，远斩后牵引折返 | 出手时空手状态、飞剑控制、折返通道与接回握持；不在手和远端同时存在 |
| 剑气长城 | 立起层墙，外层拦截、内层反推 | 有效墙面、局部受损、加载与控制者后续任务；防守仍改变局势 |
| 踏雪无痕 | 轻步隐匿绕线，利用背侧窗口刺入 | 地形/遮挡和实际绕行；不以“背后显形”跳过转向与跨度 |
| 九转轮回 | 围阵心轮转，逐步改距后刺入空隙 | 阵心/阵边、每转新条件、对手反制与出口；九转是招式设计非通用硬配额 |
| 破空裂虚 | 长斩带出短时空间裂缝及边缘作用 | 已设裂空机制、边界/寿命、避开主刃后是否仍入作用区；不自动追踪所有目标 |
| 大道无形 | 极短路线、极小起手完成精确作用 | 已设能力、控制/目标依据与接收结果；不以看不见省略因果，不强加满屏炸光 |

## 组合成攻防乐句

从本轮机会取进入、诱防/换线、承压/拆解、反扑、追及、封区、收聚或终结的相容结构；不是将招名串起来。前招被卸开的剑路、敌方回收、地形被切出的通道或已设阵点提供后招条件。纯持剑也能通过高低、直弧、长短、顺逆、接触和空间层变化丰富；御剑与手持转换须有实体与控制依据。

来源中的挑刺要害、三叠/九段、悬停与定格是具体招式设计，不自动改用户胜负、伤害、时长或节奏。来源的30°/45°/60°摄影、禁90°侧拍、慢推蓄势和固定镜序不作为硬规则；依据当前攻击线、取景、轴线与观看收益选机位，侧面清晰读线时仍可用。

## 转译给非剑角色

无剑术者只迁移战术关系：例如层浪接力转译为当前已设介质的封路，外卸内切转译为偏转后源端短反制；重新建立本角色的身体、源点、材料、控制和结果。不得将“以剑为核心”的动作直接移植给法师，或因丰富模块让所有人突然持剑。能力锁定则仅在已有用途内调整。

## 观看与验证

身体取位、有效剑路、目标响应和下一状态先成立，再选局部接触、关系景或范围景；高速以入距/地标与攻击相位证明，阵墙以层级、作用与反制证明。残影、剑气和材质沿同次路径延续，fx-env不重发招。完整原文、来源哈希与迁移边界见[学习记录](../../an-workflow/references/combat-transition-study-20261012.md)。本表是资料转译，不是25招生成实测结果。
