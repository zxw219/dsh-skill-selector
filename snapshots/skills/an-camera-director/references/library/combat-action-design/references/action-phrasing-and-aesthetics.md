# 动作词汇、组合与身体美感

用于原创打斗、动作单调、只有少量挥砍、拳腿与施法像摆姿、近远战转换缺动作的设计与返工。先采用当前角色、武器/能力、任务和用户指定表现，再取相关动作关系。以下为影视/动画编排方法与原创选项，不是经实战验证的技术教程，也不是固定招式菜单。

## 先决定角色怎样动，再验证能否接上

反馈“动作模组少、只用几个动作”时，先按[可接续动作模块库](action-module-bank.md)定位储备、选用、组合、表达或成片执行缺口，在编事件之前采用差异明确的结构。下面的动作族是索引，不等于模块已经用进正文；先写斩刺挡退后再附一份丰富清单不能补救。需要丰富时，把相容的控制/摔转、手脚组合、兵器长短转换、翻腾恢复、施法/御器及团队接入选择落实为实际过程，不要求每场全族遍历。

动作语言由主战距离、进入方式、身体轮廓、攻击路线、防法、收势与释放习惯共同构成。轻巧角色可用紧凑步位与突然展开，重型角色可用压入与承力，精确角色可用小幅截线，夸张角色可用大弧与腾跃；同一角色也会因对手和地形改变解法。不要让所有人都用“前冲—横斩—格挡—退开”。

先给本段一个目的，选择能改变局面的行动；从上一结果找到入口，再设计主动作和出口。状态约束用来补成立路径，不能把选择范围预先缩成斩、刺、挡、退。正文写动作过程，不只给流派/招式名，也不逐招公开内部字段。

一个动作单元可以这样推演：

`当前距离与威胁 → 身体/兵器从什么姿态进入哪条路 → 对手如何改变来路或承受 → 哪个部位先回收/接重 → 出口产生什么下一任务`

## 动作关系索引：选用条件比动词数量更重要

| 动作族 | 可选择的身体/路线变化 | 何时有用；出口接什么 |
|---|---|---|
| 接敌与步位 | 追步、斜切、低位滑进、交错步换侧、急停折返、跨越障碍、掠过转胸 | 改变相对距离与攻击角度；滑进须有动力/接重，不能默认低头就避开整个扫弧 |
| 兵器直线 | 短送、追刺、收肘缩线、回带后再送、由高路转中路 | 狭窄净空、短窗口、对手让线后重新找目标；回带不是再次命中 |
| 兵器弧线 | 斜落、低位上撩、回切、斜挑、压低刃尖后翻腕换线、绕体收刃 | 改变攻击高度与侧面、利用已有余势；旋转先看净空和对手的自由攻击，武器不能穿身 |
| 接触与拆解 | 短拨、斜架导离、沿刃滑压、收臂脱开、换步卸开、柄/护手短撞 | 来力、接触点与持续时间各异；结束后究竟自由、仍受压还是已失距决定后招 |
| 拳掌与紧凑近身 | 直送、弧拳、回护接短拳、掌推、前臂截线、肘部短撞 | 进入本体距离才采用；闲手、来刃和对方反抗明确，持械者保留兵器当前任务 |
| 腿与高低 | 提膝威胁、短膝、侧送腿、弧形扫踢、低位扫、跃起伸腿、收腿落步 | 目标高度、髋部方向和支撑/腾空相容；提膝不自动算膝击，踢后折叠/落步有区别 |
| 身体让线与反制 | 转肩、折腰、下沉、侧移、绕接触点转胸、借来势改向 | 身体须离开实际攻击体积或改变它；控臂转身必须有接触、支撑及对手挣脱，不凭一词翻摔 |
| 地面翻滚 | 前/后/肩背/侧滚、斜入滚、卸开滚出、滚势起身 | 上路已让开/接触已卸开时改变距离与高度；对手追低路/出口，落脚回护接续，不等表演完成 |
| 腾空翻腾 | 前/后/侧空翻、侧手翻、栏上前翻、墙柱借力侧翻 | 净空、支撑或已设动力产生越障/换侧收益；对手追下降区，武器体外路、可达落点与接重明确 |
| 旋身与融合 | 轴转回切、低位旋身、空中转体/拧身、旋子式飞旋、回旋腿/后踢、旋身回斩 | 转背窗、攻击端/身体路线和控制任务相容；收势与制动利用上一余势，不把镜头转当身体转 |
| 接重与恢复 | 后脚抢接、侧步吸收、屈膝缓冲、落地转胸、回护中追步、被迫扶撑 | 受力改变下一距离、朝向或忙闲资源；恢复有压力，不默认完整复位 |
| 器物与控制转换 | 接回握柄、换握、离手操控、收器回身、持杖回带再指向 | 实体位置、手的占用与既定控制方式连续；只有一器不能同时在手、脚下和远处 |

表中选项可用于一招的相位，也可成为乐句的一部分，不要求每场遍历。不同词若身体过程相同，仍然单调；同一动作因目标、入距、防法和出口改变，也可能形成有效变化。

## 施法与远程释放的身体动作

先问发动到底需要什么：手诀、接触、器物、步位、视线、念动或事件触发。然后设计相容的身体过程；技能已锁定时不换发动规则。手势、辅助纹光、实际作用体与目标端变化分别判断，不能把所有施法改成持彩带甩击。

| 当前机制 | 可设计的动作相位 | 持续任务与出口 |
|---|---|---|
| 点发/短诀 | 回护中收指、转腕定向、指端短送；其余身体继续让线或移动 | 瞬发无需长蓄力；短诀后能否松手依能力，不强行物理后坐 |
| 掌式释放 | 胸侧收拢、肩胸打开、掌面到达发射方向、腕臂回收接转身 | 掌推出前方向已对准；已离体独立运行的作用不随收手整体折返 |
| 挥器投射 | 上一接触脱开、收刃转肩、沿新的弧面挥出远程作用、回刃护住追近方向 | 兵器实体与投射作用区分；没有投射能力只保留物理挥动 |
| 触物布置 | 屈身接近承载物、空手触及、撤手同时离开该面 | 地点/附着对象确定；未获授权不凭此增加阵法或标记 |
| 持续操控 | 在移动中改变指向/器物角度，身体承接对手压力，操控手仍承担任务 | 不能同手放弃控制做另一攻击；控制解除、转交或自主运行有已有规则 |
| 范围展开/召引 | 由收拢到展开、双臂/器物形成相容姿态、身体与场域方向相接 | 仅机制需要才采用；大招不必举双手，远端巨物仍接本体当前任务 |
| 念动/被动/无形 | 视线、呼吸、身体应对或接收端状态提供必要证据 | 没有手势条件就不强加结印；被动效果不冒称本体主动释放 |

同一掌法在追近时短推出、侧身中定向发出、受压后压实再送，可以不同；这种身体变化不能擅自改变射程、控制权或伤害规则。施法美感不只手指：眼神指向、肩胸开合、肘腕领随、步位/飞行方向、衣发滞后都可服务一个明确作用。

## 把近身、远程与法术编成乐句

明确手脚并用时采用[全身与能力协同](../../an-workflow/references/full-body-ability-integration.md)的窗口关系：上肢截线/牵制→腿改低路；腿迫使换防→手抢新空线；接触脱开/落脚→术法作用利用新状态。脚仅跑动、承重或起跳不能代替实际腿攻/腿防/下盘控制；踢击需进入距离、支撑或合法腾空、髋膝路径、目标响应、收腿/落步与续招。用户锁定纯远程/纯兵器仍保持，不遍历拳肘膝腿目录。

不按类别轮流表演。转换来自当前结果：

- **远程迫避→追入**：弹体占据旧路线，对手被迫移向可达通路，攻击者用实际位移缩短距离；对手仍能回护，不能凭远程命中把人送到身前。
- **近身受压→制造释放窗**：偏转、错身、遮挡或已有控制让本体离开短刃覆盖区，释放准备接在移动/回收里；对手追入或争别的目标，不无故停等。
- **兵器接触→身体/柄部动作**：来刃被导离且双方进入相应距离，空肢体才参与；兵器任务保留，结果再决定脱开还是追压。
- **离体运行→本体第二任务**：前招已按规则独立运行，本体可以追近、防守或移动；若需持续控制，第二任务只能使用兼容资源。
- **落地/接重→发力或反制**：接重同时产生下一动作条件，不在两个动作间重摆架势；需要缓冲时保留，不把所有落地写成弹射。

每个乐句有变化、主重音和出口。变化可以是距离、高低、方向、幅度、防法、主动权或身体开合，不为“多样”强制换属性。真正的高潮兑现本段争夺，不能末尾插入无关的大招。

## 动作美感：轮廓、领随与轻重

1. **行动线与剪影**：关键姿态的身体方向、攻击端和目标关系清楚。收拢蓄势与展开抵达可形成对比；紧凑动作同样好看，不都拉成长弧。
2. **高低与方向**：根据威胁在高路、中路、低路或不同侧面间转换；脚步和转胸带出变化，不能只把镜头转到另一侧冒充新招。
3. **部位领随**：先有目标与动力，肩胸/髋部、肘腕/兵器按本招关系传递；衣发延迟辅助读形。别让全身同速插值，也别套每招相同发力顺序。
4. **幅度与节律**：小拨接较长切线、短压接突然展开、受力制动接迅速回护都可形成轻重。具体时间服从内容，不规定每秒招数、每击停帧或一律零停顿。
5. **接触重音与出口**：峰值由真实交会/变化承担，受阻后路线和形态有改变；漂亮姿态不是停给相机看，除非用户指定定势、慢镜或演武。
6. **角色差异**：准确、灵巧、强压、沉重、飘逸或夸张由动作选择兑现；不把“美感”统一成转圈、翻滚、舞蹈或慢动作。

抽帧能支持姿态与相位关系；真实快慢、停顿感、连续过渡与声画重音须正常速度播放再判断。未知处不要补成精确武术名或推测的摄影参数。

## 摄影只放大已设计的动作

先看需要观众辨认的身体变化。换步/腿技需要取景保留脚、髋与目标；控臂转体需要读到接触和身体改向；释放需要本体发动与生效对象之间有观察衔接。侧面/斜侧可读剪影与路径，近景可读局部接触，高位可读多向威胁；按当前收益选择，不固定镜序。

相机可稳定跟移、固定、一镜到底或切镜。切在来路、接触或新出口上，继承进度，不重播起手/命中。大幅绕拍不能占用动作时间迫使角色停姿；特效不遮关键接触，衣料不与主体轮廓糊成一块。纯动作缺变化先修身体；已有好动作没看清再修观察。

## 成稿与反例验收

隐藏招名、华丽/高速标签、装饰光和摄影词，再读正文：是否还有明确的进入、不同路径/防法、身体变化、受力与有因接续？有用户“丰富”要求时，差异必须出现在正文而不是角色表中。没有实际动作过程就补编排，不仅扩充同义词。

同时验当前锁定反例：纯持械可以只靠剑路与步法变化；单技能可以深化应用；慢镜、定势、持续压制和重复追击可有意成立；单人展示不硬加对手；完全静音不加冲击声；固定机位不偷插特写；无飞行/瞬移角色靠已有支撑和通路完成。不给所有场景设动作数量、镜数或成功率。

只报告实际层级：原创文字、文本结构检查、人工语义复核、源帧观察、正常播放、生成试跑或真实成片验收。完整动作词汇不等于模型已经稳定生成。

## 大动作专项的按需扩展

明确翻滚/空翻/旋转或要更丰富武学动作时，从[过程与完整链](acrobatic-action-design.md)取相容结构；以上词汇先影响选招，再验对手追截、恢复和观看，不只在交付前扫描词数。24项训练不是每场动作配额，纯剑/单能力/合法保持仍成立。
