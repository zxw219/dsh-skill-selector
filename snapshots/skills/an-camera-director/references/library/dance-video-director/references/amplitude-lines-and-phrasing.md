# 幅度、身体线条、收放与镜头配合

适用于动作幅度失控、动作不美观、舞句只有摆胯抬手、镜头有变化却读不到美感的返工。以下是从已观察片段转译出的设计方法，参考锚点见[研究记录](sensual-reference-study-20261008.md)；原创编排须与源片观察分开。

## 先决定哪一处展开

不要用一个“幅度大/小”支配全身。为重点舞句分别决定下列部位的范围与主次，正文只保留会改变执行的关系。

| 控制对象 | 可读的描述方式 | 失控时修改 |
|---|---|---|
| 步幅与身体位置 | 脚踏到哪里接重，躯干随步走到哪里，另一脚如何收近 | 先修接重与通路；增大上身幅度不必同时迈更大步 |
| 膝部与高低 | 小幅屈伸承接，或明确下降后推地回起 | 区分承重缓冲与刻意低位重音，不把每拍都写成深蹲 |
| 胸廓与肩 | 前送/回收、侧移、转胸；一肩领动，另一侧如何响应 | 防止胸廓隔离变成整个人前后晃，或每次转胸都附带甩头 |
| 腰胯与躯干侧线 | 换重心形成侧线，侧送后回中，弧线经过哪些方位 | 区分骨盆侧移、转向、提落和绕环，不用“扭腰”囊括全部 |
| 手臂 | 肘从身侧打开，腕与指尖延展到身体外轮廓，再沿哪条弧线收回 | 大幅展臂与小幅胸肩可以并存；不要全程手脚都抢主动作 |
| 头、脸与视线 | 身体先转、脸延后回应，或短促转头到位后继续舞句 | 不把每个重音都改成甩头；保留已锁墨镜、发饰与人物性格 |

用角色自身的肩线、腰侧、头顶、腿线和地面作到位参照。小、中、大是相对本句的设计语言，必要时转成可见形状，不能只贴级别。只有需要精确匹配参考且证据足够时才指定角度/距离；数字是目标，不是模型必然执行的控制器。

“更大”优先放大本段要读的部位与完整路径；“太大”先收掉无作用的附带运动。两种反馈都不自动改变音乐、总时长或性感强度。全身同幅、同速、同相位会丢掉主次，但有意齐振或爆发仍按当前舞风保留。

## 路径本身也要好看

为每个重要舞句选择实际成立的轮廓关系，而非给所有舞句套同一姿势。

- **肩颈与胸肩**：选择沉肩长颈、肩部短促提落或收胸/展胸的具体相位；有意耸肩和收缩可以成为重音，随后有释放。把胸廓主动作与衣物下随动区分。
- **躯干与腰侧**：侧移、转胸和骨盆方向形成可读的侧弧或扭转；手臂与身体之间留出能读线条的空间。不要把肩、腰、胯全向同侧平移当作所有侧弧。
- **手臂与手腕**：手肘给弧线结构，手腕和指尖继续方向；腕的轻折服务当前手势。手掠过脸时留出读取窗口，再离开，不用无因手指抖动和持续遮脸证明媚态。
- **腿与支撑**：承重腿托住整体，另一腿的收近、点地、屈膝或延伸改变轮廓。交叉与低位可以好看，必须有当前支撑；转向用踏步/可执行枢转，脚固定却把身体拧走会破坏线条。
- **过渡**：检查打开之前、峰值之后的中间轮廓。只有终点漂亮而路径软塌、肘部乱飞或脚滑，仍需重编。长发、袖子和衣摆可加强弧线，也可能遮住来路和脸。

手放腰侧、另一手经过脸侧、肩胸略转的非对称关系可以成立；全身长线条、对称开合与短重音也可成立。妩媚、冷艳、俏皮和热辣分别由事件、速度和表情配合，不能统统改成同一种媚笑和身体波浪。

## 幅度、速度、用力与停留分开

内部编排可用“入口支撑 → 领动与路径 → 可读的轮廓峰值 → 减速/回收 → 下一句入口”。峰值是形状/方向最明确的相位，不要求每句停住或慢放。

| 想要的观感 | 动作组织 | 防止的误写 |
|---|---|---|
| 细腻魅惑 | 小幅肩胸/腰侧变化，一手形成框架，头脸作短回应，回收继续流动 | “小幅”不是不跳舞；不长时间摆姿等待特写 |
| 热辣重音 | 有准备的短促到位，接重/制动后继续连贯路径 | 有力不等于全身最大幅度，正常速度不等于乱甩 |
| 长线展开 | 从紧凑形状沿对角线或侧弧展开，给腕、指尖与腿线到位空间，再收束 | 不把大开大合压成岔腿，或全片均匀缓慢 |
| 二次元俏媚 | 头侧手势、展臂、侧摆与踏步形成清楚造型，角色表情接短回应 | 角色衣装不替代魅惑事件；原片光效不必移植 |

音乐驱动可以是人声、旋律、拨弦或鼓点。无源音轨时设计关系，不报实测BPM、精确拍点或原片速度结论。不同句法换动作质感，避免所有段落重复“胸—腹—胯wave”。

## 摄影与动作一起分配

先选本段读轮廓、支撑、细节表演还是空间移动，再定机位与景别。相机的起幅、主要路径、触发和落幅服务已编舞句；固定镜头同样可通过人物走位改变占幅。

| 当前观看对象 | 合适解法 | 衔接与返工 |
|---|---|---|
| 完整展臂、侧弧、腿线/步法 | 全身或能容纳整条轮廓的中全景，给展开方向留空间 | 在准备到回收之间持续读清主动作；脚被裁掉时邻镜补支撑，不能凭上身宣称已验步法 |
| 胸肩隔离与侧线 | 正面偏斜侧中景，保留脸、两肩、动作手与腰线 | 先比较投影；镜头和身体同向同速旋转可能抹掉变化，需要保留相对角度 |
| 头侧/肩侧手势与目光 | 脸肩中近景，手势长路径用更宽取景或沿路径轻跟 | 准备、变化、离开要可读；眼睛被墨镜遮住时改读头脸回应，不承诺微小眼神 |
| 行进与构图变化 | 跟移或人物向固定机位靠近/远离，各写自己的路线 | 主体占幅改变不直接证明推镜；背景视差与主体路线分开检查 |
| 主峰后细节强调 | 主形读清后切入/推进局部，再接原动作的回收或下一句 | 特写可独立审美，不能用它代替所有展开；切出不重新做一次原动作 |

实际移动镜头在关键中段也检查轮廓、遮脸和画幅边界，不只检查起止。切点可选展开完成、重音、头脸回应或回收，按音乐与观看意图取舍；允许有意在途切接，但另一镜继承同一相位。静态一镜、连续弧移或较多切镜均可成立，不设固定镜数和运镜配额。

当反馈同时是“动作不好看、镜头不好看”，先把可见身体事件、相位和线条确定，再比较能读它的机位；动作与摄影来回校准，共用一条时间线。若动作已经好看而仅被裁断，就只改覆盖与切点，保留编舞。

## 具体句法与反例

空泛句：“大幅性感扭胯，抬手，镜头丝滑环绕，眼神魅惑。”

原创修订片段：“成年舞者右脚侧踏接重，左脚收近点地；右胯侧送到位时左肩略回，让腰侧形成不对称曲线。右手留在腰侧，左臂从身前沿外侧打开到肩高，肘腕继续曲线；短促到位后胯回中，左手经头侧收回，脸随转胸回应镜头，接下一次侧踏。斜侧中全景包含脸、腰线和支撑；摄影机在这次展开期间站定，待手势回到头侧才按需要切近景。”

该句为原创设计，不是源片逐拍复述。已锁定一镜到底则改用同镜走位/构图交接；已锁静音则不用音乐落点；用户要更大展开则改变主弧线与峰值，不给所有部位同时加“剧烈”。

## 交付前与成片后的两次不同判断

文本阶段核对：可执行支撑、主次幅度、路径轮廓、速度拐点、到位与回收、镜头覆盖、时间和已锁约束。成片阶段对照对应区间的真实图像与音轨，确认这些决定是否执行、过渡是否好看、有无人体/衣装/切镜故障。文本检查通过不能代替后者；参考抽帧不能证明已学会整支舞或生成稳定。
