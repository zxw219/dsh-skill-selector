# 从动作到摄影：同事件学习后的选择方法

用于摄影分镜系统学习、没有学会自主选拍法、角色动作被切碎或技法堆砌的返工。先继承已定身体事件、角色、能力、时长与格式。普通创作只取当前缺口的方法，不读取全练习或要求全套设备。

## 先读谁、读哪一段、为何此时

需要身体美感时读头肩髋脚的领随、转向、展开和接重；需要交锋时读来刃、真实接触/滑离、对手负载与新出口；需要情绪时读发现对象、判断和决定后的行动；需要宏伟时读小人/结构/有效作用边界与传播。关键变化不可见，先决定补全身、局部、脸或范围哪种观看证据，再决定拍法。全身不是每场唯一选择，特写也不代替全部关系。

## 同一事件的变量对照

重要选择不确定时，内部锁同一事件比较一项关键变量；训练可做多案，普通成稿只交采用案。

| 变量 | 实际差异与选择依据 |
|---|---|
| 相机位置/视场 | 近处宽视场可读近刃/远目标深度与视差；远处窄视场可读紧凑重叠线，但刀尖/脚/落点净空要满足。本场选择不能由焦段数字独自推出。 |
| 支撑/相对速度 | 稳定侧跟读完整步位；手持观察者可在追刀逼近时侧避、滞后后追回、制动落稳；固定迎来读地标间的逼近变化。相机等速并不抹掉角色位移。 |
| 转向/位移 | 摇摄转交朝向，横移改变遮挡/视差，短弧打开叠影；被柱遮住的身体不能凭原位摇镜显出。相机路径不迫使角色等镜头。 |
| 推近/急变焦/希区柯克 | 推近改变相对位置与透视；急收视场捕捉关键细节；希区柯克改变相机与主体相对距离并反向变焦保持占幅，让有层次背景变化。使用它须有相应心理/空间收益。 |
| 清晰区/局部覆盖 | 转焦交注意、深焦同读关系、单层清晰集中表情；脸CU真实裁切与目光指向明确，画外脚/刃继续推进。切接手刃ECU后不重打接触。 |
| 画幅/层次 | 横幅可容横向通路，竖幅可通过纵深/跟移组织跨度；起中落幅保留当前必要人物/攻击端/目标/落点，不能把幅面不足改成身体瞬移。 |

## 翻腾与旋转的覆盖

相机需要读出的是角色相对地标的旋转轴、实际前进路线、兵器外侧路径、对手追落点及接重。翻腾段可侧面/斜侧全身，换侧段可高位交地理，接触细节可局部；选择服从这一招，不禁90度侧拍。相机滚转可以风格化使用，但不能作为身体已前翻/后翻的唯一证据。可用稳定地标/前后相位解决二者混淆。

镜内连续移动可以从全身收近再拓宽；切镜版本从已到相位接起，保留画外进程、刀剑约束与破损。真一镜的观察路没有切点，不能套J/L-cut或暗插ECU剪接。甩镜须明确是同机位镜内跟转，还是模糊峰处切到下一机位并落稳；两者都不能丢失武器与当前任务。

## 选择检验

去掉技法名再看：相机站哪里、触发是什么、发生哪种可见变化、落幅读到什么、如何接后续？没有收益便改实际变量；有作用的固定/慢镜/静音/单技能仍合法。动作本身单调应回动作层；已有动作未读清才修摄影。摄影取景/焦点推演通过不证明实际模型执行。

## 本轮原理与练习证据

原理核验：ASC [camera movement](https://theasc.com/article/shot-craft-camera-movement/)的手持用途；Adobe [dolly zoom](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)的相对位移/反向变焦。其余本场选择是原创导演推演。资料文章已读，嵌入视频未观看。
