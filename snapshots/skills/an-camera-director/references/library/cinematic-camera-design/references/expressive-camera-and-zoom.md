# 表现性摄影：把感受编成画面变化

用于艺术化、情绪化、电影级构图、复杂拍摄、特殊变焦的设计与返工。重要变化在选镜时使用本页，不等成稿平淡后再补术语。独立摄影任务继承现有事件；方案的审美目的可以是心理、图形、节律或尺度，不限新增剧情信息。来源与原创推演分开记录于[本轮研究](../../an-workflow/references/cinema-study-20261022.md)。

## 先决定观众经历什么

从本段选一个主要的感受变化，例如“以为能控制→发现没有退路”，确定观众贴近谁、何时知道、注意被什么牵住。再选可见的关系：人物与边框的余量、前后体量、遮挡开合、清晰层、亮暗面积、线条汇聚、动作方向。最后匹配相机与镜头。情绪不与某一种角度绑定；悲伤可用远处冷观，威胁可在稳定画面里逼近，英雄感也能发生在持续承压中。

关键镜在设计时辨认起幅、决定性中段、落幅的主次与轮廓。已有明确方案直接用；若只得到“低角度广角慢推”，用同一事件比较另一种观看立场，选择能形成不同感受且可拍清的版本。普通出稿只交采用案。

**先保主证据，再安排路径。** 重要镜先找决定理解/感受的实际变化，围绕它安排主次与移动；已建立的机制与地标不在每个落幅重讲。复合运动经过多个对象时，说明哪一项要辨清细节、哪一项只需轮廓/进路，不能把控制手、脸、全身、敌人反应和范围都当同一短拍的同等重点。近→远英雄弧绕可大胆保留，但关键变化须在真正可读的相位发生；不能一面宣称观察落后/失联，一面把决定结局的接触或环境变化放在失联里，再用后镜特写补造。固定全身框也逐关键变化核案沿/身体是否挡手脚；前后都入框不证明中段不遮挡。必要时重排观看交接或选择另一条相容路径，不默认削掉动作强度与规模。

## 构图的方法与实际变化

| 要组织的感受/关系 | 可采用的构图与调度 | 中段发生什么 | 失效与修法 |
|---|---|---|---|
| 威胁还未到，却已经挤占退路 | 人物偏边，留空给已建立的来向；近层遮掉部分出口 | 威胁进入留空，或出口被关上，人物可用空间缩小 | 不随意添怪物；负空间有方向/期待，空白不必永远被填满 |
| 人物失去控制 | 原有对称/水平秩序被位移、遮挡或倾斜打破 | 受力/认知转折改变人物与基准线关系 | 不能只把每镜都倾斜；恢复水平也可作为反控制的重音 |
| 巨物压过身体 | 近层人物/持物占明确尺度，作用体越过中远层地标 | 原可见天际/出口被主形吞没，小人物仍作有效应对 | 超广角靠近处参照；不用大全景小人同时索取微表情 |
| 两人争夺同一目标 | 人、目标与对手形成不等重心的三角/纵深斜线 | 一条攻击线切断三角，目标从一人可达变为另一人可达 | 不是摆三人合影；顶点对应真实距离和当前任务 |
| 亲密、侵入或无法躲闪 | 近视线位置与近距离裁切，边框压住退让方向 | 靠近/转身改变脸侧、空间余量与接受程度 | 广角近拍可产生侵入，长焦远观察可产生窥视；按当前关系选 |
| 观众比人物先知道 | 前景人物操作与后景危险分层，保留足够可读深度 | 人物继续原任务，危险在另一层取得优势 | 深焦/分区清晰不等于所有物体一样抢眼，明暗和运动分主次 |
| 观众跟人物一起发现 | 先留遮挡/失焦，随人物注意或机位变化才交证据 | 信息进入清晰区或遮挡打开，人物判断随之改变 | 焦点不能看穿柱子；隐藏不能漏掉结局必需的证据 |
| 具有绘画感的秩序与转折 | 色块、剪影、重复线条、负形与反射组织画面 | 同一母题被打破、夺走或变义，形成节律重音 | 保住关键轮廓，镜面需真实反射视线；不把所有画面做成居中海报 |

艺术化不要求每镜都有三层、构图反转或新信息。保持同一构图可以累积压力、对比与等待，但要能指出当下正在发展的关系。

## 焦段、距离、焦点各管什么

先选站在哪里，再选该位置容纳多少，最后选哪层清楚。景别与焦段分别决定：近距离广角CU可让近手/脸压向观众、远层仍有环境；远处长焦CU可隔着遮挡层叠观看。同机位光学变焦改变视场与放大率，不能打开实体遮挡或凭空压缩透视。景深还取决于距离、光圈、画幅与焦点，广角不自动深焦，长焦不自动只能特写。

转焦交接两个真实深度层；深焦允许观众同时比较；split diopter（分割式近摄附加镜）形成近远两个清晰区，中间过渡不保证连续清晰，要安排分界位置和人物路线，不冒称全空间深焦。跟焦维持移动主体清晰，不等于每次都转交注意。细节须有实际裁切，远处手势不得靠文字声明清楚。

## 特殊变焦的独立选用

| 手法 | 触发与画面执行 | 落幅读取及边界 |
|---|---|---|
| 急推变焦 crash/snap zoom in | 已有异常/判断触发，机位大致不变，视场迅速缩窄到具体手、眼或裂缝 | 给细节清楚的落点与接出；区别于快速推轨，不用抖动替代 |
| 急拉变焦 snap zoom out | 先读局部，突发范围变化使视场迅速打开 | 原局部缩小，同机位周边显露；不产生横移视差，也不突然看见被柱子挡住的背面 |
| 后退加长焦的 dolly zoom | 有背景层次，相机退远，反向加长焦段，主体占幅大致稳定 | 远层相对主体变大、压近；用于空间压迫或认知突变，主体移动时按相对距离同步，不能说锁焦不变 |
| 前进缩短焦的 dolly zoom | 相机接近且缩短焦段，维持主体占幅 | 背景相对缩小、空间张开；不能只写“希区柯克”或全画面缩放 |
| 缓变焦与画内调度 | 人物持续行动，光学视场按注意/疏离逐渐变化 | 描述主次与边缘如何被纳入/剔除；不把缓慢本身当高级 |
| 位移与变焦同向增强 | 接近同时缩窄视场，或退远同时开阔视场 | 占幅剧变，承认是强化逼近/抽离，不能称主体等大的dolly zoom；快战不额外拖慢世界时间 |

快速运动、变焦和转焦可以分相接力，没必要在一个很短的切片同时完成全套。若为锁定一镜到底，可以连续变焦；裸眼POV、定焦或固定视场的明确约束优先。前后状态解释不通时改路径/切接，不补瞬移。

## 复合与特殊运镜的选择库

| 拍法 | 起幅—中段—落幅 | 使用条件与反例 |
|---|---|---|
| 低位英雄弧绕并后拉 | 从控制手/半身近处起，绕到可读脸侧；中段由近层掠过形成视差；半径扩大并后退，展开人物、作用体与对手 | 适合召唤成形/扭转压力。人物继续移步导引/承压，控制手不无故释放；对手同期逼近、改线或拆解。无需站定或转满360° |
| 反向运动 counter-move | 人物沿一条路线，相机从另一侧横移/短弧，先重叠后分开 | 用相对视差放大错身/控制易手；轴线被可见交会重建，不乱跳左右 |
| 领先—被超越—回转接续 | 起于人物前方，留可通过的空侧；人物从旁超越，机位转随接剩余任务 | 体现爆发与观察落后；相机不穿身体，人物不等它归位 |
| 近地掠行—抬升揭示 | 从地面攻击端/支撑经既有通路掠进，随同次作用抬升展开范围 | 地标与路径成立；全景仍是正在发生的作用，不另开全员站立建立镜 |
| 越肩让位—转交对手 | 起于一人的投入，沿实际接触/来线侧开，读到另一人当前处理 | 适合主动权转移，不把每次反击做成独立正反打 |
| 环境遮挡擦开/穿门 | 近处实体擦过边缘后显露深层关系 | 不要求全遮、不自动藏剪；虚拟穿越说明净空与入口出口，不穿未打开实体 |
| 人体附着机位 | 相机相对胸前/兵器等固定，主体近似稳定，环境剧烈变化 | 适合主观受力/失控；不能同时宣称人物静止就证明高速，须读世界参照和受力 |
| 翻滚/滚转观察 | 人物失衡或视觉世界翻转时相机改变滚转，保留地标 | 相机转与身体转分别证明；不要每次出招随机滚画面 |
| 俯视平面到贴近人物 | 从可读路线关系下降/偏移，进入某人的承担与决定 | 运动时间、净空和新观察面成立；锁真实机位时不无因穿屋顶 |
| 焦点接力的弧移 | 横向开遮挡时把注意从近层操作交到远层结果 | 两个变量各有职责；关键操作读清再交接，不全程失焦 |

表中为可迁移的原创设计，不是每段必须出现的技法。英雄环绕近→远是对用户需求的应用，不宣称所有迈克尔·贝镜头都按此路线。复合路径的详细可达性见[路径](composite-camera-paths.md)。

## 编译与反证

将采用的距离/观察侧、主次、触发、中段、落幅和接出放进原画面/S/transition，避免另交解释表。去掉技法名后，读者仍须能画出关键关系；去掉摄影运动后，角色和在途作用仍在共享时间推进。转场见[切接](../../action-camera-direction/references/transition-direction.md)，动作同期见[压力重叠](../../combat-action-design/references/pressure-overlap-and-release.md)。不能用电影感术语、镜数或本页已读作为交付证据。
