# 复合运镜：从一次观看关系接向下一次

用于基础手法都会写、成稿仍等大侧跟，或连续镜头缺少高低/远近/对象变化。与[摄影执行](camera-execution.md)共用同一方案；只继承已存在的动作与作用，不为运镜增加攻击、瞬移或障碍。以下为原创摄影设计候选，未进行实拍或视频生成验证。

## 先选改变，再接路径

取当前最值得强调的变化：高度改变、逼近、负载移交、遮挡打开、关系转移或局部影响扩展。确定先读什么、读够后交给什么，再从上一落幅走到下一位置。可组合主位移、朝向/视场或焦点变化，但同时组合的每个变量都应有作用；保持观察和切镜同样是候选。

| 路径族 | 起幅—关键中段—落幅 | 触发、接出与失效边界 |
|---|---|---|
| 随降—侧开—抬接 | 从肩胸侧面跟已有下潜降高；侧移让来线从上沿经过；随起身或新目标抬到读取高度 | 触发是实际肩胸下降，不是只低头；低位读完即接现有反击/受压。地面无空间时改侧向覆盖，不穿地 |
| 攻击端—接收端—新威胁 | 从攻击端外侧伴随短推进；接触处短促制动；沿受力或另一条已成立来线移交注意 | 相机不占攻击体积，不重放命中；攻击快到不能覆盖全程可只取接收端或切同次余相位 |
| 局部—退升—范围 | 起于控制手/受压材料；退移打开同一作用连接；升高展开已知地标及人物后果 | 巨物按本场快战节奏果断退升，不因大自动慢移/固定；范围仍在同次相位，不再次成形 |
| 领先—让过—转随 | 从目标前方退行读入距；主体在可用侧通过；弧移/转向接其侧后与前方任务 | 相对速度实际改变占幅/距离；起幅无通道就不能从身体中穿过，未跟上可选择真实切镜 |
| 落后—追平—超前取位 | 跟原任务暂落后；追至侧面；提前到已知交会处，让人物进入新的关系构图 | 相机赶得上且净空成立；不能用下个S段直接复位到终点，也不让人物等相机 |
| 遮挡打开—深层交接 | 沿柱/门边横移或短弧移露出既有后景对象；需要时由近层转焦；落幅读新关系 | 转焦不能看穿遮挡，远近清晰顺序服从信息揭示；前景不是隐藏新距离的借口 |
| 地面—空域—人物回接 | 从人物/支撑升高并调整朝向读空域交会；下降或移向既有接收者，接已推进的身体相位 | 高度变化要有参照；回接时空域作用仍继续，未锁的一镜可在必要处切，锁一镜则走通全程 |
| 人物关系接力 | 在第一组关系结束前取得下一组可见面；沿实际介入/遮挡/交会转交；旧关系落在次层或画外 | 由谁改变谁的条件触发，不按姓名轮流；新关系没成立时不靠甩镜补造 |

同一族可以稳定、手持或风格化；质地按本片立场选，不给每段随机换设备。主体贴附、反射或狭处穿行只在实际条件需要时展开：贴附要明确固定在主体哪个位置、背景怎样变；反射要有可达反射视线；穿行要有镜头体积/虚拟相机允许的净空。不把设备名当成路径已成立。

## 召唤的近到远英雄弧绕

从正在导引/承压的控制端近处低位起，以可读脸侧和近处地标形成弧移视差；中段显露敌人同期进路；扩大半径并后退展开本体、作用体与敌人的关系，接同一次交会。持续控制手和作用机制不变，不令敌人等相机，不用满360°作为完成证明。详细选型与反向运动、附着视点、滚转、焦点接力见[表现性摄影](expressive-camera-and-zoom.md#复合与特殊运镜的选择库)。

## 两个同事件选择对照

**已定事件：甲俯身让过横扫，起身接乙侧面反扑，地面通路已建立。**

- 方案甲从肩侧中景随胸廓快速降高并向空侧移，让横扫擦过上沿；起身时不跟回原构图，而是向已有反扑来向短弧移，落幅同时容纳甲回护与乙攻击端。读取身体避线与新防线，代价是远端全场不在本镜解释。
- 方案乙保留斜侧较宽观察，甲从已有来线下方通过，乙反扑在纵深进入；必要时同次切近接触。更便于比较距离和支撑。若用户要贴身参与感，优先甲；锁固定或当前空间无法完成路径，可选乙。不是甲总比乙高级。

**已定事件：术者持续控制巨型弧面，对方截断局部，术者收控退出。**

- 局部—范围路径从变控手近处迅速退开，沿已存在的作用连接显露弧面受截处，再退升让地标与双方新落点进入。形成、受截与退出共享时间；相机不能为经过整条连接而拖慢攻击。
- 若截断先于路径完成，可从受截局部开始，在读清剩余部分后快速展开范围，控制手由同次邻镜或现有同框提供。牺牲完整源端跟随，保留决定性变化。用户锁一镜且两端不可同时走通，则重选同镜覆盖，不补造第二次截断。

## 固定、制动与切镜的统一边界

先区分当前观看任务：文戏、氛围、关系/表演与等待/揭示可主动用固定调度；能力展示、控制博弈和危险间隙按[能力观看](../../an-workflow/references/ability-led-combat-direction.md#控制端作用端与接收端)选稳定关系、画内通过或保持，给读取与出口。特殊能力快战仍按[摄影执行](camera-execution.md#战斗中的速度力量与摄影压力)主动选快速果断移动，巨物、命中与传播本身不自动构成固定理由。用户锁定拍法优先；不按运动比例或技法配额验收。

## 交给正文什么

只交所选路径及决定它的对象、触发、相对速度、关键中段和接出，放回原镜头/画面/S/transition。不是把整表串成一镜，不增固定镜数。核上一落幅能否进入本起幅、切近后谁仍在画外推进、关键变化是否有可读窗口；还要核本路径丢掉的证据是否由当前镜或同次邻镜承担。文字可达与真实生成执行分别记录。
