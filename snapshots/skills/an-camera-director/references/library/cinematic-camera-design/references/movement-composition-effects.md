# 通用镜头语言：观看效果、运镜与构图

适用于文戏、情绪、悬念、揭示、人物关系、追逐、写实动作、奇幻战斗、灾变/巨物、舞蹈表演、氛围和图形场面。先选当前观看任务，再选择机位、构图、相机运动、节奏与切点；不把奇幻快战的快速摄影推广为所有场景的统一速度。普通出稿只采用有关条目，已读的有效规则直接复用。

先区分当前观看任务：文戏、氛围、关系/表演与等待/揭示可主动用固定调度；能力展示、控制博弈和危险间隙按[能力观看](../../an-workflow/references/ability-led-combat-direction.md#控制端作用端与接收端)选稳定关系、画内通过或保持，给读取与出口。特殊能力快战仍按[摄影执行](camera-execution.md#战斗中的速度力量与摄影压力)主动选快速果断移动，巨物、命中与传播本身不自动构成固定理由。用户锁定拍法优先；不按运动比例或技法配额验收。

## 从观看目的到拍法

先问观众需要接近谁、何时知道什么、怎样感受距离/力量/关系和空间。先定人物调度、事件与可用通路，再比较保持观察、移动观察和切镜。移动可以改变注意、遮挡、透视、心理参与、空间体验或图形节律；固定可以让这些变化在稳定参照中发生。不要求每个镜头出现新信息，也不以镜数、移动比例或技法数量验收。

摄影选择写入实际画面：起幅关系 → 刺激/触发 → 人物与相机各自变化 → 关键中段 → 落幅读取与继续/停止/切出。普通稿不附内部方案菜单。

## 运镜、速度与观看效果

下表是场景设计候选，不是固定情绪查表。相同手法在不同调度、距离、光色和剪辑语境中可能有不同作用。本表只做文戏/情绪与动作/大场面两类的用途对照；手法的定义、变体、描述要求与误用以[拍摄手法的选择](shooting-grammar.md#普通运动的具体职责)为准，按观看需求索引落幅证据见[摄影执行](camera-execution.md#按画面需求选择相机行为)。

| 手法 | 改变的观看关系 | 文戏/情绪/悬念用途 | 动作/大场面用途与边界 |
|---|---|---|---|
| 推近 | 观察距离缩短、参与和占幅增加 | 接近认识变化或难以回避的反应；细微慢推须有持续表演 | 快推进入破防/撞击关系；不能先慢推数秒才开始普通出招 |
| 退移/拉远 | 关系展开、人物与环境比例改变 | 疏离、孤立、离开共同空间或揭示原来画外对象 | 从局部受力展开范围破坏；追拍退速与来袭速度共同决定逼近 |
| 横移/弧移 | 视差、遮挡、可见面和人物投影改变 | 越过柱边显露秘密；从交接转到接收者反应；拉开两人之间空处 | 打开重叠的交锋线，读偏转/反扑；绕拍不迫使人物等待 |
| 跟随/并行/领先 | 与移动主体的观察关系持续 | 陪伴人物、共同发现、读取走动表演；等速跟随可成立 | 追压、撤退、步态、地标通过；身体速度不靠背景滑动代替 |
| 原地摇/俯仰 | 朝向和取景对象改变，机位基本不换 | 从听者交给声源，沿身形/建筑逐步揭示 | 追踪飞出/落击、读取高度；摇摄不能绕过实体遮挡 |
| 甩镜/快摇 | 注意突然转交、运动急变 | 突然转头、发现、喜剧呼应或有意转场 | 交给侧面反扑，落幅接住来向；模糊只占过渡，不隐藏接触 |
| 升起/下降/俯冲 | 高度、遮挡、整体与局部关系改变 | 从个人处境揭示人群/环境，或从整体进入细节 | 展开区域/阵法、跟落线进入战场；路径必须有可用空间 |
| 急变焦 | 视场突然改变、光学强调 | 观察者突然抓住细节、反应或喜剧重音 | 可以强调远处弱点；不能冒充相机逼近或绕过遮挡 |
| Dolly zoom | 相机位移与反向变焦，主体近似等大而背景比例变化 | 认知崩塌、意识到危险、空间眩晕，需可读背景层 | 特定威压/异变可以选用；不将每次受击都做成该效果 |
| 转焦 | 清晰深度与注意归属改变 | 在人物、手中物、后方目击者之间转交信息 | 读取目标与在途攻击；焦点变化不代替机位移动或动作 |
| 快速运动后制动 | 动与止的对比、注意落点和重量变化 | 突然发现后停住观察，或将注意留给反应 | 撞墙、重挡、砸地处短促硬停，立即接真实受力/传播 |
| 固定观察 | 地标、画面边界和关系基准保持 | 观察关系破裂、入口等待、对称秩序被打破、关键表演选择 | 巨物侵入、关键接触和范围破坏；画内动作与效果继续发生 |

相机稳定与相机固定分别判断：稳定跟拍仍在位移；本文固定镜头指机位与取景朝向保持。推拉、变焦、摇摄、转焦和时间处理分别改变不同变量，不能混名。相机速度、主体速度和剪辑速度也分开，不能把所有情绪做慢推、所有动作做乱甩。

## 构图、机位与视场

| 选择 | 实际画面关系与效果 | 使用条件 |
|---|---|---|
| 三分/非对称平衡 | 主体与空处、环境或另一人形成不同重量 | 指明谁在哪边、另一侧承担什么；不为了网格破坏有效轴线 |
| 居中/对称 | 注意稳定、正面凝视、制度/仪式秩序，也可形成不安 | 指明主轴与被打破时刻；快剪辑可让关键目标容易被找到 |
| 留白/行进空间 | 预期画外对象、去向、缺席或危险侵入 | 空处随后怎样改变；挤占出口可形成压力，不能裁掉必要动作 |
| 前中后景分层 | 遮挡、距离、速度参照、人物关系与环境深度 | 主次清楚，不把最亮前景粒子挡在关键脸/接触上 |
| 斜向/纵深动作线 | 对冲、穿越、力量方向和高低关系 | 动作线可以斜向，地平线不必倾斜；镜头中段仍看清作用 |
| 框中框/边界 | 隔离、窥视、限制或从局部显露新关系 | 已有门窗/柱/身体形成边界，何时跨越或打开有依据 |
| 低位近距宽视场 | 支撑、近物侵入和巨大上方结构共处，亦可亲近低矮主体 | 人物与建筑提供尺度，不只剩天空和模糊特效 |
| 高位/俯视 | 路线、区域、围困或疏离观察 | 让观众读真实覆盖/出口；不把高机位机械等同角色软弱 |
| 较远机位窄视场 | 背景层叠、隔障观察、关系压近或孤立 | 透视由相对距离决定，焦段只是匹配视场，不靠镜头数字制造巨物 |
| 接触近景 | 局部变化、材料承力、手部/表情细节 | 邻镜承接裁掉的进入/支撑与结果，同一次作用不重演 |

景别是主体占幅，广角是视场；观察位置决定透视与遮挡。构图检查起幅、决定性中段、落幅，人物走位和相机运动后重新判断注意、轮廓、空处、轴线、焦点和边界。为本场实际画幅重排，不把横屏裁切当竖屏设计。

## 固定镜头的特殊用途及退出

导演可以根据明确观看收益主动选择，不需要用户逐镜点名。以下是特殊观看任务，适用于不同题材；不是每个镜头固定，也不限于战斗：

- **尺度/压迫**：机位锁定，巨物、车辆、人物或空间阴影进入已有画面，占据原来的空处；参照物保持，让逼近可比较。固定低位也可承接巨型压顶和坠击。
- **接触/传播**：固定局部读压缩、折偏、裂开；固定范围读裂纹、水浪、火焰、群体行动或结构倾覆。先建立落点与人物位置，保持画内持续过程，结束后接后果与下一任务。
- **关系/表演**：同框观察交接后的犹豫、空椅、对称被一人离开打破，或关键认识与选择；表演刺激和对象关系持续，不为停留摆姿。
- **等待/揭示/图形重音**：稳定构图让门洞/画外空处被事件侵入，或以秩序变化承担揭示。风格化静态影像按已选美学使用，不把某位导演偏好推广成通用禁令。

每个被采用的固定镜头说明固定看什么、事件怎样进入/改变该关系、何时看够、下一镜或镜内任务接什么。普通追击与交锋不退成无任务的固定平列；文戏也不能靠无作用停等冒充高级。没有收益的移动同样返工。用户明确全片禁固定、锁定固定/一镜到底等条件仍优先；“少固定、特殊场景可用”不解释为全片禁止。

## 编译与检查

1. 先按当前题材选择观看、信息、关系、行动或感官体验。文戏关注刺激/接收/反应；悬念分清观众与角色知识；舞蹈读取轮廓/节律/表情；动作读取来向/接触/承力；大场面读取尺度/侵入/传播；纯氛围可以只承担空间/光色/图形体验。
2. 把采用的相机起幅、路径或保持、触发/相对速度与落幅写进本镜；动作/环境各自继续，镜头不制造等待，不改人物世界位置。
3. 保持用户格式。MOKE中镜头/画面/S承担当前事件与观看，fx-env：、sound：、transition：接同次作用；固定段不偷插特写，真实切镜才新建镜头。
4. 交付前查“实际获得的观看效果—具体画面变化—与相邻镜的承接”。发现无用默认慢推、随机甩镜、无目的固定或不成立的投影就修受影响链。不能把是否运动当单一验收项，保留动作强度、画质、动态物理与必要表演。

文戏与悬念的完整原创演练见[关系变化10秒](../assets/cases/camera-relationship-10s.txt)、[遮挡揭示10秒](../assets/cases/camera-suspense-10s.txt)；动作与范围破坏见[奇幻快战30秒](../../an-workflow/assets/cases/fantasy-fast-combat-30s.txt)。它们用于校准用途和编译，不成为默认人物、时长、招数或镜数。

## 学习依据与边界

本轮查阅教学资料、网页说明和访谈文字，未观看嵌入影片或完成新成片生成。上述表格和例稿为跨题材应用推导，手法与情绪的对应不是必然规律。

- [ASC：Tools for Camera Movement](https://theasc.com/article/shot-craft-camera-movement/)：以场景需求选择运动；稳定移动、细微推进、Dolly zoom与不同观察工具有各自作用。
- [Ken Seng谈Terminator: Dark Fate](https://theasc.com/article/problem-solving-on-terminator-dark-fate/)：随动作甩动并在撞击处硬停，以强调惯性和超人级重量。
- [John Seale：Framing Mad Max: Fury Road](https://theasc.com/video/john-seale-asc-acs-framing-mad-max-fury-road/)：网页说明居中构图服务快速剪辑；未声称看完访谈视频。
- [ASC：Understanding Lens Distortion](https://theasc.com/article/understanding-lens-distortion/)：透视与前后比例取决于观察距离关系，不能仅由焦段推断。
- [Nikon：Composition Guidelines](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/5-easy-composition-guidelines)：主体位置、行进留空与引导线，规则是起点而非保证美感。
- [Nicolas Winding Refn谈The Neon Demon](https://theasc.com/article/moving-pictures-the-neon-demon/)：静态影像与特定退拉服务所选观察美学；这是该导演/作品的选择。
- [Boris Kaufman：Filming 12 Angry Men](https://theasc.com/article/filming-12-angry-men/)：用单一场地的限制与视觉关系组织人物心理和压迫，不以题材预设替代场景设计。
