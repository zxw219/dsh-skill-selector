# 覆盖、巨物与冲击写法

这些机位是选择，不是必拍镜头表。先选证据，再按画幅、媒介、场地与指定拍法调整。

## 按任务选角度

| 读取对象 | 一种有效观察位置 | 接续与风险 |
|---|---|---|
| 起跑发力 | 低位斜侧中全景，保留接重脚与目标方向 | 蹬离切接同一次推进，不重新起跑 |
| 高速逼近 | 侧向跟移，保留地标掠过与目标距离 | 镜头只跟头会丢掉身体移动证据 |
| 闪避姿态 | 斜侧全身看攻击体积、身体离线和落点 | 不能仅侧肩但身体仍在横扫内 |
| 转招力量 | 三分之四角度读支撑、躯干与武器关系 | 不要求每个细节永远同框 |
| 格挡负载 | 双人斜侧中景或接触局部 | 接后退、兵器滑脱与追压，不凭空倒飞 |
| 巨剑压顶 | 落点外低位仰拍，人物、檐口与剑体分层 | 不让近物透视冒充真实巨大尺寸 |
| 场地被改写 | 广景/高位观察断路、残骸和新路线 | 人物继续行动，场景不因切镜复原 |

## 三种覆盖选择

**多机位连续动作**：第一镜斜侧看角色跨过柱列并进入攻击距离，在出刃在途切出；第二镜从同一行动轴可解释的一侧接刀剑相触，守方接重后退；第三镜沿受力方向看进攻者追步和守方换线。三镜是这次例子的选择，不是所有战斗固定镜数。

**固定镜头**：起幅同时容纳入口、接触区和离开方向；跑者跨过前景柱影快速逼近，另一方提前让线或拦截；接触与退步留在取景内。相机不动，角色仍有清楚的距离与支撑变化；不得为了展示自动加推镜。

**一镜到底**：从斜侧读跑动，沿已知台缘移动保持交锋关系；巨物进入时调整俯仰并退到能同时看到人物与参照的位置，随后跟随新通路上的行动。若场地不给相机退路，应改观察起点或调度，不在墙里穿过去后仍声称实拍可达。

## 运动证据与魅力取景

先指出本段哪一项容易读不清：进入距离、支撑发力、接触承力还是受力后追入。把取景交给缺失证据，已清楚的部分不重复覆盖。等速柔滑跟拍可以使用，但画内还须有距离骤缩、地标越过或足地变化；相机移动不能是唯一“快”的东西。

腿部细节或腰上近镜能展示成年角色的裸腿、丝袜、腰线与衣料；赤足/穿靴按实际形象取景，不无因换装。足踝近景可读接重、前脚掌蹬离、支撑调整和脚部攻击接触，保留地面或目标参照；若它同时承担完整重踢验收，裁掉承重脚或髋腿关系就缺证据。可在前镜读蹬伸与髋腿送出，在接触相位切近景，再承接受力接重；三项也可同镜完成，不固定三镜。镜头照顾展示不等于让对手等候，身体轮廓来自真正让线、转髋或制动；明确独立魅力镜头仍保留其窗口。

近镜不把人物头部和攻击端压在同一投影下遮住命中；按实际空间选择斜侧角，留来力及反应方向。命中后跟着受力者与追入者交接注意，不持续停在已伸直的腿或拳上。后续是明确定格、持续压制或有意慢镜时，则读取其力量关系，不自动取消。

离体技能离开源点后，相机可沿传播读拦截与结果，同时通过同框或连续切点交付施术者回收；持续施法仍按控制姿态观察。大招的正常画面须出现本次所需的目标/结构改变，光弧漂亮而柱体和目标不变，不能靠镜头标签判定已破防。

成人魅力取景不限于腿脚。可用斜侧上身近景同读眼神、肩颈与胸肩轮廓；正面后退跟拍让推进、胸肩与裙料随动和腿线共时可见；从关系局部逐渐退开，揭示腰胯、腿线、衣装与武器。各选本次观看重点和起止画幅，不能只写“性感特写”。独立审美近景允许保留，在战斗窗口内交代对方行动，读清后交还关系。观察来源与迁移边界见[用户视频研究](../../an-workflow/references/charm-reference-study-20261008.md)；原片有切镜，未提供独立足部特写，不将它当作踢击/赤足证据。

## 追逐与封路覆盖

先按当前事件选择缺失的覆盖，具体拍法的A/B研究保存在项目目录，未试片不认定哪种稳定更好：

| 本段已有事件 | 覆盖所缺的关系 | 不能偷偷改变什么 |
|---|---|---|
| 冲近、越过地标、退出 | 入距/通过/退出中当前缺的证据；等大跟移可由地标和视差读速度 | 同一速度、路线与行动进度，尾迹不替代接近 |
| 追高、让斩、反斩 | 距离闭合、攻击在途进入目标空间、交会与双方出口 | 不切成并排飞，不自动贴近或重挥一次 |
| 已设攻击封路，人物走剩余出口 | 通路由可用到收窄，人物利用未关闭的空隙 | 不因换角度将人物放到封锁之外，不新增封路能力 |
| 巨物落斩、让线、环境结果 | 局部侵占与出口、同一次落点、范围中的人物状态 | 不加险伤、第二次释放或新逃生能力 |

这些是覆盖任务，不是固定机位、镜数或实验配额；地面持械、狭窄通路或不同媒介要重选锚点。固定机位可在同框交付入距与让线；一镜到底不为套覆盖暗插切镜；无音乐/静音也不靠声音补证据。实际输出先静音正常速度判断，再按允许声源检查接续，仅有联系表或预演时保持节奏与稳定性待验证。

## 巨剑的尺度链

前提：场景有已建立的人物、山门/楼层等参照，巨剑为设定内技能，逃生路线和结果已有编排。

可选覆盖：先让巨剑与门楼的比例可读；随后低位仰拍，剑尖越过屋檐高度、剑身向上出框，近处人物向已知缺口移动。切到斜侧关系镜读拦截或躲避，再以地面新裂口、断桥与被改变的路线承接后果。若用户要求无蓄力或一镜到底，省去不必要形成展示，连续建立相同证据。

尺度检查：局部出框之前或同框中是否已有大小依据？不同镜头是否仍是同一大小和路径？相机贴着剑体飞时是否失去目标距离？人物很小的远景是否又要求读毛孔？

## 冲击帧句法

> 两刃在肩前相触，守方腕甲随负载压缩；接触处出现极短的高反差轮廓重音，方向沿来刃与抵抗关系展开，随即恢复连续画面。守方后脚接重退半步，剑身沿交点滑开，进攻者顺势追入。

“退半步”是此例结果，不是格挡统一距离。写实CG保留材质与负载；二维可用线条、色块和设计性拖形，但冲击前后身份、握持与位置不变。非接触场域破界也可有冲击强调，须先有生效机制，不硬加身体碰撞。

## 快速故障定位

- 动作写全却没力量：检查镜头是否只读脸、不见发力或目标反作用。
- 镜头飞得快但人物像走路：先检查身体运动；不再加环绕掩盖。
- 位置翻转：核对新机位所在侧和地标，不强制删除所有跨轴设计。
- 特写接全景像重打一次：核对在途、接触、回收的时间顺序。
- 满屏白光：保留关键轮廓和接触窗口，整理局部层次，不自动缩小整个技能。
- 大场面像空镜插播：看人物是否利用/应对破坏后的新处境。

自查边界：用户要求慢镜、静止或重复回放时照其意图处理，不把快战偏好当所有作品的默认规则。文字取景合理与实际生成成功是不同验收。

## 决定性细节与利落切点

施法源端、攻击脚/兵器接触等局部覆盖按[细节、切接与力量](detail-coverage-clean-cuts.md)判断实际可见性。前后镜接同一次运动进度、目标和结果，局部不要求全身同框。对照[踢击6秒](../../an-workflow/assets/cases/kick-detail-impact-6s.txt)与[施法8秒](../../an-workflow/assets/cases/spell-detail-material-8s.txt)选择本次职责，不照抄镜数、角色或能力。
