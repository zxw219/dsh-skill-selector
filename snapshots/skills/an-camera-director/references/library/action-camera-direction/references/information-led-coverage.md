# 信息、反应与同次事件的镜头覆盖

用于危险预期、揭示、施法与识破、控制负载、力量比较及“动作写了但分镜不好看”的返工。先继承当前事件与能力，再组织观看顺序。不同镜头可以交付新事实，也可以维持等待、比较压力或承受表演；不要求每镜反转、不每招三镜。

## 切镜前决定此刻要知道什么

分开已知危险、下一次具体袭击与尚隐藏的来源。人物先察觉可以让观众等待画外对象，但人物察觉须有已设感官、可见/可听线索或能力依据；观众先看见危险不自动让角色也知道。选择同知、观众先知或角色先察觉，再选当前可读的脸、手、作用体、接收端或关系范围。

| 可选组织 | 相邻画面应交付的关系 | 切接要继承 |
|---|---|---|
| 危险预期 | 线索/人物注意改变 → 特定来袭揭示 → 当前应对 | 视线对应画外方向，已知威胁不重新当首次揭示 |
| 观众先知 | 盲侧危险形成 → 人物仍处理旧任务 → 逼近/发现/介入 | 谁还不知道、危险到达距离与剩余窗口 |
| 施法与识破 | 决定性手诀/器具变化 → 对手识别并开始应对 → 已发展到的法术整体 | 形成继续、控制资源、对手位置及来向 |
| 力量与负载 | 法术受压/目标被束 → 施者维持吃力 → 目标仍推进/挣脱 → 新决定 | 压力没有清零、既有破口和仍有效作用 |
| 延迟结果 | 真实作用进入 → 遮挡/余波 → 局部存活或失效证据 → 状态揭示 | 不能用白闪跳造命中/死亡，结果服从用户结局 |
| 发现并利用 | 作用暴露结构/窗口 → 人物识别 → 改控/改路 → 结果验证 | 弱点或机会来自当前证据，不凭空全知 |
| 尺度揭示 | 局部异常 → 地标受影响 → 巨型全形/危险部位 → 人物处境 | 同一空间与源点，范围显露后仍有定位 |
| 见证转参与 | 一人创造条件 → 另一人看见并变任务 → 同场接续 → 共同结果 | 前景运行术法、双方控制职责和作用归属 |

这些关系可以由多镜，也可以由单镜调度、遮挡打开或转焦完成。用户锁定固定/一镜到底时用画内变化达成，不暗加切镜；纯表演、展示或氛围不强造危险。

## 特写不是让全场等候

切脸时施法者仍维持/调整，目标继续抵抗；切对手时攻击继续形成/飞行；切手时本体沿既有路线或承担既有负载。返回整体承接当前相位，不重新从抬手、蓄力或起跑开始。写清必要的持续任务与此镜中有意义的变化，不重复逐项罗列全场。

关键脸/手镜要有真实占幅和清楚轮廓，袖口、亮光、粒子不遮掉需要读的关节/视线。脸上选择与观察对象相容的具体变化，如瞳线收向上方、呼吸短收同时肩部让线；不能只写“紧张特写”却无刺激或后续行动。反应镜不是只能拍静止人物，持续负载的克制保持也有作用。

## 干净、美感与切点

每镜确立主要形体关系和视觉中心，留出能接向下一对象的视线/运动空处；高亮层和前景框景支持而不抢走证据。范围景组织人物、术法、目标和地标的比例，竖幅重排高度/斜向/纵深。短镜读清局部变化即可交接，形成/负载/传播所需镜留足作用；不按相同秒数、景别顺序或运镜配额分镜。

切点可以接视线、判断、控制变化、力量关系、揭示或动作相位；并非只沿剑锋/碎片/裂纹切。运镜带来遮挡打开、参与距离或关系投影变化才采用，不让一段短特写同时绕拍、推进、变焦和甩摇。相邻镜一起核对方向、焦点、动作/法术阶段、负载与信息，保持当前模板。

源例：完整参考约112.75–140.75秒的施法发展—包覆—施者维持—目标破束，以及约193.333–200.875秒的剑列框住见证者—参与—整体—发动/接收。它们是采样帧可见关系，不是精确硬切清单，未知焦段和连续运镜不冒称实测；见[学习依据](../../an-workflow/references/latest-combat-study-20261010.md)。
