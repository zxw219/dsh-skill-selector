# 分镜转场：六类连接与真实切点

依据用户提供的《AI分镜转场Skill_独立完整版》转译。主工作流沿原镜头/S/fx-env/sound/transition使用；独立素材桥接或剪辑方案才展开上传职责、补图、生成片段及剪辑步骤。来源的即梦＋剪映、16:9、真实摄影、六类教程数量和操作默认不覆盖当前项目，不自动把整片拆成独立生成。

## 先确定是在接什么

同场动作切接继承身份、位置、朝向、攻击相位、控制、画外发展与损伤；跨场连接可采用图形/色彩/声音等关联，有意跳时空须明确，不假称同一现场。镜内摇摄、转焦、变焦是摄影变化，只有真实剪辑才新建镜头及镜尾transition。

切点交接具体的注意和进程：前镜读到了什么，在哪个可见条件切出，后镜第一幅接到哪个已发展的状态，何时再次清晰。提示词设计可给原片长内的目标时码；已有成片要从实际可用帧选切点，不能将文字时间说成已经发生。

## 交接前后两幅实际画面

选好关系后，明确前镜最后可读的对象、位置/占幅和动势，后镜第一个可读对象、身份锚与当前动作相位。注意可顺接，也可有意跳向另一处；决定依据是本段理解、情绪或图形节奏，而非每次都贴到同一像素。远近、角度或速度的变化要有观看收益，避免同样裁切的轻微换角只重复信息。

“在动作中切”还须给切出相位、接入的剩余部分与观看重点；信息已读清可留反应或结果，未读够不以快切吞掉。保持一镜到底时，将上述交接转为机位/朝向/构图/焦点的连续发展，不新增切点、全遮或甩镜拼接来代替路径。具体镜内执行见[连续长镜头](../../cinematic-camera-design/references/camera-execution.md#连续长镜头的观看发展)。

## 六类按关系选用

| 类型 | 前镜切出依据与后镜接入 | 重点校核 |
|---|---|---|
| 动作匹配 | 从当前出招/转身/落地相位切出，后镜承接其剩余部分；不同主体可接相似轨迹与注意位置 | 关节路线、支撑、控制手、动势与阶段前进；不重复起手/接重/命中 |
| 图形匹配 | 明确承接轮廓、位置、占幅、视角；构图和颜色匹配是相关子路线 | 圆与椭圆、透视与裁边差异；色彩仅呼应时不冒称轮廓无缝，允许干净硬切，不强制形变 |
| 视线衔接 | 先读人物看向何处，再交所见、对视或主观镜头 | 目标相对高度/方向、人物知识与轴线；后一镜的银幕左右由机位决定，不机械复制眼神方向 |
| 遮挡（含黑场） | 已建立的不透明前景进入并实际覆盖切点，后镜从相容遮挡中退出；后期黑场标明后期 | 覆盖完整、进入退出方向、材质光照、切后状态；透明尾迹/毛发缝隙不默认全遮，无暗源不编门洞 |
| 甩镜 | 相机沿同一世界/画面定义甩出与甩入，在运动方向与速度相容处剪接，后镜减速落稳 | 相机右摇通常景物向左掠过；主体移动不等于甩镜；落幅可读，模糊不掩盖身份形变 |
| 声音衔接 | J-cut让后一声源先进入前画面；L-cut让前声源在切后继续；相似声音以音色/节奏关联 | 声源归属、允许声轨、响度与尾音；对白不重读，试听才能验证音色，无声项目不用 |

同场交锋可用动作匹配与声尾让身体连续，用视线交接建立判断与敌方行动，用图形呼应交付尺度；需要突发方向时甩接。允许组合时说明各负责哪个环节，不每镜加遮挡、不把所有切点放最糊处、不统一叠化。冲击画的风格进出不是空间重置，退出接同次受力及损伤。

## 切镜手法先选功能，再写实际接口

| 需要的连接 | 可选办法 | 两幅画面须成立什么 |
|---|---|---|
| 不打断持续动作 | 动作中切、局部插入后接回 | 切出在当前相位，切入是剩余相位；插镜时间内画外追压/在途继续 |
| 从原因转向承受/判断 | 因果切、反应切、视线切 | 先后认知明确；反应发生于真实任务中，不为脸部镜头冻结对手 |
| 强调同次尺度/心理骤变 | 轴向近切/远切、冲击硬切 | 身份与方向锚连续，尺度差承担强调；不机械规定转角或重放碰撞 |
| 两条共同时间线交会 | 交叉剪辑 | 每条线都有进程和交会依据；另一方不在每次返回时重新起手 |
| 跨时间/场景关联意义 | 图形/动作/声桥、对比切、省略剪辑 | 区分相似性与时空连续，明确跳跃；实战不省掉决定结果的必要连接 |
| 连续方向的突然转交 | 甩接、遮挡擦接 | 切前后方向/速度/入口/落稳相容；普通硬切足够时不必叠加效果 |

J/L-cut的声源分别先于/晚于画面切换，无对白也可用真实环境与动作声；同一连续雨底不自动算设计了J-cut。不同景别/角度只是覆盖选择，切镜须说明本次观看收益。实战不以华丽转场隐藏重置站位、等待或持续控制被解除；一镜到底将接口变成镜内注意交接。来源校准见[本轮研究](../../an-workflow/references/cinema-study-20261022.md)。

## 主工作流的成稿写法

写入原transition，如“在刀锋已压偏、守方开始侧移时切出；下一镜从其侧面接正在发生的脱开与反切，刀面仍带受压缺口，前镜晶裂尾音延续”。正文动作先成立，transition不补造原S里没有的换位。无需再交转场方案、素材表或重复全片。

连续速度来自前后镜同一动势，不靠缩镜长；延迟读到对手可形成惊险，但关键应对必须交付。镜头之间的局部/范围、受压/反扑、源端/接收端都有因果关系，不用“沿动作切”概括全部。

## 独立片段、补图与后期才走制作路线

分开角色外观参考、构图参考、视频首帧、视频尾帧。动作桥接以A实际可用帧校准B入口；A尾帧进入桥接时作首帧，B入口作尾帧仅在工具确实支持时采用。多图上传不认证时序控制，不能给清晰首图却要求第一帧已完全遮挡/模糊。

叠放比较位置、占幅与关节轨迹可辅助接点，缩放/移位不能修错手或反向动作；调速不能挽救不同作用阶段。甩入需要实际模糊入口或明确后期模拟，倒放不用于有奔跑、水流、烟尘等不可逆过程。已有合格素材只补缺项，声音剪辑无需重生成。

平台能力未知保持中立；方法不承诺精确首尾帧、成片长度或一遍成功。重复制作失败要依据新结果定向修正或说明具体限制，保留用户坚持的核心目标，不自动提交生成或付费。

## 复核与来源

核前镜出口、后镜入口、动势/光照/遮挡、阶段推进与同一时轴；画外压力和已破坏结构不复原。人工文字走查、静态素材对齐、动态观看/试听与实际剪辑分别报告。完整来源和本轮采用边界见[学习记录](../../an-workflow/references/combat-transition-study-20261012.md)。
