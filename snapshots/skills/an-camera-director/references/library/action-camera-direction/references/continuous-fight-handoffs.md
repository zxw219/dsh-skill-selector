# 连续多人交锋：镜内交接注意

用于四人连续打斗、一对多、固定机位群战，或“人多必出错／必须多切镜”的返工。只设计已成立事件的观看；人数、剪辑次数和模型名称不能单独预测稳定性。完整导演设计与动作层共同校准，独立摄影不新增招式、队伍或位移能力。

## 接力的依据是交会，不是人物名单

连续镜头可以贴近一组接触，再借真实进入者、受力去向、离开的兵器或显露的通路交给另一组关系。下一读取对象在转镜前已有可推得位置和相位，旧对象在转走后继续任务。四人按姓名依次展示一招，镜头再回中心，不构成这种接力。

| 时刻 | 动作事实交给摄影的内容 | 观看决定 |
|---|---|---|
| 接入之前 | 下一人已经进入哪条通路，正在准备、追压或恢复什么 | 留轮廓、在途端、地标或可推得的邻层关系；不强制一直拍全员 |
| 共享交会 | 哪次接触、让线、过身或追及把两组行动连起来 | 交会附近转注意，原攻击来向与新目标仍可辨；不是随机甩向另一张脸 |
| 转接过程 | 新旧人物相对同一地标怎样移动，谁被遮挡 | 选择跟移、摇转、退开、升降或转焦的真实路径；人物与相机分别推进 |
| 接入之后 | 新关系已经到哪个相位；旧关系怎样继续 | 落幅读当前接触/下降/追压，不能重新起手；不因为失去焦点就让旧角色停止 |
| 再次显露 | 遮挡期间的位移、朝向、武器与限制 | 用未被遮掉的地标/轮廓接回；揭开后的位置须能从前态推出 |

这是一组可用判断，不是必须依次出现的五镜或固定秒数。固定镜头可通过人物进深、过身与高低改变注意；一镜到底可快速运动，也可有作用地保持。

## 让多线交锋有可辨的相位和形体

### 把关系交接落实成相机运动

默认从共同事件选择一次有观看收益的路径，不围绕人物名单匀速转圈。先给下一关系留下进入证据，再写相机由哪次交会触发、走哪条净空路线、相对速度如何改变、何处落稳读作用，以及原关系如何留在次层或接入下一镜。完整导演任务与动作层共同推演，独立摄影只使用已成立事实。

| 已成立的交会 | 可采用的运动和观看变化 | 落幅与同期承接 |
|---|---|---|
| 近侧承压使后方队友获得进线 | 先贴近当前受力，来线被带离时沿外侧横移并退开，显露早已前进的队友；近者移出主位、远者增大 | 读到队友实际利用，不切到他重新起跑；原承压者继续卸力/续攻 |
| 一向防守后另一向迅速到达 | 先让另一攻击端或来者在边缘/后层可定位，随第一向受力短移后摇向第二交会并及时落稳 | 读新接触时仍知道第一名敌人的朝向与追入，不把整段模糊当速度 |
| 抢位/过身令主次互换 | 在角色实际经过时降低观察高度或沿外围短弧移动，使近身路线与后层反制暂时同框，再随新主攻加速 | 旧角色从新位置继续；相机不穿人体/武器、不凭绕拍造角色绕后 |
| 近身变成多线围合/破围 | 随已经展开的路线后撤或升高，让威胁方向与真实缺口显露，再朝下一交会收近 | 退开期间仍有作用发展，不能全员停等范围镜拍齐 |

以上是可选结构，不是每场运镜菜单。变化可发生在同一镜里，也可在允许切镜时由前后镜共享事件完成；固定机位采用画内入距、轮廓、高低、清晰层与目标接力，不强加相机移动。近远变化不能切断必要接触，保持足够景深让关键次层有可辨来源，不能把“背景继续”写成看不见任何作用的免责句。

连续段对比起幅、中段与落幅：观看是否从一组实际压力交给另一组、主体占幅/前后层/观察关系是否因此改变、每次落稳是否正好读到新的作用；仅“快速跟拍—环绕—升高”而全员等大居中、分散演招的稿回修。局部的力来自可见接触和受力，整体的速度来自密集交会与空间参照，两者不能互相替代。

同一时刻可以一人接触承压、一人低位恢复、一人追入、一人转向新来线；下一相位互相影响。相位错开由距离、支撑、争夺和阻隔产生，不让非主读者等主角完成整套动作。相位不同也不等于已经协作，协作仍须有实际条件改变。

原身份中的体型、服装主块、面部轮廓和持物归属是转接后的识别依据。用它们安排重叠和占幅，不为清楚擅改角色造型。盾面朝向是当前来线证据：灰鬃持盾者不是因为与虎同框就把盾转交给虎；强反光和遮挡不会改变归属。

近景可读刃盾接触，退开可读不同高度和接近路线，升高可读围合或结果，下一次近景读新的争夺。场地参照随观察接力，例如同一院落的门、廊柱、碎石坡；不要求每次回到同一全景，也不以镜头绕拍制造人物绕后。

遮挡、WHIP、强光可用于速度和交接，但它们遮住的身份、接触和路线仍有前后相容证据。看不清时先定位所需证据，再选改裁切、重叠、落稳或地标的方法；不靠减少人物、统一小动作或增加模糊解决。

## 检查连续段与宣传包装

分别登记文件内的明确剪辑、慢放/定格、连续外观的战斗段和无法验证的接合。相邻帧显著变化是候选，甩动、爆闪也会触发；不能当作切镜数量。全白或全遮挡前后相容不证明原始生成确实无接合，宣传字幕也不能认证模型版本、成功率或完整原片。

检查关键转接前、交会中、落幅后：新目标是否提前存在；旧角色是否继续；可见人数、武器归属和地标是否相容；遮挡是否恰好省掉必要接触；返回是否复位。正常速度观感、音轨、逐帧接合及生成复现分别登记。真实观察依据见[六条参考学习](../../an-workflow/references/six-reference-study-20261015.md)，基础闭环仍用[多人覆盖](multi-character-coverage.md)。
