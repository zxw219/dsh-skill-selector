# 翻滚、翻腾与旋身：动作覆盖和切接

只处理已有动作如何看清，不为了覆盖重新加招或改能力。适用于翻滚、翻腾、弯腰/俯身有动作却缺少相机跟随，或只见镜头转、切后重新摆姿的返工。相机可随肩髋降高、沿滚动路径低位推进、随起身抬升，按当前相位选用；不要求整段复制身体翻轴，也不固定“全身→局部→脸→全景”的镜序。具体可选方法见[动作点跟随与广角特写](../../cinematic-camera-design/references/camera-execution.md#动作点跟随与广角特写)。

| 当前缺口 | 本职责内的修法 | 切后继承 |
|---|---|---|
| 侧滚只有低头与站起两端 | 可沿肩髋下降与侧滚路径快速降高/低位跟进，地标或邻段交付过肩背与落脚；局部只取所需接点 | 人已滚到哪个侧、腿是否接地、兵器忙闲、对手追出口 |
| 俯身/下潜时相机仍留在原高度 | 可随胸肩下降降高并侧移，让既有来袭掠过上沿；再按收益跟起身或交给低位反击 | 低身出口、来袭剩余路线与忙闲肢体，不为下降运镜另加招 |
| 前后翻只见头发转 | 加身体相对固定栏/柱的头—髋—脚关系；不靠相机滚转代替翻轴 | 翻转已到程度、下降路与落点，不能从空中切回再蹬地 |
| 旋身回斩与相机整圈一起转 | 选能分离两者的地标/角度或接邻段，读刃是否自由、脚如何制动 | 剩余旋势、来刀位置、护剑与接重，不自动完整复位 |
| 腾空中没有对手 | 以同框/邻段交付对手移到下降区与攻击到达；空中局部不冻结他 | 对手追刀是否进入下降线路，角色已需回护或改剑面 |
| 脸特写打断全身链 | 用当前发现/判断承担CU，身体与刀画外继续，随后接剩余动作 | 不重起翻、不重演架刀；表情改变哪项实际选择 |
| 手持晃动吞掉接触 | 对威胁侧避/滞后追回后给当前必要清晰窗口 | 当前交刃/脱开/脚位已变化，不以晃动盖丢帧 |

切出与接入至少选择当前需要的相位、注意对象和动作向量；新机位下投影可变，实际场地方位不能变。柱、衣尾或碎片遮挡的隐切继承同次时间，不能重置控制/兵器/场地。图形匹配是观看联系，不能单凭形状证明同一物件；相关转场仍用[转场方法](transition-direction.md)。

实际对照见[30秒两版](../../an-workflow/assets/reference-studies/director-learning-20261012/30%E7%A7%92%E5%90%8C%E4%BA%8B%E4%BB%B6%E6%91%84%E5%BD%B1%E5%AF%B9%E7%85%A7.md)，动作成立条件见[动作专项](../../combat-action-design/references/acrobatic-action-design.md)。文字取景可读不等于实际生成好看；固定、一镜、静音、合法保持按本场目标继承，不要求每招全身/特写/关系三镜。
