# 25式剑招：逐式交锋应用练习

2026-10-12。保留用户资料25式原名和顺序，以已整理执行结构逐式写“当前机会—对手改变—接后招”。本表25行是25个独立原创练习，不是一场全用25招，更不是实战招法或生成稳定性认证。每行需要的御剑、托举、剑气或裂空机制在该行明确特许；不移植给无剑角色。

| 招式 | 独立练习：机会、双方行动、结果与后续 |
|---|---|
| 天罡横旋 | 圆台有外圈净空，持剑A从已脱刃的外切带出换脚横旋推进；B退外层并用短刀抢回收内线，A前脚接重制动护刃转短送。回改：原“转三圈破围”没有对手行动，改为这一次旋势争到一层距离。 |
| 九霄凌云 | 本组已有剑气阶承重，A从完好台沿踏第一阶拔高；B在上阶形成时射向下一个踏点，A改踏侧阶继续升高并从高位压线。阶未成不能已站其上；不套九次拔高。 |
| 逆鳞翻江 | A先反手撤引卸掉B压刃，后方完整踏点成立才后翻，剑沿体外低上挑；B缩刀截撩并追下降，A落脚护身接逆向斜切争侧面。只一次后翻有清楚入口，不凭翻身到B背后。 |
| 星河倒卷 | A既有螺旋剑气先收住门侧通路；B沿窄边退并用已有盾抵住外卷边缘，A控制端改向让外卷绕盾压到柱后，B后脚接柱座继续反攻。受阻后改边界而非光球突然全屏炸。 |
| 流云追月 | B沿三块既定完整石台退，A用已有高速身法折线追及；B封直路，A斜向第二台接真实踏点切侧线，第三段由B回刀产生。残像只留过去位置，不当三具实体同时打人。 |
| 惊鸿三叠 | 第一短突迫B抬刀，A脱刃侧换线取B外侧，B压低追切，A上挑导开后斜落压线；B后脚接重抵住，三叠结果是迫退到栏前。三段由前段防守产生条件，不承诺三击要害必中。 |
| 莲华绽放 | 本组剑气可外扩八向，A在柱间展开封外圈，B压入未满的内侧争控制者；A收回临近B的一路护中，其他路继续外扩；B趁局部回收侧移。八向有效区与持剑实体分开。 |
| 龙渊潜行 | B高刃守门，A低位剑尖沿完好地面弧进但身体不爬行贴地，接近后上挑；B下压截锋，A斜滑脱刃并换侧，不让剑从地里穿出。身体与剑尖不同路径均能读清。 |
| 凤舞九天 | 本组有持续空中动力，A高位回旋避B束线，每次转向由束追来的新角度产生；最后沿B控制手外侧俯冲，B抬防，A滑过脱开后继续飞行。示例不把九转写成九次无事转圈；若锁九段则逐段给威胁。 |
| 万剑归宗 | A收回此前散出的剑气，B在收聚时冲控制者；A身体退柱外并以既有护线拖住，散气沿真实回路聚为细剑，压成一线逼B侧避，A继续争门。聚合源不从空气凭空多一百把实体剑。 |
| 阴阳轮转 | 本组已有双轨剑气，A用正轨护上路、反轨取低线，B改刀压中路使A先护中再切外；手中唯一剑仍沿可达路线转腕换线。双色不等于持剑实体复制。 |
| 断浪新潮 | 前浪迫B退出直通道，中浪沿B新侧面切来，B上跃越边，后浪封其原落脚；B改落完好柱座，A追到可达距离。前、中、后各接B选择，不能只是三团同方向爆光。 |
| 百步穿杨 | A在远台看见B从柱后露肩，瞄准点与通路明确才发细线；B转身退回柱后，细线穿过旧位打石面，A沿被迫遮挡的空窗移位。精确射线不自动追踪或必中。 |
| 缥缈幻影 | A真身沿台东边高速斜移，残影留在上一位置；B确实挥向残影后暴露侧面，A从可达踏点短切，B回刀挡住。若B没有被骗，就用真身快速换角而非写诱敌已成功。 |
| 天外飞仙 | 本组可滑翔/飞行，A从高台长滑入距再俯冲长斩；B举刀并退向完好空地，斩被导向地面，A用既定动力减速或落脚接重回护。俯冲线、长刃路和B退出相容，不用高镜头就证明高速。 |
| 陨星坠地 | A剑尖聚核后沿清楚垂直通道坠击，B先让开核心区，剑先触石台并沿台面传播裂纹；B在柱座抵住边缘压力，A接重收刃接追。核心挥空/击地与伤到B分开。 |
| 盘龙缠身 | 已设龙形剑气绕住B持刀腕而非全身，B空手拉开束环并退步，A收束逼其刀路变窄再沿空侧短刺；B转肩回避仍可行动。控哪里、剩余资源和解法明确。 |
| 回风拂柳 | A转腰在外圈斜架来刀，刀剑滑离后沿内圈短反切；B回刀收护并踏后，A追一步到门侧。没有接触就不写卸力，没有脱开就不写剑独立回砍。 |
| 雪落无痕 | 细点剑气从既设上方区域缓下，B抬头看到局部点位便移到柱沿遮挡，A借其视线/步位改变在地面进逼；少数点落石面留下证据。难察觉是感知关系，不自动必中。 |
| 乾坤一掷 | 本组有牵引回剑，A旋身把唯一实体剑从外侧掷出，手从此空下；B避剑后追A本体，A用换步拖住并牵剑沿明确外路折返，接回握柄后才再剑击。不得同时手握与敌后飞剑。 |
| 剑气长城 | A立外层拦束、内层反推，B连续攻同一区使外层出现破口；A控制端向破口加载，身体因此失去另一侧自由，B绕侧逼A撤墙换路。防墙不是全场无损停格。 |
| 踏雪无痕 | A借雪地柱影真实绕东侧，B视线被原柱遮但听/看到新侧脚迹，转刀回护；A从已走到的侧面短刺被挡，继承柱外距离。隐匿不代替绕行和B转向。 |
| 九转轮回 | 本组已有阵心与阵边，A每转改变距B和阵线的关系，B冲阵边迫A缩圈；A下一转切到B被阵边限制的侧面，短刺逼其退。若要求九转则各转有不同威胁/机会；本训练只示一段局部选择。 |
| 破空裂虚 | 本组已有短时裂空，A长斩带出边缘作用，B躲过实体剑但侧身仍靠裂缘，继续退步避开边缘区；A在裂缝消散前只能沿已有控制规则追线，消散后不留永续封锁。 |
| 大道无形 | 本组已有极短路线精确作用，A在B回刀露出的线窗里极小转腕，作用端到B刀侧使其偏线，B重接支撑回护，A趁偏线争门。可见因果由接收端/判断依据承担，不为炫酷强加巨光爆炸。 |

## 组合迁移复核

一组纯持剑链可取“龙渊潜行的低路接近→回风拂柳的接触外卸→天罡横旋的一次有净空回切”，只取身体与剑路，不从招名偷加御剑/剑气。另一组已设剑气链可取“断浪新潮迫换通路→盘龙缠身限制持械腕→既定细线取空侧”，保持束缚部位、持续控制与本体防线。用户两图是术者外观，不能因为学习该表就默认给她们剑；非剑角色只迁移逼位、截线、封出口等战术关系。

复核结果：25式有逐式练习；未把原资料摄影角度/慢推/九段推广为通用规定；被挡、落空、受阻、追击与恢复都有实际文字结果。仅作者语义复核，未进行独立模型或成片验证。
