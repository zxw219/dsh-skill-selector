# 多人对战、团队作战与一对多：专项学习计划

本轮触发：四人战斗成片暴露出无任务站立、站桩发射与防御、对方停机、距离失真、敌前无掩护救援，以及多人分镜无法交代同一战局。用户要求先制定详细计划并实际学习；本轮学习方法，不擅自重写这条视频的完整提示词。

## 学习目标与工作顺序

先建立多人共同时间、空间与任务，再编攻防和配合，最后选择观看顺序与切点。依次完成：失败样本补查 → 一手制作资料学习 → 24项问题练习 → 4项综合迁移 → 正反例复核 → 写回实际技能及发布包。以具体产物和证据推进，不用学习小时数承诺掌握。

**验收对象是关系，不是招式清单。** 逐个关键交会点回答：每个人此刻想做什么、能到哪里、受到谁限制、为何暂时不出手、上一人的动作如何改变下一人的选择。没有作用的等待不能被衣发、粒子、运镜或“高速”词抵消；有作用的维持、受压、瞄准、伤后恢复与戏剧停顿不能被误改成乱动。

## 十个学习模块

| 模块 | 学什么、对应什么失效 | 要做的练习 | 通过依据 |
|---|---|---|---|
| M1 开局进入与争夺 | 从威胁已在形成或双方抢位进入，站位具有目的；区分必要对峙与无任务展示 | E01 无效开局；E02 同时进入 | 读得到谁先争夺什么、对手如何应对；不以全员摆架开场代替关系 |
| M2 共享时间与背景行动 | 一人出招时，其余人仍受同一时间约束；次要角色可推进、维持、受阻、恢复或观察判断 | E03 二对二同期；E04 背景回接；E05 不能凭“站着蓄力”免于威胁 | 没有可达自由攻击被无因搁置；画外角色返回继承位置与任务 |
| M3 有效距离与移动攻防 | 接近、追退、横移、拦截、投射在途、进攻端与防守面；近战/远程距离有区别 | E06 近战入距；E07 移动盾；E08 射线；E09 飞行/高度 | 攻击与目标在同一时刻交会；镜头变化不能制造距离或安全位置 |
| M4 团队协同与职责变换 | 掩护突进、诱防利用、交叉威胁、交接目标、封路与反包夹；对手也会拆配合 | E10 掩护；E11 诱防；E12 交接；E13 配合被打断 | 拿掉协助者后，主攻的机会或结果实际改变；对手不是等待合作表演 |
| M5 敌前救援与有代价脱困 | 救援窗口来源、敌方同期续攻、束缚的控制端、忙闲手、破除后支撑与撤/反击 | E14 无掩护救援；E15 边防边解；E16 抢救失败/改案 | 救援持续期间敌人的可达攻击有真实处理；不能让敌人等到解绑完成 |
| M6 一对多的多向压力 | 关键攻击者与外围敌人分层；同时逼迫但可阅读；用已成立的阻挡/净空解释先后 | E17 双向来袭；E18 地形限流；E19 受击与外围接续 | 敌人不排队，单方不能同一肢体处理互斥任务；阻挡一解除，威胁继续 |
| M7 混合战法与术法控制 | 近战、弓射、护盾、法术与代理保留差异；维持控制与释放后运行不同；来源—路径—作用可辨 | E20 近远程配合；E21 施术者受压 | 无默认全员拳脚或站桩施法；本体、在途作用、控制占用互相相容 |
| M8 多人分镜与注意交接 | 关系景、主攻局部、目标接收、援护关系；多条动态攻击轴；景深背景与画外威胁 | E22 同事件两种覆盖；E23 多轴/切接；E24 关键窗口特写 | 关键协作至少有同框或连续镜证据；切近后未拍者仍行动，切回不复位 |
| M9 跨题材综合迁移 | T1 二对二徒手/兵器；T2 四人近远程奇幻；T3 一对三有限通路；T4 三人协同压制单个强敌 | 每项先行动链，再观看顺序，再反向检查；不沿用同一招式套餐 | 同期、距离、资源、敌方反制与结果均成立；没有固定牺牲/救援/反转剧情 |
| M10 负例与回归 | 将本片六项漏检逐项回查；保留合法定势、受压、观察、慢镜、仪式与单人展示 | B1–B6 合法反例；所有练习由作者逐项语义复核 | 验收能发现本片问题，也不会把全员运动、固定镜数、固定速度强加给其他任务 |

## 参考选择与拆解方法

素材至少覆盖三种职责：团队近战/混合能力、多人协同对强敌、一对多。优先采用制作方的分镜/预演/动作花絮与导演、动作导演、动画主管的直接访谈。二手影评可用于找素材，不能替代动作证据。

每个参考分开记录：已读正文、已看静帧、已做连续播放、已做关键帧复核。不能读完访谈就声称逐帧看过片子，也不能把官方作品简介当成完整战术教学。

拆解逐个有效变化：

1. 用场地地标和有效攻击范围建立关系，不凭透视缩略图给虚假米数。
2. 为关键人物记录“位置/面向—任务—当前限制—作用体/忙闲资源—下一出口”。不强迫每帧填表。
3. 看主攻时，同时查辅助者与对手；画外者记持续任务和回接时机。
4. 判定合作：协助造成窗口，主攻利用窗口，敌人有同期应对，结果改变后续关系。单纯同屏或不同颜色技能不算。
5. 救援反推：敌人的续攻要多久能到；救援要完成哪些实际动作；若没有掩护、隔离、牵制、遮挡或相容边防边解，不能直接宣布成功。
6. 镜头拆解记录观看任务、起幅、关键中段、切出时点、切入相位与被裁角色的同期事件；镜数按信息需要决定。

## 每项练习的产物

练习统一包含：失败基线、修订的具体事件、全部关键人物的同期任务、距离/路线及资源检查、对手反制、适用边界、作者复核结论。方法写回动作与摄影来源，不以堆“禁止站桩/禁止瞬移”结束。

综合迁移每项保留至少一个配合受阻后改变方案的过程；这是本轮训练压力，不是以后每场必须反转。受压、维持和真正观察可保持静态，必须有当前作用和出口。
