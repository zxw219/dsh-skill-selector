# 四项综合迁移与六项边界复核

均为本轮原创文字练习，不是用户原片改稿或参考电影复述。先写采用事件，再组织观看，最后核四人或多人的同一时间。作者复核不能代替独立评审和成片验证。

## T1 二对二兵器：抢廊口与目标交接

设定：A/B与C/D双方各持一把短剑，无投射或超自然移动。C守廊口，D在侧栏，A从廊外进入，B在A外后侧。廊前可容两人横移，侧栏限制向外退距。

采用事件：A斜切入距逼C护上路，C用短拨后追刺，A收肘护腕，追步没有完成。B沿外侧靠近D，D不站着等，提前斜进把B逼向A。A/B的路径因而挤在同一窄处，B先侧身避开D剑尖，A被迫收短前压以免撞B；C趁收短进剑，A偏转剑线接回防守。B利用D追步形成的回收窗口短切D武器外侧，将其迫到侧栏。A不继续与C僵持，抽离接触转向D；C追A侧背，B立即跨入短接C刃，完成目标交接。D借A尚未完全转胸时前送剑，A护住来尖后才形成新的近身压力。四人从拥挤关系转换成两条新的交锋线，均未复位。

观看顺序：斜侧关系中景读双方入距与路线挤压；沿B让线显露A被迫收短，再切A/C短接触局部；切回用同一栏角接B压D；A转向D时短移保留C追背与B拦刃，最后接A/D的新来尖。不是A打完才给B一个展示镜。

作者复核：C/D主动拆A/B配合；近战接触前均有入距，目标交接有实际承担。局部镜裁掉B/D时继承其贴栏状态，不重启动第一次斜进。两人持剑不被要求额外用拳腿。

## T2 四人近远程奇幻：救援先受阻，再建立窗口

设定：A短刀近战；B左手维持局部盾，右踝被D的根索缠在石根旁；C持长杖短距压进；D在外侧控制一条根索并能从另一只手发短投射。根索已有可切的近地段，破除需真实触及，不设卡扣、无敌罩或自动净化。B受束位置紧邻宽柱遮挡边缘，未束腿允许小范围换支撑；D可绕柱重新找射线。

采用事件：A退到B近旁伸刀触根，C立即用杖端压其肩线；A收救援动作，用刀背偏开杖端并横移到B前。B仍用左盾承接D绕柱侧的短投射，右踝不能带动身体跑开。A沿C回收追半步逼其改握，D将根索收紧迫B的支撑偏斜；B下沉接重，盾面随支撑变低，新的箭线将越盾而来。A不强行继续救，先短刀偏掉这路投射，C趁机再进。A借C杖杆已前伸的短接触斜压其杆，转肩维持一条防线；B以未束腿在根索许可的小范围接重，转肩将上身移入已近在身侧的柱后，右踝仍留在束点；D立即绕柱寻找新射线。A利用当前短窗口刀端触及近地根段，C抽杆使A无法连续切完；B用未束腿接住身体，A转刀回防。根段已经受损，D为收紧必须在控制端继续动作；A/B从这个部分损伤状态再争下一窗口，救援并未凭一刀完成。

观看顺序：先关系景读束缚、C来杆与D绕柱；短跟A中断施救，接B盾受力和踝部受限局部；回关系景读A偏投射与C再进；柱遮射和A压杖必须在触根特写之前/相邻同次镜中可辨；切回继承未切断根、C抽杆和B换支撑。

作者复核：两个敌人都续攻；A同一把刀不会同时切根、挡杖、挡投射，动作被迫中断。B仅有踝受束，左盾与未束腿仍可用，不能恢复成四肢自由。柱只暂遮D当前射线。结果保持救援受阻，不用敌人站着制造成功。

## T3 一对三：暂时限流，外围重新形成压力

设定：X持短兵器，无瞬移；Y正面持短棍，Z右侧持短刃，W沿左外侧接近。场地有一根宽柱、栏边及一段可绕的通路，没有不可见新门。

采用事件：Y正面压X，Z绕右切X偏转出口，W沿柱外侧接近。X将Y短棍偏向柱侧并转肩减小正面，Z的来刃因Y身体挡路缩短，随即换外侧进入；W已经接近X的左后侧，不等Y受击结束。X来不及反击Y，先护Z的近线并侧移到柱旁，柱暂隔开W与X。Y追进，Z保持外側压力；W绕柱向另一边出现。X与Y短接时被迫换支撑，Z压这一落脚，X用短兵器横护导致原对Y的控制解除，Y继续逼近。X趁W绕行尚未结束、两条来线未完全合拢时脱出栏角，但Z立即追其出口，Y随后调整路线而非回原位。

观看顺序：稍高斜侧关系景读三条通路；X护Z时保留Y轮廓形成遮挡证据，短跟X经过柱侧，W从另一边逐渐显露；接X受压换脚的局部后立即回关系景读Z追落脚与Y控制解除。不能每切一个敌人就把其他两人时间暂停。

作者复核：Z暂收短有身体遮挡，不是排队；W绕柱用时存在，不能在X背后凭空出现。X每次避开一向都会失去其他控制；脱栏角服务继续交锋，未默认整场逃跑。保留单方受压，不强制碾压多人。

## T4 三人对一个强敌：协同控制与破坏配合

设定：A近战持剑，B持续控制一条连接石柱的束带，C发射一次只可维持一个方向的窄束；强敌X持重刃且有已设的强力身体。束带需B持续保持张力，窄束不能穿队友，强敌没有临时新增的全域防御。

采用事件：A从X前方迫其抬刃，B将束带绕向X持刃腕外侧并锚到既有柱面，限制X刃的外展；C从A外侧发窄束压X侧步出口。X顺束带方向向柱侧踏入，B张力暂松，X可把刃收成短线逼A胸口；A收剑回護，C射线被A身体遮住，须停束横移找净空。B重新拉紧时X先用重刃短接迫A收腕退半步，空闲左手牵束段至刃的回收线，再顺受载方向斩断；B承力骤减向后接重；A利用X处理束带的窗口侧切，但X的刃已在近线，挡切后以肩步挤掉A支撑。C从新侧面再次放束，X转肩逼A进入这条来线，C收短避免打队友，团队的原夹压被拆。B不是闲置，借接重恢复控制端，在新角度重新布带；A顺挤压出口转向，三人必须重建新的关系，不能继续调用已断束带的旧窗口。

观看顺序：同框读A引刃、B束带锚点与C压侧路；腕部局部读刃受限时邻镜接X踏向柱面造成松带；X短攻A后用侧移镜露出C停止射线的原因；切B接重，再回关系景交X把A挤入C射线与C收束。强敌的动作改变整个配合，而非挨三种颜色技能。

作者复核：X有连续反制，三人各自作用和占用可辨；C没有穿A发射，B断带后未继续控制原段。A受挤后不自动恢复完整剑架。3v1和1v3可以从不同立场设计，但不能因“单个强敌”免除其资源约束。

## B1–B6 合法边界：防止把纠错变成新错误

| 编号 | 合法情况 | 为什么不能一律改成全员运动 |
|---|---|---|
| B1 | B保持盾面，抵住同一方向持续束流，脚下支撑受载；A在盾外争位 | 保持本身在承担防线；来向改变时才需改角、换步或承认覆盖失败 |
| B2 | D暂持弓不发，C正遮在箭线上，D正在横移找净空 | 不出射有实际原因，不能强制乱射或加不相容的跳跃 |
| B3 | Y受击扶栏恢复，另一敌人已经接续追压 | 受限恢复不是无事可做；不能要求倒地者立即无伤反击 |
| B4 | 明确对峙或仪式开局，有互相观察/规则/压力变化并有后续触发 | 用户指定的戏剧停留保留；不能用本片问题宣布所有静止开局非法 |
| B5 | 明确慢镜展示一次决定性多人接触，各人同速时间关系仍成立 | 慢镜不是角色单独停机，不能为“高速”删掉合法主峰 |
| B6 | 固定/一镜到底或单人展示为用户锁定 | 固定可用画内调度展示合作；单人没有团队任务，不套全员共享检查表 |

复核方式：逐项用同一标准反向判断，以上均可在给定条件下保留。没有外部盲评，不把此表登记为独立行为测试通过。
