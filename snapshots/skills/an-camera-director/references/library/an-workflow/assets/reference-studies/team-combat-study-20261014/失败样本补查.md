# 四人片补查：上一轮漏掉的核心问题

用户补充后，按已有全片与加密帧重查；沿用0.5秒全片及交锋段4–6 fps的采样范围，未将抽帧称为连续正常速度观看。原检查报告保留，此文件补足并修正优先级。

## 应从开局就判断失效

| 区间 | 已见事实 | 应检查而上一轮漏查的关系 |
|---|---|---|
| 0–约3秒 | 四人分成两组站在平台两端，主要变化是衣发、尾部及小幅姿态，身体位置和互相距离基本不变 | 没有明确的抢位、逼近、封路、瞄准修正或持续争夺；没有可见信息把这段保持成立为必要对峙。对本片的持续协作战斗目标，这段是无任务开局。 |
| 约3–3.8秒 | 弓手放出箭线，蓝色原地立盾，粉色原地持球，紫色仍在原位准备 | 站桩进攻与站桩防御不能靠光效抵消。应看防御有没有应来向改角/接重、进攻有没有追踪和改线、其余两人如何利用这次接触；此片主要停留在两个效果相碰。 |
| 约4–5.7秒 | 紫色冲起并跃向右侧，右侧两人的位置与主要姿态变化很少 | 未按突进更新右侧目标的判断、射线、拦截或让线。粉色没有把紫色逼入某条路线，弓手没有清楚处理正在迅速改变的目标距离。左方进攻没有迫使右方作出有效同期行动。 |
| 约6–10.8秒 | 紫色已进入右侧近身，蓝色追进；后续三人近距聚集，粉色仍持球 | 初始远射关系已变成近身关系，必须重判弓手拉弓净空、射线、盾面保护谁、紫色出招能否到达、粉色控制能否挡住近身。片中角色职责未清楚适应新距离。 |
| 约11.3–14.3秒 | 蓝盾附近箭杆与藤环约束前臂；紫色到蓝色旁边，约13.7秒击向藤环区域 | 上一轮把“击藤后藤减少”判成局部配合，忽略了粉色和弓手的同期进攻条件。关键错误是没有建立救援窗口：敌人仍处于可施压关系，为什么不在紫色转向救援时续攻？谁挡住、隔开或牵制他们？切近景把敌人裁掉不能充当安全条件。 |
| 约17.4–20.3秒 | 高处追击切到弓手特写，后来回到低处和地面聚集 | 摄影只交出弓手的形象/操作，没有交出正在到达的紫色威胁、敌方拆解、下降路线和落脚。把未拍人物停止，是多人分镜的严重失效。 |
| 约20.5–24.8秒 | 木杆、盾与光球长时间维持相近关系，紫色在中间重复挥动 | 主攻、辅助和反制没有形成状态变化。仅“每人有一团光”既不是持续角力，也不是团队协作；谁维持控制、谁受限、谁绕侧、谁利用空线需要具体成立。 |

## 距离问题的准确表述

本片没有可靠的米制空间标定，不能从倾斜远景与近景的人物占幅推算真实米数，也不能把每次切近称为瞬移。蓝色约6.1–6.3秒确实有追进迹象。

可以确认的缺口是：远距箭线、紫色跨越过程、蓝盾的实际保护区域，以及近身后的弓箭/术法有效范围，没有共同决定四人的后续选择。防御“在场”不等于挡住了队友当时的来袭线；敌人在近身范围内却持续保持远程展示，必须有隔离、牵制、让线或抢距的依据。

## 救援结论的修正

约13.7秒有可见解藤动作，只能证明**局部动作—结果**，不能直接证明**受压中的团队救援成立**。救援还要覆盖同一时间的敌人和被救者：敌方为何无法打断、被救者剩余可用资源如何防守、救援者用哪只手/哪条路线施救、解开后怎样接重和继续任务。当前成片没有给足这些证据。

## 学习优先级

先补开局任务、全员共享时间与有效距离；再补移动攻防、配合与救援窗口；最后补摄影覆盖。不能先加更多切镜、粒子或招式名称，因为它们解决不了敌人停机和无掩护救援。
