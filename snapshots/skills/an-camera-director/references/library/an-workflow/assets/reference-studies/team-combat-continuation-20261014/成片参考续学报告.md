# 多人战斗续学：从任务分配到实际配合

日期：2026-10-14。针对用户指出的四人开局停机、站桩攻防、对侧不响应、距离失效、敌前解绑和分镜问题继续学习。本轮没有重新生成视频，也没有改写用户原片剧情。

## 上一轮哪里仍然不足

上一轮建立了共享时间、有效距离和救援窗口，但主要证据是访谈、失败片抽帧及作者文字推演。24项练习覆盖了问题名称，不等于动作编排已经成熟。重新读正文后发现：多处靠短压、偏开、侧移、再争窗口接续；协助者的提前准备、身体高低与占用变化、成功救援后的接重仍不够具体。让四个人各有任务，也可能只是两组独立对打。

本轮改为取得公开提供的完整片段文件，先按全片时间顺序采样，再对决定性区间加密，核对身份、实际来向、支撑、威胁交会与注意交接。以下“完整片段”指发布页提供的片段，不指整部电影或整个电影战斗段。

## 成片观察与推演分别记录

### 玻璃房：关注被控制者和另一名进攻者

112–122秒的采样可辨两侧人物、主角不同高度的受压与反应；146–158秒可辨接近、身体纠缠、将被控制者转到另一来向附近，以及第三人继续进入。这里有用的是“处理一向会改变处理另一向的身体条件”。不能把一个挡住的瞬间写成永久人体盾，也不能从暗部推定精确锁住哪根手指。

片段也含倒地恢复和明显的对话/礼让保持。它们服务该段剧情，不应搬成普通持续追击中的敌人默认等待。背景旁观者与当前参与攻击者也必须区分。

### 楼梯：并行推进不等于每一下都是合作

30–38秒主次层都有交锋，近层处理敌人时上层仍在变化，楼梯与扶手保留位置参照。这能支持同期覆盖；仅凭两人同向推进，不能宣称每个动作都替另一人制造窗口。

132–149秒另有远处持长枪者、犬、地面受压者和近处持手枪者。近逐帧可见近敌持枪手受扰缩回，原指向地面人物的枪口离线，随后地面人物开始恢复；近敌仍在场。犬在这一段没有可辨的直接扑袭，不能记成“犬扑倒枪手完成救援”。谁发动那次干预的精确瞬间，在这次未听音的采样中保留不确定。可以迁移的有限关系是：当前致命来线先被改变，恢复随后发生；一条来线失效不等于所有敌人失能。

### 卡萨布兰卡：协作先改身体条件，再接下一行动

60–67秒可辨犬低位接入、敌人姿态变化、人物推进接触与近距射击的相连过程。犬不是衣饰特效，人物也不是留在原地等犬演完。迁移时保留“协助端实际改了目标的支撑/防线，另一端已经在可利用位置”的关系，不把犬或枪硬塞给奇幻角色。

124–134秒的面对面举枪，经加密确认是敌我对峙，撤销粗看时“可能资源交接”的猜测。166–173秒的犬由下方接近屋顶目标，撤销“从屋顶跳下”的方向误读。低清不足以确认每次借力接触，因此不凭空补写人物托举或完整的登高动力学。

### 巴士：身体变化不能只剩小步换边

22–36秒可辨两侧上肢控制、身体下沉与回转、固定扶杆参与的腾挪，以及后续攻击接入。46–55秒可辨近处交锋、后层敌人接近、乘客反应和再次合围。扶杆是当时的实体支撑：手抓杆时不能同时宣称那只手自由攻击，腾空后还要接落地。

这段含喜剧性反应与短保持，公开片段也没有提供完整巴士战斗的后半段。不能由这一个片段推定整场敌人从不等待，或强制所有一对多都分腿腾空。乘客是目击者，不应被计作不行动的战斗队友。

## 真正改变的方法

1. **配合从窗口出现以前开始。** 接近、找净空、把武器送到可用位置应与前一轮交锋重叠。窗口到来时才开始跨场赶路，往往需要敌人等候。核对的是协助作用结束前，利用者是否确实能完成必要操作。
2. **同时不是四个人同一拍命中。** 主攻接触、队友贴入、敌人回收和另一敌人改线可以重叠；先后来自控制、路线和受力。把四个攻击动词并排也可能互穿、遮射或抢同一通路。
3. **任务要产生可见的动作变化。** 用角色相容的高低、支撑、躯干领随、接触方式、武器用途和释放过程编组合；不能每个人都改成“短挡—侧移”。有效维持仍保留，不用随机动作伪装忙碌。
4. **救援需要接替防线与释放后的恢复。** 接替者先实际承担下一次攻击，救援手再离开原防守；解除束缚后处理失去支撑、手臂落下或重新持物，同时接敌方续攻。近敌受扰只解释当次来线，不解释永远安全。
5. **注意交接跟着配合的变化。** 在主攻阶段让次要人物的准备可定位；协助改变条件时交接注意；结果镜接队友真正利用和对手再应对。不能只给各人一个孤立特写便算多人分镜。
6. **对名场面也保留反证。** 对话、礼让、喜剧保持和旁观角色要按场景职责理解。可迁移的是关系，不是电影中的等待长度、镜数、枪犬或身体招式。

[Chris Townsend直接访谈](https://beforesandafters.com/2021/09/17/heres-what-went-into-the-visual-effects-of-shang-chis-crazy-bus-sequence-part-1/)介绍了巴士路线规划以及动作预演与摄影预演之间的往返。这支持动作、空间与观察共同校准的工作方法；上面六项是本轮成片采样及原创推演的结论，不冒称访谈逐条教过。

## 针对原片的回修要求

| 用户指出的失败 | 采用的方法 | 原片/新稿必须交出的证据 |
|---|---|---|
| 开局四人站着 | 起幅进入已形成的争夺；次要人物提前准备 | 双方正在抢哪条通路/射线，谁的靠近使谁必须调整 |
| 左攻右不动 | 将四人放进同一次威胁交会 | 守方的当前应对及其他人的同期限制/准备；不写静候整组攻击 |
| 站桩攻防 | 来线变化引起身体和防线变化 | 高低/支撑/朝向/武器任务的具体变化；有负载的保持可保留 |
| 距离混乱 | 以同期目标和地标核可达操作 | 进入、净空、接触与制动；切近不替代闭距 |
| 敌前解绑 | 先接替/改变可达威胁，再操作，最后接重 | 近敌当次武器去哪、另一敌人为何暂不可达、窗口如何结束 |
| 分镜割裂 | 先读提前准备，再读改变条件，接利用与反制 | 被裁掉角色切回的新位置；不重置开场平列 |

## 练习与接入

已重做[三条具体动作链与反向检查](%E4%B8%89%E6%9D%A1%E5%8A%A8%E4%BD%9C%E9%93%BE%E9%87%8D%E5%81%9A%E4%B8%8E%E5%8F%8D%E5%90%91%E5%A4%8D%E6%A0%B8.md)：二对二的提前接近及打断协助、能完成一次解除的敌前救援、一对三中的临时阻挡和受压后果。每条区分设定、同期事件、观看、最早错误和反向条件；不以练习数宣称掌握。

本轮方法回填多人动作、多人摄影、多人终检及An入口的相关职责，并随工作流同步。包、链接和指纹检查只证明文件接入。仍未做正常速度音画评估、独立评审或新生成验证；真人兵器/枪械参考也不能独自证明二维、仙侠多代理能力战已掌握。

下一次实际创作应用时，先选一条明确的协助关系，检查提前准备→改变条件→利用→反制→出口是否在正文兑现，再检查该事件影响的其他角色和镜头。新成片先看正常速度效果，再在最早失效处密采样；不能以方法文件变长当作改善。
