## 本轮重新核验的外部资料

1. [ASC：Shot Craft: Tools for Camera Movement，Jay Holben](https://theasc.com/article/shot-craft-camera-movement/)：手持支撑方式、跟随与观察响应，及其即时感/紧张用途。正文已读。迁移为“指定观察者位置、事件触发和构图修正”，不规定手持必须大抖，也不把所有空中追拍称手持。
2. [Adobe：Dolly zoom effect](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)：相机位移配反向变焦，主体保持占幅、纵深背景改变；背景需要可读层次。正文已读。本轮将相对距离及背景参照落实到对照，而非把急变焦叫希区柯克。
3. [Adobe：Match cut](https://www.adobe.com/in/creativecloud/video/discover/match-cut.html)：图形/动作/声音等匹配用于视觉联系。正文已访问；本轮原创例明确“形状或颜色联系不等于同一时空”。
4. [Animation Mentor：Anticipation，Chris Hurtt](https://www.animationmentor.com/blog/anticipation-the-12-basic-principles-of-animation/)：准备可大可小，不只统一向反方向摆动。正文已读。迁移为准备嵌入回收/接重，保持角色个性与急缓。
5. [Animation Mentor：Body Mechanics，Wayne Gilbert](https://www.animationmentor.com/blog/animation-tips-tricks-what-makes-or-breaks-a-good-body-mechanics-shot/)：全文抓取失败，本轮仅搜索摘要核到动力一致和预先重心转移，不能登记为全文学完。八条新动作链是本轮原创推演，不冒称从该页学得特定空翻技术。

Slow In/Out、J/L-cut页本轮抓取失败，未登记本轮全文阅读。J/L等方法继承已有转场来源，并做本轮文字练习。网页中嵌入视频没有观看，文章查阅不等于看完课程。用户两份本地剑招/转场原文在此前已完整归档与转译，本轮用其执行练习，不重新宣称新获全文。

## 学到的方法怎样改变工作流

动作侧：显式接入翻滚/翻腾/旋转的过程与窗口，先用大动作获得当前战术收益，再用对手追落点查空窗；不因为连续性严格就把角色全部写成斩刺挡退。招名、转镜、衣摆与残像不能代替真实身体路。

摄影侧：从要观众读到的“身体轴/交会/判断/范围”选机位、取景和路径。关键相位保留身体与地标；全身/局部/脸分工，切回延续剩余相位。手持有明确观察立场及滞后/追回/侧避，急变焦、希区柯克与推近分清实际变量。

联用侧：沿同一事件链回填当前An模板；动作不重新导演摄影，摄影不改变角色胜负，质量复核不强制全库。训练可做多个版本比较，普通作品只交所选方案。新增资源按问题定向读取，不把训练数设成创作配额。

## 已发现并回改的问题

1. 原先“受压滚出”未解除刃接触：补先导离/脱刃，再接重滚出，对手追起身口。
2. 希区柯克若角色也在动，仅写相机后退不够：改为相机与主体相对距离变化，再匹配视场保持占幅。
3. 翻腾中同时大滚转相机可能读不出真实身体轴：补可读地标或邻段身体过程，不把所有相机滚转禁掉。
4. 切回不能由同招起手再演：每个切点指定已到相位、残留与画外任务。
5. 同一作者新题选型属于自主迁移作者复核：删除“独立盲测通过”一类不成立结论。
