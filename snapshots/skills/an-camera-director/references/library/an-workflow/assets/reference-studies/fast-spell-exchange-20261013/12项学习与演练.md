# 施法与高速交锋：12项文字学习和作者复核

日期：2026-10-13。全部是本轮原创的学习练习，不冒称用户前稿、实拍或生成观察。雷修A与晶修B为训练用补设；并非从用户图片推定的角色能力。作者已对操作、手资源、作用与出口复核，没有独立模型盲测或成片验收。[来源与执行边界](evidence-manifest.json)。

## 01 高速交锋与追逐任务的分类

构造片段甲：两人沿廊道飞奔、越柱、留连续残影，六秒里只在末尾互放一发雷弹。证据支持移动/追逐很快，交锋仅末尾一次；不能据跑动给出“六秒连续超高速打斗”的结论。

构造片段乙：双方相距约两米，指端短法刚成立，对方折面截入；原控制手受压即换另一手触点破法，刚开的空线又被地晶封住，立即以近体压力解开；身体只作必要让线/接重。快发生在发动、拦截、改控和后招相位，可设计为高速交锋。

构造片段丙：一人高速退走，每跨一个柱间，对手已截住下个落点，退者持续变诀化掉当前威胁。追逐与高速交锋同时成立，不能因本轮纠偏删掉其追逐。

结论：三段是分类例，不是同条件对照。高速交锋要找有效攻防相位，纯跑动的速度不能转借；追逐和远程仍合法，不固定人人近身。

## 02 三秒、有限区域的短促施法反制

条件：A/B相距约2.5米，各可在可见区域施短法；B一手可调一面晶镜；A近体雷环为一次主动脉冲，放出后独立结束。双方小步让线累计不到一米，镜内不切镜。时间是文字设计预算。

- S=0.0–0.6s：A右食中指并起，拇指扣无名指锁定B前臂，指节短促弹开放出窄雷针；B从A抬指时左腕内转立镜，雷针触镜后偏入侧方石地。镜的去向先于接触成立，A肩肘随释放收回。
- S=0.6–1.2s：B右食指与拇指圈合，晶环箍到A右腕外侧并限制旋腕；A右肘下收，把受压腕带到腰侧，左掌再向外翻开释放近体雷环，同一平面的晶环被撑裂，右肘接着回护。B左手仍控原镜，右手释放锁腕后可收势。
- S=1.2–1.9s：A右指恢复自由，目光指向原镜转轴，指端点雷扰动镜面一角；B左指分开，放弃受损角，保住剩余镜片，身体半步让开漏出的短雷。只解除局部，镜不全部复原。
- S=1.9–3.0s：B右掌按地，A足前一段晶脊上升；A左足侧让，右掌触身侧石面布一枚待命雷印，再离地收肘。晶脊阻住原位，印尚未触发，双方接新支撑准备下一交锋。

结论：两次进攻/反制和一次封路/布置连续接力，主要速度证据来自短促作用。没有为“快”增加长距离跑动，也没有将布印写成当场爆炸。左/右手任务逐段相容，静止片段不证明实际速度，仍待输出观看。

## 03 同样移动很快，交锋作用不同

例A：A贴地滑过B身侧却未出招，B也未攻击或封路；相机高速绕场。可读移动和摄影，不能据此证明短法交锋高频。

例B：既定A直线雷针在途，B向身侧半步让出其窄作用区；同一动作里右掌按地，令A将要接重处的晶脊抬起。A看见地晶起势而改落脚点，先前雷针击入空处，接着换左手压破新脊。位移分别解决来袭与支撑威胁，有同期攻防。

例C：用户锁定纯追逐空间体验，摄影读地标通过与闭距。即便没有高频交锋，也可验收追逐目的；不得为了满足本轮课程强塞法术互打。

结论：动作收益、交锋速度和场景任务分别判断，不靠“移动了多少米”给所有维度评分。

## 04 七种操作怎样变成施法动作

| 操作 | 原创过程 | 作用与出口 |
|---|---|---|
| 锁定 | 眼先追到目标晶轴，右食中指并起，拇指压无名指，肘靠肋稳住方向 | 窄雷针目标成立；指节弹开后收肘，不新增追踪 |
| 聚拢 | 两掌相对由宽转窄，肩肘随压力内收，掌指向掌心回扣 | 雷压缩成扁印；断诀后独立释放，掌指自由 |
| 分层 | 左掌托住既有术核，右指先后展开并向外分开，前臂上抬 | 两层晶面真实分离，一层继续接来袭；不能只写手指张开却效果不变 |
| 接通 | 屈膝接重，右两指触铜纹交点，左手维持护源诀 | 固定地点留下待命印；起身后印留在原铜纹，不跟脚走 |
| 改向 | 控镜右腕向内旋，右肘带镜面角度收紧，左手保持另一项已定控制 | 来袭从新面角导入空侧；角色不握一根雷绳 |
| 截断 | 维持两分路的食中指由分开转交剪，掌面反转，松开对应指节 | 一条控制路失活，另一条仍运行；旧碎片保留 |
| 交代理 | 掌中已有小雷鸦成形，食指指向晶轴下令，松开构形指、肩肘回护 | 雷鸦按一次任务独立截击，本体可另布印，不每次挥同款手势 |

结论：动作词相同不一定机制相同，动作词更多也不保证差异；核的是操作改变了哪项状态。这里不规定普通法师每招做全身七段动作，精密小诀照样合法。

## 05 同一折面术、三种负载条件

采用机制：任一空手可立并调一面晶镜；主动控制解除后失去定向，晶料仍有实体与惯性，不自动消失。

条件一，稳定站姿：右指在身前立薄面，腕由掌向外转至斜向，肘短收使镜面避开脸部；来雷触面导向已空出的石缝。左手保持自由，不多写无作用舞动。

条件二，脚下受压下沉：同一右腕控制不放，屈膝接重、肩降低时右肘同步调整，让镜仍留在实际来袭线；镜面不能随胸口下降后仍凭旧位置挡住高路。结束时从新支撑收势，不自动站回开场。

条件三，右腕遭晶环锁住：原右镜失去精调；先有右镜倾斜落下的后果，再用空闲左手另立可用面。新镜不凭换手复活旧碎裂面，右手不能同时继续调角。

结论：同一能力的施法可以因负载改变，不需要换招名证明动作丰富；这组比较的是不同条件，未声称同事实只改摄影。

## 06 快速换诀与时间预算

待修构造：无超常肢体速度设定，却让角色在0.2秒里双臂绕完整大圈、掐三套不同印、跨两步，再放法。细小时间码没有使路径与身体资源成立。

快速短法设计：在0.6秒窗口，当前已举起的右食中指由分开转并拢，拇指短扣锁位，指节弹开，肘随即回护；效果是一次窄雷截击。对手从源端变化提前应对，在途与回收共用时间。该预算仅供本题设计，不承诺生成精确执行。

较复杂成形设计：使用2.4秒，前0.8秒两掌托开既有核，中0.9秒分层并转两片晶面，后0.7秒断开其中一片释放；对手在同期压迫，角色借已有另一晶面抵抗，不无故让双方暂停。新动作没有全部挤进0.2秒。

结论：快速普通施法保留有作用的形态；重要形成可读但须有真实窗口，不能把所有招式统一缩成响指，也不能为显得施法多拖成轮流仪式。

## 07 两个相容体系，各七种机制原型

下表是本轮原创能力设计原型，当前任务可择其相容项，不要求每个角色学会十四招；手势不是既有用户人物设定。

| 雷系原型 | 发动/作用/终态 |
|---|---|
| 雷针截线 | 并指锁位、指节弹开，窄雷针沿当前直线截控制端；离体后不追踪，落空有去处 |
| 触物雷篆 | 两指真实触到晶构留印；只扰动所附晶材供能，印仍在该部位，不万能麻痹全身 |
| 伏雷触发 | 拇指扣既定诀指启动旧印，附着处发生短脉冲；印消耗，未设印不能隔空补出 |
| 近体雷环 | 左掌从腰侧翻开，一次腰平面压力环向外展开；用于解近环/短距阻入，放出后独立耗尽 |
| 定点引雷 | 指定已见地标上方源区，右手引指后骤落；雷击从该源区落在选定点，不是手里甩球 |
| 雷鸦御使 | 掌指塑出有翼/喙/躯体的小雷鸦，指令一次拦截；本体可另动作，代理受损/结束连续 |
| 三点雷域 | 先触地立三固定印，再以双掌合诀接通边界；越过边界才受短脉冲，维持/解除有控制端 |

| 晶系原型 | 发动/作用/终态 |
|---|---|
| 折面导向 | 单手立面并旋腕；只对可被该面作用的来雷改向，角度与离开路成立，破面不复原 |
| 定点晶锁 | 指端圈合后收窄可见目标外的晶环；目标仍可在闭合前离开，无自动无限追踪 |
| 接地晶脊 | 掌心按地、肘向前牵起指定近区材料；脊改变支撑/通路，断块与地损保留 |
| 晶材重排 | 在已控制晶材上分指/回扣，原脊改成阶面或斜片；不是凭空新增另一件材料 |
| 镜蝶截击 | 掌指分出具翼面的小镜蝶并交拦截指令；自主只执行当前任务，不自动无限生长 |
| 三棱拘域 | 三根既立晶棱接通局部边界，控制手改变开闭；角色跨界/作用穿界有区别，不是圆阵贴图 |
| 层瓣晶莲 | 基座已成立后双掌翻叠展开多片晶瓣，层次闭合/承压改角；当前双手被引导占用，破瓣/剩余瓣延续 |

组合练习甲：触物雷篆留下条件，角色先以雷针迫使对手转镜，再触发旧印破对应晶边；两招不能合并成一发更亮雷弹。

组合练习乙：B按地晶脊阻A原落点，随后将同脊重排成斜片承接来雷，A因此改变接重与下一目标；沿用同一材料，不为“多技能”清掉旧地损。

组合练习丙：雷鸦执行独立截击，A同时布一地印；B镜蝶挡雷鸦并受损，本体单手调折面。指令后的独立状态使并行成立，不能默认为四只手。

结论：14原型在触发、作用位置、操作、运行与终态上有实质差异。原型不等于已经生成的动画，也不升级为全角色技能全集。

## 08 同一窄雷、三种反制

共同条件：来雷为既定方向的窄直线，不追踪；B已具有可见范围内晶锁和可调折面。比较作用解法，不改来雷成更慢的攻击。

截起手：B看见A并指，提前圈诀使晶环逼向A当前控制腕；能否在雷离体前闭合须由窗口判，若晚到只能改变下一招，不能取消已在途雷。

偏转：B从源端指向先立镜，腕调到能导入空侧的角；接触以后雷走新路，B不能松手后仍无条件精调多路。

避区：B脚向侧空地让半步，胸肩随脚退出窄雷作用区，原雷继续击空；后招从新支撑发动，不能只写侧脸转头就算整身避开。

结论：起手、在途和接收端是不同反制位置；不全退成盾牌撞爆。三种都可按事实成功或失败，不能为了精彩强行每次挡住并反击。

## 09 控制状态与忙闲手核对

| 构造事实 | 作者结论 |
|---|---|
| B左手持续调镜，却双掌合起来再造莲，旧镜仍一直精准转角 | 不成立：左手控制未交接，须解除/保留实体后果或使用已设自主机制，不能只加“同时” |
| A一次放出近体雷环后收掌，雷环继续短暂展开 | 可成立：本题已定义为放出后独立的一次脉冲，不补不存在的持续供能 |
| A触地留印并离开，后镜扣诀触发原地印 | 可成立：固定地点与待命状态先建立，触发不是再布一枚 |
| A触地留印，当镜立刻自动爆炸，下一镜又称还可引爆 | 不成立：待命、触发与消耗混乱，须选择实际状态 |
| 镜蝶得一次截击指令，本体右掌改地晶，镜蝶仍挡当前来袭 | 可成立：已设自主任务；不能据此再授予任意追踪与无限攻击 |

结论：独立、持续和自主是实际资源条件，字幕/名称不能代替状态继承。

## 10 普通施法的实际覆盖

共同事件：右腕由掌向外转斜，晶面随之倾斜导走同一次雷。既定左手不参与，身体正在接重。

弱观看：始终远景小人，镜头写“指节清晰”，最高亮度雷光盖住手和镜角。文字喊清晰没有让普通施法可辨。

采用观看：先以斜侧中景读身体与镜面/来雷关系；关键腕转用手腕和镜根CU读角度变化，前臂轮廓与袖口留开；接关系景时雷已导走、身体已接到新支撑，镜不再从头立起。也可用一镜接近完成同样读取，不强制三镜。

结论：小招的关键操作获得占幅，原事件不重放；大招、无手部发动与固定任务按其需要取景，不每招拍完整双手教程。

## 11 大型成形期间，另一方仍在施法

条件：B已立晶座，要双掌引导层瓣；A相距四米，有短雷针及触物印。地面与已成瓣是同期状态，形成目标预算2.6秒。

S=0.0–0.8s：B双掌相叠翻转、肩肘向上牵，先展开前层两瓣；A从B起势即并指截向右控制腕，雷先碰到已成前瓣，瓣边一角破裂。不是B开始仪式后A站着等。

S=0.8–1.7s：B右肘回收、腕改变原引导角，让破瓣斜开卸来势，左掌继续托起后层；A改左手触身侧一块既有断晶留印，再离开接触回护。A没有隔着四米触B莲芯。

S=1.7–2.6s：B把剩余瓣接到原晶座，双手仍占用，破角保留；A右指重新锁定尚未闭合的上侧空隙，下一招已有真实射线。未承诺这短针必破大莲，也未让B额外长第三只手攻击。

结论：成形、干扰、调整和后续窗口同时间发展；大招可有动作与读取，普通施法仍参与，不把整场降成轮流展示。

## 12 五秒短场景与相邻合法反例

条件：A南/B北相距2.0米，空石地，西侧有不会碰到两人的空石缝。B一手主动立镜在其身前0.8米；A触物印必须真实触到晶材，近体雷环为腰平面的一次薄脉冲，最大半径2.0米；晶环实体接触腕部后可随其动作受力，不获得脱离后的无限追踪。两人都没有瞬移。一次中全景观察，普通手势和镜边占幅足够；关键触印可在需要时补近景，不靠快切生造交锋。

- S=0.0–0.8s：A右指弹放窄雷针，B从A并指时左腕先转镜，将针导入西空缝。A利用雷已离体、镜边暴露的窗口向北踏进0.4米，距离变1.6米，A距镜边0.8米；B仍面向A，镜未自行移动。
- S=0.8–1.6s：B右指圈合使晶环箍住A右腕并限制旋腕；A先降右肘，把受压腕带到腰侧，再以空闲左掌翻出雷环，晶环在同一平面裂开。右手恢复自由后进入触印任务，左掌释放后的脉冲独立结束；不把已经离体的雷针再放一次。
- S=1.6–2.7s：A右肩前送，在原支撑内前倾，右两指探到镜侧边，短触留篆随即收回；B左腕继续调同镜，使其侧刃朝A刚收走的手位压入。A手已回护，身体在原脚上微让，未绕到B背后。印留在被触镜边，不直接封B全身。
- S=2.7–3.7s：B右掌按地，一条0.15米宽晶脊向A左足前抬起，A右足接重、左脚侧让到西侧0.3米空地再接重，右拇指扣诀触发旧篆；镜的被标边开始失活，B左手再压也不能复活该边。晶脊作为实体仍在原处。
- S=3.7–5.0s：标边短脉冲沿镜面向西裂开，实体冲击画强调镜边定向错层、沿西侧石缝飞出的碎片与同次掌侧受压，退出保持原裂面。A趁镜边失活左掌再展一次腰平面雷环；B解除左镜控制并收下控制臂，屈膝俯身使头肩沉到环面以下，右掌将原晶脊重排成低斜面承受削切。支撑、碎晶与地面沟痕保留，双方接各自收势，没有长距离追击或凭空大招。

作者复核：A一次短进与支撑内前倾为触印创造可达条件，之后横让解决左足前窄晶脊；B面向和镜位置随实际控制变化，不用切镜搬位。雷针、触印、延迟触发、近体脉冲、折面、晶锁和晶材重排各有作用，不全是换色发射。右腕被限制时先用空闲左掌解环，双手资源继承；特定腰平面使B下沉避区有依据，实体晶脊继续承受剩余环力。5秒是设计预算，未验证实际生成时序。

相邻合法反例：用户锁定纯投射单招时可用不同落点/时机丰富，不添七技能；常驻被动或意念瞬发不硬加手诀；固定远距截击按有效作用验速度，不强迫近身；追逐目的仍可保留高速路线；用户要慢仪式则给其有作用的形成期；只有局部摄影授权就不重编能力。
