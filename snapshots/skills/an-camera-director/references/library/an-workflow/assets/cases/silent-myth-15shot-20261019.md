# 用户 15 镜神话分镜校准（2026-10-19）

仅作“镜头作用与分镜程度”的方法校准样本；不是固定模板，剧情、角色与镜头归属用户。普通出稿不加载本页。

## 用户的 15 镜

1. 帕特农神庙的火炬着火。
2. 奶蛙鬼鬼祟祟的脸特写。
3. 中景：奶蛙小心翼翼靠近火炬。
4. 奶蛙盗取火。
5. 奶蛙匆匆逃走。备选覆盖：腿部/跑路镜头、面部急促镜头、怀中摇曳的火苗、场景跟随奶蛙跑出神庙；或第一人称——先看出口，再看火苗，最后看出口。
6. 人间没有火，人们受寒冷侵袭。
7. 突然天上亮火光。
8. 奶蛙携火而来。
9. 人们欢呼，奶蛙微笑。
10. 画面定格奶蛙的眼睛，眼睛里有火苗。
11. 陡然转场：超广角低角度，诸神在天空中的阴影，电闪雷劈。
12. 没有火的火炬，诸神震怒。
13. 诸神讨伐，奶蛙一人挡下。
14. 奶蛙遭到巨鹰啄食。
15. 悲壮镜头定格。

## 每镜作用

| # | 作用 | 手法与为什么有效 |
|---|---|---|
| 1 | 建立火源/世界 | 先让观众知道“火是神的”，盗才有分量；火是唯一暖色 |
| 2 | 人物/基调 | 近景读眼睛和嘴；“偷”的性格与紧张，先给人物再给动作 |
| 3 | 空间/接近 | 中景读人与火的尺度、脚步与影子；不急着偷 |
| 4 | 动作/转折 | 插入或微距：手、火炬、火苗；盗的瞬间 |
| 5 | 速度/赌注/空间 | 覆盖菜单：腿=速度，脸=恐惧，火苗=赌注，跟随=空间，POV=选择；**选 3 个，不全都用** |
| 6 | 需要/对比 | 冷色广角、空火圈、缩着的人；与神殿的暖形成对比 |
| 7 | 转折/希望 | 光先到、人抬头；低角度，暖光落在脸上 |
| 8 | 到达/答案 | 中景/广角，火在怀里；人与火的尺度 |
| 9 | 情绪峰值 | 暖光、人脸、奶蛙的笑；可爱的脸与后面的惩罚形成反差 |
| 10 | 转场/物件桥 | 微距，瞳孔里的火；**匹配切**到神的火/闪电 |
| 11 | 调性转折/威胁 | 硬切、超广角低角度、神的阴影压天；**尺度与权力**，不给脸 |
| 12 | 证据/反应 | 插入空火炬、神的手与冷杯；**不用台词**，盗火被看见 |
| 13 | 角色/主动性 | 奶蛙挡在人类前面、举起火炬/双臂；**它选择**，不是被抓 |
| 14 | 惩罚/身体 | 巨鹰（或巨影+真鹰）、崖、链、喙；**尺度**，不给内脏 |
| 15 | 落点 | 近景仰拍、冷光斜切、脸与眼；**不是大远景** |

## 可迁移的方法

1. **一个功能一镜**：建立、人物、接近、动作、逃走、需要、转折、到达、峰值、物件桥、调性切、证据、主动性、惩罚、落点。功能不重复，镜数由功能决定，不按“每段一张图”。
2. **50 秒 12–18 镜是正常的**：短镜 2–3 秒给插入/动作，长镜 3–5 秒给眼睛/定格；不要平均分配。
3. **逃走用覆盖菜单**：腿/脸/火/跟随/POV 选 2–3 个；全用会碎，只用一个会薄。
4. **两座桥**：眼中火（暖→神的火/闪电）与空火炬（神发现盗火）；物件承担转场与证据，不靠台词。
5. **对比切**：神殿暖 → 人间冷 → 天光亮 → 欢呼暖 → 硬切神界冷/闪电；情绪由切点承担。
6. **主角要有一拍自己选择**：一人挡下，惩罚才是“代价”，不是“遭遇”。
7. **最后落幅给脸**：近景仰拍、冷光斜切；全景只负责尺度。
8. **样本不是模板**：不复制用户的剧情、角色与具体镜头；只迁移“功能—覆盖—切点—落点”的方法。
