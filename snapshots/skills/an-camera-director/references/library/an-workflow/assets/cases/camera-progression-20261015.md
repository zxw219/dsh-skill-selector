# 摄影推进：六项维护纸面演练

本文件是维护用例，非本轮交付给用户的生产提示词；全部为作者原创文字预演。作者逐项核读观看收益、连续路径、占幅与边界，没有独立模型试写、真实片或三维相机测试。各例的秒数、阶段与机位不成为全局模板。

## 1. 24秒奔向坐者：同一事实的弱基线与改进

锁定：A从人群离开，沿开阔花径奔向树下B，越来越快，最后制动屈膝伸手；24秒真连续镜头，不加台词、障碍或新剧情。风格要求为艺术化且景别有发展。实拍设备未指定，本例采用有净空的连续虚拟相机；人物通路旁留出相机外侧路线。

弱基线：斜前方领拍→六秒浅弧转侧→八秒等大侧跟→树下下降。读取长期重复“A在跑”，丰富观看未兑现；侧跟本身不是错误。

改进候选：

| 区间 | 实际画面与相机关系 | 观看交接与连续出口 |
|---|---|---|
| 0–3秒 | 斜前中景领拍，A离开人群；相机外侧退移 | 群体从背景缩小，A成为独立主体；相机已在A前外侧 |
| 3–6秒 | 相机退速略低，A自然追近至胸上近景，留出前行空间 | 读到目光与加快的呼吸；不是换个角度仍拍全身。两者仍有安全间距 |
| 6–11秒 | 相机沿外侧弧由领先经过侧面到侧后，同时适度升高、向前方转向，逐渐退开为全景 | A由近到远，树与B在前方显露，花径连接两端；路径绕A外侧，不穿身或瞬间反打 |
| 11–16秒 | 从侧后沿外侧通路降回较低的全身跟随，前景快速通过，树持续变大 | 由距离转交身体投入与前进速度，保留已知目标；此段不是毫无作用的跑姿插入 |
| 16–20秒 | 相机在外侧加速超过A，连续转为斜前关系，退向树旁预先选好的机位 | A脸侧重新可读，目标临近；超越有实际净空与相对速度，不靠甩镜藏跳位 |
| 20–24秒 | 机位先减速，让A进入B所在构图，再随屈膝下降至坐姿眼高 | 从单人到双人、距离到伸手，手在两人之间清楚可见；持续到动作读清 |

作者复核：每阶段交接实际裁切/主次，不以段数或六种运动作通过依据；同一焦段也能通过距离形成上述景别。中段相机绕外侧，后段在外侧追过，方向变化连续可见。仍需真实片检查惯性、阅读时长和美感。

## 2. 不同题材迁移：18秒仓库搜寻，人物不奔跑

锁定：A沿货架寻找失物，听到B呼唤，最终发现B手中拿着该物。要求悬念与发现，一镜到底。

作者采用：从A肩后近景沿货架同行，仅见局部遮挡→在A停步倾听时相机继续沿架端横移，空隙逐渐打开，B与物件进入远层→短暂深层关系读取后靠近A的脸侧，让接收可读→A向B走近，同框读到物件归属。没套奔跑例的升高/超越，也没让摇镜看穿货架。读取由寻找、声源到发现，路径经架端成立。

## 3. 固定静音反例：20秒等候

锁定机位、朝向与视场。A等在空门边，B到来，A让开；不增加声音。

作者采用稳定双人可进入的中全景：A与空门形成负空间→B由远入近占据空处→A侧让，门内通路打开。维持同一景别，观看关系随画内调度发展。不得为“每段变化”偷偷推近、转焦或切镜。结果：合法保持，不因镜头数量少而判错。

## 4. 等大侧跟反例：8秒步态展示

任务只要求看清奔跑步态、披风负载与地标通过，没有脸部反应或丰富视点要求。作者选择同侧等速全身跟移，保留脚部接重和真实背景视差。不加贴脸、航升、环绕。结果：单一观察关系完成任务，不能迁移例1的返工结论。

## 5. 真实切镜：6秒递钥匙

锁定：A伸右手递钥匙，B伸左手接住，A松手。选择关系中景→局部→关系中景。第一镜以两人之间的手部为注意落点，在B尚未握牢前切局部；局部接B手指合拢而不是重演A伸手，t=3.2秒B握稳后A松开；返回关系景时A手已收、钥匙留B手。占幅变化突出接触，身份、手位与相位承接，不加遮挡、甩镜或叠化充当“高级衔接”。

## 6. 丰富度与空间边界反例

条件：长廊一侧是实体墙，A前行，B在尽头；用户锁定真一镜、保持原人物行动。候选“相机从A身后瞬间绕到墙内再拍正脸”不可达，即使景别变化丰富也不采用。作者改选开放侧的可达弧线，或在净空不足时用人物进入机位改变占幅；不新增墙洞、人物停步或隐藏剪辑。反之，开阔地存在可见连续过轴时不以“永远同侧”禁止它。结果：保留观看要求，同时修相机实际路径。

## 维护审阅结论

例1抓住本轮重复陪跑缺口；例2检验没有搬运跑步镜序；例3、4保护固定与侧跟；例5核真实前后画面与动作相位；例6核丰富要求不覆盖空间与一镜约束。结论仅为作者纸面情境审阅；这六例不提供导演能力评分或生成成功率。
