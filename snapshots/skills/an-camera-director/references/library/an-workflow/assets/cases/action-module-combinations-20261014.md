# 动作模块组合：三条原创采用链

对应[模块库](../../../combat-action-design/references/action-module-bank.md)。内部文字练习，不是用户原片新版提示词。以下不锁通用时长、出手数或镜数；实际创作按当前项目选可读段并回填原An格式。模块标签用于检查实际采用，正文不输出标签。

## 一：空手近身，不只左右挥拳

设定：成年甲乙空手，在可正常接重的平整庭院争通道；甲抢入，乙阻拦。身体接触与受力可用，不新增法术。采用H1、H2、G1、H4、A1，结果可以受挡或落空。

甲右拳由胸侧送入，乙左前臂截住；甲右臂收肘，左手从侧线逼乙回护，右肘随贴近短送。乙右掌推住甲肩，肘线受扰，甲没有硬算命中。甲左手接到乙回护的左臂，右臂护乙的右手，支撑脚接重，右膝向乙近距腹线进入；乙右前臂下压并退髋，使膝只形成短接触压力。

甲折回右腿，右脚向乙臂外侧接地，屈膝将胯侧送入相容承力位置；左手现有臂部接触随转肩牵其重量。乙撤近脚并推甲肩，托转还未承足重量就受阻。甲以右脚承重，左腿低弧追乙刚换出的近腿；乙撤脚稍迟，这次接触使支撑偏斜，侧倒时用手臂接地。甲收左腿落向外侧，左手原控制随转移松开。乙倒地仍用可用腿从低位蹬甲的接近方向，甲在短接触已卸开的空侧顺受力降身肩滚；乙翻身收腿到支撑位。甲滚势接脚、抬臂回护再起时，乙已半起抢回通道方向，争夺继续。

采用差异：直线拳/侧线逼防与折肘，控上路接膝，落脚入胯转控，低扫改变新支撑，倒地低腿回应，受压卸开后滚与双方再起。摔转受阻而低扫有接触结果，不是全部招式一律命中或一律落空。观察以斜侧保留接触与支撑；取膝或手部局部后，邻镜接收腿和对手换脚，不靠换镜冒充新动作。

作者复核：右腿膝后确实折回再落脚，低扫改用左腿；左腿扫后回收落地，才能接乙地面蹬来的压力。左手控臂在滚出前已解除；乙倒地先以可用腿回应，再翻身收腿半起，不能还倒着却突然站立追击。入胯不是自动摔成，倒地也不把乙冻结为失能。这个过程仍是文字推演，没有认证真人安全、速度或模型执行。

## 二：长枪对长刀，纯兵器也能变距离

设定：甲双手持同一长枪，乙双手持长刀，庭院净空可容杆端转移，双方争门前线；不加拳腿、御器或飞行。采用W2、W1、W3的相容兵器结构，柄部使用枪杆近端，不另造短兵。

甲从最后一步接重前送枪尖，乙把刀线压向枪前段并继续贴入。甲让前端随压下沉，双手沿杆调整握持把长距收短，尾端从身体外侧转到乙追入的刀线；乙收短斩路，追甲握杆处。甲以杆身斜导当次来刃，接触滑离后近端沿短路顶向乙可达胸线；乙转胸退肩，使杆端从其旧胸位擦过。

甲不把杆端悬停，后手带杆回收、前手沿杆复位，枪前端借已恢复的体外净空低位斜挑。乙退一步举刀接挑，甲枪前端被导向外侧；甲顺导收肘释放接触，转支撑将前端从新的内线送回。乙向门侧追甲新支撑，以短刀路争其近线；甲再收杆护住，双方已由长距到贴入、由杆端近用回到前端压线，没有回开场。

采用差异：长距前送、被压收短、杆身导离、近端短顶、枪前端低挑、脱开内线再送、再收短防线。过程靠同一兵器长度与接触改变，不能用数次同名格挡冒充模块多。

作者复核：尾端/近端/前端均属于同一实体杆；两手只持杆或沿杆调整，不同时撑地/结诀。大杆转移走体外净空，乙仍追握持与支撑。各次“被导开”结束后才改自由路线；纯兵器不强塞肘膝。观察交出至少一次长短距离变化及杆端位置，局部切回不复制起手。

## 三：一把飞剑对近战与射手，御器和身法共用状态

设定：甲一柄实体短剑，右手握持；能力只增加右手持续剑诀操控这一柄离手剑并召回，甲无飞行/瞬移。乙持长杖在近距追压，丙持弓在外侧找射线。平地有可用斜侧通路，没有临时障碍。采用W1、F3、H4、A1、W4、W3的相容部分；拳腿在本例允许。

甲手持剑与乙杖短接，顺乙外导收刃滑离，沿新内线迫乙回杖；两器已经脱开，甲才将剑离手送到乙杖外侧，右手转为剑诀。本体同期沿另一可达侧路靠近，乙拨飞剑并转杖追甲身体。甲右手仍控剑，支撑脚接重、另一腿低扫乙当前新落脚；乙移重撤目标腿，甲扫空后收腿落地，没有把乙留在旧位置。

丙取得一条不经过乙的射线放箭；甲用不承担控器的左侧身体接降身肩滚，右手剑诀不承担撑地，箭越过旧肩位。乙已拨开飞剑，原牵制失效，趁甲滚出追再起；丙重新搭箭并改向甲新出口。甲右手转为召回，剑沿无遮挡外侧路线返到握持位置；左脚接地、左手短支撑上身，右手握剑后才短护乙追来的杖端。

甲随杖端导离贴入，用剑柄短撞乙握杖前臂，乙抽杖推身回应，甲的柄击未形成长期控制。丙的新瞄准因甲乙贴身叠位暂失净空，丙继续横移；甲剑回收，乙再压近线，丙新的射线正在形成，未决交会中结束。

采用差异：手持脱刃内线、单剑离手牵防与本体分路、低腿追新支撑、避箭肩滚、召回接握、短柄接敌。飞剑不是身体动作的装饰，甲也没有一把在手一把在外；乙丙在所有相位都继续自己的压力或恢复。

作者复核：收腿落脚先于滚动；右手控剑时只用相容的肩背滚动，不拿控器手撑地。乙拨器后牵制立即失效，返剑之前甲不能用剑格杖；左手支撑与右手接握分担，握稳才近护。丙临时失净空只因当时身体叠位，继续横移后威胁恢复。弓手的搭箭不等于无因等待；不能将本例节奏假称已正常播放验证。

## 仍需实际成片校准

三条链由作者检查模块是否真正兑现、是否靠复位连接、肢体/实体占用、同期目标与出口，以及纯兵器/单器物的反例。它们证明文字中可以采用不同过程，不能证明生成会执行这些模块。新成片仍需对照采用稿，检查动作遗漏、降成重复招、观察裁切或实际接触失效。
