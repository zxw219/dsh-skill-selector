# 独立文本前向试用方案

在读取任何试用正文前冻结。本轮测试仅文本，不生成媒体。

## 同题有限对照

旧版：修改前ZIP中提取的技能及来源快照。新版：本轮已安装修订来源。两个互不通信的创作者只得到同一个原始新任务及其技能入口，未得到故障诊断、修补建议、比较结果或标准答案。

原始任务：用An声画分栏写30秒东方幻想双人交锋，正在运转的山谷水车栈道；成年女剑修用单剑和沿木石表面行进的霜脉，成年男戟修用长戟和可短暂塑形的风压；争通路，未分胜负；高速高频、自然丰富动作、双方真正起效技能、震撼特效、动作衔接、无对白。

审阅者只得到任务、匿名原始成品与下列维度，不给版本身份、设计者解释或预期胜者。

| 维度 | 审阅问题 |
|---|---|
| 完整身体运动 | 身体路线、转轴、高低、支撑、接重与兵器是否有可读差别，是否只是列招名或局部挥打 |
| 对抗发展 | 是否反复同一压进/挡退；双方解法与同刻行动是否改变下一条件；不强制平均出手 |
| 技能采用 | 两项既定能力是否都实际起效并改变行动，而非仅设定/装饰；作用是否仍守机制 |
| 震撼主峰 | 主形/范围/负载及人物关系是否在过程可读，是否靠闪白和形容词跳过主作用 |
| 可行与衔接 | 身体、兵器、控制、距离、落点和时长是否有关键矛盾，观看是否裁掉必要相位 |
| 用户边界 | 片长、格式、单剑/长戟、原能力、场地、结局和无对白是否保留 |

先写具体正文证据、缺项和不确定性，再比较。不得以招数、字数、镜数或负片数量直接判优。

## 未泄露解法的迁移与边界

迁移：18秒二维塔楼，长杖者仅持续风流、双刃者无能力，丰富持械身体动作、风流贯穿、有一次震撼但不毁塔，杖者最终仍被压制，未分胜负，无对白。

相邻边界：只改摄影，12秒固定机位一镜到底、普通剑客持续剑上角力，乙侧移卸力不脱开，不能新增动作、术法、冲击帧、武器与胜负，简短自然段。

迁移创作者未得本轮修改建议或前例结果。审阅不把“长期压制”或“固定角力”按频率/换手配额判错，检查实际动作与原任务。

## 结论限度

每版本一例、另加一迁移和一边界，样本很小且存在创作随机性；支持定位文本采用和明显回退，不支持稳定成功率、所有战斗泛化或成片美感结论。新稿有缺陷就保留原稿及独立结论，修源后用新任务核受影响项；不能教会同一例后改称自主采用。
