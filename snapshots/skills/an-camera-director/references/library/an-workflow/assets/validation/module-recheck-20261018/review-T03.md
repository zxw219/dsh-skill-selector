# T03 独立文本审阅

结论：文本层面可交付。

产出为原三个镜头对应的sound三段，保留两句原词、甲2.0—6.0秒和乙8.6—10.8秒的起止，以及4.6—5.4秒的一次汽笛。没有改变镜头、动作、人物关系或总时长，没有增加配乐、对白或新声源。

可交付的原句证据：

- 甲的跨镜发声是同一次：“本镜2.0—4.0秒说到‘钥匙在蓝色抽屉里，’”，下一段“4.0秒从上一镜同一次发声的剩余分句接入”，继续“先不要开门。”到6.0秒。明确“不停顿重起、不重读前半句”，修复镜2整句重播。
- 对白和汽笛有可执行的主次：“4.6—5.4秒保留灶台水壶的一次短汽笛，起止不移”“汽笛清楚可辨但处于对白之后”，并降低重叠时汽笛的混音存在感，保护“不要开门”的可懂度。不靠删除汽笛或挪动对白解决冲突。
- 空间与余响保持连续：“声源仍在桌边，画面切到乙不会把甲的声音移到乙嘴边”；开放同室不做隔墙闷滤。汽笛停止后仅留短余响，甲句尾的室内余响不重复词尾。
- 镜3保留乙在画外、低声、原灶台方向的发声：“8.6秒乙……低声说‘我等你回来。’，10.8秒说完”，钥匙碰触退到次层；10.9秒甲抬眼“不加重音或新声源”，动作仍按原画面进行。

确定矛盾：未发现。对第一句在4秒切点处分配分句，是原定2—6秒发声窗口内的声音执行选择；请求没有锁定更细的字词时间，因此不构成擅改句子起止。钥匙轻响对应原画面收拾钥匙，未另外增加动作声源。

生成执行风险：仍需实际试听确认汽笛可辨且不掩盖否定词、跨镜发声无重读或截断；文字已明确所需混音关系与连续性。这是声音制作结果待验，不是文本自相矛盾。

个人偏好：具体分贝、声像宽度或混响秒数并非本请求的强制参数，现有相对音量、空间和衰减描述足以执行，不应因未给数值要求重写。
