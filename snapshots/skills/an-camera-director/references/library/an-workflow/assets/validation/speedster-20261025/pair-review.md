# 匿名样本 H / J：独立配对审阅

审阅范围：仅以原始任务与匿名文本 H、J 为依据；未读源技能、研究、版本映射、作者解释或其他代理审阅。J 的首读意见另保存在 review-J.md。本份先列证据，再作比较；不以字数、镜数、数值倍率直接判优。

## H 的证据与逐项判断

- **开场速度与普通反应分离。** H 在 0.3 秒起动、0.4 秒已经贴到守卫臂内侧；0.6 秒取物受阻时，守卫右掌是继续开场已有的压腰动作，头部才转向速度者先前掠过的位置。这里没有要求普通守卫在看清极速换位后重新瞄准。
- **取物失败有实体原因。** 钥匙被手甲压住；速度者控制腕肘并使其短暂露出，守卫收肩遮挡；随后衣摆被真实抓住、肩撞和勾踝迫使守卫补步。机械臂扫入取物线又迫使速度者低身走真实净空。并未直接穿过手甲或机械臂取钥匙。
- **主观段改变完成顺序。** 8.6 秒起，守卫同一次左肘仍在推进，速度者先送开肘线、移到右腰、掀开护腰掌、压扣取钥匙并撤离；守卫到 12.8 秒后的正常世界才扫完肘、拍空腰扣并跪地。速度因此创造了守卫原动作完成前的连续操作窗口。
- **接触状态有兑现。** 右手甲被掀离扣位、簧片张开及回弹、守卫上臂受肩顶而躯干偏转、右跟离地，都在正常世界继续发展。正文还明确不新增一记不可见重击解释倒地。
- **时间与装置连续。** 0–8.6 与 12.8–18 为正常世界，8.6–12.8 为短暂主观读取。既有肘击、雨滴、机械臂及远门均缓进，并借同一雨滴、臂端位置和脚的落点接回。下降闸门、400 米站台与纵向奔跑在 H 自身内部一致。
- **结尾与格式。** 18.0 秒钥匙在右拳，距门槛约两米，仍未通过下降门底；声画分项齐全、无对白。18.0 秒切黑结束可按结束边界理解，文本未另列占时黑场，不能直接判超时。

由这些证据，**H 未出现可直接坐实的硬约束违例**。其实质近战、实体取物及跨时率后果都成立。

## H 的具体风险

1. **主观段以前，速度者对普通反应的支配没有持续建立。** 从 2.2 秒腕肘控制，到 2.6 秒守卫收肩抓衣，再到 5.7 秒避臂、6.4 秒穿出后等待守卫收回撑手转腰出肘，直到 8.6 秒才利用差速处理这记肘击，读起来容易像普通速度的一连串互相反制。尤其 6.4–8.2 秒，速度者已脱离机械臂，守卫有时间重新组织另一侧肘击，文本没有明显交代速度者为何不能在该动作形成前处理护腰掌。它没有明文赋予守卫同速，也不要求速度者每次都最大速度；这是核心体验的动机和节奏风险。

2. **主观段中水珠的速度归属略含糊。** “沿触碰方向散开，脱离后相对运动减慢”可能只想表达从速度者身边离开后不再被持续带动；但若画成一离体就自动恢复与未触碰雨滴相同的缓慢状态，会把观看时率误写成物体所属类别。相同时率中，受冲量后的水珠仍须继承得到的速度，再由空气阻力等因素改变；不能仅因失去接触换一套时钟。没有具体轨迹或数值，尚不足以判物理硬错。

3. **近身左右侧切换有一定构图负担。** 正文从右后侧接守卫左肘，再绕肘到右腰，同时处理右手甲、右上臂与脚的支撑。可执行，但小半径摄影弧移须让观众确认究竟绕过哪条实体手臂，避免把“肘下外缘”拍成穿过双臂。需要检查构图兑现，而非凭术语视为已解决。

## 配对结论

**没有充分证据判定其中一份全面优于另一份。** J 在速度如何抓住护腰动作的未完成窗口上较集中，H 在移开实体手甲、取物细节及恢复正常世界后的受力后果上较具体。若优先检验“速度是否重排近身交锋”，J 有小幅优势；若优先检验“手甲怎样真正让路、取物怎样接上后果”，H 有小幅优势。两者均保留普通反应与超速主体的明确区别，但都仍存在以常规节奏展开近战、再用主观段集中展示能力的倾向，H 更突出。

上述差异来自可见因果及状态接续，不来自匿名身份、篇幅、镜头数量或倍率大小。
