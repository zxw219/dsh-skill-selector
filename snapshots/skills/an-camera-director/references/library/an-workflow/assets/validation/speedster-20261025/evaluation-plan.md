# 速度型能力战文本验证

主代理在读取试用成品前固定任务与维度。旧版使用本轮冻结的before/skills，新版使用本轮已安装来源；创作者仅获技能与原始任务，不获诊断、方案、其他稿或预期胜者。

同题：18秒雨夜货运站台，成年速度者抢普通装甲守卫腰间钥匙；只有超常移动/感知/身体动作，无瞬移/穿墙/时停/放电。普通守卫保持普通反应，开场前已经运行的横扫机械臂与逐步闭合闸门继续。要速度型战斗与实质近身，短暂主观时间后回正常世界，结尾取到钥匙但尚需过闸，无对白，An声画分项。

迁移：14秒干燥展馆中两个同级速度者争夺唯一金属环，柱间/窄台路线；纯外部正常世界观察，无慢镜/时停/电弧/分身/瞬移，固定外部机位一镜到底，结尾未分胜负。给出实质可辨的拦截/变向/接触和结果，而非两条光线跑圈。

边界：只优化摄影，普通人6秒高速拳脚，动作与时间锁定，不新增超级速度/主观慢世界/电光；一段自然说明即可。

审阅维度：速度是否改变行动机会/执行次序；真身路线和近身接触是否存在；成片/世界进程能否分清；普通人与同级对手是否守实际反应能力；跨时率是否接同次对象状态；效果有归属；用户能力/时长/格式/拍法/胜负是否保持。按具体缺项与证据判断，不以速度词/镜数/倍率/动作数选优。

比较用匿名原稿，审阅者不读版本映射、来源修改或作者解释。旧新各一例，加一迁移与一边界只支持有限文本采用证据；不证明稳定改进、真实速度、美感或生成成功。原稿冻结，不用反馈修改同题后称无提示成功。
