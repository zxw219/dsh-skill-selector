# T01 独立文本审阅

结论：文本层面可交付。

请求锁定的12秒、9:16、一镜到底和静音均被保留。产出只扩写摄影，未添加人物动作、事件、道具或声源，也没有把交接、甲走向后门、回头及乙小幅举杯改写为新动作。摄影职责覆盖起幅、中段、落幅、焦点与速度变化。

可交付的原句证据：

- 交接信息有实际取景与遮挡安排：“两人的脸侧、甲右手、乙左手和整只杯子同时入画”“甲的躯干不挡乙握杯的手”，并明确“乙握住杯身后减速停稳，让甲确认、松手的完整先后连续可读”。没有用动作替换来补摄影问题。
- 中段既安排了路径，也保留分离关系：“相机继续沿右半侧斜向庭院入口退开”“后退总行程控制在约0.8米内，不追到甲身后”；构图明确为“乙与她手中的杯留在左侧近层，甲沿画面中部向上方门口变小”。速度由加快到逐步减速，8秒前完成构图。
- 落幅没有丢掉关系：“门、空通路、乙与杯同框”，并用“杯口与既有柜台水平边保持分离”帮助读取约3厘米的举杯。焦点由门边甲转回乙和杯，同时保留甲的回望方向，最后持续到12秒。

确定矛盾：未发现。

生成执行风险：狭长庭院内，双人中近景展开到前后两层关系，对起始纵深位置和末段景深有实际要求；原稿已给出约24mm视场、机高、距手约1.3米、退移行程及景深安排，没有发现必然越出4米×6米空间的描述。实际生成仍需核对遮挡、3厘米抬杯的可见度及转焦结果。这属于成片验证范围，不能据此认定文本失败。

个人偏好：焦点最终停乙或停甲均可形成不同情绪，但请求要求交接和分离关系可读，并未强制最后只拍甲。本稿落在乙与远层甲的同框关系是合理选择，不应因偏好改判。
