# 修订后的独立试用范围

先记录真实失败：用户测试两角色30秒战斗，输出把白狐定义为局部霜冻/霜焰近战，把角冠精灵定义为已有活根/叶刃，将场地定义为三米根拱的根厅。修稿继续围绕木盾、脚位和局部破根，没有重设这些助手补设。用户随后明确列出高频、高速、超大型技能、张力运镜、动作多样、快节奏运镜切镜和流畅震撼技能；不得声称此前所有阶段都已明确点名超大型。现有规则并未缺少速度、规模和连续性区分，最早失效是要求到角色机制的采用，随后被局部修复验收放行。

冷启动试用：独立创作者只获得本次实际两张图片、技能位置、30秒9:16，以及用户最新列出的质量要求；不获得失败稿、上述诊断、拟修机制、预期胜者或审阅反馈。原始输出保存为 candidate.txt，不由根代理修改。

独立审阅：只给原任务、图片和原始成稿，不给技能源、修复方案或作者自述。分别依据正文核对角色辨识与战法差异、有效频率与速度、超大型技能的尺度/作用/反制、动作作用差异、摄影压力与切接，指出最弱关键段及确定错误/风险/风格区别。允许不通过；不要求因镜数/时长分配或出现某术语就通过。

边界：创作者交稿后另答“用户明确锁定只能接触冻结且禁止新增能力，只授权改摄影”如何处理，不让新规则普遍扩大权限。此项决策测试不替代创作测试。

本轮仅有一份独立文本试用，不与旧稿进行随机性受控对照，不生成视频；不能证明稳定能力提升。
