# 匿名分镜独立审阅

本报告只依据原任务、共同质量目标与三稿实际正文，不以作者意图补足动作，不把文字方案判为成片验收。引用均采用稿名、镜头与时间。

## 总体结论

稿甲、稿乙在文本层面均覆盖18秒交战任务的核心事实，未发现足以直接判定违背原任务的硬矛盾；两稿可以并列，现有证据不足以判定某一稿总体更优。稿甲较便于追踪地标、手部控制与最后的三点受力；稿乙较突出近身躲避、位置转换和由前一击制造后续卡位条件。它们各有需要进一步落实的空间与执行接口。

稿丙独立满足固定机位任务的边界。其压力来自同框内的双手占用、抵抗和绕过封锁，不依赖镜头运动。末段角力能否持续发展，需要视频验证；不能仅因机位固定或角力持续就判作停机。

## 稿甲：成立之处与具体风险

**构图与摄影有任务作用。** 镜头1把印章置于近前景，让枪尖与印章之间“尚未闭合的距离”成为争夺的计时器；爪端从上层压入，体量与人的手路同时可读。镜头2随被撞偏的枪杆横移，落幅保留B的落脚与印章距离，运动结果与抢位关联。镜头4随B沉肩下降，显出先已设定的V形缝与凹口，摄影不是独立展示一种技法。镜头7从印章退开、抬升，把取物目标、两人的手部占用和兽爪负载重新放在同一关系里。

**控制代价和双方选择有可见因果。** 镜头3，5.5秒A撤右手取印，兽爪随即停止；6.0秒B攻击取物手路，A缩手并于6.7秒恢复导引。B利用的是对手的资源空缺，未新增能力。镜头5的A下压，是把B的低姿理解为可压制的机会；B侧挪并借下压力入缝。镜头7两人瞥向印章又回到受力任务，交代了“想拿但不能腾手”的未决状态。

**欠写／执行风险一：卡位的决定性动作出现两层。** 镜头5，11.6秒已经写“厚石掌被缝壁夹住”；镜头6，13.5秒再写“第一次被硬生生卡住”。可以合理读成先暂时楔紧、再被枪锁死，尚不构成硬矛盾。但前一句完成度较强，可能使观众把长枪看成事后补压，削弱B用枪决定结局的作用。实际执行必须看见加枪前后回抽能力的差别，而不能只用两次石粉和磨响区分。

**欠写／执行风险二：三点接触有说明，三维几何仍需落实。** 镜头6明确给出“枪尖顶住石唇下缘、杆身压住爪腕、B双手压着枪尾”，是可检查的受力意图。但枪尖位于东侧石唇，B又在东南侧；枪杆怎样斜穿爪腕、枪尖是否确实被上唇扣住、手端是否能在此位置下压，需要同一真实角度证明。不能仅因三个接触点都写到了，就判定支点和力矩已经成立；现有文字也不足以反证其必然不成立。

**欠写／执行风险三：末镜同时清楚的层次较多。** 镜头7要求近前景印章清晰，同时读到A双手、B压枪、枪爪接点、脚跟与断缘。其作用明确，但2.7秒内的短退抬升、人物遮挡与景深需要协调；若只保住印章和兽肩，结尾的资源限制会退回文字说明。

## 稿乙：成立之处与具体风险

**近距离威胁与路线变化相互推动。** 镜头1由A导引手起幅，逐步把B、石兽和印章纳入，建立谁控制危险。镜头4跟随B下潜，巨爪逼近上沿，再回到落点；镜头5换俯斜关系景，展示B已跨到北侧、印章仍在南侧，以及可向东退让的位置。这个视角切换负责解释诱导路线，不应因换机位本身加分或扣分。

**同期行动与诱导成立。** 镜头2，A失去导引时B持续占住取印线路，逼A退开；镜头3，B准备腾左手取物，A恢复导引，B立即回握并撤步，没有让B站着等技能。镜头4，9.5秒砸裂南唇，B在兽爪回收期间跨缝；镜头5再用前脚和身体的抢入倾向诱出落爪，随后撤出落线。前一击的环境变化成为后一击的解法，B的主动选择比单纯躲闪更明确。

**欠写／执行风险一：开镜信息密度高。** 镜头1的3秒要完成双手近景、脸侧、手臂空隙中的B、扩大半径后退及关系落幅，同时容纳横掠、缩步、斜移、出枪和A两步进位。各项不是无因堆砌，但观众需要看到的有效信息多；若运镜占去太多时间，A持续导引或B改线会只剩瞬间轮廓。此处是执行负担，不能据此认定正常速度必然做不完。

**欠写／执行风险二：落点的失联不能吞掉关键几何。** 镜头4写“观察短暂落后半拍，随即补摇找回B与落点”，有贴近险情的明确意图。此时南唇的崩裂及“向下内扣的断面”又是镜头6卡趾的前提。如果补摇只找回人，没有读清破裂形状，最后的钩扣和楔枪会显得靠特写临时补造。镜头5保留断面能补充空间，但不能自动替代因果的可见性。

**欠写／执行风险三：A从下压改为拔爪的入口略省。** 镜头5写A“向前一送”，让前爪“斜向南压”；镜头6在15.3秒附近写A“仍以双手上提并转向”。A发现受困后改为上提是合理反应，但改向的触发和开始时刻没有明确落笔，“仍”缺少紧邻的前态。不是能力或结尾矛盾；风险是同一次卡位中，兽爪的受力何时由下压变为上拔，可能不够可读。

**欠写／执行风险四：锁趾依赖较具体的局部形状。** 镜头6依赖“弯钩状趾尖”、破裂南唇下方、枪刃宽肩、北唇和回旋空隙共同锁止。正文已写出各部件及作用，因此不能指为完全没有卡位机制；但中趾的进入路径和枪刃的楔入方向需要清楚展示。只拍到枪杆弯曲与B吃力，无法证明这套锁止真正成立。石兽尺寸更大，也增加枪与石唇承担负载的表现难度；尺寸本身不能替代压迫感，也不单独构成物理硬矛盾。

## 稿丙：固定摄影边界与动作可达性

**固定机位有具体构图，不是只有禁令。** 稿丙给出案长、案宽、布包离端部距离、刀客与空手者的两侧位置，以及斜案沿、交会空处和两条手臂的分离轮廓。35mm、1.6米高和略俯视与全身取景服务于看见手路和脚下接重。正文未要求推拉、变焦或剪辑，也未以术语替代全部取景关系。

**双手占用与身体任务连续。** 0—3秒，刀客左手取包被更近的对手打断，改用右刀截手；空手者撤右手、左掌压持刀前臂，再以右掌推胸，逼刀客左臂由取包改为抵挡。3—7秒，空手者右手由推胸改撑案接重，左手仍压原前臂；刀客把刀面转平压案，是主动寻找支撑。7—12秒，空手者放开撑案手，从封锁旁伸向布包，刀客压低左肘继续限制。双方都在改变解决问题的方式，没有凭空多出一只手。

**欠写／执行风险一：固定取景需承受遮挡变化。** 起幅对两人的脸侧、刀手、伸手给出了分离要求，但“全身”入框不等于远侧人物的下肢不会被厚石案挡住。末段空手者沉肩钻过横臂时，持刀前臂、刀面和取包手也可能叠在同一案角。机位距离和斜角要在全程成立；如果最后两三厘米被身体或案沿挡住，不能靠临时切镜补救。

**欠写／执行风险二：最后5秒依赖持续角力的细节。** “一点点向前”已有刀客压肘挤窄空隙、空手者肩部绷紧作为反作用，不是没有对手响应的慢伸手。不过放开撑案的右手后，空手者怎样由双脚接住前压，且维持左手对刀臂的压力，写得较概括。实际动作必须出现重心调整、接重和空隙变化，才不会把7—12秒演成靠静止摆姿拖长的结尾。此为执行风险，不能直接判定正文已出现停手对峙。

刀面平压石案、空手者只压前臂而不抓刃、结尾停在触包之前，都是符合原任务的合理选择；没有理由要求追加刀花、特技或镜头变化。

## 停顿、复位与可复制性

稿甲镜头3的石兽停止，是规则导致的局部停止，B仍回枪进攻；镜头5—7则是负载不断发展的卡位，不能与无作用停机混为一谈。稿乙镜头2的停兽伴随B逼退A；镜头4上提回收期间B跨缝，下一掌沿其新位置追压，不是单击后双方复位。稿丙的撑案、压刀与末段争缝都存在相反方向的力和目标，文字未出现双人突然站定观看或闲置对峙。

稿甲约3838个非空白字符，稿乙约3754个，篇幅接近。两稿都采用画面、时间、环境、声音和转场分栏，便于定位，但18秒内每镜重复控制规则、印章不动和无新增效果，会与主要动作争夺注意。不能把较长等同于更完整，或把略短直接判为更可执行；真正需要优先保住的是手部占用、路径、触点和切镜接口。稿丙约1006个非空白字符，单镜分段较易复制，但没有剪辑替它修复遮挡或接重。

综上，甲乙各自的主要风险都发生在“文字已说明、画面尚待证明”的位置：稿甲偏向三点受力与终局层次，稿乙偏向动态摄影中的信息交接与局部锁止形状。没有依据按运镜数量、尺度大小或说明密度排出胜者。

## 仍需实际视频验证

- 三稿的时长、正常速度和各动作间距能否同时成立；不能将文字时间码视为节奏已通过。
- 稿甲、稿乙的同一只前爪、同一把长枪、唯一印章及石唇损伤能否跨镜保持；放手时是否只有石兽停、恢复后是否从同姿态续动。
- 两稿卡位是否具有真实可见的枪—爪—桥缝接触、负载方向和支撑，而非穿模、枪杆漂浮或靠弯曲声暗示成立。
- 两稿的前后层、脚步落点、断缘危险和切镜接口是否可读；巨大石兽是否有重量，B的制动与压枪是否有接重。
- 稿丙是否全程保持摄影机位置、焦段和连续时间；固定框内是否看清刀面压案、双手连续占用、末段从旁伸手及尚未触包的结尾。
- 三稿是否真正呈现身体抵抗、目光选择和动作声同步；凶险、惊艳、压迫或紧张的实际感受不能仅由形容词确认。
