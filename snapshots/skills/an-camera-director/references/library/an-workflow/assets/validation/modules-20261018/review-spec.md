# 独立文本审阅范围

冻结于首次试写产物读取之前。审阅者仅接收原始任务与匿名完整成品，不接收技能版本身份、作者解释、来源修订或预期结论。

逐项检查：

1. 原任务的身份、人数、既有道具、能力上限、时长、画幅、原词、声音、结局和拍法是否保持。
2. 场景目标、信息顺序、人物选择与身体任务是否在具体声画中成立。
3. 空间、支撑、控制资源、接触、画外同期过程与结果是否相容；不能脑补动作补缺。
4. 构图、观察位置、相机路径和切点是否交付本次需要的证据；主次和容量是否让关键变化可读。
5. 情绪接收、声音与时间、材料/技能状态和续段出口按本题实际范围检查。
6. 固定、同构保持、无攻击的揭示和静音舞蹈按本题目标成立，不以技法、镜数、反转或攻击端配额判好坏。

每题给“文本层面可交付 / 局部待修 / 需要重设计”，附具体位置、问题证据和最小改法；没有问题如实说明。区分确定矛盾、具体执行风险与合法风格，不能用总分抵消硬错。文字审阅不判断真实视频已经流畅、声音自然或生成成功。
