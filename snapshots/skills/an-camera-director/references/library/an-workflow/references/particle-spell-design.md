# 粒子运动与技能展示

用于粒子像烟花/撒亮粉、技能只有光团、释放缺乏力量、角色法术同质化、满屏特效遮住动作等设计与返工。与[vfx-finishing.md](vfx-finishing.md)联用：本页补运动、识别与技能观看顺序，不替代动作、空间和材质合成规则。不是软件操作手册，不以术语或参数数量证明画面质量。

技能概念尚未形成、不同招式只换色或缺少可拍的释放形体时，先按[技能创作](ability-effect-authoring.md)确定实际作用、主形与观看，再使用本页粒子规则。粒子、光色和生命周期不能代替角色法术/神通设计；掌边电纹、尾迹与符纹可以是辅助，不把它们变成角色握着抽打的工具。已有概念不重新发明。

## 1. 先读清技能，再丰富细节

先用一句话明确本次技能做什么，以及观众必须看到什么变化。选择可识别的主轮廓、运动方向和作用边界；微粒补充运动和材质，不承担所有形体。弧刃、束流、束缚线、推进波面、剑阵、实体巨剑与烟尘不能都变成同一种发光球。

主作用、辅助交互与细部装饰按需组织，不凑固定层数。强技能允许大范围高密度，但把最大明暗差、最清楚轮廓和主要速度变化留给当前关键事件。大并不必然亮，亮也不证明有力。普通命中、持续状态、关键破防可不同等级，高潮不必以粒子最多判定。

颜色不是唯一身份。给当前角色选择相容的源点、形状、运动方式和残留；示例不是强制设定：

- **机械能源**：从已存在的导轨/装甲接缝/刃缘启动，主能量沿明确轴线加速；接触后有定向喷散、硬件负载或冷却残光。先确认装备存在，不因为“赛博”凭空添加炮口。
- **剑修术法**：从已建立的剑、指诀或法印触发，剑气的锋面与飞行方向可辨；符纹表达聚拢、锁定区域、封路或约束，不只是旋转装饰。飞剑操控、阵域与离体剑气各有不同作用，按角色能力选择。
- **元素能力**：水体现连贯流体与破碎液滴，土石体现颗粒和固块，火烟体现不同形态与消散；魔法规则可夸张，但不能只改同一粒子预设的颜色。

保持用户指定的光色与视觉强度。分清能量实体/有效边界和外围无伤害光晕，避免人物已离开作用范围却无因受击，或站在有效区域内毫无反应。

主形的内部结构也参与识别：细颈与扩张端、主束与分支、网面与孔隙、亮边与暗部，让高密度仍有观看路径。选本场有效的一组关系，不要求每种技能都有暗芯或所有粒子独立精密控制。学习抽象流体/纤维参考或设计平面图样到体积显化时，按[形状与释放](effect-shape-release.md)区分作用载体、材质证据与成像处理；形状相似不证明具有相同攻击权。

## 2. 把“粒子”写成可见运动

根据镜头只选决定观感的项，在稿内核对：

`源点/表面 → 一次爆发或持续发射 → 起始方向及源运动继承 → 主流向与局部变化 → 碰撞/遮挡 → 寿命与停止后的残留`

- **发射位置与方式**：刃缘划出的短条、接触点迸出的火星、裂缝漏出的细屑、术法区域内受场力牵引的尘粒，不能一律从屏幕中心喷出。爆发产生一批粒子；持续发射不断产生新粒子，不是把同一批点反复放大。
- **随身与离体**：源点可以跟随手、兵器或关节；离体粒子此后按已定速度/场力在世界中运动。需要仍被法术束缚才随控制源改向，不能角色转身就把身后全部旧粒子旋回去。关节装饰光与脱离碎屑不是同一种绑定。
- **初速度与后续运动**：明确向前扇开、沿剑路拉长、绕有位置的中心收束或随波面推进。继承源运动不等于永远贴在源上；风阻使相对周围流动的速度改变，而不是所有粒子突然统一归零。局部旋涡/噪声服从主运动，不打散整条攻击方向。
- **成组差异**：选主颗粒与陪衬颗粒的形状、大小、方向散布和寿命差异；同一颗粒跨帧保持身份与连续变化，不每帧随机换位置、颜色和大小。不要把每颗都写成独立精密轨迹。
- **碰撞与遮挡**：石屑可碰地反弹后停留，水滴可打湿表面并散开，法光可按规则消散或沿护盾滑走；遮在人物后面的粒子不能叠到脸上。二次喷散从真正的碰撞位置产生，不从粒子早已飞过的位置冒出。
- **发射结束与生命周期**：停止产生新粒子后，旧粒子继续飞行、受阻、熄灭或落定。不同阶段的粒子可以陆续消退；持续光场则保留持续源，不强迫所有效果同一秒消失。不可把真实碎石全部淡出当作能量熄灭。
- **拖尾与模糊**：短尾用于读方向/速度，长尾用于已经过的路线；长度、粗细与亮度沿轨迹有组织地变化。明亮头部配较弱尾部是一种选择，不是所有技能通用形状。拖尾和运动模糊有不同作用，叠加前先检查是否抹掉锋面或把同一运动重复拉长。

无需在视频提示词中写发射率、阻力系数或节点名；将它们译成可见事件。未知模型不承诺精确粒子数、帧数、速度曲线或仿真结果。

## 3. 材料决定粒子行为，不全是发光点

| 载体 | 当前镜头可用的运动/材质证据 | 不要自动套用 |
|---|---|---|
| 金属火星 | 来自摩擦/切割等具体接触，先定向飞散，再沿各自轨迹衰减；冷却后不仍全部同亮 | 每次空气挥剑都喷火星；所有金属碰撞都烧成熔滴 |
| 石块与粉尘 | 接触处裂开、不同形状固块离开原表面，粉尘围绕破坏区扩散；固块有后续碰撞和残留 | “越重自由下落越快”；所有碎块先后顺序固定；全变玻璃 |
| 水滴与薄水幕 | 连贯水体被牵引后拉成片/丝，局部破碎成液滴，碰撞后有湿痕与涟漪 | 全部变成不受力的圆珠；没有水源却不断喷水 |
| 烟/尘体积 | 大的形体与流向承载主运动，内部卷动和边缘细节服从整体，密度改变后方可见度 | 整团平面贴图等速放大；所有烟都自发光 |
| 花瓣/符纸 | 薄片翻转、受风/场力牵引，正反面受光不同；折弯与旋转不同步 | 厚塑料片、整齐珠串或每片同速自转 |
| 法光/数据碎片 | 按已定规则汇聚、沿路径传输或在边界失活，形态与主技能同属一套设计 | 为填画面添加额外伤害范围或新能力 |

声波/压力前沿、被卷起物质和光效边缘不是同一个东西。波面先到某处，该处才产生对应扰动；远近物件的反应次序要能解释。幻想全域同步作用可成立，但须是规则，不冒充逐步传播。天空空旷处的发光圆环不自动证明地面受压。

## 4. 技能展示是行动，不是插播技能动画

根据技能类型选择必要阶段，不强制所有技能都蓄力、停顿、爆炸。先用已有动作和对手反应决定释放窗口，再安排观看。

| 作用类型 | 必须区分的状态 | 展示重点 |
|---|---|---|
| 离体弹体/剑气 | 发射、在途、命中/落空/偏转、终态 | 发出后不无因跟着施术者转身；绕行/追踪须有规则，尾迹不另算攻击 |
| 持续束流 | 源点、供能是否持续、束路、接收端与关闭 | 截断或移动源头怎样改变束流；不在断供后凭空维持同等强度，除非机制支持 |
| 领域/阵法 | 建立边界、生效区域、维持/解除、对抗 | 阵纹在哪里、区域随谁移动、如何限制路线；不能旋转光圈却不影响选择 |
| 防御/拦截 | 来袭、接触、偏转/吸收/破裂、恢复或残留 | 撞击处局部反应与对手下一动作；护盾不是无限万能停战按钮 |
| 召唤/实体化巨物 | 来源/显形前沿、部分形体、完整或足够辨识的体量、介入战场 | 主形体和尺度先可读；粒子解释形成过程，不用白闪突然换成另一物体 |
| 位移/转化 | 启动区域、消失/变化前沿、目标状态与有效边界 | 不改变不该变化的身体或装备；原物体与全量粒子副本不能同时存在，除非明确复制能力 |

“前兆”可与逼近、换步、格挡回收同时发生，只需足够辨识，不要求慢速摆姿。主攻、守方破招与下一轮可以连续接入；若蓄力需要时间，掩护、距离或压制须由剧情提供，对手不能无故看完技能展示。

### 4.1 技能相遇：先判作用，再设计粒子

在稿内确认：`来袭实体/有效区域 → 接收面或体积 → 相遇位置与时刻 → 交互机制 → 两边各自剩下什么 → 双方如何利用结果`。仅在需要时补运动方向、接收面朝向和材质；不是要求每个提示词增加参数表。屏幕投影重叠不等于世界空间接触，光色混合不等于能量抵消。

| 交互 | 可见证据 | 易误写处 |
|---|---|---|
| 阻挡/承受 | 来袭在接收处停止或持续施压；盾面、支撑或角色按规则响应，未受击部分保留 | 一点受击整面盾无因炸掉；停住的是攻击，施术者却也无故停战 |
| 偏转/反射 | 来向、接触区、离开方向连贯；偏转后仍有载体的去处 | 斜面一碰就必定原路返还；无接触/操控依据突然拐直角；反射后原弹与全量新弹并存 |
| 穿透/局部破防 | 入口受作用，前锋越过边界，接收体留下局部损伤；继续在途部分与后方目标可追踪 | 同一弹既完整爆炸消失又完整出现在盾后；前后孔位置不相容；孔被粒子盖住就算自动修好 |
| 吸收/转化 | 来袭在边界逐步失去原形，接收端呈现既定储存、传导或转化迹象 | 缩小的光球不说明吸收去了哪里；吸收自动变成反弹或治愈；无设定强加过载与代价 |
| 抵消/对抗 | 有明确相克或对抗规则，两边的有效部分怎样减少、侵入或持续可见 | 颜色一混就判双方消失；持续束流总在几何中点长出静止大光球；用亮度判谁强 |
| 绕开/落空 | 轨迹从有效范围旁经过，守方确实离开攻击体积；攻击继续落向合理区域 | 未接触也喷碰撞火花；躲开剑尖却仍处于剑身或扫弧内；尾迹自动追加一次伤害 |

反射可按选定的光学或弹性模型设计；一般魔法偏转不必服从镜面反射，但要给已建立的操控/场力依据。持续对抗的交界随源向、接收面或设定中的优势变化；僵持可以成立，不强制移动，也不套虚构的通用力量公式。特效只表现已经确定的结果，不凭光色、角色类别临时发明克制规则。

**接收物与空间**：薄盾面、厚墙和体积领域分开处理。盾面波纹沿面扩散；若盾随持有者移动，附着纹理随盾走，已经脱离的火花仍在世界中运动。实体穿过厚物需要可解释的路径，不能把表面闪光当成穿透证明。体积领域中可持续受作用，不强迫只在边缘一次碰撞。冲击、切割、灼烧、湿润按实际材质和招式分流，蓝光不自动烧焦所有东西。

**破坏与压力回到战术**：巨剑落点、体量、到达路径先与人物/建筑建立关系；若产生地面波、断桥或飞散大块，就继续检查传播到谁、封住哪条路、谁必须改步或换支撑。近处、接触处和远处反应按机制衔接，不能所有建筑同一时刻无因爆炸。已有孔洞、残骸与护盾缺口跨镜保留；修复和再生需原因。巨物不必笨重，速度也不允许跳过可读的介入过程。

**中断、二次事件和跨镜**：区分施法起手被打断、持续供能被截断、离体弹被拦截；分别继承尚未生成、已经在途和已经碰撞的部分，按已定机制收束。接触后沿面滑擦可以持续出火星，真正再次碰撞可以再喷散；切换机位或原处停留不能无因重触发同一次爆炸。多角度覆盖同一作用的不同阶段，不把接触前后的时间倒回去。结果镜中双方继续追击、脱离或利用新路径，除非动作确实被限制。

### 4.2 状态触发、联动与非碰撞交互

需要主动/被动、预置、标记、恢复/解除、自主代理或场与场作用时，先从[技能体系与状态](ability-system-design.md)继承有效条件，不把这些都套成粒子发射。主动开启一次后持续运行、事件触发自行响应、积累条件改变、已发离体体继续在途分别处理；中断控制端只影响机制允许的部分。

非碰撞交互按同一事件接续：谁建立条件→条件附着于谁/哪里→谁或什么触发/读取→接收状态改变→条件消耗/保留→双方下一行动。标记不自动追踪或引爆，解除一个状态不清空所有类型，恢复只兑现已有能力允许的部位/条件。领域重叠按已定叠加、覆盖、竞争或互不作用读取内外差异，不必生长中央对波光团；合作让第一招真正改变第二招的入口。

感知/隐匿/诱骗须分角色与观众知识，效果也可由判断和行为差异显露，不强制发光。形体、粒子与残留只细化有效状态；观看选择见[技能画面与摄影](ability-screen-direction.md)，不能用效果外观反推能力或胜负。

## 5. 镜头、层次与作用点

机位随观看任务选择，不固定“四镜必齐”：

- **源头/起效**：近景读硬件点亮、剑纹形成或手势变化，保留必要持物与朝向；小变化足以说明时不加长转台展示。
- **传播/逼近**：斜侧/横向机位保留轨迹和被跨越的地标；需要临场感可让部分粒子掠过近景，但不是所有粒子朝镜头飞。不能一直贴着弹体拍到失去目标距离。
- **拦截/命中**：双人关系或接触近景读主作用，局部密度/明暗让关键点短暂可见；大效果仍可充满其余空间。冲击帧强调接触或状态突变，具体用法沿用[分镜视觉](storyboard-visual.md)，不另设固定帧数。
- **规模/后果**：广景读技能跨过的建筑、人群或通路；低位仰拍可强化压顶但保留尺度参照。结果镜里双方已经在应对新处境，残留不能切镜复原。

粒子深度按真实空间组织：近处遮挡与掠过较显著，主作用区域形状清楚，远处聚成层次而非同样大小的亮点。视差依赖相机运动方式和距离，不机械给静止镜头加整屏背景滑动。保护可读性不等于人物周围永久空一圈，也不必永远看清所有人脸。

保持技能色彩归属、明暗主次和稳定曝光意图。发光效果在写实融合中应有相应局部受光，接收物材质与遮挡影响结果；图形化二维则可用色块/轮廓关系表达，不强加摄影光照。折射、热扰动只影响适用区域，不把全画面持续扭曲当压迫。特效规模由形体、距离、传播与环境后果证明，不单靠增加泛光。

## 6. 定向返工与验证

| 失败 | 优先修的变量 |
|---|---|
| 像撒亮粉，技能辨不出 | 主形状/主流向、源点与粒子职责 |
| 一停手全部消失 | 发射关闭与旧粒子寿命分离 |
| 人物转身，全部尾迹跟着转 | 随身源与离体粒子的空间归属 |
| 所有攻击都同样爆炸 | 作用类型、反应材质、强度层级 |
| 炫酷但感觉没打中 | 作用点、目标局部响应、持续结果 |
| 巨剑像贴在天空的小图标 | 尺度参照、深度遮挡、逼近及战场改变 |
| 粒子很多但像屏幕贴纸 | 深度/遮挡、世界位置、相对运动 |
| 特效一强角色就停动作 | 释放窗口、同时发生的攻防与回收 |
| 主峰只剩白团 | 主轮廓、局部明暗/密度和关键作用点，不先全量降强度 |
| 两束光一叠就爆炸 | 世界空间是否相遇、有效边界、既定交互机制 |
| 偏转后不知打向哪里 | 接收面/场力、出射路线及其后方接收物 |
| 切镜就再爆一次或破口复原 | 同一事件的阶段、二次触发依据及损伤继承 |

没有视频时做纸面检验：去掉颜色和技能名，是否仍能分辨不同机制？去掉装饰粒子，主作用是否仍清楚？去掉大形体，粒子是否还能说明既定流向而非随机散布？后两项是诊断，不是要求成片删除相应层。

有视频时先正常速度看方向与技能结果，再抽查发射关闭、在途、接触、粒子碰撞、残留与跨镜；核对身份/武器数量、边界、遮挡及景别。改稿先固定有效部分，针对已定位原因改一类变量；若有多个独立错误可分别修，不以“一次只改一个词”阻止必要修复。文字检查、仿真/合成预览和生成视频实测分别报告。
