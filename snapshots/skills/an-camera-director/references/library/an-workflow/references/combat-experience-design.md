# 战斗体验设计：场景、速度、情绪与交互

用于战斗主体验选择、普通实战的主动设计，以及高速、高燃、能力展示、控制博弈与压制等要求和返工。先成立本段的交锋、力量与观看体验，再编译，不等用户报告缺项才调用。本页只取当前角色与任务相关部分；快战、能力展示、教学、文戏和舞蹈各守目标，固定与单招按允许变量实现。

“根据角色/参考图直接出打斗”先过[打斗默认契约](fight-default-contract.md)：分清独立人物、双方能力/限制、打斗逻辑、blocking 与朝向、建立/交换/冲击/结果覆盖、能力四拍；速度、拍数、反应链和时长见[打斗速度、节拍、分镜与技能展示](fight-speed-and-sequencing.md)，景别/角度/构图/运镜见[打斗镜头语言](fight-shot-grammar.md)；本页负责体验与模块组织，不替代这些前置决定。

## 普通打斗的主动设计起点

先根据当前请求、参考与已采用事件判断本段主体验。未另示的普通实战仍主动设计高速、高频、快节奏、力量、相容变化与摄影；能力展示、控制博弈、压制或反扑侧重能力认识、条件改变和结果读取时，按[能力作战](ability-led-combat-direction.md#主体验与事件节奏)分配必要辨认、爆发、作用和反应，不等用户额外声明慢打。同场可切换，能力战可高频；已锁高速/高频不被此分支降级。速度、频率、力量、规模和摄影是不同维度，不能互相抵偿，也不因造型轻灵而主动削弱强度。

| 本段主读 | 事件与观看的组织重点 | 应避开的误用 |
|---|---|---|
| 高速密集交锋 | 反制与续攻直接接力，相容准备/恢复重叠，关键接触可读 | 只加跑动、短时码或残像 |
| 能力展示/控制博弈 | 辨认规则和作用对象，读取对方尝试与条件变化，再交结果 | 每招长仪式、站桩轮流播效果，或为加密强塞近战 |
| 压制/巨大力量 | 小控制对大响应、局部触点对范围后果，人物承受改变强弱感觉 | 只有尺寸数字/亮光，保持无压力发展 |
| 伤后反扑/优势转换 | 代价、恢复和行动选择接回原战局 | 无依据新增伤势或为省时删掉必要人物接收 |

以上是选用维度，不是固定四段模板；可混合、跳过或在一场中转换，不按题材名字直接判快慢。

**先编交锋簇，再分秒数**：从当次抢攻/争夺选择可接续的一组压力变化，例如抢线被截后就势变层、受力过程中换支撑反扑、截断控制后追入新空线；前一次应对创造下一次攻击条件，角色不用回到起手位。两人的准备、短促作用、恢复与在途效果按资源相容重叠，不把每一项排成互相等待的独立步骤。角色被迫失去主动时可只有防御或受击，但进攻方仍利用窗口。每簇入口、转折和出口成立后再分配真实时间，不先切成几个四五秒段再各填一招。

**动作变化在选用阶段落实**：从[模块库](../../combat-action-design/references/action-module-bank.md)选择入口与身体/兵器/术式操作不同、能互相接续的结构；相容的高度、攻线、支撑、接触、距离或控制权改变要成为攻防结果。能力可有主题重复，但不能用同一张焰面改成大面、窄面、楔面就自动证明攻击模组丰富。重复压制或签名技有战术发展才保留，不靠随机翻腾与换名补数量；不设固定招数。

## 单向推压与主动权换手

最长交锋簇合并重复进退后，若仍只是同样来线、同样防法与一路后退，按推搡回修；让身体转轴、高低、支撑、兵器关系或既有技能改变难题，双方继续读取变化。合法单方压制不强制每几秒换手或平均出手。用户要自然丰富动作时主动从完整身体乐句组织，不用换攻击端充数；必要技能与主峰也必须在S正文起效。统一方法见[设计系统](fight-design-system.md)。

**速度与力量在普通招就出现**：写出紧凑加载、攻击端迅速跨过参照、接触时减速/压缩、受力端被带离原线以及下一次恢复或反扑。贴身技读支撑、髋肩传力、接触部位与受力去向；需要高速的远程投射读源端释放、短促到达与结构抵抗；持续控制、压制或规则术读负载、条件改变和接收结果，不强制变成短弹。轻点、试探与重击有层次，不能直到结尾爆炸才出现力量。关键普通招的[运动与传力](../../combat-action-design/references/motion-impact.md)不足就回修动作，而不是追加镜头抖动。

**清掉无作用的节奏空档**：合并同一持续事件后，检查形成、在途、接触、受力与续攻之间的时间去了哪里。“恢复重心、准备下一招、继续推压、看向对手”如没有新负载、抢位、反制或读取价值，不单独占据一长段。几秒只演一次引偏/托举/推幕，即使全程有粒子和运镜，也不能直接当作高频交锋。先重编接力与相容并行；必要时重分段落时间，不只把时间码写小或增加近义动词。

持续角力、疼痛接收和主峰可以有阅读窗口，但要说明当时谁正尝试改变什么，以及何种变化结束保持。快战不默认以数秒熄火、喘息、松手和对视收尾；按既定结局选择动作结果或必要反应结束，空出的片长回给有效交锋。用户锁定慢镜、收尾表演、定势或仪式则保留相应占时。

**摄影和动作共同完成体验**：每簇选择决定性来线、交会/受力及下一威胁的观看顺序，在动作成立时就安排占幅、纵深、相对速度和注意交接。按[战斗摄影](../../cinematic-camera-design/references/camera-execution.md#战斗中的速度力量与摄影压力)写实际起幅—触发—路径/速度变化—落幅，不能用长期等大侧跟覆盖所有交锋。固定拍法用画内入距、前景参照与主次接力，长镜用连续视点发展，均不制造假切镜。

修复顺序是体验目标与角色机制 → 交锋簇和相容模块 → 速度/传力与并行 → 摄影压力与阅读 → 时长、空间和资源复核。发现空间问题，先修路线、入口或观看，不以删掉模块、拉长准备、缩小幅度来求方便。终检见[体验门槛](final-check.md#战斗体验先于连续性放行)，普通交付不附内部设计表。

## 场景要提供当前战斗的机会和压力

选场前先确定双方正在争夺什么，以及各自准备如何进攻、反制或守住目标。普通打斗、高速、高燃不自动转为逃跑；无已定追逃目的时，不让一方长期只找出口、另一方只追堵。避线、受击后退、拉距、破围和穿越技能缺口可以成立，但下一任务应继承当前交战意图；“镜头出口/动作出口”仅指段尾状态，不能偷换成角色撤离目标。明确追逃任务照原意执行，详见[交战意图与覆盖](combat-intent-performance-coverage.md)。

原创选景从角色战法与观看体验决定具体环境：哪些结构允许高速穿行，哪里限制高度/转向，什么材质承受技能，哪一处关系能形成记忆画面。先选实际可用的主结构及关联路线，再建立最小空间；不能先默认云海祭台、石桥、残柱，之后只让它们充当爆炸背景。锁定场地则使用原结构，不借反馈擅自换景。

让场景参与一次有用途的变化：狭窄通路迫使变层；倾斜承重面改变接重；悬垂物或巨型构件分开本体与术法路线；视线遮挡促成有依据的骗招；被切开的地形产生下一轮可利用的支撑/危险。例子不限定环境清单，不每场都拆楼，也不靠“场地最终全毁”证明此前参与。

氛围选择与当前威胁相连的光、空气、材质和声音变化：遮光的主形逐步占天，粉尘先被吸向负载源，反光显示看不见的来袭，地面裂声暴露失去支撑的时机。环境层可以运动较慢，人物仍高速争夺；不要让整场一起慢化或以增加尘雾掩盖动作。

## 高频、高速、高燃分别兑现

高频是有效作用的连续接力；高速交锋先看角色有效距离内的短促发动、判断/应对、作用与改控/截断/反击，人物/攻击端迅速改距、过点、越线与制动可增强它，但高速追逐或跑动不能单独证明交锋快。追逐任务与交锋速度可同时或分别成立，按当前请求验收；高燃是观众期待的行动或力量被兑现，人物有投入和选择，节奏有重音。三者不能由相同的招数、0.1秒时码或鼓点代替。

施法过程或普通技能贫乏时按[实际交锋与施法操作](fast-spell-exchange-design.md)先修采用事件：操作决定手势/身体，技能差别决定触发、位置、控制和终态，反制有当前窗口。不能靠增加长距离移动、甩掌次数或大招展示抵消小招没有动作/作用。

设计关键速度差：发动前的紧凑加载→短促爆发吞掉地标间距→攻击/避线交会→接触制动或沿余势改线→下一次追及。远程施术者可通过源端短放、攻击在途与本体御空改层实现，不强加肉搏。大动作保留开合、领随和真实进入，避免用缩小幅度换快。

摄影能暂时被人物甩开，随后追回下一交会点；也可在地标旁迎接主体快速入距，或低位并行让近物掠过、目标间距收缩。不是每镜都让角色居中等大、匀速侧滑，导致观众失去速度参照。关键接触留清晰窗口，过渡模糊不占据全部有效攻防。高速残像只记录旧路线，真身的新位置和有效攻击另有路径依据。

## 招式模块按当前战局组合

先确定双方不同战法，再从当前未决问题选相容的变化；模块是战术功能，不是每场必须齐备的招式菜单。

| 当前问题 | 可采用的交锋模块 | 后招继承什么 |
|---|---|---|
| 无法进入有效距离 | 压线突入、低位潜进、空地转层、远近协同 | 入距路线、对手剩余攻击与落点 |
| 防线单一或被抢先 | 高低换线、延迟/错拍、佯攻诱防、分路逼选 | 暴露的空线、真实主攻及对手已占用控制端 |
| 防守只挡住然后复位 | 外卸内切、接触牵制、破控端、借冲势反扑 | 未解除负载、忙闲肢体和反击窗口 |
| 追击总是直线发弹 | 贴地弧追、折线追及、越障截路、掠身后改向 | 地标越过顺序、同期目标、攻击可达距离 |
| 技能只有颜色差别 | 层浪压路、环绕束控、边界切割、收聚穿透、反制供能 | 作用区域、路径结构、残留和新任务 |
| 大招与人物脱节 | 人与代理交叉、穿越有效部位、截断连接、引导环境碰撞 | 代理负载、控制归属和剩余威胁 |

需要剑修、御剑或剑阵时读[25式剑招转译](../../combat-action-design/references/cultivator-sword-techniques.md)，取动作与作用结构，不只取招名。无剑法师不因读取剑库新增持剑；能迁移的是诱防、换线、层浪、收聚或封路的战术关系，须重新设计本角色的源头、身体动作和介质。纯远程、单技能、单方压制仍可通过不同用途与压力发展丰富，不强制所有角色同一套近战→大招顺序。

## 情绪、行动与反馈同场成立

先选这场具体的争夺与失败压力；原创可设计，锁定剧情内补表达，竞技/展示不强塞救人、惨败或受伤。人物接收到新事实时，可改变预测、控制或行动，也可在维持原目标时显出疼痛、投入、克制、兴奋或受力后的余波。目光、小动作、情绪动作与反馈有当次对象、负荷或性格依据；不要求每次表情都产生新策略，不每次统一皱眉、喘气、仰头或怒吼。

脸部特写可读判断、承受、投入或控制中的细微变化；身体镜读负载、情绪动作与行动；召唤物局部读有效部位、材料、形成或受损变化；范围镜读同次威胁与关系。反应期间对手、在途体与持续场继续，不把战斗停住插一张紧张脸。声音获准时按来势、短接触、持续加载、释放和余响分配主次；高燃不依赖全程同响度音乐，静音也须凭选择和画面成立。

手持须有身处事件中的观察关系，按[贴身手持与压迫摄影](../../cinematic-camera-design/references/embodied-combat-camera.md)落实；空中大范围相机可用虚拟惯性质地，但不把航拍下降改名为手持。

## 巨型技能必须与对方形成交互

先区分完整召唤代理、有效局部显化、领域、结构化术式和一次性投射。狐首可以是合法的一击显化；但用户要求丰富交互时，不能把局部狐首放大直撞当作已完成的召唤战斗。未锁定形态可选择完整代理或更适合本场的结构，锁定狐首则在颚、有效边界和当前控制机制内设计，不擅自长出实体身体。

从当前战局写出双方互相改变行动的回路：有效部位逼近/压路→对手避开、承压或打断关键部位→主形/控制者依据结果改向、续压或改变用途→对手利用新缺口/路线继续行动。需要几轮由本段任务决定，不设固定次数；一次性终结或碾压照原目标成立。

代理有实际可达部位、尺度、自由度和任务。本体维持、改指令或趁代理创造窗口行动；自主任务须有采用机制。对手可进入局部空间、攻击有效连接、借部位受限抢位、诱导巨物撞已建立障碍等，采用一种真实方案即可；不是任何人都自动识破唯一弱点。被击破的是局部还是整体明确，后镜保留剩余形体与负载。

宏观作用和人物短攻共用时间。巨物转向、咬合、拦截、受压、破部位与环境碰撞若采用，应各有不同攻击路径、抵抗和结果，不能每项都变成弹头相撞后碎光。主峰先选可记住的形体关系，再定摄影，例如小身影穿过尚未闭合的巨大夹口、曲面被斜向切口撑开；不把这些例子固定给狐狸或每场重复。

## 冲击帧先设计看得见的特殊画面

用户明确要冲击帧时先按[冲击帧导演](../../image-impact-frame/entry-guide.md)选实际峰值。实体模式写当瞬间的夸张透视、轮廓压缩/错位、受压材料与定向碎片；图形模式写具体正负形、主力向、亮暗组织及笔束。普通晶体碎裂、曝光变亮和“同机位冲击帧”标签不能自动充数。

进入前有首触或机制突变证据；峰值有区别于常规画面的明确形体；退出接同次受力、破损和下一行动。若设计多张组图，明确各张表现的相位及交接，不能把同一张重复停放。持续范围按当前阅读和节奏选取，计入原总时长；不由未知帧率推固定画张/曝光保证。

## 交付时核对真实设计

先核当前主体验；能力展示/控制博弈核辨认、应对、结果与有效保持，快战核有效高频与独立高速证据。再分别核：场景是否改变选择，人物判断是否引出行动，手持是否有观察者响应，巨型技能是否存在对方反制后的发展，冲击帧是否有特殊形体，主峰是否兑现前面的期待，切点是否交付下一相位。检查对应实际正文；任何适用项缺失就修其最早决定及依赖，不只加禁令或再读库。文本推演、人工短例与成片正常速度观看分开报告。
