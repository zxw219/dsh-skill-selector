# 2D 打斗镜头与作画语法

用于二维动画/赛璐璐/卡通角色的打斗提示词。和真人电影共享景别、构图、切镜、轴线规则，但不能把“真实相机”直接搬进 2D：2D 的镜头运动、速度、冲击主要靠分层、关键帧、smear、冲击帧和剪辑完成。

## 1. 2D 的“利落”是什么

- **关键姿势清楚**：每一拍先有可读的起势、接触、受力、收势；中间帧可以少，关键帧不能含糊。
- **接触帧明确**：拳/爪/兵器/脚与目标接触的那一帧，轮廓、方向、压缩要看得清；不能只用速度线盖过去。
- **受击帧有变形**：头/肩/胸/衣料/武器在受力方向短暂拉伸、压缩或偏移，下一帧回到可继续动作的姿态。
- **smear（拉伸帧）只用于高速经过**：把攻击端拉长、糊化、变薄，表示快速跨过空间；不能每一帧都 smear，也不能用 smear 代替接触。
- **冲击帧是重音**：1–2 帧高反差轮廓/负形/色块，力向与接触点一致；不是白闪。按轻/重/必杀分级配比，不每次接触都用，见[动作密度与镜头预算](action-density-and-shot-budget.md#交击三级)。
- **hold（停格）只在有作用时**：读表情、读结果、读控制；无作用的 hold 就是拖时长。
- **少帧不等于省动作**：2D 可以“少画”，但不能“少设计”；关键相位、接触、受力、下一任务都要成立。
- **流畅不等于帧数**：先分解关键姿势与关键帧，再补中割；严格按时间轴平均推进反而失去缓急和打击感。关键拍顿一下、过渡拍快带，才读得出重量。
- **预备、跟随与弧线**：启动前有反向预备，停下后发/摆/武器还在走，四肢走弧线不走直线；帧的三段与暴露区见[动作原理与帧逻辑](action-animation-and-frame-logic.md)。

## 2. 2D 的镜头运动

2D 没有真实相机，但有“摄影台/多层背景”：

- **横移/竖移**：背景层、中景层、人物层以不同速度移动，形成视差；不是把整张画面平移。
- **推/拉**：用 zoom/scale 或多层放大；近景层放大快，远景层放大慢，才有纵深。
- **摇/俯仰**：背景长图横移/竖移；人物层单独动，避免人物像贴纸。
- **环绕**：2D 不能真绕，只能用角色转身、背景旋转、分层错位或切镜模拟；不能假装 3D 环绕。
- **甩镜**：用背景速度线/模糊/方向性 smear；甩完要落稳到新信息。
- **手持**：2D 手持靠不规则边框、背景抖动、局部错位；不能全画面乱抖。
- **速度**：前景掠过、地标越过、人物层与背景层速度差；不是只加速度线。

每个运动写：**起幅 → 触发 → 分层/路径 → 速度变化 → 落幅 → 接什么**。

## 3. 2D 的构图

- 剪影优先：打斗姿势在黑白剪影下仍能读出击打方向、支撑、持物。
- 色块分区：主角/对手/背景用明度/色相分开；不要所有颜色一样亮。
- 透视可以夸张，但接触点、支撑脚、兵器归属要清楚。
- 前景可以用速度线、烟、碎片、栏杆、手臂遮挡；不能遮住关键接触。
- 2D 的“大场面”靠层次和留白，不是靠堆细节；远景可以更概括。

## 4. 2D 的切镜

- 切在关键姿势/接触/受击/方向变化；不切在动作中间看不出结果的地方。
- 切出接“正在发生的动作”，切入接“剩余相位”；不能切完重新起手。
- 同方向动作可以匹配切；反向动作要看清转身/换轴。
- 2D 的“快切”不能代替动作设计；切得再快，每镜也要有一个可读姿势。
- 冲击帧可以单独 1 帧，但要接回同一动作的下一相位。

## 5. 2D 打斗的镜头菜单

| 任务 | 常用镜头 | 2D 做法 |
|---|---|---|
| 建立距离/朝向 | 远景/中远景/低机位 | 背景长图+人物全身剪影，地标给距离 |
| 交锋/攻防 | 中景/中近景/过肩 | 关键姿势+接触帧，背景层轻移 |
| 冲击/命中 | 近景/插入/大特写 | 接触帧+受击变形+1–2帧冲击帧 |
| 反应/读取 | 近景/中近景 | 受击帧后的表情/身体反应，下一拍接动作 |
| 技能机制 | 插入/近景 | 手/载体/主形形成，背景层继续 |
| 结果/范围 | 中景/远景/俯拍 | 新位置/距离/环境结果，人物层与背景层分开 |

## 6. 2D 能力/特效

- 能力主形用清晰轮廓和色块，不靠细碎粒子堆；
- 形成/作用/残留分阶段；同一能力不同用途换形/换路径，不换色充数；
- 特效层和人物层分开，人物不能被特效吞掉；
- 技能在交锋中完成，插入机制近景时对手/在途作用继续。

## 7. 2D 打斗自检

- 黑白剪影下，关键姿势还能读出击打方向/支撑/持物吗？
- 接触帧清楚吗？还是只用速度线/白闪盖过去？
- smear 只用在高速经过，且下一帧回到可读姿势吗？
- 冲击帧的力向、对象、结果一致吗？
- hold 有明确作用吗？没有就删。
- 镜头运动有分层/视差/起落幅吗？还是整张画面平移？
- 切镜接住剩余相位吗？有没有切完重新站好？
- 技能在动作里完成吗？有没有停下来放技能？

## 8. 常见错误

- 全程速度线，接触帧反而看不清。
- 每一下都冲击帧，重音变噪音。
- 2D 假装 3D 环绕，背景和人物透视打架。
- 人物层和背景层同速移动，像贴纸滑行。
- 切镜只换背景，不换姿势/注意。
- 技能放完双方站着，等特效结束。
- 为了“流畅”加很多中间帧，关键姿势反而软。
