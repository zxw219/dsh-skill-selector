# 角色战法、施法表演与术法协同

用于原创战斗、角色战法错配、法师被改成拳脚战士、施法站桩、释放后停手，以及领域/召唤/大型术法只有招名的返工。先选本场战法再取动作；保留当前角色设定、结果、摄影、画质、声音与MOKE格式。它是按缺口读取的专项，不增加每稿必读链。

## 先判断角色怎样战斗

当前用户明确手脚并用、近远混合或身体技结合术法时，以此选相容混合战法；不能以助手旧稿补设的纯法师定位拒绝。只有造型图不锁定只用手施术。手可截线/牵制而腿改低路，腿迫使换防而手抢空线，身体接触/踩点与术法协作有前提与结果；具体按[手脚协同与能力多样性](full-body-ability-integration.md)。用户明确锁定纯远程、无近身、单招或特定发动方式时保留，不能为多样性强行加拳腿。

用户明确的类型和采用设定优先；图片建立外观、已有道具与可见能力线索，不单凭裙色、发色、角冠断言法则。类型不明且允许原创时，提出与形象和任务相容的战法并在本稿定义，不能把上一稿助手新增的武器或肘腿当用户锁定事实。

| 类型/本场战法 | 实际争夺与身体语言 | 易错移植 |
|---|---|---|
| 徒手或兵器近战 | 距离、攻击线、支撑、接触与收势；身体/兵器直接作用 | 为丰富技能放弃已锁定兵器或授予万能法术 |
| 远程施术 | 保持或改变距离、选源点/目标、改诀、导向、释放、避险与续法 | 默认贴身拳肘腿、持盾互顶；只有掌心球发射 |
| 召唤/御使 | 本体选择、指令、移位/施法与代理任务共享时间 | 本体当观众，代理当背景，或强迫每次镜像同一动作 |
| 领域/规则术 | 建立边界/条件、改变区域关系，本体与对手利用/突破新条件 | 地面圆阵和换背景就称领域；没有实际作用 |
| 混合战法 | 用已设窗口与距离转换，保留双方不同优势 | 每角色都走近战→法术→巨物的同一顺序 |
| 巨物/异形/机械 | 来自现有体型、器官或机构的有效动作 | 无因改成人形拳脚、添加喷口/法器 |

决定本场主战距离、发动方式、进攻/防守/位移职责及重要状态前，先核它们能否承担本次要求。角色设计不止给元素命名：双方应在进入方式、攻击运行、控制/恢复和破局选择上形成相容差异。仅有造型图且允许原创时，先选择能承载所需频率、速度、变化与规模的能力和场地；助手先前补设的“仅接触局部、仅用现成材料、只在狭小内景”不自动成为锁定事实。当前要求超大型技能时，在设计阶段就留出真实尺度参照、威胁作用范围、对方反制及之后的发展，不能到末尾把局部招式放大或用无依据背景巨物补数；未要求巨型或用户已锁低能力时不强加。动作、场地或能力补设已经压低要求时，回修这些未锁前提，不只继续打磨盾面、脚位和手部连续性。

将采用战法直接编入同一事件链。战斗多样性包括施法方式、落点、时机、空间、控制与召唤协作，不靠人人混用拳肘膝踢。法师可在真实窗口贴近触印或拆施法，但不因“快”强加肉搏。

参考角色先分清图中已有装备和可原创的能力机制。普通“根据这张角色图编打斗”继承图中既有武器、持物与穿戴；允许补能力不自动等于允许重设装备。只有用户要求、用户已确认设定或本轮明确开放的装备设计才新增兵器/护具。不能为套格挡链自动添加剑、盾牌、护臂或晶甲，也不能从腰间圆饰、冠饰或模糊长杆断言盾/剑/弓。

防守可以由避线、变路、干扰源端、现有能力和环境作用承担；具体术法防护按当次机制设计，不全改成手持盾。附在前臂、反复负责承击并像盾使用的木甲/冰甲仍是盾式护具，不能用材质或“临时生长”掩盖新增装备。当前明确没有盾牌、不加武器或保留原装备时，角色不携带或生成这类实体装备；瞬时术法作用与新增穿戴/持物分别检查，不借“原创能力”绕过当前禁项。

## 施法是可辨的身体任务

召唤动作与召唤物本身分别选择观看证据：控制端可给指节闭合、腕肘牵引、身体接重或断诀交令的CU/ECU；作用体可给有效部位、成形边界、材料展开、承压或局部受损的CU/ECU。无形领域则取可辨边界/介质变化，不凭镜头需要添加兽首或实体。推近、横移、升降或转焦可交接控制端与作用体，范围镜承接同次运行；不把生成过程剪成另一次召唤，不以一直拍全景代替所有局部。具体按[召唤与表演覆盖](combat-intent-performance-coverage.md)采用，瞬发、无手势与一镜限制仍保留。

施法动作少或高速被缩成抬手甩波时，先按[操作到身体过程](fast-spell-exchange-design.md#施法动作从本招的操作长出来)确定本次锁定、聚拢、分层、接通、改向、截断或交代理的实际变化，再选手指/腕/肘、肩胸、支撑与收势。快速普通法也保留有作用的形态，不只给大招成形；精密小诀、无手势及纯投射按角色机制成立，不强塞全身舞动或仪式。

当前技能选真实所需相位，不强制每招完整仪式/同一套手诀。手势、目光、呼吸、躯干、步位/御空与作用体在同一时间里有因联系：

- **取位/起势**：看定实际目标或源点，接重/改高度，肩胸与手臂进入当前施法路线。不是原地看镜头摆姿。
- **引动/成形**：捻指合印、翻腕分层、双臂牵开区域、触地留印、步位接通阵点或其他角色专属方式；写哪项动作改变哪一项法术。不要给所有短招加转圈咏唱。
- **释放/生效**：指诀骤合、断诀放出、移掌改向或远端触发，效果按机制起效；形成可慢，发射/侵入的速度另定。
- **运行/协作**：持续控制者转腕、牵掌、步位或视线修正作用；离体攻击、自主代理和已开启场按其机制继续，本体能执行相容的另一任务。
- **收势/续法**：解除已结束的手势、承接受力或换位、准备下一招；已经离体/自主的效果不因此无因消失。释放完举手等爆炸结束不是默认收势。

例如虹光法师侧步避过根刺，右手两指在胸侧划开折光面，翻腕让三片折面转向目标，指节骤收将射线分路放出；射线离体后，她收肘转肩进入空出的通路，左手点亮先前落下的光印。森灵施术者后撤时左掌向地压印，使根脊抬升封路；右手从低位展指向上引出花苞，在召唤物独立截击时沿根台换位，双掌再牵开巨花。都是原创选择，不授予所有人物相同能力。

角色的沉稳、克制或有意不动可以保留；有明确持续控制、压迫、仪式或表演任务的驻立不等于呆滞。高速场景中的停留有作用和窗口，对手仍行动或有已设限制。不能为纠正站桩让全员无目的翻滚、踢腿或舞蹈。

## 施法相位与人物下一任务

造型峰值不是每次施法的终结姿势。持续控制确需保留的手势与本体能做的任务分别成立；离体/自主作用成立后，按角色战法接回收、避线、转移、改诀或观察新的作用点。对手在形成、释放与传播中仍处理自己的威胁。关键手部细节与身体任务互相兼容，不为特写重新从起印开始，也不因修摆姿把远程施术改成近战或无目的舞动。

## 巨型形体的战法与反制

大技能只剩狐首/龙头飞去撞的反馈，按[交互设计](combat-experience-design.md)先区分局部显化、一次投射、代理或领域；丰富交互由对方反制实际改变主形、控制者和下一任务。有效部位、可达路线、局部负载与剩余作用同时明确，本体在维持/改令/利用窗口中主动参与。一次性终结和锁定局部仍可保留，不以完整召唤兽或万能弱点替换原角色。

## 本体、法术与代理共同作战

区分持续操控、一次指令后自主、预置触发、离体攻击和纯残像；按实际机制维护控制端、在途体、接收端和残留。并行可以是召唤物截击迫使敌人避线，本体在其另一侧布印；分身牵制注意，本体从远端发动；领域限制路径，普通法术利用新通路。关系景、镜内交接或切镜让归属与两路任务可读，不要求一直同框。

代理不是本体动作的自动复印机。本体也不必须亲自拳打：它可召唤、改诀、牵引、闪避、布阵、转移或续法。若本体需要全部精力操控，移动/另施法须相容；自主不是自动获得无限追踪、免疫或所有攻击权。对手反应由实际威胁与当前能力决定，不强制每招相消或设唯一弱点。

## 技能创意开放，角色边界明确

下列领域、代理、召唤、荷花与星体只是研究和校准样例，不是技能类型全集。按当前角色和战局创造相容机制、形体、介质、规模、控制与运动关系；变化可来自作用条件、物性、感知、时间组织或其他已定义能力，不能都退成发射光球。采用一个有效方案即可，不为开放创意穷举全库；锁定能力不自动新增。关键施法细节按[取景与切接](../../action-camera-direction/references/detail-coverage-clean-cuts.md)让观众看见，释放后接人物与法术的相容任务。

## 法术差别必须进入战斗

比较用途、发动、作用区、运行方式、交互和终态；去掉招名、颜色和尺寸后仍能读到采用差别。不是所有技能都发射→撞盾→爆碎。单招多用可成立，但本次目标、时机和结果须改变双方行动。

| 所选结构 | 必须兑现的事件 | 原创场面选择 |
|---|---|---|
| 领域 | 边界/条件与内外差别，谁在利用/突破；持续与解除 | 同一射线跨界后弯成绕行轨道，对手改变穿越点；不能只有转阵 |
| 替身/分身 | 来源、归属、任务与本体另一项行动 | 代理引开前路攻势，本体从后侧布印；残像不自动有攻击权 |
| 大型召唤 | 出现与执行任务分开，形体/体量/指令与结果连续 | 巨鹿截断法术通路或角枝挑开落势，施术者同时移位续法 |
| 巨型荷花 | 来源、层叠花瓣/莲心/根系、开合或其他真实作用、人物后果 | 花苞越过母树，花瓣封闭空域，莲心汇入既有落点后释放；不是放大花形光球 |
| 巨型星球 | 真实天体、术法星体、幻象或投影的类别，星面结构/尺度、控制与作用 | 岩质星体自星海入口显现，转动改变落势，人物牵引后立即续法；星球在背景不等于召唤 |
| 外太空/星海 | 真实跨场、领域内部空间或尺度揭示的明确选择，原事件与新参照相连 | 从同一空间入口交到云层/星体弧面，再回本体当前控制；不无因换背景 |

这是可用结构，不是每角色/每短片必须收齐的招数清单。用户明确指定的领域、召唤或宇宙规模须落实到实际事件，不能用普通树枝、远处亮球或“大招”二字替代。新能力须在当前原创权限内成立；已锁定能力不为迁就样例扩写。小技、高速截击和大型形成可并行、接力或反制；不统一排成先肉搏再轮流放大招。

## 摄影、成稿与联合检查

相机跟随控制端→作用体/规则变化→接收端→新行动的观看收益，避免一直等速贴弹头或只给掌心特写。施法近景与邻镜接足身体取位/支撑，快速移位与术法在途保持方向，固定范围可承担领域变化/巨物侵入/作用传播，不让人物等绕拍完成。

全局给角色战法、能力与共享画质，S写双方人物及法术/代理的实际行动，fx-env：给同次主形、材质、环境与残留，sound：给声源，transition：承接真实相位。无需另交技能菜单或过程表，不为精简删掉专属施法动作。

并入一次复核：战法与角色是否匹配？新增持物是否有依据？施法动作是否真实改变术式？释放后人物的下一任务是什么？人物与法术的并行是否控制相容？领域有实际规则，召唤有实际任务，巨大主形有作用与结果吗？当前要求的高速、规模与摄影是否仍兑现？缺项修具体事件与依赖链，不以加禁令替代。

## 手势、结构与后续战术的参考学习增量

施法身体开合、手势和可辨主形的形成/方向/控制相接；重要成形可主动获得读取时间，但对手与本体后续任务仍成立。前招标记/残留或独立作用按既定机制创造窗口，后招利用；不强迫所有法师接近持械。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。

## 修仙战术与器物控制的适用增量

明确修仙定位时，让本场已设的离手法器、变诀、感知、护体、空域/法域或破法决定交锋。实体法器/有效术法投影/普通残像区分，控制与本体并行有资源依据；不让仙侠只剩武者近战加发光。详见[修仙战法](cultivator-tactical-combat.md)，体修/近身与用户锁定能力仍保留。
