# 2026-10-18 技能释放逻辑与动作流维护记录

## 触发
用户在同一份 30 秒 2D 打斗稿上继续反馈：技能释放逻辑和打斗逻辑还差，动作流畅度不够。

## 定位（规则已有，未被强制采用）
- [打斗默认契约](fight-default-contract.md) §3 已写"意图→尝试→应对→结果→新条件"，§7 已写能力四拍；[战斗执行](combat-execution.md) §9 已有 `当前局面 → 起效条件 → 来源与路径 → 对手应对 → 结果 → 后续` 的公式；[近身持续交锋](continuous-close-exchange.md) 已写收势提供下一招条件。
- 实际稿仍在三处失效：①整段没有可读的争夺，输赢条件只写在设定里；②技能成形缺少"起效条件"，画个圈就喷，追问不了为什么；③镜头按事件列表排列，上一镜的出口没有被下一镜用掉。
- 因此不是缺规则，而是入口没有强制产物、参考页没有把"条件—反制窗口—出口"接成一条链。继续追加同义禁令不会改变下一次选择。
