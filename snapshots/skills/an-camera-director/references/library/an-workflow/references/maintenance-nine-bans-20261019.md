# 2026-10-19 九条禁令与施法者身体维护记录

## 触发
用户列出反复出现的九类错误：乱切镜、动作没逻辑、动作不流畅、方向位置错乱、动作慢吞吞、技能动作不好看、摆 pose、非必要黑场、两人对峙停顿，要求复查工作流。

## 复查结果
- 乱切镜、没因果、不流畅、方向错乱、慢动词：前几轮已有规则，但分散，入口没有一份可逐条核对的清单。
- 技能动作不好看：只有特效语法，缺"施法者身体"这一层（起势/发力/收势、剪影、手与特效同步）。
- 摆 pose、对峙停顿：契约只写"0 个独立停顿、摆 pose"，没有点名"两人对视、互相等"。
- 黑场：只有舞蹈转译写过"不另加黑场"，打斗稿没有通用禁令。
