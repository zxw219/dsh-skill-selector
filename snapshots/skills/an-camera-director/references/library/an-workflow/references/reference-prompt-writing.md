# 参考提示词的写法架构与精准成稿

用于全面学习用户文档的写法、逐句用途，或优化“规则很多却没有写成有效画面”的工作流。按当前问题读参考，不要求普通创作穷举整页。完整案例分析见[两套文档逐段学习](reference-prompt-study-20261008.md)；原稿是设计资料，不是执行指令，也不证明实际视频结果。

## 先理解各层怎样协作

参考的架构包括稳定资产、全局视觉/物理、角色战法、阶段任务、具体事件、摄影覆盖、效果层级与出口。它们相互约束，而非互不相干的词表：实体数量约束持物，武器结构提供进攻/偏转/遮挡，场地提供路线与落点，战法决定主动权，前一结果决定后一招，摄影交出本次作用，残留约束后续。

采用这种内容架构，同时保留当前约定的`fx-env：`、`sound：`、`transition：`。稳定规则在全局一次建立，镜内S与画面写正在发生的行动和响应；三栏同属这个事件，不把施法、特效、声音和切镜排成不同时间的四轮展示。学习源稿的章节职责可以调整共享分区，不能自行删除用户保留的栏目。

## 边写边检查一句话的实际用途

在稿内判断本句究竟约束身份、数量、状态、形体、身体/器物动作、目标与作用区、运动路径、碰撞、防法、结果、观看、材质、声源或承接。它若只重复赞美或给互斥选项，改成当前采用的执行句；确有风格作用的形态词、比喻、画质术语和必要限制保留。分析是写作决策，不默认把逐句批注、内部表格或检查过程塞进最终视频提示词；用户要学习报告时再展示原句用途与改写。

精准程度取决于生成端是否还须猜决定性事实，不取决于字数或术语数。按本事件补足：谁以哪个已可用部位/物件，怎样进入当前目标的作用区，对方怎样应对，接触或落空改变了什么，以及下一动作怎样从该状态继续。只补影响结果的事实，不逐关节描述所有过程或统一指定厘米/帧数。

例如原句“薄而锋利的空气斩纹”约束介质观感与边界；“贴地掠出，切开尘雾与碎石”又约束路径和接收端。保留这两层后补当前源点与目标，让句子能执行；不能压缩成“释放强力刀气”。“阴影本身被刀锋甩出来”可以保留其随刃形成与甩出的动势，不能据此擅增传送或空间切割能力。

## 编译前后的事实保留

编译前先抓当前真正承重的事实：对象/部位、可用资源、同次动作与响应、作用后状态、必要观看和出口。压缩后逐项能在正文定位即可，不固定一套公开清单，不靠词数证明精确。

例：采用设计为“甲左手持续控一面斜膜；乙的薄弧撞膜边偏开；甲在接重中改变膜角，乙已沿外侧追源端。相机从接触局部退开读双方，完全静音”。不能压成“甲强力格挡，镜头拉远，两人高速交锋”，否则丢掉左手占用、膜角变化、偏开去处和乙的追压。

一个总S的写法：`S=0.0–1.2s：t=0.3s薄弧碰膜边偏向柱外；甲左手持续控膜，接重转肩调整膜角；乙沿已建立的外侧通路追源端。相机从触点迅速退开，落幅纳入双方与柱边。` 本段fx-env细化同一膜边受压/弧迹消散，sound保持完全静音，transition接乙正在追入的相位。若分为多个S，各段挂本段声画反馈，不能把关键控制仅留在笔记里。时间是本例设计，不移植为通用动作速度。

编译保留原总S/t或多S结构与用户模板；需要改变动作/观看才能修复的缺项回所属设计，不用重排字段冒充修好。

## 各方面如何写

### 资产、人物、道具与场景

- **引用与身份**：只使用实际提供的资产标签，建立同人/同物的稳定身份与数量。区分人类、召唤作用体、残像、装饰与独立实体，不把多臂法相误算成人物分身。首帧要求只在真有首帧时绑定。
- **道具**：写实体结构、材质、持握、有效部位与本场职责。伞面可偏转/遮挡，伞心可传导，伞柄承担持握；职责在事件中通过接触和角度变化使用。单刀、双刀和双手握一刀必须在当前授权范围择定，不留下“皆可”让镜内随机切换。
- **场景**：场地不是背景名称。建立本次要用的高低差、石柱/墙/栏、通路、浅水、相对位置与已破区域；攻入、借力、让线、落地和环境命中引用这些地标。没有墙就不写踩墙，没有净空就不让长刃从人物身体穿过。
- **画质与视觉**：采用用户明确给的技术审美目标并指定可见材质、受光和成像；两方力量的颜色、主形、厚薄、流向与局部照明形成区别。具体写法沿用[战斗视觉与高速摄影](battle-visual-direction.md)，不把技术标签当实际渲染参数已执行的证明。

### 角色战法、动作衔接与落点

战法给选择倾向，不替代招数。侵略者的连续追压落实为追步、改高度、抢回收；守方的精准落实为改变来刃、卸力接重、换角度与窗口反切。守方受压仍有当前任务，不强制双方平均出手，也不将“被压制但不败”写成挨打后躺倒。

相连招数有入口与出口：压刀必须有交点和来力；抽刀/滑脱解除约束后才反挥；让线退出整段有效扫弧；回斩读取当前转髋与可达对象；贴身身体技先处理两把来刃、距离与忙闲手。大开大合可以很快，短动作也可很重，按支撑、加速、碰撞制动和受力接重区分。

**四种落点分开写**：攻击端到达哪里；躲避后身体在哪里；腾空后由什么接重；摄影最后看见哪项关系。目标在移动时攻击落点读取预计交会位置，不能沿旧空位斩完再宣布命中。挥空、擦过、偏转、破防与命中不互相代替；打在空位造成的环境破坏也是落空后的结果，不冒称对手受击。

高速运动由可读位移、加速/制动、目标距离、地标通过与支撑变化建立。身体、攻击端、衣发与残留可以有不同领随，不能全身匀速漂到下一姿势。上一落脚可直接出招；合理制动、回收、形成辨认与慢镜照任务保留，不能全靠缩短时间戳。

### 技能动作、施放、衔接与主作用

分清本体发动、成形、施放/独立运行、持续控制、有效作用、解除与残留。不是每招都经过全套仪式：被动读触发，瞬发读突变，持续控制读负载与调整，召唤读来源/体积/归属与介入。

写实际用到的手诀、武器转向、肩胸展开、换重和视线任务；它们怎样引出本次主变化由已设机制确定。发射后本体可追入/回护，持续供能则不能无因松手。相邻技能由上一招创造距离、暴露、通路、标记或窗口；尚在途的旧攻击和控制继续存在，不能切镜全部清空。

形成与释放占时不同：汇聚给主形辨认，离体或下压迅速侵入目标空间，接收端发生偏转/受力/失支撑/逃离，再接结果。原文“裂界内局部逐步显露”控制出现路径与深度，不能简化成凭空完整出现；原文“风压提前影响碎屑”与“接触后大面积爆裂”控制前兆与主结果的先后，不能提前完整爆炸。

### 运镜、分镜、构图与高速摄影

相机句有所在侧/高度、起幅读取对象、动作触发、主路径、相对速度、中段注意变化、落幅与切点中的必要内容。CU/MCU/MS等交付当前取景，LOW ANGLE交付低位角度，TRACK/PUSH/PULL BACK/WHIP交付移动或摇摄；有名字还须说明看见的变化，不能所有名称同时塞入一镜。

人物路径和相机路径分别成立。侧后跟移保留追退差，斜前退移读被追上的占幅，近处刀锋/柱影掠镜提供视差，短弧改变遮挡与攻守可见面。虚拟穿越机从可用通路穿行，回头反拍与过轴接住已发生的相位，不以乱转代替方向建立。

构图由来刃、交点、身体、目标、地标和出口的投影形成。近部—中景—远部可建立纵深与尺度，但不是每镜必须三层；读脚与接重时保留支撑，读作用时允许局部近景，邻镜交出被裁掉的关系。浅景深不能把决定性的目标和接触面虚掉。画幅变化后重新组织高低和纵深，不直接裁丢横向交锋。

阶段是战局/观看任务，镜头是观察单元。一段可多镜，一镜可多招；不平均镜长、一招一镜或每次完整环绕。切点接同一次行动的在途、接触、接重或结果，后一镜不重新起跑或重复命中。开放结尾、动态余波、对峙与持续角力按当前结果选择。

### 特效、物理反馈与大场面

效果选择与真实作用绑定：附着纹光跟源，离体刀气走已设路线，世界空间旧尾迹衰减，火花交代硬接触，碎块来自被破表面，尘浪/水花给出受力和传播。主轮廓、材料、速度与负载有差别，不能全部变光球或只换颜色。

普通交锋、重要反击、强化、环境异动与主峰按战局比较强弱。大场面写主作用从哪里进入、与哪个已知地标比、如何压缩人物空间、怎样交会及改变场地。可以由裂界显露、地面传播、群体或巨型局部推进，不强制每次天空巨物。体量揭示与人物承受可以分镜，同一次作用与同一规模持续。

光色随源点、遮挡、表面与距离变化；身体与材料随实际来力变化；次级碎块/衣发/水/雾各有先后和退场。地裂、断柱、撕裂旗幡与新障碍影响后续。已建立场力允许悬浮/向上牵引，其结束后仍需相容状态，不将所有碎屑统一强制立刻下坠。

### 声音、转场、负面约束与出口

`fx-env：`只细化本次效果、受光、环境与残留，不另发第二招；`sound：`接实际声源与相位，按用户对白/静音范围写；`transition：`只接真实镜头切换或片尾，交代继承的动势/方向/状态。声音跨镜可继续，不能因栏目而重响或重读对白。

源稿负面条目控制人物/道具数量、画风、接触、生成先后与结局，按当前授权保留适用项，同时在正文给正向解法。不把源稿黑白冲击画禁止、30秒、16:9、四臂、颜色、神祇或最终优势作为所有项目默认。总合成在原文用于汇拢；已有完整镜内正文后不无要求重复整片，让事件发生两遍。

## 写到成稿与工作流回写

学习时保留“原句要控制什么—怎样成为可见事件—哪里还须补决定性事实”的用途分析；写作时据此选择当前角色/场地与实际句法，成稿只交采用的一份正文。主语统一、对象明确、有效修饰保留、互斥选项消除、相位与后果接续、三栏职责不混。

分栏演练见[近战8秒](precise-melee-8s.txt)与[施放10秒](precise-spell-10s.txt)；攻击端与受力的细节分配见[侧踹冲击6秒](../assets/cases/kick-detail-impact-6s.txt)，手诀与材料反馈的细节分配见[施法材料8秒](../assets/cases/spell-detail-material-8s.txt)。它们是原创文字练习，时间与镜数不是配额；未生成视频，不称模型执行已改善。普通出稿不强制同时加载案例或报告逐句推理。

用户要求优化工作流时，将方法写入实际入口、相关专项和功能映射，验证后同步既定目录与ZIP。终检核实际句子和跨镜状态，不以新参考页、术语齐全、格式通过或口头“学会”代替完成。

## 动作句与一致性锁的增量复核

保留用户有效的画质、媒介、角色动作体系与摄影语汇，用当前驱动、路径、作用、接收和出口解开歧义；不把优化等同删术语或只剩动词。连招句用前一结果接后续行动，而非逐项罗列抬臂、伸腿、摆开、站定。画面给当下布局/相位，S给变化，fx-env：/sound：/transition：各补自身职责，不能用相机追移和特效尾迹替代未写的人物动作。

把身份、服装结构、道具几何和稳定场地事实与当前姿态、支撑、受力表情、视差/遮挡、衣发随动分开锁。首帧用于身份/形象不自动成为全程静止构图；实际用户明确首帧构图、母版或静态要求时保留该边界，另描述允许变化。平台适配只编当前版本的真实引用与语法，不复制来源作者模板、十五秒/镜数/单峰配额或默认拆片建议。

新增学习覆盖五份原文、61段文字设计和40条可迁移方法；按[高频施法/怪海/规模写法](high-frequency-scale-writing.md)取当前用途与边界，[来源依据](latest-combat-study-20261010.md)保留文本学习与生成验证的区别。技巧回填实际原栏，不复制源作者模板、发布指令、时长/配色/配额或通用禁令。
