# 无对白神话段：动作、接收与表达渠道

用于无对白/非人角色的分镜像海报、动作与接收单薄。继承[整段分镜](storyboard-sequence-design.md)、[表演](drama.md)、声音与角色解剖；神话案例不成为下一场的剧情、情绪顺序或拍法。

## 无对白仍有任务与接收

从人物想影响谁/什么、受到的刺激与障碍、选择及其后果组织事件。表演可通过眼、头部、呼吸、手、重心、轮廓、材质或机械结构体现；角色没有瞳孔、嘴、鼻翼、喉结时不添加人类器官。沉默、后背或面罩可以成立，关键理解由本角色确实具备的渠道交付。

动作选当前有作用的尝试、受阻、改法与终态。承托/交接须新支点成立后才退出旧支点；重量、温度、衣物、风或火只按当前素材与设定响应。走、看、等待可以承担信息与压力，不能仅因动词简单删掉，也不能无任务堆小动作。

## 根据实际转折选覆盖

关键转折先有刺激/读取，再有决定及可见变化；脸、手、全身、对象、视点、范围均为可选证据。可同框、镜内交接或跨镜，不固定“怕—定—软—忍”，不规定每幕插入/反应/视点各一次或全片两个匹配切。无对白不等于完全静音，声音按用户范围；完全静音时靠画面兑现。

神、人、动物、环境或代理若影响下一拍，给其实际作用与接收，不强塞同一组参与者。规模靠可靠参照、通路、作用与后果，不靠持续远景或持续切脸。图形匹配、轴向切、留白、对称和近景按观看收益选择，不要求大师技法数量。

## 结尾与留白

从本片实际落点选择人物、关系、物件或世界；不默认仰拍冷光脸、赠予物视线、悲剧定格或最后两秒冻结。用户锁定以景收尾、不露脸、单镜或持续运动时，在这些变量内交付当前理解。结尾是否完整由已定出口与未决作用决定。

## 复核与案例

查关键任务、作用、接收、表达渠道与跨镜状态是否可读，保持/省略是否有用途；数量和景别不是验收证据。身体动作、观看与效果分属各自职责，局部调用不重写剧情。文本通过不证明成片表演。
