# 2026-10-18 动作衔接与技能释放维护记录

## 触发
用户纠正："高频高速是指动作与衔接，技能与释放"，并指出技能设计描述仍差。

## 定位
此前几轮把"快"理解成动作数量与攻防转换，没有处理真正的机制：**后摇能不能被下一招取消**。旧稿每镜一个动作、镜与镜之间靠切，等于每一招都等收招走完再起手，动作再多也是回合制。

## 新读到的外部资料
- [《〈鬼泣5〉、〈只狼〉：动作游戏设计思考与分析》](https://www.gameres.com/forum/t/882861)（GameRes，腾讯游戏学院）：攻击动作＝前摇帧＋攻击帧＋后摇帧；接续规则（后摇、取消、目押、序列技表、连招）越自由，主动反应频率越高；鬼泣大部分技能无缝衔接，长后摇用切武器取消；猎天使魔女的 Dodge Offset 闪避不中断连招；平A前摇约 5/60 秒、红剑充能判定约 12/60 秒等量级。

## 写回
- 新增[动作衔接与技能释放](action-linkage-and-release.md)：动作三段与可取消窗口、三种接法（取消接/同帧接/借势接）、闪避不中断连招、技能的释放三段与三种释放节奏、动作与技能共用接口、交稿前自检。
- 入口路由加一行；[速度与技能设计](speed-and-skill-design.md) 的攻防一体节接入站链接。
- 未改既有密度、镜头与对抗性规则。
