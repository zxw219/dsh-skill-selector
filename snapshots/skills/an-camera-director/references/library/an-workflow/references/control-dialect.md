# 控制方言

用户明确选择紧凑An、两层时间轴/视觉配比，或要求解决控制字段冲突时使用。仅增加A/B代号、FS等景别缩写或一个t=锚点，不触发本页、不改变已有模板。明确采用的成功样本只在其指定职责内校准。本页负责控制字段语义，不证明目标平台一定按字面解析。

## 先辨认字段角色

- `A`、`B` 通常是主体代号，不是镜头语言。必须在全局区定义一次，后文保持同一身份、外观和道具归属；若原文另有定义，以原文为准。
- `FS`（Full Shot）、`MS`（Medium Shot）、`CU`（Close-Up）、`ECU`（Extreme Close-Up）是常见景别缩写。可以同时附中文说明，但二者不能冲突。其他缩写只有含义明确或用户已定义时才保留，不能凭字母猜测。
- 运镜词描述摄影机路径，景别词描述画面覆盖范围，主体代号描述谁在行动；三者不能混为同一字段。

## 两层时间轴

允许一段提示词同时存在：

1. **宏观时间段**：例如 `0–9秒【冲阵与受阻】`，锁定场景功能、运动走廊和主摄影策略；
2. **段内事件节点**：例如 `t=4s`、`t=6s`，锁定关键动作触发、接触、技能释放、切换景别或结果出现的时刻。

默认把 `t=` 解释为全片绝对时间；只有用户明确说明时才使用段内相对时间。节点必须落在所属宏观段内并严格递增，前一节点的结果要能成为下一节点的入口。节点是事件锚点，不是单帧塞入多招的许可；两个节点之间允许持续跑动、回收、受力、特效传播和摄影机过渡。

节点按实际用途选择两种精度：

- `t=4s`：用户明确要求的硬锚点，或会改变身份、持物、位置、主动权、能力阶段、镜头阶段和结局的关键时刻；
- `t≈4s`：平台未核验精确时间服从性，但仍需要表达先后与大致落点时使用的柔性锚点。

不得把原本明确的硬锚点擅自改成柔性锚点。用户未指定精度时，关键接触和段落出口可用硬锚点，次要过渡优先写进相邻节点之间，不制造虚假的逐秒精度。

不要求每秒都有节点。每个节点默认只保留：`时间锚点 | 景别/运镜 | 主体动作与路径 | 一个主要状态结果 | 随动作触发的特效`。一个主要结果可以由共享运动路线的2–4次因果连击形成，但每次命中都要有接触和受力证据；不能在一个节点并列多个互不依赖的结果。纯延续状态不必重复标注。用户提供的成功样本已证明高密度节点可用时，可以沿用其密度，但仍须修复样本中的人数、复活、忙闲肢体和时间矛盾。

## 段首摄影路径预告

紧凑An模板每个宏观段标题后保留“镜头预告”；其他模板按用户指定结构。可用二至三个短语预告摄影路径，例如：

`超低机位贴地飞掠 + 极限甩镜 + 动态特写`

把预告理解为有顺序的摄影合同：`起始机位/运动 → 由事件触发的转换 → 读取结果的终点镜头`。例如贴地飞掠用于建立冲刺路线，甩镜由新威胁或动作落点触发，动态特写读取一次关键接触或状态变化。段内节点必须按此顺序兑现，并给出触发对象和停止点。

加号表示先后组合，不表示三台摄影机同时执行。若几种策略不能位于一条可达路径，必须写明切镜或中性桥接；仍不成立就删去收益最低的一项。固定镜头的预告写保持机位、场内信息变化及同构图结果，不能因无运镜而删预告；时间分段不是切镜。每段可使用不同组合，也允许稳定主镜；不能为了格式机械复制“贴地飞掠＋极限甩镜＋动态特写”。

## 特效构成比例

类似 `能量体50% + 水墨25% + 流体25%` 默认是视觉构成权重，不是通用渲染器参数。用户指定或成功样本明确采用时原样保留，并把比例落实为不同职责：

- 能量体：核心亮度、力量来源、传播主路径和命中主体；
- 水墨：边缘破碎、扩散纹理、冲击转场或消散痕迹；
- 流体：拖尾形变、绕体运动、卷吸和回流。

写成百分比混合时检查合计是否为100%；若用户有意使用非归一化权重，保留并标明是相对权重。比例默认在全局定义一次，节点只调用当前动作实际需要的层，不逐段重复百分比。只有剧情或技能阶段确实改变视觉主次时才更新配比，并说明变化触发点。不能让三层重复承担同一效果，也不能用配比遮住手、脸、武器和接触窗。未指定比例时按画面需要描述可见职责，不擅自编造数字。

## 推荐交付骨架

```text
【全局事实】媒介、时长、画幅、身份、道具、场景与起始状态；结局状态仅在相应事件后写入
【代号与镜头缩写】A/B；FS/MS/CU/ECU
【特效构成】比例 + 每层唯一职责

【0–Xs｜段落功能】起始机位 → 触发转换 → 结果镜头
t=...｜景别/运镜｜主体动作与路径｜主要结果｜适用特效
t=...｜景别/运镜｜承接动作｜主要结果｜适用特效

【连续性锁】只列高概率漂移且正文不足以维持的项目
```

本页骨架只在用户明确选择紧凑An模板时使用；选择某个控制字段不等于选择整套骨架。其他情况下将需要的字段融入当前模板，保留原标题和顺序；参考样例不自动取得模板优先权。修复缺失定义、节点过载、摄影不可达和特效职责冲突时，保持已选模板。

## 保留与降级

用户明确要求或已校准样本中的控制方言属于输出事实，应优先保留。负载冲突按入口顺序处理：先删重复装饰和无功能机位变化，再整理共享动势的动作，保留攻击密度、时间锚点、主体代号和已要求的配比；不能以格式简化为由先删有效攻击。仍超载且须改变硬要求时说明冲突。
