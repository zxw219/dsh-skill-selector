# 多人战斗适用终检：先查战局，再查好看的局部

用于团队、二对二、一对多及“全员站桩/旁人停机/敌前救援/距离混乱”的成稿和成片。先沿整段查最早失效，再查角色、动作、摄影和生成的具体层；不只抽查高潮。任务模式、用户事实、格式、能力、时长和专项修改边界继续有效。

## 先验共同交锋与观看体验

继承普通快战的速度、频率、力量、动作变化和主动摄影要求。先查多人关系是否真的改变、动作是否有实质接续、分镜和运镜是否让观众读到这些变化，再查下表中的状态连续性。全员有任务、无穿帮、无停机，只完成了条件核对，不能据此称多人战斗已经精彩或学会运用参考。

沿实际共同交锋单元检查：

1. **关系发展**：谁改变了谁的攻线/支撑/控制/机会，谁已经到位利用，敌人怎样拆配合；独立并行与自由混战不强行判为团队。删去所谓协助者后若其余动作可原样运行，不能称为有效配合。
2. **动作变化与接力**：前一接触、受力或高度变化是否提供下一模块入口；实际身体/兵器/施法过程是否不同，攻击端加速、接触制动、受力与恢复是否能看见；角色轮流演短挡侧移、背景长蓄力不能靠名单齐全放行。每人的准备、入距与恢复共享时轴，不能通过切镜排队。
3. **分镜因果**：介入者在结果改变前是否可定位，关键变化和利用是否读清，镜尾为何交给下一关系；“甲一镜、乙一镜、丙一镜”若缺共同变化，回关系设计，不只加几个全景。
4. **运镜执行**：实际起幅、交会触发、相机净空路径、相对速度、显露/遮挡变化和落幅读到什么；摄影转走后旧关系仍怎样推进；四人同框或环绕一圈不能替代观看接力。固定与一镜按各自允许变量验收。
5. **多向压力的可信度**：处理第一向后暴露/限制了什么，第二向为什么此时到达，外围何时解除遮挡继续；不能把一对多编成礼貌排队，也不能让所有敌人同时穿到同一点制造假高频。

任何体验项缺失，回[共同交锋单元](../../combat-action-design/references/team-combat-choreography.md#先编共同交锋单元)、[关系分镜](../../action-camera-direction/references/multi-character-coverage.md#从共同变化决定镜头)或[接力运镜](../../action-camera-direction/references/continuous-fight-handoffs.md#把关系交接落实成相机运动)修最早缺口。修空间时不通过删人、缩水动作、放慢攻击或冻结画外来求稳；修完重新核体验与全部受影响的同期状态。维护时可用[短例与边界审阅](../assets/cases/team-shared-action-20261016.md)校准，普通创作不加载整套练习。

## 状态与条件核对

| 必查关系 | 需要的证据 | 不能作为放行依据 |
|---|---|---|
| 开局目的 | 本轮争夺、正在形成的威胁、入距/抢位/判断或合法保持的作用及触发 | 四人摆架、衣发飘、技能亮起来 |
| 全员同期 | 正确指认当前交战者；每人的相位、限制与出口，准备/进入/接触/恢复怎样重叠 | 只分任务；“其他人警戒/等待/蓄力”但没有条件；把旁观者算停机队友 |
| 有效距离 | 来线、交会时点、目标同刻位置、射线遮挡/净空、盾的实际覆盖、高低与支撑 | 近景变大、切到近身、泛称精准/全程掩护 |
| 持续攻防 | 新来向/距离/负载引起相容的高低、支撑、接触/武器任务与释放变化 | 伸手举盾、反复短挡侧移，身体与战术复位；随机小动作冒充忙碌 |
| 协作作用 | 协助改变条件时利用者已能入距/操作；主攻实际利用，对手拆配合与出口 | 同屏、同时、不同颜色；先出现瞬间窗口再让远处队友赶来 |
| 救援条件 | 束缚范围、操作/资源、窗口来源、实际接替、全部可达续攻处理、释放后恢复 | 有解藤画面但近敌停机；裁敌特写；绳断直接接满状态反攻 |
| 一对多压力 | 关键敌人推进/改线，外围真实受阻或绕行；单方顾一向后的其他限制 | 人数多、敌人排队/挥空、主角一只手万能处理两向 |
| 镜头继承 | 同次剩余相位、画外新位置、在途作用、残留、动态关系轴和高度 | 镜号齐全、甩镜、遮挡、切回初始坐标 |
| 每镜关系闭环 | 镜前状态→镜内实际改变→其他人的同期进程→镜后未决状态，并有可辨身份/目标绑定 | 各人独立镜头串联；全局写四人而特写重造四人；增加镜数但缺共同进程 |
| 结尾关系 | 战斗继续的未决动势，或明确中止/退距/胜负条件 | 双方突然同向排队展示而无触发 |
| 连续镜内接力 | 新对象转镜前的位置/相位、交会触发、旧关系续行、遮挡后地标/持物承接 | 一镜到底标签、依次四人各演一招、背景全虚或白闪掩盖未决状态 |
| 身体组合兑现 | 前一拍的接触/高低/支撑提供后招入口；对方同期反制，释放/接重后接新任务 | 只列拳肘膝翻摔名称；相机转圈代替身体转体；落地回开场 |

对手“没有动作”先区分尚不可达、视线受阻、受压维持、恢复、观察判断、剧情保持与无因闲置。保持有作用不强加随机动作；连续快战要求下无任务静止不能放行。全员一直乱动也不是通过标准。

救援作为独立重点复核，不能因为局部束缚消失就通过。把敌方当前自由可达续攻加入同一时刻，检查救援是否被打断；若必须脑补敌人等待或新增能力，返回[多人动作](../../combat-action-design/references/team-combat-choreography.md)修当前链。缺失敌人画面是观看问题或证据不足，不自动证明其停止；也不能因在场就一律禁止边防边解。

声称合作处做一次局部反向核对：去掉协助者，机会/负载/结果改变在哪里；利用者晚到一个必要相位，窗口是否仍有效；对手抽离或绕出后，旧控制/遮挡何时失效。无需每场输出分支表，独立并行作战也不硬标协同。救援若本来失败，保留真实失败；若声称成功，要核完成破除和释放后的恢复，而非一直争窗口便算学会救援。

摄影只查已成立行动能否看清，具体用[多人观看覆盖](../../action-camera-direction/references/multi-character-coverage.md)。不让近景/切镜替代空间或窗口；只有摄影授权时，报告最早上游冲突，不越界重写动作。

完整导演任务在关键关系设计阶段就核每镜闭环，动作调度与观看结构往返校准；不能直到终检才发现孤立镜头拼不成战局。检查分开镜头欠建立/欠覆盖/回接断开、动作本身互斥、正文角色/目标歧义与生成未遵循。分镜是重要控制层，但无源稿或新成片对照不把所有bug确定归为单一原因，修镜头也不冒称已修实际视频。

## 成片检查范围与结论

多人连续段的具体取证用[镜内接力](../../action-camera-direction/references/continuous-fight-handoffs.md)，动作组合看[接触与高低](../../combat-action-design/references/contact-height-combinations.md)。器物/触脸等非战斗参考按[表演响应](../../performance-scene-director/references/contact-task-response.md)检查相关接触和资源，不套多人攻防项。宣传包装的明确切换、慢放/定格与无法认证的接合分别记，不能反推出原始生成只有一个镜头或某平台稳定率。

先正常速度看每人的实际运动、攻防变化、注意与节奏，再在起步、闭距、束缚/救援、目标交接、高低转换和切点加密复核。没有播放条件时，可先按完整抽帧及疑点密采样报告静帧/相位证据，明确未做播放/声音与未见条件；不能由抽帧认证瞬时速度、持续停机或所有切点无错。

源端方法/提示词未拿到时，不把所有失败归给生成器，也不确定声称某一句造成。分开提示欠写、动作矛盾、观察未执行、生成没遵循、素材遮挡和未知。对原片抽帧看见的几乎无位移关系与用户正常观看反馈可联合定位，但说明来源，不假装自己重新连续看过。

从最早断点回修受影响链并复核。文本语义通过不证明新成片；结构/链接/ZIP检查不证明审美或生成稳定率；资料与作者练习不称独立盲评。合法对峙、仪式、慢镜、单人展示、固定单镜和持续受压保持必须保留。
