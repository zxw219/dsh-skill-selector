# 速度型战斗：极速、相对时间与交锋

用于闪电侠/快银式超级速度、极速感知、正常世界近乎凝滞而角色行动、高速者互斗及相应返工。普通高速拳脚、快剪、普通追逐不自动获得超级速度；仅说“飞速”先从题材与已锁能力判断。本文是动作、观看、时间及特效的共同接口，各专项只修改原有职责。

## 1. 先确定速度改变了什么

继承已定能力，内部确认实际移动/飞行、感知判断、肢体操作、加速/制动/换向中哪些超常，是否存在发动条件或持续控制。只给了高速移动，不自动取得同级感知；明确速度者创作且获准补未定项时，选择足以支持当前任务的协调能力，不为每一项额外设门槛。用户已给强度就保留，不能因物理检查把极速缩回普通冲刺。

闪电侠、快银在不同作品中的规则并不统一；可以借鉴外部瞬逝或慢世界中的行动语言，不自动移入神速力、放电伤害、穿墙、时停、逆时、时间旅行、无敌或分身。实际飞行按已定推进/御空机制转弯，不强求脚踩地；地面跑动、滑移、借面与跳跃则保留相容支撑。

## 2. 分开成片时间、世界进程与相对速度

- **成片时间**：观众看到的S段与`t=`锚点，沿原模板连续到锁定片长。默认0.1秒是表达精度，不是世界最短行动单位。
- **世界进程**：场内事件实际前进多少；按需要追踪闸门边缘、下落物、雨滴/水团、正在扫过的攻击或引信等可辨状态。主观段可播放数秒而世界只前进很短一段，不要求每个普通人都完成新动作。
- **相对速度**：速度者、同级对手、普通人、投射物、机械与接触后物体分别按能力和动力推进；它们共享世界事件，不共享屏幕运动速度。无关对象不因镜头换档突然追平。

只写影响理解的时率关系，未锁倍率不编造精确万倍/毫秒。需要数值时，同一档内世界增量按成片占时与所选倍率相容，换档另接；不把主观时长加成世界等待。没有必要公开三张表，正文给当前档位与决定性参照即可。

同一个物体在切换前、主观段内、回正常段后继承位置、朝向、速度/受力和损伤：正在坠落的螺栓可只缓缓转过一点，机械臂仍朝原方向推进，角色触碰后则从该触点改变运动。**近乎凝滞是相对运动，不是获得时停。** 风险来自世界中仍在发生的威胁，不能一切清零等待主角表演。

## 3. 从速度优势编战斗，而不是只跑得快

确定本次要夺取、拦截、击穿、防住或阻止什么，再从速度改变的机会选相容动作乐句。候选不限于以下结构，也不每场齐备：

**先试直接极速解法**：代入已定的移动、感知和手脚速度，此刻能否在普通对手完成原动作前解决目标？如果能，就围绕真实的极速执行和后果设计，不能为填满片长让主角先普速拆手数秒、等敌人补完多轮护腰/转身，最后才想起加速。确有持续接触的力/结构限制、保护任务、观察或主动诱导时，可有目的降速，正文须读到这项约束或选择；没有依据的忘记能力先回选招层，不临时加弱点。

**同级也须让速度持续作战**：不是开场掠过几米、随后整段普通抓腕顶推便算完成。已定的极速应继续改变追及目标、交会地点、攻击线、反应窗口或真身出口；相互牵制可锁住位移，按任务读持续负载、改控/争脱或其他有效发展与出口，不按持续时长判错，不强制争脱或反扑。纯外部不能看清全部瞬间时，选择能辨身份和前后因果的交会姿态、轨迹间隙与结果，不为逐招说明把世界速度降成常规互拆；也不靠一长串模糊取消关键接触。

| 当前难题 | 可比较的速度型解法 | 必须在事件中成立 |
|---|---|---|
| 前方攻击已经出手 | 切入其行进线、绕过有效体积、短促触碰改向后立即转攻 | 来袭的世界进程、入距路线、实际触点与改变后的去处；不隔空抹掉威胁 |
| 目标在移动或多处任务相互牵制 | 连续截点、穿插换层、急停折返、改变处理顺序 | 跨过哪些参照、每次接触改变什么、落脚/转弯与下一目标；不是原地连挥 |
| 借冲势进入近身 | 掠身击、转轴避线接回击、卸速滑入、低位穿越后回切 | 交会时身体/兵器路径和目标受力，从上次出口继续，不每击站好 |
| 对方能追上或切断路线 | 变速诱追、假入口真转向、抢未来交会点、反向截击 | 追当前真身和可达出口，双方速度/感知差与路线约束持续；不是追残影 |
| 已有空间/机械威胁占住通路 | 抢在封闭前通过、绕入空隙、短暂改线或先解除一处阻碍 | 可用缝隙的时机与体积，障碍继续推进，不能高速穿实体 |

起动、急停、换向可极短，按既定超常动力保留压缩的加载、身体倾转/转轴、受力或新支撑，不强加数秒刹车。高速不必每次大弧跑圈，也不统一锯齿瞬移；路线由拦截、攻击面和目标变化产生。主观段中可有从容的精密操作，也可仍是迅猛交锋，按本场体验选择，不能整段只慢跑观光、碰一下人就结束。

单人多点出现时追踪同一真身；残影只记录旧相位，没有独立攻击权。若选抽象轨迹略去中段，前后状态与可行通路仍能推出实际穿越；不是每格都清楚，也不是用光线随意连接两端。

## 4. 对手按实际速度和信息应对

**速度者对普通人**：普通人只完成世界时间允许的启动或延续动作；不能在极短世界进程内追眼、转身、连挡多次。可处理的是进入极速前已发动/预判的攻击、既有机械动作、占据区域的威胁及速度者自己的目标取舍。原创允许从开始设计这些相容条件；锁定稿不得结尾临时添自动锁定、万能陷阱或新弱点给普通敌人翻盘。明确碾压、无有效反制可以成立，不为维持对称打斗削速度。

**同级/不同级速度者**：双方可在慢世界中互相追及、错位、截击与近身；普通背景慢并不意味着两人也慢。先确定谁此刻相对占优、信息和转弯/距离窗口，再把追及、脱线、接触、受力与续攻写出。不能全程一前一后跑圈，或按“你打我一次”做冻结背景中的普通拳赛。

速度不是永远免伤；已知同级追截、封路体积或碰撞可以有效，须有实际可达性。反过来，“敌人有同期任务”也不等于敌人必须能跟上。受击从真实接触开始改变对象动势，回正常时间可读到积累后果，不另加一段“此前接触都还没生效”的延迟魔法。

## 5. 选择能证明速度的观看关系

| 观看方式 | 主要证据 | 避免的退化 |
|---|---|---|
| 正常世界的外部观察 | 已知入口/出口、人物极短穿越、观察者来不及跟随，接触和余波留在原地 | 完美等速跟拍把人锁成原地跑；只甩一条光线没有结果 |
| 速度者的相对观察 | 身体路线与手脚操作可读，背景事件缓进，固定物因相机位移产生视差 | 把视差当物体主动运动；所有人绝对冻结；把主角也统一慢放 |
| 同级交锋的相对观察 | 两个真身持续争线，慢背景/在途物提供速度参照，关键接触有相位 | 两条无身份光带绕圈；切近后忘记高速路线和出口 |
| 时间档位切换 | 同一地标/物体的未完相位承接，改变播放速度后看清当前结果 | 重播同次命中、重启爆炸、切回旧站位；换滤镜当时间机制 |

固定外部机位、稳定伴随或快速移动摄影都可承担证据，不因是快战而强制相机高速环绕。切镜或镜内变速都可换档，一镜到底不偷切，固定取景不偷偷跟走；裸眼POV不加光学变焦。主观慢世界是速度型能力的重要可选分支，不受普通快打“少慢镜”的偏好否决。

切换不强制三段固定镜序：需要外部对照时用实际穿越/后果证明；明确全主观或纯外部时在原锁定形式内建立相对速度，不擅自加回正速镜。速度感与动作可读各有证据，无须所有中间画格都锐利；决定性触点和路线关系不能全被模糊吞掉。

## 6. 特效、接触物与声音跟随同一进程

分开源体、附体表现、已脱离轨迹/粒子与被触碰物。附体光/电可跟角色局部动作；脱离后按本场既定世界进程传播、衰减或在相对观察中缓进，不让旧尾迹随真身急转全部翻转。无放电能力时，风格光迹不自动获得雷击伤害；没有尾迹也能用位移和时间对照证明极速。

身体穿过水/尘、碰到兵器或改变目标速度时，局部介质从该交互产生新运动，远处未受影响的雨滴/爆炸继续原时率。主观段中身体附近飞溅更活跃、脱离后缓进可用，但须是同一次作用的分层关系，不能任意把所有碎片一会儿冻结一会儿爆散。搬动/救援非速度者时，按当前世界已定的承载/保护与接收状态，不从某部电影复制必然伤害或自动保护设定。

**脱离不重设物体时钟**：受触物保留刚得到的速度和受力，松手/离体本身不把它恢复成未触碰背景的速度。相对缓进可以来自不再随源体驱动、阻力/既定动力或已选表现性时间处理，正文按需要明确；采用风格化局部时间归属时视为观看约定，不从粒子分类推导角色获得时停。切换回正常观察仍接同一状态，不能抹掉已有冲量。

冲击和空气扰动按所选强度、媒介与世界规则体现；不推导每步必然城市爆炸、每次超声速都必须声爆，也不为现实阻力把能力删掉。闪白、负片、速度线与电弧是强调，不能替代拦截、接触或战局结果。

声音继承授权：正常外部的短穿越/碰撞与主观听觉的拉伸、抑制、局部强调可相容组合；这是声画处理，不表示世界真的静音或物体暂停。变速后接触声、残响和回正速的后果按同次事件处理，不重复撞击，不强添心跳/配乐/雷声；完全静音版本仍须凭画面成立。

## 7. 编译与验收

沿原格式交一份正文：共享设定给速度能力与必要时间关系，事件段给当前档位、实际穿越/交锋、世界参照与新状态；fx-env/sound细化同次过程。不要另造每镜世界坐标/倍率规格表；只有精确计时任务才增加必要世界时间锚点，并与成片时间分名。

从最终成品查：

1. 去掉“极速”、残影和电弧，仍能定位跨越、拦截、急变向或差速吗？只有近身招数/跑步不够。
2. 关键接触、身体/兵器中段、接重与下一目标真实存在吗？跑圈或光带是否占掉了战斗？
3. 当前成片时段中，世界到底推进到哪？普通人、同级对手、机械、触碰后物体有无被无因改速？
4. 选一个切换参照，从切出到切回是否接同一未完事件和新状态，不回滚、不重播、不清残留？
5. 敌人反制是否来自已定速度/信息/区域机会，既未强给普通人同速，也未把速度者写成无条件穿过实体？
6. 观看是否同时证明相对速度与当前关键动作，保留用户锁定的固定/一镜/无慢镜/全主观/静音/胜负？

再合并全部普通抓挡推与赶路区间：速度优势是否贯穿关键争夺，还是只有一次起跑/主观取物在用能力？若主要时长是无理由普速互拆，先查被忽略的直接极速解法与交锋选择；合法控力、诱导和相互钳制保留，不以极速名义要求每秒跑动或强制招数。

按世界进程审对手同期，不以主观段播放了三秒、脚不动便判站桩；近冻结也不自动免检。没有足够的真实世界进程、当前任务或反制条件时明确回修，不能只在全局加“时间变慢”再照旧写普通打斗。文本、文件与真实生成分开；来源学习与本轮验证见[维护记录](maintenance-speedster-combat-20261025.md)。
