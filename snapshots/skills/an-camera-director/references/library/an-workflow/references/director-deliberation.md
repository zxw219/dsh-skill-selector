# 导演推敲：把判断变成实际成稿

用于创作前的关键决定与交付前的语义复查，尤其是“规则很多却没有好分镜”、角色战法错配、无效停顿和升级只有粒子变多的反馈。与入口的一条采用事件链共同执行；简单任务直接解决所需决定，复杂段落认真推敲关键关系，不另造完整后台报告或所有模块必调链。

## 先选本场真正需要的决定

### 关键决定先于套模板

先区分用户不可改事实、仍有效的体验偏好与本次可设计空间。最影响这次作品成败的体验要在事件或观看上有承担者：例如快战由持续抢线与反扑承担，多人张力由介入改变别人的条件承担，克制文戏由刺激、接收与策略差异承担。它们是设计目标，不是必须向用户展示的口号；用户没有逐项点名时仍按题材与已有约定主动作决定，不能把“没说”作为基础质量缺项的理由。

在占比大、决定转折或最可能重复旧毛病的位置，先作一次真实选择：当前机会允许什么操作，最熟悉的解法会留下什么弱点，另一个相容解法能否更清楚地兑现目标。比较保留用户锁定的机制、事实、结局、时长与修改权限；先核助手补设是否已让当前要求无法成立，必要时回到角色/场地设计层重选，不把“同条件”解释成必须维护助手自己设下的能力上限。仅局部表达问题才在既有机制内比较，不能为保住某个花招临时添加能力。只比较能改变该决定的局部，不强制每镜多案；相同动作换名、换色、换焦段不构成替代。

确定选择后，再取会改变本场操作、观看或检验的专项。读取的知识若没有改变采用动作、关系、相位或取景，就不算在该处应用；不为证明学习而硬塞不相容方法，也不凭引用数量决定质量。把实际采用写进原模板，直到关键变化、对方应对和观看证据能由成稿自身推出，再补足前后段。

初稿完成后切换检查目的：不再解释“为什么我这样写也合理”，而按[成品反证](final-check.md#从成品反证不从作者解释放行)寻找最可能让用户再次指出同一问题的位置。若正文缺少必要过程，回到选择层改实质设计；不能追加一句“高速、有力、全员持续”作为补救。已有清楚方案无需反复重开，明确风格选择不因作者偏好被否决。

| 要解决的决定 | 在正文中必须能找到的结果 |
|---|---|
| 角色为什么这样打 | 目标、主战距离、发动/控制方式与眼前机会相容；类型由用户/采用设定确定，不让参考动作或助手旧稿接管 |
| 这一段怎样改变局势或体验 | 压力、选择、暴露、策略、关系、通路或感官组织的实际变化；纯展示/氛围也可按其目的成立 |
| 观众先知道什么，人物何时知道 | 注意线索、隐藏/揭示、判断依据与接下来的行动；观众先见不等于人物先知 |
| 为什么现在看脸、手、法术、敌人或范围 | 具体可读对象、取景位置与占幅，何时读够，下一镜接住什么；切镜不能只是换角度 |
| 镜头之外什么仍在发生 | 本体、敌人、在途法术、持续场与残留共享时间；返回时接已发展的相位 |
| 升级凭什么更精彩 | 新作用方式、交错频率、目标/空间层级、规模参照、材料后果与重音对比；仍保留用户所需密度与强度 |

不要求把每格写成一份表，也不把每个小动作重新论证。决定要能改变具体句子；只有“炫酷、电影感、紧张”而无实际事件或取景，表示尚未完成设计。

## 顺着同一次事件推敲

技能与身体动作同时单一的反馈，在选招前按[手脚协同与能力多样性](full-body-ability-integration.md)分别定位身体攻击端、技能作用与发动条件；当前明确手脚并用则先采用能落实腿技/腿防/控制的混合战法，不受助手旧稿的纯法师补设限制。手腿互相创造窗口、对手回应与收腿接重先成立，镜头再读实际身体路线和接触；脚仅移动或只给掌电换源点不能证明通过。

先按[交战意图与召唤/表演覆盖](combat-intent-performance-coverage.md)核当前角色目标：普通打斗不默认追逃，向后位移与破围不自动代表撤离。选镜时让召唤动作、召唤物局部、人物表情/小动作/情绪动作及受力反馈成为独立可选的观看对象；它们可以显出承受、投入与控制，不必每镜改变策略。已定事件不为凑覆盖重编，主动选用的局部和运镜要进入实际稿。

在第3步观看设计之前，继承明确的特写/拍法要求，为其分配承担事件；特写写局部裁切和细节，关键运镜写触发、起中落幅及变化变量。按[摄影执行](../../cinematic-camera-design/references/camera-execution.md)补实际缺项，不能到成稿末尾加名称。复查先对照这些要求的正文证据，再查连续性；已有规则却漏用时修选用顺序，不只复制术语表。

按下面的依赖完成采用决定；保持在同一事件链内，不要求另交过程表：

1. **角色与机制有依据**：区分用户设定、图中可见事实和本次原创补设；确定当前任务、主战距离、发动/控制与实际采用的能力。未确定就不能默认双方都是持械武者。明确修仙时由御使、术法、感知、空域、破法或已定体修机制决定战术；不强塞御剑/飞行全套能力。读过专项不等于正文采用了它。
2. **事件产生所需变化**：先按[攻防意图与可用应对](combat-execution.md#先编不同解法再从出口推演)确定双方当前争取的优势、尝试被拆后的转折和下一机会；再沿入口—作用—对方应对—新状态—后续任务编链。逐招能接不代表整段有章法，关键动作不能依赖对手无依据地原地承接。高速/高燃或场景、巨物交互失效时，先按[战斗体验](combat-experience-design.md)选择能改变当前行动的环境结构、压力与相容模块；高频、速度、情绪和冲击分别兑现，不把添加拍法当上游修复。连续挡住、反复追击或持续控制可以成立，但当前负载、位置、可用路线或观众体验应继续发展；不能每次回到相同起点等下一招。判断冗余时也核用户要求的密度、乐句、压力累积与感官体验；重复拦截或持续保持可能承担这些作用，不能只因最终结果相同就删去。确认没有本段作用且未锁定的冗余可合并、缩短或改成有效事件；锁定动作有问题先在授权范围修其条件和承接，不用删招或随机移动填时间。

技能少/重复/单一在第2项选招前按[原创与选招](ability-variation-selection.md)定位储备、选用或兑现；当前对手条件与前招结果决定采用，不先套熟悉招组。作用、施法、决定性画面分别成立；有重复问题才局部比较一个不同解法，不枚举全库。合法同招与锁定重复按本段用途保留。

高速打斗在这里先成立有效交锋，不直接落成跑动/追逐。施法动作与普通技能不足则按[操作与机制](fast-spell-exchange-design.md)把身体进入/变控/退出和本招触发/作用/终态并入事件，普通小招不能只留甩掌；已有规则未兑现要修采用顺序，不在末尾加技能清单。锁定能力、追逐、单技能、无手势与获准慢仪式继续有效。

空间关系决定结果时，在第2项中先建立最小地标布局，并按[空间连续推演](spatial-continuity.md)从上一出口更新人物/作用体路线、面向、同期目标、距离及遮挡，再进入第3项选镜。不是先设想漂亮的鹿角穿越或近距反击，再用全局距离和“始终同侧”解救缺失路径。世界、人物局部和屏幕方向分开；缺失跨度、落点、连接位置或可动范围时先补获准条件，不能用脑补当已通过。

选新增大动作之前，把“能做”与“此刻值得做”分开。先明确谁追谁、角色正在解决什么，再比较省去候选动作而延续当前有效行动的结果：翻滚/旋身实际避开什么、越过什么、抢到什么或表达什么？若没有已成立收益，只使追击中断或暴露背部，则不采用。可达落点、漂亮身体线条与动作库收录都不单独证明用途；不要先选花招，再临时添加敌方攻击替它找理由。明确的表演/挑衅/舞蹈任务可以提供收益，用户锁定动作在授权内成立条件，不机械删招。

3. **观看安排先于模板**：从事件中选所需信息与感受，确定观众与人物何时知道，再安排实际景别、观察距离/高度、构图与注意交接，最后分配时间并走通机位路径。长镜头不可只按人物动作阶段配等速跟随；持续观看按[摄影执行](../../cinematic-camera-design/references/camera-execution.md#连续长镜头的观看发展)安排所需局部、关系与空间读取，合法保持依其观看作用成立。剧情必须理解的关系、规则、失败原因和关键代价要在声画中有必要建立；只写在全局不等于观众已经知道。脸/手近景读取当次判断或控制变化，关系/范围景接正在发展的威胁与结果；不把按时间切成几段、写景别标签当作分镜。脸部反应不是默认起手，手部特写不是每法必备，范围镜不是必然放在最后；一镜到底通过画内变化交付信息。

整段分镜反馈在此先定本段理解/感受的进入、变化与出口，再安排每次交接的状态、注意与强调；多个画面或层级不同时争最高强调，画外任务仍继续。必要转折比较一个相容替代，锁同事实/结果/时长及修改范围，不用增加能力或剧情让新版天然更精彩。具体定位与合法反例见[整段分镜](storyboard-sequence-design.md)；普通镜直接选择，不逐镜强制三案或增加公开过程表。
4. **编译不补造缺失设计**：只有前三项成立才沿采用链填正文；模板发现角色不明、因果空白或取景读不到关键变化时回修所属决定，不能先填“电影感、高速、环绕”再宣布完成。直接出稿只省去向用户展示方案，不能省去设计。

例如把“举剑—格挡—退回—对视”拆成四镜，仍未证明角色战法和观看收益；给每镜换焦段也不补足。修仙反制应先有采用机制与实际线索，再拍识破/改控和同次结果；纯近战则按真实抢线、负载和后续机会成立，不为通过检查强加法术。

关键方案有具体冲突时，在当前局部比较少量确实可用的处理，例如提前显示危险还是先给人物察觉、同框读取还是切向目标端。采用能同时保留用户意图、成立机制并交付观看效果的一种，回填原稿；无需穷举技能、镜法或另写几套全片。已成立的决定仅因新约束、具体矛盾或观看缺项重开。

判断并行时追踪真正占用的控制手/注意、法器位置、在途阶段与身体路线。反应镜所用的成片时间也是画外战斗继续的一段时间；不能插入一张脸就让两边停住，切回再从出招起点开始。机制要求集中维持或有意等待时，保留并让压力/期待/读取的作用可见。

## 用可见结果复查采用决定

合并进入原有一次复核，按依赖先查设计，再查结构。把结论对应到正文的事件与取景：角色采用的机制是否实际决定行动；关键结果前面是否有成立条件；观众在切点能否读清证据；人物判断是否有接收来源；画外事件是否同时间推进；新的压力是否改变下一行动；主峰是否兑现前面的选择。仅查时码、肢体和接招不能判完整稿通过，新增镜号或运镜词也不能证明分镜已经完成。

对每处疑似停顿检查“当前维持/接收什么、对手或在途作用如何推进、何种变化让本段结束”。持续控制、真实角力、反应、仪式、慢镜和主峰读取按本场目的保留；没有这些作用时重编当前时间，不能只在全局追加“禁止停顿”。用户反馈类型错误、无意义动作或没分镜时，先重新审查角色/事件/观看安排，不能仅修末镜或减少一个停留就结束。仅在实际出错的依赖范围修复，上游影响全场则复查全场，不限制必要修订轮次。

针对修仙、信息切镜和高速大场面，分别按需用[修仙战法](cultivator-tactical-combat.md)、[信息与反应覆盖](../../action-camera-direction/references/information-led-coverage.md)、[高频施法与规模写法](high-frequency-scale-writing.md)。普通文戏、固定一镜到底、舞蹈或图形片不套战斗套餐。

创作或已授权改稿时交一份采用方案的完整提示词，思考体现在设计结果；仅检查/查因时交具体问题、证据与改法，工作流维护修改技能来源，不能擅自切回改稿。用户问是否检查时，说明实际查过的层级和范围，并以具体镜头/事件说明发现与遗漏；没做完整复核就不笼统答“检查过”。用户要解释时交简短设计决定、依据和取舍；不把内部推演、逐项检查表或第二套方案自动塞入生成正文。不以“已思考”、推演长度、格式或文件检查通过证明成片美感；有成片才按实际观看继续修复。
