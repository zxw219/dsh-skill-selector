# 2026-10-18 技能类型维护记录

## 触发
用户指出对技能有误解，要求学习技能设计、召唤、领域、技能特效、法术。

## 定位
旧稿两个技能（银线、红字）其实都是同一类：构造物＋切割，只是换了材质。没有召唤的行动经济，没有领域的规则与代价，特效只分亮暗不分主次，法术没有力量来源。

- [《英雄联盟》VFX 视觉风格指南](https://www.gameres.com/874476.html)（GameRes）：主/次元素、范围准确性、重要等级、亮度与饱和、形状语言、预备与消散、动态时间分配。

- [「领域展开」](https://wapbaike.baidu.com/item/%E9%A2%86%E5%9F%9F%E5%B1%95%E5%BC%80/57346743)（百度百科）：领域内增益与必中、发动三条件、术式熔断的代价、封闭/开放/未完全三种变体。
