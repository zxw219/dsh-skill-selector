# 打斗速度、节拍、分镜与技能展示

先按[打斗默认契约](fight-default-contract.md)继承人物、战法、空间和主体验。本页深化快战编排与观看容量；能力控场、固定长镜、纯远程和用户慢镜条件按各自作用执行。


速度型能力战先用[极速与相对时间](speedster-combat-direction.md)：普通快战的镜长/拍数仅作参考，不按成片占时推定普通人能反应；主观世界缓进、同级速度者交锋及正常外部瞬逝按本场成立。

## 1. 28 秒基准

先按[动作密度与镜头预算](action-density-and-shot-budget.md)定位动作/观看超载；短镜约3点、30秒约40点与下列镜数均为旧样本的诊断参照，不是硬上限。是否修改取决于实际动作可完成、关键作用可读和段落节奏。

普通快战可从28秒10–14镜、18–24拍、1.5–3秒常规镜长的参考开始估算，短促反应可参考0.1–0.3秒；它们不是时长默认、最低完成数或成片规律。先成立事件与观看，再决定实际镜数和相位。

主体验不同不按比例换算这组数值。用户明确锁定镜数/节奏时按原条件设计；能力作用慢、摄影稳定、身体高速可在同一段共存，分别判断。

## 1.5 默认不套起承转合，不留停顿

本标题中的“不留停顿”指清除无作用的复位、摆姿、重复准备和等特效。普通快战主动保持压力，未指定完整故事时不强制试探—升级—终结或固定反转。

普通快战清除无作用摆姿、复位、重复准备和等特效；必要控制、抵抗、判断与人物接收在共同时间里发展，有明确作用及出口。能力展示/控场不必等用户另说“慢打”才使用相应观看时间，已锁全程高速高频仍优先。

逐交锋检查有效变化和占时，不规定每2.5–3秒必须另添动作。超过3秒的镜头或持续状态应读其负载、预期、控制和目标进程；只有无作用重复/等待才返工，不用缩时间码或补随机招式达标。

## 2. 动作利落：五相位

加载→攻击端爆发→接触/避开→受力/回收→下一任务构成相容动作过程。加载可接前招回收，反应可与追步、回护并行；阶段快慢按身体负荷、距离和媒介决定，不把五段各给统一毫秒。

具体取证可选：加载接前招受阻后的屈肘或追步接重；爆发让支撑和躯干带攻击端进入有效区；接触读局部受压、偏转或明确让开；回收接余势与新支撑；下一任务利用对手当次被改变的条件。轻拨、重击、持续压制各自分配相位，不套统一时长套餐。

短促动作的速度证据是加速、跨参照、接触和立即出现的新任务。不能只改时间码使远距到达、沉重回收或长台词突然可行。

## 3. 高速高频：拍链与三种快

运动速度、有效交锋频率与观看节奏、实际作战窗口、相容攻防一体与多重威胁见[速度与技能设计](speed-and-skill-design.md)。

发动快、在途快、接触后快分别设计：起势紧凑，作用迅速进入有效区，结果立即改变后续任务。高频看有效施放/应对/改控，不能用跑得快代替交锋。

相邻强弱由争夺变化选择。重复攻击若积累负载、测试防法、逼出反应或兑现签名可保留；同一输入、同一应对、同一出口的空循环回选招层。反应有方向、负载和身体后果，防法成功也可以不受伤。

## 4. 分镜覆盖：10–14 镜

标题数字是上述快战样例范围。实际覆盖解决：从哪里来、正在怎样交锋、决定性作用发生在哪里、现在变成什么条件。一个镜头可承担多项，局部/范围按需要接力。

决定性变化先选择主看对象，其余角色和效果在同一时段继续。机制特写、人物表情与巨物全貌同时竞争时，提前建立、错开强调或用同框关系接力，保留核心动作与既定时长。不能每层都写“同时完整读清”。

## 5. 衔接与朝向

切点先接动作相位、视线、注意或声音，再核双方同期位置与动态轴。切入不重播起手，反打不自动掉头，画外动作继续。相机运动路线与人物移动路线分别可达。

方向改变由可见转身、可达换位、明确介质或已锁能力支持，不能用“顺势”省略决定性路线。

## 6. 时长预算

先排真实依赖：准备、行动、在途、作用、接收和后续；再把相容任务并行，只计一次。相机读到哪层，其他层到何相位，明确后再分配S与必要t节点。

无作用长段先合并重复、接续余势并整理观看；需要读取的控制、受力和表演保留。超过3秒的镜头不自动拆，短于某值的反应不自动算清楚。确实装不下时指出锁定内容的具体冲突和最小取舍。

## 7. 技能设计矩阵

按需核来源/介质、发动条件、主形、作用、反制、控制资源、限制和终态；它们是设计决定，不要求每个技能填一张表。

同机制可以比较接近、拦截、控制等不同用途；实际从当前机会选择，不强制每方三次。局部机制与范围结果要可辨，不强制每招插近景再切远景。隐藏名称和颜色后，作用、操作与对手新条件仍应有需要的差别。

任何改变战局的技能，至少一次让观众看清来源/触发→主形/作用→结果/对手反应；可以同框/合并/连续镜，不强制三次或一近一远，但不能只有一句“发动能力”。

2D 角色按[2D 打斗镜头与作画语法](2d-fight-grammar.md)核关键姿势、接触帧、smear、冲击帧、hold 和分层运动；不能把真人相机运动直接搬到 2D。

## 8. 交付前计数与自检

计数仅核用户明确要求和时间覆盖。质量复核从实际作用取证：快战有加速、有效交锋和接续吗；必要反应可读吗；能力用途和防法是否发展；旧状态是否继承；主看对象和切点是否清楚？

- 是否有无作用等待、复位或等特效？先修最早事件/观看缺口，保留必要控制、承压与接收。
- 长段是否持续交付本场需要的压力、速度或读取？样例秒数不作硬错，已锁高频不靠空镜/慢展示替代。
- 身份判断不出时，是否按独立人物处理？有没有合并成镜像/分身？
- 改变战局的技能是否至少一次看清来源/触发→主形/作用→结果/反应？没有→补机制/结果。

无作用等待、重复复位和确证断链返工；有依据的保持、单能力、单向压制和连续镜保留。偏离28秒样例的镜数、拍数或秒数本身不触发重排。
