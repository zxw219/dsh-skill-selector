# 技能原创与选招：让丰富进入实际交锋

用于“技能少、重复度高、单一”、招名很多而正文仍是同一发动/对抗，或不同角色共享同套法术。继承用户锁定能力、身份、距离、结果与格式；原创才补机制。这里改善可选空间、选用和成稿，不要求每场凑技能类别，也不把训练原型发给所有角色。

## 先定位重复发生在哪一层

用户反馈只有手掌电流、动作与技能同时单一时，按[手脚协同与能力多样性](full-body-ability-integration.md)先拆三种缺口：身体攻防是否只有上肢；技能是否都在发射/碰撞；发动是否全由掌前释放。三项分别修并编入采用事件，不能只把电流改到脚底、增加踢腿词或新增招名。已明确手脚并用时实际腿技/腿防/下盘控制有贡献，移动和承重本身不冒充腿技；用户锁定的纯远程与有效同招保留。

| 失效 | 处理 |
|---|---|
| 储备狭窄：总想到针、球、刃、盾、阵 | 从本角色能改变的对象和关系扩展机制；形状目录不能替代作用 |
| 技能表不同，正文都发射—拦截—爆碎 | 修实际作用过程与结果，再做观看设计；不追加招名抵消旧段落 |
| 有多种技能，却总选熟悉的一组 | 先读当前对手/环境/旧状态带来的机会，再选招；当前确有重复反馈时比较一个不同解法，不枚举全库 |
| 每招功能不同，却都甩掌、泛光、敌人后退 | 分别修施法操作、决定性画面和接收结果；战术差异不能单独证明画面丰富 |
| 两个角色只换服色与能量色 | 从力量观念、发动习惯、控制模式与解决问题的偏好区分，不从造型直接授予能力 |
| 增加了辅助，却攻击仍只有光波 | 扩展实际进攻的侵入、剥离、失稳、切断、局部显化、夹击或条件起效等相容解法；不只补一个感知/治疗栏目 |

前次高速施法练习补了操作和机制维度，但雷针/晶面/晶环的近距反制仍集中；它证明写过这些例子，不证明陌生题已能跳出惯性。旧库中感知、代理、规则等方法继续有效，本轮修其选用和兑现。

## 从角色力量观念生成可选空间

先说清力量能操作什么、如何取得作用条件、什么超出边界。共享媒介不意味着技能同质：水可以侵入已湿缝隙、改变流向、局部相变、转移一段液体，前提与结果各自成立。反过来，水球、火球、雷球若只是同一弹道与爆炸，就不能靠元素数证明丰富。

原创时沿当前问题选择一条确有作用的变化，例如：

- 改物性/连接：局部脆化、软化、剥离接缝、润湿、失活；对象和接触区明确，不默认全身崩解。
- 改运动/负载：牵引重心、交换已定方向、储放一段动势、挪动承力点；不是全部击飞。
- 改路径/位置：开出成对出口、留下可返回点、变更可通行表面；边界、落点与旧环境继续成立。
- 改信息/判断：移走某条声源、投出受限制的误导、显露不可见作用；谁知道什么决定其下一选择。
- 改时间/条件：暂存尚未执行的局部操作、按已经满足的条件起效、改变运行次序；不把小条件术自动升级全场时停。
- 改任务归属/协作：召唤物执行明确任务、接管一个旧状态、拆除某种控制；本体与代理的时间和资源分开。

这些是设计方向，不能按行给每个角色配全套。需要更多形态时，以本招实际变化生成决定性画面：甲缝张开、碎块改轨、真实影像与误判分离、固定位置再次被占用、代理完成任务等。光效可以保留，但不可遮住差别。

## 选招先看眼前机会

从当前争夺开始：对手正在依靠什么、哪项条件已经具备、前招留下什么、自己哪些资源可用？再选此刻适合的能力。发生重复问题时，只比较一个确实相容的不同处理，确定为什么采用当前招：能绕过某防法、利用残留、缩短控制占用、创造下一窗口或兑现人物意图。没有可用替代就承认边界，不临时发万能反制。

升级也从已发生的应对来：对方躲开接触，改取已湿衣料；对方切断一个代理，剩下代理改任务；对方识破诱影，主动利用其识破动作。不能总由助手主动换更大弹头；反制失败、僵持和有意重复都可以成立，按本段压力/学习/性格作用继续发展。

## 三项差别一起落实

**作用差别**：谁或什么被改变，改变后下一步能做/不能做什么？

**施法差别**：实际操作是什么，手指/腕肘/肩胸/支撑怎样进入、变控与退出？指诀可精密短促，念动可无手势，传统结印/咏唱按既定规则成立；“有手势”本身不构成差别。动作细化复用[高速施法交锋](fast-spell-exchange-design.md)。

**观看差别**：本招决定性画面是什么，观众在何时、什么占幅读到？局部状态、运动路线、真假判断、多个代理分工或区域内外可以有不同观看任务；只换机位不补作用缺项。复用[技能画面](ability-screen-direction.md)，不逐招固定手部—弹体—敌人三镜。

有一项未成立就修所属层。需要多样性时，作用有差别而全部同姿同光、或动作形态不同而结果相同的自动复位，都不能由另一项通过来抵消。

## 检查实际采用的片段

只沿最终正文的相关招式核对，内部可用一句机制摘要定位：条件/发动 → 作用对象与操作 → 对方响应 → 剩余状态/下一机会。无需公开过程表。

遇到疑似换皮，暂去招名、颜色、大小和摄影词，再看两段是否还有实际差别；把招式互换，原防法与后招若可以原样接续且无新的读取，只在要求丰富且没有重复用途时判为需要修订。互换检验是编辑辅助，不是数值评分；同一招的压迫累积、识破、诱导、签名复现和用户锁定重复可以承担明确作用。

同时检查：特殊机制是否只写在全局而逐段消失，前置是否早已成立，控制资源是否相容，普通攻击与大技能是否各自有决定性画面，下一招是否读到了旧结果。机制已经不同但摄影没读到就修摄影，不擅增新技能。

## 从对手改变的条件重新选用

暂去招名、颜色和相机后，比较两招的实际操作、对象、限制与结果；如果可互换而对手防法和后招完全不变，回机制或选用层查同质。签名技重复但迫使对手改防、累积负载或利用旧状态，可以保留。

新机会应由对手行动和场地当前状态产生。题目锁定单机制时，用对象、方向、控制任务、材料状态与时机变化深化，不靠新增神通或随机改规则解决；只改特效时更不得重定机制。
