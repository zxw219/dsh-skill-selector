# 特效设计与合成完成度

用于复杂效果、塑料感/贴图感返工、实体消散、粒子重组、严格匹配或专业合成质量要求。先遵守本场媒介、剧情、镜头与声音，再设计效果。AE是可选制作工具，不是画风或质量保证；提示词、分层制作方案和已完成合成分开报告。

## 执行方式

- **直接生成提示词**：将可见的材质、运动、遮挡、受光和终态融入全局与连续阶段；明确分栏时写入S=与fx-env；不在正文堆AE图层、节点、插件或渲染参数。只有提示词任务时仍完整交付提示词，不因复杂而停工，也不自动启动生成或购买插件。
- **分层合成方案**：用户要求制作流程，或明确需要逐帧控制实体消失、精确遮挡/重组/跨场匹配时，说明具体依赖：背景补全、主体分离、跟踪、效果层及必要遮罩。复杂几何/体积模拟可需3D或其他工具，不能承诺AE单独完成全部物理模拟。未授权制作时仅给设计与依赖，不擅自拆clip或生成资产。
- **实际制作**：仅在请求包含执行时启用。先确认可用软件、素材及输出规格，缺少什么就如实报告；未打开工程、未渲染就不能说已做成AE效果。

## 大场面触发

效果主导、巨物压迫、跨战场作用或“场面很小/没有冲击力”返工时，设计阶段联用[大场面与冲击导演](../../spectacle-impact-direction/entry-guide.md)。先安排主形跨越参照、抵抗/失效与连续后果，给场面变化实际观看时间，再细化本页的材质和粒子；不只在局部格挡的效果栏追加巨大爆炸。冲击帧的特殊造型画、画张切换与曝光，和特效的物理传播分别设计：连续开裂、喷散、慢放不自动成为冲击帧。具体见[冲击帧造型与曝光](../../spectacle-impact-direction/references/impact-rhythm.md)；延长冲击序列仍不能替代战场作用。普通火星、拖尾、单次局部命中不触发额外阅读。

战斗中技能有形无用、只有换色光团或与动作脱节时，先按[战斗执行与表现](combat-execution.md)检查起效条件、当前战术目的与实际结果，再设计本页主形和融合。强化型能力可改变速度/负载，不强制增加控制机制；已锁能力不擅换。不得为预定结果临时添加万能吸收、自动控制或方便的唯一薄弱边缘，也不能让未符合条件的接触触发技能。

## 从零创作能力与关键画面

本场还没有有效技能概念，或反复“扩幕、挡开、爆碎”时，按[技能、特效与释放画面创作](ability-effect-authoring.md)先确定使用理由、相容作用、可辨主形和作用后的新行动，再细化材质与融合。角色施法先明确法术/神通的发动和直接作用，再选视觉载体；手诀控制不等于握住一条法力线，衣装不自动决定操绫能力。不同招式的使用条件与终态要有区别，不能只替换颜色或尺寸；已锁机制不借此重写。设计释放时选择能读到作用的画面关系，不只填效果栏。已有概念继续用下方规则，不自动展开案例全库。

## 主动/被动、交互与大小技能的展现

技能多样性反馈先按[体系与状态](ability-system-design.md)检查本场采用的用途、触发、控制与时间行为，再按[画面与摄影](ability-screen-direction.md)分配条件、作用和结果的可见证据。主动开启后运行不是每次重新施放，常驻与事件被动不用补不存在的结印；标记、诱饵、恢复、解除、区域规则与自主代理不统一套碰撞爆炸。

小技看接收端的具体差别和后续使用，大场面看局部侵入、网络/区域/环境改变与范围中的人物状态；规模不只巨物坠落，也不靠小技放大取得重要性。效果细化已定机制，摄影读关键关系，声音不在静音任务中补解释。例稿仅按当前缺口选读，不把能力数量写成固定指标。

## 先定主视觉，再分配层次

先用本页完成普通拖尾、火星、单次技能命中与残留设计。需要细化粒子生命周期、复杂拦截/转化、满屏可读性，或诊断“只有光团/亮粉”、技能同质化时，再读[粒子与技能展示](particle-spell-design.md)；已读有效规则直接复用。先让技能的主形状、方向和作用可辨，再设计发射方式、世界运动、碰撞与生命周期，并将释放、攻防和残留交给有职责的镜头。不同角色的特效区别落实在源点、载体、形状和运动规则，不只换颜色；不新增固定层数和阶段配额。

确定本镜要读清的是形体改变、能量路径、冲击还是残留。选主导机制；主效果、次级碎片、环境交互与成像处理按用途取舍，不设必须五层/三种交互的配额。次级效果补充尺度与动势，不遮掉主变化。用户要求强烈或满屏时保留强度，通过阶段、空间层和关键可读区域组织，不默认削成稀薄粒子。

每个重要效果应能回答：来源在哪里；何时触发；载体是什么；怎样走；作用于谁；目标怎样改变；最终留下什么。无接触的氛围效果不硬造撞击，无蓄力的瞬发不补蓄力阶段。

战斗效果先区分作用体与光迹：武器附着延长刃、脱离弹体、定域场或随施术者移动的区域。写清本场采用哪种、有效范围与控制归属，不能同一效果既随手臂转向又无因独立追踪。尾焰、残影和光晕不自动造成第二次命中。

高速拖尾附着于已建立的发光源或明确风格化残像：源点随人物/兵器走真实路线，旧轨迹留在经过的世界位置并衰减，人物在当前端；转弯时尾迹不能整体变成直线或吸附镜头。残像不复制实体武器和第二个攻击者。拖尾、运动模糊、真实投影、相机视差是不同机制，按媒介选用；保留人物轮廓、步态或飞行姿态、地标跨越和接触可读区。停下后尾迹可以短暂消退，但不能替代实际制动。相关运动与摄影见[motion-language.md](motion-language.md)。

风格化拖形可以在短时表现帧拉长或弯曲轮廓，但握点、手柄数量、有效刃侧与前后道具身份要连续；它不自动授予永久形变能力。关键接触先保持可辨，再以选择性的冲击图、曝光或摄影脉冲增强，强光不遮掉要求观看的命中证据。

关键技能沿“发射/起效时双方所处状态 → 传播期间双方能做的事 → 拦截或命中 → 强制改变的行动 → 残留如何参与后续”组织。作用到物体和作用到施术者并非必然相同：附着武器按设定传回负载，脱离弹体是否反馈须有规则；护盾、法阵也要明确承载源、控制是否持续占手及中断后状态。不机械给所有法术添加物理反冲。

受力结果有方向：偏转须说明原来的路径变到哪里、谁被迫跟随或如何解除连接，范围技须说明哪一部分地形/人被覆盖。大招毁掉的是角色用过或即将争夺的条件时，下一动作要改变；不能只增加远处碎石，再让双方无代价回到原位置重打。

学习特效静帧/技能展示，或效果有亮度却缺主形、介质显化与释放观看关系时，补读[特效形状与释放画面](effect-shape-release.md)。先把参考的轮廓、孔隙、结构密度和材质关系转成当前角色可辨的技能，再按本页落实空间、受光与终态；不把成像光晕授予伤害，也不把展示片的等待带进战斗。

## 本场效果层级与角色辨识

任务要求递进或保留高潮时，先比较本场必要的层级，选可见的差别：常态附着/局部前兆、近战接触反馈、改变通路的作用、大范围主峰。它们是本场设计选项，不是所有技能都要走完的四阶段；允许峰值开场、小尺度精准高潮、瞬发和纯展示。

层级差异落实到主形占幅/覆盖、传播与接收区域、抵抗/失效、材质响应或持续后果，不只提高亮度和粒子数量。用户指定主峰最大时，前段不提前耗尽同级规模；用户锁定从最强开场则保留。多色强光按本场视觉基线分配，让关键阶段仍能辨认主体与主作用，不默认长期单色覆盖或强行一黑一白。

角色特效选择与其战法相容的形状语汇：刃上附着纹与挥斩方向、控制丝束与约束区域、伞骨/硬件上的传导路径。气质、武器、主形与运动可以相互呼应，但不能由外观临时增加能力。衣料延迟、积水外推、石屑喷散与落定按真实原因取适用反馈，不规定每次命中至少几项，也不把所有材质都套成火花加爆炸；效果与下一段共同继承结果。

## 与导演、表演和时间共同设计

先确定效果在当前节拍承担什么：逼近威胁、改变实体、交代受力、封锁空间或留下后果。对剧情动作引发的效果，先有动作或接触，再有相应变化；环境威胁可以先发生并触发角色反应，不能套成所有效果都由主角发动。

将主运动与人物路线、摄影机视线放在同一空间中检查。效果不能擅自改写姿态、身份、道具接触或反转时刻；遮住必要证据时，调整层次、局部密度、阶段或机位，保留用户锁定规模与构图。必要时定向回改导演设计，不用满屏闪光代替发生过程。

效果阶段与表演、对白共用时间：已在说话或动作中完成的起效不另计时，尾部可以延续到下一镜；阶段并行有因果依据，不让整个变化在一个瞬间全发生。静帧概念只能描述选定阶段，不能当完整生命周期的验证。

## 材质与运动

| 载体 | 可见材质与运动决策 | 常见失败 |
|---|---|---|
| 花瓣、纸片、织物碎片 | 薄片厚薄/弯曲、正反面受光差异；整体风向一致，局部翻卷有差别 | 所有片都像厚塑料、随机乱飞或同步转动 |
| 粉尘、烟雾 | 疏密结构、透光与遮挡随厚度变化；来源附近与远端的速度、扩散不同 | 均匀灰团、整张贴片等速放大 |
| 石屑、金属、玻璃 | 破裂形态对应来源材质；继承受力方向，再碰撞、滑动或落定 | 一切都碎成玻璃，碎片无起点 |
| 能量、魔法、图形效果 | 建立本世界的形态与传播规则；亮部内部有结构，是否照亮环境由既定风格决定 | 发光白团覆盖一切，所有魔法套同一粒子喷泉 |

写主流向、速度变化与阻力/碰撞/场力中的适用因素。随机性围绕统一运动展开，不用完全随机制造细节。粒径、密度、旋转与寿命有主次和分布，不是所有粒子一样，也不是每颗都不同得毫无组织。二维效果用轮廓节奏、色块、关键形与拖形实现这些关系，不强加写实反射和摄影虚化。

动画以事件确定启动、发展、峰值、衰减；爆发可快起缓收，飘落可持续受风，不给所有运动套统一缓入缓出。次级效果在相应原因之后产生，不能机械把所有层错开固定帧数。尾部结束于散尽、落定、离画或继续存在的明确状态；未散完时可有意切出；同一时空的下一镜继承残留，明确跨时空或结束短片时不强迫展示散尽。尾部不自动增加总时长，可与后续表演并行。

## 机制与材料的交叉选择

已有机制只细化形体，不添加新的反射、吸收或伤害；获准原创时才据任务补机制。同一介质不只一种作用，同一机制也可有不同外观。

| 本场已定作用 | 相容材料/形体候选 | 受阻、失活与后续证据 |
|---|---|---|
| 牵引/转移负载 | 连续纤维、局部实体支点、可见压力边界 | 哪一连接断、哪段仍受力，不能断一点全部消失 |
| 切断/剥离连接 | 薄锋、接缝局部失活、片层错开 | 切缝和接收端改变，不统一整个目标爆碎 |
| 屏障/导离 | 薄膜受压、硬面偏转、密度边界让开路径 | 原来线和剩余来袭分别有去处，材质不会自动授予反弹 |
| 区域/通路改变 | 地表局部转相、流向改道、规则边界 | 已变/未变区能比较，后续落点真实使用新条件 |
| 感知/隐匿 | 条件允许的声源差、折射层、真假痕迹 | 受影响者判断与外部事实有区别，不把全画面滤镜当机制 |
| 恢复/解除 | 修复前沿、局部解除、承载物状态回退 | 哪部分恢复、消耗什么、谁能重新行动，不自动全状态治愈 |

跨招案例：已有凝结术使湿石局部成脆层，对手踏上后改变落脚，后招只利用该已成立的新支撑条件；若对手绕开，脆层仍留原地，不把术临时改成追踪弹。另例：代理的一处肢体被截后，剩余身体改为阻路，本体处理失去的控制负载；若规则规定代理随核心失活整体解体，则按该规则，不为保留场面擅改。正文分别写已变区、控制与接收端，不在效果栏重复发动。

## 火焰、烟雾与大规模环境效果

区分燃烧源、可见火焰、烟、适用的余烬及被影响表面，按本场实际需要取舍。火从明确区域持续产生，烟的形体随流动、遮挡和疏密演化；不能让整片火墙或烟团像透明贴纸同速平移。风向与主体运动有共同依据，局部变化不等于每帧随机重生。

规模以既有人物、建筑或地形为参照，并通过覆盖范围、前后层次及对可用路线的影响体现；“大火”不能只变成几条边缘小火苗。逼近感写出威胁相对参照的距离和可用空间怎样改变，不能只增加天空亮点数量或放大光晕。指定真实物质或特殊燃烧机制而事实不确定时，先核验参考，不由名称臆造颜色、轨迹、爆炸或伤害表现。

写实场景中，火光对临近可见表面的照明应随位置与遮挡变化；烟改变背景可见性，热扰动仅在尺度、距离和画面允许时使用，不强制全画面扭曲。燃烧持续时，残留、受影响区域和逃生空间不能在换镜后恢复。涉及战争等题材时，视觉强度服务事件后果，不以漂亮火花替代既定残酷性，也不自动添加额外伤亡。

## 空间、光色与边缘

- 世界中的效果跟随源点、相机透视与空间深度；只有既定HUD或平面图形才固定在屏幕坐标。前后遮挡由实际位置决定，不能全叠在人物最上层。若跟踪或背景尚未取得，只标记依赖，不声称已对齐。
- 非发光材质接受现场光；发光效果在需要写实融合时影响附近表面，方向、遮挡与距离一致。阴影和反射只在尺度、材质和机位下可见时使用；不为每颗粉尘制造硬阴影。
- 先对齐亮暗层次、色彩与黑位，再控制光晕。保留主要材质细节，不能用泛光掩盖错误边缘；暗场不等于效果自发光，光包边不等于描一圈均匀亮线。
- 景深与运动模糊跟随镜头焦点和相对运动；不让远近所有效果同时锐利，也不把必须读清的接触全糊掉。已有模糊素材不要无判断再次加重。颗粒、锐度和压缩观感按底片匹配，不把噪点当高级感。
- 实际合成出现黑白边、灰边或透明区漏色时先查遮罩和alpha解释，再修边缘，不能先大幅羽化。素材输入、工作空间及输出转换保持一致，不随意重复套色彩转换。

## 实体消散与重组

涉及角色变身/强化时，先选择同姿态显现、连续局部变化、核心扩展或实体分离等适用机制，保留可辨身份、当前持物/支撑与空间锚点；光幕后的装甲显现不能当作已写出逐片组装。分身有独立作用与数量，残像只有视觉尾迹，二者不混名。完成后的造型与功能接入下一行动，变化期间的攻防仍共用时间；单人展示不强加战术。详细设计与图形峰值分类见[参考迁移、变身与图形重音](combat-reference-transfer.md)。

绑定同一变化前沿：实体哪部分正在消失，效果就从对应表面产生；已转化区域露出正确背景，不出现完整人体外再叠一层花瓣。保留部分未变化区域作为过程参照，除非用户指定整体溶解。重组则明确粒子如何汇入目标轮廓、实体何时稳定，不能简单倒放却保留错误受力与残留。

花瓣消散的设计例：轮廓局部转成薄片，脱离的薄片沿统一风向移动并分别翻转；主花瓣承担形体变化，少量细屑承接尾部。已消失区域同时露出草地，近处花瓣按实际深度短暂遮住尚未消失的部分。最后少数花瓣飘出或落在草叶上。是否粉色、发光、柔化边缘由原设定决定，不迁移成所有效果的默认样式。

实际分层制作可按需要准备：干净背景/补全、主体及其消失遮罩、源点/运动参照、主要花瓣、细屑、前景遮挡、可见阴影或反射。主体消失遮罩和粒子发射区域共享时间与空间依据。光晕和最终调色在形体、运动及遮挡成立后调整。制作顺序不等于永远固定的图层上下顺序，前后穿插需分层或适用的深度处理。

## 跨镜连续与专业合成完成度

关键跨镜承接仅记录会变化的源点、阶段、主流向、遮挡层、已改变区域和残留。相机改变只改变投影，不让发射源吸附屏幕、消散区域复原或烟火重新启动；明显时间跳跃按剧情处理。

“AE高水平”转换为可验收的画面条件：跟踪与透视稳定，主体边缘和透明层干净，材质及尺度可信，时间变化连续，光色和适用的焦点/模糊与底片相容，结果完整。不开软件、不渲染时只报告设计完成；不用插件名、位深数字或“电影级”字样充当证据。

实际制作按依赖推进：先确认底片、镜头运动与主体分离/背景补全；用低成本预览检验源点、遮挡和变化前沿；再细化材质运动及必要受光、反射与阴影；基础融合成立后调整光晕、颗粒与最终输出。具体工具、色彩设置和格式服从项目并在执行时核验。这个顺序不增加用户提示词任务的交付门槛，也不强制购买插件。

## 验收与定向返工

有视频时正常速度看节奏，再抽查起效、主要变化和收尾；必要时逐帧查边缘及跟踪。静帧只能确认材质、构图和当帧融合，不能证明运动自然。无素材时只能审查设计，不声称已排除塑料感。

| 证据 | 优先修什么 |
|---|---|
| 原物体不变，效果在表面飘 | 转化前沿、主体遮罩和背景显露 |
| 厚亮片、整齐珠串 | 材质厚薄、反射/透光与形态分布 |
| 粒子像预设烟花 | 源点、主流向、速度变化和生命周期 |
| 效果随屏幕漂移、穿脸 | 跟踪、透视、深度与遮挡 |
| 灰边、亮边、悬浮感 | alpha/边缘、曝光黑位、必要接触关系 |
| 单帧漂亮，播放乱跳 | 跨帧身份、跟踪、随机变化连续性与速度 |
| 开始都很强、结尾一起没 | 强弱组织、衰减分布与剩余状态 |
| 大规模威胁只剩装饰亮点 | 尺度参照、覆盖范围、逼近过程与空间后果 |
| 切镜后残留复位、效果重播 | 源点世界位置、阶段、已变化区域与跨镜时间 |
| 效果很亮却看不到关键选择 | 局部密度、遮挡和发生时序，保留要求的规模 |
| 发射停止时全部粒子消失 | 停止产生新粒子与旧粒子继续运动/衰减分开 |
| 角色转身时离体粒子整体回转 | 区分附着发射源与世界空间粒子，核对是否存在控制场 |
| 不同技能只换颜色，作用分不清 | 主形状、运动方式、有效边界与目标响应 |

定位每条故障链的最早失效原因，修复并核对依赖；同一轮可处理多个独立问题，保留未受影响的正确部分，不全量随机换参数。通过标准是主变化可读、材质与媒介一致、运动连续、空间光色融合、结尾承接成立。检查通过不等于生成稳定率保证。

## 从视频迁移效果的时间行为

按[视频施法蒸馏](video-distillation-method.md)分开成形辨认、离体传播、持续控制、接触峰值与退场；排列可保持，发射和目标区变化可以快速发生，不让整个能力都以同速漂浮。场地边界、受光和地表变化在既有空间建立，主形的尺度升级与当前作用相容；巨物必须有逼近/遮挡/作用部位，不能只增亮度和尺寸。原片图案、轨迹、链状控制和外显作用体分别解释，未确认机制不自动取得攻击权。

## 动作媒介、主次与后果交接

写实CG依当前光学与材料表现方向性模糊、负载、接触和局部照明；风格化3D/2.5D可用短时几何拖形与二维重音，二维依轮廓、画张对比和形状生命周期。混合媒介分别限定实体纵深/接触、图形表现与合成职责，节奏和遮挡共用同次事件；不把所有媒介都写成柔光粒子，也不取消用户强度或现有画质词。

主作用、接收端和余波存在注意层次；临时压低装饰竞争不删除实际主形、范围与破坏。法相/召唤的本体、代理与场地作用共享时间，效果形成/传播/衰减不要求演员一直维持发射姿态。大尺度可由较慢的次级环境响应证明，与本体普攻速度分别成立；不从来源的规模示例推导全场慢动作或每招必须牺牲代价。

## 技能母题与情绪兑现的参考学习增量

技能形体、运动和材料在成形/释放/交互/残留中保持辨识，前招建立的标记/结构可按设定在后续换用途并回收。局部受光与环境参与同次作用，协作写实际输入和结果；双色光或更大泛光不能代替有效技能。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。

## 主形辨识、威胁读取与材料阶段

先区分身份签名、作用信息和装饰：主形/流向使人辨认归属与来向，作用边界让人理解哪里正在改变，装饰不能获得新的攻击权。当前最重要的变化获得视觉与声音强调，重要性来自本场任务，不能把所有效果都提到同等亮度或把“更强”统一等同更亮。

同体系可共享一种形态或材料规律，具体选招则因前置、作用和反制不同而分化。形成、受压、失效和消散分别继承当前材料；切镜不能把实体、投影与尾迹互换。巨物、人物和局部机制有主读窗口，背景反馈继续同一时间，不每层重复起效。
