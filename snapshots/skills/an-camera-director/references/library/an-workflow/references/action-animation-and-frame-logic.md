# 动作原理与帧逻辑

用于启动/停止突兀、身体负载不清、挡后先后关系不明时。借用动画相位与游戏分支作推演工具，服从本片媒介、身体和能力机制；不把特定游戏的帧数、取消规则或判定框直接当成影视动作定律。

## 十二条法则里，打斗真正用得上的六条

- **预备动作**：需要预载的动作给相容支撑与储力，可来自上一动作余势，不必每招重新下蹲或反向摆动。瞬发、预先加载和明确风格化另按机制。
- **跟随与重叠**：身体、衣发、兵器与介质按各自连接、质量和惯性延续；接触、制动与主动控制可以使某部分突然受限，不强迫全身同一减速曲线。
- **加减速**：按任务分配发动、通过、接触和回收；持续匀速、短促制动和非均匀运动都可能成立，先核当前负载。
- **路径**：攻击端可走直线、弧线或复合路径，躯干与关节协调完成；不为遵守“弧线”把已定直刺改成绕行。
- **附属动作**：衣发、饰物与碎屑帮助读取方向和材料，不遮住关键手脚、触点或控制；数量多不自动更有生气。
- **呈像**：关键意图、接触和转换的姿势应可辨；高速过渡的拖形、模糊或遮挡由相邻证据承接，不要求每一帧都是展示造型。

## 帧逻辑：每一招都有三个结果

设计时比较打中、被挡、落空各自可能留下的恢复、距离和暴露条件；正文只采用本次实际分支，不写三套竞争结果。游戏的发生、命中和防御恢复概念可帮助比较先后，但精确值随具体动作与系统变化，本工作流不预设通用数据。

- 谁先恢复只是机会之一，还需目标可达、攻击端可用、防线和支撑允许。
- 被挡可以被惩罚，也可安全退出或继续压制；必须由本次接触方向与恢复关系推出。
- 落空可能暴露，也可能是试探、佯攻或主动收距，不能统一给对方最大反击窗口。
- 反击从当前可用身体与距离进入，不能挡住后凭空贴身。

## 判定框：破绽是姿势给的

借用攻击区/可受击区帮助检验可达路径，具体到持物、肢体、护具、姿态和支撑。影视正文写可见接触与控制关系，不新增不可见的游戏判定规则。

暴露不等于必然受击：对手须能读到、到达并有资源利用；已设护具、能力或主动保护可以覆盖该部位。恢复期也不自动让所有受击区变大。

## 把三条合起来

沿实际分支推演：当前入口→发动/作用→对方响应→接触或避开→双方恢复/受限→下一可用任务。普通快战主动让后续压力接在真实出口上；稳定、制动和受压保持有作用时保留。

## 交稿前

- 必要预载、支撑与控制来自哪里？突然变化有同次作用依据吗？
- 攻击端路径、身体与附属运动相容吗？关键姿势/触点是否可读？
- 实际结果给谁留下什么机会，距离与恢复是否允许利用？
- 是否把可能破绽写成必然命中，或把未发生分支混入正文？
