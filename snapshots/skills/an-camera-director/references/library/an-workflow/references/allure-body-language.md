# 勾引、魅惑、性感、曲线与柔软

本页处理成年角色的身体魅力语言：怎样发出邀请、怎样劫持注意、性感靠什么成立、曲线怎样被读出来、柔软写成什么才不空。用于战斗、文戏与混合段；明确舞蹈段优先走[舞蹈转译](dance-transfer-direction.md)，本页取与舞蹈不冲突的通用部分。

五个词不是一件事，各有不同的写法入口。混着写，最后只剩“她很性感”这类空词：

| 词 | 本质 | 写法入口 | 失效表现 |
|---|---|---|---|
| 勾引 | 主动发出的邀请，有对象有目的 | 谁先发出、想让对方做什么、什么时候收 | 只有展示，没有对象，也没有收 |
| 魅惑 | 让对方与观众失神的机制 | 节奏、注意、反差的安排 | 只是一张好看的脸，对方行为不变 |
| 性感 | 观看层面的差 | 露与遮、紧与松、动与静、攻与柔 | 靠露肤面积堆，越露越平 |
| 曲线 | 形体的可见轮廓 | 转体、反弓、侧线，加光与机位 | 站着不动让镜头上下扫 |
| 柔软 | 身体的力学质感 | 脊柱传递、跟随延迟、分级缓冲 | 写“像水一样”“很软”，没有过程 |

## 勾引：写发出，不写展示

勾引有对象、有目的、有收放。动笔前先定三件事：向谁发出、想让他做什么、什么时候收回来。三件事定了，动作自然长出来；没定就只是摆姿势。

四个最有效的载体：

- **视线三段**：先看，再移开，再回看。回看的重量远大于直视；直视是宣示，回看是邀请。移开的时长写清，半秒和两秒是两种意思。
- **临界距离**：缩短到能感到气息、但还差一寸的位置停住。停住的那一下比贴上去更有力，因为剩下的空间交给对方决定。
- **停半拍**：说话说到一半停，动作做到一半停，让对方等一个答案。等待期间身体保持当前相位，手不急着补完。
- **手上有别的事**：一边系带、擦刀、拨发、扶栏，一边发出。手在做事，说明她不急；不急才是主导。

目的决定写法：拖住对方就慢，试探就短，挑衅就直，掩盖真实意图就把发出做得比实际更明显。同一个抬眼看，配不同目的，落点完全不同。

## 魅惑：四个劫持注意的机制

魅惑不是“美”，是让注意被拽走。四个机制可以直接排进分镜：

| 机制 | 写法 | 对方要有的后果 |
|---|---|---|
| 节奏差 | 全场快，她慢半拍；全场静，她突然一动 | 对方的出手被拖慢或抢早 |
| 局部先给 | 先给手指、锁骨、脚踝、后颈，再给整体 | 观众先补，看到全貌时落差成立 |
| 反差 | 刚打完的喘息里出现一个完全松弛的动作 | 对方判断出错，以为机会来了 |
| 做到八成停 | 动作差最后两成就停住，剩下的交给对方补 | 对方注意力黏在未完成处 |

第四项最容易被忽略：完整做完的动作只能被看见，做到八成才会被追着看。

每种机制都要落到对方的实际反应：看错了目标、手慢了、退错方向、话说半句停住。没有后果的魅惑只是画面好看，不参与交锋。

## 性感：靠四组差，不靠露

露肤面积与性感不成正比。四组对比才是可写的东西：

- **露与遮**：露出的部分要少，遮住的部分要多。门框、兵刃、垂落的衣料、第三人的肩背都能当遮挡；暗部吃掉细节，只留一段边缘。
- **紧与松**：整体贴身，留一处松。滑下的肩带、敞开的领口、卷到手肘的袖、松开的腰带，任何一处松都会让其余部分显得更紧。
- **动与静**：全身静止，只留一处微动——呼吸、一缕发丝、衣角。反过来，全身在动，只有脸是静的。
- **攻与柔**：手里握着致命的东西，身体却是软的；或者身体绷紧，声音是软的。反差越具体，越不靠形容词。

四种差可以叠加，一段里选一到两组就够。全上会互相抵消。

## 曲线：让轮廓被运动与光读出来

曲线不靠站立展示，靠三种动作把线拉出来：

| 读法 | 身体怎么做 | 什么时候成立 |
|---|---|---|
| 转体 | 骨盆转、胸廓反向，肩线与胯线成角，腰线被拉长 | 闪避、换位、回头、绕到身侧 |
| 反弓 | 脊柱后弯，胸廓打开，下颌抬起，髋向前送 | 受击后仰、下腰避线、落地前展开 |
| 侧线 | 侧身，手臂离开躯干，从颈到踝一条连续线 | 待机、观察、绕行、持械待发 |

手臂贴住躯干会吃掉腰线，这一条决定了多数的“曲线没出来”。侧线成立的最低条件是手臂与躯干之间留出空隙。

光与机位决定这条线能不能被看见：

- **单侧硬光**：亮面画轮廓，暗面收细节，曲线靠明暗交界线读。
- **逆光轮廓**：只留边缘发亮，形体变成剪影，适合穿宽松衣料时。
- **斜侧三四分**：比正面更能读出前后层次，胸、腰、胯的进退关系清楚。
- **低机位**：拉长腿与躯干，适合站姿与落地；**高机位**压缩比例，适合俯视与被压制。

曲线要落在动作里。站着不动等镜头扫，读到的只是姿势；同样的线由转体带出来，才有力量来源。

## 柔软：六条可写的物理

柔软最容易写空。它不是一个形容词，是六个可观察的过程：

1. **脊柱波浪**：动作从一端传入，逐节传递。头先动→颈→胸→腰→髋，每节比上一节晚一点点。写成一条顺序，读者才能看见“软”。
2. **跟随延迟**：发梢、衣摆、袖口、佩饰比身体晚到，幅度按材料定。丝绸滞后长，皮革几乎不滞后。
3. **分级缓冲**：落地不一次停住。接触点先承重，膝、髋、脊柱依次屈曲卸力，最后收势。三级缓冲比一级更有肉身感。
4. **松紧过渡**：发力前有一下明显的松弛。全程绷紧显得硬，松到紧的那一下才显得身体是活的。
5. **关节余量**：腕、踝、指、颈留出超过常规的角度；肘与膝保持结构，靠旋转与伸展表现柔度。
6. **呼吸可见**：柔软状态下呼吸更深，胸腔与腹部起伏可读，锁骨与肋弓随之变化。气息浅的人显得紧。

六条里至少写两条，且要写出传递顺序。只写“身体柔软地避开”，等于没写。

## 三个可用窗口

魅力动作需要位置与时间，三种窗口在战斗与文戏里都成立：

- **对峙前**：开打前一到两秒。双方都还没动，注意力最集中，此时发出的东西会被完整接收。
- **交手中**：贴身瞬间。卸力、闪避、擦身而过、被压制时的转身，柔软与曲线在受力里最可信。
- **结束后**：收势、喘息、整理衣发、捡回兵器。余韵窗口最长，适合放一次完整的勾引或一次反差。

每个窗口写清对手此刻在做什么。对方被第三人牵制、正在回收兵器、正在判断距离，都是合法空档；对方无缘无故停手则不成立。

## 四种高价值组合

魅力与战斗结合，比纯展示有效得多：

| 组合 | 写法 | 为什么成立 |
|---|---|---|
| 柔软卸力 | 身体顺着来力走，关节不硬顶，力被引到侧后 | 柔是另一种防，不是弱；卸掉之后对方门户大开 |
| 曲线闪避 | 转体、下腰、侧弯让攻击擦过，攻击端从轮廓外侧掠过 | 闪避路线由曲线给出，不是凭空位移 |
| 魅惑干扰 | 看手打脸，看脸打手；或故意暴露一处 | 注意被引走，防守跟着错 |
| 勾引拖延 | 用一次靠近、一次停顿换半秒 | 时间被实际买走，对手的节奏被打断 |

每种组合都要写对手的后续反应。组合只改变条件，不替代攻防成立。

## 门槛

一段里采用本页内容时，按以下四项核：

1. 相邻两次魅力动作至少变两项：载体（视线／距离／节奏／曲线／柔软）、对象、目的、是否被打断。
2. 至少有一次效果落地：对方失神、判断偏移、手慢半拍、退错方向。效果不落地，魅力不参与事件。
3. 柔软写出传递顺序与至少两级过程；曲线写出是哪种读法带出来的。
4. 魅力占用的窗口里，对手的同期行动可指认。

露肤程度、镜头数量、特写时长都不作为达标证据。

## An声画分栏写法

示例仅示范写法，不替代用户已锁的身份、服装、招式与格式。

```text
【镜头：S=0.0–3.6s｜斜侧双人中景，短跟移，读发出与失神】
画面：成年甲侧身立于断墙前，右手持短刃垂在体侧，左臂离开躯干，从颈到踝留出一条连续侧线；成年乙在其外侧两步，长刀横持。
S=0.0–0.9s：甲不举刃，先将下颌抬起半寸，视线从乙的刀尖移到其眼睛，停住；锁骨随吸气压低，腰线在单侧硬光下亮起一段边缘。
S=0.9–1.4s：甲视线移开，落到乙持刀的手上，同时左手抬起拨开垂落的一缕发，手腕过伸，指尖在耳后多停一拍。
S=1.4–2.1s：甲髋部先行，胸廓反向微转，侧线转成斜侧；乙的刀尖随之偏了半个掌宽。
S=2.1–3.6s：甲借这次转动侧踏入内，短刃从体侧翻起走直线，乙因刀尖偏出只能前臂回护，重心被压退半步。
fx-env：发丝比肩线晚半拍落回，衣摆滞后扫过墙灰；短刃翻转时反光沿刃口移动。
sound：衣料摩擦、鞋底在碎石上的短促接重、一次刃口破空。
transition：结束于乙重心后移、刀尖仍偏在外侧的状态。
```
此段用视线三段、临界距离与转体曲线把“发出”写进交锋：效果落在乙的刀尖偏移与重心后退上，而不是停在好看。

## 边界

成年身份、双方自愿、非露骨、衣料保持覆盖，四项在各窗口一致。身体魅力服务当前动作与观看，不替代动作成立，也不以受伤、疼痛或强迫情境做情色化处理。年龄不明或未成年角色不采用本页内容；纯技术展示、纯战力对峙段可以不采用。

## 同次检查

三个窗口里对手在做什么是否写清；勾引有没有对象与收放；魅惑的机制与对方后果是否对应；性感是否靠差而非露肤；曲线是哪一种读法带出、光与机位是否读到；柔软是否写出传递顺序；相邻动作是否过差异门槛；效果是否真的改变了下一招的条件。

输出融入原稿的画面与S段，不另交魅力说明表。文本设计通过不证明成片成立，实际身体的柔软度、曲线的可读性与魅惑效果需要观看验证。

## 回应的选择与身体任务

明确成年且适用的场景中，发起者有想获得的回应，接收者可接住、延迟、转移注意或明确收住；下一步依实际回应调整。自愿的来回由双方行为成立，不把沉默、失神或被迫近距自动解释为愿意。

身体曲线与柔软来自已选动作的支撑、分部位领随和收放，不在腰、肩、膝同时安排互斥任务。取景读当前变化，临界距离和衣料响应继承原服装；局部表现完成后接回人物任务，不连续复制同一种展示。
