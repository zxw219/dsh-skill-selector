# 交战意图与召唤/表演覆盖

用于普通打斗被误编为逃跑，以及召唤段只有奔跑/全景、施术者和作用体缺少局部、情绪反馈被省略或摄影只有跟拍的缺口。承接同一事件链与用户授权，不重设能力、胜负、时长或声音；维护修来源，普通创作不增加过程报告。

## 先确定为何移动

用户明确目标与已确认剧情优先。只说打斗、高速、高燃或炫酷时，双方保持主动交战意图，先选抢攻、夺控、打断、压迫、反制、守住或竞技中的实际争夺；不先设定一方必须逃跑，再围绕出口排招。

避线、卸力后退、主动拉距、被迫换位、破围或穿过术法缺口都可以服务交战。正文让移动接上原任务，例如侧让后截控制手、卸力后压回攻击线、切开根笼后取得反击角度。没有撤离目的时，别把破围的终点持续写成远离对手。镜头/动作“出口”只表示段尾状态，并不授予角色逃离任务。明确追逃、脱离或守退照原目标执行，不禁止合理后退。

## 按事件选观看对象

| 对象 | 可读局部与变化 | 接出条件 |
|---|---|---|
| 施术/召唤动作 | 指节扣合、掌面开闭、腕肘牵引、肩胸接负载、断诀交令 | 作用已改变，接同次作用体/目标；不重演起手 |
| 召唤物/大型作用体 | 有效部位、形成边界、材料铺展、关节/连接受力、局部损伤 | 接其运行、交会或范围；保留归属与尺度参照 |
| 人物表情与小动作 | 目光接收、嘴角/下颌变化、负荷下指节微颤、呼吸回收、强撑或放松 | 接仍在持续的任务或相容决定，不强制变招 |
| 情绪动作与受力反馈 | 身体开合、肩背顶住、局部回缩、接重、愤怒/兴奋/克制的实际身体表达 | 同次负荷与攻防继续，不切镜复位 |
| 交会与范围 | 来力、有效接触、主形/人物关系、区域结果 | 接真实受力与下一行动 |

这是选择空间，不是每招必拍清单。局部有当前观看收益即可采用，不必每次提供独有破绽；可以呈现形成、材料质感、承受、投入、控制或审美重音。无形领域取可见介质/边界，不凭空补兽首；无手势或瞬发不硬加仪式，参考图身份不冻结动态表演。

## 运镜与切镜进入同一时间

先选看什么，再给起幅、触发、可达路径/相对速度与落幅读取。可从控制手近处退开交同次主形，沿形成结构横移，随有效部位退移读逼近，或在已建立的手/作用体/人物深度层间转焦；机位与焦点分别成立。不用无目的环绕填时间。

CU/ECU写局部裁切、可见侧和实际细节，主体占幅须支持读取；不能在全景索取细微指节，也不能以召唤物头部特写证明全身路径。范围由同次邻镜或连续退移承接。已有空间无需重新插地图，必要归属/尺度不能丢失。

人物接收、表情和小动作可发生在持续施法、攻击、接重与余波中。对手、召唤物、在途术法和持续场在画外仍推进；返回时接到已发展的相位，不重新释放。反馈不必改变下一招，但须继承身体负荷、关注对象或已采用性格；不让同一控制手同时施术和整理饰物。

锁定一镜到底用允许的移动、调度、焦点交接；锁定固定机位用已有画内变化，不暗插特写或强制运镜。摄影专项只修观看，动作/表演专项只修所属过程；有上游缺项按已有授权处理，不借覆盖重编剧情。

## 并入最终正文复核

1. 原交战目标是否被默认换成逃跑，或因反向纠偏而禁止合法后退/明确追逃？
2. 采用的控制端、作用体局部、人物反馈和范围是否在正文真实可读，而非只在全局列出？
3. 表情、情绪动作、微动作与反馈是否有负荷/接收/性格依据，不被“必须改变策略”误删？
4. 运镜实际改变位置、视场、朝向或焦点中的哪项，何时交接，局部返回继承哪项进度？
5. 瞬发、无手势、固定、一镜、纯近战和有意隐藏等边界是否保留？
