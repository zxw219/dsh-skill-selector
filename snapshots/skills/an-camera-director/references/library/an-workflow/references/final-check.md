# 交付前终检

已有剧本、对白/悬念或多场叙事先用[剧情编译](script-to-screen.md#交付前四遍反证)对原文、声画理解、空间、时间分别核实际最终稿；下方实战检查只用于实战段。原文事实/否定事实与逐字对白未覆盖，人物提前知道，视线/通路/持物断裂，或对白与同期动作重复加时，均先回所属层修，不能因镜头术语、栏位或时码连续放行。

先按[任务对象](task-routing.md)确定正在检查作品还是维护工作流。维护模式将样本问题归因并写回实际来源，交修改与验证证据；不能从“检查一下”直接跳到重写、改时长或另起故事。

## 速度型能力先核相对时间

闪电侠/快银式超级速度先按[专项验收](speedster-combat-direction.md#7-编译与验收)从最终正文取证：真身路线与拦截/变向/交锋是否写出，成片时间与世界推进是否分开，普通人与同级对手是否各守速度/感知能力，切换参照是否接同次位置/动势/结果，附体/脱离特效与触碰物是否持续。不能用残影、电光、快剪或招数代替；不能按主观画面三秒脚不动误判普通人停机，也不能临时赋予其同速反击。固定、全主观、纯外部、无慢镜、静音和一镜约束按原要求检查。时间处理已成立才核下方普通快战的同期与摄影偏好。

## 本次实战与表现性摄影的先行核对

先按[连续打斗](continuous-fight-gate.md)逐关键准备/显化/回收/反应窗口读双方有效行动与限制；去掉摄影、特效后仍须持续争夺，不以相机环绕抵偿停机。非必要双人站立全景、中途停手对峙、一人放技能另一人观看须回修最早事件接口。必要角力/控制保持核具体压力发展与出口，不用统一秒数判断。

再按[视觉门槛](cinematic-composition-gate.md)核最弱关键段的观众立场、画面主次、起中落幅、特殊变焦变量与切点前后状态。只有技巧名称或所有镜头平均强烈就不算艺术化兑现；固定/一镜/慢镜只锁原指定变量，裸眼POV限制不能扩大到全部摄影。

改控/负载方向变更须有紧邻的刺激与转换，不能让“仍/继续”暗接从未成立的前态。卡阻/杠杆/锁止核加入约束前后的自由度和实际接触几何；先被缝夹住、后再加枪锁死时，两次的作用区别要可读。复杂路径或固定全身框的关键中段不能漏掉必要接触/地形变化、遮住所需手脚；已建立事实不反复挤占主变化。具体回修[压力接口](../../combat-action-design/references/pressure-overlap-and-release.md)与[主证据优先](../../cinematic-camera-design/references/expressive-camera-and-zoom.md#先决定观众经历什么)。

## 交付条件与检查分支

### 从成品反证不从作者解释放行

检查先从当前请求与会话有效要求确定检查项，再以用户事实和最终正文取证；不从草稿反推本次只需检查哪些项。用户要求的速度、频率、技能规模/变化和摄影各有证据，不能互相抵偿；局部连续性修好不等于整稿达标。正文缺少一项必要设计时，先核是否由助手补设的能力/场地上限造成，回到该未锁前提修复。设计笔记、技能知识、脑内补全或“我是想表达”都不算成品证据；只在全局写要求而具体镜头未兑现，判欠写。结构正确与审美可用分开，缺项先修再交。

参考图角色的身份也包含装备事实。先对照原图、用户锁定与实际动作中出现的武器/护具，不能只核脸、发型和服色；木盾、冰盾或前臂常驻承击结构按实际功能核为盾式装备，不因被称作法术而跳过授权。发现助手为格挡链补出装备时回到战法设计层，不继续围绕该补设增加破盾、修盾与持盾手检查。角色原有道具难辨时保留可见事实，不凭轮廓认定新武器。

先选择最可能拖累体验的关键段，检验真实失败路径：去掉“高速/力量/默契/电影感”和装饰音光，是否仍有对应运动与关系；合并重复推挡、长保持及等大跟随，是否暴露只有一项作用被拉长；遮住作者解释，读者能否确定谁改变了谁、为什么此刻转镜、之后发生什么。无需机械处理全文每一个形容词，也不以文字长短或招数阈值判美感。明确慢镜、仪式、固定、主题复现与纯氛围按本场目标检验。

对发现的最大缺口，用同条件的相容替代核实是否需要重设计：保留角色、能力、结局和时长，改变具体攻防/表演关系或观看顺序，是否能兑现原稿没有的作用。能明确改进就回填实际稿并检查依赖；不能证明原稿失效则保留合理选择。不得用增加能力、删人、降幅度或改变故事来制造容易通过的替代。

跨镜仍在持续的接触，另将前镜最后一次成立的连接与后镜首次采用的连接并排核对：谁的哪侧肢体/器物、接谁的哪侧部位、当时是抵住/抓持/滑移还是已脱开。来源写在S、画面或transition任一栏都算，不能各栏分别自洽却互相换了对象。部位变化须能指回同次换点或解除再接；没有转换时修正错误侧别/部位并顺查后续占用，不为一个笔误另编换手动作。其他无持续连接的切镜不增加这项账本，空间推演见[入口与出口](spatial-continuity.md#把空间作为事件的入口和出口)。

检查输出是修好的成品或具体未解决限制，不是自评高分或全项“已通过”。完成适用复查且没有已知缺项即可交付，不无限自我挑错。用户询问检查范围时，给实际发现/修改和剩余不确定性；未发现问题也如实说，不虚构一次修复来证明认真。

同一作者的复核仍属于作者审阅，不能写成独立验证。工作流维护是否改善了无提醒出稿，按[前向验证](bundle-maintenance.md#用新任务检验是否改变下一次选择)另行记录；一次新稿或独立评价也不证明稳定掌握，成片效果需要真实观看。

### 把采用、可读与依赖分别取证

对本次最弱的关键变化，先在最终稿定位谁/哪个部位发生什么，再核三层：实际事件是否写出不同解法或作用；所选画面能否在当前时刻读到它；结果是否有前态并进入下一任务。三层不能用同一个“高速、丰富、默契”标签互相代替。

动作若受阻或配合失败，从真实出口重新读支撑、接触和资源，不继续套模块成功版；摄影若丢了关键相位，先比较同次局部/关系覆盖或[复合路径](../../cinematic-camera-design/references/composite-camera-paths.md)，不补第二次动作。巨物、人物、表演与声画同窗时，说明本拍主读及其他层怎样继续，无法同时读取不一律减规模或冻结敌人。

编译返工后反向定位丢失的控制/部位/作用事实；新状态用唯一对象和部位承接，不能把右腕旧裂口当成胸背前态。以上是现有事件、观看与连续性核验的执行方式，不加动作数、技法数或新公开表格。作者审阅、独立文本和成片分别保留证据与未通过项。

### 战斗体验先于连续性放行

先按请求、参考和采用事件核当前主体验，不能从草稿自选低要求。未另示的普通实战保留主动速度、频率、力量、变化与摄影要求；能力展示、控制博弈、压制和反扑按[能力作战](ability-led-combat-direction.md#采用后复核)核能力辨认、条件应对、结果、人物接收与保持作用，不以低频直接判失败。明确高速/高频继续各自取证，同场分段核；先验实际体验，再核空间/资源、时间/声音与格式。固定、单能力、纯远程和单镜按原边界，不误报为必须加招或移动相机。

沿最终稿的全部交锋簇逐段核以下问题；内部核对，不要求向用户输出表格或套固定招数。按人物图直接出打斗时，先按[打斗默认契约](fight-default-contract.md)核分人、能力、主动权与镜头因果，再进下表。

| 维度 | 要在实际稿里找到的证据 | 不能据此放行 |
|---|---|---|
| 攻防章法 | 双方本段争取的优势、尝试与拆解、转折及下一机会；关键处对手可用的退让/截击没有被作者无故忽略，升高与下降处理同一威胁和任务 | 动作都能接上、每招都有“应对”，但整段靠对手原地承接或给花招补装置 |
| 高速（采用时） | 紧凑发动、攻击端跨参照、交会制动和随即改线/续攻；源端与在途分别成立 | 小数时码、“迅速”、仅跑动或残像 |
| 高频与快节奏（采用时） | 前招的应对/受力产生后招条件，准备与恢复有相容重叠；画外对手仍在行动 | 几秒一次施放，效果结束再准备，字幕式排列动词 |
| 能力展示与控制博弈（采用时） | 能力/对象可辨，对方处理同一威胁；保持有读取与退出，同系复现产生本场需要的用途或出口变化；本体与在途作用资源相容 | 只标能力战便站桩轮播，用动作少直接判失败，或为丰富强加新能力 |
| 力量 | 身体/机制驱动、攻击端路线、抵抗/接触、受力与恢复是同次运动；拳腿有当前支撑、髋肩/髋膝参与和可见触点，腿型不混作直线伸腿 | 发力术语、对手自动后退、“厚重爆响”、白闪、抖屏、最后才爆炸 |
| 动作利落与拍数 | 关键动作有相容加载/爆发/接触或避开/受力回收/下一任务，速度与频率在实际作用中可读；样例拍数和镜长不作硬配额 | 只有起手—结果、无作用复位/等待、切镜重播、用慢镜或快切掩盖缺失作用 |
| 反应链 | 攻击/威胁→应对或防法结果→可读受力/回护/接收→新条件；反应与任务同时间，快战短反应区间仅供估算 | 只写攻击方、对手自动后退、反应只是表情、不影响下一拍 |
| 模块变化 | 不同身体/兵器/作用结构改变对方解法和下一条件；身体过程可辨 | 换攻击端、换色或全局模块菜单抵偿自然动作 |
| 主动权与换手 | 最长簇合并重复进退后仍有压力、支撑、路线或控制难题发展，防守者有相容尝试 | 一路压进/格挡/后退；用固定反转次数抵偿重复 |
| 全身动作（自然动作请求） | 身体轴、重心路线、支撑转换和幅度可读，贯穿所需交锋；持械/对手同期/接重续招成立 | 只有动作名、局部攻击端、衣摆/残影/相机转动，或结尾点缀一招 |
| 动作拓扑（自然动作请求） | 高低、支撑、攻线、兵器关系与恢复的变化服务实际解法和美感 | 同一动作改名，或按八轴数量取代实际身体过程 |
| 人物与能力 | 每个独立参考是不同的人；判断不出时按独立人物处理，只有明确同一人/多视图/变身才合并；继承或获准原创的能力/限制可辨，采用用途改变对方条件；不为次数补能力 | 把两张人物图写成镜像/分身/同一人；能力只在结尾加装饰光却不改变条件，或只换颜色 |
| 能力展示 | 用户要求的每项能力在事件正文（An格式下为S）有触发/归属、实际作用、对手同期与新状态，观看可读；瞬发/被动/离体按机制 | 全局列技能但正文只肉搏，fx-env泛光，拿技能上限放行零交付 |
| 技能设计矩阵 | 来源/介质、发动、主形、作用、控制/限制和终态相容；用途按战局选，不强制表格、三次和固定镜序 | 只列名字/光效却无实际作用，违背已定限制，重复用途没有发展，或无作用地等效果播完 |
| 大招尺度（采用时） | 区别普攻的主变化、所需尺度/强度参照、抵抗/传播和人物后续，主峰有读取时间 | 小道具挂大招名、亮度/米数抵偿，统一六拍破口或白闪跳过作用 |
| 摄影覆盖 | 关键身体中段、对手关系与同次能力作用有实际可读覆盖，注意接力有收益 | 固定摄影相位数、相邻属性配额，快切掩盖身体或技能缺失 |
| 打斗逻辑与连续性 | 每个交锋有意图→尝试→反制→结果→新条件；本场有目标/胜负条件；条件连续变化，不强制起承转合/固定反转；单方压制、速杀、追击可成立；结束由具体动作 | 招式串、双方空挥、强制三次反转、只会打一套、写“更强”就赢 |
| 节奏与观看容量 | 普通快战有速度、持续压力和相容变化；控制、承压与接收有可读发展及出口；同镜/跨镜按证据成立 | 无作用摆姿、复位和等特效；仅靠动作点、秒数、镜数或运镜种数放行/判错 |
| 距离账 | 两人的支撑点连线是否移动，距离/高度/朝向是否在变；连续三秒同一位置时，有没有接触或控制、对手是否在逼近 | 只有特效、镜头或身体微动；两人定距各放其法 |
| 技能交错 | 前招在途/持续/残留时共享时间；已彻底结束则从新状态承接，不补假残留；后招读取真实结果 | 无因等候、复位再施放的轮播；强制瞬发技能保留假作用期 |
| 同期动作 | 每个S段里对手在做哪件会改变条件的事；他不动时，是哪种限制成立 | 一人在蓄力、另一人站在画外等结果 |
| 称谓与代词 | 全篇她/他、甲/乙与身份一致，不因动作强硬改称 | 前半段“她”、后半段“他”；两个角色代词互换 |
| 2D作画 | 关键姿势/接触帧/smear/冲击帧/hold/分层运动可读；2D 镜头用分层/视差/起落幅 | 真人相机硬搬、全程速度线、每击冲击帧、人物层背景层同速 |
| 空间与朝向 | 每镜有 blocking（画面侧/面向/距离/轴/机位侧）；切镜不重置；跨轴有中性/可见过轴；背后/换位有路线和对手面向 | 左右跳、反打自动掉头、无路径绕后、前一镜三米后一镜贴身 |
| 分镜与覆盖 | 必要建立/交换/作用/结果得到覆盖，可在镜内；切镜有观看收益，运镜有起幅/触发/可达中段/落幅 | 全是大平侧跟、只换景别、随机角度、无因360/环绕、快切遮动作 |
| 镜头语言与构图 | 景别/角度/焦段/构图服务当前观看；建立/交换/冲击/反应/技能插入各有职责；冲击不靠白闪 | 全景—中景—特写机械轮换、随机Dutch、平构图、只换景别 |
| 镜头因果 | 每镜空间→路径→接触→结果→下一条件；换位有路线/遮挡/绳索/能力带动 | 无路径换位、未成立作用却击飞、无依据出现在背后；同质切镜另按具体观看问题处理 |
| 运镜与张力 | 本拍主读的控制、作用、接收或范围得到真实注意交接；运镜有起幅/触发/速度/落幅；快战有快速果断摄影 | 镜头抖代替速度、无因环绕/360/升格、全场等大侧跟、技法配额 |
| 保持与收尾 | 保持有当前任务、负载/预期/判断发展及出口；结束承接同一次行动与既定声音/时长，黑场仅按采用要求处理 | 以有效保持之名掩盖空等或削弱已锁高频；为凑主峰/完整曲线新增结局 |

对较长S段先合并语义等价动作，再看它实际完成多少不同压力变化、每次变化占时是否合理；不能用拆成小数秒子段伪造频率，也不能统一规定每秒几招。需要阅读的重击、表情、持续承压与慢镜按本场用途保留。发现无作用空档，回[体验设计](combat-experience-design.md#普通打斗的主动设计起点)重编交锋簇与并行；发现攻击趋同回模块选用；摄影趋同回摄影执行；力量欠缺回传力和受力。修后复核空间和资源，再重过体验项，不能通过删招、减幅度、拉长准备来换连续性通过。

对本轮采用的细则再核适用性：交手因果在连续事件中闭合，不要求每镜齐攻防反；样例密度与运动菜单不创造配额；身体负载、轻控制、离体/自主与被动按机制选；双色、三段形成、强度配色与反制窗口不强加。违反用户事实、控制资源、时间/空间或必要观看证据才按具体缺项返工。负责依据见[规则适用](fight-default-contract.md#规则适用与验收)。

摄影复核核对实际选择是否兑现当前体验，不要求每镜都跟拳/跟脚、都广角、都倾斜或都快速移动，也不要求每招走完起手—在途—命中—反应。明确慢打、文戏、艺术化保持与锁定拍法继续有效；跟随中的短促制动与独立固定段分开判断。相关方法见[动作点跟随与广角特写](../../cinematic-camera-design/references/camera-execution.md#动作点跟随与广角特写)，学习证据见[本轮研究](action-follow-camera-study-20261016.md)。

本轮来源维护的实际失败样本与人工情境审阅见[2026-10-16记录](combat-default-execution-20261016.md)，普通创作不加载记录。文字审阅、独立调用与真实成片验证分别报告。

采用多人连续参考或新动作组合时，在原适用终检中核[镜内接力](../../action-camera-direction/references/continuous-fight-handoffs.md)和[接触/高低接续](../../combat-action-design/references/contact-height-combinations.md)的实际进入、交会、旧关系续行、支撑/释放和遮挡回接。接触/器物文戏只核[表演响应](../../performance-scene-director/references/contact-task-response.md)的当前任务与资源，不套全员攻防。各项是本场采用分支，不另加全套课程或动作配额；观察边界见[六条记录](six-reference-study-20261015.md)。

多人/团队/一对多先沿[多人体验与学习兑现](multi-character-combat-review.md#先验共同交锋与观看体验)核共同关系变化、动作接力、因果分镜与实际运镜，再核所有关键人物的同期状态、有效交会/射线、救援窗口、画外回接和结尾。局部解藤/断杆不单独证明救援，近景裁掉敌人不形成安全；明确保持/对峙/慢镜和单人展示按目的保留。无停机或空间错误不能单独放行，先定位最早失效层。

打斗采用本次学习方法时，核角色习惯是否在进入/攻击线/发力/回收中可辨，招式职责是否读取实际窗口，密集动作是否有具体同期攻防，破防后的可用肢体/防线是否真实过渡；升级不能只增爆炸。再核效果形状与攻击路径相容、源点/接触变化/残留同源、载体已有、普通与主峰层次成立；取景读到身体/接触所需证据，事件触发摄影，切后接剩余相位。缺项回动作、效果或观看所属层修，不能以三块栏目齐全放行。方法与相邻反例见[选择性学习](combat-skill-transfer-20261013.md)，按实际采用项核，不要求每场用齐12项，也不把固定配额写成验收条件。

创作/已授权改稿：检查属于出稿本身，不另等用户批准修复。对发现的问题先改实际正文，再复查其依赖；最终核已修稿，已知硬错误、未落实的本次适用要求或未核的受影响后段尚存时继续处理。不要以“检查过”“因果大致成立”或一份待修问题清单替代完整作品。缺失信息确实阻碍修复时报告具体冲突与所需信息，不虚称通过。

单独检查/查因：只交实际证据、原因和改法；没有修稿授权不自动重写。作品与工作流同时获准优化时，两者分别完成，作品通过不代替来源修订及同步，文件/ZIP通过也不代替作品语义复核。询问既有交付是否检查完成时，如实核查当时范围；仍有效的创作/修复授权允许补完漏检及必要修正，用户明确只查不改则优先。

“一次性完成”是同次交付内收完适用检查、修复与复查，不是一次扫描保证零遗漏，也不要求无问题稿反复全审。检查结论必须对应当前最终版本；只做局部或结构核验就按该范围报告。实际成片验收另依生成结果，不由文字通过推导。

## 摄影设计与持续观看的适用复核

先沿最终稿的真实观看顺序复核用户要的电影感、艺术化拍摄、景别/构图丰富度与必要局部已经怎样发生，再核路线、肢体、时间和格式；连续性成立不能代替摄影要求兑现。没有这些要求的简单任务也核当前观看目的，不强加变化。

- **实际画面**：每次需要读脸、手、身体、关系或空间时，裁切、观察侧/高度、遮挡和清晰层能读到；景别标签和焦段名不作证明。
- **持续作用**：长镜及较长跟随合并语义等价的S段后，仍有什么表演、关系、空间、图形或期待在发展/被承受；加速、背景掠过和相机移动不自动证明艺术化观看充分。只有长时间等大侧跟、同一观察侧与同一注意对象时，回改摄影选择；本项按常规复核执行，不等用户提出丰富要求。
- **切镜差异**：同一交锋簇内相邻两镜比较距离/占幅、观察侧/高度、注意对象和运动质地；只换侧面却没有观看收益时回改，有作用的回应/同构回返不按项数判错，按[切镜差异门槛](../../cinematic-camera-design/references/camera-execution.md#切镜之间的相机关系差异门槛)回改。此项只看两次切镜之间的关系，不换算成每场角度数、景别档位或换镜频率的指标。
- **路径与构图**：中段可见轮廓、留空、层次与注意如何交接；机位能从前一出口连续到下一位置，人物无需等相机，镜内不靠隐藏剪辑补造路径。
- **真实切接**：前镜最后与后镜最先可读画面如何接注意、占幅、动势和状态；不是只写“顺动作切”。
- **一镜到底**：选型符合本场目的，持续观看的关系/注意/期待有实际发展；真实连续、无缝剪辑外观与多段生成接缝分清。一般摄影可连续变焦，裸眼POV/定焦/固定视场约束优先；不以三次占幅、出画1.5秒或表情1.5秒作通用门槛。动作与画外时间不断，方法见[一镜到底](one-take-direction.md)。
- **身体机位的距离**：POV 或床边镜头里，每个距离都能说出他站在哪个平面、我和他之间隔着什么、我偏了多少度；小于 1.2m 有跨越或支撑；转头后屏幕侧重算；光与站位一致。方法见[POV 距离与站位](pov-spatial-composition.md#距离与站位床边沙发地铺这类身体机位)。

任何一项尚无正文证据时先修对应设计与受影响后镜。固定等待、长期读步态、单一焦段或少机位可因用途成立；不设置镜数、角度数、每几秒变景别或必须升降的阈值。具体方法见[持续摄影](../../cinematic-camera-design/references/camera-execution.md#连续长镜头的观看发展)和[同条件案例](../assets/cases/camera-progression-20261015.md)。文本审阅不证明真实生成节奏与美感。

## 技能丰富与重复的适用复核

普通打斗主动核动作与技能的相容变化，明确锁定单招或重复任务按其作用评估；要求丰富或反馈单一时进一步定位漏用。沿最终实际采用片段核作用结果、施法操作与决定性画面，不只读技能表或统计招名。遇疑似换皮，暂去名/色/大小/摄影词，再核两招是否可互换而原防法、出口与后招原样成立；没有重复用途就按[原创与选招](ability-variation-selection.md)修所属层和依赖。主题共享、签名复现、压迫累积、识破、锁定同招及纯展示按目的保留。攻击本身也需相容变化，不能只添加感知/治疗类别却正文进攻仍全甩光波；观看差异不替代机制，机制差异不自动证明已拍清。作者原型/练习、独立调用和成片证据分开。

## 切镜与短距攻击的交叉核对

高速施法稿沿最终正文核全部适用交锋与普通施法：速度有短促有效作用/应对/改控证据吗，移动有当前用途吗，手势/身体真正操作了术式吗，招式去名/去色仍有本次需要的机制差别吗，控制手、前置、在途/自主和残留接得上吗，关键小招动作/结果也取景可读吗？缺项按[高速施法交锋](fast-spell-exchange-design.md)回所属层修；只跑很快、只加招名、只为大招写手诀不能放行。投射单招、无手势、追逐、固定与合法仪式按本次请求保留，作者文字学习不冒称实际视频验证。

先沿最终正文读整段观看发展，再核局部连续性：关键理解是否有必要证据、人物选择是否接到刺激、主次是否允许读取、相邻镜头/镜内变化是否接状态与注意、强调和节律是否相对本段基线成立、结果是否兑现请求。只有单镜可达与时码连续不能判分镜充分；缺项按[整段分镜](storyboard-sequence-design.md)回所属层修，并复查受影响前后镜。固定静音、直观结果、持续压制、一镜与无叙事氛围按目的保留，不套统一镜序或起伏曲线。

位置/距离/方向反馈先沿[空间连续推演](spatial-continuity.md)检查最小布局和动态出口：每次新距离、绕后、落点、通路和接触条件是否由前段路线/转向/同期目标推出，未知地标关系是否被偷偷补成有利布局；射程与无遮挡射线、身体后撤与双方增距、世界方位与屏幕投影分别成立。巨物固定源点/移动端/整体自由度、障碍高度/体积与环境损伤的原位置要有依据。按更新后的轴与机位复核，不以“始终东侧”或单幅坐标宣布全片方向通过。缺项、已证矛盾和合法幻想选择分开报告。

分栏稿沿正文逐处寻找真实切镜，包括S段、画面和衔接里的“切至/切到”等；实际剪辑点对应独立镜头、包络与镜尾transition，同镜的转焦、摇摄和阶段变化不误拆。按用户锁定的一镜到底或其他格式处理，不为增加编号虚造剪辑。局部镜接同一次动作的剩余相位，不能重放起手或命中。

短距攻击分别核离体、在途、接触及防御启动的时间与当前距离；高速要求下不要让近距箭路占去无作用的长段，也不能只缩短数字逼对手在命中后才防御。必要时让对方根据可见的拉弦、瞄准或源端形成预判；所选飞行与形成时间来自当前机制，不把某个样本的0.1–0.2秒当所有攻击统一配额。改接触锚点后，声音、材料反馈、持续控制与下一行动一起调整。

## 镜头语言与奇幻快战验收

先核交战意图：没有用户明确或已采用的追逃/脱离任务时，整场是否被默认编成一方找出口、一方追堵？后退、避线、破围和通过技能缺口是否服务原抢攻/夺控/反击，镜头/动作出口有没有被误当撤离目的？明确追逃仍可成立，不能反向禁止所有后退。

召唤/大型作用体与表演覆盖按[交战意图与覆盖](combat-intent-performance-coverage.md)核实际采用项：必要控制动作、作用体有效局部、人物接收/表情/小动作/情绪动作/受力反馈与范围关系是否有合适占幅和相位；不能只拍角色奔跑与最终大远景。局部与运镜各读什么、切出后谁继续、返回接何相位要成立。反馈可呈现投入、承受或控制，不要求每次改变策略；固定、一镜、无手势、瞬发与有意隐藏按目的保留，不强制全套特写。

会用摄影还须检查未被用户点名的必要观看：本次事件的重要线索、微小控制、关系/范围和转折是否主动找到合适取景与交接；选择是否在镜头/画面、S及衔接实际生效。无术语要求不表示可以漏拍必要证据；合理隐藏、单一拍法和已锁固定/单镜仍按目的保留。自主选用的行为验证以不给拍法答案的新场景为证据，不按技法出现数或点名照写判通过，具体按[主动摄影决定](../../cinematic-camera-design/references/camera-execution.md#用户给体验摄影主动做决定)。

摄影验收先对本次明确要求找到正文证据：要特写须有CU/ECU的对象、实际局部裁切和可辨细节，不能把泛称近景或远处小人物算作兑现。再暂去名称，按[摄影执行](../../cinematic-camera-design/references/camera-execution.md)核实际变量：推拉改变距离、摇摄改变朝向、横移/弧移改变视差、急变焦迅速改变视场、希区柯克有反向位移/变焦及主体稳定和背景相对变化、手持有观察者应对与所需质地、转焦有真实深度交接。起中落幅、触发/落稳和画外推进在同一时轴成立；模糊过渡与关键读取窗口有分工。用户未要求的手法不凑齐，固定静音/一镜到底等合法约束仍保留。

局部镜同时核人物自身的可见面与相机视线，右肩外侧不能在未成立转体时由左侧镜头直接读到。正文指定等效焦段、距离、画幅时，其容纳范围与全身/局部标签须相容；不能在检查报告里补原稿没有的姿势或摄距解救取景。只在明确数值已采用时做必要几何校核，不给所有镜头强塞镜头参数。

先按[导演决定](director-deliberation.md)回查角色/机制、事件作用、观看安排与时间用途，再核肢体、连续性、时码和栏目；局部结构通过不能放行上游设计缺项。战法错配、无效动作/停顿或分镜不足的反馈须返回该依赖层，不能仅改末镜、加快切或新增镜号。用户要求查因/维护时分别交证据/实际来源修改，不擅自重写提示词。

所有题材先查观看任务、构图/观察位置、运动或保持的实际收益及相邻承接。文戏查刺激/接收/关系变化，悬念查观众与角色知识、遮挡与揭示，舞蹈查轮廓/节律/表情，动作查来向/接触/承力，大场面查尺度/侵入/传播，氛围可承担空间与图形体验；不将快战速度要求套给所有场景。见[通用镜头语言](../../cinematic-camera-design/references/movement-composition-effects.md)。

快战再查不同解法的招式、迅速普攻、快速追压、真实冲击与要求的区域主峰。固定镜头有尺度压迫、关键接触、范围传播或其他明确特殊作用时可以成立，核其固定对象、画内变化、读取结束与出口；不能因为用户未逐镜点名或出现“固定”就判错。无目的固定平列、普通过程长期慢移、左右拳循环、重击只闪白、小技能多秒聚光和远处大球则返工实际事件。明确全片禁固定仍按禁令验收。

本页用于完整审计或难以定位的跨段故障，普通出稿沿入口页完成适用检查及必要修复、复查即可。只展开实际相关项目，不为不适用项另写说明。需要追查断链时从出错结果反查来源，无需每次全稿双向执行。

## 判定

用户明确的时长、镜数和声音范围按硬条件核。28秒快战样例、攻击端数、切镜差异项数与短反应区间用于设计和诊断，偏离它们本身不构成硬错；按当前战法与主体验核实际作用、观看收益及容量。

动作/打斗的小数秒验收按[时间编排](subsecond-action-timing.md)：镜头/S边界与关键相位以0.1秒精度给出，锚点在所属区间且依赖成立，相邻段和切后接同次剩余相位，效果/声音不重触发，总片长不变。不能仅查有小数点就判通过；连续快战还须有实际可达的发动、接触/避开、受力/控制和后续任务。整数锁定锚点写`.0`不代表已经细化动作，合法持续保持仍按作用保留；不承诺生成端逐点执行。

- **硬错误**：文本内部已能证明矛盾、断链、不可达或用户事实被改。必须修复，不能带错交付。
- **生成风险**：文本自洽，但有具体角色、状态、接触或摄影负载难点。先按[生成端适配](director-handbook.md#生成端适配)处理，保留核心要求；仍影响使用时说明具体风险，不因抽象的失败可能性削减动作、强度或反应。
- **风格选择**：存在多个合理方案，不因检查者偏好判错。已建立的幻想机制、有意时空断裂、象征画面或留白按其表现目的判断；不强加写实物理或剧情解释，也不能把意外断链事后称作风格。

## 动作多样性与美感（仅相关要求）

手脚并用与技能单一反馈按[全身与能力协同](full-body-ability-integration.md)对最终正文逐段核：脚是否仅走路/承重，是否有实际腿攻/腿防/下盘控制；手与腿怎样互相建立窗口，对手响应、收腿接重与下一距离怎样延续；去掉颜色/源点后，技能作用是否仍不同，是否又退回统一掌前发射。摄影须交付腿技的髋膝、支撑/腾空、攻击端与目标关系，局部可由邻镜补同次必要事实；不以踢腿词、发光脚掌或数量配额通过。纯远程/纯兵器/锁定单招保留，用户新明确要求优先于助手补设。

动作与打斗终检时，沿实际S逐簇核[攻击端差异门槛](../../combat-action-design/references/action-module-bank.md#多样化攻击模组攻击端差异门槛)：相邻行动的攻击端、轨迹、高度、接触与用途是否回应当前条件；重复是否积累负载、试探或继续改变机会，身体/混合快战是否主动采用相容攻击端和下肢/全身作用，纯远程/持械/单端按允许变量发展，防法是否回应当前压力；爪战角色按所选勾、撕、刺、扯、压核具体过程，爪端动作在景别里是否可辨。有动作丰富/模组少反馈时从同一处进入：前出口是否接后入口，还是库里很多而正文仍循环几招；缺口回选招/组合，不只换词。再按[身体美感](../../combat-action-design/references/action-phrasing-and-aesthetics.md)查实际正文，不查类别是否凑齐：隐藏招名、华丽/高速标签、装饰光和摄影词后，进入、路线、防法、身体开合/领随、释放与收势是否仍有本场需要的差别？近远转换是否有真实距离、窗口和控制资源；对手的响应是否改变下一招？动作缺口补编排与完整乐句，已有好动作未读清才改观察，不只加环绕或同义词。纯持械、单技能、慢镜/定势、持续压制、单人演武、静音和固定一镜到底是合法反例，具体见[成稿练习](action-diversity-lab.md)。源帧仅证明采样姿态/相位；节律、连贯、美感和生成精度需真实片正常速度验收，脚本不替代。

格式先核本次选用：完整MOKE提示词默认有全局、真实镜头/画面、S=、fx-env、sound及镜尾transition；连续阶段与丰富动作须在这些栏目中兑现。用户明确选择自然叙述，或入口允许的无既定格式简单单场顺序事件采用简洁正文时，按该格式验收；新角色/新场景本身不取消默认模板。使用文件检查时，分栏选fusion，合法简洁正文选prose，不能用prose通过代替分栏核验；普通成稿人工核同一格式要求，不强制每稿跑脚本。

采用成人魅力/腿脚特写时，按[战斗魅力与腿脚细节](adult-combat-detail-direction.md)核本次成年身份、鞋履衣装、支撑/来刃窗口、读取相位、对手任务与出口。裸腿/赤足展示是可选项；局部镜不证明全部发力，邻镜接同一次动作，固定、穿靴、纯持械与无展示均可成立。本场采用情趣互动时，再核[双向情趣](adult-combat-detail-direction.md#双向情趣发起接收与回应)的三跳、张力来源、对手同期任务与下一招的接回；两次以上互动核相邻差异门槛。

## 写法架构与精准表达验收（相关任务）

使用[参考文档精准写法](reference-prompt-writing.md)时，检查实际句子是否给当前需要的主语/物件、有效部位、对象/作用区、路径、应对、结果及下一条件；保留有效形态修饰、运动比喻、用户画质词，互斥的单/双武器方案已经择定。动作作用点、避线出口、腾空落脚与相机落幅分别成立，不因换镜改世界位置或把挥空算命中。

本体发动、形成、施放/运行、持续控制、作用与解除按当前机制区分，旧攻击和残留继承。取景术语给出观看与相机变化，阶段不等于每招一镜。`fx-env：`、`sound：`、`transition：`保持字面与职责，三栏不重复触发、不重置相位，transition只接真实镜头/结尾。用途报告不能代替精准成稿；用户要求维护时核实际源入口、相关映射和同步副本，未生成不报告影片执行已改善。

## 全局视觉与高速摄影验收（相关任务）

采用[战斗视觉与高速摄影](battle-visual-direction.md)时核实际成稿：画质术语是否同时落到稳定体积、皮肤、武器、衣发和场地材质；环境底色、双方能量主形/色彩及局部受光是否分开；侧风/换向/碰撞的随动、碎块落地、浅水与破坏残留是否接续；普通交锋、强化、环境异动与主峰是否有当前战局的作用差别。用户给出的渲染审美词保留为视觉目标，不冒称生成端实际管线或8K输出。

用户要高速时，检查实际攻防是否连续改线/改距/改支撑，防守者是否只举盾等候；相机起幅、触发、路径与落幅是否在接敌、换位、接触和尺度变化中兑现，不能用慢推/轻升/短横移覆盖整场。末段对峙须有任务；固定、慢镜、纯兵器、单技能和既定结局仍按意图保留，不把本次返工变成镜数/招数配额。源帧检查与正常速度播放分开，未生成修订片不报告质量已改善。

## 角色战法与术法协同（相关任务并入一次复核）

按[角色战法与施法协同](character-led-spell-combat.md)查实际正文：类型、主战距离与能力是否相容；持物是否有用户/设定依据；法师是否被默认改成盾牌格斗或晶甲肘腿。专属施法动作改变哪项术式，释放后本体、在途法术、持续场与代理各做什么，控制/忙闲肢体是否相容？有任务的沉稳驻立允许，不以是否奔跑判合格。

用户指定的领域是否有条件/边界的实际变化，召唤是否执行任务，巨型荷花/星体等是否有来源、结构、运动、作用与人物端后果？不同法术是否只有颜色/尺寸替换，或总是发射—撞盾—爆碎？去掉名词仍能看出本场差别；不能从背景行星、圆阵或巨大花纹宣布机制已成立。纠偏不全禁近身/术法防御，不给所有角色强制一套技能清单；既定摄影、规模、画质、物理与模板继续验。

## 细节、干净分镜与进攻力量（相关返工并入一次复核）

- **实际可见**：本次需要辨的手诀、攻击端/落点或其他细节，在景别、占幅、角度、遮挡与焦点里能读到吗？不能以“全景里清晰手指”或特写标题放过远处小人物；范围镜保留其范围任务。
- **同次动作**：局部裁掉的身体取位/支撑、目标与后续受力由相邻镜头接住吗？切点、注意位置、动作进度和持续状态相容吗？没有重抬手、重放招或重复命中。
- **干净利落**：必要主次/轮廓与深度明确，切镜有观看任务交接，瞬发/短攻不被无效停留拖慢；不靠每动词快切、全景特写随机互跳或削弱大场面解决。
- **真实力量**：去掉迅猛词、光弧、抖动和大声后，肉身仍有驱动/加速、接触阻力、受力与惯性出口；术法仍有决定性发动和实际起效/抵抗/新处境。对手与施术者继续成立的任务，不统一倒飞/反冲。
- **创意与保持**：技能从角色与战局产生，用户提过的类型不构成闭集；能力锁定、原质量/物理/范围/声音、fx-env：sound：transition：与提速路径仍保持。方法见[细节覆盖专项](../../action-camera-direction/references/detail-coverage-clean-cuts.md)，未生成不声称实际力量已验证。

## 高速、高燃、手持与大技能的体验复核

适用时按[战斗体验](combat-experience-design.md)、[手持观察响应](../../cinematic-camera-design/references/embodied-combat-camera.md)与[转场切点](../../action-camera-direction/references/transition-direction.md)找实际正文证据。分别核场景是否改变选择、模块是否围绕当前争夺变化、高频作用是否有效、高速是否有改距/过点/追及/制动、表情是否引出行动、手持是否存在观察者响应、巨型技能是否在敌方反制后发展、冲击帧是否有特殊形体和返回状态、主峰是否兑现期待、切后是否接剩余相位。

“左右位置正确、S连续、栏目齐全、技法出现”只能证明所查范围，不能合并宣称全部体验已完成。来源已存在却成稿仍失效，应回修选用与事件而非叠更多禁令；已知缺项修复后重读实际稿及受影响依赖。此为文本语义复核，未生成不得报告真实片的手持、速度、情绪或冲击画已通过。

## 十二项检查

| 项目 | 正文证据与处理 |
|---|---|
| 1. 用户事实 | 最新采用的版本和禁用项有效；锁定剧情、对白及格式未被擅改。创意补足只在授权范围内，不凭空增加改变因果或结果的事件；用户已授权改写不重复审批。 |
| 2. 生成负载 | 排查主体、状态变化、接触/交接、并行互动和摄影阶段中实际拥挤的部分，不要求无问题场景逐项统计。能力未知时不伪造阈值；明显拥挤就执行降级顺序。 |
| 3. 状态继承 | 每次位置、持物、控制、关系或能力变化都有可见来源；前段出口能成为后段入口。“继续、仍然、再次、松开、回收、换位”均有前因。 |
| 4. 路线与接触 | 角色、道具和摄影机路线分别可达，不穿实体；障碍有足够通路和兵器净空。攻击/交接包含进入、接触或落空、反作用/承重和新状态，关键步骤未被特效或切镜隐藏。 |
| 5. 朝向与肢体 | 胸口朝向、行进方向、头部/视线分开判断；反拍不改变角色自身左右。同一肢体没有互斥任务，武器握点、接触面、支撑和承重先后成立。 |
| 6. 投影与可见性 | 从当前机位重建画面左右、前后、可见面和遮挡；人物转身、换位或相机移动后重新计算。景别实际容纳本段必须验收的脚步、接触、交接、道具边界或表情。 |
| 7. 轴线与摄影 | 双人视线线或行动线明确；换侧具有可见过轴、中性机位或重新建立空间。每个摄影阶段有主要路径和观看目的，不用甩镜/遮挡冒充过轴，不让镜头改写动作。 |
| 8. 动作/表演因果 | 动作继承距离、支撑和动势；文戏具备刺激、处理、选择、行为和结果，可有有动机的静止。终结、态度变化和任务结果均由画面或允许的声音建立。 |
| 9. 文本卫生 | 删除旧人物/场地、脚注、系统或后台字段、空模板、无效素材标签和未经核验的跨平台参数。模糊方向词与“瞬间、锁定、继续”等结合上下文能唯一执行；不靠“流畅、稳定、无崩坏”证明质量。 |
| 10. 控制方言 | `A/B` 等主体代号已定义且不漂移；`FS/MS/CU/ECU` 等景别缩写含义稳定并与画面任务相容。每个 `t=` 节点位于所属大段；默认全片绝对时间递增，明确采用段内相对时间时先加该段起点再校验全片顺序，默认只有一个主要状态结果；硬锚点与 `t≈` 柔性锚点没有擅自互换。段首预告形成“起始路径→事件触发→结果镜头”并在节点中兑现，加号不被误解为同时多机位。百分比合计和职责清楚，只在全局定义，除非剧情明确改变配比。 |
| 11. 战斗承诺 | 用户要求的速度、攻击密度、力量、压迫、伤害、击杀和高潮有画面证据。高速有相对位移，重击有接触和受力；死亡有失去行动能力及持续结果，需要血液时才核对来源。范围攻击可成组命中，海量敌人按空间呈现活动和压力；不退化成少量挥空，不向碾压剧情强加失势。 |
| 12. 可选生产 | 只核对已启用的导演参数、声光、慢动作、独立clip继承、素材/音色、容量或项目状态。模板不引入额外字段和审批；单次生成不逐镜重复全局，独立clip不依赖不可见上下文。揭示前线索不泄漏，调色或视角转换不误写成实体变身。 |

## 战斗执行专项（复杂快战或本类反馈，并入一次检查）

按[战斗执行与表现](combat-execution.md)从实际出口接下一招，不以“规则齐全”验收：

- 接触/控制解除、回收、承重与新任务是否相容；对手不停手时窗口仍成立吗？位置、转向与当前目标是否在同一事件中完成，而非由切镜或镜头环绕代替？
- 绕后或主轴改变后的“退/追”是否与当前面向和距离变化相容，是否误沿用开场的地标方向？必要出口是否足以让下一段继承，还是审查者必须脑补重新站位？
- 快战中较长回收、蓄势、近身转换、顶剑与凝视期间，对手还能怎样续攻？正文有真实限制或应对吗？持械者改变武器用途是否有理由，刃尖仍有威胁却默认改拳肘膝踢吗？结束是否继承动态交锋，或仅因镜头要看脸就停止？按[持械与空档推演](weapon-exchange-lab.md)复核实际片段，保留有因近身技和用户指定慢打，不按关键词判合格。
- 干净动作是否保留角色相容的必要转换、持续压力和用户指定作用；近战实击或远程施术/代理协作分别验，是否以少打、重复挡面、全远景或压短时间戳回避实际交锋？
- 视觉速度力量是否独立成立：动作内部加减速、身体领随、接触负载、接重与下一招利用能否读清；是否只在姿势间平缓过渡、长伸腿配光弧？专项见[速度与传力](../../combat-action-design/references/motion-impact.md)，不要求每击倒飞或删掉明确慢镜。
- 能力是否满足指定触发、占用与作用路径，实际改变力量/行动/结果；是否临时补万能机制或方便弱点？未受改变的效果与破坏是否继续？
- 近战/能力战转换是否继承距离、支撑、兵器和效果状态，破防后的追入或击飞后的续攻能否达到当前目标？屏障局部受损是否误写成整体消失，能量巨像接触是否误当施放者已受伤？接触近景与结果远景是否无意重复命中？具体接续按[参考迁移](combat-reference-transfer.md)处理，纯近战/单人展示不强加模式切换。
- 冲击画是否由当前作用点与受力形体设计，短促/延长按最新要求；是否只换底色、减帧或震屏？未知帧率、某次四格示意不得成为固定默认。
- 分身/召唤是否被误当残像，数量、位置、任务与控制归属能否承接；变身是否保留必要身份/持物/支撑，变化期间对手有真实行动窗口或受阻原因，新状态在后镜继续？单人变身不硬加敌人。
- 当前表现是接触爆光、图形重音、释放/变身峰值、技能过程还是持续图形终结？按用途核对入口与退出，不把满白当命中证据，也不因短促默认删掉用户指定的长图形段。细则见[参考迁移与图形重音](combat-reference-transfer.md)。

- 一镜内密集交锋按[窗口与观看交接](one-shot-skill-exchange.md)查实际防法、受威胁部分与攻击体积，反击是否利用当前低位/偏转/回收而非复位后再打；双方同期任务与控制资源相容吗？技能用途/领域展开是否改变实际通路，旧威胁和地形仍在吗？相机读到这些关系，遮挡后归属和相位能接上吗？参考硬切、未知巨物关系或光遮结果不能被包装成全片连续、既定能力或命中成功。固定、单技能、持续压制与有意保持仍合法。

修复后只重查受影响依赖。用户明确长冲击组、既定能力、合法背向攻击或大胆机位仍须保留；本专项不产生第二份审计、通用配额或成片成功承诺。

成片验收区分正常速度播放、抽帧与试听，记录实际完成项。稀疏抽帧不证明中间每步、瞬时速度或精确曝光；连续源帧和时间戳可核对已覆盖窗口的顺序与曝光边界，编码帧数不等于不同画张数，也不替代正常速度观感。未试听不下音画同步结论；文本检查或已写规则不代表成片运动兑现。

## 协同快战与大招专项（仅相关任务，并入上述一次检查）

先检查战斗是否被写出来，再检查是否无矛盾。时间轴齐全、左右手固定和所有路线可达，不能证明交锋充分。针对动作欠缺、单方攻守或大场面空洞，抽取关键段按以下问题倒查；案例见[action-staging-lab.md](action-staging-lab.md)。

- **双方时间**：一人进攻、退到高处、施法或受击时，另一人具体在做什么？无法行动有无原因？“随后反击”是否等到了不可能存在的空档？
- **招式依赖**：后一招沿何种回收、脱开、追步或受力接入？检查攻防接触发生前、中、后，而不只检查段首与段尾。关键动作未写不能由审查者自行脑补为已完成。
- **方位与攻击体积**：闪避是否真正离开刺线/扫弧/范围区域？近身控制是否先进入距离？转向后人物自身左右、武器侧与相机投影是否仍一致？
- **大场面与环境**：技能覆盖、破坏或巨物接近是否改变了目标可达性、支撑或双方选择？是否为避免bug把破坏全移到不影响人物的区域？ 明确要求大场面时，正文是否给出了可见尺度参照、主形跨越/逼近、作用传播及场面展开时间，而非仅在结尾列出废墟？冲击组是否可定位，写出了具体特殊造型画、画张关系和曝光，而非慢放效果动画？入口与出口是否承接同一动作的因果？相关修复见[大场面与冲击导演](../../spectacle-impact-direction/entry-guide.md)，不要把增加粒子、闪光或停格数量当成规模已经成立。
- **张力与主动性**：能指出威胁的逼近过程、应对和代价吗？性感/对视有没有替代战术？防守者有明确目的即可成立，不强制轮流夺权或均分出手。
- **修复收益**：若删去了动作，是否得到用户授权且仍兑现速度与密度？补入的故障、永续护盾或新规则是否只为让预定结局成立？先回改交锋，不叠限制词。

涉及跑动、角色运动差异或巨物时，用[motion-language.md](motion-language.md)再核对实际故障：步态与位移相符，跑/闪/落地接招不缺支撑转换；移除拖尾仍有速度证据；力量有负载而非只有慢镜；不同机型及法术战法在行动选择上可辨，飞剑/御剑不复制同一实体剑。镜头区分视角与景别，巨物有稳定尺度与逼近过程，非露骨身体表演有可见取景和时间窗口。只查相关项，不要求每片翻滚、御剑或巨物。

- 协同是否有可见依赖：谁改变了目标/风险/通路，队友怎样利用，共同结果是什么？只写两人各自攻击不能当作协同验收。关键交接能否同框或通过匹配切镜读懂？
- 多主体是否可承接：人员/动物/机器的相对位置、体量、忙闲肢体/机构、控制归属与当前目标能否解释？暂时出画不判角色消失，但返回需依据；“始终同框、永不换位”不能代替实际空间检查。多视图是否被误当多角色，攻击或机构行程是否撞到队友？
- 人机/场景交互是否闭合：输入/触发、机构响应/场景受力、承接利用与结果是否成立？顺序交接是否被误写成同时，机械忙闲与承重是否冲突？新路、门、支撑、遮挡改变后有无继承，是否凭空制造便利机关？非战斗交互只查适用项。
- 速度与打击是否有证据：去掉高速/猛烈等词后，是否还有加速、距离变化、接触负载、受力方向与回收？是否只剩背景滑动、震屏、闪光或每招同样倒飞？快速切镜不能把碰撞前后都切掉。
- 主峰值是否成立：去掉“大招、巨大、震撼”等词，作用、防御失效或战局变化是否仍明显超过本场普攻？按任务所需核对规模参照、力量传递、敌人可选行动减少及战果持续；不要求所有技能统治全场。
- 容量是否真实：队友接应移动、主命中和结果有无被缩时挤掉？主峰值是否被无关支线或默认补怪收尾削弱？仍有生成负载风险就如实标记，不以时间戳连续判定解决。

维护回归需覆盖实际失败组合及相邻反例：人兽体型差+群战+快速换镜+范围大招；合法越肩、单主体战斗、没有统治结果的大招、固定文戏。区分修改者自写样稿、独立调用与真实成片；机械通过不证明协同、速度和统治力。

协同范围扩展时补多人接力、遥控/自主机器的职责区别、人物利用场景变化，以及非战斗承重交接；不能只用双主体战斗通过情况推断所有协作均有效。

## 导演分镜专项（动作与打斗分镜终检时核；文戏、纯氛围按本场相关项核）

- 拍摄覆盖（方案/返工涉及时）：关键关系、局部证据和反应是否有可剪接材料；设置数、take与成片切镜是否混淆；插入镜是否重复动作或掩盖缺失的转折。非顺拍/不同素材衔接保留刺激、动作相位、持物与表演阶段；纸面预演不能报实拍完成。细则见[导演拍摄实践](director-shooting-practice.md)。
- 观看顺序：人物目标与关系变化由可见/可听证据承载；观众信息与角色知识分开，先前线索、期待与揭示成立，未把镜头列表当故事推进。纯氛围/节律不强套反转；固定调度、长镜交接与跨镜并置也能承担意义。
- 构图：人物占幅、视线空间、遮挡/明暗与重点一致；所用三分线/留白/框架/三角/引导线/巨构都能指出实际位置、空处、顶点、线条终点或尺度参照，删掉术语仍有设计。比较相邻镜的主读对象、占幅、框边、空处归属和前后层，定位无收益重复；同构回返或持续观察有作用时保留，不按变化项数判平。不要求每镜全套；场内调度后核对关键中段。
- 运镜：位置、高度、朝向与取景能读到证据；起幅、决定性中段、落幅的投影/遮挡与注意连续，主路径、相对速度及停留/切点有作用。动机可来自叙述者、空间体验或图形节律，不局限人物动作。固定、重复及大胆运动按观看收益判断，不要求凑种类。
- 光色与整场基线：清晰对象、明暗/色彩重点、反射、剪影和美术允许读到当前证据；来源启发或表现性语法符合媒介与项目，跨镜/光区状态延续。深清晰与分割两清晰区不混同，镜面不凭空显示任意角度。只查实际相关项，不能靠设备/画幅/滤镜名称证明成像。
- 审美与重音：在空间正确之外，实际线条、轮廓、占幅、明暗主次与节奏是否兑现要求？重要转折的摄影是否有胜过平淡默认跟随的可见收益？必要视觉重音落到关系变化，不靠术语或统一高潮配额。细则按需读[电影机位与运镜设计](../../cinematic-camera-design/entry-guide.md)，不再启动第二轮重复审计。
- 拍法：机位距离与焦段视场分开，画幅假定明确；固定/手持质地与跟拍路径分开。dolly zoom 若选用，移动与反向变焦能保持主体占幅，且有可读背景相对变化；摇镜有正确起落对象，甩镜不隐藏关键缺失动作。抓拍感、急变焦、抽帧、停格与慢动作不混名；时间处理后的成片占时与声音相容。只核对实际采用项，详见[拍摄手法](../../cinematic-camera-design/references/shooting-grammar.md)。
- 剪辑与声音：入镜/切出与表演、动作、信息或体验阶段对应，相邻镜头有连续或有意中断依据；匹配/跳切/多线交错的实际时序明确，剪辑变化不冒充实体变化。J/L或主观声有来源、交接时刻与角色可听条件，原句不重读、跨镜占时不重复；用户禁用声轨未被恢复。必要情绪停留不因无新事实被删除。
- 动作覆盖：同一动作的不同角度分别读清速度、发力、姿态、接触或后果，整组镜头动作相位连续，无无意重复起手/受击；不要求每镜全身同框。冲击帧有明确的插入相位和图形表达，允许画内抽象化；入口与出口的作用点、受力方向与结果一致，不以闪白隐藏缺失动作，不机械限定只在最终大招使用。长序列检查画张设计、曝光差异与动作衔接，不能只检查秒数是否变大。
- 指向：角色自身左右与画面左右分清，道具对相机的方向可判定；隐藏信息由取景或切点实现，不能只靠禁止词。未看成片时不声称定位了具体模型故障。
- 转场/效果：叙事性转场检查切换前后的期待与理解变化，多次往返不只重复相似亮物；用户要求的纯图形过渡按其表现目的验收。匹配项具体到动作阶段和接触，变化项与之不冲突；效果有起效、实体变化和最后残留，精准执行依赖没有被文字保证掩盖。

维护时至少按改动涉及的失败组合与一个相邻反例演练：反转+持物+匹配动作；固定一镜到底文戏；主动离开人物的叙事运镜。普通生成不附这份清单。文本演练只验证设计可读与规则适配，不等于视频生成成功。

## 完整人物表演专项（只核对本场涉及项，并入一次终检）

- **表演兑现**：人物意图、接收信息、任务变化与情绪有可见/可听证据；静止与强烈释放均可成立，不规定策略转折或哭喊配额。不受控痛感反应能先于理解，其后的行动才按意图检查。
- **战斗表演**：受击有完整反应链——刺激抵达、身体先反应、判断、继续或改变作战；痛感与是否继续打是同一个取舍，优势或压制时读得到从容与代价。反应发生在当前身体任务、气息与负荷里，手不停下来等表情；画外威胁继续推进。
- **身体与气息**：伤侧、支撑、可用肢体与负重连续；抖动有部位和触发，未让支撑手同时擦脸。台词口型、呼吸、哭泣和动作在同一时间可完成，非词声音未越过用户声音范围。
- **面部与液体**：动态皱纹回到身份基线，旧疤不换边/长出/消失；眼泪、鼻涕和擦拭有来源及残留。跨镜不恢复干净皮肤或全体力，实际表情/纹理在当前景别可读，二维风格不硬塞写实解剖密度。
- **台词与声线**：原词与说话者连续，重音/停连标注不改引号内正文；低声、低沉、气声、耳语和沙哑区分，变化由交流目的或身体状态触发。不能通过“自然、演技炸裂”等词验收，也不能让全句吼叫替代层次。
- **情绪曲线**：整段能指出带入、被打偏、压住、泄出各在哪一拍；转折有具体触发事件，不用“怒火中烧”代替；带入与泄出至少变一项强度、性质或控制度；主峰前有压制段，情绪写在呼吸节拍、握持力度或目光落点上；受击后的落点与下一招的选择对得上。双人以上分别核双方此刻各在哪一拍，交错而非同步。整体压制或整体冷静按本段目的成立，仍要能指出余量变化。
- **情趣互动（本场采用时）**：每次互动三跳齐全，发起方有自身状态，接收方反应落在当前身体任务里，回应落在画面上；张力能指出走的是距离、气息还是注意，且给出具体相位；互动占用的是实际空档，对手同期行动写清；结束后接回距离、重心或视线一项。两次以上时相邻互动过差异门槛；成年、自愿、非露骨、衣物覆盖四项保持。
- **身体魅力（本场采用时）**：勾引能指出向谁发出、要他做什么、何时收；魅惑的机制与对方的实际后果对应，不停在好看；性感落在露与遮、紧与松、动与静、攻与柔的哪一组差上，露肤面积不作证据；曲线能说出是转体、反弓还是侧线带出，光与机位读到轮廓；柔软写出传递顺序与至少两级过程。相邻两次魅力动作至少变两项载体、对象、目的或是否被打断；魅力占用的窗口里对手同期行动可指认。成年、自愿、非露骨、覆盖四项保持。

需定位机制时联用[人物表演导演](../../performance-scene-director/entry-guide.md)的相关参考，不追加重复审计。维护演练覆盖痛中说话与支撑、哭泣湿痕与旧疤跨镜、低声对峙及固定静音等相邻反例；文本通过不等于成片或配音成功。

## 对白与节奏专项（对白冲突、揭示或相关返工时）

- **整句包镜检查**：镜头是否机械地总在句末才换？关键语义变化若落在听者身上，正文是否用同框或有依据的切点呈现必要反应？有意隐藏反应按揭示安排核对。单镜持续表演成立时保留，不设最长秒数。
- **双方表演检查**：谁说、谁听、哪个刺激改变原行为？听者是否只等轮到自己说话才动？关键变化是否被背影、失焦或画外说明藏掉？同一反应是否在对白期间和句后重复演两遍？
- **声画连续检查**：各镜台词片段按时间拼接后逐字保持原文，角色归属准确；切镜不重读、不吞字、不凭空停声，区分同场画外、电话/广播和旁白，不改变角色能获知的信息。
- **模板与声音范围**：用户指定/已采用格式优先；声画分栏稿的各S段有适用fx-env与sound，真实衔接与结尾有transition。简洁正文检查相应声画信息，不强制分栏。黑场声音与叠化重叠不漏计或重复计时，无环境音不误读成仅无音乐。
- **容量与依赖检查**：按[剧情估时](narrative-timing.md)核锁定总长、唯一声轨、必须先后的操作及真正并行区间；不简单求和，不把所有任务写“同时”消除前置，不用倒填时间码遮住超载。
- **空等检查**：句末停顿、推镜落幅、反应镜与转场是否重复加时？静默是否有尚在进行的选择或明确情绪作用？仅写“仍看着、烛火继续、留一秒”不足以证明必要。空房间/空门口收尾、台词后的空停、同一信息第三次、不动的静物按[无信息镜头与空停](storyboard-sequence-design.md#无信息镜头与空停删段不补气氛)判删；觉得慢先删段，不用补气氛或配乐填。
- **覆盖与构图检查**：能指出本镜让观众比前镜多读到哪项关系或表情吗？时间段是否冒充镜头，正反打是否只是同样头像互换，固定机位是否暗藏特写？
- **身体与语气检查**：身体基线、支撑、持物和体力限制是否跨镜继承？说话是否有对象和策略，气息是否与身体相容？语言、原词和音色身份是否保持？不把听者静止自动判呆滞，也不把每次处理都写成停顿；有成片或录音时再核验实际语调、可懂度与音画同步。
- **压力与节奏检查**：诉求、阻力、策略/认识变化是否落实在反应和接话中？不可用快切数量、抖动或满配乐替代紧张，也不可用“克制”消除核心表演。

维护时用失败片段和相邻反例作语义演练：长句含揭示、短句连续争执、冷漠听者、必要沉默、指定固定一镜到底。结构检查不能自动判定演技和节奏成功。

## 特效完成度专项（复杂效果或相关返工时）

粒子/技能展示按[专项规则](particle-spell-design.md)补查实际使用项：主轮廓和方向是否可辨，作用边界与角色响应是否相符；发射源附着与离体运动是否混淆；停止发射后旧粒子的运动、碰撞和寿命是否仍成立；不同角色的技能是否在源点、形状或机制上可辨；释放、拦截、命中、残留镜头有无重播或让对手无故停战。无需每个效果都完整蓄力、爆炸与散尽。

- 形状与释放（仅本场采用时）：主轮廓、内部结构/孔隙与密度组织是否仍可辨；介质、形体细部和成像处理有无无因追加攻击权；平面图样的职责及离面/终态关系是否成立；尺度切换是否丢失源头或传播，战斗有无照搬展示等待？按[特效形状与释放](effect-shape-release.md)复核，抽象展示不强加目标或伤害。
- 机制：来源、触发、主变化及终态成立；实体转化与效果发射相对应，背景显露正确，不是原物体上覆盖贴片。
- 材质与动画：载体符合本场媒介；主运动、局部差异和生命周期有组织，强度不全程一样，不靠光晕隐藏材质。
- 合成：跟踪/透视、前后遮挡、适用的受光与接触关系连续；焦点、模糊、边缘和颗粒与底片相容。非发光物不强加发光，二维不强加写实反射。
- 时序：起效跟随原因，环境威胁可先于角色反应；主峰不抹掉动作/表情，残留完整或在后镜承接；收尾可与剧情并行，不重复计时或为尾巴无因延时。
- 规模与连续：覆盖、尺度参照和空间后果兑现指定强度；相机换位后源点仍在原世界位置，效果阶段、已变化区域和残留不复位。火烟不得退化成平移贴片或无因逐帧重生。
- 执行：分层方案标清必要素材和未完成依赖；未用软件渲染不报AE工程完成，文字自检不报实际去塑料成功。

有成片时看正常速度与关键阶段，静帧不证明跨帧运动。诊断和局部返工见[特效设计与合成](vfx-finishing.md)。

技能对抗与环境交互另查实际发生项：屏幕重叠是否被误当真实接触；偏转、穿透、吸收、抵消是否各有既定规则和可见终态，出射路径是否误伤尚在该路径上的人物；盾面与体积场是否混用；一次命中有没有因切镜重播，持续接触与真实二次碰撞是否区分；中断后已在途载体和脱离粒子是否按机制继续；孔洞、残骸、剩余防御与通路变化是否被下一动作继承。相关细则见[粒子与技能展示](particle-spell-design.md)，不要求每段使用所有交互类型。

## 模板规格编译专项（采用模块化战斗规格或相关返工时）

并入本次检查，只查模板实际承诺：角色气质是否体现为不同进攻/应对，武器多用途是否有部位与转换、占手是否相容；常态/接触/范围/主峰是否按本场要求有可见比较；优势、明确胜负、隐藏结果和动态余波是否各由正文兑现。字段齐全或“未败”标签不能覆盖实际终结，结果隐藏不能在旁白/fx-env提前泄漏。

共享设定、逐段发生过程与出口有无重复或矛盾？未定刀/剑、单/双武器是否仍以备选混在生成正文？资产引用是否真实可用？镜头清单有无落实路径与观看职责？技术标签、禁令和总合成是否代替了可见动作，规格是否错误压过用户采用的格式？按[战斗写法与模板适配](combat-writing-patterns.md)定向修复。简洁文戏、无递进短片及明确峰值开场不强加角色表、四层升级或开放结尾。

## 多项观看体验的兑现（仅系统强化或本类反馈）

按[观看体验转成品](visual-intent-compilation.md)在已请求的关键事件中找实际证据：速度的相对位移、冲击的来力与负载、技能的主形及作用、材料的动态变化、表演的选择、规模与压迫的空间关系，以及峰值后的新状态。没有逻辑矛盾但只剩标签的项目，定位最早缺失的设计并回写；不能因结构检查通过就宣称画面有力度或质感。真实成片与文本审查分别报告，文戏/静止/仪式不套快战与毁城要求。

## 巨型压迫与法相（仅相关场景）

按[巨型压迫与法相显化](../../spectacle-impact-direction/references/giant-pressure-manifestation.md)定位实际画面：巨物局部是否与已知参照构成悬殊关系，是否占据或逼近人物的天空/通路？只裁掉头脚或背后摆巨像是否冒充压迫？近处抵抗与宏观作用能否接上同一事件？本体巨化、附身、外显和投影的作用主体、操控及受损传递是否混淆？不强制恐惧、破坏、慢镜、顶掌或反杀，按锁定能力与剧情判断。

## 成片返工的观察与假设（仅有反馈时）

先区分用户预期、实际可见偏差、最早偏离位置与已成功部分；未拿到片段时只据症状判断，不编造时间戳。检查本次使用的原稿、素材职责、模式与入口，优先排除继承污染和相反约束，再判断身份/动作/摄影/材质或控制条件的具体缺口。

修订围绕最早断点及依赖，说明下一次应出现的可见变化；多个独立硬错误可同轮修复，但多变量同改不能据结果归因某个词或参数。参数/语法被接受只证明提交通过，目标控制是否生效仍需实际画面证据；一次随机成功不直接升为跨项目通则。

同类失败反复且没有新证据时，先定向补看现有输出、参考或实际模式，再修相关问题，不重复堆形容词或盲改全稿。已有证据足够时直接修复；没有成片仍可完成文本改稿，不强制试跑、缩短时长、拆片或等待外部生成。提示词任务继续交一份保留原模板的完整修订，不另交诊断账本。

## 修复顺序

来源模板融合时补查：对抗/单人/变身是否误路由；混合题材是否按角色分别保留动力与能力；场地差异是否真实改变行动；压力变化是否擅改锁定胜负；未到场的素材、强制无配乐/删对白、固定招数/镜数或未核验平台上限是否混入正文。按[战斗写法与模板适配](combat-writing-patterns.md)只取当前所需骨架，普通场景不凑齐全部类型。

先修用户事实与身份，再修状态、接触和路线，然后修投影、轴线与摄影，最后清理措辞。硬错误从最早错误状态回写，并重检其后所有依赖；未受影响部分不重复改写。修复若必须改变用户硬要求，应指出具体冲突并请求取舍。

动作/摄影负载引起的生成风险按下列顺序处理；对白戏的节奏或覆盖不足不走“先减少切镜”的降级，先按上节补齐必要反应和声画衔接：

1. 删除装饰性效果、重复震动和不改变结果的反应；
2. 减少无观看收益的相机改向、切镜和变速，保留能看清命中的主镜，以及承载关键表情和证据的切镜；
3. 把共享路线与结果的攻击整理成动作乐句，不先删除观看承诺；
4. 把相互依赖的并行事件改为有清晰承接的串联，同时保留敌群空间压力；
5. 再考虑延长、删减或经用户授权拆分生成单元。

## 可选工具边界

### 舞蹈幅度、线条与摄影（仅舞蹈相关段）

互动转圈核双方同期行动、联结臂可动范围与出口；穿行换位核身前/后侧通路及两人更新后的屏幕位置，不把永久同侧站位当连续性。后倾/侧倾核接近、承接成立、支撑与进入，需要续舞时查恢复出口；参考未展示的回起保持原创状态。无接触呼应、有作用的主题复现和结尾保持不按不牵手/重复/静止判错，具体源证据见[双人舞学习](../../dance-video-director/references/duet-reference-study-20261012.md)。

双人舞还须查正文的身体乐句与接收关系：步法中肩胸、手臂和表情如何发展，第二个人何时接到并回应；逐关键出口核支撑、手位、同期位置和通路。走位/距离正确不代替身体美感，精简也不能删除必要换握或转动条件；连续握持可延续，不为每句强制复位。摄影核本句展开、变化、回收与对方回应是否可读，特写期间画外舞句继续，回宽不重演；不按新增镜数或技法种类放行。单人相近取景参考不证明双人调度、多景别、音乐关系或画外支撑，依据见[本次学习](../../dance-video-director/references/reference-study-20261012.md)。已有动作成立仅覆盖失效时只修摄影；一镜、静音、单人或有意停拍按当前任务验收。

按[舞蹈转译](dance-transfer-direction.md)检查当前舞句的主驱动、分部位范围、路径/峰值轮廓、速度变化、回收与支撑出口，是否在最终正文兑现用户所要的热舞或魅惑感。逻辑成立和词汇丰富不能证明动作好看；相机应读清采用的相位与身体关系，不以抖动/裁切冒充人体幅度。已锁一镜、静音、服装、速度和用户格式继续有效；特写不重置动作，已有有效编舞只缺覆盖时仅改摄影。擦边参考须是成年博主相关舞蹈，网页、抽帧、局部播放与生成验收分别报告；本轮来源见[舞蹈研究](../../dance-video-director/references/sensual-reference-study-20261008.md)。不把该筛选或舞蹈规则应用于普通战斗/文戏。

`scripts/check_prompt.py` 的语法、模式与完整示例统一见[检查与标准例](validation.md)。基础检查覆盖时间窗、文本卫生与已支持素材标签；融合模式追加全局、镜头、画面、逐段fx-env/sound及镜尾transition检查。显式原对白契约可核对说话人、发声顺序与逐字内容；静音契约只自动确认明确的静音字段，其余需复核。非零续写起点必须显式提供，黑场可由所属S段推导时间，叠化只接受已声明的相邻镜头重叠。模板和契约的检查范围分别报告，不把“RUN”当作通过。空正文属于输入错误；basic模式无正文时间轴的CLI调用要求复核，按入口规则采用简洁正文或用户指定自由叙述时用prose。默认t=仍人工复核；显式`--event-times absolute`只增加所属S范围与行动顺序的数值检查，自然语言动作因果、语气、复杂声音及视频仍不自动验收。存在复核项时状态为`TEXT_REVIEW_REQUIRED`，为兼容旧命令退出码仍为0；调用者同时检查状态与覆盖范围。只有文本自动检查不能证明可交付或成片成功。

复杂空间审计可显式提供二维坐标：平面 x 向东、y 向北；机位 C 看向 T 时，右向量为 `(dy,-dx)`，主体 P 的屏幕横向由 `(P-C)·right` 判断。轴线 A→B 的相机侧由叉积符号判断；符号变化只是换侧提示，还需核对可见过轴、正轴中性镜头或空间重建。坐标只能验证记录的数据，不能冒充对自然语言或成片的自动理解。

对外只报告实际完成的层级与范围：结构检查、局部语义复核、完整适用语义复核、独立生成试跑、真实成片验收。完整语义复核应覆盖当前角色/机制、事件作用、分镜观看、节奏及相关连续性；只查时码/肢体时明确局部范围，被问检查结果时给实际正文证据与遗漏。读取规则、栏目完整、结构通过或局部修复不等于完整语义通过；前四者都不能冒充真实成片已经稳定。


## 精准编译与样本转译（仅相关改动）

去重后主体、目标、方向、作用与出口仍明确；材料/形状用于辨识和受力，不按词性全部删除。作品名后限定借鉴对象，有本场实际行为承载；禁令所指偏离已在正文修复，用户明确禁令仍保留。参考样本中的角色、时长、武器选项和风格禁令不覆盖当前任务，尤其不把禁止抽象冲击画继承到明确要求冲击帧的项目。精准不以字数、术语数量或压缩比例验收；检查器通过也不证明实际生成稳定。


学样本写法的返工，逐句对照实际成稿：有效的形态修饰、介质与运动比喻是否被删成“能量/刀气”，是否仅更换栏目或套作用框架？大招的形成、释放、接触与余波是否在当前时间安排中区分，不能写“急落”却跨多段持续下降。这些只在当前目标下判断，慢镜或仪式按用户意图保留。


## 原创技能与释放画面（仅相关任务）

主峰以牺牲、绝境或唯一解成立时，按[关键结果与代价](ability-system-design.md#关键结果与代价的必要性)检查已设能力是否存在直接更低成本解，解决最早机制冲突及其展示；不结尾临时禁能。观众必须知道的关系、规则和代价有声画建立，不能用全局说明当作已拍到。倒地、恢复、接重和离开按前态相接，不能用末镜新位置省掉必要移动。合法主动选择、无代价胜利及有意省略仍按目的成立。

按[技能创作](ability-effect-authoring.md)核对实际成稿：技能名以外有没有明确使用理由、作用体和接收端变化；角色不同招式是否只是换色/放大/统一格挡；反制来自先建立的规则还是结尾临时加能力；关键主形、介质、运动和受力有没有在当前视点与时间中可读。形成、释放、接触、余波分开安排，静帧只取一个当前状态。无需每招复杂控制或公开技能卡，纯伤害、强化、无法反制与有意留白按当前任务判断。案例文本通过与实际成片效果分别报告。


仙侠施法稿另查：技能写的是角色实际法术、神通/御器，还是反复让角色手持不同颜色的线带做抽、缠、挡？手势、作用体与视觉辅助分开；是否无因新增从手掌到远端的长连接，是否仅凭衣装颜色/丝绸推断操绫。线形雷电、刀痕、阵纹或用户明确采用的丝线法器仍可保留，不能因本次纠偏全面禁用。

从视频迁移的新稿另查：形成期间目标是否继续行动，释放是否仍被写成数秒同姿态保持，局部作用与范围镜是否是同一次事件，源头/目标/余波是否跨镜承接；单人展示有无被硬添实战，轨迹是否无因变成手持武器，图案/巨首有无被误认完整法相或死亡证据。具体观察锚点与迁移方法见[视频蒸馏](video-distillation-method.md)。按本场检查；源片视觉抽帧、正常播放、试听、原创文本与真实生成分别报告，不用学习样本数量证明稳定。

空战追击与尺度任务只检查当前采用项：本段是否改变距离/高度/通路，或提供持续速度、压力、尺度与空间体验；跟拍是否有地标通过、视差或相对占幅变化，反打是否误重置世界方向，近处负载与范围镜是否为同一作用，已有地形是否被误报新破坏，场地跃迁是有意蒙太奇还是遗漏必要通路。具体锚点见[空战追击与尺度](aerial-pursuit-scale.md)；全文源帧覆盖不等于正常速度播放、试听或生成稳定性验收。


## 追逐、张力与切镜的画面证据（仅相关任务）

按[追逐与镜头张力](pursuit-camera-tension.md)核对当前采用项，不给每段套同一指标：

| 问题 | 文本/成片各自要找的证据 | 失败时回改 |
|---|---|---|
| 追逐是否有作用 | 距离/通路/交会机会变化，或持续速度、压力、尺度与空间体验 | 定位无收益重复区间；不按时长或所有移动一律删 |
| 速度是否可见 | 地标通过、视差、占幅改变、距离闭合、通过后远去等本段采用证据 | 先分身体路径与观察路径；只有尾迹/抖动不通过 |
| 危险与出口是否可读 | 威胁进入当前空间，人物有成立的避线/承受/抢入；出口与后果承接 | 有动作但不可见改投影/切点；无动作事实交回动作层 |
| 切镜是否带来收益 | 新视点读到在途/接触/受力/新路线或新的空间体验，并继承进度 | 修最早的相位断点，消除重起手、距离复位和重复命中 |
| 局部与范围是否同源 | 同一次作用扩大范围后仍有地标/层级接住人物状态 | 改观察交接，不以孤立巨物或废墟插播证明压力 |

有实际片先静音正常速度看，再按允许的声音条件检查声画，之后查看关键切点/接触窗口。记录最早偏离时间、证据与提示欠写/动作失效/摄影未执行/素材遮挡/未知的判断；只有文本时写设计缺口，有抽帧时写静帧关系，不混报节奏和稳定性。厚涂等媒介与身份继续验，泛光/闪屏不能遮掉所需接触；固定、一镜到底和纯空间体验是合法反例。连续失败无新证据时改变控制方法或说明限制，不重复堆形容词。


## 技能体系、多样性与展现（仅相关任务）

先按[体系与状态](ability-system-design.md)核对当前实际用的机制，再按[画面与摄影](ability-screen-direction.md)看其证据；不是每场必须多技能、多属性或全套主动被动。

- 去掉招名、颜色和大小，使用理由、触发、控制、时间行为、对象或终态是否仍有本场需要的差别？同一招多用可成立，不用类别数量验多样性。
- 常驻/事件被动是否被无因写成主动施法；主动开启后持续的状态是否每镜重启；代理自主是否被改成施术者同步每次挥手？
- 发动、形成、施放、运行、生效和解除按实际机制相连，瞬发、点生效与常驻没有硬补仪式/弹道；身体、持物、视线和控制任务能否兼容？形成时对手有真实任务/阻隔吗？
- 标记/布置/累积/协同的前置条件是否存在，后招真正读取了它吗？原条件消耗还是保留，附着对象与地点跨镜稳定吗？
- 交互在同一空间和时刻成立，结果来自既定规则；吸收不自动反弹/治疗，局部解除不清掉全部区域，被动不凭需求变成万能反制？
- 小技的接收部位/状态与后续动作有需要时的证据；大场面的网络、环境、区域或巨型作用与人物当前任务相接；信息/恢复/隐匿不只被写成颜色滤镜？
- 镜头起幅、中段与落幅各自读什么，注意交接是否接到触发、在途、生效、状态转变或新路径？运镜不为转完而制造等待，切镜不重新施放同一运行中的技能？
- 当前格式、媒介、声音、强度和胜负保持，丰满形态语言已编进事件正文而非只在技能表；固定/一镜到底、单技能、纯展示、无代价和不可驱散是合法反例。

文本/静帧只审对应设计和采样关系；实际片先正常速度静音看能否分清不同作用与触发，再按声音范围验声画，查关键窗口。最早偏离分别归于机制、身体时机、状态继承、观察未执行、素材遮挡或未知；没有视频不得称“多样性已在成片兑现”。

## 全面增量与近身摆姿的联合检查

检查当前涉及的各功能是否把其增量回填为实际观看证据，而非只增加禁令、栏目或来源名。近战重点核对：上一动作的余势/回收/受力怎样成为后招入口；被打开的防线如何继续受限或恢复；控制点怎样变化；对手是否在相同时间持续施压/应对；切镜是否接剩余相位；动作镜长是否被空白展示撑满。仅衣发/光迹/相机运动不算人物有效行动。

区分合法受压/制动、表演等待、仪式、展示定势、舞蹈停拍和已锁冲击画，不能按“停住”“固定”或静帧姿态关键词自动判错。正常速度看无作用停顿与节奏，再查停顿前后支撑、握持、接触和时间继承；只抽帧不证明持续摆姿或瞬时速度。修最早失效层与依赖，保留成功部分及当前格式；没有片段时报告文本风险，不称已经消除摆姿。

全面维护还核对既有规则、功能/依赖/素材范围和用户锁定未被新资料替代。文本、源文件保留、分发哈希与成片体验分别报告；文件测试不判断身体美感、生成稳定率或声音效果。

## 精彩度参与同次验收的参考学习增量

沿开头的体验优先顺序，先核本场期待、动作美感/速度/负载、技能特点、镜头交接及主峰兑现，再核连续性/格式；有作用的静默、形成和承压保持不按姿态/时长误判。双片全区间采样与密集窗口、正常播放/试听、文本演练和生成验证分别报告。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。

## 剧情攻防的具体缺项与相邻合法情况

在原联合复核中查当前采用项：挡住接触后身体/支撑结果是否相容；持续防御有没有跟来向并占用正确肢体；倒地恢复有无接重和保护位置；近脸是否接刚看见的结果且继承身体；施放归属是否靠源头而非同框；实体芯/扩展面与材料相位、目标结果及残留是否跨镜保持。形成读取、角力保持、获准慢镜和未揭结果可以合法，不能因停留判pose，也不能以白闪补未示胜负。只修具体缺项及依赖，不给所有稿强塞完整链。设计自审和结构/ZIP验证不证明真实成片，按需取[执行方法](narrative-combat-transfer.md)。

## 最新修仙与信息分镜的语义检查

并入适用复核：去掉招名/发光，角色战法是否仍符合定位；危险察觉/识破有何证据；脸/手/术法/目标镜增加什么观看收益；画外同次作用是否继续，返回是否重放；负载比较是否改变下一行动；怪群/主形/首触/范围结果和适用正向约束是否可见。按[导演推敲](director-deliberation.md)定向修最早缺口，固定/一镜到底、纯近战、单技能与合法保持仍可成立；文件通过不是成片验证。

## 动作用途、翻腾与方向的联合核对（实际出现即检查）

最终正文出现新增翻滚、翻腾、旋身、绕行或折返就核用途和完整身体过程。原创可从一开始共同设计相容压力、地形与反制，让用户要求的身体美感成为设计目标；锁定场景不事后造威胁替花招找理由。比较延续当前行动与所选动势的观看和战术收益，不能用最短路径原则删掉全部大动作，也不能只因“能做/有落点”便通过。

再查实际身体轴/路径、来刃解决方式、兵器/控制任务、对手同刻位置与面向、追截出口、落点与接重后续；只有名称、衣摆/残影或相机转动不算已写身体动作。逐处核世界/身体/屏幕方向，绕后、缩距、转身及切后返回须由前段路线与同期双方状态推出；不靠镜头反打、B旧位置或脑补起立通过。用途成立而空间条件缺失时补获准条件，关键相位被裁切则修覆盖，不自动缩成小步。

这些核对并入同次交付自审，涵盖全稿的相关变化而非只抽一招；修改动作/路线/时间后复查受影响距离、射线、支撑、动态轴与后续事件。只查时码、左右手或ZIP时不得声称已完成动作与空间语义检查；用户未提供实际样本时，也不能将其概述虚报为逐镜原稿诊断。

脸/手刃局部后的画外任务继续、切回已到相位；滚出前是否脱刃，翻后是否真实接地，旋身是否有收势，手持是否读到交会。固定静音、慢镜、单剑、无剑术者、单能力、局部返工和一镜约束仍成立。相关文字练习见[执行记录](director-learning-execution-20261012.md)；不把作者复核/几何/文件通过改称独立模型或成片质量通过。
