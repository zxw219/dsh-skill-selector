# 两套文档提示词的逐段用途学习｜2026-10-08

对象为用户提供的“提示词.txt”全文：骨伞女子对白衣剑客，以及黑风剑客压制冷白刀客。本文分析文字架构与句子用途，不还原隐藏提示词，不声称该文本对应此前某条参考视频或生成效果已经验证。下面把原文表达提炼为作者的控制意图；补足项是本工作流的写作选择。可迁移方法见[精准成稿](reference-prompt-writing.md)。

## 第一套：稳定资产到神祇主作用

| 原文部位/短句 | 在控制什么 | 写入当前成稿的方法 |
|---|---|---|
| 资产引用、面容/发型/服装结构 | 身份与可变状态的边界 | 全局绑定实际素材；事件造成的姿态、伤损另写，不把参考姿势锁死全片 |
| “全片只有一把骨伞”“一把实体长剑” | 实体数量和所有权 | 明确持握与存放；换手要有接稳，残像/刀光不算额外实体 |
| 伞面、伞骨、伞心、长柄 | 不同有效部位的职责 | 伞面承接/遮挡，伞心聚能，伞柄调整朝向；事件明确用哪个部位 |
| “鬼神属于…召出的法相” | 归属、人物计数与作用体 | 建立发动者、来源、控制与连接；神躯不是第三名独立人类 |
| 湿石、残柱、浅水、雾气、阴天 | 材料、地标与可见响应 | 借力/让线/落地引用实际地标，水与碎石显示足地/接触，雾显示气流 |
| UE5.4、Path Tracing、Lumen、Nanite、PBR | 技术审美与几何/受光意图 | 保留用户选择，并配具体体积、材质和光照，不当作已启用引擎的证据 |
| 8K、HDR、ACES、5219、次表面、体积光、景深 | 细节、明暗、色彩、皮肤与空间观感 | 基线写一次；近镜兑现纤维与柔透皮肤，大景兑现空气深度，接触不被虚焦遮住 |
| 冷灰环境、幽绿与金白力量 | 环境和角色分离、力量辨识 | 三套颜色各有职责，能量在受光对象上体现，不长期全场同色 |
| 幽绿照亮积水/边缘/残柱/雾 | 效果和世界的融合 | 把源位置、遮挡与随动受光写入同次fx-env，照明随施放衰减 |
| 侧风吹动长发、披帛、饰物 | 背景基线与身体次级运动 | 所有随动物共享风因，急停/换向/冲击后有相容滞后与回弹 |
| 石块“飞出→下坠→弹跳→滚动” | 有起点、来力、碰撞与退场 | 在环境命中后继承落点，下一镜碎块不重生、不悬空冻结 |
| 积水涟漪、水花、外推 | 不同来力的不同响应 | 脚步局部，碰撞放射，气浪范围推移；不每击复制同一水花 |
| 前半近战、后半空间/神祇压迫 | 整体强弱和观看规模 | 本例按阶段升级，主峰留对比；其他战局不强制相同顺序 |
| 骨伞轻巧克制、剑客主动追击 | 攻守倾向与武器使用 | 防守改变剑路和位置，剑客追进新位置；不是两个气质形容词 |
| 高处登场、观察后直接入战 | 入口空间、决策与节奏 | 建立高低、目标与可达路线，最后一次落脚成为出招支撑 |
| 俯冲、主动迎击、伞改变剑路 | 同时趋近与有效接触 | 写交会位置/攻向，伞倾斜承接来刃，接重与偏转创造下一攻防 |
| 短碰撞后换位/变线/续攻 | 快战接触后的出口 | 接触约束怎样解除，谁追回谁，下一招读新方向，不双方复位 |
| 防守空隙接近身反击 | 战术转换与主动权 | 空隙来自已发生的偏转/遮挡，先入距并处理剑锋再反击 |
| 受力退出、惯性、衣物延迟、积水 | 击打重量与接收端 | 接触之后才受力；后脚抢接、衣摆拖后、水沿退向飞散，接新距离 |
| 拉开、伞转天空、伞心聚能、升起 | 近战到施法的距离与本体任务 | 原接触先解除；转伞、供能、托身按已设机制，对手在空档仍追攻 |
| 云旋转扩大、深色中心、亮度降低 | 局部能量到环境异动 | 在同一天空建立范围变化；云雾运动与照明变化分开，不突然换场景 |
| 裂界深处手臂/面甲逐步显露 | 出现方向、空间纵深、形体稳定 | 按局部到可辨神躯出现，手臂连接、体量参照持续，不完整跳出 |
| 前景巨手、中景建筑、远处人物 | 尺度与空间支配 | 看同一实体与已知参照，近部占幅同时保留人物任务和出口 |
| 剑客抬剑、掌来向提前建立 | 主动应对、方向与目标区域 | 先读威胁与可走路线，凝光/撤步/支撑并行，不静止等攻击 |
| 下降风压先影响水/碎屑 | 逼近前兆与作用顺序 | 压力有方向和范围，主体仍下降；不提前出现完整主爆炸 |
| 接触后砖裂、水外推、碎石尘波 | 主作用、传力与传播结果 | 接触点产生负载，变化向参照传播，人物/防御承受同次结果 |
| 尘雾遮住最终身体状态 | 信息控制与开放结尾 | 不擅补死亡/补刀；破损场地、法相轮廓与持续余波保留 |
| 四级特效、普通近战克制 | 作用层级和主次 | 每级有不同形体、规模及负载，主峰强不等于全部同级亮团 |
| CU/MCU/MS/FS、LOW/TRACK/PUSH/PULL/WHIP/TOP | 摄影选择的用途 | 用本次交点、位移、俯视通路与尺度具体选型，术语不是自动生成的多镜方案 |
| 前段物理声、中段汇聚声、后段空间/巨掌声 | 声源随事件升级 | sound：继承相位和余响；无对白/无喊招只约束本例，不强加其他项目 |
| 身份/数量/画风/结构/先后/结局禁令 | 本例容易偏离的边界 | 将适用限制转成正向动作与成形链，不原样继承全部禁令到新角色 |
| 总合成复述全片 | 汇拢共享决定与整场顺序 | 用于核整场；已有完整分栏稿不再重复整片，防止双版本互斥 |

第一套精准在资产数量、材质对象、动态顺序、效果层级与结果边界。它给近战关系和召唤过程，但未给每次具体兵器路径/支撑、每个真实切点与动作秒数。当前编写须补本次依赖事实，不据此声称原文逐关节或逐镜已全部确定。

## 第二套：主动压迫、反扑与高速摄影

| 原文部分/阶段 | 实际用途 | 精准迁移与应补事实 |
|---|---|---|
| 30秒、16:9、24fps及CG材质 | 时长/画幅/成像基线 | 作为该例规格，按当前任务继承或换定；数字不证明实际编码与执行 |
| 侧后、贴地、掠刀、穿梭与环绕 | 观看参与、视差与动态构图 | 当前相机起点、通路、触发、落幅必须明确，不能只有“始终高速盘旋” |
| A野性追压、B精准反切 | 不同战法与主动权 | A如何追回新距离，B在何处改变刀线；不是给A更长光尾就判上风 |
| 黑墨风/裂帛刀幕对冷白薄弧 | 颜色之外的轮廓/运动区别 | 保留厚薄、材质观感、流向与随刃形成；“空间裂缝感”不自动授予传送或裂界能力 |
| “双手持刀/主刀副刀皆可” | 作者留下的武器选项 | 当前成稿选定单刀双手或双刀，建立忙闲手与数量，不能镜内随机混用 |
| 强攻、重要刀气、对拼反馈、破坏 | 联动动作与效果 | 刀路触发锋面，碰撞交负载，落点交环境；不用一套火花/爆炸覆盖所有动作 |
| 0–3.5：已有交击→压刀→抽刀回斩→沉身格开 | 快速入口和第一轮压迫 | 首帧继承须有真实素材；抽离解除交点后才能回斩，目标侧腰与躲避扫弧清楚 |
| 3.5–7：连续高低/直弧强攻与精准防法 | 招式变化、对抗密度与角色完成度 | 将重要追斩与当前防法成对连写，不能A五招/B五防单独列菜单 |
| 7–11：低空爆冲连段→B月牙反击→硬接 | 第一波强化与反扑窗口 | 地标/尘痕显示推进，腾空落点和回收成立；白薄弧有源点、目标、贴地路线和接收结果 |
| 11–15：踩墙俯冲→B穿入反斩→落地拔刀追压 | 高低互换、过身、借力与摄影穿越 | 墙已存在且可借力；B让出下降刀的整个作用体积，再到有效反斩距离；相机穿的是可用空隙 |
| 15–19：B挑开反扑→A近身夺回节奏→逼退破栏 | 用反扑证明B强，再兑现被压制 | 刀线受限才有身体接触机会；失势表现为距离、接重与路线变化，不无接触先飞 |
| 19–23：不停顿追压、黑风强化、B边退边挡 | 保持压力并累积高潮条件 | 出刀与回收连续，B剩余空间持续缩小；旧尾迹衰减，光膜不每镜重置身体架势 |
| 23–26.5：三次交错重击与主峰 | 累积与爆发、交会重音 | 三次分别给攻向、拦截和出口，回身继承真实落脚；强光后恢复同次受力，不用闪帧替代三次交会 |
| 26.5–30：终斩、极限接挡、拖退、仍能抬刀 | A占优、B未败、悬念边界 | 限定终斩有效形体和抗压面，接触传力到支撑；抬刀是仍有行动能力的结果，不擅加击杀 |
| 尾镜低空绕后拉远、尘浪/旗幡持续 | 从局部对抗转到整体余势 | 拉远接当前双方距离、方向、破损与压力，停势在本例有结果任务，不默认所有快战长对视 |
| 全局约束/负面词 | 风格、数量、场景与结果锁定 | 优先补具体编排；不照搬作品名、全圈环绕、无慢镜或非当前媒介的禁止项 |

第二套精准在战局波形、角色差别、动作与刀气绑定、环境破坏和有方向的摄影偏好；部分句仍是招式菜单、抽象赞美或任选武器。学习时保留有效视觉词和清楚的压力关系，补实际使用的对象、相位、路径、落点和约束，不靠增加同义形容词解决。

## 代表性句子的写作用途

| 原句 | 用途分析 | 当前写法应如何接下去 |
|---|---|---|
| “倾斜伞面改变剑路” | 器物操作、有效接收面与反制 | 指出倾向哪侧、承接哪段剑锋、被导向的空间，以及谁利用改变后的线路 |
| “剑刃和骨伞接触只保持极短时间” | 相位占时、快战避免顶推 | 写滑脱/抽离、换步、下一招，不只保留一个禁止互推句 |
| “受到冲击后向外退出” | 接收端与新距离 | 给来力方向、承重/接重和退向地标；进攻者仍能追或转远程 |
| “伞面…转向天空…向伞心集中” | 主体操作、目标方位与聚能 | 同一伞、同一持握和成形位置，身体/气流与对手任务并行 |
| “巨大…手臂与面甲…从裂界深处显现” | 局部形体、出现源与纵深 | 摄影让远处裂口、近部手臂、地面参照同属空间，未见部分不乱补结构 |
| “极薄…月牙斩…贴地掠出” | 主轮廓、厚度、速度和高度 | 写从当前刃锋离体到对手区域，后者如何拦截/让线，余势到哪 |
| “地面炸起…长痕” | 推进路径的环境证据 | 尘痕沿已经经过的路径发展，人物确实跨地标而非原地快摆腿 |
| “从两人中间穿过去，再回头反拍” | 相机路径、观察侧变化与注意交接 | 先建立双方路径和净空，反拍承接同一次动作，地标帮助重建方向 |
| “几乎单膝跪地…最终还是稳住” | 受力程度与结果边界 | 给持续支撑和重新接重，避免无因倒地又恢复；下一姿态继承损耗 |

## 与三栏的对应

- 身份、实体数、场地、战法、材质/物理和技能规则进共享设定；阶段/镜头给当前观看任务。
- 动作、对手响应、施法控制、角色位置与接重变化进画面/S；攻击正在进行的事实必须成立。
- fx-env：细化同次锋面/法相、作用路径、接收材料、照明、风压、水与碎块、残留。不另起一次发射。
- sound：对接物理声、聚能声、空间/巨物声与允许对白，前后声源同一事件。
- transition：接真实切换、动势/来向/作用相位，结尾接当前结果；不每招造转场。
