# 动作编排

## 角色适配与施法协同优先

先按[角色战法与施法协同](character-led-spell-combat.md)确定类型、主战距离与控制任务，再用本页方法。法师、召唤与领域术者不因要求高速/美感而套近战乐句或新增盾剑/晶甲；施法动作、人物与法术/代理的并行及释放后任务进入实际正文。领域要改条件，召唤要执行任务，指定大型主形要有作用与结果，不能只在共享技能表出现；近战/混合角色仍保留其相容招式。

动作先在世界空间中成立，再交给摄影机。技术名、速度词和冲击效果只辅助识别，不能代替路径、接触和结果。

## 先兑现战斗承诺

先判断用户要看的核心体验：技术对招、压倒性割草、险胜、生存压迫、残酷击杀、能力爆发或环境奇观。把速度、攻击密度、力量尺度、受伤/血液尺度、敌群压迫、胜负和高潮方式锁成观看承诺。用户明确要求高速重击、连续击杀和血液时，不能为了简化生成把战斗改成缓慢走位、两次挥剑、攻击落空或只靠塌方解决兽潮。

“一个节点一个主要状态结果”不等于“一个节点只能有一招”。共享运动路线和战术目的的连续攻防可以组成一个动作乐句，例如斩开前敌后借回收弧反斩侧敌，或在对方封挡过程中连续变线迫使其换步；每次关键接触仍需可见，不能把互不相关的多招压成动词清单。具体密度服从用户成功样本和目标模型能力，不设统一招数或伪造的每秒上限。

复杂快战或“动作不干净、位置转向bug、技能无意义”的反馈，按[战斗执行与表现](combat-execution.md)在关键接触/换位出口实际尝试下一动作，不能只重述本页原则。肢体回收、接触解除与施法条件以当时状态判断；保留密度与身体实击，不用全远景、固定方位或少打回避问题。

## 动作选择与美感先进入编排

手脚并用是本轮明确要求或当前混合战法缺口时，先按[手脚协同与能力多样性](full-body-ability-integration.md)采用上肢与腿脚互相创造窗口的动作乐句。腿脚须真的攻击、截腿、封步或参与控制，不以冲刺、踏地与起跳次数代替；膝/腿命中、收回/落步、对手响应与后招承接写入实际S段。持械或持续施法的手保留原任务，别先把角色设为纯掌式法师再仅在末尾添加一脚。

原创需要招式变化，或反馈动作模组少、正文只用几个动作时，先按[可接续模块](../../combat-action-design/references/action-module-bank.md)选择角色相容的具体结构，让身体/兵器/控制方式的差异在编事件阶段发生；不先写熟悉斩刺挡退再加名称。随后按[身体美感](../../combat-action-design/references/action-phrasing-and-aesthetics.md)设计：进入/高低、直弧/幅度、防法、释放与收势。选动作时就编出身体开合、领随、轻重及相容的近远战转换，不能只在逻辑审计之后换动词。合理大弧、转身、腾跃与混合近身补支撑、净空、窗口和对手应对；连续性不等于只准短直线。完整原创例见[动作成稿练习](action-diversity-lab.md)。每个乐句的差异必须写进当前正文，简洁不删除有效身体过程；不强制每场拳腿、每秒招数或多种技能。

## 动作脊柱

先区分对抗、单人演绎与形态变化，再选择符合既定胜负的战术压力变化；混合题材按角色分别绑定动力、武器用途和能力规则，不把全场套成同一拳路。需要模板时读[战斗写法与模板适配](combat-writing-patterns.md)：提供可替换的交锋句法、场地分区、关键/群体对手调度与斗法连锁；不是固定秒数、镜数或招式配额。

在正文内组织动作因果，不另生成无运镜草稿。每个必须读懂的动作单元使用：

`入口状态 → 发力/来力与可达路径 → 接触或落空 → 双方即时反作用 → 持物、位置或主动权的新状态`

下一单元必须继承上一单元的忙闲肢体、支撑、距离、动势和武器相位。准备动作可以发生在跑动、转身或上一击回收中；除非剧情要求对峙或停势，不让双方每招后复位等待。

攻击与防守是同一事件的两面：一方进入距离时，另一方同步让线、封挡、卸力、受击或逃离。反击只能发生在距离、肢体和回收窗口允许时；不可达就改成追压、封路或撤离。文字先后不等于动作先后，明确关键重叠发生在对方的起手、出招、接触还是回收阶段。

模板中的武器用途与角色气质须落入具体交锋：选当前有效部位、握持/占手、目标与进入方法，再接对手应对。武器从遮挡转偏转、从格挡转追击或从近战转传导时，转换期间也有动作和威胁；不把“善于转伞/善于变线”当成已写出反击。优势与未败、明确终结及隐藏结果按[战斗写法](combat-writing-patterns.md)分别兑现，不用效果强度推导胜负。

## 从单方列招改为双方交锋

先确定双方当前要争取的具体结果，如夺回中线、越过门槛、逼离支撑面、打断施法或保住同伴；“击败对方”不足以决定这一轮怎么打。在稿内并看双方时间，不额外强制向用户交表：

`双方入口与目的 → A发起时B正在做什么 → B应对改变了什么 → A怎样续压或被迫改招 → 新距离/角度/资源决定下一轮`

- 躲避须避开明确的攻击体积，并产生位置或出手机会；追击者要续步改线、封住落点或承担挥空回收。不能每次躲开后双方复位，再从相同距离重打一遍。
- 主动防守可顶住一段推进、诱导攻击、抢内线或拖延目标；不强制每招反击，也不把一方连续受压误判为必然回合制。问题是未受限制的一方无故停止行动，而非招数不对称。
- 连招的承接点写清：被挡住的是刀尖、刀身还是手臂；旧接触保持、滑开还是已经分离；空着的手和支撑脚能否承担下一动作。不能在兵器仍被压住时直接完成反向大幅挥斩。
- 反击出现时保留原攻击者的应对。可追腕、回护、转身逃线或受击失衡，不能自动冻结成被操作的道具。击退、受伤或主动诱敌可以终止其行动，但须有可见原因。
- 后撤蓄力、抬升武器、登台、展示或长距离重组时，另一方仍在追压、封路、处理余波或争取自己的目标；撤离者依靠速度差、遮挡、压制或牺牲距离创造窗口。没有依据的双方空等先修调度。

逐个动作不能互不相干地增加。用户要密集高速战斗时，增加可承接的变线、拆解、追击、受击恢复和二次利用，让进攻方式因上一次结果改变；不以手脚动词数量、每秒招数或加快播放代替交锋密度。具体演练见[action-staging-lab.md](action-staging-lab.md)。

## 动态方位、距离与接触

世界方位负责地标，人物自身左右负责肢体，画面左右负责摄影，三者分开。仅在关键换位、碰撞、跃迁或交接时，稿内核对双方位置、胸口朝向、运动方向、有效距离和忙闲肢体；普通正文用最少而唯一的描述，不逐招塞坐标。

### 让每次攻击找到此刻的目标

给当前交锋保留最小状态：双方相对哪个地标、躯干朝哪一侧、相隔何种攻击距离、正在做什么、哪些肢体/兵器仍受约束。出招依据当前状态，不从开场站位推导整段；对手移动期间，攻击瞄准其预计接触位置或明确的封路区，不能追着已经空掉的旧位置却写成命中。

在关键变线、转身、绕后与跨镜攻击处，依次核对以下关系，检查结果直接落实到原有画面与S段，不另交坐标表或增加固定栏目：

1. **为什么出招**：继承上一结果产生的机会或威胁，例如格挡后空出的防线、对手的回收窗口、必须封住的通路。开场主动试探可由目标驱动，不必先挨打；佯攻、压制与有意挥空写明要诱导/限制的反应，不能把所有未命中判成无意义。
2. **到底打谁**：明确攻击者、对象、作用部位或区域；连续多人动作中用名字/代号解除“她、其、对方”的歧义。目标出画时仍承接其行动和位置，不因镜头跟一人就默认另一人移到背后。
3. **怎样抵达**：区分手臂向后预备与攻击端向前打出、身体转向与兵器回收、角色后退与武器前送。直线攻击的有效行程必须到达目标或封路区；弧线攻击看完整扫掠路径是否经过该区，不能只比较起点和终点。位移、转体、解缠、接重发生在需要它们的出招之前或可成立的重叠阶段。
4. **接触时是否还成立**：同步代入对手的闪避、追击和格挡。距离不够先追入或改为合法远程作用；已经让开的目标不能原地受击。受控手、缠住的脚、未收回的兵器不自动恢复自由。
5. **下一镜接什么**：记录接触后的实际位置、朝向、距离、动势及剩余约束。换到反面机位只改变屏幕投影；若相对前后发生变化，必须由人物路线或转向造成，并在正文出现。

**方向表述**：优先写“右拳从肩侧送向仍在面前的乙左肩”“甲转向钢柱，面向从柱侧追来的乙，再出掌”；局部明确即可，不逐句同时堆东南西北与画面左右。“反手”只描述用手方式，不能单独决定攻击方向。相机后拉不表示角色后撤，敌人在画面后景也不表示位于角色身后。为读脸而换正面机位，不得令角色为看镜头转离敌人。

**两次针对性复核**：先在稿内忽略摄影词，只推演人物与攻击能否相交、每招有无目的；再放回摄影，确认画面容纳目标、攻击线或已经建立的画外关系。重点查变化节点，不为每个细节重启全流程。出现“身前目标／向后出击／前方命中”而中间没有回转路径时，回改最早出错的动作；不靠新增禁令、重命名左右或一句“始终朝向敌人”结案。允许已建立的背向攻击、回旋路径与回返兵器，但必须写出其目标、感知依据、路径和对手应对。

- 面对面时，甲的右侧常对应乙的左侧；转身后重新判断。“向外侧闪”须说明是避开哪条攻击线、进入谁的哪一侧，必要时补一个地标方向。
- “侧步”不是免伤指令：刺击沿线、横扫覆盖弧面、下劈覆盖纵向平面、范围技占据区域。写出身体何时越出该范围，若靠格挡改变轨迹则交代接触与偏转，不能让招式穿体。
- 长刃的有效距离与人物距离不同。远端先命中时，近身者尚未到位；缩刃、追入和控腕需要各自可见过程。前后扫掠空间、拔回路径与变向弧不能穿地、穿墙或穿自己身体。
- 接触解除后不能继续借力；先脱开被控肢体再执行新任务。抓、压、推、拉分别产生不同约束，不用“控制住”省略握点、来力和对方尚能活动的部分。
- 退步、受击滑行、转体和落地都会改变下一招距离。切镜承接位移后的真实关系；守住目标可以改变站位，不锁死整片甲左乙右。

动力学只保留决定结果的证据。为动画或幻想设定编动作，不把未经核验的关节操控写成可靠实战教学；反常能力可以成立，但不能在同一交锋临时改规则。

## 多主体协同与场景交互

按需要采用“发起者/输入 → 被改变的人、设备或场景状态 → 承接者利用窗口 → 共同结果”。参与者可以混合多人、动物与机器；场景是可利用、触发或改变的条件，不默认是有意志的队友。也适用于搬运、救援、驾驶配合和机关操作，不强加敌人、战斗或大招。正文只写当前依赖，不另交全员矩阵。

用户要求协同时，在关键战术节拍落实“谁创造条件 → 队友利用什么窗口 → 共同改变什么结果”。破甲后追击同一裂口、拦截侧敌保护施法、压制出口供队友突破、将敌阵逼入攻击区域均可；不固定先后角色，不把每次配合都写成同目标补刀。检验移除一人的贡献后，另一人的机会、风险或效果是否改变；只是各打各的，不足以承担协同主峰。

交接时明确目标的受力方向、位置、姿态和窗口：被击飞很远的敌人不能原地接招，飞行途中转移控制需队友实际赶到。兽类按四足支撑、扑落与咬合发力，接力沿已有动势；人类的跟进速度与巨兽步幅有差异，用短程冲刺、错位掩护或已建立的移动能力承接，不靠“并肩”让双方无条件等速。友方与法术/甩掷路线分开，避让必须有时间和通路。

关键配合用同框或清楚的动作匹配切镜交付，按需承接当前发起者、响应对象、承接者和接触关系。短暂出画允许，但下一镜回到其真实新位置或状态。围绕少量可辨认的交互对象兑现协同，其余人员/敌群保持相关任务与空间压力；不为每个背景对象新开一套精密动作。

### 多人分工与接力

分工由共同目标决定：牵制、破防、接应、掩护、转移、操控等按任务选，不固定角色职业。三人以上也可同时协作，但需读清当前依赖：一人架住障碍，第二人送入支撑，第三人通过；支撑接重后首人才可放手。战斗中可让一人牵制前敌、另一人截断支援、第三人突破，不要求所有人攻击同一目标。

动作能并行须有可用肢体、空间和各自信息依据；顺序依赖不能因“同时”而跳过。指令、视线、可见结果或已建立默契可触发接力，不强加口令，但新信息不能被全员无因同步得知。突出当前交接者，不按人物名单轮流给表演镜头；未承担主拍的成员仍维持已建立的任务和位置，伤亡/离场不得重置。

### 人机操控与执行

先按设定区分驾驶/遥控、预设自动运行和自主机器；同一动作的操作者与控制归属清楚，不能从手动无因变成自主。操控输入或触发信号 → 机构启动/运动 → 接触承载/作用 → 可见反馈与下一状态，反应与行程按实际设定留时间，不虚构固定延迟。

机械臂抓取要先闭合受力再搬运，吊索先绷紧再接重，载具加减速和转向影响乘员与接应位置。炮塔/机械臂运动范围、射线、载荷、支撑和队友位置不能互相冲突；设备正在承重、回收、锁定或重载时，除非结构支持，不同时执行互斥任务。人物借设备运动接力须在可达窗口内完成，控制失效与接管需有依据。设备缺少的功能不靠一个指令临时获得。

### 人与场景交互

先建立可交互对象及与当前动作有关的性质：墙面的支撑、门的开合、绳索张力、平台运动、地面的摩擦或已损坏结构。人物施力/触发 → 场景受力或机构改变 → 人物/队友利用新条件 → 状态持续；借墙转向、踏台跃起、开门放行、切断支撑制造阻隔均按这条关系兑现。变化可以由既定天气/机械周期触发，接应者仍需感知并赶上窗口。

区分环境装饰与有功能的交互：花瓣飞起只说明气流，路面塌陷迫使敌人转向才改变战术。地形不是自动帮主角取胜的便利事件；承重、破坏阈值按已建立材质/能力解释，不凭空增设机关或坍塌。通路、遮挡、支撑与落脚点变化后，重新承接人和机器的可达路线；被毁桥板、已开门、掉落物或移动平台不能切镜复原。

修空间错误时仍保留环境压力：可通行不等于无压力的永久安全走廊。若所有破坏都被移到双方用不到的远处，大场面只剩背景装修。让既有破坏实际改变某一方的进攻角度、支撑、目标可达性或时间窗口，对手尝试利用该变化；不强制每场坍塌，也不凭空增加灾害。

## 速度与力量的可见证据

先选运动方式再描述速度。快步、奔跑、冲刺、侧移、翻滚、滑行与飞行各有支撑或动力依据；跑动接攻击、闪避接反击必须保留使后者成立的换步、接重、脱离与变向。针对“大步走冒充跑、角色滑动、机械/修仙同招”，设计和检查用[motion-language.md](motion-language.md)，不只追加高速词、步幅或光尾。该模块也区分灵活型/重装机甲、飞剑/御剑与镜头尺度，不按角色标签固定快慢。

速度写成变化而不是形容词：运动中预备 → 蹬地/转髋产生加速度 → 背景和敌群相对位移迅速扩大 → 接触短暂清晰 → 过冲、滑退、回收或立刻衔接下一击。高速角色不能只有运动模糊和残影；至少保留落脚、剑路和接触窗。

力量由身体和环境共同证明：支撑落地、铠甲/躯干传力、武器进入目标、目标受力方向、攻击者过冲、地面划痕、碎石、甲壳破裂或附近物体震动。重武器不能像无重量光棒；挥空也要有惯性和回收代价。攻击写了“命中”却没有目标受力、伤口或位置变化，视为没有完成命中。

身体高速、攻击间隔紧凑和频繁切镜分别设计。跟拍让主体接近静止时，用接近敌人的距离变化、足下跨步、越过固定地标和碰撞速度证明前进；花海横移或残影单独不足以证明高速。准备与回收可并入奔跑、转身或下一招，保留关键发力，不让完整起手在每招间重复。

接触应有负载：狼肩先压入目标、扑击先压弯支撑、法术先抵住护甲再击穿，表现按速度与材质适配，不强制慢放或每击停帧。普通打击可偏转、破防、失衡，重击再增加压溃、惯性拖拽或阵列碰撞；不要所有命中都同样倒飞。冲击帧、短震与音效落在真实接触点，只强化已有力量证据。

## 击杀、血液与残留

前景关键击杀给出命中、符合媒介与伤害尺度的破坏、失去行动能力及后续残留。用户要求血液时，加入从伤口按受力方向喷溅及落地痕迹；仅要求死亡不自动加血。血液是伤害层，不默认占用能量、水墨或流体配比；用户要求风格化替代或明确消散时按其方式留下可读结果。

不必特写逐只展示海量敌人的死亡。前景关键目标给清楚命中和死亡，中景用同一剑弧或能力路径造成一组倒伏，背景用缺口、残骸或既定能力留下的痕迹表现战果。不能无原因清空尸体，也不能只写飞溅而看不到命中。

## 敌群压迫与紧张升级

### 双人交锋的压力与情绪

先确定观众此刻担心的具体结果，如护臂即将失守、落脚位被追击占住、退出通道只剩最后一步；在结果发生前让危险可见。未知剧情可原创这种约束，已有剧情不得擅自增加限时炸弹、伤情或反败为胜。用户锁定碾压时，压力由被压制方的持续失败与强者推进承担，不强迫强者先吃亏。

把数次攻防编成一个改变局面的乐句：首攻迫使对手选择防线，续击利用刚产生的空处/受力，第三个变化兑现代价或夺回主动。这里是因果关系示意，不要求固定三招或每镜一招。防守有成绩也有付出，例如挡住拳却被迫退到栏边；进攻者在其换脚时追压，防守者必须换方法而不是再次轻松回到中心。留给观众读威胁的时间可发生在持续受压中，不等于停战等镜头。

“激情”给双方各自的投入方式：一方受挫后呼吸骤短、目光从对手眼睛转向暴露防线，撤掉试探直接追入；另一方被逼退时咬紧下颌、护臂颤动，却用落脚后的第一次发力夺回中线。情绪改变节奏与选择，后果继续影响攻防；不只在近景写“愤怒眼神”，也不把喊叫、胡乱挥拳或每次命中都惨叫当投入。角色仍遵守前面建立的能力与空间。

检查整场有没有累积：上一击减少了哪条退路、消耗了哪段回收余量、改变了谁的判断？若每轮末尾都恢复完整防线和舒适距离，先重写续压与代价。高潮兑现前面争夺的东西，例如连续压退终于破开一条防线；不另起无关光球或突然切成对视收尾。必要喘息仍有追兵逼近、支撑恢复或下一选择，不能空耗用户指定的快战时间。

海量敌群按空间选择层次：前景近身侵入、中景堵路接敌、远景持续补充。可用低机位遮挡、长焦压缩、高位包围圈、残骸和出口收窄制造压迫；狭窄室内不强造地平线，也不要求每镜三层同框。群体实际活动，不能只是静止贴图。

用户要求紧张险境时，通过逼近、回收窗口压上、路线受阻与夺回主动权形成升级；不是每场必须五步。压倒性碾压则保持其胜负与强度，以敌方主动冲击和连续被击破表现力量，不强加主角失势。

## 场景类型

- **技术对招**：稳定主战法，保留可辨认的步法、发力路径、拆解方式和一次清楚结果；不随机堆流派。
- **连续群战**：精确跟踪当前接触者、下一威胁和可走出口，按实际空间选择群体层次和持续接入来维持数量压力，不强制前中后三层同框。匿名群体可形成压力，不能同时执行多组精密互动。败退或死亡者离开活跃集合并留下可见残留，除非画面明确重新加入。
- **单体与范围攻击**：单体命中明确目标；范围攻击沿同一剑弧、冲击波或能力路径影响多目标，写清传播与成组反应。一个主要状态结果不等于只能击中一个敌人；下一威胁在回收、换步或转向中接入，不复活已退出对象。
- **追逐**：通路、障碍和速度差决定接近或脱离；急转需要减速换重心、弧线或已建立的超自然动力。
- **能力/特效战**：写清来源、形成、传播路径、接触、结果、残留和消散。效果不能遮住决定胜负的接触。

## 大招、压迫与战场结果

仅任务包含大招/高潮时，先确定它比本场普攻多改变什么：作用机制、覆盖尺度、防御失效或战局控制。选择一个主作用并贯穿形成到结果；保留用户指定技能，不为震撼随意增加第二套能力。快速施法可在移动、掩护或上一击回收中完成，视觉辨认时间优先留给主命中与结果，具体负载见容量模块。

大场面是发生在大范围内的交锋，不是放大兵器后打一遍原来的回合。编排“局部接触如何扩展到全场 → 场域变化怎样逼人物改招 → 人物的应对怎样改变下一次大范围作用”。护盾、巨物、场域也属于攻防参与者：对手可抢源点、移动到作用盲区、破坏承载、借遮挡逼近或以自己的技能争夺通路，具体由既有能力决定；不能总是攻击者挥大招、防守者展开更大光罩。

胜负须由前面的争夺兑现。可见受损只是状态，尚不自动证明最后失手；若靠损伤获胜，说明它怎样改变当前可用动作，以及获胜者如何在追压中利用。不能先决定对手必须输，再补一处故障令其放弃所有应对。

- 震撼来自比较：用已建立的人物/伙伴、敌阵与地形作为尺度参照；既看见攻击跨度，也能辨认被改变的战场。小尺度技能可凭精准压制或穿透既有防御成为高潮，不强制巨型法阵。
- 冲击来自传力：抵抗在接触处失败，破坏沿确定路径扩散，身体、甲壳或环境出现相应惯性与残留。抵抗可在高速瞬间崩溃，不强加僵持；单纯增亮、铺粒子和扩大爆炸不算力量升级。
- 压迫来自选项减少：冲锋被压住、退路被封、救援被隔断或防御逐层失效，按既定能力与剧情落实。敌人仍尝试行动，不能全体先站住等特效。
- 统治来自可持续的战局改变：当前包围被瓦解、进攻被截断或主角掌控通路。只在用户要求且胜负允许时表现统治；失败大招、险胜和持续苦战保持原结果，不自动改成清场。

协同大招承接队友提供的战机，或让队友在同一主作用中完成必要一环。主峰值不切去无关小怪补击，搭档的贡献可通过掩护、已完成的聚敌、避让或结果接力保持可见。结尾选择当前战果的延续；若已表现决定性压制，不默认再塞漏网敌人恢复普攻。用户指定继续战斗或高潮后反扑时照常保留，并交代其来源。

## 身体、兵器与服装

持械交锋先判断兵器当前还能完成什么任务，不仅为了招式变化就改拳肘膝踢/肩撞。近身混合技需有贴入窗口、对方刃尖的离线或约束、自己兵器的保留及对手回应；缺条件先修交锋，不能让对手停等。用户指定混合技时补条件而非删除；相关短链见[连续持械交锋](weapon-exchange-lab.md)。

需要时核对支撑脚、重心、躯干传力、非攻击手、视线和恢复，但正文只保留决定结果的部分。同一肢体不能同时持物、格挡和抓握；接触控制者改变必须有可见交接。

区分刀刃斩切、刀背偏转、护手顶压和柄部控制。持武器的手、握点、实体数量和武器所在侧持续一致；长兵器要有扫掠净空。轻功或超自然位移需要已建立的借力点、落点或动力规则。

服装限制动作幅度，但不自动把角色变成站桩。优先调整步幅、转身、腾挪和招式；只有无法兼容时才向用户提出造型取舍。

## 摄影与冲击

镜头变化跟随威胁、主动权和空间变化：对手从侧后侵入可触发揭示机位，包围收紧可借遮挡与尺度表现，关键接触后可随受力方向转移。固定镜头和长焦也能承载冲击，环绕或甩镜须带来可读信息，不按情绪词或技法配额安排。群像优先看清当前接触者、下一威胁及出口，画外敌群仍继承推进与退出状态。

光色、景深和环境层次服务剑路、轮廓与接触窗；保留用户特效规模和伤害展示，选择关键瞬间的明暗、遮挡或焦点分离来读清证据。重击余波可与回收或追击同镜承接，不为“情绪留白”强插空镜中断连招。需要专项视觉细化时见[分镜视觉](storyboard-visual.md)相关部分。

动作与摄影在同一稿内组织，以足够读清状态变化的摄影阶段承载用户要求的镜头设计。大位移用能看到路线和落脚的中全景/全景；贴身控制可用中近景；特写承担已建立空间后的局部证据，不另设动作稿通过门槛。

每个摄影阶段只有一条主要相机路径，起点、跟随对象、触发变化和停止点明确。切镜承接尚未消失的回收、失衡、衣料滞后或追击，可在接触附近做动作匹配切镜，但前后须合起来读清来力、接触和结果，不把决定性接触完整省略。遮挡、闪白、模糊和甩镜不能替代合法过轴或关键接触。

速度来自可读入口、加速、接触、惯性和恢复的差异。普通命中用局部受力与适用的伤害反馈；重击可增加位移、破防和环境反作用。关键格挡、破防、落地或主峰可按表现需要使用短促冲击帧，不限制只有最终大招能用；强调之后承接受力结果，以强弱对比避免每击同样变速、震动或闪屏。若用户要求血液，让剧情实际包含的关键命中具有可读的伤害来源与后果；可同框或由连续镜头承接，不强制新增多次命中或全部同框。

同一次动作可用多个机位分别表现发力、速度、姿态、接触与结果，具体覆盖和冲击帧设计见[分镜视觉](storyboard-visual.md)。动作完整是整组连续镜头共同交付，不是要求每镜看全身、演完整招或永远同一角度；切镜也不允许重复起手、重播命中或略去使下一招成立的必要转换。

## 超载降级

若动作无法在目标时长和模型能力内清楚执行，依次：

1. 删除不改变战局的装饰动作、重复震动和重复特效；
2. 保留可读主镜，减少无必要特写、反拍和相机改向；
3. 把共享路线和结果的攻击整理成明确动作乐句，不删除用户要求的攻击密度与击杀证据；
4. 减少同时精确互动的对象，让威胁连续接入，同时保留中远景兽潮压迫；
5. 仍超载时才建议延长、删减或拆生成单元。

人数、位置、武器归属、退出与持续痕迹并入入口的一次检查，有断链再倒查相关结果。终结条件来自已建立的环境、能力或攻击，不临时生成便利事故。

先辨别超载和欠写：若数秒内只有一次挥击，其余全是特效、外观和禁令，或两招之间缺了脱离/追入，这不是动作太多。应补足交锋与承接，压缩展示空耗；不得用降载规则进一步删动作。

## 高速空战的追击关系

空战先接续领先者、追赶者、交会点和退出路线，爬升/反制期间双方仍有行动；并排同距飞行加尾迹不能兑现追赶。需要具体迁移时见[空战追击与尺度](aerial-pursuit-scale.md)，按已有飞行与施法能力选择抄截或绕出，不用换镜自动补完追入。
