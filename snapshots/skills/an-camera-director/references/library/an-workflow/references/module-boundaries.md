# 12 模块分工与交接

用于判断当前问题该归哪个模块、避免多个模块抢活或互相重写。每个模块只改自己的变量；需要改上游时给证据和依赖，不擅自扩大范围。

## 1. 一张表看懂 12 个模块

| 模块 | 一句话职责 | 主要输入 | 主要输出 | 不负责 |
|---|---|---|---|---|
| 场景导演 | 为什么打、在哪打、先让观众知道什么 | 目标、冲突、场地、信息顺序 | 事件链、调度、场地用途、揭示顺序 | 具体招式、镜头运动 |
| 动作与战斗 | 怎么打、为什么能接上 | 角色战法、距离、资源、对手应对 | 攻防动作链、受力、出口 | 镜头、特效形状、胜负改写 |
| 人物表演 | 打的时候人怎么想、怎么疼、怎么装 | 刺激、任务、关系、台词 | 接收、策略、微表情、身体任务 | 新增命中、改台词、改动作结果 |
| 构图与分镜 | 画面怎么放、一段拆成几眼 | 事件、观看任务、blocking | 景别/角度/占幅/切点/覆盖 | 相机路径、动作重设计 |
| 运镜设计 | 镜头怎么动、多快、为什么动 | 已定取景、动作相位、观看任务 | 起幅/触发/路径/速度/落幅 | 改人物行动、能力或锁定主次；获准摄影变量可与构图共同调整 |
| 特效设计 | 能力长什么样、怎么作用、什么代价 | 机制、材质、作用对象、限制 | 主形、形成、作用、残留 | 胜负、动作、镜头数量 |
| 冲击帧设计 | 哪一下最重、力量从哪来、打到哪 | 已定峰值、力向、对象、结果 | 峰值形体、冲击帧、退出承接 | 整段攻防、重新命中 |
| 声音与时间 | 什么时候响、什么时候静、占多久 | 声源、原词、动作相位、时长 | 声画关系、J/L cut、时间预算 | 新增镜头/攻击、改台词 |
| 素材与连续性 | 人、衣服、道具、伤口不能乱 | 素材、身份、状态、引用 | 绑定、状态表、续写入口 | 动作/机位/能力重设计 |
| 提示词编译 | 把决定写成能直接用的稿 | 已采用设计、格式、平台 | 一份完整正文 | 新增设计、补未决动作 |
| 检查与返工 | 找最早出错的地方 | 最终稿、请求、证据 | 问题、原因、最早断点、最小改法 | 把风格偏好当硬错、擅自重写 |
| 平台适配 | 按平台规则改，不改导演决定 | 明确版本、上游稿、真实标签 | 平台语法/结构适配稿 | 重写剧情/动作/镜头 |

## 2. 最容易抢活的四组

### 构图 vs 分镜 vs 运镜

- **构图**：画面里谁大谁小、谁前谁后、眼睛先看哪。
- **分镜**：这一段拆成几眼、每眼给什么、切点在哪。
- **运镜**：这一眼镜头怎么动、多快、停在哪。

构图管画面关系，分镜管观看顺序与边界，运镜管连续路径；三者共用一份摄影方案。一个连续镜头可先建立再转到反应/结果，不因主读交接必须切镜；当前获准摄影依赖合并处理，具体见[联用边界](functional-collaboration.md)。

### 动作 vs 表演 vs 特效

- **动作**：身体怎么打、攻防怎么接。
- **表演**：人怎么想、怎么疼、怎么装。
- **特效**：能力长什么样、怎么作用。

一句话：动作管“打”，表演管“人”，特效管“能力”。

### 场景 vs 连续性

- **场景**：为什么在这打、场地怎么参与。
- **连续性**：人、物、伤口、位置不能乱。

一句话：场景管“为什么”，连续性管“别穿帮”。

### 编译 vs 检查

- **编译**：把已定的东西写清楚。
- **检查**：找最早出错的地方。

一句话：编译不新增设计，检查不擅自重写。

## 3. 交接规则

1. **一个变化只有一个负责模块**：动作变了归动作，镜头变了归摄影，别在编译里偷偷改。
2. **需要上游变化时给证据**：写清“哪一拍、什么冲突、最小依赖”，不直接重写全场。
3. **局部修完复查依赖**：动作改了要查空间/镜头；镜头改了要查动作是否还被看见；特效改了要查胜负/动作。
4. **不把风格偏好当硬错**：不喜欢不等于不成立；硬错要有事实/因果/空间/时间证据。
5. **不把模块清单当必做**：按当前问题读，不要求每场把 12 个模块都跑一遍。

## 4. 不知道该找谁时

按顺序问：

1. 这是“为什么打/在哪打”吗？→ 场景。
2. 这是“身体怎么打/为什么接得上”吗？→ 动作。
3. 这是“人怎么反应/怎么演”吗？→ 表演。
4. 这是“画面怎么放/怎么切”吗？→ 构图与分镜。
5. 这是“镜头怎么动”吗？→ 运镜。
6. 这是“能力/特效怎么长、怎么作用”吗？→ 特效。
7. 这是“哪一下最重/力量怎么传”吗？→ 冲击帧。
8. 这是“声音/时间不够”吗？→ 声音与时间。
9. 这是“人/物/伤口变了”吗？→ 素材与连续性。
10. 这是“写不成能用的稿”吗？→ 编译。
11. 这是“找最早错误”吗？→ 检查。
12. 这是“平台版本/标签/结构”吗？→ 平台适配。

## 5. 常见越权

- 运镜为了“酷”改人物路线。
- 构图为了“好看”改动作结果。
- 特效为了“大”改胜负。
- 表演为了“有戏”加台词/加命中。
- 编译为了“完整”补未决动作。
- 检查把“我不喜欢”写成“硬错”。
- 平台适配把“官方建议”写成“硬规则”。
