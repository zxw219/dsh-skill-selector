# 案例：16:9双人打斗——从“打一下停一下”到连续压力

本页保留本日较早的历史样本与作者自检，不能作为当前通过范例。旧六问中用近景/相机在动放行结尾互抵、按每2.5–3秒变化判合格的依据已撤销；结尾长时间互抵若只有手抖、眼神与相机慢推，仍须核持续限制、压力发展与出口。当前执行见[连续打斗门槛](continuous-fight-gate.md)，新练习见[本轮演练](cinema-practice-20261022.md)。原稿保留以追溯失效，不能因为被称作修后稿就免检。

用户要 16:9、30s、纯打斗、华丽技能。修前稿有：S1 两人站定、S2→S3 银黑突然半空落地、S4 银黑放日轮红发在龙卷里等、S7 两人蓄力对峙、S9 起身对视、S11–S12 停住大全景。用户判“打一下停一下、站定对峙、一人放技能另一人看”。

## 诊断

| 位置 | 失败 | 修法 |
|---|---|---|
| S1 | 两人在石台两端站定，缓推+急变焦，开打前先摆姿势 | 两人已经在跑；贴肩跟跑+急变焦+甩镜，没有站定 |
| S2→S3 | S2 结束在贴身，S3 银黑突然“半空翻身/落地”，没有起跳与距离来源 | S2 银黑借护腕泄压后撤，S3 边退边布阵，红发追进；没有落地 |
| S3 | 银黑站定控阵，红发在龙卷里 | 银黑边退边控，红发追进阵心；两人都在动 |
| S4 | 银黑放日轮，红发在龙卷里等光束，翼“仓促成形” | 红发提前收龙卷、冲向银黑，逼她提前开火；红发的翼是偏转不是护盾；日轮因提前开火裂开 |
| S6 | 红发靠柱烧火、再飞，中间有停顿 | 火烧到一半就蹬柱；镜头近→远英雄环绕跟着她飞；不停 |
| S7 | 两人蓄力对峙，像对波 | 红发用断羽/碎石砸盘，逼银黑提前放；赤鸢侧切；没有对称蓄力 |
| S9 | 两人起身、对视、再走 | 起身即走；红发抓柱借力，银黑边起边扯纱；没有对视 |
| S11–S12 | 停住大全景，两人站着不动 | 近景环绕/推近，手还在发力；不拉大全 |
| 整体 | 每镜一个交手，切完像重新开始 | 每个切点接剩余相位；S2→S3/S3→S4/S6→S7 的出口→入口写清 |
