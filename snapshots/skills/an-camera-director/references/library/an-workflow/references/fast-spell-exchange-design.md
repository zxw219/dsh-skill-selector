# 高速交锋、施法动作与技能作用

用于普通法术打斗的选招与编排，也用于高速被写成追击、施法只有甩掌或反复光波的返工。它补入口第2–4步及终检：先定实际交锋，再让施法操作和技能机制进入同一事件，不等用户点名“高速”才执行。用户明确慢打、仪式、追逐、单招、无手势或已锁能力时按其要求，不把本轮纠偏变成禁追逐、禁投射或强制多技能。

## 速度先发生在交锋里

按攻击压力的接力编写，不能每招都完整执行“抬手形成—发出—看效果—恢复—再准备”。短促术法的形成可嵌入当前避线或受力，下一次改控可使用上一招留下的接触/节点；对手在源端动作暴露时预判，来不及反击时继续受压。已有攻击离体、交代理或解除控制以后，才释放对应资源给下一动作；重叠来自真实机制，不凭“同时”分出多只手。

区别三种快：源端发动紧凑、在途攻击迅速、接触后马上产生新任务。长时间飞行靠短时码掩饰、普通法每次慢慢成形、命中后双方一起收手，都须回修。持续大法可与相容的短促截击并存，或在同次负载中发生争控/破口/转向；双手全占用就用既有代理、身体避线或被迫承压，不为高频凭空添能力。

在角色实际有效距离内，安排短促发动、对方判断/应对、当次起效或落空、改控/截断、反击与下一窗口。近身可以是触印拆法，远距可以是截击与跨点接力；不因法师必须交锋就改成拳脚武者。位移服务当前避线、抢位、接重或出招条件，位移大和残像多不单独证明打斗快。

高速交锋的证据是双方来得及做什么、被迫改变什么，以及攻击端/接触/控制怎样短促发展。例如同一区域里落点接连更改、指诀受截马上换手、上一防线未卸载下一威胁已进入；无需让双方跑过整个场地。有效频率、高速、高燃继续分别验收，不能用切镜、时码或响度代替。

追逐是场景任务，交锋速度是事件属性，二者可同时存在也可分开。当前只给高速打斗诉求时，先成立足够的有效交锋，再按真实收益选移动；明确追逐则保留通路、追及与空间体验。没有交会/作用发展的快速奔跑，可作为追逐素材，但不能单独验收交锋速度。

## 施法动作从本招的操作长出来

不先从掌心投射选技能。当前能力允许时，可用身体接触、落脚接点、器物载体、已布状态、环境连接或自主代理发动，并让它们改变作用位置、控制关系与终态；仅把同一弹道改成脚底射出不证明机制丰富。明确手脚并用/混合战法时，本体手法与腿技通过真实防线变化接术法，控制手保持占用，腿须有实际攻防作用。方法按[手脚协同](full-body-ability-integration.md)，纯远程、无手势与锁定发动条件继续有效。

先问这次操作改变什么，再选择身体任务。下表是可转译关系，不是每招必须凑齐的手势清单：

| 当前操作 | 可选动作过程 | 作用证据 |
|---|---|---|
| 选定/锁定 | 目光追到有效目标，指端指向或夹住已定作用区，拇指压住诀指锁位 | 目标/节点确被锁住；不自动新增全域追踪 |
| 聚拢/压缩 | 两掌相对或掌指回扣，肩肘随作用向内收，拇指与指根缩小间隙 | 主形/介质收聚、压力或结构变化，不只是脸前搓球 |
| 分层/开闭 | 指节逐次展开，前臂相对转向，手掌分离或一手推一手留 | 哪层/哪片打开、哪段继续控制可辨 |
| 接通/布置 | 指端触物、掌心按地、脚步接已定阵点，身体接重 | 原位置留下状态/连接，后招真的读取它 |
| 牵引/改向 | 控制手沿成立范围牵移，另一手护源或换诀，胸肩顺着负载调整 | 被控对象沿新路/新角度运动；不把所有术法当长绳 |
| 截断/解除 | 当前诀指交剪、指节松开、掌面反转或离开接触点 | 哪项控制停止、哪项离体作用继续，残留保留 |
| 释放/交代理 | 成形已可读后断诀、指向指令对象，再收势进入下一任务 | 作用体离开/代理获指令，本体后续任务兼容 |

关键施法写清当前手臂/手指如何进入、变化和退出，并让目光、肩肘、胸腰、支撑或御空按当前负载参加。需要身体幅度时保持实际开合与线条，不能把所有施法压成孤立手腕抖一下；精密小诀和无动作发动仍按角色机制成立，不强塞全身舞动。

快来自紧凑的相位和相容并行，不来自省掉身体动作。熟练换诀可以快速且可辨；复杂仪式需要实际预算。不要为了多写施法让对手停等，也不要把一次短法配成许多无作用手势。每招选择有必要作用的过程，普通正文不附全套操作表。

持续控制先占用真实手/注意，再分配另一项行动。已离体、布置待命或自主代理按既定机制继续；角色不能一边维持双掌引导一边又用同一双手召唤。改变手势时检查是在变控、交接、解除还是另起一招。

## 技能丰富先改变作用，不只换招名

持续反馈技能少/重复/单一时，先按[原创与选招](ability-variation-selection.md)检查储备、熟悉组合惯性与正文兑现，当前机会决定采用。这里的机制维度是基础，不能由类别齐全推断选招和画面已经丰富；作用、施法操作与决定性画面分别落实。

在本角色体系内，从当前攻防问题选所需能力：精确点生效、触物附着、近体压力、预置触发、区域改变、材料变化、感知/诱导、御使/自主代理或独立投射等。它们是设计空间，不给每角色强塞全套。允许原创则设计实际机制；已锁能力只使用其相容方式。

两招去掉名称、颜色和大小后，看是否仍有本场需要的触发、位置、操作、时间行为、对象或终态差别。不同法术都变成掌前成球—甩出—撞碎，说明差异没有编进事件。投射本身是合法结构，单技能多用也可以丰富，但其当前用途、应对和出口要兑现。

建立施法与作用的直接对应：布印有后来触发，凝面有真实偏转，触点封禁改变可用动作，领域改变边界内外，代理执行指令，材料变化改变支撑或阻力。相同介质能有不同作用；不必靠换元素增加技能。

反制从当前事实选择：截起手、避作用区、改变目标/载体、破控制点、毁局部结构、承压导走或解除状态等。起效条件、起手前/在途/作用后三种反制窗口，以及同一技能第二次出现的变形要求，见[战斗逻辑与动作流](combat-logic-and-flow.md)。不能每次都添一道盾挡爆；也不要求每次防守必有反击，无法抵抗或碾压按当前任务成立。

## 普通施法也要有观看与情绪

把本段关键的换诀、控制和接收变化分配到实际占幅，不只给大招近景。当前一镜可读就保留；局部读手时邻镜接同次目标/作用，画外对手继续。衣袖、头饰、泛光和浅焦不遮关键指节/接触；大招范围仍保留规模。

情绪从失效、识破、改控和投入进入下一招。例如惯用折面被点破，角色先察觉控制端失活，随后由单手精调改为双掌稳阵；不是每次统一皱眉后放更大光波。高燃与冲击帧强调已成立的选择和力量，不能补造缺失技能。

## 同次验收

沿最终稿核所有适用施法与交锋：速度有没有有效作用证据，移动有没有当前用途，手势/身体有没有实际操作，普通招式有没有机制差别，控制资源和前置/残留是否承接，必要动作/作用是否取景可读。发现有名无动作、有动作无作用、只有跑动或只有换色投射，修最早的所属决定与后续依赖；不能末尾加禁令抵消正文。

文本设计、作者复核、独立调用、正常播放/试听和成片体验分开。当前练习及待校准层见[专项学习计划](fast-spell-learning-plan-20261013.md)和[12项文字学习](../assets/reference-studies/fast-spell-exchange-20261013/12%E9%A1%B9%E5%AD%A6%E4%B9%A0%E4%B8%8E%E6%BC%94%E7%BB%83.md)。普通作品不执行整个训练集，不设施法/技能/镜数配额。
