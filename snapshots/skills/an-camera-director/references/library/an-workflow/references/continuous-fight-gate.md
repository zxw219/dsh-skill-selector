# 连续打斗门槛：不停、不站、不单人演出、不定距

双人/多人实战在编排前和交付前使用，不等站桩反馈才读取。当前用户明确要求：两人非必要不要停顿站立全景，禁止打中突然停手对峙，禁止一人释放技能而另一人站立观看。普通文戏、明确仪式展示、固定/慢镜按原目的设计，不能靠分类把当前实战改成展示。

## 速度型段落的时间口径

下方同期、脚账及三秒诊断用于同一世界进程，不把成片播放时间等同所有人的可反应时间。极速感知/慢世界按[速度型战斗](speedster-combat-direction.md)先分成片、世界与主体差速：普通人在极短世界区间近乎凝滞可成立，不要求其为了过门槛转身连挡；在途攻击、机械和触碰后物体仍按各自状态前进，切回不复位。也不能只用“他太快”包办未写出的路径、作用与世界进程。普通快打的无因停机仍照本页回修。

## 五条禁止

1. **不加非必要的双人站立全景。** 用正在发生的接近、拦截、追压或争夺建立关系；确有必要的受控/角力须有实际限制和正在发展的代价，不能仅为交代站位停手。
2. **不中断交战插入停手对峙。** 眼神、疼痛、愤怒和判断在回护、接重、改控或避线中发生，不能为了特写令对手停机。
3. **不让对手看技能播完。** 准备、显化、释放、结果的关键窗口中，对手已在做可达行动，或此前已有具体限制；切到单人独拍，画外时间照走。
4. **不做单击与复位循环。** 回收、恢复、回应与下一准备相容重叠；后招从前招真实出口接，受阻后不继续成功版。
5. **不靠摄影遮断链。** 相机动、快切、衣摆动与满屏粒子不证明持续交战；切出/切入接同次剩余相位，不重复或补造状态。

## 距离账

站桩与技能轮播的判定。“双方都在动”不是打斗。打斗是同一段可打距离的争夺：谁压得近、谁被逼出去、谁退到打不到的地方。开写前先画一条距离线，至少三个节点——开距、最紧、终点；每一次需要看清的变化都要落在这条线上。

- **脚账**：把两人的支撑点按时间连起来。连续三秒以上同一只脚承重、两人距离变化不到半步，又没有接触、抓握或压制关系，判原地，回修。判据用秒数不用“拍”，避免另一种隐形配额。
- **技能账**：技能按发动时间编号。后一个必须由前一个的结果触发——能接在作用期内就接（在途、残留、被控、地形已改）；前招被彻底打散、真正结束的，以散掉之后的新状态和新距离承接，不补假残留。甲放完→乙放完→甲放完是轮播，不是交锋。
- **施法账**：发动和维持的这段时间，施法者本人的脚在做什么——压进、退让、换层、被推走、抢支撑。双手被占，就用身体和步法解决空间问题。站定施法要有依据：术式本身要求定身（且对手正在利用这段定身），或正在贴身接触、被锁住、被压制；只是图省事不算依据。对手那边同样要付代价，不能一边定身一边没人靠近。

合法的“不动”要三条同时成立：有实际接触或控制关系；每一次变化都有重心、防线、位置或支撑的调整；对手正在逼近或拆解。缺一条按站桩处理。纯远程对峙要求两人都在换位找角度，只是暂时没有接触；固定机位只固定相机，不固定人。只有用户明确锁定的单招、定格、慢镜和仪式不受本账约束；写作者自己把一段定距轮播称作“仪式”或“有意不动”，不算锁定，仍按站桩处理。

失效样本：两人相距四到五米，八秒里一个升空施法、一个原地还手，距离只从4.8米变到3.5米，脚几乎没动。事件、因果和镜头都在，唯独距离没被争夺——读感就是“轮流站桩放技能”。修法不是加特效或加快切，而是重编距离：施法者逼近、受术者退让，或反过来，让技能在移动中发动。

## 连续压力链

先按[压力重叠](../../combat-action-design/references/pressure-overlap-and-release.md)编关键窗口，再安排观看与时间：双方任务和资源→可达尝试→条件变化→未完成任务接下去。取消旧版每2.5–3秒换状态的硬指标，不因姿态稳定自动判错；超过三秒的站定按[距离账](#距离账)三条核——有接触或控制、每次变化有调整、对手在逼近，三条都成立就保留。三秒是判站桩的下限，不是要求每三秒换一个动作。

在准备/回收/显化窗口代入对手最直接有效的行动。可行却没发生就修同期；不可行须有已成立的封锁、占用或危险证据。不能临时添束缚、胆怯或新能力替等待找理由。

## 技能释放的双方同期

控制者、作用体、对手共用时间。持续控制与自主代理分开，双手导引时双手不可另做事；能否移动由机制与支撑决定。对手可抢控制端、改线、拆作用体或争目标，不强制每次反制成功、贴身或新增法术。技能结果立即提供新任务，不留“等烟散、等站起、重新站好”的空场。

## 动作衔接

接位置/面向、距离、支撑、持物、未解接触、余势与控制占用中影响后招的项。刃仍被压住先解除或转用；落地前不能按站稳状态发动后招。“借惯性”“接着攻击”须有身体/兵器或控制的具体过渡。方法见[动作衔接](action-linkage-and-release.md)。

## 镜头

稳、动、短促制动均可读持续交战。动态全景读路线/关系，近景读控制/接收；**人物站着等而相机绕圈仍然不合格。** 施术者可有必要站稳控制，但须先过[距离账](#距离账)的三条成立条件；依据是正在负载且敌人/作用继续改变条件，不是摄影在动。

**近→远英雄环绕**是召唤/显化/反压制的主动候选：低位从控制手/半身近处起，弧绕读脸侧与负担；中段地标掠过并显露敌人同期进路；扩大半径后拉到人物、作用体与对手的范围关系，落幅接正在发生的交会。不让角色等相机，不把双手控制变放手，不要求转满360°。选型见[表现性摄影](../../cinematic-camera-design/references/expressive-camera-and-zoom.md#复合与特殊运镜的选择库)。

## 验收七问

1. 双人站立全景是否确有必要、可见限制与当下发展？
2. 技能每个关键窗口，对手同期在做什么；不能行动的限制在哪成立？
3. 前招支撑、接触和控制资源能进入后招吗？
4. 中途是否为了眼神、造型或落幅停手对峙？
5. 去掉摄影、特效和“高速”词，两人的脚是否还在互相逼近、推挤或换位？连续三秒站在同一位置、距离不到半步，有没有接触关系撑着？
6. 局部/范围/环绕是否在同一时间交出发展中的关系？
7. 有在途/持续/残留时后招是否共享世界进程，前招真实结束后是否从新状态承接；有没有无因等候、假残留或切回重放？

答案在最终正文取证；不设动作数、镜数或运镜配额，距离账里的三秒只作判站桩的下限。旧[修前修后](fight-continuity-case-20261022.md)的数值不作为规则；新演练见[本轮练习](cinema-practice-20261022.md)。文本门槛不证明实际视频节奏。
