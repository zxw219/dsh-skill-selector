# 动作推演与返工例

用于动作少、回合式对打、空间含糊、大场面与剧情脱节的返工，以及技能维护时的行为检查。与[action.md](action.md)联用；不为普通文戏加载，不强制输出分析表。这里的原创演练是动画/影视编排，不是实战技术教学，也不代表视频已经生成验证。

## 先辨认问题，不把所有问题都当超载

| 证据 | 应修什么 | 不能用什么冒充修复 |
|---|---|---|
| 几秒只写一击，余下是衣料、粒子和规则 | 补可承接的交锋与对手应对 | 再删招、增加“高速”“激烈数回合” |
| 攻击结束才轮到对方，起跳/准备期间另一人消失 | 双方共享时间、创造窗口的行为 | 每句添“同时”却让一只手承担互斥任务 |
| 每次都攻击→避开→退回原位 | 本轮目的、继续追压、阻断或反击的后果 | 机械均分双方进攻次数 |
| 站位没错，兵器仍穿人或抓不到手 | 攻击体积、距离、接触解除与进入时机 | 全片写死甲左乙右 |
| 写了巨大武器，但人物仍原地轮流出招 | 技能如何改变地形、目标和可用行动 | 再增加高度、法阵层数或爆炸尺寸 |
| 近景好看但没有危险进程 | 接近的威胁、应对代价及被迫选择 | 用性感、贴脸、微笑代替战斗张力 |

动作干净、动态方位、技能有效性及冲击画返工，联用[战斗执行与表现](combat-execution.md)。执行本页的小段推演，不以规则出现、格式通过或更多禁止词代替实际状态接续。

## 小段推演方法

只挑会影响结果的交会点，在稿内或维护报告中写“甲当前动作／乙当前动作／两者交会及结果”。这些是同一时段，不是依次排队。标注发起、到达、接触/避开、恢复的先后，随之继承距离、朝向、支撑和忙闲手。每次追问：对手此时若不停手，后招是否还成立？

动作接触可能约束双方自由度，不能立刻独立挥舞；脱开是事件而不是默认。攻击落空也有后果，攻击者继续追步、改变剑路或承担回收，对手才可能利用。一次必要停顿可以形成压迫，必须有等待目标、受限原因和结束条件；快战请求不能靠反复停顿填满时长。

对关键歧义可简写地标方位或平面坐标，但应先决定所争路线再选机位。镜头的运动不改变角色位置。“来到侧后”要靠弧线移动、迫使对手转身、遮挡窗口或既有位移能力得到，不靠硬切。

## 原创对照：方向核对与守门交锋

先处理以下方向专项时，沿用动作模块的“为什么出招—打谁—路径—接触—新状态”核对。下例是文字反例和修法，不是已生成的视频结果。

### 方向与无因攻击的反例

| 错误片段 | 断点 | 在原交锋中修复 |
|---|---|---|
| 乙在甲面前；甲向身后直拳，击中乙肩部 | 拳路不经过目标；未发生绕行或回转 | 甲将右拳从肩侧沿前方短线送向乙肩部，乙抬臂截住；若后摆只是蓄势，要接着写出向前打出的阶段 |
| 乙已从甲右侧绕到背后；甲仍向原正面刺，乙受击 | 沿用旧位置，缺少追踪/转向 | 甲依据右侧脚步转头辨位，撤出原刺、转脚面向柱侧的乙再追刺；乙在转向期间继续压近，不能停等 |
| 上镜乙位于甲侧后；切镜后乙迎面重击甲 | 剪辑替代了人物绕行或甲转身 | 保留乙侧后位置；甲在回护时转身面向乙，乙利用她转身未稳的窗口攻击已转过来的防线；或另写可达的绕行路线 |
| 甲后撤蓄力，乙无动作；甲无目的旋转三圈再挥拳 | 没有撤离窗口，转动与交锋无因果 | 让甲用前一击压开距离，乙随即追压；甲把蓄势并入后撤落脚，以对手接近触发出拳。保留用户指定的舞蹈/炫技时另给成立窗口 |
| 乙已被击退数步，甲原地短肘再次命中 | 距离继承错误 | 甲追步进入短肘范围，乙在追入期间回护；或承接既有远程招式，不能临时把肘击当远程波 |
| 相机绕到乙背后，甲也因此变成背向乙 | 相机路线被错误转成角色转身 | 人物位置与躯干朝向继承，仅重新描述两人的画面左右和遮挡；需读甲脸侧时调整摄影而非让甲离开攻击方向 |

相邻合法情况必须保留：向后拉拳蓄势再向前出击；已知敌人位于身后时的后肘；回旋兵器先离开目标再沿已建立曲线返回；对出口的封路攻击；敌人闪避造成的落空。它们都需要路径与作用依据，但不能只见“后、转、空”就一律删掉。

### 守门交锋

前提：甲在西侧向东突进，乙在东侧守门，双方右手持剑；北侧窄道可绕门，南侧有石栏。此例仅演示关系，不绑定用户角色或固定流派。

欠写：甲连斩，乙连续闪躲。甲退回高台蓄力，乙展开护罩，双方释放大招。

改写片段：甲的直刺尚在前送，乙已向南跨出刺线，用剑身斜推甲剑向北，试图占住甲右臂外侧。甲不沿原线收回，手腕随偏转抬起，剑身从乙剑上滑脱，后脚追上转胸朝南，以短横切封住乙的进入路线。乙的进步被迫刹住，直剑竖起接切，冲力把她推近南栏；她没有退回原位，而是借这次碰撞转向东退，保持在甲与门之间。甲顺势抢向北侧窄道，乙边横移截路边反刺其肩甲；甲必须把已前伸的脚收回制动、回剑封住，突进路线再次改变。

这段的收益是每次应对改变下一次可用动作：让线不是无效闪避，甲会阻止进入，乙会阻止绕行。侧步、滑脱、转胸、刹步都有前因。实际速度与演员/模型执行仍须实测，不由这些文字证明。

相邻反例：若用户明确要甲碾压，乙可以反刺但被立刻压溃，不强制乙成功夺回主动；若乙目标只是拖延，可以连续防守，只要甲持续试图突破且拖延有目标进度。

## 原创对照：大场面要改变交锋

欠写：百米巨刃落下，百米护罩挡住，远处地面崩塌，双方回到完好的中央继续打。

改写机制：进攻者发现对手持续守住正面，改将延长刃扫向其正在使用的侧廊，把撤步路线切断。防守者在斩线到达前跃回内台，但落点被进攻者续出的横斩封住，于是从仍连接建筑的护栏借力改落点；其反击击偏刀根，使后续斩线抬高撞到廊柱。倒向通路的柱体短暂阻挡追击，防守者利用它接地前的窗口转入内侧。进攻者切开柱体继续推进，不等待对方另起一套展示。

大范围的破坏与近身交锋是同一过程；威压来自退路变少、落点仍被追击、借力窗口正在消失。防守者不是简单换一个更大的盾，攻击者也不是放完技能等结果。具体巨刃是否与手臂传力、护栏是否承重，应在项目中先建立；例子不作为万能技能包。

## 维护时的行为案例

实际留存试写后才能报告已执行。以下只定义案例和判据，不代表它们已经通过；不用关键词命中或自评分代替结果。

| 输入 | 观察什么 | 相邻边界 |
|---|---|---|
| 12秒双人高速刀剑交锋，守门者不能只躲 | 两人持续改变对方选择，关键接触与恢复写出 | 不要求每次防守后必反击 |
| 两人面对面，各右手持剑；一方要求进入对方右臂外侧 | 自身左右、地标方位、出入距离和攻击弧一致 | 不强制一直甲左乙右 |
| 角色退到台阶上释放技能，敌人距离很近 | 退开的窗口由压制/阻隔/追击处理产生 | 不靠给敌人添加无因犹豫 |
| 20秒巨物技能对抗，破坏主战场 | 威胁越过参照、迫使改路，人物利用/抵抗后果 | 不要求所有场景坍塌或都有巨物 |
| 武器延长十米，最终近身控腕 | 远端接触到实体接近之间有时间、路线和对手动作 | 不把缩刃等同于瞬移 |
| 60秒两段，断在接触前 | 后段延续动作相位、追击与受力，不重复起手 | 没有帧参考不承诺精确匹配 |
| 性感开场后进入高强度对攻 | 开场吸引力和打斗威胁分别兑现，展示不令对手停机 | 用户明确的停顿/魅力镜头仍可保留 |
| 强者压倒性击退追兵；另写一场普通生活对话 | 守住指定胜负；对话不被动作规则改成强制敌对 | 不套平均主动权、镜头数、攻击频率 |

## 此类反馈的维护演练

按本轮改动选择相关请求实际成稿，再对可观察结果检查；下表是待验证案例，不是通过记录。

| 请求组合 | 查看实际结果 | 相邻反例 |
|---|---|---|
| 高速近身 + 对手绕到自身右后 + 相机另换侧 | 是否真的给出绕行/感知/转胸/攻击新位置，切镜后肢体负载与距离能否承接 | 合法背向攻击、固定相机、单人演绎不被统一禁止 |
| 绕后改变主轴 + 下一段继续退守/追击 | 新相对位置和面向下，后撤是否增距、追入是否缩距，是否误继承开场“向东退”；镜头换侧是否只改变投影 | 横移、诱进和有意缩距可成立，但不能无解释称后撤 |
| 控腕/束腿 + 反击/移动施法 | 手脚是否仍受控、先脱开什么、对手是否仍行动；技能触发与控制占用是否成立 | 短偏转不是永久锁定，已说明固定后不占手的能力仍可成立 |
| 密集实击 + 两种不同能力 + 高潮 | 能力是否改变推进/负载/路线/选择，是否只剩换色拳头或方便的薄弱边缘；身体命中与结果是否实际交付 | 已锁能力不换掉，强化型能力不强制新增控制/资源机制 |
| 限色冲击画 + 短促曝光 + 强特效 | 特殊画是否由同一接触推导、退出是否接同一次运动，曝光是否未抢走攻防且造型保留 | 明确长冲击组仍按要求组织，未知帧率不默认24fps，无冲击帧任务不添加 |

报告区分结构检查、文本语义演练和真实成片；文本通过不能宣称无方向bug、不卡顿或特效质感已验证。

## 查阅材料与迁移边界（2026-09-27）

本轮读取下列文字资料及网页说明，没有声称观看完整影片、完成特技排练或生成视频。以上双向时间、方位检查、战术因果和对照练习是本工作流的原创综合，不是假称这些来源给出了同一套模型提示词规范。

- [Lionsgate《John Wick: Chapter 4》制作资料](https://www.lionsgateawards.com/assets/files/JW4_Production_Notes.pdf)：主创描述车辆、楼梯和空间结构参与动作设计。迁移为环境改变可用行动，不照搬剧情、训练时长或把结尾慢决斗用于所有快战。
- [SOC：James Frater访谈](https://soc.org/project/john-wick-chapter-4-8/)：动作呈现强调可读性及特技团队与摄影的配合。迁移为接触与接续有画面证据，不把某场长镜经验变成固定镜长或禁止快切。
- [ASC：John Seale谈《Mad Max: Fury Road》构图](https://theasc.com/video/john-seale-asc-acs-framing-mad-max-fury-road/)：此处仅核对网页对中心构图服务快速剪辑的说明，未声称观看内嵌视频。迁移为跨镜注意中心连续，不强制所有镜头居中。
- [ASC：《Dune: Part Two》摄影](https://theasc.com/article/expanding-view-dune-part-two/)：收割机段落以演员穿行大尺度阴影连接人物和CG巨物。迁移为近处人物受光、遮蔽与同一巨物运动一致，不把所有能量体写成有实体投影。
- [Animation Mentor：Wayne Gilbert谈重量](https://www.animationmentor.com/blog/how-to-create-believable-weight-in-animation/)：从相抗的力量、姿态和平衡理解重量表现。迁移为接触负载与身体反作用，不给所有幻想动作套现实力量上限。
- [Animation Mentor：Chris Hurtt谈预备动作](https://www.animationmentor.com/blog/anticipation-the-12-basic-principles-of-animation/)：准备须与随后的动作相称，受击反应不应早于命中。迁移为在回收/奔跑中保留发力依据，并区分主动闪避与命中后的被动反应，不延长每次蓄力。
