# 摄影分镜与动作招式：学习执行和入口继承

2026-10-12执行此前用户要求的学习计划。实写39组对照、24项大动作的过程/条件与8条链、25式剑招应用、同一30秒一镜/切镜版本及新题自主选型。记录详见[报告](../assets/reference-studies/director-learning-20261012/%E5%AD%A6%E4%B9%A0%E6%8A%A5%E5%91%8A.md)。这些是文字训练及作者复核，没有独立盲测、正常速度声画验收或生成试跑。

## 普通出稿怎样使用学习

角色要求丰富身法或明确翻滚/前空翻/后空翻/旋转时，先按[动作专项](../../combat-action-design/references/acrobatic-action-design.md)选实际进入条件、身体轴/路径、同步对手、落点与续招。相容大动作保留幅度，不全部缩成斩刺挡退；持续控制、兵器任务和前后状态仍成立。无剑术者不因剑招学习新增剑。

摄影分镜不会选或动作未读清时按[同事件选择方法](../../cinematic-camera-design/references/camera-action-learning.md)决定全身读形、局部读接触、脸读判断、范围读规模；手持/摇移/急变焦/希区柯克各有实际变量与观看收益。用[翻腾覆盖与相位切接](../../action-camera-direction/references/acrobatic-coverage-and-phase-cuts.md)保留角色与地标、画外对手和切后剩余进程。所有专项只回填同一采用事件及原An格式，不多写竞争导演稿。

有问题才读相应方法；普通创作不读39组全表，不凑动作/拍法/镜数。固定静音、慢镜、单剑、单能力、局部返工与真一镜的反例仍成立。文字/几何/文件校验只证明对应层，不宣布模型已学会动作或影片已经高燃。
