# 打斗设计系统：全身动作、能力作用与场面兑现

用于连续实战原创及“动作少、只推搡、技能没出现、特效不震撼”的返工。先设计用户要看的实际过程，再编时间与格式；不把某一场30秒案例、招数上限或固定反转路线当通用结构。角色、能力、装备、胜负、片长、媒介与用户格式优先。

## 1. 写前锁体验和事实

内部确定：双方争夺与战法、入口距离/面向/支撑、持物/控制任务、用户要的身体幅度与动作变化、必须实际使用的能力、主峰强度及出口。用户要双方技能，就给双方各自安排真正起效的用途；只写“技能不超过几个”不能覆盖这项正向义务。机制种类、施放次数、用途和高潮事件分别判断，同一能力可以多次以相容方式参与交锋。

用户说“自然动作/动作丰富”，指全身连续运动的变化：旋转、翻滚、回旋踢、跳跃、扫堂腿、越障等是候选方向，不是每场逐项打卡。先从身体路线、支撑转换、高低和兵器关系共同编排；不能先写完斩刺肘膝，再靠换攻击部位过关。拳肘也可有完整全身驱动，但仅增加拳肘名称不足以兑现本次身法幅度要求。

原创可从开场共同设计相容来线、障碍、落点和反制，让大动作、技能与场地从一开始互相需要。已有锁定段落则从真实状态修，不事后凭空补敌人攻击为花招找理由。用户要动作美感本身也是表演目标，战术最短路径不是唯一选招标准；仍须保留对手行动、可行空域与接续。

## 2. 先编动作乐句，不先切均匀秒段

每簇由一个未解决问题推进：`当前威胁/任务 → 身体或能力解法 → 对手同期响应 → 新限制/机会 → 下一解法`。动作可以衔接、受阻和改线，既不等每招完全收完，也不省掉必要脱开、接重与恢复。

主动比较不同身体结构，按本场选取并贯穿交锋，而非只在结尾点缀一次：

| 已有出口 | 可比较的下一结构 | 正文需要的过程 |
|---|---|---|
| 前招转势未尽、来线绕侧 | 轴转回击、旋身让线、回旋腿 | 支撑脚/身体轴、髋肩领随、弧线路径、回护与落脚；不靠衣摆或相机转证明人转 |
| 被迫低身、失去站立线 | 低滚穿线、扫腿、侧撑换层 | 头肩/躯干怎样离开威胁，支撑如何转换，武器避身，对方追截与滚后接重 |
| 地面来线/通路封闭 | 腾跃、越障、借结构改向 | 起跳来源或已定御空机制、身体弧线、在空中的攻击/避让、落点与对手位置 |
| 持械接触受限 | 绕兵器转身、滚动脱线、长兵器回绕 | 先解哪处接触、握持/刃尖去向、身体与兵器各自扫掠体积、续攻可达距离 |

这是选择方法，不是固定连招。优先写决定这次动作差异的身体过程；不用每招机械列关节。完整方法见[翻腾设计](../../combat-action-design/references/acrobatic-action-design.md)和[模块库](../../combat-action-design/references/action-module-bank.md)。

## 3. 把推搡改成持续发展的对抗

合并“压进、格挡、后退、再压进”等语义重复，检查最长连续交锋簇：双方是否一直复制同样来线、防法和直线进退？若只是换招名、脚步和粒子，十秒仍是一件事被拉长，必须重编解法。让防守者主动利用低位、转轴、借力、抢侧、截支撑或既有技能改变压力；进攻者读取变化后续压或改攻，不能只让对方一路倒退。

单方压制可以持续且精彩；判据是身体路线、支撑、武器接触或控制难题是否真实发展，对手是否有尝试与被限制的原因。换手不是唯一变化，也不强制平均出手。用户已锁反转次数时照办；其余不以“每几秒必换手”代替对抗设计。

## 4. 技能必须进入实际事件

把用户要求的每项能力从正文定位到：**可辨触发/归属 → 实际作用或主形变化 → 对手同期应对 → 接收端新状态 → 下一行动**。可在同一镜里合并，不机械拆成五拍。An格式中关键作用写入S；fx-env细化同一次材料、前沿、传播和残留。只在全局技能表、招名、尾注或“剑上泛光”里存在，按缺失返修。

技能与全身动作共用时空：位移可沿既有作用开出的通路，旋身可承接已定挥器释放，翻滚可穿过正在收拢的边界；用什么由当前机制决定。不能为了凑身法让持续控制松手仍有效，也不能把法师统一改成近战。瞬发无须慢蓄力，离体作用不要求人物一直挥手，领域不要求先造实体道具；每招不强制立刻暴露并被利用的破口。反制与限制来自已定机制和可达窗口。

## 5. 震撼效果先有主事件，再有细节

用户要大招或震撼，就先设计一次明显区别于普通交锋的场面变化，让它在时间内真正展开：主轮廓/有效边界如何逼近或改形，跨多大空间，遇到何种抵抗，人物怎样在其中选择与承受。大范围请求要有已建立的人物/结构/区域参照，可同框或沿稳定地标连续接力；不能靠写一个米数或“大”字证明规模。

主作用驱动宏观介质响应，再影响人物下一路线/支撑/防线：例如已允许的风压推动连续水幕或既有霜脉改变支撑，都须由本场机制成立；不复制参考作品的水龙、城市折叠或海战。力量可以由结构变形、流体分层、区域规则、代理交互或短促高能抵抗表现，不统一为更大光球、毁楼和环形爆炸。

先交主形和变化节奏，再加碎片、烟水、局部粒子；细节有材料、流向、阶段与持续状态。风格适合时在关键相位设计冲击画的正负形、力向与曝光，写实可用形变/制动/传播承担重音。负片、抽帧、鱼眼和闪白是选择，不能每次接触全套套用，也不能白闪前完整、白闪后废墟省掉主作用。已要求冲击帧时仍须给可辨特殊造型画。见[特效语法](vfx-grammar.md)与[技能画面](ability-screen-direction.md)。

## 6. 观看与时间跟随已成立事件

关键转体/翻滚/腾跃给足能读身体路径、兵器和对手关系的覆盖，再用局部强调接触与控制，不能全程脸手特写或快切遮掉身体中段。范围展开接同次触发与人物任务；不让双方停住供镜头绕完。一镜到底、固定取景同样用画内层次与注意交接实现，摄影变化不抵偿动作变化。

按加载、爆发、交会、恢复及相容并行分配时长，留出主峰中段的读取时间。超载先删无关修辞、重复作用与多余镜头，重新组合动作，不能靠把不可能的连招塞进小数秒或削掉所需技能过关。模板/分镜请求沿An声画分栏；未指定格式沿上游默认，不由本页改格式。

## 7. 从最终正文反证

内部逐项找实际句段，缺一项就修其负责层和前后依赖：

- **全身动作**：去掉招名，是否仍能读出不同的身体轴、重心路径、支撑转换和落点？变化是否贯穿所需交锋，持械时兵器是否接得上？四个“旋身”或手脚部位计数不算证据。
- **持续对抗**：合并重复进退后，最长簇是否仍有不同解法、同期反制和新条件？换镜头或强制换手不能抵偿推搡。
- **技能存在**：每项用户要求的能力是否在正文真正发动/起效并改变对方条件？全局设定及“最多几个”不能放行零交付。
- **主峰兑现**：删掉招名、颜色和“巨大、震撼”，是否仍有可辨主变化、尺度/强度证据、抵抗和后续？只有fx-env的粒子尾注不算。
- **可行与可读**：动作中段、对手同期、控制资源、真实距离、支撑恢复、相位时间和观看证据是否同时成立？发现缺项优先改设计，不能一律收缩成站桩。

数量只核用户明确约束或用于标记需复看的过载/稀疏区间，不拿统一招数、每五秒端数或反转次数判精彩。普通创作不输出内部检查表。维护学习和验证边界见[本轮学习与反思](learning-full-body-skills-20261025.md)，文件与文本通过不证明生成成片已经达到效果。
