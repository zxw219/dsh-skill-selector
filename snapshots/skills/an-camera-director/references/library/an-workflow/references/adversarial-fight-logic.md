# 对抗性：为什么打斗像表演

用于轮流出招、对手配合挨打、攻防没有策略后果时。与[战斗逻辑](combat-logic-and-flow.md)共用角色目标、资源和时间；已锁单方压制、切磋、能力展示与结局继续成立。

## 表演与对抗的差别

检查每次行动是否改变对方可用选择，对手是否利用当时真正存在的机会，以及结果怎样进入下一任务。双方轮流获得主动权可以形成有效对抗；问题在于无因让路、复位等待和每次都按对方预案行动。

## 四个设计决定

1. **压力关系**：本段是连续压制、反复争夺、控制僵持还是追截？指出当前谁占优势、另一方正在解决什么。优势可以延续或交换，不规定30秒里多少秒必须单向。
2. **为什么现在**：读取上一拍的距离、支撑、防线、控制与目标进程，选择当前有收益的行动；避免轮到谁就出招。
3. **信息与判断**：角色根据什么判断，信息是否可靠？试探、误判、佯攻与识破按角色能力和任务选用，不强制每段都有被骗和挨打。
4. **约束与后果**：行动占用什么、放弃什么、得到什么？既定无消耗/压倒性能力可以成立，张力可来自目标、时间或他人处境，不临时添加弱点平衡胜负。

## 中线与距离（间合）

近身持械时比较双方有效攻击区、武器线、控制接触和可达路线。占线或先恢复只是可能机会；还需距离、忙闲肢体、支撑和防线允许才能起效。

长兵可控外距，短兵可争入身条件，但路线由当前武器和局面选择，不按兵器名称固定直线或弧线。出招、受阻与回收的方向应能接出下一任务，不把所有攻击都绑成同一种躯干旋转。

## 动作风格由人物决定

从人物任务、训练、性格、伤情和既定能力选择习惯：抢先、试探、护住关键部位、借环境、保持距离等，落实到具体攻击与响应。造型、职业和兵器不直接决定唯一打法；反差可以成立，正文给动作依据。

## 环境是可用条件

幕布、栏杆、台阶、门洞与地形可改变支撑、通路、视线和攻击机会。使用时写出实际收益与后果；平地、纯身体交锋或锁定场地同样可以成立，不为“用过环境”临时加障碍。

## 交稿前

- 去掉特效、台词和策略说明，正文还能看出本段争夺、压力和双方选择吗？
- 对手有可用应对却无故停机吗？失败是否有当时条件支持？
- 主动权变化有具体触发吗？持续压制是否仍在改变负载、距离或目标进程？
- 误判、受伤、反击、环境利用是本场所需，还是为清单临时补入？
- 既定强弱、能力上限和胜负保持吗？
