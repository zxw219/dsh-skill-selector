# 导演拍摄学习：来源与提炼

2026-10-04阅读以下一手访谈、作者自述及机构的公开相关文字。没有观看嵌入访谈、完整电影或会员课程；网页链接到的静帧只定位到资源地址，未完成画面分析。不是“已掌握导演拍摄”的证明。练习是原创纸面应用。

## 已完成的学习与应用

1. 从导演的实际工作差异理解排戏、排镜、现场适应及覆盖选择，不将手法清单作为学习上限。
2. 写一场原创留物/离开戏，给出人物路线、三种机位设置与可剪接顺序，比较连续机动观察的替代方案。
3. 在本例定义的二维空间里核对绕桌路线、门口净空和所选固定机位相对于人物轴线的侧别。仅是简化几何，不验证机身体积、演员身体细节、景深、布光或审美。
4. 将实际决定接入MOKE与摄影入口；拍摄说明按需展开，普通提示词保持原模板。

没有实拍/视频资料就不报完成现场排练、镜头测试、成片节奏或美感验证。以后有实际结果，再按表演、调度、取景、可剪接性定位修正，不重复追加无关规章。
