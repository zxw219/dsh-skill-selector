# 战斗写法与模板适配

## 角色适配与施法协同优先

先按[角色战法与施法协同](character-led-spell-combat.md)确定类型、主战距离与控制任务，再用本页方法。法师、召唤与领域术者不因要求高速/美感而套近战乐句或新增盾剑/晶甲；施法动作、人物与法术/代理的并行及释放后任务进入实际正文。领域要改条件，召唤要执行任务，指定大型主形要有作用与结果，不能只在共享技能表出现；近战/混合角色仍保留其相容招式。

## 奇幻快战中的摄影选择与执行

按[通用镜头语言](../../cinematic-camera-design/references/movement-composition-effects.md)先定观看效果；当前快战再按[快战执行](fantasy-fast-combat.md)落实追压、招式、短促普攻、冲击与区域主峰。快战以快速移动为主，特殊固定可承担巨型压顶、关键接触和范围传播，由导演按观看收益主动选择；不要把“少固定”解释为全禁，也不借例外把普通交锋拍成整场固定。文戏、情绪、悬念与表演采用各自观看任务，不套快战速度。正文与衔接兑现采用决定，文本/打包通过不代表成片已改善。

用于选择/改写打斗提示词模板、战术升级与角色差异。先沿用入口、[动作](action.md)和用户硬条件，再取相关写法，不把整页装入成稿。下列骨架是创作选项，不是固定剧情或模型容量证明。

## 战斗成稿：角色语言、连续事件与所选模板

用户此前要求逐句学习并“以后也这样写”，本节承接的是形态语言、连续攻防、作用反馈与时间编排。此前阶段叙述默认导致模板偏离，现恢复An声画分栏为完整战斗提示词的默认；连续阶段作为镜内事件组织，叙述格式仅在明确选用时使用。用户最新指定格式、有效的既定项目模板或局部修改范围优先；简单动作可短写，文戏不强行建立特效表。

共享设定一次，建立以下适用内容：素材身份/道具数量；角色的施法技能/神通、御器或其他战法；相应法术的发动、作用、轮廓、介质与运动；场地参照、整体视觉与声音范围。随后按真实事件安排连续阶段，每段将行动、对方响应、相位内的效果变化、摄影观看与必要声音连成叙述。阶段不是镜头数，一段可含连续调度或明确切镜；正文不能让读者靠另一个栏目猜同一次接触。

特效词汇应形成角色专属的视觉语言，按当前技能选择必要轮廓、厚薄、透光、卷边、裂纹、流向等，不填固定属性清单。具体到动作时写卷、绷、甩、切、挤压、裂开与材料响应。“有掌面与指部轮廓的火掌”不能压成“红光球”，“外显巨剑”不能压成“白色光柱”。原来丝缕/风绫只是某种特定术法的形态例，不是所有角色的默认能力。这些是形态指令；泛泛“顶级、震撼”或重复器材词仍清理。

近战、法术增强、主要释放和余波可形成强度差异，但按本场安排，不固定开场克制、末尾才大招。形成、释放、受阻/接触与结果的时间含义不同；巨大存在要进入人物正在争夺的空间。负面约束只针对本场偏离，与正文里的具体修法对应。作品名需要时限定借鉴对象，不要求每稿加游戏名。

### 身体与招式差异必须进入事件正文

角色表可以概括战法，正文要写当前进入、身体/兵器路线、对手响应和收势如何形成下一动作。近身、远程与施法转换由上一结果创造距离和资源窗口；指、掌、印、器物或念动采用既定发动条件，不全写成站直伸臂。美感需要轮廓、开合、部位领随和轻重的实际转换；精准措辞不能把过程压成“挥砍、躲开、释放”。方法见[动作词汇、组合与身体美感](../../combat-action-design/references/action-phrasing-and-aesthetics.md)，完整文本校准见[动作成稿练习](action-diversity-lab.md)。例稿的秒数/动作数、拳腿选项与镜序不成为通用要求。

### 技能差异必须进入事件正文

共享技能说明建立本场实际用到的触发与作用，正文再兑现使用：被动由条件触发，不改成一次结印；主动开启后的状态跨段继承，不重播启动；标记/布置/召唤的运行和后续利用有来源与新结果。施法、施放、生效的身体/效果/接收端相位接在同一时间内，恢复、感知与场域也有可见作用，不只交代攻击。

需要丰富机制读[技能体系与状态](ability-system-design.md)，需要镜头/运镜展现读[技能画面与摄影](ability-screen-direction.md)。把所选触发、主变化、交互后状态和摄影写成连贯行动，不能共享设定很丰富、正文仍每招“发出—格挡—炸开”。已有模板继续使用，不按新分类增加必填栏目。

### 可用的完整组织

以下是明确选用阶段叙述时的组织示意，不是MOKE默认交付模板，也不可原样提交占位稿；默认分栏依主入口，角色/技能/场面进全局，阶段事件进S段：

```text
时长、媒介、必要视觉与声音范围。
【角色与战斗语言】
真实素材引用、身份与持物；当前角色的施法技能、御器或其他战法。
需要法术时写发动方式、直接作用、生效位置与终态，再写该法术的主形、介质与运动。
【场面与摄影】
必要地标、空域/通路、尺度参照和主要观察方式。
【起–止秒｜本阶段实际变化】
相连行动与对方应对；特效在动作相位中的形态与接触变化；相机如何读到；允许的声音随事件发生。
【后续阶段】
继承上一段的距离、动势、残留与破坏，接出新的争夺和结果。
【负面约束】
当前需要保留的具体禁止项。
```

声音可全局限定并在段内自然交代，逐字台词仍注明说话者与原词；无需为接近样本而新增音效。结果是唯一完整正文，不同时交“总合成”再重复整场。内部各板块仍有分工，最终不拼贴多套说明。默认An声画分栏把同样的视觉语言与事件写入画面、S、fx-env、sound和真实transition；只有明确采用叙述格式时才按上方示意合写。

连续事件与形态语言学习例见[28秒仙侠阶段叙述](battle-prose-example-28s.txt)，该例不是默认外层格式；默认声画分栏结构按主入口模板，须将所学内容写入相应栏目。人物、能力、秒数、阶段数、飞行、巨剑与结局均为这份例稿的设计，只学习其表达方式，不成为所有项目固定内容。

## 全面原文学习与精准写法

全面学习文档时，使用[写法架构与逐句用途](reference-prompt-writing.md)及其逐段分析，确认稳定资产、道具职责、场地通路、角色战法、压力阶段、动作/技能相位、摄影与结果如何协作。边写边判本句控制对象和实际用途，再以当前角色/场地成稿。保留源稿有作用的形态、运动比喻、技术审美词及必要限制，补原文未确定的当前武器选项、作用/落脚点、让线路径和跨镜状态。

当前保持`fx-env：`、`sound：`、`transition：`，共享职责分区与镜内连续阶段共存。精准句不能只剩招名与快/帅：谁以什么有效部位从当前状态进入哪个对象，对方如何应对，结果如何接下一招；景别与运镜名称同时给出观看关系。原句用途分析只在学习交付中展示，普通视频提示词不夹批注。两份原创分栏演练在参考页可按问题读取，不作为固定秒数、镜数、人数或结局。

## 画质、物理、规模与快战一起编译

采用[战斗视觉与高速摄影](battle-visual-direction.md)的四层全局：画质与具体材料、环境底色与双方能量受光、动态随动和破坏残留、战斗层级。写入当前全局一次，各镜S承载抢线/反击/形成/施放/作用，fx-env承载同次照明与物理反馈，镜头描述承载起幅、触发、路径和落幅。简洁不删用户画质词、有效攻防或尺度结果；不用全局规则齐全代替镜内发生。

快战可在同镜衔接斜面导开、抽刃变线、追步与对手反击，在来刃在途或接触相位换观察，不按两秒一招或固定六镜设计。前景武器/地标、中景身体、后景目标形成可读纵深；短弧、侧后跟拍、甩镜与范围退拉各有事件。共享全局与原An分栏保留，不能把参考的全圈环绕、神祇结局、画幅或角色机械移植。

## 模板规格怎样进入生成正文

模块化模板可提供身份/资产、战法、视觉基线、场面层级与出口规格；自然段可提供鲜明场景意象；分段稿可提供压力变化。只采用当前任务有效的设计，不把样本角色、黑白配色、全命中、固定时长/帧率、镜头贯穿要求或负面词自动继承。

编写时把规格与发生过程分开，交付仍是一份用户指定格式的正文：

- **全局共享**放稳定身份、真实素材引用、武器实体数量、已设能力、环境/媒介及声音范围。选项在授权创作空间内择定；锁定事实不擅改，缺少参考不虚构编号。
- **逐段事件**兑现谁用哪个有效部位沿什么路径作用于当前目标、对方怎样回应、武器/距离/通路怎样改变；镜头与效果跟随实际变化，不以一串招名充当交锋。
- **出口**只说明本次已经兑现的优势、胜负、揭示与剩余状态；隐藏部分按观看意图保留。

设计规格只在需要时补足，不强制每稿交角色表、效果表、前置方案或总合成。已有栏目优先；“总合成”作为唯一简洁成稿可用，已有逐段稿后不再无要求重复完整剧情。技术/质量标签转成可见材质、光色与成像意图，不当作工具已执行的证据；限制项保留具体易偏离点，不逐段复述整套禁令。

## 1. 先区分事件，再选压力变化

- **双方/多方对抗**：攻击、应对、再应对共享时间；结果改变距离、角度、支撑、控制或目标可达性。防守连续受压也能成立，不必平均出手。
- **单人演绎**：没有对手就不制造受击者；以路线、姿态转换、兵器相位和环境响应表达完成度，不为了近身连招配额添加敌人。
- **形态变化/召唤**：起态、变化前沿、足够辨识的终态及新能力介入连续；不强制头部最后变化，不因为“变身”就自动延长或暂停战斗。

压力曲线描述本轮争夺的变化，不负责重排已锁事件。可选：

| 当前看点 | 变化骨架 | 实际需补的因果 |
|---|---|---|
| 持续压迫 | 尚有退路 → 应对使路线收窄 → 被迫换招/承担结果 | 哪条路被谁怎样封住；不能只让守方越来越狼狈 |
| 诱导反击 | 让出角度 → 引出承诺动作 → 脱线/牵引 → 利用回收窗口 | 诱饵可见，攻击者仍有可执行回应，不无因冻结 |
| 拉锯调整 | 原方案受阻 → 改距离/路线/节奏 → 新方法改变局势 | 不机械轮流打一下；改招来自具体阻力 |
| 追逐截击 | 距离差 → 通道选择 → 提前占位或错失窗口 | 跑动和镜头分别可达；不是靠残影瞬移到终点 |
| 群战破围 | 多向逼近 → 利用身位/障碍重组威胁 → 撕开出口 | 其他敌人持续推进、绕行或受阻，不能排队等击倒 |
| 能力争夺 | 第一作用 → 破解留下改变 → 利用或对抗改变 → 新结果 | 可以利用破口、落点和通路；不强迫失活余光继续伤人 |

压倒性胜负、失败大招、无反转及开放结尾按原要求保留。密度来自相互依赖的连招与少空等，不以“4–6节点”“3轻1重”或每秒命中数作合格线。强度也可来自更精准的封锁，不必越来越致命或越来越大。

### 优势、胜负与观看出口分开

用用户锁定的关系决定本场进程，而不是由特效亮度或跪姿推导结果：

| 本场要求 | 正文要兑现的证据 | 避免误写 |
|---|---|---|
| 占上风、对方未败 | 追击/封线/迫退体现优势；守方仍完成指定应对，保留可用兵器、支撑或继续行动 | 每招平均夺回主动权；为显强临时把守方写成败者；用一句“未败”覆盖已失去全部行动的事实 |
| 明确获胜/失败 | 既定终结条件实际达成，随后保持该结果 | 因偏好开放结尾重置战果；高潮后无因补一个敌人再试探 |
| 结果隐藏 | 主作用与可见环境结果成立，取景/遮挡在揭示前控制可见范围 | 旁白或效果栏提前断言未展示的死亡、伤势或胜者；随后又补胜利摆姿 |
| 动态余波/继续交锋 | 保留已造成的损伤、残留、双方当前行动与可用空间 | 换镜恢复原地形；强迫等待尘雾全部散尽；默认共同摆姿收尾 |

“被压制但不失风度”可用紧凑回护、卸力后接重、持续判断与反制企图表现，不要求人物永远不退、不喘或不受力。明确静止、对峙、终结定格按用户目的保留。出口若隐藏身体状态，只继承可确认的事实，不能把不可见当作未受伤或已死亡。

## 2. 每个角色有自己的行动语法

在稿内简记：`目标/主战方式 + 进入有效距离的方法 + 发力/动力 + 防守与回收 + 武器/法术职责`。服装与外观仍按参考锁定，不为对比强行一黑一白、换体型或换武器。

机械战士可以用短距加速、关节制动和准确追线表现精密，也可用承重、转体负载表现重装；没有既定推进器就不新增喷口。修仙者可以用干净步法、御剑控线和法术封路，但飞剑/御剑须继承实体剑数量与控制归属。高速、御空和巨物不强制站桩或匀速漂浮。细则见[运动语言](motion-language.md)。

题材词按主体和源头归属，不按全场单一词库删词：机械与仙子同场时，伺服声属于机械关节，符纹属于既定法术；两者可作用于同一石台。雨夜霓虹不自动赋予普通人EMP，古装也不自动赋予飞行。技能克制、吸收与破防依据已有规则，不由颜色决定。

从兵器库取条目时，提炼有效部位、握持方式、攻击体积、距离、扫掠净空和回收窗口。招名只辅助识别；专属角色的能量弓、时停、分身和数值层数不自动迁入新角色。未经核验的“正统/实战必杀”说法不当事实。

### 气质与武器职责落实到行动

角色的“狂烈、克制、精密、轻盈”等气质，选择能在动作中辨认的表现：连续追步压缩回收窗口、用小幅偏转保住中线、借支点让出攻击体积后再入线。气质可与当前压力一起变化，不机械固定所有狂烈者大开大合、所有克制者只防守。

一个武器可有多种已设用途，例如伞面的遮挡/偏转、长柄的控制、伞心的传导；在具体段中选当前有效部位并补功能转换。姿态、握点与占手继承，转换期间对手仍有行动；“武器同时承担多种职责”不等于同一只手能同时完成互斥任务。普通武器不会因角色气质自动具有法术。

用一段真实交锋呈现差异：压线者的推进怎样逼对方改角度，精密者怎样在有限空间保持应对，下一招怎样继承。外观与效果能提示角色，但动作全部一样时，不能靠一黑一白或不同形容词宣称战法不同。

## 3. 场地分区让风格冲突产生战术

先选实际影响路线的区别：干/湿、开阔/狭窄、高/低、可承重/已破损、遮挡/暴露；不强制左右两种天气。明确谁当前受益、谁要把对方逼入哪个区域，以及越过边界后什么动作改变。

例如：长刃一方试图留在开阔石台，短刃一方沿廊柱逼近以压缩其横扫空间。长刃者可换直刺、退到开阔处或借纵向招式应对；不能因靠柱就突然不会战斗。水深、摩擦、障碍与能力只采用已设性质，不把苔藓默认当防滑材料。

具名关键对手用可辨外观与持续状态；匿名敌群按区域、来向、当前威胁组织。身份相似的制服/克隆保留设定，用位置、装备状态或动作职责区分，不强迫每张脸不同。画外威胁可用可感知的影子、脚步或边缘运动预告；有意伏击允许不预告，揭示后仍须有可达入口。

## 4. 可替换的交锋句法

方括号是编写时的槽位，成稿填成具体事实后删除。骨架可落入用户现有模板；MOKE仍使用全局、镜头/画面、S、fx-env、sound和真实transition，不叠加第二套固定栏目。

**近身拆招与破防承接**

```text
S：A沿[已可达路线]以[在用肢体/武器有效部位]攻向[明确区域]；B在[起手/在途/接触阶段]以[让线或接触方式]应对，同时[可并行换位]。这一接触让[手/武器/支撑]处于[新状态]，A/B利用[真实回收或脱离窗口]接入下一招。
fx-env：[接触处的材料响应]与[必要环境痕迹]，不每击加爆炸。
sound：[该次接触与步法实际声源]，遵守项目配乐/静音要求。
```

破防示例：B的剑身被压向身体外侧，B先向后撤步并转肩让开紧跟的刺线，同时把剑回收至可护身的位置；A追步改变刺线。不能下一句B已经原地完整架剑，也不能让所有破防都固定持续半秒。若B失去行动能力，就继承结果，不补无意义闪挡。

**巨物或范围技争夺**

```text
画面：[人物与稳定建筑/地标]建立尺度，[源头、目标及可用路线]的位置明确。
S：[形成/介入前沿]逼近，[守方已在执行的行动]与施放同一时间推进；攻击到达[接触区]造成[主作用]，[裂口/遮挡/支撑/通路]随之改变。双方分别[利用/应对改变]，下一招从剩余可达关系接入。
fx-env：[主形体和传播]、[接收材质响应]、[仍在运动或持留的残留]。
```

选镜按证据分工：低位广角读压顶与尺度，斜侧关系镜读避线和接触，结果广景读封路/突破；不强制五镜、慢蓄力或每镜完整打一遍。小人物须有可辨参照，镜头贴着剑飞不能取代目标距离。大招可以失败、被偏转或逼出代价，不默认清场。

**追逐与场地换区**

```text
S：[追击者]连续跨越[固定参照]缩短距离；[被追者]在[可用节点]换向/借力，把路线引向[已建立区域]。追击者因[武器长度/支撑/视线]改用[可执行应对]，双方以[新位置/距离/动势]接下一拍。
摄影：[起始机位]沿[可达路径]跟随[主体/关键距离]，在[变化触发点]重构画面；换镜继承同一动作相位。
```

**单人武学与形态变化**

```text
单人：起始持物/支撑 → 发力与兵器线路 → 换步或回收使下一式成立 → 用户指定出口。衣袖与发丝只显示各自滞后、回摆和碰触，不代替身体运动。
变化：原形与源点 → 变化前沿及局部新状态 → 未变与已变区域共存 → 完成后获得已设功能并继续动作。实体分解时不保留全量原物及全量副本。
```

## 5. 声画反馈与连锁，不堆满每一拍

衣料、发丝、水面和碎屑是辅助证据：指出受什么动作影响、方向如何变化、何时回摆/落定。湿布料可能贴附、阻尼变大，不一律飘得更远；旋转不自动生成稳定雨环；普通挥刀不必出现一米水墙。夸张介质响应需属于既定媒介或能力。

把上一招留下的改变交给下一招：盾面缺口改变防御，飞剑已占的线路限制转身，落石改变落脚区。若要残弧重新攻击，必须已有再控制能力、仍有效的载体与接通路径；被破解的技能也可真正结束，以新距离承接，不强制每拍法术复活。完整交互见[粒子与技能展示](particle-spell-design.md)。

画面变化先成立，声音再对应具体来源；声音可以预示画外威胁。静音、配乐、对白按任务保留，不凑5–7或10–14项音效。冲击帧依[分镜视觉](storyboard-visual.md)强调实际状态突变，不借其隐藏动作，也不因素材写了“不能慢打”就禁止所有短促重音。

## 6. 模板输入与返工边界

用户给锁定动作链时，只补使原事件成立的支撑、来向、对手回应、接触释放和摄影；补的反制若改变胜负、能力或出口，就不是微动作。粗略灵感且允许原创时可设计多轮变化，不受来源“只能一个结果”限制。

用户点名采用某模板时保留其栏目和表达习惯；仅提供研究样本不等于授权改变默认格式、对白或生成单元。没有素材不写虚构@编号，头像不锁定不可见全身。来源中的平台上限、参考数量、整数时间戳与成功率须另行核验，不能据此擅改当前任务。

返工先定位最早错误及影响范围，修好后检查下游；多个独立错误可同轮处理。先辨认欠写还是超载，不能把摔投自动换成推撞、把巨物缩成局部烟花、让三人围攻变成排队，再称“优化完成”。

## 7. 把参考、特效与负面约束编成指令

### 作品参考：写借什么，再兑现

作品名是风格定位，后接本场要借的行为或观看关系；具体动作仍按当前人物、持物、场地和出口设计。比如“参考《影之刃零》的贴身兵器追压与快速攻防衔接；攻方在守方撤步时追入回斩，守方偏刃卸力并沿外线反切，攻方回护后继续压近”。后半是本场原创编排，不宣称观察到原作的同一招。

只给作品名或主创文章时，可以按已知意图提出设计，不能编造片段时码、逐招观察或实测速度。提供实际视频时按[战斗参考迁移](combat-reference-transfer.md)记录观察范围。艺术方向、动作逻辑、摄影或效果形态分别择取，不把作品名当全套身份、武器、法术和结局授权；样本中黑羽残影、银弧和真空线是样本自身设计，未经证据不能称为原游戏机制。

### 特效：主形跟着有效动作走

在需要辨识角色技能时，确定源点、主要轮廓/介质、怎样随动作变化、接触怎样起效、解除后留下什么。必要形状、材料和方向要保留，不以删名词为由只剩“放技能”。共享规律写一次，镜内写实际释放与作用；瞬发不强制先蓄力，普通近战不强制每刀爆炸。

- **近战附着**：例如“黑墨细带接在刀背，随追步回斩弯向刃线；刀停转后旧带沿原路径散开”。源点、转向和残留有关系，不是绕全身无目标飞舞。
- **释放传播**：例如“刃尖划出薄银弧，离刃沿挥斩方向扩展；遇伞面后弧面折偏，扫断侧后石柱”。主形、对手干预和结果连成一次作用，不先爆炸再补命中。
- **法相介入**：例如“伞轴上连裂隙中的腕骨；女子转伞，掌缘随之侧压，挡住剑客退路；剑客斩开指缝并换线”。操控与防守者行动共享时间，显化不是暂停战斗的展示。
- **材料质感**：例如“伞骨受压弯曲，湿布拉紧；裂口漏光照进积水，碎砖沿掌压方向掀起”。软件、渲染器、分辨率与胶片名不代替这些动态结果。

以上是可替换的原创方法例，不能自动并入当前项目或创造未授权能力。伞、剑、巨掌只是样本对象；应把方法转成当前实际角色与道具。颜色只负责区分的一部分，主形、介质、动作绑定和作用不同才有技能身份。

### 负面约束：保留要求，正文给解法

负面约束能点明用户不接受的偏离。不要因强调正向描述就删除用户明确禁令；也不要把新增禁令当作已修好的动作。先修对应正文，再在全局或末尾保留本场必要的短约束。

| 已提出的偏离 | 正文补足的执行办法 |
|---|---|
| 慢吞吞、站桩、摆姿后才继续 | 明确同一时间中的追入与应对，动作出口直接接下一招，借固定参照和相对距离体现速度；仅在快战目标下采用 |
| 长时间顶刀、回合式互打 | 接触后偏刃卸开、换步让线或继续传力，对手同时回护/续压；不靠“迅猛”掩盖重置 |
| 乱飞、无目标环绕 | 相机在具体通路跟随要读的交会点，写清触发后的落幅，视线被遮时改机位或切镜 |
| 满屏光团、廉价光炮 | 建立已要求的线/面/实体主形，作用路径与接收端有辨识，次级光雾不遮住关键关系；用户指定光炮时仍保留 |
| 巨物像背景摆件 | 局部与已知参照比较，威胁侵入可用天空/通路，小人物为继续行动付出具体代价 |
| 无接触先爆炸、环境复原 | 攻击到达作用区再写结果；下一事件沿用裂口、障碍和残留，除非既定能力使其复原 |
| 塑料感、效果同质化 | 写当前材料受光、负载、摩擦与滞后的区别，角色技能分别有形体和运动规则 |

样本一的“禁止黑白/二维冲击画”属于那份写实任务；不能覆盖当前用户明确要求的冲击帧。样本二的“杜绝慢吞吞”属于快战目标；不能用来禁止另一项目的慢镜、停顿或仪式。资产名、30秒、人数、武器选项与胜负同样只按当前授权采用。

### 学样本的句法，别把视觉语言压成泛称

用户要求逐句学写法、或反馈“框架齐全却不像示例”时，直接对照影响当前成稿的原句，分别识别它写的实体、形态修饰、运动动词、比喻、动作相位与观看变化，再用当前人物/场地重写。仅提炼成“源点、路径、结果”的说明不算完成语言迁移；对照需要看到实际前后句，不能只报告读过或添加一份分类表。

精准保留有画面作用的修饰与比喻。例如“黑色丝缕状刀气”“极薄的银白真空月牙斩”指定了颜色、厚度、边界与主形；“阴影被刀锋甩出来”还指定了源点和运动。“高级、顶级、视觉炸裂”等泛评语可以压缩，但不能把整组效果都统一删成“能量、刀气”。同物统一名字不等于删掉必要形态。先建立角色特效的形态体系，在动作相位内写卷、绷、甩、切、挤压、裂开等实际变化，再按当前媒介补接收物的响应；数量按观看需要，不默认每击凑全部层。

某丝线术法的形态练习（仅确已采用该能力时）：“她反转手腕，赤金丝缕沿掌缘拧成裂帛状风绫，斜切追来的剑锋；剑锋压入后，风绫褶皱收紧，断开的金箔薄片沿斩线翻散。”主体与作用仍清楚，同时保留介质、造型和接触变化。不可只改写成“她释放能量，挡住攻击”。粗光球或光柱不是这种形态的等价替换；用户明确指定它们时则按其风格设计。

分清**形成的可读时间、释放的速度、接触负载和余波**。写“急落”却跨多个阶段持续下降，仍可能形成慢吞吞的设计；应从全片实际事件安排里改，不能只加禁令。镜头围绕交会、人物路线、威胁逼近和规模揭示变化，不为让句子更有气势堆穿越机名称或无目的转圈。文戏、慢镜与仪式照用户目标采用。

用户明确要求按样本写法重写时，采用其适用的句法和叙述方式；仅研究样本不自动换掉已锁模板。人物、器物、能力和结局仍按当前项目；用户明确采用的技术审美词保留并对应可见材料/光色/成像，按媒介适配，重复或互斥内容才清理。当前稿仍要完成动作承接与观看体验复核，学习批注不能代替成稿。

## 分栏、阶段与精准：分别判断

用户在2026-10-07追问为什么取消分栏、这样是否更好。本轮重新读取其Downloads/已粘贴的文本.txt：第一份按资产、整体视觉、战法、事件阶段、特效层级、运镜、声音和负面约束分区；第二份按角色/特效体系、战斗关系、时间阶段和约束组织，并在阶段内合写动作、效果与观看。两份都未采用S/fx-env/sound，但保留职责分区；这仅是文档观察，不证明一种结构的生成效果更好。

此前把“以后也这样写”落实为阶段叙述默认，是本工作流的实现选择，不是用户明确要求一律删除分栏，也不是模型性能结论。继承有效的既定模板；学习形态词、动作绑定、接触反馈、释放相位和负面约束不自动授权改格式。

区分三个层次：角色/技能/场地等共享分区，时间阶段的事件组织，以及镜头内S/fx-env/sound的职责分栏。它们可以共存。角色能力规则只写一次，每个真实镜头建立观看关系，镜内用阶段写连续事件；所选分栏分别承载行动、效果环境与声音，必要时间锚点对应同一次作用，不因分栏而把动作/效果排成先后三个回合。

分栏的实用收益是便于发现遗漏、局部返工和核对声画锚点；连续叙述便于读一条动作因果链。以上是编辑与表达层面的判断，不能据此保证模型服从或优胜。两种写法都可能重复、冲突或欠写。精准删除同义夸赞、互斥命令和无作用术语，保留决定当前形体与作用的词；不以删除标题、压短字数或合并所有内容证明更精准。

### 同一事件的两种表达（原创文本对照）

连续叙述：4–6秒，相机沿桥侧跟移，保留桥尾两人的距离。白发踏步横斩向黑发胸前，赤黑弧形刃面沿斩向离刃；黑发从右侧桥栏跃出，刃面掠过她离开的空位切断栏杆，断石向桥外翻落。白发沿桥面追近断栏口。刃风尖啸接石块断裂声。

职责分栏：
```text
【镜头：4–6秒｜桥侧跟移｜读清出栏路线与刀气落点】
画面：黑发在桥尾，白发沿桥面追近；右侧栏杆外是云海。
S=4–6s：白发踏步横斩向黑发胸前；黑发从右侧桥栏跃出，白发沿桥面追近断栏口。
fx-env：赤黑弧形刃面沿该次斩向离刃，掠过黑发离开的空位，切断栏杆；断石向桥外翻落。
sound：刃风尖啸接石块断裂声。
```

分栏例的fx-env细化同一次横斩，没有另起手、再发射或让声音触发攻击；它与叙述例共享人物、路线、作用和出口。这里只证明可以在文本层对应，不是同模型/素材/参数的生成A/B测试。静音、固定镜头或不同媒介时替换当前条件，不复制例中声音、场地和能力。

有实际生成验证授权时，保留同一事件与提交条件，比较双方位置、动作次序、接触、技能主形、目标回应、镜头和声音执行，再根据真实偏离修稿；无试片就报告文字复核，不能宣称取消分栏更稳定。
