# 整场戏的导演语言

用于整体导演功底、场景设计、观看视点、调度、光色、剪辑和声音的协同设计。学习范围不以用户列出的技法为边界；本页按观看问题组织方法，具体摄影选型仍读已有摄影模块。保持用户的剧情、台词、媒介、时长与声音要求，不将补课变成擅改剧情。

## 从场景变化到观众体验

先确认本场发生什么、人物想改变什么，以及观众进入与离开时如何理解这件事。观众可以比人物先知、同知或后知；也可保持含混或只是感受时间/空间。选此刻的立场，而非先选择炫技手法再寻找理由。

“观众知道”和“角色知道”分开。观众先看见门后等待者，不代表主角已经知道；切到某人视线附近，不代表它就是字面主观镜头；跟拍一人也不代表整场禁止其它视点。必要转折写清哪条可见/可听证据使理解改变。纯氛围、音乐或图形片按感官与节律组织，不强加秘密和反转。

不要求每镜带来新事实。镜头也能维持期待、改变参与距离、让关系被承受、比较两种状态或形成图形节律。问题是它在此处怎样工作，而非解释能否贴上“推进剧情”。

## 场面调度：让关系发生在空间里

相机先面对人物任务、地标、出口、共同物件与障碍。走位改变的是接近/隔离、让路/封路、共同区域/分离区域、主导/退让，而不是为了丰富画面随便走动。演员行动和相机路径分别可达。

| 可改变关系的方法 | 稿内要确定的实际变化 | 适用与代价 |
|---|---|---|
| 纵深调度 | 谁从远层进入近层，体量与遮挡怎样变，关键行为在哪层发生 | 可以在一镜内转交注意；靠近者可能盖住远处证据 |
| 横向调度/出入画 | 谁占据共同区域，谁退出，留下的空位为何有作用 | 固定画面也可发生权力或亲疏变化，不必追着离去者走 |
| 挡与露 | 已有身体/家具挡住什么，何时移开，揭示后留多少读取机会 | 控制信息顺序；不能隐藏用户要求读清的表演或必要接触 |
| 停与动 | 何人继续任务，何人开始行动，运动的对比怎样转交注意 | 不让所有背景人物同时动来证明画面有生命 |
| 共同任务/道具 | 谁接重、握住、放回、让出或收回，如何改变对方的选择 | 局部动作可承担潜台词，不因细节漂亮就拍无关物件 |

持续画面可通过近远、遮挡与重心变化组织观看；这不是所有长镜必须采用的配方。[Bordwell 的原始研究](https://www.davidbordwell.org/essays/nordisk.php)支持这种空间与时间联动的认识；本表为工作流应用。

## 覆盖与视点：决定看谁、漏掉什么

- 同框、越肩、单人、局部插入、主观、反应、环境与画外空间按证据分工，不默认先大全景再交替头像。
- 长镜把注意交接留在连续空间；切镜可以重新选择距离、重心、时刻或关系。二者比较读取、表演、空间体验与节律，不按镜头长度判高级。
- 主观镜头要有观察者位置、视线对象和可见范围；主观感可以通过声音、距离、色彩、焦点或持续时间实现，不必须模拟眼球。
- 画外空间要在既定地理/声音/视线中有依据。隐藏某人是导演选择，不能让其在下一镜突然获得此前不可能知道的信息。
- 情绪可由行为、关系与镜头并置读到，不要求角色用脸演完所有心理。但用户指定的关键面部变化仍需可见，不能借蒙太奇取消。

Hitchcock 的自述将局部与人物的观看顺序用作心理表达。[原文](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)也带有其个人偏好，不能推导通用禁长镜。

## 剪辑：相邻画面怎样产生意思

先确定切前期待、切后证据及两者关系。硬切本身可以强烈或柔和，叠化也不自动诗意；技法名称不替代相邻首尾画面的设计。

| 方法 | 选择依据 | 必须兑现的关系 |
|---|---|---|
| 连续动作切接 | 不同位置各读一个动作阶段 | 接剩余动作与结果，不每次重新起手；必要重叠需有明确表现意图和计时 |
| 视线/反应交接 | 人物判断或观众注意转移 | 看向谁/何物，何时理解，为什么此刻看回应；空间与知识成立 |
| 局部/关系并置 | 让观众从画面关系推断意图 | 局部不是随机装饰，前后关系可成立；不把某人的中性脸解释成已经改变表情 |
| 图形/动作/声音匹配 | 跨时间、地点或主题建立相似/对比 | 明确匹配项与变化项；剪辑跳时空不等于现场换装/变身/瞬移 |
| 跳切/省略 | 省去过程、产生断续或主观时间 | 省略的是哪一段，剩余状态如何解释；关键因果不可无说明消失 |
| 多线交错 | 比较、逼近、误导或表达并行事件 | 声明真实时间关系、观众暂时判断和揭示依据；不能仅因交替剪辑就认定现场同步 |
| 突然硬切/对比切 | 笑点、惊变、反差或段落断裂 | 切前已经成立什么预期，切后怎样改写；不等于凭空添加响声或反转 |
| 长镜/重复镜位 | 持续观察、承受、仪式、关系回返 | 哪个过程持续，重复时含义怎样继承或变化；允许纯节律重复 |

定义参考 [Adobe：剪辑类型](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film.html)；多线关系另见[交错剪辑说明](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/cross-cut.html)。页面对术语和例子有简化，本工作流以实际事件时间与观看顺序为准，不照搬未观影片举例或来源中的相互矛盾定义。

剪辑节奏不只看镜长：镜内运动、表演变化、信息到达、景别差、图形方向、声音密度都影响感受。短镜不自动快、长镜不自动慢。需要急迫时，先让等待和行动有压力，再设计信息交接；不靠平均切碎场景制造紧张。

## 声音也是导演，不只填 sound 栏

区分同场可听声、画外同场声、下一场预入声、上一场延续声、角色主观处理、旁白与音乐。按用户获准的声轨选择；无音乐/完全静音不可被技法模板恢复。

- **J cut**：下一镜/场的声音先入当前画面；写清谁发声、何时开始、属于哪个空间，角色是否实际能听见。
- **L cut**：切走画面后原声音延续；适合在听者/结果上持续原话，不让切镜造成重读或漏词。
- **声桥/声音匹配**：同一声或相似声音连接不同画面；相似音色不自动表示同一真实声源。
- **主观声音**：可按风格选择压低环境、强化某个已存在的声音、失真或突然切断，须有主观立场与返回；不为每次震惊加耳鸣，不擅改医学事实。
- **静默与密度**：静音、环境底声中的无对白、角色停止说话分别描述；安静可让期待集中，持续密集声也可成为表达，不规定统一“高潮先静音”。

J/L 定义见 [Adobe 官方说明](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/l-and-j-cut.html)。声画错开只改变交接时刻；同一个声轨持续时间按全片计一次，不能把镜外提前声音额外加到影片总长。普通创作将声源与时刻写回原 sound/transition，不新增第二套时间轴。

## 光、色、焦点与美术协同

先决定本场视觉基线、可见证据和环境规则，再选择真实光源启发或有意表现性光色。亮暗、焦点、颜色和服装/背景可以让注意集中，也可以保留多层关系；不自动所有背景虚化、全片蓝橙、轮廓逆光或胶片颗粒。

复杂清晰层、镜面、剪影、表现性光与镜头质地按需读[焦点、光色与成像](../../cinematic-camera-design/references/focus-light-image.md)。美术可配合路径和光区，不能为漂亮任意挪动既有出口、修复已破坏空间或改变道具状态。

## 整场语法与视觉母题

在稿内选择与当前作品相容的主要观察方式、空间秩序、光色/焦点策略及节律；不是每片必交四项声明。转折可改变其中一项，基线也可持续不变。风格化与写实各有合法语法，不强迫每种手法都有物理动机，不用跨风格禁令磨平用户意图。

反复出现的门、空位、颜色、声音、动作或视角可以承担母题；再次出现时检查它如今指向什么，是否只有重复好看。母题可保留含混，不强迫象征解释；已锁剧本没有相应物件，不擅增关键道具来套练习。

题材不是手法套餐：悬疑可由画外、信息差、空处与时间承担；喜剧可由完整关系和迟到的反应承担；亲密可用近距宽视场或较远观察；动作可用固定、长镜或多机位。先解决当前场景，不把一部名片的语法泛化为整个类型。

## 编译与验收

只把实际选定的决定回填全局、镜头头部、画面、S、fx-env、sound 和真实 transition。理由、替代版本与研究记录留在稿内；用户要求学习/诊断才展开。普通短片不加载所有新模块，遇到相应关系问题再补读。

复核整场：观众何时知道/感到什么；人物如何改变空间；镜内或跨镜注意如何交接；光色/焦点是否允许读到证据；声画与真实时间是否相容；主要重音是否兑现请求。文字关系、数字和文件结构通过不能证明美感，有成片再按正常播放与必要逐帧观察修正。练习见[整场戏对照演练](scene-grammar-lab.md)，来源范围见[本轮学习记录](directorial-study-notes.md)。

## 预期、判断与画外时间的推敲

关键转折先决定观众与人物的知情差、实际证据、判断怎样改变任务，再决定揭示/反应的距离与切点，按[信息覆盖](../../action-camera-direction/references/information-led-coverage.md)选择适用关系；不把切脸视为战斗暂停。采用决定按[导演推敲](director-deliberation.md)回到正文验证，纯氛围/同镜展示不强造反转。
