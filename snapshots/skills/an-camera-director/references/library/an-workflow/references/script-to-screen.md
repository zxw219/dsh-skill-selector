# 剧本转剧情提示词

适用于已有剧本、多场叙事、对白、误解、发现、悬念和关系变化；无对白剧情同样适用。先完成本页的转换，再按实际缺口读表演、空间、摄影或平台资料。用户只改摄影时继承已有事件，只检验拍得到与承接，不自行补写剧情。内部记录只保留会影响结果的关系，普通交付不附分析表。

## 先保住原剧本

通读当前交付范围及影响其入口/出口的相邻内容，把原文分成三类：

- **锁定事实**：人物、场次/昼夜、事件及先后、谁在场、关键道具、逐字对白及说话者、揭示/结局、声音和时长要求。保留“不知道、没听见、没交出、尚未发生”等否定事实。
- **可设计的呈现**：未锁定的取景、切点、相机路线、相容表演、信息的强调方式。不得借近景提前展示原文要求后知的证据。
- **缺口**：完成已写事件所必需、但原文未说明的通路、动作衔接或声源条件。获准创作时补最少的相容条件；不新增关键证据、秘密、人物关系、能力、对白或反转来圆逻辑。原文互斥且不能在授权内解决时，指出具体冲突及影响，继续不依赖它的工作。

场次、戏剧节拍、镜头、生成单元分别判断：换地点/故事时间才是场次变化；诉求、认识、策略或关系发生承重变化才是节拍；观察任务和切点决定镜头；平台容量才决定独立生成单元。不能把每行剧本、每句话、每个动词直接切成一镜，也不把整场对白硬包在一镜。

多场任务先确认全部场次与结尾都被覆盖，再细化。篇幅较长时只给当前必需的工作记录，不用一场精写冒充全剧完成；交付范围与续写边界遵守[容量与项目](project-control.md)。

## 事件因果与知情顺序

沿原文为关键变化保留一条短链：

`入口状态 → 当前尝试/持续任务 → 实际抵达的刺激或信息 → 角色接收/选择 → 可见结果 → 下一入口`

它是检查依赖的工作记录，不是每拍必须六步停顿的表演配方。坦率交谈、持续等待、直接行动都可成立；不强造反转和抵抗。

每次认出、误判、转向、追问或改变行动，分别核：事实何时存在，观众何时得知，当事人经视线/声音/触碰何时能得知。观众看到了不代表角色知道，角色知道也不代表观众已经看过。电话另一端、隔门者和背对证据的人分别成立；作者写“她明白了”不足以支持提示词里的反应。误解允许延续，悬念允许不解释，但下一步必须符合角色此刻可得的信息。

原文“没交出”就不能在插镜变成已交接；“听见才回头”就不能先回头再补声源；“先看空袋再停手”就不能先惊愕再首次揭示空袋。反应先于对象是可选摄影语法，仅在原文允许这种观众知情顺序时采用。

对白按原句、原说话者和顺序保留。长句跨镜时只分配一次连续发声，各片段拼回等于原文；演法在引号外，不靠新增省略号、叹词或补一句解释修逻辑。无对白场景不自动配旁白。更细的倾听、策略与身体任务按[文戏](drama.md)选读。

## 调度先走得通，再决定怎样拍

先建能支撑本场的最小布局：人物和关键物件在地标哪侧、有效通路、门的开合区、会遮视线/声音的结构。没有影响结果的尺寸不必填坐标；一旦需要绕柜台、进出门、跨桌交接或看见背后，条件必须真实可用。

对承重变化更新同一状态：所在地标侧、身体朝向、关注对象、手中物/支撑、门与道具状态、已经获知什么。第三人在画外仍处于同一时间，不因切回突然到位或获得信息；无关者不必每拍活动。

移动写实际起点、必要转向/绕行和落点，移动时间容纳距离与开门/避让；拿取、放置、递接各有接触和释放，新支撑成立后旧支撑才退出。世界位置、人物自身左右和屏幕投影分开；相机换侧不让人物、门、伞柄或袋子跟着换世界位置。详见[剧情空间](spatial-continuity.md#剧情场景的调度与可见性)。

## 从观众的理解安排分镜

每个承重节拍先确定这次要读的证据：一次未被接受的交物、听者改口的触发、一条真实眼线、跨过关系边界、原物变空等；再选谁是当前主读对象、需要看到什么范围和结果。这样决定同框、说话者、听者、局部或空间关系，最后才命名景别与运动。

切镜必须有观看收益：把注意交给新证据/接收者、读清刚发生的结果、改变有依据的主观距离，或兑现明确节律。切在一句的关键词、动作相位或关系变化处均可，不等每句说完才切；已经在话中读清的反应不在句后重演。同框可以完整承担一轮来回，长镜也可持续发展。不按镜数、景别数、正反打数或固定镜长证明分镜。

逐次交接核三件：前幅已经交付什么；后幅第一眼能读到谁/什么及其归属；正在进行的动作、声轨和画外人接到哪个相位。近景不承担看不见的全身移动，后脑/失焦脸不承担细微眼神转折。焦点由手交给脸时写出何事触发，不只列“转焦、慢推、侧绕”。复杂覆盖见[整段分镜](storyboard-sequence-design.md)。

固定机位一镜到底：所有必要证据必须在一个实际可达的观察位置读清，用人物调度、遮显与已有物件完成；没有暗切、插入特写、临时光学变焦或跳位置。一般连续摄影允许用户未锁定的移动和变焦，按[一镜到底](one-take-direction.md)判断，不混用裸眼POV。

## 时长与编译

先粗核整场容量，避免设计完才发现结尾装不下；确定事件、观看与可并行部分后，按[剧情时长](narrative-timing.md)定每镜包络。总长自定就让内容决定长度，固定总长就先验证可行性；不是平均分秒、每句加停顿、起步就定两分钟，也不是将对白和同期动作全部相加。

编译只交采用稿。共享事实写全局；画面写本镜入口、布局和具体观察；S写这次行动/接收/结果；sound写唯一声轨、说话者、原词及同场画外/电话等来源；fx-env只承接实际环境和物理变化，无新增效果可简写；transition写切出的真实相位与下一幅接什么。心理目的转成可见/可听证据，不把内部因果表、负面清单或“稍后补拍”当完成正文。模板字段按用户格式优先，默认An声画分栏。

独立生成单元在用户任务或已核验容量确需时才拆，包含必要身份、场地入口、持物/知情和未完成动作，接续原事件及声轨；镜头数不等于生成次数，不能每到揭示前就截掉结果。平台未知保持中立。

## 交付前四遍反证

不是输出四份报告；只对最终稿完成以下不同任务，合并修复并复查受影响链：

1. **对原文**：每个锁定事件、否定事实、对白和结尾在何处兑现；有没有漏拍、重复、调序或未授权补戏。
2. **对声画理解**：只读实际画面与声音，关键选择有没有可接收的前因，观众能否按原要求顺序知道；作者解释和全局禁令不能补缺失镜头。
3. **走空间**：从起点连续走到终点，逐关键出口核人、门、通路、手/道具、视线及画外人；同侧标签不抵消具体位置矛盾。
4. **走时间**：对白片段拼回原文，动作可完成，并行不重复、先后不抹去；每镜入口/出口与下一镜真实承接，末镜没有未读清就硬截或已完成却拖尾。

发现最早断点就回到事件、调度、观看或估时层修，随后重查受影响部分；不以镜头术语、分栏完整或数字连续放行。文字成立、独立文本试写、真实生成与正常速度视听分别登记。

## 方法依据与迁移边界

以下为核读网页/文档后的方法整合，不是已观看其中影片：

- [ScreenSkills：Script Supervisor 职责](https://www.screenskills.com/media/7610/final-jd-script-supervisor-110523.pdf)：剧本时序、道具/服化连续性、对白核对及估时/实拍时长更新，支持把原文拆解和连续性贯穿到交付。这里迁移为提示词内的最小状态和覆盖检查，不要求普通用户填写片场报表。
- [Hitchcock 自述](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)：局部与接收者画面可共同交付心理理解，声音可延续在倾听者画面上。采用注意与信息组织，不继承其否定固定长镜的个人偏好。
- [Yale Film Analysis：Editing](https://filmanalysis.yale.edu/editing/)：建立关系、眼线、动作匹配、平行剪辑和省略分别处理空间与时间。采用这些区别；本工作流在要求连续空间的任务里不借艺术化剪辑偷换物理条件。
- [Adobe：J/L cuts](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/l-and-j-cut.html)：声音与画面可在不同切点交接。这里只据此保留一条连续声轨和反应覆盖，不推导视频生成端必能精确执行。
