# 2026-10-22：连续打斗门槛——不停、不站、不单人演出

本页是本日较早维护的历史记录。本轮已发现其中相机运动免责、统一秒数和只在反馈路由触发的缺口，当前规则与实际试用状态见[后续维护](maintenance-expressive-cinema-20261022.md)。保留原记录，不将当时的自检结论追认为已完成独立或成片验证。

本轮对象是工作流源。触发来自用户对 16:9 双人打斗稿的反馈：“两人非必要不要有停顿站立的全景；禁止打着打着突然停下来对峙；不要一个人释放技能，另一个站立观看，比如召唤；可以给迈克尔贝英雄环绕运镜，由近到远；角色动作不连贯，打一下停一下。”

## 失败样本

修前的 16:9 双人打斗稿有六处直接违反：

1. S1 两人在石台两端站定，缓推+急变焦，开打前先摆姿势。
2. S2 结束在贴身，S3 银黑突然“半空翻身/落地”，没有起跳与距离来源——切镜像重置。
3. S3 银黑站定控阵，红发在龙卷里；S4 银黑放日轮，红发在龙卷里等光束，翼“仓促成形”——一人放技能、另一人当靶子。
4. S7 两人蓄力对峙，像对波；中段停手。
5. S9 两人起身、对视、再走；停顿站立。
6. S11–S12 停住大全景，两人站着不动。

整体读感是“打一下停一下”：每个切点像重新开始，而不是接剩余相位。

## 根因

规则并非不存在：`fight-default-contract` 已写“不等对手、不无因复位”，`action-linkage-and-release` 已写出口→入口，`fight-motion-gate` 已写镜头跟观看任务。失效在采用层：

- 入口没有一条“连续打斗”的采用门槛，稿子可以用“大全景交代两人”“技能展示”“蓄力对峙”通过。
- 技能释放被当成过场：施法者的形成/作用与对手的逼近/打断没有写在同一 S 段。
- 切点没有接出口：S2→S3 的“突然半空”就是没有写银黑怎样从贴身到空中。
- 全景被当成“交代两人”的默认镜，而不是“有人在动/相机在动”的观看选择。
- 迈克尔·贝英雄环绕没有被写成“人物在动、近→远、有中段/落幅”的镜头，只被当成“环绕”名称。
