# 导演学习扩展：来源与完成范围

2026-10-04，承接用户“学习的不止我说的那些”的纠正。此前拍法选型资料保留，本轮把范围扩展到场景导演方法，不把用户点名词汇当学习目录上限。

## 本轮已实施的学习

| 学习轴 | 已读原始/官方内容 | 转为工作流的应用 |
|---|---|---|
| 调度、纵深与持续观看 | [David Bordwell：Nordisk and Tableau Aesthetic](https://www.davidbordwell.org/essays/nordisk.php)，视觉注意、2D/3D、遮挡与显露相关正文 | 长镜注意交接、关系调度、停动与体量比较；不强制所有片都长镜 |
| 局部、反应与心理视点 | [Alfred Hitchcock：My Own Methods](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)，局部/反应、声音与色彩相关自述 | 观众信息与人物知识分开，局部并置、主观声与重点色；不继承其长镜偏好禁令 |
| 清晰层与光学取舍 | [ASC：Deep Focus — Diopters](https://theasc.com/article/shot-craft-deep-focus-diopters/)，近摄与split-field相关正文 | 选择性清晰、深清晰、转焦与分割两清晰层分开，不误称分屏或全深度锐利 |
| 光色与场景语境 | [ASC：Fresh Perspectives](https://theasc.com/article/shot-craft-fresh-perspectives/)，Michael Goi、Alan Caso访谈段 | 场地可识别与摄影语法可变化并存；允许表达性光，不普遍锁现实光源 |
| 减光、反射与现场限制 | [ASC / Jon Joffin：Remote-Location Lighting](https://theasc.com/article/shot-craft-remote-location-lighting-with-jon-joffin-asc/)，减光/反射/环境一致性段 | 明暗塑形与人物进入光区，负补光不是黑光灯；不照搬设备与曝光参数 |
| 美术、颜色和摄影协作 | [ASC：《Ballard》主创第一手记录](https://theasc.com/article/ballard-vibrant-noir-cinematography/)，lookbook、美术、光区及色域段 | 场景基线、重点色、材质与调度协同；不复刻该剧色表或镜头 |
| 镜头质地的选择 | [ARRI / Brett Pawlak：《The Glass Castle》访谈](https://www.arri.com/news-en/dp-brett-pawlak-on-the-glass-castle-/45482-45482)，镜头测试与较干净成像段 | 镜头类别不是统一瑕疵套餐，测试所得不能变品牌质量保证 |
| 镜头并置与剪辑时间 | [Adobe：Cuts in Film](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film.html)，动作/反应、跳切、匹配、硬切相关段 | 看切前期待与切后证据，区分时空省略与实体变化 |
| 多线交错 | [Adobe：Cross-cutting](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/cross-cut.html)，定义、视点、画幅与时间关系段 | 不以交替剪辑自动推导同步；以本场实际时序为准，不照搬未观影片例 |
| 声画交接 | [Adobe：J/L cuts](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/l-and-j-cut.html)，定义、声音前入与延续段 | 提前/延续声源、角色听觉与剪辑时钟分开，同一句只发一次 |

以上阅读是正文或所列段落，未播放嵌入影片，不声称逐帧研究完整作品。对照练习是原创转译，不是任何主创的固定导演公式。Adobe不同文章对交错/并行剪辑的术语使用有简化或不一致，采用“明确实际时序和观看关系”的设计，不把页面措辞当物理规则。

## 范围不止本轮词条

持续的学习结构按问题组织：戏剧与视点 → 表演和场面调度 → 摄影/构图/焦点 → 光色/美术/成像 → 剪辑与声画/时空 → 整场基线、母题、节奏和观众体验。题材与媒介的应用可以继续扩展；不是本轮十项来源就覆盖了全部导演知识。

遇到新任务，先判断哪个层面没有起作用，再查对应主创/作者或制作资料，把认识转成同事件对照和相邻反例，随后更新命中模块。不要每次添加更多通用禁令，不因为用户没点名就忽略明显的导演缺口，也不在普通生成时无故启动全库研究。

## 本轮落地与限制

已完成资料阅读、原有导演/表演模块核对、场景层归纳和8组自写对照演练，并接入 MOKE 的核心设计与终检、摄影模块及原导演参考入口。保留上一轮拍法、构图与冲击帧修正，不另建竞争工作流。

没有实拍、视频生成、独立盲测、试听或成片验收。J/L算例校验声画区间及原台词分配，不把纸面5秒当录音实测。镜面与光学条目提供简化几何/可读性判断，不能自动验证复杂实际镜头效果。审美与观众心理解释不能靠关键词、文件校验或一次算例证明。
