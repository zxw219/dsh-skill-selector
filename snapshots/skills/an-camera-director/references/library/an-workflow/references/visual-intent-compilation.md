# 把学习转成成品提示词

用于系统强化多项观看体验、学习成果转译，或稿件逻辑成立却仍缺速度、压迫、表演、质感与视觉重音的情况。普通任务复用入口的必要设计与一次检查；本页不要求每稿读全库、交内部表或启动代理。

## 先让知识改变选择

研究得到的造型、调度或摄影方法，要改变当前场景的一项实际选择：角色怎样行动、对手如何回应、技能怎样起效、观众从哪里看见、材料怎样变化、事件如何结束。引用技能名称、加入“电影级”等标签、列全所有板块，都不构成转译完成。

保留项目已锁的事实、格式和结果。素材的可见外观、作者陈述、观察到的时间顺序与自己的设计推导分开；参考作品的招式、机制、镜数和结局不自动成为当前要求。没有证据的效果机制，可在用户允许创作时作为本项目新设计明确建立，不能伪称从参考看到了它。

动作多样性与美感的学习，要改变身体选择并产出完整乐句：使用[动作词汇、组合与身体美感](../../combat-action-design/references/action-phrasing-and-aesthetics.md)及[成稿练习](action-diversity-lab.md)，把入距、高低、直弧、防法、释放/回收、身体开合与领随写进当前事件。基线中重复的挥砍/伸掌要对应实际新解法，不以新增招名、技能表或禁止项结案；参考观察、原创编排、文本复核与视频验证分别记录。

## 用途分析必须改变实际措辞

文档学习或“全面学其写法”的任务，按[参考写法与精准成稿](reference-prompt-writing.md)在编写时判断每句控制什么：稳定资产/物件职责、场地支持、当前动作对象、路径落点、双方应对、技能控制相位、效果材料、相机取景或剩余状态。把有效原句关系重写成当前事件，不仅加一张分类表或泛称“源点路径结果”。精准保留有效修饰与审美词，择定互斥武器方案，补决定性事实，避免逐关节扩写无收益细节。

保持`fx-env：`、`sound：`、`transition：`，动作、效果环境、声音和切镜共用一次事件；共享架构与分栏可以并存。学习报告展示用途，生成正文只交采用的句子。要求维护时实际写回入口、专项和映射并同步包，不能把学习记录当成工作流已更新。

## 共用一个事件，再分工

导演先确定本场重要体验、人物选择与主要变化。关键事件按需要确认：

`入口状态与当前威胁 → 行动/技能及对方响应 → 决定性作用 → 观看证据 → 新状态与后续条件`

各模块处理同一事件的不同部分：动作管双方行动与受力；表演管选择和身体表现；特效管形体、介质和作用；构图管可见关系；运镜管实际路径与相对运动；分镜管覆盖、切点与承接；冲击帧管已定峰值的瞬间形体。总导演解决相互冲突并检查整场体验，不由任何一个模块另定剧情或第二条时间线。

例如“巨掌压向人物”已是当前事件：特效不能再安排一段暂停战斗的掌形展示，摄影不能只给没有参照的手部特写，动作不能靠瞬移跳出困境，冲击画不能把尚未接触改成已经命中。允许抽象画内省略形体，进出仍接同一作用。模块交付融入当前稿，不把各自说明串成成品。

## 用户的词怎样进入正文

下表是转译选择，不是每镜必填字段或固定技法。先取本场适用关系，再按媒介、人物能力和用户风格表达。

| 需求 | 需要设计的画面关系 | 写入正文的内容 |
|---|---|---|
| 导演 | 观众此刻期待什么、人物怎样选择、主要事件改变什么 | 信息给出顺序、重要决定和场景出口；理由不写进生成正文 |
| 分镜 | 各视点分别读到什么，切前后属于何种时间关系 | 镜头取景与切点、动作相位和结果接续；同一攻击不反复重演 |
| 构图 | 主体、威胁、通路、参照、遮挡与明暗的实际关系 | 起幅、决定性中段、落幅中谁占哪里，什么正在侵入或显露 |
| 运镜 | 相机和主体之间怎样改变距离、占幅、视差或观看对象 | 起点、主要路径、触发、相对速度和落点；技法名不足以执行 |
| 动作/速度 | 从何处到何处，以什么支撑换线，对手此刻做什么 | 加速、进入/离开攻击区、接触、制动/承重及接出的行动 |
| 表演 | 角色接收到什么、做了什么判断、如何坚持或改变任务 | 当前景别可见的视线、身体任务、呼吸或主要表情；不为看脸让战斗停机 |
| 质感 | 材料怎样接受光、运动、接触或负载 | 刃内折射、金属擦痕、布料滞后、皮肤受光等适用证据，落在能读到的镜内；媒介统一 |
| 特效 | 主形、内部结构、源点、路径、交互与终态怎样成立 | 主作用与次级反馈的可见变化；角色辨识不只换颜色，旧尾迹不随源头整体转向 |
| 技能释放 | 起效为何发生，如何取得作用，对手如何干预 | 本技能适用的起势/在途/受阻/命中/收束；瞬发不硬加完整蓄力流程 |
| 大招释放 | 这次重要释放的标志形、抵抗与场景结果是什么 | 让主作用获得可读时间，编出强烈形体变化及后果；不只写技能名和白闪 |
| 大场面 | 主作用怎样跨越已知参照并改变可用空间/介质 | 传播、体量、接收端变化与持续新处境；无破坏的大场面也可成立 |
| 巨型压迫 | 巨物局部、人物世界与正在被占据的天空/通路怎样比较 | 局部尺寸、逼近/遮挡、悬殊应对和局部抵抗，法相明确操控与作用主体 |
| 张力画面 | 什么结果令人担心，出路/时间/选择怎样受到威胁 | 危险推进、对手干预、尝试受阻及选择代价；角色不必显得恐惧 |
| 冲击力 | 力量通过哪里、被什么阻挡、接触后发生什么变化 | 来力、负载、受力方向和结果；震屏、音量不独自证明力度 |
| 冲击帧 | 哪个已定峰值值得图形强调，用什么形体表达力向 | 特殊轮廓、正负形、刮刷/断面与曝光方式，入口和退出承接；不套通用帧数 |
| 帅气/酷炫 | 什么主动决定、动作完成度或造型冲突令人记住角色 | 用危险中清楚的判断、干净有力的执行、独特技能形体兑现；不只结尾微笑 |

“全部加强”在整场协调上述职责，按重要事件分别兑现。一个瞬间可以兼顾动作、材质、构图和冲击，但不为配齐表格塞入所有特效和运镜。文戏、慢镜、仪式、静止凝视或图形短片按本场目标选择。

## 编译成一份可复制正文

1. **共享事实只写一次。** 时长、画幅、媒介、参考职责、人物身份、场地、关键能力规则与声音范围放全局。动态状态随发生时间写，不预先给人物最终伤痕。未知平台不假造参数或片长上限。
2. **重要事件确定后再分配镜头。** 让观众能够读清决定性变化；一镜可通过调度完成多项职责，真实切镜才建新镜头。不要先平均镜长再倒填动作。动作、表演、材料和效果共享实际时间。
3. **把理解性说明换成可见结果。** “压迫感增强”改写为已知天空/通路怎样被占；“有质感”写当前材料在镜内怎样变化。共享媒介和必要材质基线保留一次，局部写主体、动作与结果，删除不改变执行的同义赞美和无作用名词。作品参考限定借鉴对象，负面约束先在正文落实修法；具体例见[战斗写法](combat-writing-patterns.md#7-把参考特效与负面约束编成指令)，明确2.5时采用[精准编译](../../seedance-2-5-prompting/references/precision-compilation.md)。
4. **写回所选格式。** 战斗先建立角色战斗语言/特效体系和连续事件，继承有效的既定格式；完整提示词无其他指定时默认按An声画分栏，连续阶段作为镜内事件组织，参见[战斗成稿与表达选择](combat-writing-patterns.md)。已有或选用An分栏时，全局写共同设定，画面写起始关系，S写行动/响应/变化，fx-env写效果和环境，sound写获准声源，transition写真实切换；其他明确模板同样保留，不另造平行版本。
5. **去重而保留作用。** 已在S说明的触发不用在fx-env重发一次；普通延续只带必要状态。删掉重复装饰和无收益摄影说明，保留主形、攻防、表演、结果辨认与用户明确要求。

编译模块发现上游没有主形、动作出口或观看证据时，由主导演协调拥有该决定的模块定向补足再成稿；用户锁定设计时报告具体冲突，不私自重新导演，也不带着“待补”占位交付完整稿。普通创作默认只交最后采用的一份正文。

## 同时检查成立与兑现

在已有一次复核中，先修身份、状态、路径、接触、时长和模板的硬错误，再针对请求检查观看证据。两类问题分别记录：逻辑自洽但观感欠写仍需改善；强烈画面但事实矛盾不能放行。结构检查器只覆盖其明确支持项，不用关键词计数或总评分代替审美判断。

实际指出关键事件和镜内证据：哪里证明快、哪里形成负载、哪里让巨大存在占据人物空间、哪里表现选择、哪里能读材料、哪里形成技能身份、峰值过后改变了什么。只有形容词、全局标签或栏目标题的项目视为尚未兑现；有意含混或静止按用户目的判断，不强制每项都有新事实。

修复落在最早缺失的决定：无技能辨识先改主形；无张力先改危险/选择关系；无力度先改来力和阻力；无速度先改相对位移和动作时机；无质感先改材料与观看条件；峰值被挤掉先整理重复展示和镜头组织。然后只复核受影响的后段。勿在整份稿后反复追加“更巨大、更震撼”。

## 输出一致性怎样维护

同一项目沿用已确认的身份、能力机制、时间码方言、模板和出口。修订明确替换旧决定，不留下互斥版本供生成器随机选择。变化只需在事件中建立一次，之后继承；控制方式和素材标签保持同一含义。

“稳定”分开验证：文本层核对硬条件、时间/格式与语义承接；行为层以真实使用问题和相邻合法情况检验路由、范围与返工选择；成片层看实际工具执行、正常速度观感及必要接触窗口。自写示例不能叫独立测试，暂停截图不能叫完整视听验收。没有授权生成时完成成品提示词，不启动付费试跑；有成片后区分设计欠写、工具未执行与素材问题，不把任一层通过说成全部稳定。

本页统一各专项的转译接口，不复制它们的完整方法。按问题联用[分镜视觉](storyboard-visual.md)、[表演](drama.md)、[战斗执行](combat-execution.md)、[特效形状与释放](effect-shape-release.md)、[巨型压迫与法相](../../spectacle-impact-direction/references/giant-pressure-manifestation.md)和[终检](final-check.md)；已有内容直接复用。需要检视完整整合例时读[28秒成品演练](visual-compilation-28s.txt)，它是原创练习，人物、时长、技能与镜数不成为后续默认。源于2026-10-07用户对“只学习却没有稳定转成品”的纠正，是工作流设计增量，不是新的视频模型能力声明。

## 精彩度编入原声画栏的参考学习增量

把期待兑现落到决定/作用/结果与具体观看中，技能形体、人物选择、身体线条、加速/负载、局部受光及后果分别进入原全局、画面/S和fx-env：sound：transition：。有效专有画质词及原时长/密度保持，不用禁止pose和炫酷标签替代正向设计。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。

## 从完整版证据到原稿执行句

学习成果改变正文中的选择：身体接重恢复、持续防守改角/空手反击、目光接收后继续任务、效果随相位变材料、局部受光和旧残留承接。只把采用关系编入原画面/S/fx-env：sound：transition：，不把学习表或21条方法全贴给生成端；共享身份与能力规则只写一次。观察帧率、源时间精度、技能数和样本时长不是生成参数。已有格式和强度照旧，具体关系见[执行方法](narrative-combat-transfer.md)。

## 把导演判断落实为执行句

沿[导演推敲](director-deliberation.md)把采用的战法、信息顺序、观看目的和并行机制写为实际画面/S与同次声画栏。美感不由思考标签或原则说明证明；脸/手/目标有真实取景，切回有已发展相位，规模有主形、参照、作用与结果。普通成稿不附内部过程报告。

## 读者不补全的编译复核

重点核指代的有效范围。“她/它/原位/另一侧/旧裂口”跨角色、物件或镜头后，是否仍唯一指向对象、部位和地标？若原结果是薄片弯折，后稿的“旧裂口继续扩大”不能靠末尾禁令抵消，直接删除过期状态并重写为该片原弯折处的当前变化。

对修改后的执行句做定向删除检验：删这句是否丢失持续控制、到达条件、材料区别、必要读取或出口之一？会丢则保留必要事实，能由同段唯一确定的重复才合并。S写身体作用、fx-env接同次材料结果，不在另栏再次触发。
