# 手脚协同与能力多样性

用于技能/动作单一、全程掌前放电或手脚并用未兑现的创作与返工。先修选招与身体/能力关系，再编摄影；不把手脚动词表、换颜色或换发光源当丰富。最新用户要求优先，既定能力、胜负、时长与专项职责继续继承。

## 先修三个独立缺口

| 缺口 | 采用决定 | 最终正文的证据 |
|---|---|---|
| 身体只上肢出招、脚仅移动 | 明确混合战法，手法与腿技互相创造窗口 | 实际腿攻/腿防/封步或下盘控制、对手响应、收腿接重与后招 |
| 全部技能是弹体相撞/根枝拦截 | 从当前机会改变作用对象、条件、负载、路径或任务 | 同招互换后防法/出口不能无区别复用，或重复确有战术用途 |
| 所有发动都是掌前推出 | 在既定体系内采用接触、踩点、载体、布置、环境连接或代理 | 源点/条件不同真正改变作用区与时序；不只脚底放同一光波 |

有造型图不等于用户锁定纯法师；助手旧稿的纯掌式补设也不是限制本轮手脚并用的理由。允许原创时选相容混合角色，用户明确要手脚并用时补成立条件，不消极退回只摆手诀。纯远程、禁止近身、纯兵器或锁定发动方式按本轮授权执行；不把所有角色都转成武者。

## 手与腿以窗口衔接，不按部位轮流表演

可从当前交锋选一种关系，再让对手应对改变后招：

| 关系 | 身体与对手任务 | 承接关键 |
|---|---|---|
| 手压上路→腿改低路 | 截开来臂/牵制上身，低扫、封步或侧送腿迫使换重 | 手控是否仍有效；对手提腿/移步后，收腿进入新空线 |
| 腿逼防→手抢线 | 踢击令防臂下移或身体退偏，收腿/落步中拳肘/触印抢新线 | 对手不是等踢完再防，手招距离由腿击结果与追入决定 |
| 上肢受控→腿截击 | 被抓腕或维持手部术式时，以膝/短踢截贴身威胁 | 支撑、可达目标与空余腿成立；不凭“同时”放行占用矛盾 |
| 腿被截→落步换线 | 踢击被偏转，折叠收腿并用其落点换侧，手保持回护 | 不凭被接腿自动空翻脱开；持续抓持要有解除过程 |
| 拳肘近身→膝/腿续压 | 上一接触压缩距离或改变躯干，短膝/侧送腿读取该窗口 | 目标仍可达，近膝与长踢不能共用同一距离 |
| 踢击/接重→能力起效 | 脚真实接触已设节点/载体，身体技结果触发旧状态 | 节点、发动边界与物理踢击分开；不是每脚自动释放新法术 |
| 代理造窗→本体手腿 | 自主/已交令代理改变防线，本体在另一可达方向截腕/踢击 | 控制归属、忙闲手、同期位置与反制全部继承 |

提膝不自动算膝击，蹬地不自动算踢，腿部泛光不自动算技能。身体技可以不附法术，每次踢击也不必倒飞；腿技的防守、偏转、逼换重与封路同样有作用。低扫、高踢、侧踹、膝与旋身踢的进入/回收不同，不为凑丰富随机旋转或统一高踢。

## 能力从作用关系扩展，不只从形状选

原创时可取当前体系相容的一条变化，全部不是强制技能菜单：

- **触物/接触起效**：接触处传导、剥离或暂时压住连接；作用区局部且有解除/残留，不默认一碰全场失活。
- **踏点/边界起效**：已布节点由落脚/接重接通，改变一个落点、阻力或通路；不无因获得全域追踪。
- **介质/材料改变**：既有水、木、岩或能量按本体系改变硬度、相位、弹性或连接，结果影响攻防；不是同色大球。
- **路径/负载改控**：引开在途攻击、挪开局部承力、用已设弹性储放冲势；对象、可控范围与惯性残留可辨。
- **载体/旧状态接力**：短击、踢物或接触把已设作用交给实体/标记；源与载体分别维护，不凭动作新增能力。
- **代理/召唤协同**：有效部位执行截击、牵制、开路或守护，本体手腿处理另一个实际窗口；代理不是装饰背景。

雷、火、森灵等体系均可这样原创，但更改发动条件属于获准能力设计，动作/摄影专项不可自行授予。手→脚换源若不改变作用条件、路径和结果，只能算身体动作变化，不能同时证明技能多样。封印、时停、吸收、分身等也不凭“丰富”自动加入。

## 小片段校准：不是固定连招或实战教学

**手截→低扫→收腿抢线**：B直拳进入A上身，A左前臂斜引来臂；左脚承重、右腿沿低路扫向B前脚。B提腿撤出扫线，以后脚接重并回护；A右腿收回前落，借缩近的距离送出右手短拳，B左臂即时截住。手与腿都改变过攻防，后招不假设B已经中招。

**腿迫防→落步肘入**：A左脚支撑，右腿侧送到B前臂防线；B双臂封住有效接触，受力退半步。A折膝收腿并向前落步补回距离，左手挡开B开始反击的右臂，右肘在贴入窗口压向其肩前；B转肩卸开，双方进入新的近距离争夺。不能从踢后原地用短肘命中退远者。

**手控术式→膝截贴入→根系反扑**：B双手维持既设根网，A沿空隙贴入；B左脚稳住根台，右膝短提截向A腰前。A收左肘承接膝锋并侧移卸开，B折膝落脚，同时右腕在原根网内改向，根枝从A新站位侧前方逼入。手部控制、腿防和召唤各有任务，不让脚只当移动工具；右腕只是改控，不另释放第二份召唤。

**强者戏弄也能手脚协作**：B上路出拳，A小幅拨开，短抬腿封住B准备前踏的路线；B被迫改落点，A收腿落地，在B重新取线时轻触其控制手并主动松开。A的优势来自预判与尺度控制，不必全程双指夹电，也不默认把B赶成逃跑者。

## 摄影与终检

先让身体动作成立，再按观看对象选择：斜侧中全景读手法→腿击→收腿接重，近景读截腕/接触或表情，作用体局部读材料/控制变化，范围接同次结果。腿部CU能读局部，但其髋、支撑/腾空与目标关系需由同次邻镜承接；不要全程腰上施法手特写。运镜跟手腿接力的真实相位，切镜不重打一脚。

最终正文逐相关片段核：真实腿攻/腿防/控制是否发生；支撑与占用是否相容；对手应对有没有改变下一步；踢后距离、收腿/落步与后招是否继承；技能去名去色与换源点后是否还不同；摄影有没有拍到关键事实。当前明确手脚并用却只有脚步时继续返工，不能用全局承诺或一个无意义高踢放行。不设拳腿比例、每秒招数、每人技能类别或镜数配额。
