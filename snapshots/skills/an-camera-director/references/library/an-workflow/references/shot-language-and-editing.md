# 镜头语言与剪辑手法

用于"镜头运动只有一种、角度不会用、转场乱、分镜组没有推进"的默认创作与返工。与打斗专用的[打斗镜头语言](fight-shot-grammar.md)分工：这页管通用镜头、运动、角度、轴线、转场、蒙太奇、长镜头与演出结构；动作怎么打仍回动作与战斗执行层。

## 六种运动，各有功能

| 运动 | 怎么动 | 主要功能 | 常见误用 |
|---|---|---|---|
| 推 | 机位沿光轴靠近 | 细节、悬念、情绪递进；快推制造紧张，慢推做情感 | 用推镜代替剪辑，推完没有新信息 |
| 拉 | 机位远离 | 交代环境、释放情绪、段落收尾 | 拉出去只看到空景 |
| 摇 | 机位不动，镜头转 | 环视、交代关系、跟随视线 | 无因乱摇，摇完没落稳 |
| 移 | 机位平移 | 动态、节奏、与人物同行 | 与人物同速，人物像贴纸 |
| 跟 | 跟随主体 | 代入、运动轨迹 | 全程等大侧跟 |
| 升降 | 高度变化 | 规模、压迫、释放 | 只有起落两端，中段没变化 |

每个运动都要写**起幅、中段变化、落幅**；起幅与落幅决定下一镜从哪里切。

## 推镜不等于变焦

- 推镜是机位真的靠近，透视会变：近大远小、前景掠过。
- 变焦只改视场，透视不变；原地换焦段造不出新的空间关系。
- **希区柯克变焦**（推轨同时反向变焦）制造眩晕与失衡，要有背景层次才成立。
- **甩镜头**是快速摇，产生方向性模糊，适合转场；甩完要落稳到新信息。

## 高能运镜：手持、甩镜、快变焦

### 手持

- 两档质地：**肩扛**有抖动与呼吸，给现场感、写实感；**稳定器**消除抖动，丝滑，可做 360 度旋转。
- 抖动必须有来源：脚步、呼吸、躲闪、被冲击波推。没有来源的抖只是噪音。
- 幅度按观察者任务、步伐和画面可读性选择，写明微漂移、跟步或受冲击后的修正；不以未经实测的统一角度当设备/生成参数。
- 手持不等于全程乱抖：**微漂移 + 关键时刻一次猛晃**，比一直抖更有效，也不遮动作。
- 手持也能做转场：快速下拉、前景遮挡、甩，都能接下一镜。
- 写法：机位在谁的哪一侧、跟着谁、幅度多大、什么时候稳住。

### 甩镜

- 摇镜头里，**慢摇是观察与交代，快摇才是甩**；甩的功能是连接两个空间或接住突发事件。
- 必须有**触发**：一声响、一个人闯入、一次打击。
- 必须**落在新信息**上；甩过去还是同一张脸，就白甩了。
- 甩动压缩无关过渡，落稳给关键新信息足够读取时间；具体时长按本片节奏和已知帧率设计。
- 写法：从哪甩到哪、触发是什么、落稳看到什么。

### 快变焦

- **快速变焦（snap zoom）**：原地迅速改变视场，落点是本拍需要强调的细节或关系；与机位前移分开写，时长服务读取与节奏。
- **推轨变焦（dolly zoom）**：机位与变焦配合，在保持目标占幅的同时改变空间透视关系。写清采用的目标、背景层次和路径；构图位置、速度曲线与使用次数服从当前设计，不固定居中、匀速或一次。
- 两种都不是"快速推镜"的同义词：急推改的是视场，推轨变焦改的是透视关系。
- 写法：从多宽到多窄、几帧、落在什么上；推轨变焦要写清背景里有什么在被拉伸。

### 共同点与自检

- 三者都要有**触发与落点**；没有落点的运动就是噪音。
- 手持、甩镜与快速变焦可单用或组合；每次交接有明确收益且关键动作仍可读，不按种类上限判断过载。
- 自检：手持的抖动有来源吗？甩镜落稳看到的是新信息吗？快变焦落在具体细节上了吗？这一段的运动，去掉之后会损失什么？

## 角度就是态度

- 俯拍：全貌、渺小、被审视；仰拍：权威、压迫、威胁。
- 荷兰角可表达失衡或主观压力；是否重复取决于当前视觉语法和可读性，不规定一场一次。
- 平视：对等、客观，适合对话与交代。
- 主观镜头：代入；受限视角（模糊、遮挡、窄视场）可以外化心理。
- 空镜：交代环境、铺垫情绪、做转场；不能只当风景。

## 轴线、反打与 30 度

- **180° 轴线**：双人关系不换边；要越轴，用中性镜头、可见的移动或重新建立。
- **反打/过肩**：对话、对峙的基本覆盖；过肩能同时读到关系和反应。
- **30° 法则**：相邻镜头角度差太小时会跳；要么明显换角度，要么换景别与注意对象。

## 转场：五种够用

- **切**：默认。切在动作中段、视线交接、声音重音上。
- **动作匹配**：前后两镜的动作接得上，切点藏在动作里。
- **甩/遮挡**：快速转场，用运动模糊或前景（人、柱、烟、墨）盖住切换点。
- **叠化**：时间流逝、记忆、地点迁移；动作段少用。
- **划变/图形匹配**：按采用的风格与信息关联使用，次数不作通用门槛。
- 声音可以独立转场：**J-cut**（下一镜的声音先入）、**L-cut**（上一镜的声音延续）。

## 蒙太奇

- **平行**：两条线交替，制造对照。
- **交叉**：切换越来越快，制造悬念。
- **隐喻**：两个镜头并置产生新意义（不靠台词解释）。
- 不是所有快切都叫蒙太奇；没有意义生成的切换只是碎。

## 长镜头

- 一镜到底靠调度、焦点、构图变化完成观看变化，不能暗插切镜。
- 要有观看发展：从什么进入、中段哪次变化、落幅读到什么。
- 失败的长镜头＝人物走、镜头跟、信息没变。

## 演出结构（过场/必杀/技能展示）

格斗游戏的必杀演出可以拆成固定段：**起手动画 → 台词 → 动作 → 受击 → 处决瞬间 → 结算**。可迁移的四点：

- **角色特性决定镜头**：用拳的角色让拳头占半幅，用力量的角色用高机位俯压对手。
- **瞬间失声**：在最强的一下之前抽掉声音，比加音效更能制造生理紧张。
- **首尾呼应**：开场与收尾用同一个构图或同一个动作，读成"完成"。
- **对手同期行动成立**：根据距离、控制和角色任务选择截击、避让、防守或承受；蓄力期间可被抢攻，也可有既定保护，不为演出冻结对手。

## 分镜组：建立—发展—落点

- **建立**：全景/关系/地标，回答"在哪、谁对谁"。
- **发展**：中景、近景、局部，推进信息或压力。
- **落点**：结果、反应、新状态。
- 相邻镜交接本次必要信息或强调；景别、观察侧、注意对象和运动质地可帮助发现同质，但有作用的同构回返与持续观察不按变化项数判错。

## 交稿前

- 每个运动有起幅、落幅和动机吗？
- 运镜的对象、关系和作用有发展吗？重复运动是在延续当前任务，还是没有观看收益？
- 推镜和变焦分得清吗？甩镜落稳了吗？
- 轴线守住没有？越轴有中性镜头或可见移动交代吗？
- 转场是切、匹配、遮挡还是叠化？有没有滥用叠化？
- 长镜头有观看发展吗？
- 这一组镜头是从什么建立、推进了什么、落在哪？
