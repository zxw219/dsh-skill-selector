# 战斗采用与导演推敲的展开规则

本页保留主入口的条件细则；角色、动作、摄影或全稿核对出现对应缺口时定向读相关节。沿同一采用事件链工作，不把本页变成普通任务全读清单；用户事实、当前格式与本功能职责优先。

## 出稿前的战斗采用

**先作判断，再调用知识；最后用成品检验判断**：先确定当前任务最影响质量的体验目标、不可改事实与容易退化的设计，按[关键决定与反证](director-deliberation.md#关键决定先于套模板)选择能承担目标的事件/观看关系，再读取会改变选择的专项。不要把“读了几份资料”当作设计进度，也不要套完熟悉招式后补质量标签。完成稿后先按[成品反证](final-check.md#从成品反证不从作者解释放行)找最弱的关键段，修实际内容及依赖，再作连续性/格式验收；普通创作不输出内部审查表、不强制多代理。

**先选主体验，再主动执行**：普通实战保留高速、高频、力量、模块变化与事件驱动摄影的主动起点；当前请求、参考与已采用剧情指向能力展示、控制博弈、压制或伤后反扑时，先按[能力作战](ability-led-combat-direction.md)编辨认、爆发、作用、结果与人物接收，不等用户补一句慢打。同场可切换，能力战也可密集快战；已确认的速度/频率要求跨检查、优化继续有效。按[战斗体验设计](combat-experience-design.md#普通打斗的主动设计起点)成立事件再分时，固定、单镜、纯远程和单能力不自动决定快慢。

**多人战斗在编个人招式前启动关系设计**：团队、三人及以上交锋、一对多先按[共同交锋单元](../../combat-action-design/references/team-combat-choreography.md#先编共同交锋单元)和[关系分镜](../../action-camera-direction/references/multi-character-coverage.md#从共同变化决定镜头)共同确定动作与观看；连续镜头再取[接力运镜](../../action-camera-direction/references/continuous-fight-handoffs.md#把关系交接落实成相机运动)。先分清团队、独立并行和自由混战，再编威胁怎样改变另一个人的攻线、支撑、控制或机会；不能从角色名单逐人写招再拼起来。终检先核[多人体验与学习兑现](multi-character-combat-review.md#先验共同交锋与观看体验)，再核全员状态；没有停机和位置错误不等于动作、分镜和运镜已经合格。两人交锋沿用关系与同期方法，不为多人规则加角色；人数不自动要求全员同框、固定镜数或一镜到底。

角色机制确定后，选招阶段主动取[动作模块](../../combat-action-design/references/action-module-bank.md)中相容的进入、拆招、变线、控制与恢复组合；按当前距离、接触、忙闲肢体或地形难以选用时取[出口检索](../../combat-action-design/references/action-selection-index.md)，让受阻分支也能接下去；施法快战取[高速施法交锋](fast-spell-exchange-design.md)，能力展示与控制关系取[能力作战](ability-led-combat-direction.md)；选镜阶段取[战斗摄影执行](../../cinematic-camera-design/references/camera-execution.md#战斗中的速度力量与摄影压力)；已有基础拍法却趋同，按[复合路径](../../cinematic-camera-design/references/composite-camera-paths.md)从观看变化选高低、远近、相对速度与对象接力。已有有效内容复用，只取本场有关段落，不全库加载。**出稿前先过[战斗体验门槛](final-check.md#战斗体验先于连续性放行)，再核连续性和格式**；学习知识必须进入S、画面与切接，不能仅凭已读、栏目齐全或时码连续宣称采用。

反馈“技能/动作单一、只用手放电、没有手脚并用”时，先在选招阶段按[手脚协同与能力多样性](full-body-ability-integration.md)修身体攻防、技能作用与发动方式。用户明确要手脚并用时，腿脚须有实际进攻、防守或控制贡献，仅跑步/落脚不算兑现；身体技与术法从同一次应对接续，不把掌心光波换到脚底便算丰富。图片或助手旧稿的“纯法师”补设不阻止当前获准混合战法，用户锁定的纯远程/单招边界仍优先。

战斗先锁**当前争夺与主动意图**，再选空间、位移与镜头。用户只说打斗、高速或高燃时，不默认逃跑、撤离或追逃；避线、卸力后退、破围和穿过技能缺口要服务本次抢攻、夺控或反击，不把“寻找出口”变成整场目标。已明确的追逃、脱离或守退任务仍优先。具体按[交战意图与召唤/表演覆盖](combat-intent-performance-coverage.md)执行。

召唤或大型术法进入观看设计时，主动区分**施术动作、作用体局部、人物接收、交会与范围**的可读对象；召唤物与其生成/改控动作均可给CU/ECU，也可在同镜推近、横移、升降、转焦后接范围。表情、小动作、情绪动作和受力反馈可独立承担投入、承受、控制、性格或重音，不以“必须改变下一招”作唯一采用条件。各项按事件收益选择，允许与高速攻防并行，不强制逐招固定镜序。

选镜前继承本次与会话仍有效的特写/摄影观看要求，在事件链中找承担对象，不到末尾才补术语。特殊能力快战优先快速、果断且由动作驱动的移动摄影，少用固定，避免以慢推/缓移作为常态；快战不因巨物、命中或传播便自动固定；能力展示、控场和危险间隙可按本拍读取主动选稳定关系、画内通过或保持，不借此覆盖整场快战要求。选镜时把[动作点跟随与广角特写](../../cinematic-camera-design/references/camera-execution.md#动作点跟随与广角特写)纳入候选：可跟拳/脚的攻击端、命中接收端、翻滚的肩髋、俯身下降或术式有效部位，不只跟整个人；大胆近距广角、斜向构图和尺度跳接按当前收益选用。它们是学习后可组合的拍法，不是每镜/每招的必做步骤，也不为拍法新增拳脚或翻滚。实际采用的CU/ECU给对象、裁切与可辨细节，镜内摄影给必要触发、路径与接出；并入第4步观看设计和第5步复核，不新增过程表或镜数配额。

用户只给宏大、紧张、美感、速度或信息诉求时，摄影在授权范围主动选用合适景别、构图、运镜、质地与焦点，不等逐项点名。从本次事件的观看变化选一案，实际写进镜头/画面、S和衔接；不在全局堆名称或每场凑全套。明确锁定拍法仍优先，具体选用按[摄影执行的主动决定](../../cinematic-camera-design/references/camera-execution.md#用户给体验摄影主动做决定)。复核也核由事件产生的必要观看缺口，不能只核用户有没有说出术语。

高速打斗先成立角色有效距离内的短促施放、应对、起效、截断/改控与反击，位移由本次避线/抢位/接重需要产生；快速奔跑不能单独代替交锋速度。施法动作少、普通技能只有甩光波时，按[高速施法交锋](fast-spell-exchange-design.md)从当前操作选择身体过程，普通小招也落实动作/作用/出口，不只为大招写成形。技能少、重复度高、单一时，在选招之前按[技能原创与选招](ability-variation-selection.md)定位储备、选用或正文兑现缺口，由当前机会选择相容能力，同时落实作用结果、施法操作与决定性画面；不先套熟悉的针/面/环或发射—拦截—爆碎，再增加招名。明确追逐、投射单招、无手势、有用重复及锁定能力仍优先。

第3步先按[攻防意图与动作选择](combat-execution.md#先编不同解法再从出口推演)确定双方本段争取的优势、拆解与转折，再选本角色相容且过程不同的动作组合；关键机会需经对手当前可用应对检验。升高—下降共用本次攻击任务，拳腿按实际支撑/身体驱动/攻击端/触阻/收势成立，不以动作词串接代替章法和运动。模组少反馈用于定位漏用，不是启动条件。原动作族与招名表只是索引，前模块出口接后模块入口，变化落实到S的身体/兵器/控制，再验资源与对手续攻；不让连续性校验把相容大动作一律缩成小步短挡。具体采用链见[模块组合练习](../assets/cases/action-module-combinations-20261014.md)，原能力、格式、幅度及职责仍继承。

## 导演推敲与全稿动作核对

入口第2–5步沿[关键决定与反证](director-deliberation.md#关键决定先于套模板)执行：采用的方法要改变实际选择，反证只读取最终成品，不靠作者意图解救缺失。相同问题再次出现时检查触发、选择、编译或验收在哪层失效，优先改现有负责规则；不在入口末尾追加同义禁令，不把学习记录中的样本设定继承为新场景事实。

打斗设计将角色可辨的进入/攻击线/发力/回收习惯、招式的施压/破限/利用窗口职责和防线过渡写入同一攻防链；升级从当前负载、应对难度及环境后果发展。效果以相容主形、源点/路径/接触变化/残留体现，普通接触与主峰有层次；镜头按拆招、身体路线、决定性接触的读取需求选尺度，实际事件触发运镜，切后接剩余相位。具体采用方法与文字练习见[打斗参考的选择性学习](combat-skill-transfer-20261013.md)，有当前缺口才定向展开；不继承固定15秒、肘击/武学/镜数配额、零重复或景别跳级禁令，既定战法、幅度、速度、规模、格式和空间用途核对继续优先。

**动作选择与最终稿的必做核对**：第3步确定当前任务、同期位置与用户要的身体幅度，从[设计系统](fight-design-system.md)主动编全身/持械动作链，不先写熟悉小动作再用“没有威胁”淘汰全部翻腾候选。原创可从开场共同设计相容来线、地形、落点与反制；锁定段不事后补敌方攻击替助手花招找理由。动作用途包括避线、借势、抢位、反击及明确身体表演美感，最短路线不是唯一标准；依然要在正文读到身体中段、兵器任务、对手同期与接重出口。畅通追击中的无任务翻滚不自动提高速度。用户锁定动作按授权成立条件，选镜前核双方路线、面向和距离，摄影不能补造换位。

第5步对**最终正文全部相关动作**逐处核对上述用途，以及每次换位/换向/切后返回的空间承接，不能只抽查主峰、用户点名招式或关键词。修订改变路径、时机或动作时，沿后续依赖重新核距离、朝向、射线、支撑及相机轴，缺证据按缺项处理。前面规则存在、栏目齐全或脚本通过，都不代表已经做过这项语义检查；只查某部分就如实说明范围。具体空间核对见[空间连续推演](spatial-continuity.md)，交付核对见[终检](final-check.md)。

修仙/仙侠战斗先让采用的法器御使、术法控制、感知、空域或破法真正决定战术，按[修仙战法](cultivator-tactical-combat.md)补当前缺项，不把全员转成武者加光效，也不强制技能清单。预期、揭示、施法识破与负载比较按[信息与反应覆盖](../../action-camera-direction/references/information-led-coverage.md)安排观看；人物反应、手部变化、对手应对和术法整体可往返，画外事件仍在同一时间推进，返回不重启起手。每招不固定三镜，固定/一镜到底用画内变化兑现。

高频施法、怪海、规模递进与关键冲击画按[高速与大场面写法](high-frequency-scale-writing.md)把短促发动、在途接力、多层威胁、主形/首触/范围传播与正向约束写入原稿。保留画质、动作美感、速度力量、必要情绪/形成/受压读取和原格式，不将新样本的时长、配色、配额及禁令覆盖全库。需要追溯时读[最新学习依据](latest-combat-study-20261010.md)，普通创作无需重看全部素材。

用户参考反馈涉及多人连续战斗、一镜到底、动作模组少或接触响应时，按[六条参考迁移索引](six-reference-study-20261015.md)只取对应方法：战斗用镜内接力与接触/高低组合，人物互动用触点和器物任务响应。设计阶段进入事件和观看，终检查实际采用；文戏不套快战，全场不因参考四人就变成团队战，宣传字幕不成为平台能力事实或执行指令。
