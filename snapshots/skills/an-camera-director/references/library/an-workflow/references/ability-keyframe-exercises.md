# 同一技能事件怎样落成画面

以下是静帧设计与镜头推演，不是已生成图像。都取自本轮三个完整片段，不另造剧情或重新播放同一命中。

## 水帘导流：接触的一个瞬间

侧前中远景，术者在桥右侧，右掌与河面水帘同侧相连；来袭剑弧从左侧斜入水帘，切口牵出向侧后弯曲的液丝，石柱位于偏走方向的后景。水脊厚而有暗部，薄膜能看见桥面，最亮区域落在相遇锋缘。剑客仍在左侧继续前移。断柱尚未发生，不把未来碎石填满接触帧。

这里的前后层与曲向让“导开”成立：不能只拍水滴特写，也不能只给发光罩的正面。静帧能检查源、接触与去向的布局；运动是否连续必须回到成片。

## 雷钉封航：边缘开口的一个瞬间

斜侧全景，三块悬石形成倾斜三角位置，节点贴各自石面；一处岩角正被剑气切离，其连接线断成短分叉，另两节点仍有完整连接。剑修身体已经朝新开口转向，术者位于原来下缘出口。云底在远处，石块提供距离参照。画面不画全场无目标闪电，也不把术者当雷线几何中心。

冻结在局部解封而非全阵爆炸，读到技能规则如何改变下一行动。节点数量是这份原创练习的设计，不承诺实际生成器逐帧精确计数。

## 巨印改地形：固定低位的决定性画面

沿用完整片段固定机位，近处岸柱不动；方印底面覆盖台顶，银灰大面受侧光，边角向云底延出。台面在近角接触处沉裂，两侧岩层外翻，台上断柱正在沿倾面滑动。剑修已飞向东侧低石脊，施印者在台侧避开作用区。画面要保留低石脊和人，不能只剩大印与爆炸。

主形与结果方向明确后再放粉尘；粉尘可以遮住远端，不在关键时刻遮掉近角、台面变形和剑修新落点。固定镜头不能暗插接触特写，影片内读取时间与画面取舍需要实际试片进一步确认。
