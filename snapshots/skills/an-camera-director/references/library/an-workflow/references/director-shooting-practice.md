# 导演拍摄实践：从排戏到镜头覆盖

用于明确学习导演怎么拍、现场调度与拍摄方案、镜头覆盖缺失或准备/排练问题。与整场语法、摄影及表演共用一份方案；普通提示词只回填最终决定，不额外交付片场表单。

## 从剧本拆成可拍的戏

锁定事件、原词和结局，找出此刻要拍清的行动、关系及转折。把“伤心、紧张、高级”落实为可表演的任务与可拍的证据；并非所有戏都需要策略反转，观察、等待和生理变化也可独立成立。针对关键节拍确定谁在行动、谁在接收、证据在哪里及什么时候出现，再选择视点和拍法。

勘景不是只找漂亮背景：门窗、可用通路、桌椅、视线、声源和可退机位共同决定怎么拍。已有场地按实际限制调整；未知场地在获准范围内设计，不把练习房间和道具迁入用户故事。实拍要结合容机、收音、演员和光区；二维/CG可用等效机位，但不靠虚拟相机替锁定剧情补不可能的交接。

## 排戏与排镜分别解决什么

**排戏**观察演员对手关系：给可执行的任务、对象和阻力，试走位、停留、接话与持物；不要只喊“再悲一点”。情绪结果和动作意图可以一起讨论，不能把行动动词变成逐字配额。具体脸部、气息和疼痛设计沿用人物表演技能。

**排镜**从镜头实际位置观察：表演关键点在不在画内，前景是否遮脸或手，转身时什么还能读到；对焦、光区、跟随、停机位及声源是否能配合。人物不必每一步踩死标记，关键接触、焦点或落幅需要锚点时才精控；有意保留自由变化时，让摄影/布光有响应范围。演员发现的有效行动可以修正摄影，不为旧分镜强行扭曲已锁身体姿态。

吕美特的预排与毕格罗较松的调度说明不同组织方式都能服务表演。不能据此规定排练次数、take上限、全手持或全多机。现场实践依据见[来源与提炼](shooting-practice-research.md)。没有演员、片场或摄影机时，只能称空间/文字预演，不能称完成演员排练。

## 镜头覆盖要给剪辑留下什么

覆盖是取得足以组织这场戏的画面与表演材料，不是拍齐远中近和双方头像。一段完整调度可以承担多项职责；局部镜头只承担它能看清的事。

| 拍摄选择 | 何时有价值 | 取舍 |
|---|---|---|
| 关系主镜/长段表演 | 同时读取任务、走位和距离变化，保住事件骨架 | 不自动要求整场一条用到底；小物件或微表情可能读不清 |
| 共框双人/多人 | 决定性变化发生在互动、等待或身体接触中 | 可省去反打，但遮挡、占幅和焦点必须容纳证据 |
| 越肩/单人/干净单人 | 需要限定站队、读脸侧或从关系中隔离一个人 | 不因谁说话就必切谁；肩部遮挡要与空间成立 |
| 动作/道具局部 | 局部变化是因果证据，主镜尺寸不足 | 拍到动作相位与归属，不能用不相关插入镜掩盖缺失事实 |
| 听者/画外后果 | 真正的转折在接收、拒绝或后果中 | 接话、眼神和前镜刺激相容；不要求每句另拍反应 |
| 持续长镜 | 连续时间、共同空间或等待本身承担体验 | 容易约束后期删改；需要可达路线及整段表演，不等于取消设计 |
| 机动/多机覆盖 | 自由行动或难重复事件需要不同观察窗口 | 光线、轴线、互相穿帮与注意重点需协调；不自动把镜头数量当收益 |

关系主镜可以是一个过程，也可以是分段连接的骨架；它不必最先拍。镜头、机位设置（setup）、take与成片切镜不是同一单位。一个设置可以取得多条可剪的材料，一个连续take也可以在成片中被分段使用。AI提示词写观众最终看见的镜头组织，不把实拍设置数误写成同时生成多个clip。

对实际要剪接的材料，保留动作接入/接出与必要声音衔接；素材前后余量是拍摄材料，成片只计使用的时间一次。逐字对白锁定时，换take/换镜不擅改词，也不能自动授权即兴对白。

### 连续拍摄也要排观看覆盖

选择长镜头时，先找出整段必须看见的反应、身体、关系与范围，决定它们通过接近/退开、画内调度、朝向/高度及焦点怎样依次或共同可读，再排人物与相机路线。不能把取消切镜等同于只留一个等大陪跑主镜，也不能为了补覆盖让演员停下来等摄影。

纸面排镜检查每次进入下一观察位置的通路、净空、相对速度、焦点与构图落点。现场设备交接属于实拍组织，连续虚拟相机也须有路径；剪接拼成的一镜感与真连续镜头分别说明。保持同一景别若能充分读到表演、步态、等待或空间可成立，不用覆盖数量评分。参见[连续观看执行](../../cinematic-camera-design/references/camera-execution.md#连续长镜头的观看发展)与[本轮同条件演练](../assets/cases/camera-progression-20261015.md)。

## 从机位与焦段走到现场选择

先试镜头位置：沿当前场地看实际人物投影、遮挡、距离及所需脸侧，再按画幅匹配视场。近处宽视场可保留人物与场景接触、放大近远差；较远机位配窄视场可隔离表演或叠压关系，但可能丢失路线和周边行动。两者都能亲密或压迫，选择依当前戏；不是固定情绪对焦段表。

相机参与的程度再决定固定、可响应手持或稳定移动。人物位置变化足以改写关系时可保留固定；需要跟随行动或改写观看距离时移动；同一机位转向另一证据用摇摄；需要突然改变主体与背景关系时再考虑dolly zoom。具体路径、构图、焦点和特殊拍法由摄影技能落实，本模块不重复参数库。

对近景需微调演员朝向或道具角度（cheat）时，区分为相机改善可见性与真实剧情行动。微调不改变已锁姿态、接触、持物和关键空间关系；有冲突就调整机位。不能借“电影允许作弊”把不可能接触合理化。

## 背景人物与场面组织

背景按任务、入口出口及主角节拍安排。有人停留、有人行动，穿行有目的和不平均的时机；重点台词、关系变化、命中或揭示发生时，核对近处的人影、亮色和动作是否抢走证据。背景群体受事件影响后按区域和可知信息响应，不能主角动作进行时所有人冻住，也不能每人同时做同一种反应。

前景遮挡可以承担偷看、阻隔或揭示，但应有进入、停留和退出时机；不能仅为“层次”不断派人经过。少量群演可以按空间与取景组织有效层次，提示词不能只靠镜头名称承诺海量人群。这些方法取自[DGA背景调度实践](https://www.dga.org/the-guild/councils/west/western-adupm-council/committees-of-the-adupm-west/standing-ad-upm-committees/first-ad-committee/setting-background)的相关部分；不照抄其中的时代性管理习惯或审美绝对句。

## 拍摄顺序、接戏与现场调整

成片观看顺序按体验组织，实拍顺序可依灯位、方向、场地、演员和重复成本组织。非顺拍必须保留人物此刻已经经历的刺激、情绪/体力阶段、道具与湿痕；同一事实要连续，表演不是把每条眉毛轨迹复制一致。相邻素材的接触相位、视线对象、行动方向和声源须能接上。

时间不足时，按场景决定性行动和可剪接性保住骨架，再取真正读不清的局部；删除冗余备用角度优于留下漂亮局部却没有转折。自由即兴与锁定一镜到底的需求不同，不能把“少覆盖”定为高级原则。换机位、改路线或选不同take后，重看受影响的焦点、光区、轴线和接戏；已经成立的部分不全盘重做。

看回放时把问题定位到事件阶段：没演到、演到了但被取景遮住、当前占幅读不清、或单镜成立却接不上。先改造成失败的表演/调度/机位关系，不仅加形容词、快切或重拍同样条件。无成片时只检查文本，不能声称已证明镜头效果。
