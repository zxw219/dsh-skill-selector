# 2026-10-17全面检查后的增量优化

用户先要求检查各模块，再授权“优化”；对象为An工作流来源及其分发，不是重写上一份作品。本记录用于维护追溯，不进入普通创作默认设定。

## 实际采用

- 统一特殊能力快战的固定/短促制动边界，修手册旧例外；An/上游职责与外部MOKE MCP资料服务分开，保留真实平台技能名。
- 动作模块由24扩展至40，新增长短相遇、双持分工、软器张力、重器回收、已有盾/失物、受截换支撑、支撑失效、阶梯/移动面、控法减载、旧状态换用途、配合失败和第三来向；另建按当前出口检索的条件索引及受阻组合。
- 摄影增加八类复合路径及同事件取舍，覆盖高低、攻击端/接收端、局部/范围、领先/让过、追平取位、遮挡/深层、空域和人物关系接力；接入摄影来源、主入口与对应提取功能。
- 场景、表演、分镜、材料机制、冲击形体、声音/时间、唯一对象状态、事实保留编译、光色/媒介、大场面和舞蹈补具体候选与原创建构案例，保留原用户边界。
- 主入口将条件细则移入[采用展开](combat-adoption-routing.md)，保留主要默认、执行链和原章节锚点；未删除迁出的规则。功能映射的12个入口各增加负责的读取路径，扩展规则与原来源继续保留。
- 检查器增加显式可选`--event-times absolute`：只验S内绝对t=数值范围及行动书写顺序；对白引文、效果声画回指、续写绝对时间、近似或不明节点分别处理。默认review模式与已有API兼容，语义和视频仍不自动验收。

## 作者情境复核

以下是维护作者依据修订来源作的边界与采用推演，不是独立模型输出、动作排练或真实视频：

| 情境 | 采用决定 |
|---|---|
| 按图无盾、需要丰富打斗 | 从既有兵器/身体/能力取结构，不取W9；丰富不授权补装备 |
| 纯远程、一个已锁能力 | 取相容F结构和既有状态用途，不因新库加入腿技或新神通 |
| 明确慢速固定静音展示 | 保留锁定节奏/拍法/声音，以身体与画内变化处理，不强制快速摄影 |
| 只改运镜、上游动作已成立 | 选复合路径和覆盖取舍，不为镜头新增攻击、翻滚或空间跳跃 |
| 双持一端被压或软器被截 | 被控端保持受限；自由端有真实净空，松器/长度/回收状态继续 |
| 配合窗口失效 | 利用者从真实位置重组任务，不再消费旧窗口；第三方不自动视为队友 |
| 人物快战与巨物变化、表演同窗 | 每拍分主读，其他层同时间继续；返回接已推进状态，不重复形成 |
| 20秒后续写、t=0.4局部数值 | 显式absolute模式报告范围错误；默认review不擅自更改相对语义 |
| 只给30秒或泛称即梦 | 保持版本中立，不切入2.5专属模式，不让平台默认覆盖上游时长 |
| 报告之后泛称“优化” | 继续来源维护并同步；只有明确改作品才转作品对象 |
