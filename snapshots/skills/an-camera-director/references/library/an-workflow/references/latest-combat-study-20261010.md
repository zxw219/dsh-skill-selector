## 视频二次复查的实际范围

围绕修仙者战法、预期/揭示、施法识破、控制负载和画外持续时间，重新查看既有带源时间图页34张：完整预告27张，第一段剧情参考4张，第二段速度/力量参考3张。完整版与第一段有同源画面，不作为两个独立证据。完整源视频及两段参考的SHA-256已与先前记录核对。

| 源范围 | 采样画面中的关系 | 采用方法 |
|---|---|---|
| 完整版91–105秒 | 人物意图、群体离地、水面异动、巨兽逐步显露与危险部位 | 征兆—空间—来源—有效危险，不把脸直接判成恐惧 |
| 完整版112.75–140.75秒 | 腕/身体引动，粉色形体发展与释放，包覆，施者维持/落地，目标挣动破束 | 手势改变术式，形成期双方继续，法术—施者—目标比较负载 |
| 完整版141.25–149.5秒 | 反应、另一人物观察及介入 | 反应接下一任务，不只插情绪脸 |
| 完整版158.833–171秒 | 转头/肩后危险/巨口，近脸与侧移，防御受力和位移 | 已知危险的新角度，不冒称首次揭示整只怪物；挡住仍会退距 |
| 完整版177–186秒 | 防御面承压、同一防守者空手橙色反击、目标响应 | 控制资源相容，画外压力不断，归属由源端确认 |
| 完整版186–200.875秒 | 防御退出，实体剑取出/离手，指诀与剑列，同伴被框景/见证/参与，发动与接收 | 法器状态与控制成立修仙战法；反应镜保留运行术法与共同空间 |
| 第二段约14–18.25秒 | 抬眼、肩后对象、更宽上方结构、逼近压力 | 人物注意使观众等待，再揭示具体来势 |
| 第二段约22.5–29秒 | 身体/脸/脚承压，对手手势与武器变化 | 对抗中往返观察，起手与应对共用时间 |

证据为抽帧与图页；此次未正常速度音画连播、未试听、未审计精确硬切边界，也未生成修订片。完整版时间有源PTS，短片旧标签是近似采样时间。若源画面是同镜运动/焦点变化，不把每个采样当一个硬切。采样关系不证明实际焦段、摄影轨道、精确速度或修订后的成片质量。

人物称谓仅用于辨认；没有可靠证据时不考据正式技能名、境界、未知增益和未展示的终击胜负。把“目标继续挣动与破束”记录为事实，“不畏惧”作为观看解释。原创迁移的神识、法域、法器用途按新场景定义，不反向算成参考原作设定。

## 五份提示词的学习范围

用户指定文件夹内五份文档均完成原文读取，包含61段文字镜头设计与40条方法。旧DOC以文本结构提取，未执行文档内生成/发布指令，原文件未修改；方法用于写法和设计迁移，没有对应视频验收。

采用内容覆盖：画质与材料/配色层级/随动；怪群来源/深度/主动威胁/补入与旧残留；连击/高速驱动/短促释放/身体与战法/地形/空战；本体与在途效果；不同传播形态/成形与发动/首触与范围传播/层级破坏；冲击画/受力摄影/越肩/低位视差/范围构图/切接与锚点；微表演/正负约束/余波与原格式。

来源中的30秒、画幅、配色、速度/动作配额、长定格与禁止词只属于原稿选择。互相冲突的“全程高速/长静止”等在新稿按用户意图择定，不变成零停留禁令；源文件标题与正文不同的地方不凭标题补不存在的内容。完整用途与边界见[40条方法索引](../assets/reference-studies/latest-learning-20261010/prompt-methods.csv)，来源哈希和证据范围见[来源清单](../assets/reference-studies/latest-learning-20261010/source.json)。

## 当前完整迁移案例

[《霜烬破关》60秒修仙分镜](../assets/cases/cultivator-storyboard-60s.txt)沿两张角色图、9:16、无对白、剑印争夺—反噬—相救—合作—破枢—取印，改用离手御剑、祭器控域、御空、护体与有依据的感知。包含危险预期、施法识破、术法负载/施者/目标、发现阵枢与参与回收等具体镜段。

它是已写出的原创文本样例，37镜和相应时长不是所有作品模板，也不是新的平台控制精度。学习、文本结构/语义复核、安装/打包验证和视频生成验收分别报告。
