# 容量、项目状态与定向返工

只启用当前任务所需小节。一次性短提示词不建立项目台账；本页不改变MOKE模板与用户交付范围。

## 容量瓶颈

已有剧本先执行[剧情时长](narrative-timing.md)：粗核锁定内容能否容纳，再在观看设计成立后精排，顺序与并行分别计时。声轨、身体行动和信息读取共用一条时间线；不能将本来同时发生的“事件+念白”简单求和。

长对白、多步顺序动作、跨空间调度或明确超时反馈时，在动笔前估算：必须顺序完成的对白/动作/移动/辨认时间，加不能重叠的停顿；能同框读清的并行行为只计算一次。切镜本身不机械加固定时间，计入的是新信息建立和阅读成本。

对白优先依据已有录音或按语言与角色语气连贯试读估时；无音频时将估算与实测分开，不以统一汉字数/秒推算外语、哭腔或复杂停连。急促、平静、发颤、讥讽不能全部按同一种慢速处理，也不把标点统一折算成停顿。无实际配音时称估算，不声称测得发声时长。

分开处理声音占时、动作占时与画面切换：对白跨三个镜头仍只计一次完整发声时间；听者表情、说话者手势与同期运动可并行，不能各自加一段时间。切镜无需额外停顿；接话可在上一句结束处立即发生，必要时由下一人声音先入再切画面。锁定台词不能借“打断”吞字，也不能让重叠对白不可辨。

总长自定时从这些占时合计，不先定整齐的两分钟再补满，不给每句话取整成5秒、10秒镜头。短镜用于即时证据或冲击，较长镜用于持续变化；不按比例配额或固定秒数轮换。缩短先删除说完等一秒、重复表情、慢推尾巴与多余环境停留，再考虑用户授权范围内的结构调整。

每段对白之后核对：最后一个字何时结束；其后仍在发生什么；下一句能否在反应期间接上。停顿没有持续任务、策略或节奏作用就移除；必要的悬念与沉默保留。估算有余量时分配给真实换气/动作，不把余量变成每镜结尾的空等。给关键转折、动作结果和结尾台词留时间，不能开头铺满后把结尾塞进剩余一秒。慢动作按最终屏幕时长计入。

估算明显超出时，在用户授权范围内先合并重复表达、并行动作；不删锁定剧情和逐字对白。用户允许时间自定则给合理总时长；固定时长且无法容纳时，用短说明给可选自然切分/增时/改稿取舍，不先生成完整超量稿再倒填数字。最终仅复核改后的瓶颈，合并到入口的一次检查。

自然边界可落在动作完成、发现、情绪变化或对白结束，但不是到冲击就必须截断。完整反转所需的揭示和反应属于当前因果链。分段不加固定全景，不让追逐为收尾停下；特写、遮挡和离画不自动改变在场名单。

多主体快战先安排少量完整战术节拍，每拍可含沿同一路径承接的多次攻击；不是减少用户要求的攻击密度。核对队友创造条件、接应移动、命中和观众辨认所需时间，只有实际可并行的行为才重叠。别把新敌人、新招式、新机位和新法术规则同时连续引入；优先复用已建立路线和目标关系，减少无功能观光镜头。

打戏按双方共享时间估算，不把“甲完成组合→乙开始反应”默认排成串行，也不以“同时”省略必须先完成的脱开、落脚、转体和接近。关键瞬间抽查另一方处于追击、封挡、受力、恢复还是被迫受限；无依据的空白先补动作。高密度不是给每秒塞固定招数，而是减少无战术作用的等待，保留连招所需的受力和恢复。

维护或返工时，可对易失效的小段做不交给生成模型的双轨推演：同一时窗分别列双方行动和交会点，再对照实际正文；没有写进正文的动作不算已交付。只记录影响结果的方位和接触，避免全程逐帧填表。若正文只有“激烈交锋数回合”，它仍是动作缺失，不能用稿内推演替代成稿。

有主峰值时先留出主接触、抵抗失败与结果可辨的成片时间，再排前置配合；准备可短促或与行动并行，破坏过程无需统一慢放。允许快切中保留较完整的主命中，不以平均分镜长度或每秒招数作为速度保证。文案只写会改变动作、结果或观看的内容，共享设定不在末尾重复全套禁令。

用户反馈“时间太长”时结合其上下文区分总时长、蓄力/停顿拖沓和描述冗长；明确要求缩短则重排战术拍、配合和高潮时间，不等比例压缩原时间戳。不把15秒设为默认解法。仍保留硬时长时优先改善节奏；必须改变事件、时长或提交单元且尚无授权，才说明具体冲突。文本可排下但接触/换位负载仍高时，报告为待实测风险。

## 项目事实与范围

多人与机器/场景交互计入信号接收、机构行程、承重交接及人员通过时间；可并行的掩护或准备不重复加时，需要等待到位的动作不能重叠抹去。降载优先减少无关交互支线和重复机位，保留完成任务必需的参与者与功能；不因人数多直接删除队友，不要求每个成员平均分配时长。

项目默认设置、当前段临时设置分开。用户说“仅这段”后，下一段恢复已确认项目默认；说“后续统一”才改默认。真正有歧义且影响提交才问，不对明确临时例外再次确认。平台上限仅使用当前已核验或用户明确提供的依据；用户期望时长不等于平台支持。

已确认剧本/资产索引未变时，只定位当前段及少量相邻证据；不重复全文读取或全量看图。来源区分原文、用户确认、实际观察和创作补足，模型补足不冒充原文。现实依据只证明所见结构或文字，不覆盖虚构设定。

对照相邻段核对昼夜、地点、服装、伤痕、人物知识、持物和结果。新指令已经明确解决旧冲突时直接继承；仍有两个有效事实互斥、且影响制作时，只指出冲突与影响，暂停受影响部分。助手自己写出的断链直接修复，不把每次纠错都变成用户审批。

## 最小续写状态

只维护仍影响后文的事实，默认留在对话中，要求保存才落盘：

`当前版本/范围；已确认基调与禁用项；默认/临时时长；已交付位置；下一起点（场次+首个未写事件+入口状态）；必要身份/位置/朝向/持物/伤痕/已知信息；实际素材与音色映射；未解决项。`

继承状态不用一份全人物表重复每段。独立生成单元的自含要求见[生产控制](production-controls.md)。批量交付按用户范围完成，逐段模式只续当前段；没完成整场不能报整场完成，全部覆盖后不假造下一起点。

提示词交付、文件保存、视频生成、媒体验收、用户采用分别记录：保存失败或视频失败不回退已交付文本；自审不等于用户采用。返工保留同段身份并增修订版本，不重复占新段号。

用户要求带领制作时才简述当前步骤和必要下一步，可按剧本→基调→可选资产→提示词→结果→交付推进；已明确任务直接进入对应步骤，不强制逐关确认或每轮菜单。

## 定向返工

先分清输入是提示词、静帧、视频还是接口报错。静帧只能支持可见身份/构图/接触判断，不能证明完整节奏、速度和死亡过程；缺少关键时间证据时报告未确认部分。平台失败不靠堆提示词掩盖。

用实际失败证据确定最早偏离点，保留已正确的内容，仅补必要状态转换并检查依赖。用户有多个独立问题，可在同一稿内分别修复；有因果依赖的先修上游，不强制每个问题再开一轮。因果已清楚就删除重复强调，不累加历史负面词。

用户指出战斗内容不足时，先复核目标、主动权和连续攻防，再处理位置与模板。不能把取消交互、始终留出不受威胁的通路、让对手等待或追加万能能力当作消除bug的方法。确需改变原设计时说明改动如何保留原来的观赏承诺，别只报告规则更多或字数更少。

实际生成试跑只在任务包含生成时执行；修稿完成不称成片已修好。下一轮只复核新结果与受影响项目。

## 战斗的声音辨识与重音的参考学习增量

声音获准时，按角色/技能建立起势、来势、接触和结构响应的辨识与主次；接触声/余响可跨切镜衔接同次作用，音乐与留白按本场目标选。原对白/无音乐/静音范围保持，只有实听才迁移原音轨、乐器或卡点，包络不等于试听。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。
