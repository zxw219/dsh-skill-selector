# 运动语言：跑动、力量、角色差异与巨物摄影

用于“跑起来像走路、人物滑行、动作转换缺失、机械与仙侠同招、巨物像玩具、广角无压迫”的设计与返工。与[action.md](action.md)的双人交锋共同使用；先修身体运动，再加光迹和摄影。下述是按设定选择的方法，不是所有人物必须奔跑、翻滚或每镜低机位的配额。

## 先辨别实际故障

针对成片“逻辑成立但像摆姿、没有速度力量、只有音效”的反馈，补读[速度、传力与动作观感返工](../../combat-action-design/references/motion-impact.md)，实际重编失效运动。该页维护本次成片案例、身体领随与曝光/播放边界，本页不重复扩充同一套规则。

| 画面问题或输入缺口 | 优先改变 | 不能只做 |
|---|---|---|
| 大步走却标注冲刺 | 步态、躯干推进、蹬离与着地相位、地标跨越、接敌距离收缩 | 放大步幅、加长拖尾 |
| 腿跑得快，身体原地滑 | 支撑足相对地面稳定，身体前移与脚步周期匹配 | 加快摆腿或整个背景贴图平移 |
| 移动突然变出招姿势 | 最后跑步如何变成支撑、让线、转体与武器路径 | 以切镜、白闪省掉换步 |
| 打得轻或像水下慢舞 | 动作速度变化、接触负载、目标反作用、制动承接 | 每击都慢放、震屏和爆炸 |
| 大机甲像放大的人偶 | 机型动力与姿态、大小机构响应差异、环境尺度、启动与收势 | 统一慢速、每关节抽搐 |
| 仙子只拿剑互砍 | 按已定能力使用移动施法、飞剑控线、御剑换位及对手应对 | 添加名字不同的同色光波 |
| 镜头很广却无威胁 | 摄影距离、人物与威胁相对占幅、逼近速度和可用空间变化 | 只填“超广角、百米巨剑” |

没有视频时，只能根据用户报告及文字定位风险；不能声称已看见某一帧脚滑或已修复模型动画。

## 步态和动作转换

先决定当前运动方式：走、快步逼近、跑、冲刺、侧移、跳跃、滑行或飞行。不同阶段可以转换，正文写决定观感的支撑与位移，不交逐关节清单。

- **走/快步**可承载搜寻、试探、重装推进，不能无因全部替换成跑。通常以交替承重与连续足地接触读清，速度按场景。
- **常规双足跑/冲刺**应有蹬离、短暂腾空、前脚落下接重的可读节奏；重心真实前移，不是直立跨大步。起跑可用压低躯干、蹬伸和逐步建立步频；持续高速不必每步大幅上下弹跳。特殊贴地步法或非人结构按设定，不拿腾空作为所有高速运动的硬门槛。
- **持械跑动**先适配武器：持剑臂保持刀尖净空、肩肘随跑动有限调整，空手配合平衡；不要求双臂都大幅摆动又同时双手举剑攻击。硬质装甲不套皮肤的拉伸压缩。
- **跑→斩**：来敌距离进入武器范围时，跑步接重转成进攻支撑，髋肩与兵器接续；不要先站直摆造型再挥。支撑足不无因滑过地面；有意滑步须交代摩擦、动势和结束方式。
- **闪→反击**：攻击线决定闪避。侧步让出刺线，俯身避开适当高度的横扫；随后的转体/换步把身体和武器送入反击距离。只写“侧身”不保证胸口已离开刃路。
- **翻身/翻滚→再起**：只在障碍、攻击高度或落点使它有用时采用；给起跳/接触、越过范围、落地吸收、转为下一支撑的桥接。持剑不能同时用同一手撑地，不凭翻滚穿越仍在扫动的兵器。少转一圈不等于少动作，删掉无用途的炫技复位。
- **制动/转向**：惯性由换步、弧线、支撑或已建立的动力承担。轻型机器可以迅速转向，重装也可以爆发；不能只用“瞬间”跳过使下一动作成立的动力与支撑。

动作乐句应有可识别的节奏变化：接近、爆发、碰撞、承接可以高速重叠，不是同一匀速插值。准备可藏在跑步和上一击回收里；“动作干净”是没有无效绕圈与重复复位，不是省略必要的脱开、接重和追入。

## 速度的三种证据

### 把匀速动作改成有冲劲的动作

先在同一动作内决定“哪里压住、哪里骤然加速、在哪里承力、如何余势接续”，再定镜长。总时长短与运动快分别验收：两人距离长期不变，即使半秒切一镜也没有逼近；全身匀速漂到下个姿势，即使有尾迹也缺少爆发。

- **预备嵌入战斗**：蹬地前压实支撑、回收时收紧髋肩、格挡受力时短促压缩，为紧接的爆发提供可见依据；普通连击不逐招摆完整蓄力姿势。大幅爆发需要相称的发力过程，不能由“瞬间”跳过。
- **爆发要越过参照**：人物在一次蹬伸中越过地砖缝/柱边，原来的空距快速缩到接触距离；身体真正前移。正面后退镜头退得慢于追入者，使对方占幅突然增大；侧跟镜头保留足下和近处地标，不只看漂移背景。
- **接触后传力**：轻偏转可以短促，重击应见护臂被压、肩背跟随、承重脚抢步或结构受损。关键作用点短暂读清后马上承接结果；慢动作若采用只承担具体识别任务，不铺满每次命中。
- **回收不断线**：攻击端减速/被偏转时，追步或下一空闲肢体已经准备；受击者努力接重，进攻者继续逼近。恢复过程有负载，不能轻飘飘摆回原位，也不能删掉恢复直接复制下一拳。
- **身体部分错相**：躯干先加速，发梢、外套与挂件因惯性稍后跟上，制动后继续摆动再收束；硬金属不随之软化。材质变化帮助读速度，但不独立占用一段停战展示。

无视频时只判断是否给出了这些可执行证据；帧间距、逐帧停顿与精确速度曲线仍需生成或动画实测。未知模型不许用固定帧数保证效果。

1. **身体真的前进**：给可辨的起点和终点、跑姿变化、接敌距离收缩。优先用已建立的柱列、地砖、栏杆或建筑尺度；缺尺度时不用虚构精确米秒宣称物理核验。
2. **世界给出参照**：侧向跟拍保留足下与近处栏柱的快速掠过，远处楼体位移较缓；前向逼近可见人物占幅与距离变化。相机等速跟随会抵消主体的屏幕位移，但不能连脚下接触、固定地标和目标都被抹掉。纯旋转摇摄与平移视差不同。
3. **光迹辅助读路径**：已建立发光部件/剑刃留下沿真实经过路线的短尾，人物在当前端、旧位置尾迹逐渐衰减；转弯保留弯曲旧轨迹。拖尾不等于分身，不与实体同时形成多个攻击者。暗影式残像属于风格化表达，不能冒充正常照明产生的真实投影。详见[vfx-finishing.md](vfx-finishing.md)。

力量与速度不是同一指标。快速小幅偏转、沉重推进、爆发重击可共存；通过支撑—躯干/机构—兵器—目标的反作用读清来力。超自然远程术法不强制给施术者物理后坐，力量可由承受者、障碍和场域变化表现。音效与冲击帧跟随事件，不代替事件。

## 人设落到不同运动语法

稿内选定当前角色的动力来源、常用距离、移动/防守方式、施力和收势特征；仅把影响本段的部分写入正文。下表是可选角色设计，不凭外观追加装备或万能能力。

| 类型 | 动作辨识度 | 攻防与力量证据 | 要避免 |
|---|---|---|---|
| 轻型机械剑士 | 紧凑快跑、短行程换向、目标明确的出刃；可见关节驱动与接重压缩 | 受力后装甲小件短促回弹，躯干随连续动势接下一招；准确但不僵直 | 每关节顿一下；把柔性身体和硬壳都写成软胶；无设定新增喷口 |
| 灵活型巨机甲 | 长距离跨步、短促爆发，借支撑改变方向；有设定才用推进器 | 足部承重、躯干随动、制动负载与周边物件尺度；快动作仍传递质量 | 体型大就全程慢；手脚乱舞、落地后无负载 |
| 重装巨机甲 | 更早组织承重和启动，推进后难以立即回收；短路径攻击 | 重心越过支撑的连续过程、接触传力和收势代价；不是每步必震城 | 全程同速慢镜；笨重等于低效画圈；惯性突然清零 |
| 修仙剑修 | 地面换步干净、让线幅度经济；按设定将法术并入移动与回收 | 飞剑改变对手路线，术法封区迫使抢窗口；本人同时避险、追压或守目标 | 冷兵器对砍外贴光效；每次施法都停步舞袖结长印 |

飞剑、御剑和手持剑要区分：离手攻击说明剑从哪里脱手、谁控制、沿何路径折返；御剑载人说明剑如何到脚下接重、身体何时上去和何时离开。若全场只有一把实体剑，它不能同时在手、脚下、敌后；分剑/剑影必须是已建立的能力。急转与升降由剑路/术法引导，人物姿势和衣料承接运动，不能让身体锁成立像在空中平移。

法术压迫可来自快到封住退路，也可来自大到限制多个方向。先给作用范围、逼近或生效过程与对手必须改变的行动，再选巨剑、禁制、剑阵等表现；不是所有修仙者都巨剑化，也不强加慢速吟唱。

## 镜头职责：环境、身体状态与压顶

“广角镜头”是视角选择，“全景/远景”是主体占幅，两者不等同。近距离广角也能拍近景。透视取决于观察位置和距离关系，换焦段但不换机位不会独自改变物体的前后大小比例。

| 观看任务 | 机位与证据 | 风险 |
|---|---|---|
| 环境和路线 | 从能读清入口、出口、障碍和交战方向的位置取广景；让人物沿其路线移动 | 只有空环境，人物细小不可辨；无因每镜定场 |
| 跑动/腾挪状态 | 中全景或全景、侧面/斜侧机位保留支撑脚、重心和武器；近景用于已建立后的细节 | 全程腰上跟拍后声称跑姿成立；脚贴边畸变 |
| 近距离速度威胁 | 低侧机位看冲刺贴近并越过参照，或退移慢于角色以显示距离被追上 | 相机无限等速后退、距离恒定、目标一直到不了 |
| 巨剑压顶 | 在落点外侧的低位仰拍，近处人物/栏杆、中距屋檐与下降剑体互相遮挡；剑身逐渐切掉天空，剑尖逼近既定区域 | 只拍天空孤剑；相机与剑等速下降让参照冻结；近物截幅误当实际体型 |

巨物同时需要整体尺度依据与局部压迫。可以前镜用楼层、山门或人的比例建立体型，后镜贴近局部出框；无须每镜看见整个巨物。位于天空的薄云只是辅助深度，不如已知建筑可靠。光源、实体遮光与投影方向一致；纯发光剑影不自动遮日投黑影。

天降巨剑示意（原创设计，非固定模板）：先见对手在落点区域内试图突围；从区外低机位保留前景人物与中景檐口，剑尖越过屋脊高度、剑身继续向上出框。对手沿已建立缺口疾跑，施术者用既有飞剑拦住直线出口，迫使其变向；巨剑落下改变通路。具体闪避能否成功由起始距离、下降窗口和剧情决定，不能在文字里先等命中再瞬移出去。

## 身体表演与材质响应

成人角色的非露骨魅力表现可使用服装轮廓、肩背姿态、腰胯重心转换、转身和落地的整体身体线条；水珠有雨/水来源，红晕有情境原因。镜头需要拍到身体时不能全部替换成脸部特写。软组织、头发、衣料、硬壳的响应不同，硬甲不软化，衣物运动不无因变透明。这里处理自然表演和材质连续，不设计以胸臀抖动或私密部位为中心的色情化展示。

开场展示可以处于危险出现之前，或由明确距离/遮挡提供窗口；展示结束用发现威胁、转移重心和起跑接入战斗。不能让已经挥来的刀等一段姿态展示，也不必把所有魅力镜头从作品中删除。

让用户要求的非露骨魅力在正文有真实取景：例如成人角色侧身让开攻击线时，以斜侧中全景保留肩、背、腰线和承重腿，外套滞后甩开但内搭保持覆盖；落脚后视线先锁住对手，再由下颌、肩线和重心变化接入反攻。可表现从容、挑衅、锐气或受压后决绝，选择符合角色的气质。避免把整段写成服装说明或仅在负面词里禁止走光，却没有任何姿态、构图和表演设计。

魅力窗口与交锋共用时间，镜头必须说明此时对手在做什么及为何不会已然命中。取景以完整动作与主动性为中心，不把胸臀或私密部位的抖动、受击和疼痛作为色情化观看焦点；“完整衣物”本身不改变这种焦点的性质。具体边界说明一次即可，后文落实合适的画面，不堆反复禁令。

## 定向验收

无视频先做纸面移除测试：去掉“快、重、仙、机械、巨大”后，仍能从步态、接触、施术、体型参照和镜头位置分辨意图吗？去掉拖尾后人物还在真实接近目标吗？换掉角色名字后两人的行动方法还有区别吗？这是设计诊断，不是运行时保证。

有视频先正常速度看威胁与节奏，再抽查起跑、支撑、腾空/飞行、制动、接触、落地和跨镜接续。检查脚滑、身体平移而腿慢摆、无支撑转招、轨迹残像变实体、武器复制、尺寸随镜头改变。针对失败单元返工，不用一帧漂亮画面验收整段，也不承诺文字规则消灭生成崩坏。
