# 不同战法的校准与反例

以下是原创文字校准，不是参考视频原机制或已生成成片；按当前请求选读，不强制每角色有全套技能。

| 输入 | 应采用的事件 | 应返工的行为 |
|---|---|---|
| 两位空手法师，高速大场面 | 改位/改诀、射路变化、领域规则、召唤截击与本体续法；见[30秒演练](../assets/cases/fantasy-fast-combat-30s.txt)（该稿的定距站位是弱点，距离另按[距离账](continuous-fight-gate.md#距离账)编） | 加手持盾/晶甲，为招式多样性让两人长段肘腿互打 |
| 剑士近战，已锁一把剑 | 斜步压刃后抽离变线，跟当前剑尖威胁切入；合理窗口可用柄击/身法 | 因这轮法师纠偏全面禁近身，擅改为召唤法师 |
| 召唤师与自主代理 | 先下截击指令，代理从高路逼迫目标，本体侧移从低路布印；两路任务可读 | 本体每动作代理都镜像，或召唤后站看全过程 |
| 持续引导的领域术 | 手印和位置维持必要控制，改步/牵掌改变域界，对手试图越界或中断；不必全程奔跑 | 为避免站桩让双手忙控者又撑地翻滚，或每镜重开领域 |
| 一次开启的场域 | 开启后本体另施短招，旧域继续按条件生效；对手利用域外区 | 每次作用都结长印、松手即把所有状态清空 |
| 只指定巨型荷花 | 决定它是受控术法构造、独立召唤体还是视觉象征，再写来源、层瓣/莲心、实际作用 | 默认是能量球皮肤，或形体虽大却只在背景旋转 |
| 指定巨型星球/外太空 | 建立真实跨场或领域星海，星面体积/参照、运动、控制与当地结果相连；见[12秒演练](../assets/cases/celestial-summon-12s.txt) | 把背景行星当作已经施放的召唤，切太空后清空人物任务 |
| 人物沉稳驻立但有压制任务 | 动作、视线、控制与对手受限具备明确关系；必要驻立合法 | 单凭没有奔跑就判呆滞，或让敌人无因等仪式结束 |

校准时看完整事件，而不是检索“领域/召唤/星球”关键词判通过；攻击与防御不强制相消，隐藏按当前意图处理。人物类型、持物依据、施法动作、并行任务、规模与摄影合并复核，只有实际输出才验成片观感。
