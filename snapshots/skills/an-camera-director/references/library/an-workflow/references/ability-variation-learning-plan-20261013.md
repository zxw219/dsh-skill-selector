# 2026-10-13 技能多样性续学计划

当前对象：An工作流源文件与可调用方法。承接“高速不是追击、施法动作少”和最新“技能少、重复度高、单一”。这轮集中修技能储备、选招惯性和正文兑现；未续写两张人物图的30秒稿。

前轮14个原型是雷/晶训练补设，已有库也有感知、代理、规则等案例；数量与分类不能证明实际设计丰富。新的练习必须改变作用结果、施法操作与决定性画面，不能再靠更名、换色和换机位通过。

| 轮次 | 学什么与怎样做 | 交付与验收 | 当前状态 |
|---|---|---|---|
| 1. 查因与取法 | 回看前轮及既有多样性方法；阅读第一方开发说明，区分主题统一、具体选用场景与阶段状态 | 记录采用/未采用及证据范围；定位储备、选招、施法、观看的失效层 | 已完成文字资料阅读与作者诊断 |
| 2. 扩展储备 | 原创24个异质原型，涵盖不同对象、攻击、控制、信息、空间/时间、代理和状态 | 每例给前置、实际动作、主变化、响应、出口与边界；不能只是一串招名 | 已完成文字设计与作者复核 |
| 3. 迁移练习 | 做8项：去名辨别、同主题分化、同招变用、两个异质选招题、连续短交锋、大场面变奏、合法重复反例 | 题目不预给正确技能；采用结果有机会依据，同期状态/肢体/位置可接；修订落实到实际练习 | 已完成8项作者文字练习；没有独立模型评估 |
| 4. 写回工作流 | 更新入口、技能创作/体系/观看、导演选择与终检，功能映射只补职责内内容 | 备份、源文件、引用、边界、D盘副本、功能ZIP及总ZIP一致 | 本轮执行，结果另见验证记录 |
| 5. 成片校准 | 后续有同版生成片或明确生成任务时，正常速度观察施法辨识、作用/结果、战术发展与冲击 | 将提示词缺失、生成遗漏、素材限制分开；同段可有对照，但不因文件通过宣称视觉改善 | 待实际片；本轮未启动生成 |

轮次2、3的数量是本次练习规模，不是所有作品的技能、镜数或类别配额。普通创作只从当前机会选择相容技能，有意义的同招、单技能、投射、无手势、仪式、纯展示与固定镜头均可成立。

本轮方法见[技能原创与选招](ability-variation-selection.md)，完整练习见[24个原型与8项迁移练习](../assets/reference-studies/ability-variation-20261013/24%E4%B8%AA%E5%8E%9F%E5%9E%8B%E4%B8%8E8%E9%A1%B9%E8%BF%81%E7%A7%BB%E7%BB%83%E4%B9%A0.md)。作者自评与独立调用、抽帧与正常播放、文字与实际生成分别记录；本轮是本地工作流学习，不是模型参数训练或后台自动学习。
