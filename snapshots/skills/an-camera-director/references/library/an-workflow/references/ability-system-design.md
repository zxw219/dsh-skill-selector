# 技能体系、多样机制与主动/被动状态

用于技能只换颜色/大小、主动与被动混淆、角色招式万能化、施法与结果脱节。保持用户角色、世界规则、能力、胜负、媒介和表达格式。原创请求可创造相容机制；锁定能力只组织其已有可能性，不为多样性给角色发一套新能力。不要求每场收齐下面类别，也不强迫一招一镜。

## 从角色的力量观念建立体系

先决定角色怎样解决问题、力量作用于什么、什么操作属于同一体系。主题能生出不同用途，不必每个招式换一种元素。例如允许原创的“掌控物体共振”：探知结构、暂时稳定结构、留下共振条件、主动释放已积累的振动，可以共用节律与节点语汇，却改变侦察、防护、布置和破坏的实际行动。此例机制为原创，不是现实材料结论。

同一体系的招式共享必要的源点/材质/运动语法，以不同作用关系辨识；不同角色也可以同为火法却采用燃烧附着、压力推进、遮蔽感知等不同战法。服装不能自动授予能力。允许单招多用、只用一个被动或纯展示；多样性是可选择的设计空间，不是每场增加招名数量。

在需要原创或比较时，从以下维度选择会改变本场的变量，不填写一张通用满表：

| 维度 | 可选的设计差异 | 画面必须承接的事实 |
|---|---|---|
| 使用理由 | 伤害、侦察、保护、恢复、改路、控制、诱骗、创造支撑、夺取/解除状态 | 谁因此能做/不能做什么，纯造型展示则看材质/形态变化 |
| 启动 | 主动决定、常驻、事件触发、预置后触发、主动切模式、协同触发 | 此刻是否发生了一次施放，条件是否已经满足 |
| 生效位置 | 自身、接触物、沿路径、指定点、区域、远端媒介、关系/规则 | 源头、控制端与作用端可以分离；无传播的点生效不硬添弹道 |
| 操作方式 | 放出后独立、持续操控、引导供能、预设指令、自主代理、维持区域 | 施术者后续动作是否可兼容；旧在途部分是否仍存在 |
| 时间行为 | 瞬发、渐变、持续、周期、条件延迟、积累后改变、暂存后引爆 | 不是每个都蓄力—发射—爆炸；周期/阈值只在已设时使用 |
| 接收对象 | 人体/装备、物质、路径、信息、感觉、区域内的规则 | 信息变化、失去定位与结构变化都可成为结果，不只击飞 |
| 终态 | 无痕结束、附着状态、残留结构、失活节点、仍在运行的代理/场 | 下一事件继承什么，解除与残留不是同一件事 |
| 可见性 | 外显体、局部微变、环境/行为间接显露、角色可见而他人不可见、暂隐 | 区分角色知识和观众知道什么；不强迫隐蔽能力大放光 |

删除招名、颜色与大小之后，两招若仍是同样的发动、传播、相撞和消失，就检查是否只有外观变化；相同机制不同战术用途也可成立，应让其目标、时机与后果实际不同。不硬设“至少几项不同”或角色技能配额。

## 主动、被动与持续效果分开

主动/被动描述触发与控制，持续/短促描述作用时间，常驻/可用描述状态。主动开启后持续生效的护体不是“每次受击又施放”；主动放出的召唤物自主挡击，不自动变成施术者被动；被动也能产生巨大一次性结果，主动也可以几乎无光。

| 类型 | 需要建立的区别 | 可以怎样被看见 | 容易误写 |
|---|---|---|---|
| 常驻被动 | 原本就存在的能力/状态，未发生新开启动作 | 接近者的衣摆/物体持续偏移，或同一材质对作用的稳定响应 | 每镜掐诀重新点亮；所有被动都画成光环 |
| 事件触发被动 | 已有能力在明确条件满足时自行起效 | 接触/越界先发生，附着图样随后改变，接收端出现新状态 | 为自动效果补一次人物手势；没有触发就突然爆发 |
| 积累/阈值被动 | 条件逐步累积到本例已定的触发点 | 同一部位的状态逐次变化，触发后该状态消耗/转换 | 特效亮度凭空代表层数；所有角色默认三击引爆 |
| 主动瞬发 | 当次选择和起效，未必有长形成或独立弹体 | 目光/握点/步位/器物等已定发动与作用发生对应 | 不掐诀就判没施法；强加前摇或大法阵 |
| 主动持续引导 | 起效后仍要维持某项控制/供能 | 人物任务、源点和受作用区同时延续；松开/受阻引发已定结果 | 为露脸让角色放手但束流仍全强度；打断后所有旧物一起消失 |
| 主动开启状态 | 一次开启后，角色带着新状态行动，到规定条件解除 | 开启前后相同部位/材质/行动能力有可辨变化 | 启动动画反复重演；状态名自动授予新速度/免疫 |
| 布置与延迟启动 | 设置、待命、触发、作用可以由不同事件完成 | 原地点/节点持续，角色或事件触发它后才显露结果 | 布置即爆炸；每切镜重布；预置手势与后续引爆混为一次 |
| 召唤/代理自主 | 谁归属、获得了什么指令、之后按何规则行动 | 本体继续自己的行动，代理独立选择/受损/失活 | 代理每动作本体都必须挥同款手势；自主自动等于万能AI追踪 |

被动状态若作为悬念隐藏，可先只给结果，按揭示时刻补条件；不要在全局说明里提前告诉观众角色不知道的真相。隐藏不是借口，观众需要判断的触发与结果仍要在相应时刻成立。

角色定位/主战距离、施法身体语言、人物与代理协作先按[角色战法与施法协同](character-led-spell-combat.md)选择。本页区分状态与控制，不把法师改为近战，也不以通用手掌发射代替专属施法。

## 施法、施放与生效不是同一瞬间

按该技能实际需要选择：**发动/施法**决定或执行控制；**成形**使某种载体/状态成立；**施放**让作用开始或离开控制端；**传播/运行**决定到达与持续方式；**生效**改变接收对象；**维持/转态/解除**改变正在运行的状态。瞬发可合并，常驻被动可没有新的施法，领域可没有发射，远端生效可没有中间光线。缺的相位不虚构，采用的相位不靠招名跳过。

施法身体语言从实际控制任务来：瞄定点位、掐诀改路、以步位布阵、触物留印、呼吸调状态、念动远端、器物开启、同伴协同等均可选择。若规则尚未定，先选与当前角色行动相容的方式；不把所有手诀、咏唱、结印、转圈一次全加给短招。

人物动作与可读前兆可以并行。可见的握紧、指诀变化或材料向源点汇聚帮助辨认，但施法不是只给脸或手的插播。当前忙闲肢体、兵器与视线成立；形成时对手继续行动或由真实阻隔限制。施法需要长时间则由掩护、距离、已有防御或剧情安排提供窗口，不让敌人礼貌等待。

中断分别处理：尚未成立的效果、已经离体的作用体、正在供能的通路、已经附着的状态、自主代理和残留环境。是否消失、减弱或继续由机制决定，不机械全关，也不凭空无限维持。声音仅用允许的声源；瞬发不必喊招，静音不以口型解释机制。

前招在途与本体后续动作按[并行任务](ability-led-combat-direction.md#本体与在途作用并行)分清离体独立、持续供能/操控与自主代理；机制允许时可在旧作用未结束前移动/续攻，机制不允许则保留控制资源。不能让相机切走等同停机，也不能为接续自动赋予自主运行。同一能力可在不同距离、对象、限制和出口中复现，不以增加能力类别作为唯一丰富标准。

## 技能交互从条件与状态生出

不用颜色混合或亮度宣布胜负。先定位同一世界空间与时间，确定有效实体/表面/体积/关系，选已允许的交互；再分别接续双方作用体、控制端、接收对象与场地状态。

| 交互关系 | 机制设计要决定什么 | 画面要读到什么 |
|---|---|---|
| 阻挡/承受、偏转/反射、穿透 | 在哪一面/区相遇，作用后的两路分别怎样走 | 来向、作用区与剩余部分，不能完整消失后又完整穿出 |
| 吸收/储存/转化 | 原作用怎样失去形态，接收端获得什么；后续释放是否是另一主动事件 | 收入/存留与再次输出的区别，不自动赠送回血或反弹 |
| 解除/驱散/压制 | 作用于状态、控制端、媒介还是某一局部规则 | 哪部分失活，未受影响部分仍运行；驱散不默认清空所有类型 |
| 标记→追踪/引爆/定位 | 标记职责、附着处与后续技能读取条件 | 同一标记从建立、被利用到消耗/保留；标记不自动万能追踪 |
| 布置→触发，诱饵→错误应对 | 谁能触发、触发者知道什么、真正结果在哪里 | 对象/地点延续，误判后的动作与揭示证据，不能旁白宣布被骗 |
| 场与场/技能叠加 | 区域重叠时覆盖、叠加、竞争或互不作用的已定规则 | 边界内外/交界前后不同结果，不能全部变成中央光球对波 |
| 协作/接力 | 第一招创造的条件怎样被第二招利用 | 前招出口接后招入口，归属与顺序清楚；配合不是同步摆姿 |
| 感知/幻术/隐匿 | 谁被影响、哪些感知改变、何时识破 | 主观与外部视点区别、行动判断变化；不默认全场共享幻觉 |
| 环境/材料联动 | 是否需要源物、物质或载体，变化是否继续影响下一步 | 已变区和未变区、通路/支撑/受光改变，不只远处炸山 |

这是选择空间，不是元素相克表。恢复、净化、增益、传送也可与伤害/状态交互，结果取既定规则；不可抵抗、没有代价、无法驱散都可以是用户设计，不强制平衡冷却或唯一弱点。细化接触载体与残留时复用[粒子与技能展示](particle-spell-design.md)，不再另造能力。

## 完成一场的技能选择

从当前机会出发：对手正在依靠什么、前招留下什么、自己有什么可用控制资源？给实际采用的能力落实条件、施法操作、主变化、接收端状态与下一行动。已能用同一技能实现就不硬增新招；重大结果可由小动作或被动达成，不按尺寸安排地位。

技能数量或分类已丰富但成稿仍单一时，按[技能原创与选招](ability-variation-selection.md)分别修储备、选用和正文兑现；有具体重复缺口才比较一个相容替代。暂去名称/颜色/大小核实际机制，再查身体与观看差别，不能只统计类别。不同技能共享必要前兆/媒介允许，有作用的同招变化与重复也允许；互换测试是编辑辅助，不是固定评分或每稿全库审计。

需要摄影展示时读[技能的画面与摄影](ability-screen-direction.md)；需要校准成稿读[多样技能与互动片段](ability-diversity-lab.md)中命中的例子。资料观察、原创设计和实际生成证据分别记录，研究依据见[学习记录](ability-research-20261008.md)。

## 关键结果与代价的必要性

牺牲、绝境、反转或“唯一解”承担主峰时，先检查**已经采用的能力**是否直接提供更低代价的同目标解法；只查实际影响结果的一两项，不枚举全库。例如已设断片能自由召回/御使，又以“只能毁去全部修为才能用断片破阵”收尾，就须先解决召回或直接攻击的现成路径，不能用情绪宣言跳过。空间不可达、承载缺失、持续控制、保护对象或人物主动选择可以成立，但应有已有条件与可见结果。

不要在结尾才补“断片不能动、瞬移突然失效、术法忽然免疫”来逼出代价；修最早的能力定义及其前置展示，或改用当前规则下成立的选择。人物可以主动选择更昂贵的方案，须交付其实际理由，不自动判错或替用户改结局。无代价直胜、不可抵抗和纯展示不强制添加成本。

这里只修采用机制，维护模式将缺口写回本来源及相关验收，不自行重写样本。

## 实体器具、范围扩展与归属确认

按本场事实分清器具本体、主动扩展的作用面和独立在途效果；实体芯可保持而作用面开/收，持续握持与另一肢体反击共享资源。连接两人的效果可证明连接，确切保护/增幅规则还需设定或来源证据；附近同伴不能因同框被写成施放者。源片缺失的规则不补造，原创设计应明确并标为本场设计。按需读[执行方法](narrative-combat-transfer.md)。
