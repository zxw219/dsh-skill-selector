# 2026-10-21：电影级构图、特殊变焦、切镜与转场的采用门槛

本轮对象是工作流源，不是稿件。触发来自用户直接指出：“只会普通的构图，不会艺术化、情绪化、电影级构图，和分镜运镜切镜、拍摄/构图/分镜/转场/运镜手法、镜头使用、特殊变焦，这些都不会，甚至没用过。”

## 失败样本

上一版“奶蛙受刑”最后4秒只写：21mm、低机位、20°斜拍、雨、闪电、低头、微推、升格。它读起来是“雨里一个受苦的身体”，不是有视觉论点的镜头：

1. 链子只是道具，没有当前景框，也没有挡住/打开任何关系。
2. 荷兰角只写角度，没有力源；看起来是装饰。
3. 推近只是把全身放大，背景、注意和关系都没变。
4. 低头没有触发，也没有代价；抬头和低头只是两个姿势。
5. 白光/雨只是天气，没有参与叙事；没有静音。
6. 切点只是从上一镜推近，没有交接状态/注意/强调；转场只是“推近/黑场”。

## 根因

规则并非不存在；`composition-staging`、`shooting-grammar`、`camera-execution`、`storyboard-sequence-design`、`transition-direction`、`emotion-arc-design` 都已写了这些方法。失效在采用层：

- 入口的“电影感/艺术化”路由只指向摄影执行和导演手册，没有“先过视觉论点”的门槛；稿子可以用一堆气氛标签通过。
- 构图、镜头、切镜、转场分散在多个来源，写稿时只取“景别+机位+天气”的外壳，没有逐项核“主读/次读/遮挡/负空间/关系变化”。
- 终检没有问“去掉这个手法损失什么”“这个切点交接了什么”“这个转场连接了什么”。
