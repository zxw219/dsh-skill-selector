# 打斗反馈门槛：第一信息、能力来源与承受反应

用于开场同质、技能像临时道具、受击者没有接收的反馈。继承[规则适用](fight-default-contract.md#规则适用与验收)、角色能力与本轮授权；本页不设置通用技能数、反应数或开场景别。

## 开场

视频生成向默认 0 帧已在打：第一句就是接触、追击或已经发出的攻击，要定妆最多 0.3 秒；空间关系由打斗带出（踩碎的地面、撞坏的物件、被逼退的路线），不用大远景先交代场地再开打。两人相对而立、互相打量、同时出手的三拍开场，按停手对峙返修。

在用户锁定固定/慢节奏/分镜表，或空间本身是争夺对象时，仍可先给全景或稳定观看；此时不因“默认已在打”而剪掉必要的空间证据。

先确定观众此刻必须读到什么：正在逼近的威胁、人物选择、接触细节、声源或空间关系，再选全景、近景、细节、进行时、POV或声音先入。空间本身就是关键证据时可用全景；不能因上一稿全景过多而机械换成特写。近景开场也要在交会之前提供当前需要的空间依据，不必另加地图镜。

## 技能

能力来源可以是身体、既有装备、环境、无形规则、领域或自主代理，按已锁机制或明确获准补设成立。不能强制每招来自身上物件，也不能只凭凡人/神的称谓删掉已有领域或天象。

让当前必要的触发/控制、作用对象与路径、可辨变化和终态成立。代价、冷却、次数、可破边界与回收只在机制需要时交付；一次性作用可消散，无代价、瞬发、被动和无法当场破解的能力也可成立。具体形态见[技能类型](ability-forms-summon-domain-vfx.md)。

重复技能按当前用途、对手条件和观看变化判断。积压防线、反复试探、兑现角色签名可以复用；只有无新压力/信息的循环才回修，不设“三技能一展开”或“第三次必须换招”。

## 反应

关键命中、擦碰、威胁或控制须有与来力和角色机制相容的接收证据：动作被截、支撑改变、呼吸、视线、护伤或明确维持的防御等。可在同框、下一相位、声音或结果中读到，不强制另切脸；完全静音不以音效补证据。

刀抵喉等持续威胁先核刃口与皮肤的接触约束、双方当前任务和挣脱/控制空间，再选有作用的吞咽、避刃、制止伸手或呼吸变化。吞咽、抬颌、后退可能增加危险，不能把五种反应叠成必做清单。无伤、护盾、麻木、非人身体按事实处理，不凭接触自动加血或伤。

已成立的伤势与负荷影响后招；缺席接收与有意隐忍分开判断。表演细则取[人物表演](../entry-guide.md#按实际缺口读取)的对应入口。

## 检查

查第一信息是否可读、能力是否与角色机制相容、作用与接收是否在同一事件成立、后续状态是否继承。数量、景别或表格齐全不代替这些证据。修复限定于当前模块，按[联用边界](functional-collaboration.md)回填。
