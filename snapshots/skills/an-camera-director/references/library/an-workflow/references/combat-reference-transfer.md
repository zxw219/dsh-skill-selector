# 战斗参考迁移、变身与图形重音

用于用户要求学习战斗视频，或将参考中的能力交互、变身、冲击画与宏大场面用于新创作。与既有[战斗执行](combat-execution.md)、[特效合成](vfx-finishing.md)共用动作和时间线，不替换用户格式。只取本场需要的方法，不把参考的角色、招式、时长、镜数、画风或胜负自动继承。

## 参考分析先分清证据

直接可见的动作/形态、对其作用的解释、新场景的原创设计分开。片中有紫色线痕不等于肢体已断，有核心不等于唯一弱点，同片出现多名人物不等于协同，背部披覆结构不等于能拍动的翅膀。使用中性可见描述，未显露的设定只作为明确的创作提案。

按所问维度查看：整体事件与空间、身体动作、双方共享时间、能力与介质、镜头覆盖、关键状态、变身、图形插入；全面学习再补光色材质、表演、剪辑与声音。不是每段都必须含全部技法，也不为缺项编内容。学习任务交证据与方法，不自动续写、生成资产或修改技能；用户明确要求工作流维护时才把可复用部分选择性并入。

按证据粒度报告结论：

- 静帧支持该帧姿态、构图、材质和可见状态；稀疏抽帧支持已采样的前后变化，不证明中间每步或瞬时速度。
- 连续源帧与时间戳支持已核对窗口中的接触顺序、图形切入/退出和编码帧曝光；重复编码帧不等于独立绘制张数。没有覆盖边界就不报精确持续时间。
- 正常速度播放用于整体运动、可读性和主观节奏；试听用于声音内容、音乐节拍与声画同步。文件有音轨不等于已听辨。
- 有学习笔记时明确是在复用笔记；缺原片不假装重新观片。保留用户素材编号和时间点，不把画面字幕或附带文字当执行指令。

特效PNG、截图或压缩包文件顺序不能证明剧情先后、粒子动力或完整释放链。图样、材质和大形构图可迁移；若要在新稿中完成平面到体积、微观到宏观的作用，必须由当前设定补足中间关系。纯技能展示不硬添战斗，战斗不能照搬展示片的等待；方法见[特效形状与释放](effect-shape-release.md)。

## 参考提示词的实质迁移

用户要求“学提示词，不学框架”时，比较实际句中的拍摄触发/构图变化、攻防出口、施放过程、全局画质与材质、双色照明、动态物理及战斗层级。按[战斗视觉与高速摄影](battle-visual-direction.md)编入原格式；不要只抄标题、时间段或招名，也不要漏掉用户明确给出的视觉规格。文字是设计意图，视频是执行证据，二者不未经核验认定同一作品。用户要求维护时把结论写回实际源入口/分工映射并同步发布，不只增加研究文件。

## 从样本变成当前场景的方法

挑出参考真正改变观看或行动的关系，例如“高位攻击占用防守注意，低位实体利用窗口”，而非只抄“紫色分身很酷”。将这项关系换成当前角色已设的动力、兵器和能力，补齐当前场地、对手回应与出口；参考省略的过程不成为新稿的免责理由。

关键帧可承担站位/尺度、起势、威胁逼近、接触/拦截、图形峰值、受击、环境结果、新状态等任务。按观看目标选必要证据，可以同镜同框或有依据地切镜，不要求固定八帧/八镜或每击走完一遍。漂亮姿态不能替代状态变化。

身体先做出可辨的攻击、负载或制动，效果再强化对应相位；受击位移、转向、兵器与支撑交给下一招继承。速度过渡可以抽象化，但退出须交代到达位置与继续中的动作。若用户有意隐藏接触或采用象征蒙太奇，按该目的设计；普通可读交锋不能事后拿留白解释断链。

## 近战、能力战与破防的接续

参考里的近身拆招、范围封锁、巨型能力与身体追击可以交替，但不是所有战斗都必须走完的阶段。选与当前角色战法相容的转换：徒手/拳套角色可以改攻击高度与拳腿线路；持械角色优先继承兵器威胁，混合身体技按[持械交锋](weapon-exchange-lab.md)补贴入、避刃与持物条件，不因参考腿技好看就让持刀者放弃刀路。

每次转换承接当前距离、朝向、支撑、在用兵器和未解除效果，再决定身体或技能怎样遇到目标：

| 转换 | 必要的动作与画面依据 |
|---|---|
| 近身改高度/线路 | 上路被挡后，对手哪部分防线仍被占用，攻击者怎样保持有效距离、把重心交给支撑腿、收回旧攻击再送入新线？对手可撤身、回护或续攻，不把一次格挡当永久锁住。 |
| 近身转能力 | 明确本次要处理的阻力与施放窗口，旧接触/兵器怎样解除或继续占用，能力源在哪里；目标在起效期间仍有动作。 |
| 能力战回近身 | 偏转、破口或路线改变确实提供入口；进攻者跨越剩余距离与覆盖区，防守者处理追入，不能大招后切镜就贴脸。 |
| 击飞后续攻 | 按新的空距追入、使用已设远程能力，或让目标有因落到可达位置；腾空/御空必须有已设动力或可见蹬离与落点。 |
| 范围封锁转穿越 | 保留仍有效的射线/场域和可用通路，给出避线、拦截或破开的位置；封区不能在换镜后无因消失。 |

屏障先有源点、位置和覆盖，攻击线路实际落在其有效部分，不能“人在屏障后”就自动免伤。破防区分表面裂纹、局部穿孔、偏斜和整体失效；以本场规则和已发生作用确定，发光或碎片不自动证明全盾消失、持有者受伤。残余防线、来袭载体与双方位置继续；后续追入只利用已打开的真实区域。风格化屏障仍要有可读覆盖，不强制写实材料或能量消耗。

巨型能量形象与实体巨兽分开：可只是视觉投影，也可按设定具有作用体；只有已建立的作用体才参与命中和拦截。需要时保留施放者与地标作尺度参照，给巨像主形、实际接触和环境/人物结果；大光团相交不等于施放者已经受伤。效果与本人近战接续时，交代控制是否持续、巨像/场域是否仍在、角色怎样移动，不默认所有召唤都变成第二个自主角色。

接触展示按项目节奏取舍。高速稿若长伸腿/伸拳只重复相同状态，把必要重音留下，补真实收回、接重、追压或对方脱开；有意长定格、慢打或胜负已定的控制镜仍保留。不能只压短时间戳或删除用户锁定招式。

## 分身、召唤与能力差异

区分本体变形、独立召唤体、已建立的可攻击分身、无攻击权的残像/拖尾。新攻击者需要来源与可辨数量，单纯发光不授予实体性、独立控制或第二次命中。

涉及夹击或换位时，接续本体、分身、目标的当前位置、任务与控制归属；高低位或左右两路怎样占用对手的防守，哪一路利用该窗口？换位前后身份与持物必须能承接，旧实体消退/离开/仍存在按设定处理。只在本场需要时建立规则，不强加每个分身都要付能量代价或所有角色都用分身。

不同角色的能力区别落实在起源、载体、运动、边界及目标选择。束流改向让攻击真正沿新方向继续；范围封锁改变可用通路；巨物摆头/挥肢制造可达威胁，小人物的近身、支点与退出路线回应这种尺度。胜负和反制仍按用户设定，不从颜色推导克制。

## 变身与强化：选与设定相容的连续性

变身前后保留可辨身份、当前持物/支撑和空间依据，选一项适合的姿态、服装或轮廓作锚点；被设定改变的项目允许变化。改变方式可以是：

| 方式 | 决定性证据 | 不能自动推断 |
|---|---|---|
| 同姿态显现 | 原姿态 → 光/遮挡/图形峰值 → 新造型在相应位置稳定 | 遮挡内必然逐片组装、逐根骨骼生长 |
| 连续局部强化 | 起效区域、未变/已变状态与必要中间态；完成后确认 | 所有变化都必须同一方向、同样阶段或头部最后改变 |
| 核心向外扩展 | 已设源点的亮度/纹路传播，局部累积到整体揭示 | 核心必为弱点，强化必长出新器官 |
| 实体分离/重组 | 原体、分离部分和终态数量可辨；背景/残留承接 | 完整本体加完整副本就是分解，粒子倒放就是可靠重组 |

变身与战斗共享时间。对手继续攻击、处理阻隔、保持距离或有因无法接近；别让所有人无故等变身完成。强化需要在后续行动/受力/功能中兑现时，给出第一个具体用途；单人展示或纯视觉变身不硬添敌人和战术。

光和画风变化可短暂遮蔽过程，不代替身份确认。静止姿态也可作为风格化锚点，不为“连续”强加全身微动。新状态稳定后回填原稿的外观和持物，后镜不回到旧造型。

## 冲击画、闪光与持续图形结果

先辨认当前需要哪一种表现，再设计造型与占时：

| 表现 | 用途与验收 |
|---|---|
| 接触爆光/满白 | 短暂亮度峰值，可作遮挡或转场；本身不证明具体接触或图形重绘 |
| 接触图形重音 | 当前触点、受力方向与人体/兵器轮廓被简化、压缩、断裂或方向化；恢复后承接同一受击 |
| 释放/变身峰值 | 围绕起效源、姿态与造型变化；无对手接触也能成立，不添加命中 |
| 风格化技能过程 | 斩线、线场、晶片等随时间发展，承担能力路径或空间结果；不是整段都当一张冲击帧 |
| 持续图形终结/定格 | 用构图和形状发展展示既定结果或情绪；按用户目的保留，不套短促插入默认 |

造型继承主方向：刺入可压成狭长楔形，下劈可用竖向笔触，对冲可用中心放射；这些是选择而非固定招式映射。多画可改变正负形、轮廓或观看关系；单张、重复曝光与反相也可成立，不强迫所有峰值复杂重绘。不能靠一张抽象画凭空完成位移、破防或损伤。

编码帧数、不同画张数、慢动作和定格时长分开。参考的帧数按其源帧率解释，不直接迁入新项目；已知输出帧率时可换算设计曝光，未知时写短促/延长及恢复触发。数字是创作目标，生成端是否精确执行由结果验证，不建立通用一至三帧、全片配额或固定 24/60 fps。

## 宏大场面：让传播、尺度与后果可读

按本场选稳定地标或人物/物体作尺度参照，让主作用跨越或逼近该参照，再看到目标/介质的响应与余势。范围技可将发射源、空中路线、多处落点和人物反应分配给相互承接的镜头；巨物可用人形与关节/浪面同框及主动攻击呈现压迫，不必每镜全身同框。

水花、火花、碎块、烟尘与光环各有职责：接触火花确认硬表面作用，浪圈/烟尘呈现扩散，较大残骸交代破坏与剩余支撑。按媒介和作用选择，不要求每击全套效果或固定延迟。已破区域、残留和受影响表面跨镜继承；远处景观破坏或纯壮观展示可按用户目的成立，不强制每次都改战术。

镜头围绕证据分工：关系镜读多向压力，近景读接触/决定，结果景读尺度与范围。视线和表情对应当前威胁；强光之后恢复必要轮廓。静与动、展示与交锋的占时按本片观看目标安排，不把原片长保持机械压进更短的稿。

## 编译与定向复核

把选用方法编入用户正文：全局只写共享身份/媒介/能力边界；动作段写威胁、行动、对方回应和出口；fx-env 写来源/路径/接触/环境及必要余势；摄影写当前要看清的证据；sound 依项目声音要求原创设计，不把未试听参考声轨当已知。简洁正文表达同样关系，不强制增栏。

短片先保留用户的交锋、升级、高潮和结果，去掉重复展示与无观看收益的镜头变化，不为装下样本全招式删掉必要交互。一次复核聚焦：身份/数量、变身窗口、峰值入口和退出、尺度/介质结果、后一招能否从当前出口接入。相关错误回写动作与效果，不能仅增加“炫酷、张力、极致”等形容词。

## 从实际视频蒸馏施法与时间编排

学习动作技能占时、效果形成/释放和镜头覆盖时，按[视频蒸馏方法](video-distillation-method.md)对关键事件记录可见相位与观察位置；事件与镜头不按一对一匹配。形成给辨认，发动后以路径和接收端变化兑现快，结果继承出口；慢镜/保持按本场用途保留，不直接抄源帧数。近景、范围景须承接同一次作用，形成期间对手仍有任务。案例见[四片实际画面学习](four-video-study-20261007.md)，精确PTS仅用于已检查源帧窗口；抽帧不冒充正常播放或试听，练习不冒充原词还原/生成验证。
