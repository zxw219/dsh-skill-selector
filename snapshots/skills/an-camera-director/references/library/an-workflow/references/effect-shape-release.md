# 特效形状、介质与释放画面

用于学习特效静帧/视频，或强化技能释放的辨识、材质、显化与大场面分镜。把参考优点转成当前项目可见的画面关系，与[特效合成](vfx-finishing.md)、[粒子与技能展示](particle-spell-design.md)共用效果和时间线。普通火星、短拖尾不必加载本页。

## 把参考形状转成技能语言

先挑当前最有辨识力的关系，再选主轮廓、内部结构与周围空处。例如：细颈连接膨开的墨状端部，透空网面由主纤维牵引，密集亮点组成方向束而非均匀撒满。空处可以是孔隙、暗芯、轮廓间隙或主流向旁的留空，作用是让主形可读，不要求每种法术都有黑色中心。

保留同一种技能的造型语汇：前兆、展开与终态可重复同一分叉、弧线、纹路或边缘节奏，同时改变尺度和密度。可以有意反差或改形，但应服务变身、反转或升级；不把每个阶段随机换成互不相干的预设。不同角色用源点、主形、运动/材质与作用区别，不以颜色作为唯一身份。

| 参考中的形状关系 | 可转译的设计选择 | 需要保留的区别 |
|---|---|---|
| 墨状薄颈、扩张端、飞溅边 | 连贯主带支配方向，局部裂成滴/薄片；主带与飞溅有不同尺度 | 静帧不证明真实流速、黏度或制作软件；黑色不必是烟 |
| 丝束、纤维、网面与孔隙 | 以主束/面建立轮廓，小分支强调受牵方向；孔隙让后景可见 | 有孔不自动可穿越，装饰丝不自动束缚敌人 |
| 带状/幕状流动与卷曲边缘 | 一条主流向组织分层，局部卷动与疏密服从主形 | 参考表现的流动感可作新设计，未见视频不报告跨帧运动 |
| 环面、楔形、几何线描 | 环口/锋面/几何边界保持辨识，强亮区内部仍有结构 | 环口可能是装饰、边界或传送面，功能服从本场设定 |
| 云状颗粒、亮点汇成束面 | 成组密度形成方向与体积，细点补层次，最强对比落在当前重点 | 亮点不都是作用体，不因数量增加追加伤害范围 |
| 透明液膜与反光边 | 厚薄、折射区和高光帮助辨认介质表面 | 折射只改变穿过介质的视线，不让全屏同时变形 |

## 介质身份与作用权分开

只在涉及多种载体或转化时辨明以下职责，不强制每镜配齐：

- **作用载体**：实际触发、传播、拦截或作用于目标的部分，按已设规则确定。
- **形状与材质证据**：沿面纹路、纤维、湿边、金属反光、粉粒堆积等，说明载体怎么存在或变化，不一定另有伤害。
- **成像/风格处理**：泛光、景深散斑、二维反相和拖形，改变观看表现，不能自动成为新实体。

同一层可同时承担作用与造型；没有必要时不在正文列分类表。小罐里的粉末倾出后落定，与空中光带消退是不同终态。原介质转成另一形态时，写清本场规则：消耗、部分取用、能量读取、投影或复制；不能让原物质被全部消耗又完整留着，除非设定支持补给。普通小道具发光不强制变化或全身变身。

## 平面图样到体积形体

图样可能是表面印记、发射区域、作用边界、实体来源，也可能只是视觉呼应。先选本场实际职责，再决定是否需要离面显化；花纹亮起不自动证明传送、束缚、召唤或人体变化。

涉及转化时，关键画面能辨认载体的位置和朝向、开始离面/生长的区域、已建立与未建立的部分、终态与原载体的关系。平面纹样可以与体积形共享分叉或轮廓，以降低观众辨识成本；二维表现可用形状伸展、层叠和遮挡实现，不强加写实体积仿真。光幕省略细部可以成立，但光幕后的身份、位置与数量仍要确认；没有看到的组装步骤不得报告为已观察事实。

若新形体没有独立攻击权，就按装饰、附体或视觉投影使用；需介入战斗时从当前设定补作用边界、操控与对方回应。身份/持物与变身窗口按[参考迁移](combat-reference-transfer.md)处理，不由漂亮兽形自动授予分身能力。

## 技能释放的观看尺度

按当前事件安排观看，不固定“手部→全身→远景”三镜：局部纹路点亮可以交代启动，关系镜读载体与人物的连接，较大取景读展开范围，局部或结果镜确认终态。一个镜头足以同时读清时不拆；用户指定一镜到底时，用调度、视线、遮挡或焦点改变观看范围。

切换尺度时保留能让观众接上同一事件的源物、轮廓、方向、地标或持续变化，至少有当前需要的依据。微观颗粒接宏观场面不等于能量自动跨过距离；新稿要求明确传播时，先补真实路径或已设全域作用。释放峰值可抽象化，其入口与退出仍能确认谁发动、什么变了；没有对手接触就不叫命中冲击帧。

**单人展示/仪式**可以为材质显露、人物选择与新造型保留时间，不硬加敌人或伤害。**战斗释放**把同样的视觉设计放进实际交锋窗口：另一方继续避线、压制、破招或被有因阻隔；不照搬展示片的等待。战斗动作与效果共用时间，源点在移动时按既有在途/随身规则承接。

## 大形与高密度的构图

以本场可比较的船、人、门窗、街道、山体或已知物体建立尺度。选择主形跨越参照、遮住地标、逼近通路或令介质发生变化的证据；不只把技能名字前加“巨大”。可以先局部遮挡再揭示大形，但揭示之后要留出本项目所需的识别时间。景观展示不硬加战术，战斗则让可用空间与角色应对接上结果。

高强度画面让密度随观看重点变化：前景形体掠过、中层主形展开、远端群体聚成面；脸、触点或破口在需要辨认的阶段可由视角、局部明暗/密度变化露出。不是永久在人周围挖空圈，也不是默认把满屏效果削薄。主体被有意遮住可以成立，重新出现时身份、位置与动作状态须能承接。

## 定向复核

只查本场采用的项：去掉颜色后主形是否仍可辨？形体细节是在证明材质，还是无因增加作用权？表面图样与体积终态之间缺的是观察证据还是新稿的设计步骤？尺度切换有无丢掉源头、距离和当前动作？最强效果处是否仍能找到当前需要的证据？

抽象材质短片可以以形状/色彩节律为目标，不强制敌人、伤害或真实物理。写实、二维、超现实按项目媒介转译；这套方法不规定软件、镜数、粒子数量、固定曝光或生成成功率。

## 从外观到原创能力与关键画面

只有漂亮参考而本场作用仍未确定时，转[技能、特效与释放画面创作](ability-effect-authoring.md)设计相容机制，再回本页安排形态和观看；参考形状不能自动授予能力。需要冻结决定性瞬间时可选读[关键画面练习](ability-keyframe-exercises.md)，同一场面取一个正在发生的状态，不把形成、接触与最终废墟都叠进单张图。该资源是本轮原创设计，不是已生成图像。


## 多样作用的形态与可见性

主形可以是薄层改变、边界内外差异、物体关系、环境方向、材料状态或代理动作，而非一律发光实体。先从[技能体系与状态](ability-system-design.md)继承触发与有效作用，再按[技能画面与摄影](ability-screen-direction.md)选择观众需要读的状态：微小附着看具体部位与后续动作；常驻/被动看原状态与触发响应；大领域看已有地标、已变/未变区和人物如何承受或利用。信息、隐匿或幻术可以间接显露，不能靠炫彩添加伤害。

同一体系共享材质/运动语汇，招式以作用结构与变化时机区分；不将每招都做成先静态法阵再放射爆散。施法、形成、施放、生效与解除可以重叠或缺省，当前采用相位才写；离体体、附着状态、自主代理和源点控制分别继承，不随切镜重建。

## 同一作用的薄厚、包覆与失效相位

技能主形可以在展开/聚拢/离体、接触后的包覆或实体化、维持受压、破碎衰减间改变材料状态。相位决定薄厚、透明度、刚性和碎块运动，变化由当前机制与角色控制成立；不让“粉光”之类颜色泛称贯穿全部相位。器具实体芯与外扩面分开，扩展有触发/边界、实体有握持/受载，两者同属一次能力而不互相替代。施放者通过源点/操作和路径确认，同框不作归属证据。详见[执行方法](narrative-combat-transfer.md)。

## 母题转态与图形空间

同一母题承担作用、残留和背景时先分职责，再选择形体/运动的交接；环/幕转碎片可保留中心或流向，让旧形退出与新形展开可辨，不从外观变形推定真实物质转化。色框空间先继承背景、感知或世界规则，再细化图形，按[图形空间方法](perception-and-graphic-space.md)处理；本职责不新增幻术机制或伤害。
