# 2026-10-21：一镜到底、第一视角的距离与站位

本轮对象是工作流源，不是稿件。触发来自两轮实际交付：用户要第一视角的亲密单场，我先交 6 镜、后交 5 镜；用户指出这不是一镜到底，随后指出切镜版的站位与方向有多处错误，而我没有自查出来。

## 失败样本与实际错误

两份稿都在镜头朝床尾（我躺着看床尾）的前提下写了他从 2.8m 走到床边：

1. **距离落在床垫上**：写"他从画面左边走进来，停在距我 1.1m"。镜头朝床尾时眼前 1.1m 是床垫，那个位置要站在床上才成立。
2. **0.7m 没有转头**：床边的人在我侧方约 60–80°，超出约 33° 的半视场；正文却让他"停在 0.7m"并继续用原来的正面景别。
3. **左右反了**：他若从矮桌那侧（画面左）过来俯身，脸在画面左半；正文写"画面右侧那半张脸"，还让我的右手从右下入画去贴——手够不到脸，整段接触其实发生在画外。
4. **光没有跟着站位**：窗在床尾，"他挡住窗光、我这边变暗"只在他站在窗前时成立；他挪到床边俯身后，这句仍被沿用。
5. **路径被切镜藏掉**：矮桌在 2.2m，他放完盘子走到床边要绕过床角，沿床侧那几步偏角约 42° 已经出画；切到床边把一条走不通的路线盖住了。

## 根因

- 入口模板只写"一镜到底或明确切镜"，没有判断标准，单场连续戏被默认拆成覆盖。
- POV 页旧版的"不要全程同一焦段"没有一镜分支，导致第一视角里换了四次焦段。
- 分镜表门槛（旧版）要求每镜改变一个条件，逼出切镜与事件堆叠；新版已放宽，但仍没有一镜分支。
- 全程没有"距离—站位—转头"的核对：距离只被当成文字写，没有代回平面图，所以自己查不出。
