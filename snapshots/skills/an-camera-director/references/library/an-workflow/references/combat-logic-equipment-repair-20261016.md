# 动作章法、腿技与装备越界：2026-10-16维护记录

用户反馈先前30秒两角色稿“毫无逻辑、毫无章法”“突然向上跳又下来”“踢腿只是向前伸”，并指出角色设定图没有盾牌；随后再次明确本轮对象为优化工作流。

## 真实问题与边界

原稿有部分局部接招因果，不能虚构所有动作都无法执行。失效在于整段打法和选择依据：根面抬升解释了一次离地，但后续上根拱、夹压、落回近身的整串价值没有充分建立；精灵留在下方举盾承接俯冲，缺少对侧移、撤距或截击等实际选择的交代。动作可接不等于双方有攻防意图和策略发展。

腿技虽然写了屈收、侧送和命中，支撑与髋部驱动没有充分落实为连续运动及可辨取景，容易被执行成伸腿推挡。没有收到视频，实际“像伸腿”的观感来自用户反馈，不冒称已经观看或测得速度。

盾牌是助手新增的前臂木盾，后续承击、冻盾、破盾整串设计依赖该未经确认的装备。角色身份检查只对脸、发色和衣装取证不足；把护具称为生长术不能免除装备权限核对。此问题也说明只有禁止句而未改变战法采用仍会失效。

## 已修改来源

- `SKILL.md`：角色事实明确包括原图既有装备；补战法不自动授权补兵器/护具。动作模块选用前先确定双方争取的优势、拆解与转折，关键机会代入对手可用应对。
- `references/combat-execution.md`、`references/director-deliberation.md`：将逐招连续与整段章法区分；关键升高与下降共同处理本次威胁/任务，对手不能只为作者后招成立而原地承接。失败、冒险、表演和性格选择仍可有依据地保留，不强制最优招或一律禁跳。
- `combat-action-design/references/motion-impact.md`：腿技按当次承重、身体驱动、攻击端路线、触阻和收腿接续落实，区分侧踢、扫踢、膝击；关键词或命中声不替代运动，取景需交付必要相位。
- `references/character-led-spell-combat.md`：区分参考装备事实、能力原创与装备重设。常驻前臂用于格挡的木盾/冰甲按实际功能算盾式护具；明确无盾时不能换材质回加。
- `references/final-check.md`及功能映射：检查原图装备与新增依赖，先发现越界就回战法设计；新增攻防章法检查并强化身体传力证据。场景、动作、素材与审阅只处理本功能职责，12个功能的范围和原扩展规则保留。

普通按图编打斗继承已有装备，用户明确允许重设装备时仍按授权设计；术法防护也不被普遍禁用。慢打、固定镜、纯远程、单能力、指定跳跃或仅改摄影等用户条件仍优先，不能为了修本例扩大所有任务权限。

## 本轮验证范围

已作维护作者的来源语义核对：普通按图创作不得自动加盾，明确装备重设可按授权执行；有实际威胁的跃起可保留，畅通追进不为丰富而绕行；侧踢需在身体和取景上成立，不能靠改名为重踢。上述为作者条件复核，不是独立行为验证。

原拟短创作试用未执行，本轮未生成新提示词、未作独立试写/审阅、未生成视频。来源、入口、链接、章节锚点、ZIP和分发一致性通过与否由打包结果另报；即使结构通过，也不能宣称原30秒稿已修好或创作能力已稳定整改成功。当前交付为工作流来源修订。
