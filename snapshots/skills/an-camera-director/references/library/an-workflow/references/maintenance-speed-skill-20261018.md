# 2026-10-18 速度观与技能设计维护记录

## 触发
用户指出两点：技能设计描述差；没有理解高速高频打斗，不知道什么是快节奏。

## 定位
- 旧稿把"快"当成动作数量和运动速度，19 镜每镜一个完整技能，攻防转换其实是排好的，不是逼出来的。
- 技能描述写成规格表（载体/触发/上限/反制窗口），读者读到的是条款，不是设计。

## 新读到的外部资料
- [《游戏战斗设计分析：流畅、爽快、耐玩体验如何炼就？》](https://www.gameres.com/904059.html)（GameRes，HADES 拆解）：节奏的两个维度是攻防转换频率与攻击频率；作战窗口要多且短；多重威胁与攻防一体操作；攻防转换累积紧张、攻击频率释放。
- [《浅谈角色技能设计的方法论，以〈卡拉彼丘〉为例》](https://www.gcores.com/articles/189850)（机核）：伤害/增益/信息/干扰四模块、避免水桶角色、风险收益成比例、角色与技能之间的连锁影响。
