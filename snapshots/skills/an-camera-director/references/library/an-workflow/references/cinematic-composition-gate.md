# 电影级构图/分镜/运镜/转场：先过视觉论点门槛

艺术化、情绪化、电影级摄影或高级手法在设计观看之前采用，不等成稿平淡后再加标签。普通创作也主动确定观看立场与关系。方法用[表现性摄影](../../cinematic-camera-design/references/expressive-camera-and-zoom.md)、[整段分镜](storyboard-sequence-design.md)、[转场](../../action-camera-direction/references/transition-direction.md)；维护学习见[八项计划](learning-plan-cinema-20261022.md)。

## 气氛标签不是构图

先定观众与谁靠近、何时知道、此刻承受/期待什么，再让主次、空间余量、遮挡、清晰层、线条、体量、明暗或图形节律发生作用。审美目的也可来自持续承受与形色节奏，不能只有广角、低位、雨电、慢推。

重要变化辨认起幅、中段、落幅的实际关系。方案只有术语时，比较同一事件的另一观看立场，成稿只交采用案；不把三层、留白、倾斜与反转全部强加给每镜。

## 五个最容易写成标签的手法

| 手法 | 必须成立的关系 | 常见失效 |
|---|---|---|
| 留白/遮挡/框中框 | 注意被引向什么、什么暂不可知、何时证实或继续等待 | 随机塞栏杆；关键证据被挡却声明清楚 |
| 近距广角/远处长焦 | 观察距离、实际占幅、近远关系和清晰层相容 | 广角等于全景；原地长焦把背景搬近 |
| 倾斜/对称破坏 | 相对本场秩序的心理、受力或图形变化 | 所有镜都斜且没有基线；不要求所有倾斜都有物理撞击 |
| 特殊变焦/复合移动 | 触发、所改变量、可达中段与落幅 | 推镜冒称变焦；主体等大但背景无变化；绕圈摆拍 |
| 动作切/图形/甩接/声桥 | 前镜最后与后镜第一幅，同次进度或明确时空转换 | 只写顺切；重放命中/复位；每次切都加特效 |

## 切点与转场：交接三件事

切点接状态、注意/理解、强调/节律。角度/景别变化有实际收益才选切，有效同构回应可保留。连续实战接剩余相位，跨场图形/声音关联承认地点或时间变化；匹配形状不证明空间连续。普通硬切可最好，转场不要求每镜出现。

## 情绪不是一种颜色

辨认带入心理、具体刺激、当前任务中的承受与之后选择，按实际事件组织，不强制每场四拍齐全。特写发生于接重、回护、操作或其他真实任务之中，画外对手与作用继续。声桥/抽声只用允许声轨，无声任务不补雷声或配乐。

## 验收五问

1. 去掉技法名，观众从什么位置、通过什么画面关系经历感受？
2. 起中落幅的主次与轮廓可读吗；持续构图有什么当前作用？
3. 焦段/距离/焦点与裁切相容吗；特殊变焦真的改变相应变量吗？
4. 前镜最后与后镜第一幅怎样接状态、注意与节律？
5. 情绪/尺度/图形重音在哪里发生；人物与作用仍共享时间吗？

## 边界

正文取证是文本设计验收，不证明成片美感和精确执行。固定、一镜、定焦、裸眼POV只锁实际指定变量，裸眼POV禁光学变焦不扩大到所有长镜。旧[最后4秒案例](cinematic-composition-case-20261021.md)不作为默认剧情。
