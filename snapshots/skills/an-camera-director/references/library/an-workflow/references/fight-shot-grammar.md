# 打斗镜头语言：景别、角度、构图、运镜、切镜与冲击

用于“分镜不像打斗、镜头不会用、运镜没速度、构图平、冲击弱、停顿/摆 pose/拖时长”的默认任务和返工。先按[打斗默认契约](fight-default-contract.md)分人、能力、逻辑、blocking；本页负责镜头选择与执行。

## 1. 默认：不强制起承转合，不保留停顿

- 用户没要求叙事弧时，**不套“试探—控场—破局—升级—终结”**；可从冲突中段进入，连续压力链推进，结束于决定性动作。
- 普通快战清除无作用摆姿、复位和等特效；控制、危险读取、压制与人物接收按本场目的提供负载/预期/判断发展和出口，身体稳定不自动判错。
- 沿实际交锋核速度、压力与观看发展，不按每3秒补招；已锁全程高频不能退成慢展示。
- 每个镜头必须有动作、反应、条件变化、技能触发或空间变化之一；没有就删/并。
- 反应是动作的一部分：受击、失衡、回护、呼吸、抓握、换线；不是摆表情。
- 技能在交锋中发动/生效，不靠暂停展示；机制近景插入也不让对手停手。
- 单方压制、速杀、追击、连续抢攻可以成立；不强制双方对称或固定反转数。
- 用户锁定慢镜/定格/对峙/仪式时保留；自选观看时间处理须有明确收益并计入成片，不能虚构停时能力，也不能覆盖已锁全程高频。
- 2D 角色另按[2D 打斗镜头与作画语法](2d-fight-grammar.md)核关键姿势、接触帧、smear、冲击帧、hold 和分层运动。

## 2. 景别

| 景别 | 打斗里给什么 | 风险 |
|---|---|---|
| 大远景/远景 | 场地、距离、双方位置、规模、追逐路线 | 看不到接触/发力 |
| 中远景 | 两人关系、攻防路线、脚步/支撑 | 细节不足 |
| 中景 | 上半身攻防、兵器/手、身体转动 | 容易变成等大侧跟 |
| 中近景 | 接触点、肩颈/腰线、呼吸、反应 | 裁掉支撑/落脚 |
| 近景/特写 | 手、眼、接触、材质、技能机制 | 裁掉空间/来向 |
| 大特写/插入 | 指尖、刃口、蓝印、十字锚、冲击点 | 不能独自证明完整动作 |

这些是常见覆盖候选，按当前证据选择；建立不必全场远景，冲击不必每次插入，连续镜也可由画内变化交付。局部裁掉的必要支撑/接触，由同次前后画面承接。

## 3. 角度

| 角度 | 用途 | 风险 |
|---|---|---|
| 平视 | 关系对等、动作可读 | 容易平 |
| 低机位 | 压迫、逼近、力量、腿线/腰线 | 过度用会重复 |
| 高机位/俯拍 | 弱势、被围、范围、地面关系 | 看不到表情/接触细节 |
| 过肩 | 攻防关系、对手反应、视线 | 遮挡攻击端 |
| 背面/越肩 | 跟随、未知、突入 | 丢失面部/来向 |
| Dutch 倾斜 | 失衡、危险、冲击 | 连续用会晕 |
| 地面机位 | 足/落点/低姿/速度 | 丢失上半身 |

角度服务当前观看问题。快战相邻镜同质时比较景别/角度/观察侧/占幅/注意对象；有意同构、眼线回应与压制保持按目的成立，不为凑变化强换角度。

## 4. 焦段与景深

- **广角**：空间、速度、逼近、变形、群体；靠近主体让前景/背景拉开，适合冲刺、贴地跟、狭小空间。
- **中焦**：关系、自然透视；默认交换镜头。
- **长焦**：压缩距离、隔离主体、把背景压近；适合对峙、追踪、局部冲击，但会削弱空间感。
- **微距/插入**：机制、材质、触点；必须有前后关系镜头承接。
- **浅景深**：分离主体/前景，制造注意；不能把必要接触/来向虚掉。
- **深景深**：同框关系、空间/地标；适合建立和结果。

## 5. 构图与张力

- **中心**：可读对冲、正面压迫、对称关系或强图形；按事件选用，不以居中本身判平。
- **偏心**：留出威胁方向/运动空间；主体偏一侧，负空间给来袭/目标。
- **对角线**：速度、失衡、斜向冲入；用 fencing/墙线/道路形成方向。
- **前景遮挡**：铁丝网、柱、肩、刃、烟；制造深度与未知，但不能遮住关键接触。
- **框中框**：门、窗、栏杆、两人手臂；适合围困/窥视/关系。
- **负空间**：让威胁从空处进入；不要把主体挤满画面。
- **尺度对比**：巨物/小人物、近刃/远身；给规模。
- **剪影**：逆光、烟、门口；给姿态/威胁，不给材质。
- **非对称**：失衡、不安；不要每镜都歪。

张力公式（选一）：主体偏心 + 负空间指向威胁；前景压近 + 焦点在后方；低机位 + 对角线；俯拍 + 小主体 + 大环境；同框 + 一人被遮挡。

## 6. 运镜与速度

每个运动写：**起幅 → 触发 → 可达路径/相对速度 → 落幅 → 接什么**。按当前任务选择人物、攻击端、控制端或范围；同种运动可持续或复现，但须有本拍观看作用。主动比较景别、观察侧、占幅和注意交接，不规定运动种数。方法见[运镜预算](action-density-and-shot-budget.md#运镜预算)。

| 运动 | 用途 | 速度/注意 |
|---|---|---|
| 固定 | 读接触/构图/压迫；让动作在画内变 | 不靠推镜装变化 |
| 摇/俯仰 | 跟随视线/威胁/落点 | 起幅有理由，落幅接新信息 |
| 推/拉 | 逼近/退开/揭示范围 | 推要靠近事件，拉要露出结果 |
| 横移/跟拍 | 伴随冲刺/交手/并行 | 可滞后再追回，地标给速度 |
| 手持 | 身处事件、紧张、观察响应 | 有观察立场，不无因乱抖 |
| 升降/ crane | 规模、俯视关系、结果 | 中段要有变化，不只有两端 |
| 环绕 | 打开遮挡/换关系/看背面 | 只在关系变化时用，不为绕完 |
| 甩镜 | 接画外真实攻击/换目标 | 甩完落稳再读结果 |
| 变焦/滑动变焦 | 压缩/失衡/惊觉 | 有背景层次才用，不每镜 |
| 速度渐变 | 峰值/冲击/主观 | 按成片占时，不全程快放 |

禁止：无因 360、无因环绕、无因升格、无因推拉、镜头抖代替力量、快切遮动作。通用运动功能、轴线、转场与蒙太奇见[镜头语言与剪辑手法](shot-language-and-editing.md)。

## 7. 切镜

- 切在：爆发、接触、方向改变、技能触发、受击、控制权变化。
- 切点也可在结果、倾听、预期或落稳之后，只要交接有实际收益；无作用完成姿势和空等先合并，不能把“动作完成后切”一律判错。
- 快战同质切镜主动比较景别、观察侧/高度、占幅、注意对象与运动质地，通常让有收益的两项形成差异；有意回应、同构回返或冲击切不按项数判错。
- 切出写“正在发生什么”；切入接“剩余相位”，不重做起手/命中。
- 动作轴/180 度：先定 A/B 屏幕侧；越轴用中性视点、可见过轴或重新建立；反打不自动掉头。
- 30 度规则：相邻同主体镜头角度差太小会跳；要么明显换角度，要么换景别/注意对象。
- 匹配切：用动作/形状/视线/声音承接；不是随便两个相似画面。
- 跳切/硬切：用于省略/冲击；不掩盖动作缺失。
- J/L cut：声音先入/延续，给下一镜空间；不靠声音补不存在的动作。

## 8. 冲击与速度

- **冲击镜头**：接触点近景/插入 + 压缩/变形 + 方向线 + 短冲击帧 + 受力反应 + 下一动作；不靠白闪/音效。
- **速度镜头**：地标越过、前景掠过、攻击端跨参照、跟拍滞后/追回；不靠抖动/残影。
- **反应镜头**：受击/失衡/回护/呼吸/手部；接当前刺激，可承担判断、承受、人物接收或性格重音，不强制每次改变下一招。占同一事件时间，后续继承已成立负荷。
- **张力镜头**：负空间、前景遮挡、低机位、对角线、俯拍小主体、同框主次。
- **慢镜**：只在用户要求或明确峰值；按成片占时，不用真实动作时长冒充。
- **冲击帧**：继承已定峰值的力向、对象、媒介与结果，选择轮廓/负形/材料形变；时长服从本片节奏和已知帧率，不统一规定1–2帧，不靠白闪替代作用。

## 9. 28 秒镜头基准

10–14镜、1.5–3秒常规镜长与短反应可以作普通快战的起步估算，实际以事件、作用、主看和容量成立为准。详细编排及合法边界按[速度与节拍](fight-speed-and-sequencing.md)，本页不维护另一套硬配额。

## 11. 跟着力走（视频生成向写法）

观察可跟攻击、身体避让、承受端、控制或作用前沿；选能读清本拍关系的起幅、中段和落幅。事件流用可执行动作句，An分栏和用户指定摄影参数按原模板，不禁机位/轴线/焦段。

自然动作的关键中段需读到实际转轴、支撑/身体弧线、兵器与对手关系；局部特写强调同次触点，不能遮掉全部身体过程。大效果需要主形/范围与人物任务的接力，不能只跟火花。若人物事件仍只是直线推退，先修动作，换观察高度和方向不能抵偿。

按观看任务比较方位、高度、距离、路径和主读对象，不规定每两三秒变机位、相邻必变两项或固定摄影相位数。硬切、镜内变化和有来源的甩摇/遮挡等按收益选择，一镜到底不偷切；不以统一闪白藏掉决定性接触。固定、长镜和合法同构按当前目的成立，收尾接已选出口，不统一拉远。

## 10. 交付前自检

沿实际画面核必要来向、动作、接触、承受与结果是否可读；切镜接剩余相位与注意，运镜有可达中段与落幅，空间轴与人物朝向连续。快战还核速度、频率、力量和相容变化，能力控场核持续作用、读取与出口。

核快战中是否有无作用复位、摆姿和等待；控制、承压或接收有真实发展与出口，当前速度/频率要求仍兑现。2D另核关键姿势、接触帧、smear、冲击帧、hold和分层运动，不按统一秒数或帧数裁决。

对只换侧面而没有观看收益、重复起手、快切掩盖接触或无作用等待，回负责层修。固定、长镜、同构重复和必要保持按本场目的成立；不按镜数、技法项数或统一帧数判好坏。
