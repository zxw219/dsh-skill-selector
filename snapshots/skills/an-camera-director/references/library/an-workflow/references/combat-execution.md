# 战斗执行与表现

## 奇幻快战中的摄影选择与执行

按[通用镜头语言](../../cinematic-camera-design/references/movement-composition-effects.md)先定观看效果；当前快战再按[快战执行](fantasy-fast-combat.md)落实追压、招式、短促普攻、冲击与区域主峰。快战以快速移动为主，特殊固定可承担巨型压顶、关键接触和范围传播，由导演按观看收益主动选择；不要把“少固定”解释为全禁，也不借例外把普通交锋拍成整场固定。文戏、情绪、悬念与表演采用各自观看任务，不套快战速度。正文与衔接兑现采用决定，文本/打包通过不代表成片已改善。

用于复杂高速交锋、换位/控制/能力连锁，或“逻辑错误、动作不干净、位置转向bug、技能无意义、特效或冲击画廉价、冲击停留太长”的返工。与[动作](action.md)共用事件时间线，摄影与效果回填原模板；简单交锋先用入口。按实际问题使用，不给文戏、氛围或独立能力演示强加战术要求。

## 先编不同解法，再从出口推演

先确定双方本段想取得什么优势、各自准备用什么方式取得，再选动作。动作接得上只证明局部连续：关键转折还要解释谁的尝试奏效/被拆、对方为何改策略、下一次机会由什么结果产生。目的可以是击中、压迫、夺控、试探或明确表演，不强制另加争夺物和剧情。若双方只在回答上一记来招、反复回到同一距离和防线，先组织有发展的攻防意图，再按[动作词汇、组合与身体美感](../../combat-action-design/references/action-phrasing-and-aesthetics.md)选择相容模块，不用动作词数量代替章法。

对关键机会代入对手当前真正可用的选择：能否侧移、撤距、继续攻击或截断来源？正文让其留在原位举盾、维持危险接触或给出落点时，应有本次负载、封线、被诱导判断或角色意图支持；不能只因作者要下一招命中。失误、冒险与性格选择可以成立，须有观众可读的依据，不强求每次都是唯一最优解。

跳跃/升高除了起跳触发，还核下降段和对手同期行动。被迫离地后应在受限中避险、争取新攻线或承担被截的后果；上去后原路落回、对手只等在下方承接，不能仅用“避开一次攻击”解释整串绕行的价值。反查本次起跳是否真由对手的攻击任务产生，还是给预先选好的跳跃补了一个抬地板装置。修时保留有用幅度、威胁与动作数量目标，重编相容交锋，不一律禁跳或删招。

运动选择成立后再验身体和资源是否能连续完成：支撑、动力、出击、接触与收势按当次动作展开，关键拳腿用[运动与传力](../../combat-action-design/references/motion-impact.md#身体共同发力目标真正承力)检查，不用“蹬地、转髋、命中”三个词跳过过程。不能把推演退化成删大弧、删近身、删转身，只留下最短兵器路线。近远战转换写出谁创造入距/释放窗，对手仍在做什么，持续控制与离体运行各占什么资源；采用的身体过程必须进入原稿。相关完整例见[动作成稿练习](action-diversity-lab.md)，仅作原创文字校准。

## 关键交会点实际接续

先编双方共享时间的交锋，再在容易断链的接触、脱开、落脚、换位、转向、施法与镜头出口保留最小状态：

`双方相对地标的位置与有效距离；身体朝向和目标；承重/腾空状态；正在攻击、回收、支撑或控制的肢体/兵器；接触是否仍在；效果源点、作用区与阶段。`

从这个出口实际尝试下一招：哪只手能出招，目标此时在哪里，路径能否到达，哪一步先解除旧约束？同时代入对手尚在进行的攻击、恢复与控制，窗口是否仍成立？这项推演留在稿内，正文写出决定结果的证据，不交内部表、不为每招填坐标。

存在追退、跨场、绕柱、过身、穿巨物下方或位置/距离/方向反馈时，先按[空间连续推演](spatial-continuity.md)建立决定本段的地标与通路，再沿前镜出口更新路线、面向、同期目标和攻击端位置。主战距离不是每镜距离的证明；后退的身体方向和增距的实际结果分别核，近距接触不能靠后镜宣告。固定法术源点、移动作用体与环境接触点各有真实位置及自由度，射程不替代无遮挡射线，平面相交不替代高度/体积判断。

短偏转不必锁住双方，持续抓握、压剑、支撑或承重则须说明结束时机。“格挡完成”不能恢复全身自由，“同时”不能抹掉顺序依赖；同一肢体不能边压来臂边从另一路出拳。受击不自动冻结。错误从最早状态修起，后续镜头与效果共同承接。

## 动态方位与转向

分别处理人物路线和相机观察路线；角色左右、场地方位、屏幕左右不混用，只写影响下一动作的变化。

- 位移后重判距离；被击退者需要追入或已建立的远程作用才能再命中，不能原地短肘打到楼梯上的人。
- 绕后、过身或主行动线改变时，给下一段写清必要的新相对位置与面向，再从这个出口接“退/追”。后撤应沿当前面向的后方或明确撤离路线增距，追入应缩短与当前目标的距离；方向既要与用词相容，也要与下一接触距离相容。“向东退”不能继承开场：乙已在甲西南、朝东北时，直接向东移动会趋向甲，不能仍写成未解释的后退。确需东移就交代横移/转向/过身与对手应对，不能只改方向名让文字通过。
- 对手绕侧、越过或落到新位置后，依据实际感知、脚步与转胸攻击新作用区，转向时对手仍有动作。相机绕行不把敌人送到人物背后。
- 直线查行程，横扫查扫弧，范围技查有效区域；闪避须越出相应作用区。“侧身”不是免伤指令。
- 转髋发力、整身掉头、头部追视与机位换侧分别判断；不为正脸展示转离敌人，也不把全片锁成永远甲左乙右来回避bug。
- 切镜继承前镜出口；俯视、中性机位和可见过轴按观看需要选择，不为每次换位强插地图镜头。
- 复查镜内关键中段，不只看起终点：扫弧、过身、穿障碍与被击退的路径可能在中间改变接触与轴线。地标/目标关系未知时标缺项，不能检验者另造有利布局；数值或关系补设须在获准设计与正文中采用后才作为证据。

例：甲退到柱侧，乙追入截路，甲落脚转胸面向乙再出拳。反拍只改变投影；若甲尚背对乙却写正面直拳命中，先补转向或改招，不用“始终面向敌人”结案。

## 防线记忆与接触转换

在持续压迫的近身交锋中，防线被拨开、支撑被挤窄或握持被扰动后，下一拍从受限状态回答，或通过可见的回护、接重、换握/脱开恢复；不能每招结束就自动满状态。追压已占住出路时，防守不继续复制同一轻松闪避。主攻击端、护持/控制端与支撑按当前兵器/身体任务分工，可在解除接触后交换职责，不照固定左右菜单轮流表演。

抓握、夹刃与顶压在真实争夺中可以保持，但要读到线路、角度、重心或控制权怎样变化，之后如何利用、转移或释放；不能双方摆在一个抓持造型等时间过去。击后惯性、回收/抽离、受力接重和剩余负载成为后招条件，稳定的出口可以仍在运动。详细成稿与合法停留边界见[近身持续交锋](continuous-close-exchange.md)。

## 干净动作与实击

较大的回收、蓄势、换握、转身和贴身处，尝试从对手当前可用的兵器/肢体发起一次可达续攻。若会打断原动作，就补实际封线、离距、约束或代价并改后续；不能默认为对手等候。防守在来刃到达前介入，反攻准备嵌入真实换步/偏转，原发起者仍要回护或承担失败。持械与空等返工见[连续持械交锋与空档推演](weapon-exchange-lab.md)，不以“同时、顺势、已完成”制造窗口。

空间与动作占用正确，仍可能被生成成慢摆姿。出现伸拳/抬腿平缓、击后等待或声音强而视觉弱时，联用[速度、传力与动作观感](../../combat-action-design/references/motion-impact.md)，检查具体加速、身体领随、受力接重及窗口利用，不以本页逻辑通过代替观感设计。

为本轮选当前目的：抢中线、压回收、越封路、截源点等。攻击、应对和下一击利用前一招窗口，发力短、接触明确，回收直接接追步或变线。保留必要落脚、脱开和转向，不能把“干净”写成动作跳帧。

删无作用绕圈、重复摆架、每招完整蓄势、展示后的再启动和“攻—退—复位”循环；身体展示并入真正闪避、制动或出招，窗口由距离、遮挡或对手当前负载提供。保留用户要求的密度、力量与多机位覆盖，不能用少打、全远景或只打挡臂代替优化。

被拨开后改攻击线，落空后有回收或续步，受压后改变防法。轻挡、实击、失衡和重击有不同结果，不让每拳都同样倒飞。“拳拳到肉”要求的关键段须有身体命中与相容的受力后果，只有碰臂/火花不能算兑现；格挡仍可作为交锋的一部分。

文字短与动作快分开：数秒只有一击，其余全是外观、蓄光和禁令，应补可承接的交锋；顺序真实拥挤则先整理共享动势与无用摄影变化。都不靠压短时间戳解决。

## 技能作用与战术必要性

每个关键能力先确定解决什么威胁或利用什么窗口，普通行动为何达不到同一结果。强化速度、距离、负载、伤害也有意义；不强制每招控制地形、夺权或最终获胜。

编成：`当前局面 → 满足起效条件 → 来源与路径 → 对手主动应对 → 行动/力量/战场结果改变 → 后续利用或代价。`

| 检查 | 实际决定 |
|---|---|
| 移除作用 | 去掉能力只留光色，人物能否原样完成全部行动与结果？战斗能力展示未兑现就重排介入点，而非给普通拳换色；装饰/氛围或独立演示按其目的判断。 |
| 起效与占用 | 接触型先有指定接触，储能型先有输入，固定型有固定点及控制占用，离体型有出射路径/控制关系。不能用不符合条件的近似格挡当作已触发。 |
| 前后规则 | 只建立本场必要边界；不为预定胜负临时添万能吸收、永久追踪或必有薄弱边缘。弱点须先建立或由交锋制造，也不强制所有能力付出受伤/耗尽代价。 |
| 对手参与 | 施术窗口来自压制、阻隔、距离或正在处理的攻击；对手继续截断、抢源点、错开或反利用，不站住看技能，也不总换更大的盾。 |
| 后果持续 | 束缚真限制肢体，破坏真改变下一步，偏转后攻击沿新线完成；未被改变的离体效果继续。不能只毁用不到的背景、受控后凭空腾出手脚。 |

先让双方具有不同战术选择与运动机制，再定效果形体；不把所有角色统一改成动能拳。能力已锁定时在其范围内修使用方式，不擅自换掉能力。

近战与能力战转换接续上一出口：原接触如何解除，施放窗口如何获得，远程/巨型能力留下的破口如何让本人追入；击飞后先处理新空距，不在切镜后无因贴脸。屏障裂纹、局部穿孔、偏斜和整体失效分别判断，巨型能力碰撞不自动等于施放者身体受击。按当前战法保留拳腿或兵器职责，具体转换见[参考迁移](combat-reference-transfer.md)。

分身/召唤参与交锋时，区分独立作用体和无攻击权残像，接续本体、分离体与目标的位置、任务和控制归属。两路夹击要写哪一路占用防守、哪一路利用窗口；换位后数量、身份、持物和原位置余势可承接。变身与强化也在双方共享时间内发生，施放者保留身份及当前支撑/持物，对手不因展示需要无故停手。具体变化与参考迁移按[专项](combat-reference-transfer.md)选择，不强迫普通角色使用分身或逐件组装。

## 特效形体与冲击画

先确定主形、方向、边界、受力对象和可见变化，再组织层次、肌理与光色。压面有形变，切口有方向，束带有张力，碎片有来源；避免均匀光团、描边和随机粒子喷泉。主形与负空间组织重点，发光仍有内部结构。不同技能的辨识来自来源、运动与作用，不只换颜色；融合细则见[特效](vfx-finishing.md)。清理装饰竞争时保留用户规模和强度。

短促战斗重音默认插入后立即恢复同一次运动。反馈“冲击帧太长”先缩实际曝光、删重复画与无作用停顿，保留必要造型，不等比压缩整片，也不把短等同于少或弱。精确曝光按当前工程帧率与节奏选择；未知帧率写相对短曝光，不默认24fps、全片四格或固定总时长。用户明确长冲击组/长定格时保留，通过画张、曝光和正常动作间隙组织，不被默认短促覆盖。

先分清接触爆光、接触图形重音、释放/变身峰值、持续技能过程与图形终结。满白不证明接触，持续线场不等于整段冲击帧，变身峰值不必制造敌我碰撞；各自入口、造型变化和退出按事件决定，分类与源帧曝光见[参考迁移与图形重音](combat-reference-transfer.md)。

限色是色彩条件，不是完整造型。冲击画按以下顺序设计：

1. 从当前接触取出作用点、受力方向和被改变的形体。
2. 决定抽掉/保留什么，选择压缩剪影、正负形断裂、斜楔或有方向的笔触，使力量焦点与轮廓可辨。
3. 多张画若采用，改变形状或观看关系，不能只是同一正常画依次套黑白红金底色；反相可用，但与本次作用相容。
4. 曝光后接真实偏转、失衡、破防或落地，继续同一次动作。图形不能新增位移/命中/损伤，或盖住漏写的接触。

廉价感返工同时改造型与时机；只减帧数、增亮、叠负片或震屏不证明改善。抽象、极简与单张冲击画都允许，不机械强制复杂重绘或多张切换；细则见[冲击帧造型与曝光](../../spectacle-impact-direction/references/impact-rhythm.md)。

## 并入一次复核

只检查反馈涉及段及后续依赖：从上一出口能否真实接下一招；攻击能否遇到当时目标；对手不停手时窗口能否成立；去掉速度标签后是否仍有爆发/直接回收/追压/实击；能力条件和结果是否真正写进正文；冲击造型、曝光与退出是否兑现本次要求。不得为修bug删去用户要求的密度、魅力、镜头或大场面。

没有视频，只报告文本设计与已做的检查，不能声称排除了模型方向错误、测得动作速度或消除了廉价感。维护时用[返工案例](action-staging-lab.md)的失败组合与相邻反例实际演练；普通创作不强制多代理、测试报告或内部表格。

## 招式的精彩度与压力释放的参考学习增量

在已有连续性上补招式的长短/直弧、高低、开合、领随和负载变化，前招为距离/高度/施放转换提供真实条件；重复追压/拦截仍合法。持续承压可保持同姿态，通过来力、支撑/控制、材料负载和后果读取，不每次必须晃动或翻盘。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。

## 防御承载、空手反击与倒地恢复

防御接触不等于冲量已被消除：盾/武器挡住有效部位，肩肘躯体与支撑仍可能被推移或掀翻；结果沿当前设定成立。持续防守随对手来向换面/改角，当前空闲肢体可在相容窗口反击；不能让持盾同一只手同时掐诀或换武器。倒地后从滚身、手脚接重与移位继续，不用切镜恢复满状态。反击令目标退距或忙于处理结果，才获得收器/转换的窗口；纯单一战法仍保持。例见[执行方法](narrative-combat-transfer.md)。
