# 一镜内的高频攻防与技能接力

用于一镜到底的近战/技能混战，或反击、闪避、技能接续空转的返工。动作、效果和摄影共享一条世界时间；按当前缺口读相关段，不把整页变成每稿必填表。与[近身连续交换](continuous-close-exchange.md)、[高频与规模](high-frequency-scale-writing.md)联用，保留用户角色、能力、格式、声音与胜负。来源观察见[本轮记录](one-shot-combat-study-20261012.md)，普通创作不必读取原片。

## 先确认“连续”指什么

明确要求全片一镜到底时，阶段、景别变化和技能升级都在同一次相机路径中完成，不暗插切镜。参考可能包含两段长镜头、遮挡接缝或观感连续的合成；标题不证明没有剪辑。连续源帧可以确认已查看窗口的硬切，不能凭若干烟尘/毛发遮挡就证明整段几何无误或绝无隐接。

一镜内仍能近看接触、退看范围、升看高度和改侧看反击。摄影局部返工沿已定动作找可达路径，不借“一镜”重新设定人物路线或删掉技能。固定单镜则靠画内层次和调度完成观看，不强加移动。

## 高频用前招未结束的条件接后招

先写双方当前任务，再在前招的让线、偏转、制动、回收、腾空或落地中找下一入口。可以让进攻者换线追压、防守者从低位送出回击，或让已释放效果继续推进而本体换位；不是所有招式做完、回到中立姿态，再轮到对方。

关键出口只记影响后招的事实：双方相对距离/高度与朝向、当前支撑或腾空路径、兵器/手的占用、还在作用的威胁，以及谁正有行动窗口。下招必须从这些事实发生。高频不等于每帧新命中，不按招数配额写；持续压刀、形成、受压与峰值保持有任务和退出时可保留。

## 防御要说清解决了哪条危险

| 本次应对 | 必须成立的关系 | 出口仍需继承 |
|---|---|---|
| 拦截/格挡 | 攻击端实际遇到兵器、肢体或屏障的有效部分，不能只在近处冒火花 | 接触压力、偏转/剩余攻击、支撑变化与被占用的控制端 |
| 卸开/让线 | 改变来袭路线或将自己的受威胁部分移出它；擦过、部分承受与完全避开分别描述 | 对手仍可续攻，原防线不永久锁住 |
| 下潜/侧闪/跳离 | 从当前支撑进入可达路径，在来袭到达时避开攻击扫过的空间；头、翼、尾和兵器是否也在其中按当前作用核对 | 低位、侧位、空中轨迹及下一支撑，不能闪完无因回原位 |
| 被压退/受击后脱开 | 压力或命中实际改变位置/姿态，不把被迫位移一律叫成功闪避 | 负载、伤害（若成立）、距离及追击仍继续 |

防御出口常能提供下一任务，但不保证无伤或必有反击。遮挡/亮光看不清结果时保留未知，不能把“身子低了”“盾亮了”自动写成完美防住。

## 反击来自一个具体窗口

从已发生的偏转后空线、攻击越过目标后的回收、兵器受限、追击落点、上下层间隙等，选择本角色可用的机会。指定反击端、同期目标和入口；使用当前可用手/兵器/能力，不能在同一手持续控盾时无因再挥剑。对方还会回护、撤出或换线，反击不自动命中。

以下是原创的局部关系示例，并非原片逐招还原：

- 高横斩经过上方时，防守者在原支撑上压低重心、偏身让过扫线；仍在低位时从刀路下方回刺，进攻者收刀下压并退半步处理。低位直接成为入口，而非先站直再拔出第二把武器。
- 挡住下劈后沿接触将刃路卸到外侧，防守者同步移到可达侧位；解除相抵后用当前兵器回切。对方带着偏开的兵器转身回护，不能将瞬间格挡写成永久定身。
- 高位角色俯冲时，低位角色在其下降路线旁起斜向拦截；上方角色可以改轨或回护，落地后的距离与残余作用继续。不等俯冲演示结束才轮到地面方攻击。

这些例子只示意进入条件，具体距离、兵器长度、能力控制和支撑由当前场景补足。持续压制、单方优势、远程对抗与没有反击窗口的防守都是合法情形，不机械交替攻守。

## 技能以稳定的形体语言改变用途

从当前角色已设源头、材料、主形与运动方式出发，再决定如何攻击、防御、移位、占据通路或改变地形。例如同一流体可沿地追压、竖起截路、横向扩成遮蔽；每次用途改变都要有来源、路径/覆盖与对方新任务，不只换色或加大亮度。单技能多用可以成立，不强制每人新增盾、龙和领域。

兵器附着弧、离体飞行体、屏障、具象代理与普通拖尾分别确定作用权和控制：谁发动、何时有效、能影响哪里、由谁持续控制、怎样解除或留存。若参考只显示人物之后出现巨龙，不能自动判定是变身、召唤或自主第二攻击者；新设计采用哪一种便补哪一种的来源、本人状态和回归条件。无因悬浮、持物漂移不能被包装成已成立的飞剑技巧。

技能升级接当前战局：巨型主形逼近哪里，防守者用什么真实通路避开/拦截；范围扩张从哪处影响地面，对手怎样穿越、抢在形成前行动或受到限制。回到近战时旧场域、残骸和兵器继续，不能用白闪直接换到干净新场景。

## 场域与巨物接替当前威胁

巨物的头、躯干、尾或有效能量部位各有可达作用，人物路线回应正在逼近的那部分；体积不是背景贴图。追击穿过柱列时，破坏位置与下一可用路线相连，不能每次经过遮挡就将双方换位。

领域/地形展开时，用本场适合的源点、路径或稳定参照联系旧空间与新几何；相机翻滚是画面方向变化，不自动代表世界翻转。暂离画面的对手仍处理限制、沿可用路径接近或继续已发动作用。领域完成后双方利用当前地形重新交手，不只各站一边展示。

爆光遮住首触时，新稿仍须明确破坏由哪个动作/机制触发、首先作用何处、怎样传播及剩余支撑。碎块、烟尘、火带和保护面共享同一时间；峰值延长/定势按目的设计，不能拿重复近似姿态自动证明高速或物理稳定。

## 相机沿威胁交接注意

先找当前要看清的关系，再把观察点接过去：来袭路线与接触 → 防守者偏出的身体/出口 → 回击通路 → 新距离、追击或巨型威胁。不是每个箭头都换机位，更不是新切镜；合适时一个同框便能读清。近身可短弧移/横移读双方线路，低位追移读下潜和接重，退移/升移显露规模，高低转换接腾空与地面威胁；按事件选择，不全程绕圈。

相机起位、触发、可达路径、中段重点和落幅与双方当前运动相容；位移、摇摄、滚转、变焦分别表达，不靠术语名代替实际变化。关键接触、闪避是否越线、落地能否续攻须留可辨窗口，不让甩动把所有决定都糊掉。更近的观察不必总到面部特写，按当前证据选攻击端、手、支撑或双方关系；用户明确特写则落实实际占幅。

毛发、翼、柱、烟或火可以短暂遮挡相机。遮挡前后接同一人物、兵器归属、空间通路、运动相位及持续作用；无可见依据的武器增生、瞬移和损伤复原不是合格衔接。强一镜约束不能靠遮挡改成隐含剪辑。

## 合并进当前终检

核本场涉及的窗口：防法实际避开/承受什么，反击利用什么出口，对手同期做什么，技能改变什么可用空间，相机是否读清这些关系，遮挡后是否继承。问题修回所属动作/效果/摄影句，不另外加一整套审计。纯近战、单技能、固定镜头、单方压制与有意慢化/保持都按当前任务验收。抽帧、正常播放、试听、原创文本、结构与生成实测分别报告。
