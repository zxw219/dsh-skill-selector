# 分镜表门槛：先成立观看，再选择交付形式

用于多镜头稿像动作清单、相邻镜没有作用或表与正文打架。先在采用方案中确定镜头功能、必要证据、状态/注意交接和切点；这份设计可以直接存在于正文，不要求先向用户交一张表。

一镜到底、固定机位不切与单场连续表演不属于本页的“多镜缺表”问题：它们的成立依据是段内的距离、姿态、注意与停留，按[一镜到底](one-take-direction.md)核，不用本页的镜数/切点要求逼出切镜。

## 什么时候用表

用户要分镜表/故事板时交表；复杂镜组需要比较或维护定位时按需使用。用户只要可复制正文、已有模板或只改摄影时继承原形式，不以“没有表不写正文”阻塞工作。简短连续镜不为达到镜数额外拆分。

表可列镜号、绝对时间、主读任务、取景/运动、关键变化和接出。选当前有用列，不额外规定8–15行或必须六列。

## 观看与切点

每镜有主读任务，允许镜内由建立转到反应或结果；不是一个镜头只能完成一种功能。相邻镜可以同构、反打、轴向切或回返，以新信息、强调、人物接收、节律或空间关系解释收益，不以“两项变化”“三种大师手法”判通过。

持续保持可交付压力、等待、观察或环境进程，须能说明当前作用与出口。没有作用才合并/删除；不因“互锁/各退/开域/抬手/冲击帧/白场”字样自动删除。交手是事件单位，可以同镜或跨镜；纯打斗仍保留已定胜负和结束方式。

无对白/非人段按实际角色表达渠道与转折选覆盖，不套固定情绪曲线、每幕插镜数或脸部配额，见[无对白神话](silent-myth-sequence.md)。

## 表与正文共同核对

二者均为方案表达，发生不一致时回到用户要求和最终采用事件核对最早偏离，再同步修订；不让过期表格无条件覆盖正文。镜头数、片长、动作结果、声音、素材与真实转场一致才交付。

检查/查因只定位具体缺口；已有修复授权则修本职责及依赖。通用设计见[整段分镜](storyboard-sequence-design.md)，职责见[模块分工](module-boundaries.md)。
