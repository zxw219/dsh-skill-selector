# 动作多样性与美感：完整成稿练习

用于校准“只剩几次挥砍、动作少而同质、施法只有伸掌”的写法。设计方法见[动作词汇、组合与身体美感](../../combat-action-design/references/action-phrasing-and-aesthetics.md)。以下都是原创文字练习，时间为编排建议，尚未生成视频；不是参考影片逐招复刻、实战技术或新默认模板。角色能力、身份、时长、声音和格式仍以当前任务为准。

## 练习一：纯持械，固定一镜到底

6秒，16:9，二维动画。两名成年剑士在平整庭院争夺门前中线，各持一柄实体长剑，不使用法术。甲在门前，乙从庭院追近。固定斜侧全身中广景，门槛与地砖保持可见，一镜到底。完全静音。

【0–2秒】乙追步斜落剑，甲在刃路抵达前斜架剑身，同时向门侧错步，让自己胸口离开原斜线。两刃短碰后向下滑离，乙的前脚继续接重，甲的剑尖在收肘中转向乙胸前。镜头保留两人的脚步、剑身接触和滑离过程。

【2–4秒】甲沿短线送剑。乙将刚脱开的剑收近胸侧，用剑身截开刺线，躯干向庭院侧转开；甲收回伸臂，剑刃回到身侧，没有继续穿过乙。乙随转胸从低处上撩，甲后脚抢接并撤出其上撩覆盖区，门前中线因这次追压让给乙。

【4–6秒】乙向门槛续步，抬起的剑沿当前侧面回收护身。甲从退步出口斜切回门侧，剑尖重新指向乙的进入路线。乙看见甲侧切，缩短前送步并转胸截线；镜头在新的交会即将发生时结束，两人没有完整复位。

变化落实：斜落、滑离接短送、截线转胸、低路上撩、撤出后斜切；承接由距离与剑路造成。此例不靠拳腿、大招、切镜或声音丰富动作，原例的6秒不成为通用密度标准。

## 练习二：拳腿接续与对手持续回应

9秒，16:9，写实风格的动画短片。成年甲乙空手，平整宽阔场地，均能正常移动，不使用超自然能力。甲想突破乙守住的通道，乙要将甲挡在通道外。镜头以斜侧全身跟移为主，接触处保持手臂、躯干与腿的关系。仅步声、衣料和身体碰撞声，无对白、字幕、配乐。

【0–3秒】甲短步追近，右拳由胸侧送向乙上身。乙抬左前臂截住来拳，肩胸随接触向通道侧偏转，后脚抢接；甲收回右臂时已经跟进，左掌从较低路线推向乙肩侧。乙将左臂回护到胸前，右手短拨甲左臂，脚下向空侧错出，甲的掌推因此偏离目标。相机随两人横移，接触的先后保持清楚。

【3–6秒】甲的左臂被拨开后回收护住胸前，身体转向仍在侧前方的乙，左脚接重，右膝抬起形成腿部进攻的预备。乙缩臂护身并斜退，甲的右腿向乙躯干伸出，乙以前臂承挡、躯干后移，继续退出这次短接触。甲立刻折回右腿，把右脚落到推进方向，而非伸腿悬停给相机看。镜头稍后移容纳落脚和双方距离，腿的伸出只有一次接触，不把提膝误写成额外命中。

【6–9秒】乙趁甲落脚接重，短步向甲的新侧面追入，右拳送向甲肩胸。甲转肩并以回护前臂偏开来拳，左脚向通道一侧踏出，乙转胸继续追线；甲借这一步从乙守位旁挤过，乙随转身伸手追截。镜头跟住通道口的争夺，在乙仍追截、甲仍通过的出口结束。

变化落实：拳与掌走不同路线，受挡后回收、提膝伸腿、折腿落步、对手利用接重追入；最后兑现通道任务。不能迁移成所有持械者默认踢腿，也不能假称已验证写实演员安全执行。

## 练习三：远程迫避、追入与持续施法

12秒，16:9，二维仙侠动画。成年白衣剑士只持一柄实体剑，既定能力允许一次挥剑发出独立运行的弧形剑气；剑实体保留在手。成年黑衣术者空手，既定法术为右掌持续控制一面有范围限制的斜置屏障，收掌则屏障解除；此例不增加反弹、瞬移或飞行。石庭院中央有一根粗石柱，双方隔着数步，剑士想越过柱侧通路，术者要封路。仅脚步、剑气、屏障受压与衣料声，无配乐、字幕或对白。

【0–3秒】白衣剑士沿柱外侧迈步，右剑在侧后回收，转肩斜挥，将弧形剑气送向黑衣术者原来的通路；剑实体随挥后收回身侧。黑衣术者向柱旁斜退，右掌从胸侧打开，建立斜置屏障。剑气撞在屏障一侧，受压弧面短暂变扁后碎散，术者继续退入柱旁空处。镜头斜侧跟移，同时读到挥剑身体、离体剑气与对手的退位，不用快切省掉进入距离。

【3–6秒】剑气独立飞行和碎散的过程中，白衣剑士已沿柱外侧追近，右剑收近躯干准备短线送入。黑衣术者持续伸出右掌，将屏障转向白衣剑士的追入路线，身体侧步改变观察角度；右手仍在控制，没有同时出拳。剑士见屏障截在前方，缩步转胸，沿屏障边缘向柱侧切入。相机随柱侧移，保留屏障边缘、双方脚步与柱子的遮挡关系。

【6–9秒】白衣剑士抵达屏障侧边，剑尖从短路径送向术者身前。黑衣术者将右掌收回，屏障随既定规则解除；身体继续绕柱撤出，左前臂回护，但不碰刃口。剑尖从其旧胸前位置经过，剑士收肘撤回剑尖并转向柱旁的新目标位置。镜头跟过柱边接这次落空和转向，不因遮挡让术者跳到对侧。

【9–12秒】黑衣术者用已恢复自由的右掌在退步中重新定向，屏障立在剑士即将通过的柱侧窄口。白衣剑士此时右剑回护，左脚接重制动，转胸改走柱外侧更长的通路；术者随移动继续调整屏障，通道争夺尚未结束。镜头后拉至斜侧中广景读到近路受阻与新路线，承接现有状态结束。

变化落实：远程投射有挥后回收，本体追入与离体作用并行；持续控制占用右掌，解除后才重启；近战进入由脚步完成，法术通过封路改变身体选择。若角色只有物理剑/常驻盾，这个练习不能原样套用。

## 把原有28秒例稿的重复点改成动作设计

原有[28秒阶段叙述示例](battle-prose-example-28s.txt)展示技能主形与相位，动作研究不把它当用户最新失败稿。其右掌推出、剑诀指向、追近再释放容易重复，近身身体层偏少。可在保持原能力与时长的前提下，定向细化一段：

原句入口：实体剑沿回收路线落入白衣女子右手，她顺着前冲斜斩。赤衣女子侧翻让剑，左手掐诀，前方云雾显化火鸦。

原创局部改写：实体剑回到白衣女子右手，握稳后她收肘把剑带到身侧，身体由下沉飞行转向赤衣女子侧前方，剑沿斜面切入。赤衣女子先侧移让胸口离开斩路，肩胸继续随御气路线滚转，左手在靠近胸侧的位置结诀；火鸦在白衣女子继续追入的云隙形成。白衣女子见新威胁，右剑沿挥后弧线回护，身体降高穿向尚未封住的空隙；镜头从两人斜侧跟移，读到接握、身体转向、斜斩、让线和回护后降高。火鸦的数量、职责与后续结果继续按原稿，不重播施放。

改的是接握、领随、回收、身体与施法并行及观察，未增加新能力。它仍需嵌回完整28秒稿检查负载，不能单靠增加动作形容词保证成片美感。

## 同次验收的相邻反例

| 约束 | 仍然成立的设计 | 错误扩展 |
|---|---|---|
| 纯持械/禁止拳腿 | 剑路、高低、步位、接触与回收变化 | 无理由加入肘膝踢 |
| 只用一招 | 入距、方向、防法、不同任务与出口 | 为丰富新增技能 |
| 一镜到底/固定 | 调度、剪影、可辨接触与景深层 | 偷插特写/反打 |
| 慢镜/定势 | 有意延长姿态及领随，保留目的 | 一律删停顿改快战 |
| 单人展示 | 身体开合、器物路线、释放/落地 | 硬加敌人和命中 |
| 完全静音 | 动作和受力由画面承担 | 用碰撞声证明力量 |

静音场次的完整对照见[静音选择6秒](../assets/cases/fixed-silent-choice-6s.txt)：固定镜头、完全静音，人物的等待与判断由身体和视线承担，用于核对不说话时人物决定仍可读。
| 持续操控 | 空肢体和相容身体应对 | 控制手同时执行互斥攻击 |

人工语义复核检查距离、支撑、忙闲肢体、刃路净空、对手响应、接触解除、控制与出口；结构脚本只核时间/格式，不能验这些动作，更不能验正常播放观感。实际生成时另记最早失效时间，再决定补动作、改观察或改变控制方法。
