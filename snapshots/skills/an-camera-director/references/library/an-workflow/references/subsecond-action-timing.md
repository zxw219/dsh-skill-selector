# 小数秒动作编排

用于本工作流的动作、打斗及其相关摄影/效果/声音；默认以0.1秒精度写设计时间，用户明确指定其他精度、固定锚点或格式时按该要求。0.1秒是时间表示精度，不是每次动作的时长、每秒攻击配额或切镜频率。

## 先安排相位，再定时间

沿已采用的角色与事件链确定：起始支撑/控制和距离 → 发动/加速/形成 → 在途及对方同步应对 → 首次接触、避开或规则生效 → 受力/结果 → 脱开、回收或继续控制 → 下一任务。不是每招都具备全部相位：瞬发不硬添长蓄力，持续场不重复释放，接触已在发生的开场不重新抬手。只将影响本次速度、力量、应对窗口、状态或观看的变化落到时间。

先判断各动作的路径、范围、身体/控制占用和对手可达应对，再分配合理长短。近距离短攻、跨空间位移、巨物成形、持续角力和慢化峰值各按自身任务占时，不用同一套0.2秒套餐。不为填满时间新增招式，不为提高频率删掉用户锁定攻防。动作短促仍须让决定性接触和结果有可辨证据。

同一次落脚分清开始落下、承重完成与沿该支撑继续制动；跨段写“仍由此脚承重”，不再次踏步。撤步/侧移后下一招核追入、转向与攻击端可达距离，不能只写“从新支撑”。末镜明确停在取线、加速、在途、接触、受力还是脱开，并给足支持该状态的位置/控制事实；不能在短拳已飞行一段时间后，仍凭结尾标签宣布“尚未交会”。

## 速度型段落另核世界进程

下节“两层时间”指成片时间的包络与锚点，不代表世界时间与角色时间相同。闪电侠/快银式差速按[速度型战斗](speedster-combat-direction.md#2-分开成片时间世界进程与相对速度)先确认当前观察档位；S与`t=`仍是成片绝对时间，主观段中下落物/机械/普通人的世界进程另由可辨状态维护。精确世界计时确有要求时用不同名称标记，不与成片t混写，也不将主观占时相加成对手等待。

同一物体在变速/切镜前后接位置、朝向、动势和接触结果；回正常速度从已到相位继续，不再次起跑/命中/破坏。普通人物几乎未变姿可以是合理速度差，检查其世界反应窗口；同级对手与触碰后物体各按既定关系推进。未知倍率只写明确差速，不伪造毫秒精度，固定与一镜不因换档偷加切镜。

## 两层时间，保持原声画格式

- **镜头/S包络**：采用全片绝对时间，如`【镜头1：S=0.0–1.3s｜…】`、`S=0.0–0.7s：…`。相邻正文段首尾相接，最终终点等于锁定片长；20秒之后的续段从`20.0s`继续，不重新从0计时。
- **事件锚点**：同段确需精确安排时写`t=0.3s首次接触`、`t=0.6s解除接触`，均属全片绝对时间。锚点是同一次事件中的变化，不是另一个S段、额外命中或新镜头。避免将第二层独立放成裸时间区间行，被误读为新增主时间段。

默认写一位小数，包括整数边界的`.0`；采用更高精度须有实际用途，不编造百/千分秒曝光。全部锚点落在所属段内，按事件依赖排列；段尾是下一段入口，同一边界事件只描述发生一次。需要独立相位分段时新建S段并沿用`fx-env：`、`sound：`，真实镜尾才写`transition：`。不要给每个小锚点重复整套栏目。

## 并行、摄影和声音共用时间

对手在发动/回收期间继续其实际行动；独立法器、在途技能与本体在同一时间推进，只有机制允许才并行。一个0.6秒段里同时发生的移动与法术不能相加成1.2秒，手部互斥任务也不能仅写“同时”放行。

摄影在已定相位选择触发和切点，接触前后可切，但切回接剩余进程，不重放起手/命中。每0.1秒换镜会破坏读取，阶段细化不改变真实镜数；固定/一镜到底用画内变化保持连续。跟拍、摇摄、转焦可跨多个S段延续，不在每个锚点重新启动。

检查编译后的实际剪辑点，不只检查镜头标题：同一镜头正文中若真的从人物近景剪到落点特写，应拆成相邻镜头并重新核包络、锚点和衔接；连续转焦或运镜改变占幅不算剪辑。对短距高速箭弹等，离体到接触的预算与当前距离/机制相容；需要更长观看时明确采用慢化或拍作用/反应，不无意把飞行拖慢。缩短在途时间时同步检查防御是否提前从可见源端启动、接触音和材料反馈是否移到同一锚点、下一任务是否接新的结果，不按本次示例固化通用飞行秒数。

效果与声音跟同一次事件。例如S段`t=0.4s首次接触`，衣料受压、金属火星或允许的接触声就在0.4秒跟随该接触，不在fx-env再攻击一次。持续受力可延续，余响可跨段，身体不为等声音结束而停住。完全静音仍静音，不为精确卡点新增声源。

慢镜以成片占时编排，不把真实动作时长与播放时长相加。未知帧率不将0.1秒换算成一帧；即使帧率已知，曝光/冲击画张数及生成执行仍须实际证据，不能由文字时间承诺。

## 校核与交付

先检查动作/术法能否在当前条件和时间成立，再核S段连续、镜头包络、锚点范围与顺序、接触/效果/声音同次对应、跨镜剩余相位、总时长和锁定事实。相位过挤先理清相容并行、共享回收及观看组织；不能只减数字或省去受力/接重。

普通出稿交原格式完整正文，不另交时间设计过程表。局部改稿只细化获准事件及必要承接，保留既定时长、动作数和结局。例稿见[3秒近身连续攻防](../assets/cases/subsecond-close-exchange-3s.txt)，只校准时间表达，不将其动作、秒数和机位当模板。

文件检查器已支持小数S段和镜头包络；可按[验证说明](validation.md)检查数值连续性。显式选择`--event-times absolute`可核段内数值t=范围与行动顺序；语义、锚点可达性和状态仍由人工复核，数值通过不证明动作速度、时间容量或成片执行。只有实测成片才能说实际命中/切镜发生在某时刻；本页写的是可复制的时间设计目标。
