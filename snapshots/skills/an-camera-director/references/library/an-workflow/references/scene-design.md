# 场景设计细则

已有剧本、多场剧情或信息顺序复杂时，先执行[剧本转剧情提示词](script-to-screen.md)的原文拆解与事件/知情检查。每场有真实入口、承重变化与出口，后场继承人物所知及道具/场地状态；不以华丽拍法替代缺失前因，不为修补逻辑新增关键证据或剧情。

仅在本场需要展开导演、摄影、表演或动作细节时读取；普通任务先用入口页。下列规则保留原工作流的专项设计能力，按实际问题应用，不要求每镜集齐、每次全查。

交付长度、格式、生成端适配与创作权限统一由[技能入口](../entry-guide.md)决定。这里提到画面、S、fx-env、sound时，指相应信息职责；简洁正文可自然组织这些信息，无需为引用本页而切回分栏。梦境、象征、抽象冲击画和有意留白按已确认表现目的检查，不用写实规则消除艺术选择；意外断链仍须修复。

## 专项设计


**整场导演语法**：导演设计覆盖事件/视点、表演调度、摄影焦点、光色美术、剪辑声画与时间节律，不以用户列出的手法作为能力边界。先让人物目标、进出/近远/挡露及共同任务改变关系，再选择同框、局部、主观、反应、长镜或切接读取；固定也可完成注意交接。按项目建立相容的视觉基线，在有意义的节点延续、偏离或回返；不把每镜独立炫技拼成整场。明确整体导演提升、场景语法、复杂视点/调度/声画或方法学习时，读[整场戏的导演语言](directorial-foundations.md)，按问题补模块；普通创作执行这些核心决定，不自动全库加载。

声音区分同场声、画外声、下一场提前声、上一场延续声与主观处理；声画错开不自动让角色听见别处声音，不重复计时/说词。光色、焦点、空间母题与镜头并置共同引导注意；允许写实来源启发和有意表现性语法，服从当前媒介和用户锁定，不自动配乐/蓝橙/浅焦。

**构图与注意**：景别来自需要读清的证据。三分线写主体与另一侧空间；留白写缺席/等待的对象；前景与框架写真实遮挡和打开时机；三角写三个实际投影顶点；引导线写起点与目标；巨构写尺度参照与体量关系。不是每镜集齐这些手法，构图随调度变化时检查关键中段。用人物相对位置、占幅、视线空间、遮挡、明暗和焦点说明画面，不只写情绪标签。特写读取有刺激的变化；固定远景不索取不可见微表情。按需组织前中后景，不凑层数或景别配额。背景简洁也有空间和光线依据。

**运镜与剪辑**：先决定观众站在哪一方、相机所在位置/高度/朝向，再写起幅、触发/观看理由、主路径与相对速度、中段构图变化、落幅及切点；固定镜头说明观察什么；固定位置与固定朝向/视场按当前要求辨清。手持说明参与关系与微动/惯性质地，不只写强抖；稳定跟拍与手持跟拍均可成立。跟随行动、靠近心理或叙述者主动揭示均可成立。推进、变焦、摇移、转焦不混用，不默认慢推或全固定。焦段配合机位距离与实际画幅，不让原地换长焦伪造透视压缩。希区柯克变焦写移动与反向变焦、主体占幅及背景变化；甩镜写触发与落点；抓拍感与急变焦分开；抽帧说明视觉更新、曝光及成片时间，不能自动等同加速或冲击帧。相邻镜头承接视线、动作相位、声音或图形，必要时可有意中断；比较远近、动静与信息密度，不平均分镜。角色与相机路线分别可达，一镜到底不暗插机位。重要镜头除逻辑成立外，还须有实际的构图秩序、注意安排与节律；需要视觉重音时指定发生的关系变化，不用“惊艳”代替设计。氛围和纯图形运动按感官/节律用途判断，不强加剧情或反转。详细设计/返工见[分镜视觉](storyboard-visual.md)。

一个动作可由多机位分镜共同呈现速度、发力、姿态、接触与后果，不等于每镜都要塞完整动作，也不等于从不同角度重播同一击。切镜按连续动作阶段交接，构图显出所需身体线条和受力关系；冲击帧强调具体接触或状态突变，随后承接真实变化。摄影覆盖与冲击帧的选择、连续性及验收统一见分镜视觉模块，不设固定镜数。

**对白与表演**：对白冲突、关系变化或身体表演在设计阶段读[表演](drama.md)；明确强化演技、微表情、哭泣/痛感、面部纹理或台词语气时，联用[人物表演导演](../../performance-scene-director/entry-guide.md)，只读命中专项并共用一个表演锁。同时明确谁说、谁接收、观众此刻看谁；切点落到具体词句或反应起点。可同框、切听者或保持说话者持续表演，不逐句轮流打头像。切走后标实际声源，原台词按声轨顺序拼接逐字不变。关键反应在可见脸侧、合适占幅和焦点中发生；有意隐藏服从揭示时刻。听者可话中领会、句意完整后处理或合理延迟，不默认句末统一变脸。同一刺激不反复演同义微动作，自然、夸张与爆发按人物和媒介选择。 意图与不受控反应分开；身体支撑、伤痛、气息、泪/鼻涕湿痕和既有皱纹/疤痕跨镜承接。台词先定对象与行动，再处理重音、节奏、音量、音高和声质，低声/低沉不混为耳语；表演细节写入可见画面和获准sound，不替导演另设机位或改原词。

**状态与空间**：位置、朝向、持物、伤痕、接触、知识及画外人物状态随事件继承。未来伤口、污染、易手不写进初始外观。接稳/接重后才松手，同一肢体不承担互斥任务。角色自身左右与画面左右分开，换机位重算投影；隐藏道具指向靠具体取景、遮挡与切点。切镜不替代移动、交接或合法空间重建，反转切镜不写成现场变身。

**攻击指向与动机**：每次关键攻击在稿内核对“上一结果提供的机会/当前目的 → 目标在出招及预计接触时的位置 → 攻击部位从起点到作用区的路径 → 对方响应 → 双方新状态”。正文写出其中决定动作的证据，不能只靠“转身、反手、顺势、朝前/向后”代替目标与路径。相机前方、画面前景与角色面前不是同一方向；换位后重新判断，不沿用开场前后。目标尚在面前时，向身后运动只能是有依据的预备、回收、攻击另一个已建立目标或曲线路径的一部分，不能直接宣称命中面前目标。漏掉转向/追入就补在接触之前，明示佯攻与封路的预期作用；不凭空添加背后敌人解释错误。出稿复核必须检查这条关系，格式检查通过不能替代它；细则见[动作](action.md)。

**动作与协同**：保留速度、攻击密度、力量、敌群活动、伤害尺度与胜负。高速有方向、可见时间内相对地标的位移和必要制动；运镜、风声与拖影不能替代身体速度。攻击有来力/路径、接触、受力结果和下一招；连招共享动势，范围攻击可以成组成果。死亡有退出与残留，仅在用户要求时追加血液来源。多人/人兽/人机协同写出一方创造条件、另一方接应利用与共同结果，人物与环境交互先触发再改变可用通路。大招以作用和战场结果超过普攻，主峰不被无关支线抢走；不向碾压剧情强加失势。复杂动作、协作或无力诊断读[动作](action.md)。

打斗设计同时兑现空间因果与观看体验。用户要求张力、速度、激情或成人非露骨魅力时，在编排前选定各项具体的可见事件和摄影位置：张力用逼近的威胁、逐渐失去的选择及应对代价；速度用地标间距被吞掉、爆发与承力/回收的速度差；激情用受刺激后改变的目光、身体投入和抢攻选择；魅力用实际取景中的整体动作线条、服装轮廓与角色主动性。将证据编入画面、S与sound，不另交愿望清单，也不把所有项目挤到同一镜。正确性检查后，再看所要求的体验是否在正文真正发生；仅有“高燃、高速、性感”、时间戳或格式通过不算兑现。详见已有动作、运动语言与分镜模块，不增加每次必读文件。

对攻可包含积极防守，但不让另一方无故陪练或等技能放完。相邻交锋继承上一轮的压力，不能每次格挡后都推开、复位、再试探，最后仅以共同警戒代替用户要求的高潮；具体胜负仍服从原剧情。若反馈动作少、只有进攻躲避、方位混乱或大场面空洞，按[动作推演与返工例](action-staging-lab.md)重排战术交锋，不能仅追加安全通路、故障伏笔和禁止词来宣称修复。

若反馈跑动像走路、力量不足、动作转换缺失、角色战法同质化或巨物无尺度，读[运动语言](motion-language.md)：先落实步态、接重与换招、角色动力和能力，再用环境参照、光迹及有明确职责的摄影强化。机械不等于僵硬，巨大不等于全程慢，修仙不等于站桩挥剑；拖尾不能替代位移。身体姿态展示按该模块的非露骨表演与材质规则处理，不拿脸部特写替代所有身体镜头。

**媒介与声画**：视觉方式按当前项目决定；地域、时代和实体文字依据已确认设定，缺省采用相容设计，不按中文或角色类型擅定国家。写实用可见透视、曝光、光源和材质，二维/水墨用造型、线条、笔触、墨色与空间层次；不强塞手机型号、颗粒、4K、浅景深或“禁CG”。光源及适用介质有依据，模糊、雾和光晕不淹没关键证据。声音区分无音乐、无环境声、仅对白和完全静音，模板不能恢复用户禁掉的声轨。

**大场面与冲击**：明确要求效果主导的大场面、巨物压迫、连锁破坏，或反馈场面小、冲击不足、冲击帧少/看不清/太短时，在设计阶段联用[大场面与冲击导演](../../spectacle-impact-direction/entry-guide.md)。先组织可见的尺度参照、威胁逼近、主效果形体、作用传播及人物选择，再安排冲击节奏；大效果须在行动过程中获得展开时间，不能只给局部对砍附上背景爆炸或结尾废墟。冲击帧先设计特殊造型画（剪影、正负形、抽象力线等），再安排插入相位、每张曝光、画张切换与回到正常画面的方式。允许单张抽象化；序列入口与出口承接动作因果。用户要求长序列时可安排多张不同冲击画，不能以慢放碎裂或延长一张普通特效画面替代；持续区间计入全片一次，不固定配额。与动作、摄影、特效共用同一场景和时间线，回填原声画格式；普通局部打斗或文戏不因此升级成灾难场面。

**特效**：核心转化、威胁、高潮、复杂效果或AE级要求，在设计阶段读[特效设计与合成](vfx-finishing.md)。按来源、触发、主运动、作用、环境交互和终态组织，与表演共用时间；实体转化前沿与发射位置对应，已消失处露出正确背景，跨镜承接源点和残留。保留要求的规模，通过层次和关键可读区解决遮挡。用户指定配比才写数字，定义职责并核对合计。完成指定主结果即可按剧情结束，残留可散尽、留存或离画，不自动拖长尾巴；机制与验收以特效模块为准。提示词、分层方案与实际制作分开，不以“电影级”代替执行证据。

## 战斗场景与气氛的具体用途

原创战斗从角色距离、攻击路径与当前体验选择实际结构，锁定场景则使用原结构。场地影响过点、改层、落脚、视线和技能作用，光/空气/声音响应正在发展的威胁；不是默认云海祭台、残柱石桥再在高潮全部炸掉。情绪由人物接收到的新危险/机会引出决定，场地变化接后招条件。对应执行见[战斗体验设计](combat-experience-design.md)，纯展示/氛围仍按其目的，不强加败退救援。

## 用场地条件选择事件

原创或可调整的场地先选真正影响本场的条件，再给外观。锁定场地只利用已存在的结构；下面是候选，不要求每场地形变形。

| 已有条件 | 可参与的争夺/观看 | 变化后继承 |
|---|---|---|
| 狭道、门槛、桥跨 | 通过次序、长器净空、同伴遮线、门内外信息差 | 谁已通过、谁仍被挡，通路不因近景恢复宽阔 |
| 阶梯/台边/垂直落差 | 高低换线、视线遮显、上层目标与下层支撑分离 | 踏面、同刻高度、下一支撑与下降区 |
| 滑动/倾斜/破损支撑 | 争落处、提前换重心、同一载体上的关系变化 | 面和人物各自的运动，破损后的可用区域 |
| 水面/软地/松散材料 | 痕迹显露、支撑代价、已有能力的介质条件 | 湿痕/凹陷/流向与已变区，不凭材质临时授能 |
| 半透明、反射或遮挡层 | 观众先知/人物后知、显露局部、声源先行 | 真实视线/反射条件，看到反射不新增一人 |
| 开阔空域 | 相对距离、高度和作用体连接；缺少掩体本身形成压力 | 来源、目标、空域参照，不靠云雾补造落脚 |

同一门槛可用于阻敌、交接、护送、谈判或等待，不能一律变成封退路。文戏让谁跨过边界改变关系；悬念让线索的可见范围改变知情；喜剧可让同一空间规则被人物误用后再兑现；氛围可只发展材质/光线节律。验场景参与时尝试替换场地名称：若通路、选择和观看全可原样保留，回查该环境是否只做装饰；纯背景或展示任务不强制战术作用。

## 场景推进与可继续的出口

新增场景设计从人物目标、阻碍、信息与可用通路的变化进入：同一动作在当前场地为什么有效，结果怎样改变下一选择。稳定展示、等待、纯空间体验与有意隐瞒按其功能保留，不每场硬造反转。镜头或段落出口可停在未完成的行动/选择上；没有叙事收束要求时，不为结束时间段追加对视、摆开阵势或胜利造型。场景、美感与摄影共享同次变化，地图关系正确不能单独证明观众体验已兑现。

## 期待与场景主峰的参考学习增量

剧情向战斗把威胁如何碰到人物关心的对象、选择怎样发生、机会由谁创造及主峰如何兑现写进原事件链；纯展示/碾压也可成立。观看重心随人物、作用和结果转移，前招留下的未决条件推动后招，不套固定先受挫后救援。详见[战斗精彩度导演](battle-excitement-direction.md)，只取本次职责并回填同一稿。

## 战斗介入、见证与下一步的可见条件

在已经采用的剧情中，明确谁看见何事、为什么换任务、怎样到达可用位置；同场观察位与交锋位交替不自动表示事件严格串行。器具操作或人物亮相可先建立战法差别，后续用途据已有状态展开。威胁前兆可先改变环境，再揭示有效危险部位。保持纯展示、直胜和单人场景的原目的，不补强制失败/救援；按需取[执行方法](narrative-combat-transfer.md)。

## 承诺、阻力与观众判断

关键段先确定观众此刻在等哪件可见事情：门是否会被关上、谁会先松手、谁先认出线索。人物用明确行动争取条件，对手或环境用当前资源改变条件，出口兑现、推迟或改写这份预期。没有叙事冲突的氛围段可让空间、光色或运动成为观看对象，不强塞目标和反转。

人物知识和观众知识分别成立。关键反制代入对手现有选择，成功、误判和冒险各有当前依据；切到听者或遮住证据可以延迟观众知道的时刻，不能让人物凭未接收信息行动。多人每次介入改变同一争夺，先共同事件再分人动作。方法对照仅维护时读[05—07与19](../assets/reference-studies/modules-20261018/storyboard-05-20.md)。
