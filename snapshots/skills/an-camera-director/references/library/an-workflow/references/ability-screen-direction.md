# 技能如何用画面、分镜与运镜展现

用于技能设计已有却看不懂、施法被拍成站桩特写、被动没证据、大小技能都拍成同样光球、大场面脱离人物任务。机制尚未成立先回[技能体系与状态](ability-system-design.md)，已有作用只设计可见性与摄影，不借取景增加能力。所有选择回填当前模板；固定、一镜到底、无声音和不同媒介按原条件有效。

## 必要技能先有正文证据

用户要求的每项能力先在实际S正文定位触发/归属、主作用、对手同期与接收端新状态，再设计观察；仅有技能表、发动字样或fx-env泛光按欠写回机制/事件层。技能数量上限不能证明出现，身体动作不能抵偿技能缺失。观看层细化已定作用，不借查缺重新发明能力。

## 施法动作要在实际镜头里读清

普通招式的关键换诀/控制也分配实际占幅，不能只有大招给手部读取，小招全部远景甩掌；已有动作未看清只修观察，缺动作/机制交回所属层。按[高速施法交锋](fast-spell-exchange-design.md)继承当次手资源、目标与退出，镜内/邻镜让操作和结果同源，不强制每法完整手部教程或多镜。

手诀/腕向/指节承担本次发动差别时，选能辨其改变的近景或特写，让实际发动部位与必要源端有足够占幅；不是全景附一句“清晰手诀”。局部特写不要求同时装进战场，远端生效和人物新任务由邻镜继续同一次释放；大招范围镜读体量/作用，不索取小人物手指。非手部发动、常驻/自动响应按机制取证，不凑手特写。具体构图、遮挡、相位和力量交接见[细节覆盖](../../action-camera-direction/references/detail-coverage-clean-cuts.md)。

## 选择本次观看立场

本次先看谁做决定、谁承受、哪条规则改变，或只体验形态/材质？先于目标看见前兆可以制造预期，跟着目标才发现可以形成突袭；旁观关系读交互，靠施术者读控制投入，靠承受者读局部侵入。主观视点可以暂时误导，但区分角色看到与观众事实，有意隐藏按揭示时刻兑现，不给所有法术统一流程。

把采用的机制编成一条可读证据链：**入口状态 → 此次触发/选择 → 关键主变化 → 接收端新状态 → 后续行动**。它可以同框、镜内交接或必要切镜，不要求五镜。纯展示用形态、材料和空间关系作为变化，不硬添受击者。让观众实际看见当前最值得看的状态，别把多样性只留在共享技能表。

## 丰富要在决定性画面中兑现

沿已采用机制给每个重要差别选实际可读对象：侵入看接收部位、失稳看支撑变化、误导看判断与真身的分离、暂存看停物与仍动背景、代理看分工和负载、解除看前沿与恢复的动作。若全部落成甩掌/泛光/敌人后退，按[原创与选招](ability-variation-selection.md)先定位机制/动作是否已经不同，再修所属观看；镜头不能自行新造能力。普通招式和主峰都按本段职责落实，不统一三镜、夸大所有小效或把换机位当效果差异。

## 形态语言要提供可观看的差别

技能的效果不只有光：表面附着/裂纹/润湿、密度与硬度、浮力/重力方向、空间重排、透明度/遮挡、影与反射、感知偏差、代理行为和物体变形都可承载机制；是否真实起效服从世界规则，不从材质外观自动推得伤害。

给同一体系维持必要的形状与运动语汇，但本招选择自己的决定性画面。可用弧面包覆、折面错位、树状接通、空腔收窄、颗粒结成结构、薄层剥离、边界迁移、多个物体改变关系等，不逐招堆全套。辨识点可以来自受作用区和退出：同样水体的导流、附着润湿、冻结成支撑或遮蔽视线，比统一蓝球爆炸有更具体的视觉差异。

动势也有区别：瞬时接通、迟滞跟随、逐段成形、持续压缩、周期收放、自主搜寻、先静后动与突然失活。平静的被动可以在触发处突变，强烈的主动可以在远端无声生效；不默认每招呼吸灯、缓慢膨胀与爆炸。形体变动必须在合适中段可辨，起幅/落幅漂亮不能替代关键变化。

## 按机制选择证据与拍法

下表是原创导演选择，非参考影片的实测机位，不要求逐项调用。

| 本次机制 | 优先让观众读什么 | 可用机位/运动与真实交接 | 常见失效 |
|---|---|---|---|
| 微小附着/精确作用 | 源端接触、附着部位、具体材料/状态差别 | 斜侧近景容纳手/器物与接收部位；必要小幅横移打开遮挡；读清后接下一行动 | 手特写看不见对象，放大全特效仍看不出哪里改变 |
| 触发被动 | 已存在的状态、触发事件、自动响应 | 关系景让来袭进入触发面，局部变化与本体动作同框；不要切到一段不存在的结印 | 每次受击重新施法；只有泛光而无条件/后果 |
| 主动开启的强化 | 开启前后同一部位/行动能力与持续状态 | 随人物回护或攻入观察材料/姿态变化，主镜沿真实行动移动；解除时看状态变化 | 把常驻纹光当再施放；靠变脸换身份表示增强 |
| 离体弹体/锋面 | 源与目标方向、入距、作用/落空后的去处 | 斜侧路径景、目标附近观察或前景通过；在途交目标端，接触后接受力 | 一直贴弹头等速飞，看不见目标距离 |
| 持续束流/操控 | 控制端是否持续、路/面、接收端负载与转向 | 双人斜侧或含源/目标地标的关系景；沿交界变化横移/摇摄，不自动绕360度 | 只拍掌心，切镜后源头松手仍在供能 |
| 预置/延迟效果 | 节点地点、待命状态、后来什么触发它 | 前镜建立点位，后镜以同一地标接回；固定观察让触发者进入，启动后接结果 | 布置立刻爆；新角度换掉节点与触发者 |
| 标记与联动 | 附着对象、标记状态、后招怎样利用它 | 接触时建立可辨部位；后镜用相同部位/轮廓接续，对焦/局部取景只在能读变化时用 | 图案一出现就口头宣布引爆/定位，后招无读取条件 |
| 召唤与自主代理 | 归属、出现位置、指令与代理自己的任务 | 本体与代理共享参照，按任务交代理端或持续关系景；归返/失活承接真实状态 | 召唤像贴背景海报；代理每镜重新诞生 |
| 感知/隐匿/幻术 | 受影响者判断与真实情况的差别 | 按授权切主观/外部观察，以地标/相同行动相位承接；揭示镜给出可确认差别 | 随意蒙灰滤镜或镜头乱抖就称中幻术 |
| 恢复/净化/辅助 | 损伤/异常的原状态与被改变部分 | 近处读恢复前沿或状态解除，关系景接被帮助者的新行动；小效也可用全身景 | 绿色光一闪就宣布全恢复；辅助变成另一次爆炸攻击 |
| 区域/规则改变 | 边界和边界内外怎样不同，人物正在利用/受限 | 固定边界关系、俯斜布局或随越界者移动；保留已变/未变区，读规则而非只看圆阵 | 转动纹样但通路/行动没变化，瞬间换成新场景 |
| 大范围/巨型作用 | 局部体量侵入、作用区和传播/同步方式、人物后果 | 靠人物读局部与出口，再按信息收益扩大范围，或先广景预示再近处承受 | 整把巨剑缩在天空，人物如无关剪影；全部建筑乱序炸 |

幻术或图形空间需要跨主观/外部观察时，按[感知与图形空间攻防](perception-and-graphic-space.md#从误判接出真实动作)接出错误判断、真实线路和接收结果；只设计观看就继承机制，不因色框/旋转新增传送、互击或伤害。

## 参考技能句的精准转译

全面学原文的技能施放与分镜时，读[参考写法与精准成稿](reference-prompt-writing.md)，判断原句约束本体操作、源/目标方位、形成、离体/持续控制、侵入与接收结果中的哪项。伞转天空与能量聚伞心是操作/归源；裂界深处局部显露是来源/纵深；下压风压是逼近前兆；接触后破裂是负载与结果。保留这些不同用途，不合并成“释放大招”。

摄影读出本次决定性相位，控制手、本体支撑和作用体各继承状态，对手在形成期仍有任务。`fx-env：`细化同次主变化与环境，不重复施放；`sound：`对接相位声源；`transition：`在真实切镜承接同一作用，不重播启动。当前没有的神器、裂界或法相只可在授权原创中另建，不能凭参考补到锁定能力。

## 小型技能不靠放大成大招证明重要

把画面注意给决定性差别：短暂接触使甲片失活、局部印痕使后续一击改变目标、被动边界让一道攻击滑开。小面积可以有很强结果，也可以几乎无实体特效；通过对象状态和人物选择让观众理解。近景不是必选，小技能改变整个人的走位时全身关系景更有用。必要细节与全身动作可以相邻覆盖，但不重演接触。

例如已定机制为“触物留下只影响握持稳定的印”：用斜侧近景同时见手背与柄，触点留下失活痕；后镜仍是同一握持，柄开始滑动、对手改用另一握法。摄影跟的是新握持任务，不继续停在发光小印上。不能因此增设麻痹全身或武器必定飞走。

指定领域、替身、大型召唤、巨型星体或荷花时，按[角色战法与施法协同](character-led-spell-combat.md)落实实际规则/任务、显形结构、控制与本体后续行动，再用本页拍法。背景星球、花形光团或纹样铺地不自动证明已兑现这类技能。

## 大型技能有多种场面结构

不要把所有大招设计成天空巨物落下。按本次允许机制选择：

- **局部侵占到全貌**：人物附近出现超出屋檐的局部边界，主形跨过地标；扩大范围读同一次作用的全貌。适合巨大形体，但局部占幅不能伪造真实体型。
- **从点到面传播**：近点改变后，作用前沿经过第二地标再扩到远区；相机随前沿的注意转移或切到下一接收端，保持人物与起点归属。全域同时起效的领域按其规则读内外差别，不虚构传播等待。
- **多源网络/阵群**：节点在已有空间逐步接通，分别限制/保护不同区域；先读本次必要节点和可用通路，再以整体关系说明覆盖，不要求拍清每颗亮点。
- **环境作为有效作用体**：建筑层级、地面方向、水体或空间通路改变，使人物调整支撑/路线；取景保留稳定参照区，看变化侵入。景观展示可看形变，战斗需承接当前任务，不默认全场毁灭。
- **巨型代理/群体介入**：显形或入场与实际执行任务区分，体量、归属、指令/自主和结果连贯。军阵/召唤群体不是全部同时摆同一姿态。
- **远端主宰/规则覆盖**：没有巨体也可改变一片空间内的行动条件；广景看内外差别，人物端看承受或利用。强度不必靠无限放大光团。

多种结构可以相容组合，不每次全用。高潮也可由极小的条件变化解除大领域；既定结果不为规模比赛改写。清楚的强效果可以满幅，重要边界/接触/人物出口在需要时可读，不默认稀释规模。

## 大招与震撼的尺度门槛

用户要震撼时，先从本场机制选择明显区别于普攻的主峰；所需大范围用已知人物/结构/区域作尺度，读清跨越、侵入或规则覆盖的过程。参照可同框，也可由稳定地标连续接力，不强制每招完整巨体与小人物同框。

观察实际主变化、抵抗/应对和人物新条件；宏观介质响应与后续残留接同一次作用。精密高能、无形规则与无破坏要求可以用局部负载、边界内外或控制关系显出强度，不强制毁船、蚀月和生成新道具。瞬发无须慢起势，不给所有技能套起势/显形/作用/反制/破口/余波六拍。

明确要求冲击帧时设计特殊形体、力向与进出；其他媒介可用形变、制动和传播承担主峰重音，不统一负片/白闪。若只在人物附近转光环却未兑现所需规模和作用，回主事件修，不靠更多粒子、米数或“大招”称呼通过。

## 运镜跟随变化的关系

相机相对控制端、作用体和接收端分别选位置与主要路径。能力展示与控场按[观看接力](ability-led-combat-direction.md#控制端作用端与接收端)选本拍运动强度；可先看环境响应再补微小控制，也可从目标端等待攻击进入，不强制手部先行。动机可以是显露主形、让观众承受逼近、越过边界、交接控制/结果，也可以是纯材质与空间体验；不要求每次追着粒子飞。

用“相机在哪里 → 起幅看谁与什么 → 主体相对相机怎样移动 → 中段谁被显露/遮住/逼近 → 读到什么时落幅或切”编写真正必要部分。控制端近景需要后镜接远端结果；目标端承受需要前后交代来向；大范围拉远需要接住当前人物状态。环绕只有在打开重叠、显示某一面/部位或完成观看关系变化时使用，不为让相机绕完而让施法者站着等。

固定镜头可让作用前沿、人物和边界进入画面，转焦可交接不同深度的状态，一镜到底可按相同事件改变取景；锁定一镜到底不暗插切镜，锁定固定取景不暗改机位。未锁定覆盖方式时，导演可按观看任务主动选择特写和真实切镜。竖屏按高低/纵深组织因果，多路法术不用横向等距排满后被裁掉。

## 切点、节奏与模板

以当前信息变化选切点：决定已经成立、在途开始威胁目标、触发条件刚满足、接触变化可辨、控制被打断、旧状态解除或新空间可用。实际新技能才建立新事件，同一次状态保持/自动响应跨镜不重启。形成、释放、运行、生效的占时来自当前动作与读取目标，瞬发不补长仪式，小技不被大招展示挤成看不清一闪，仪式仍可慢。

沿用An分栏时，共享规则放全局；头部给观看职责/位置/主路径，画面给当前状态，S给发动与应对，fx-env细化同一次作用的主形、接收变化及残留，sound只对允许事件，transition承接真实相位。其他已选格式表达同样的事件，不把本页表格逐项粘入正文。效果的形状与动作应互相连到对象，不能另列效果词库让读者自行拼接。

## 适用复核

去掉招名/颜色，能否辨认本次的触发、有效作用与状态？施法手/身体/器物的任务和效果控制是否相容？被动是否无因加了主动动作，主动持续是否每镜重开？交互后双方剩余状态是否真的影响下一步？小技细节和大技范围是否各有需要时的证据？观看路线是否提供变化，而非用抖动、白闪和大声覆盖？

文本仅验设计，静帧仅验采样构图。真实输出先正常速度静音看识别、触发与结果，再按声音范围看声画，定向查关键窗口；无法确认的机制不编成观察事实，重复失败无新证据时改变控制方法。案例见[多样技能片段](ability-diversity-lab.md)，资料与观察范围见[研究记录](ability-research-20261008.md)。

## 能力的观察证据与当前设计

关键技能在必要时读施放者当前位置、可用肢体、载体、形成变化、离体方向、接收端和残留；阶段可合并，不要求每次完整仪式。入场漂浮可为已激活状态，不强加未见起动手诀；腕前载体有光不证明独立命中，交接光不证明数值增幅。源片观察不足处保留未知，新稿则在获准创意内明确自己的规则。源例与迁移见[执行方法](narrative-combat-transfer.md)。

## 法术、施者与对手的观察关系

关键施法/识破、压力与目标反制按[信息覆盖](../../action-camera-direction/references/information-led-coverage.md)选手/脸/作用体/接收端与范围的顺序。看施者时目标继续，切对手时法术发展；回到整体继承当前阶段，反应不能无接收证据。无需每法全套覆盖或每段硬切。
