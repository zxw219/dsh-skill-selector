# 奇幻快战：从招式到成稿的执行路径

用于奇幻高速战斗创作，以及“固定镜头多、相机太慢、近战只剩左右拳、没有冲力、技能慢、大场面与冲击镜头缺失”的返工。本页是[通用镜头语言](../../cinematic-camera-design/references/movement-composition-effects.md)中的快战应用，摄影执行[快战统一边界](../../cinematic-camera-design/references/camera-execution.md#战斗中的速度力量与摄影压力)：快速果断移动优先，尺度、接触和传播本身不自动构成固定理由；明确艺术化保持、慢打或锁定固定仍成立。只优化工作流时修改实际来源并演练，不代替用户启动媒体生成。

本页服务已采用的奇幻快战；当前是能力展示、控制博弈或压制时先按[能力作战](ability-led-combat-direction.md)选本段节奏，不以含法术/巨物直接触发本页。明确高速/高频仍按原要求，同场可分段进入。

## 先核当前观看体验和模块

高频、高速与高燃分别按[战斗体验设计](combat-experience-design.md)落实有效接力、爆发改距/过点与人物选择的兑现。场地由本场战法与机会决定，巨型技能区分投射/显化/代理及反制后发展，冲击帧有特殊形体；不要继续复用发射—偏转—追击模板再叠技法。确有剑修用[25式转译](../../combat-action-design/references/cultivator-sword-techniques.md)补当前交锋功能，无剑角色保留原机制。

## 先把五项要求编成实际事件

这五项是战法、普攻/截击、动态摄影、冲击与大场面，距离不另立一项而由战法与摄影共同承担——先按[距离账](continuous-fight-gate.md#距离账)画出距离线，再编这五项。

### 1. 角色战法决定高速交锋怎样成立

明确手脚并用时按[全身与能力协同](full-body-ability-integration.md)先采用相容混合战法：手法改变上路/控制端，腿技改变距离、下盘或守势，术法利用同次接触/落脚/旧状态；腿脚不只负责跑动。纯法师是用户事实还是助手补设要先分清，后者不能否决本轮要求。技能作用与发动也要有本次需要的差别，不能全部掌前放电或把电流换到脚底充数。锁定纯远程仍保持。

先按[角色战法与施法协同](character-led-spell-combat.md)确定主战距离、能力和身体语言，再编相互制约的事件。高速可以是远程短诀、离体术法连袭、领域改路、召唤截击与本体换位，不默认法师贴身拳肘腿，也不为套格挡链加盾、剑、护臂或晶甲。

确属近战时，进入、攻击端/高度、拆解、身法与收势产生实质差别；短截→肘撞→避低扫→侧踹等只作为适配徒手战法的关系，不是每类角色开场。施术者则可改位划印→翻腕分路→断诀释放→代理截击→本体布阵续法；施法动作改变具体术式，身体与法术共享时间，不能只列手诀名。混合转换由上一结果与角色能力提供窗口。

飞身、贴地掠行、空中换位和爆发冲刺按既定幻想机制采用；法师也可沉稳控场、御空或借召唤通路，不强制翻滚和腿击。需要的来源、实际作用、对手应对与出口仍成立；专属施法的身体开合、领随与收势同样承担动作美感。

### 2. 普攻和截击短促释放，大招才展开有价值的形成

战斗小技能默认与换步、卸力、武器回带或追入同拍发动：短诀收合即出，脱离后按机制继续，本体立即接下一任务。正文明确源点、主形、去向、交会与结果，不给每招分配几秒举手聚球。已锁定的长蓄力机制仍保留。

大招允许较长成形，但每段时间必须带来尺度/区域或战局的增长：地脉牵动建筑 → 主形越过树冠/残塔 → 可用通路收窄 → 主体压进人物所在空间。期间对手利用窗口突入、破节点或避险。成形后实际下压、横贯或坠击须果断加速；巨大不等于全程慢动作。

### 3. 按观看收益组织动态摄影与特殊固定

先编攻防，再按通用镜头语言选择构图与拍法。快战以快速追进/退移、贴地掠行、甩摇、外侧弧移与范围退拉为主，给起幅、通路、触发/相对速度和落幅；这些职责是追压、逼近、注意交接、打开遮挡或展开后果，不只列摄影名。

每簇内按[切镜差异门槛](../../cinematic-camera-design/references/camera-execution.md#切镜之间的相机关系差异门槛)核切点是否交付新的注意、作用或节律。只换侧面却无观看收益时，主动比较距离/占幅、观察侧/高度、注意对象和运动质地，采用有收益的差异；眼线回应、同构回返与冲击切按实际目的成立，不按变化项数判错。爪战另按[爪端跟随](../../cinematic-camera-design/references/camera-execution.md#动作点跟随与广角特写)把操作分给不同相机任务：勾跟回带方向、刺跟末端制动、撕把分离点与爪端装进同框、压保持承压面可读、扯跟被抓的一侧。

巨型压顶、决定性接触与范围破坏仍优先用相容的快速退移、局部随动、退升或同次切接读取，不自动转成固定展示。快速跟随可在首触短促制动，随受力或下一威胁接出；真正固定段限于本次明确艺术化、表演或锁定拍法等条件，给持续作用与出口。可按[复合路径](../../cinematic-camera-design/references/composite-camera-paths.md)从局部接范围，不预设“疾跟后必固定、范围再固定”的镜序。

一镜到底可以移动，稳定跟拍也在移动；相机加速/制动与主体速度分别成立。短促硬停可强调撞击惯性，持续震屏不能代替承力。普通交锋不退成无任务固定平列，也不因为“避免固定”让镜头全程乱甩；动作不等待相机，切镜不重发一次攻击。明确全片禁固定的项目按其禁令设计。

### 4. 冲击镜头绑定实际来力与持续结果

选本场真正改变防线/支撑/通路的重音，而不是每击震屏。近距广角让攻击端从纵深逼入画面；接触处读到挡臂被压回、躯干折偏、脚下被推走、材料挤裂或支撑断开。可在这次峰值短促压缩轮廓/曝光，再沿同一力向接倒退、飞出、撞障碍、落地接重与追击。与轻拨、卸力形成强弱对比。

强弱不是每拳都倒飞；技能也不必须让施术者物理后坐。删除音效、震屏和闪白后，关键重击仍有进入速度、决定性接触与受力后果。需要冲击造型才按专项深化，不因“没有调用冲击skill”就遗漏冲击摄影。

### 5. 大场面真的改变战场

明确要求大场面时，先设计承担主峰的区域事件再编镜头：选真实主形、人物/树冠/建筑参照、占据的空间、逼近方向、反制节点、传播与持续后果。按角色可选领域改变区域规则、巨大召唤实际截击、巨型荷花开合/莲心释放或星体从明确星海入口侵入；来源、主形、控制与人物端后果相连。枝冠承重破坏只是混合战法的一种选择，不以树枝和巨刃替代用户要求的领域/召唤。

只把光球放大、增加“百米”、在人物身后炸一下、末镜拉远看废墟，都不构成主峰。前面铺出通路/结构，主要作用侵入正在交锋的区域；特写和范围景接同一事件。昂贵的慢成形必须换来这样的场面收益，不能只得到原地伸掌。

## 实际成稿顺序

当前快战按[小数秒动作编排](subsecond-action-timing.md)以0.1秒精度落实相位：短促发动/加速、在途与敌方应对、决定性接触、受力和后续任务共用全片时间。同镜可有多个锚点，摄影不因细化时间而拆成每0.1秒一镜；不能用缩时间码替代路径/传力，持续形成与主峰按本次作用保留。

1. 写入口及双方战法/技能机制，确定重要招式、反扑、释放和主峰的出口。
2. 直接在S段编出相连动作，必要承重/脱开明确；先删掉原稿无作用的摆姿与停等，补实质招式，不先套六个长镜。编招与复查时按[攻击端差异门槛](../../combat-action-design/references/action-module-bank.md#多样化攻击模组攻击端差异门槛)逐簇核相邻攻击端、轨迹、高度与防守型；爪战角色另按[爪与指刃的换端路径](../../combat-action-design/references/action-module-bank.md#爪与指刃的换端路径)核勾、撕、刺、扯、压是否用足。快战高密度同样执行。
3. 用实际相机路径与速度组织真实镜头，指定接触和主峰的观看点；同镜允许连续多招，切镜承接在途/受力而不重复起手。
4. fx-env：补同次效果、局部受光与材料/环境后果；sound：接实际声源；transition：只接真实镜头/结尾。四层全局视觉、身份与残留照常保留。
5. 对成稿执行下面的验收；发现失效项回改当前事件和后续承接，不能只在末尾添加禁止词。

## 成稿不能放行的情况

| 检查实际正文 | 返工位置 |
|---|---|
| 固定没有特殊观看作用，或普通过程被无作用慢移覆盖；明确全片禁固定却采用 | 回改观看、路径/保持、速度和切点；有用的特殊固定按画内变化与出口验收，不按关键词计数 |
| 战法与角色错配，或去掉招名仍是同一出手—挡住—复位循环 | 先修类型/距离/能力；近战改有效动作，施术改专属发动、控制、协作与续法，不强加肉搏 |
| 隐藏招名与颜色后，相邻攻击仍是同一攻击端同一轨迹，成片只剩挥臂 | 回选用层过[攻击端差异门槛](../../combat-action-design/references/action-module-bank.md#多样化攻击模组攻击端差异门槛)：换攻击端/轨迹/高度与对手应对；正文有差异而成片同质时按观察/执行层分别归因，不追加形容词 |
| 相邻镜只换机位侧面，距离、注意对象与运动质地照旧；或每镜构图关系相同 | 过[切镜差异门槛](../../cinematic-camera-design/references/camera-execution.md#切镜之间的相机关系差异门槛)与[构图关系](../../cinematic-camera-design/references/composition-staging.md#观看段落之间的构图发展)换注意对象、距离或空处归属；一镜到底与锁定固定段按其段内发展核 |
| 打斗中人物只有皱眉、张嘴、怒吼，受击后没有判断与继续作战的取舍 | 回[人物表演导演](../../performance-scene-director/entry-guide.md)：按刺激→接收→策略→身体编在当前任务与负荷里，手不停下来等表情 |
| 去掉震屏、音效和装饰光后，重击没有实际承力或改变 | 补来力、有效接触、支撑/躯干/材质变化和受力后的续攻 |
| 施法只伸掌摆姿，释放后本体或代理无任务 | 让手势/身体实际改变术式；离体、持续场与代理分别运行，本体接相容移位/控制/续法 |
| 声称大招但主形、尺度参照、侵入、反制和破坏传播均未落实 | 重新设计主峰的区域事件和相称摄影，普通局部光效不能充数 |
| 全局、角色表很丰富，S段和镜头仍没有这些过程 | 将已采用设计编进具体相位与观看；内部表不算执行 |

这些是当前请求的语义验收，不是靠关键词计数的自动速度检测，也不是给文戏/明确固定演武套禁令。参考[30秒完整演练](../assets/cases/fantasy-fast-combat-30s.txt)学习因果和拍法，不照搬角色、能力、秒数与镜数——它的两人定距轮流放术是弱点，距离另按[距离账](continuous-fight-gate.md#距离账)编。文本与语义演练不等于成片生成或真实速度验收。

## 高频与读取共享时间

按[高频与规模写法](high-frequency-scale-writing.md)让短动作发动、在途作用、身体/控制后续任务和敌方压力接力，频率在实际战局中变化；插入脸/手/敌方反应时按[信息覆盖](../../action-camera-direction/references/information-led-coverage.md)继承画外推进，不重复起手。重要形成/负载可留，不能以快切、秒数或零停顿替代速度与机制。
