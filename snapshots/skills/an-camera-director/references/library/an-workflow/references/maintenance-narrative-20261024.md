# 剧情编译维护记录｜2026-10-24

对象：已安装的 `an-workflow` 来源及其派生功能包。用户要求制定学习计划并优化工作流；本轮不改用户作品、不生成视频。学习单元与材料范围见[学习计划](narrative-learning-plan-20261024.md)。

## 基线与最早失效

本轮没有收到对应失败剧本/成片，以下依据是安装来源的结构和具体口径，不声称已还原用户那次成片故障。

| 源头证据 | 问题与实际修订 |
|---|---|
| 入口在通用出稿路径前先给“打斗/动作提示词”八条硬线，剧情路由位于长表后部 | 在实战默认之前增加已有剧本/剧情分流；叙事行动和混合剧情不套整段实战配额 |
| 文戏、场景、整段分镜和空间已有分散规则，没有贯穿原剧本覆盖/否定事实/场次/知情的转换入口 | 新增[剧本转剧情提示词](script-to-screen.md)，将原文→因果与知情→调度→观看→估时→反证串在同一事件上 |
| 入口“时长由事件与念白相加”、整段分镜“总长等于两者之和”，与容量规则的并行只计一次相矛盾 | 新增[剧情时长](narrative-timing.md)，修改两处简单求和并接入容量、终检与声音/时间功能 |
| 空房间、静物等被按类型判删 | 改为核承重信息、期待或已锁审美作用；无作用拖尾仍删，原文承重的无人证据保留 |
| 空间入口主要列战斗运动，生活调度的触发弱 | 在[空间参考](spatial-continuity.md#剧情场景的调度与可见性)前部接入通路、门、持物/支撑、眼线、知情和画外人 |
| 使用卡、手册仍写战斗默认An分栏 | 同步当前的剧情分栏/连续实战事件流分支，保留用户格式优先 |

这些修改改变前置路由和实际设计方法；没有整包替换战斗、舞蹈或摄影专项。7个功能映射分别在场景、构图、相机、声音/时间、连续性、编译、质量职责内接入，未给局部模块重新导演权限。

### 保留的风险与结论边界

独立审阅标出4处待实测时长风险，旧/新版各2处：新版A的17.5–25秒需完成看伞、接近、开伞、共伞并离场；旧版A的8–14秒需完成转向、取伞、走至门口并开门；旧版B的27–30秒需放碗、拉椅、落座；新版B的20–28秒涵盖去北端取碗再返身落座。它们受实际距离、椅位和动作节奏影响，目前不是已确认错误，也不能靠更小时间码或作者想象宣布已经可行。

本轮证明了剧情分流可达、方法确已进入新的独立文本，以及来源/功能包可以一致发布；没有证明新版总体优于旧版，没有复现用户未提供的失败稿，也没有验证真实生成服从性与美感。后续媒体任务优先对这些受距离/串行动作影响的段落实测，再改瓶颈；不以增禁令、强定镜数或虚构语速把未知项刷成通过。

交付目标仍是已安装来源、`D:\An工作流` 和相邻总ZIP；单功能ZIP由相同来源映射重建。工作目录的最终发布核验将对实际来源、分发和总ZIP逐项核SHA-256/CRC，不能仅凭脚本返回 `updated` 宣布一致。

普通创作只读取方法文件，维护追溯时才读取本记录、学习计划和原始验证产物。
