# 表演方法与迁移边界

核对日期：2026-10-03。以下是已阅读的公开一手资料及本次编译取舍，不代表完成戏剧学院课程、FACS认证或真人训练。

| 来源 | 资料要点 | 本技能的迁移 |
|---|---|---|
| [RADA表演课程](https://www.rada.ac.uk/courses/ba-hons-acting/) | 将表演、声音、动作、文本分析和影像实践纳入综合训练 | 从独立情绪画像升级为意图、身体、声音共用一个方案；这是提示词设计取舍，不复刻课程 |
| [RSC演员声音指导](https://www.rsc.org.uk/about-us/how-we-make-theatre/voice) | 通过声音和节奏理解文本，并联结身体、声音与人物 | 先确定台词行动，再处理气息、重音、节奏和身体任务；不用吼声统一代理情绪 |
| [RSC演员问答](https://www.rsc.org.uk/learn/young-people/homework-help) | 演员讨论音高、咬字、节奏、重音、音量和呼吸的表达作用 | 将声音维度分开选择；保持原词，按意群和实际回应改变表达。页面搜索抓取可读，直接打开曾超时 |
| [Paul Ekman Group：FACS](https://www.paulekman.com/facial-action-coding-system/) | FACS把可见面部运动分解为动作单元，专业编码须训练与认证 | 描述局部外观变化与组合，不把动作名称当情绪定论，不编造编码或认证；细微变化不作为测谎依据 |

流泪、鼻涕、疼痛反应、疤痕和皱纹部分是本次虚构表演与连续性设计规则，不从上述资料推导医学结论；泪液过程、负重、口型和状态继承采用可见因果检查。未核对特定疾病、演员或特定视频模型的成功率，也未承诺模型能执行精确毫秒微表情。
