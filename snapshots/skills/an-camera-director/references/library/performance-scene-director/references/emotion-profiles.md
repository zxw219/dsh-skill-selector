# Emotion Profiles

本文件提供怒、哭、哀、喜、乐五类基础画像。画像用于帮助选择行为机制，不是固定表演配方；强度、动作幅度和镜头节奏应服从用户指定的克制写实、商业短剧或动画夸张模式。

下面的子类型、递进和镜头均为候选示例，不是情绪必经步骤；实际节点、身体和声线由主入口的表演锁决定。摄影由总导演选择，不能从本表机械映射。

## 怒戏 Anger

核心：怒的表达由争取、抗议、威胁或失控等本场行动决定。低声控制、公开高声控诉、爆发和沉默都可成立，不把声音降低当更危险或更高级的定律。

子类型：

| 类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 沉默冷怒 | 被激怒但拒绝表达 | 不说话、视线不移开 |
| 礼貌冷怒 | 用礼貌包装攻击性 | 微笑但眼神冷 |
| 蓄势冷怒 | 知道自己会赢 | 低声、等待、压迫感 |
| 嘶吼暴怒 | 完全失控 | 声音破裂、身体前倾 |
| 砸物泄怒 | 转移无法解决的压力 | 仅在剧情允许时使用既有物件；抓握、动作与后果相连，可犹豫或直接释放 |
| 攻击性怒 | 怒到要伤害关系或对方 | 缩短距离、侵入空间 |
| 控诉之怒 | 替自己或他人讨说法 | 让核心诉求清楚，可含泪、前进或退开，服从关系压力 |
| 含泪之怒 | 委屈和愤怒混合 | 泪是副产品 |
| 绝望之怒 | 怒里有疲惫 | 怒到无力、哑火 |

递进：平静 -> 刺激 -> 压制 -> 临界 -> 释放/冷却。

镜头：克制写实模式可用中近景保持压迫，在临界点推近眼睛和下颌；商业短剧或动画模式可以更早显示冲突，但仍要交代触发原因。

## 哭戏 Crying

核心：哭泣可直接释放，也可试图控制；不能把忍泪当唯一好演法。区分哭的原因、正在完成的任务与液体/气息过程，细节见[身体状态](embodied-states.md)。

子类型：

| 类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 无声落泪 | 极度隐忍 | 一滴泪，脸几乎不动 |
| 强撑微笑 | 不想让人担心 | 嘴角上扬但眼眶红 |
| 背身哭泣 | 自尊/骄傲 | 肩膀微颤 |
| 崩溃嚎啕 | 情绪决堤 | 全身参与，声音失控 |
| 愤怒含泪 | 不甘/屈辱 | 眼泪不是悲伤，是怒的副产品 |
| 突然崩塌 | 长期压抑爆发 | 前一秒正常，后一秒失控 |
| 被理解之泪 | 终于被看见 | 先愣住，再红眼 |
| 重逢之泪 | 失而复得 | 不敢相信、确认真实 |
| 释然之泪 | 放下执念 | 表情逐渐松开 |
| 笑中带泪 | 复杂交织 | 笑和哭无缝切换 |

递进：日常 -> 触动 -> 压抑 -> 临界 -> 释放。

镜头：给呼吸、吞咽、眼眶和手部足够时间；不要让眼泪成为唯一信息。

## 哀戏 Sorrow

核心：失落可从空缺、任务失去对象或关系断裂表现，也可直接流泪或持续行动。根据事件选择，不把“空”当统一神情。

子类型：

| 类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 怀旧之哀 | 回不去的过去 | 短暂恍惚 |
| 故人之哀 | 想念不在的人 | 抚摸物件、闻、静止 |
| 时光之哀 | 意识到流逝 | 看远方、长叹 |
| 独处之哀 | 一个人的安静 | 重复性小动作 |
| 人群中的孤独 | 周围有人但更孤独 | 笑容假但不刻意 |
| 失语之哀 | 说不出口 | 张嘴又合上 |
| 知而不说 | 替对方承担 | 强撑微笑 |
| 默默告别 | 不打扰的离开 | 多看一眼、转身 |
| 物是人非 | 同地不同人 | 抚摸旧物、长停顿 |

递进：日常 -> 裂痕 -> 沉浸 -> 消化 -> 留白。

镜头：克制写实模式可用远景、背影、空房间、物件和长停顿维持低强度长尾；商业短剧或动画模式允许更高强度，只要仍保留失去之后的空与余韵。

## 喜戏 Joy

核心：喜悦可以即刻笑、行动、落泪或先确认。用获得了什么、想分享给谁决定表达，不强制先愣住或眼睛发亮。

子类型：

| 类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 不敢相信的喜 | 好到不真实 | 反复确认、颤抖 |
| 久旱逢甘的喜 | 等太久终于来了 | 先哭后笑 |
| 反转之喜 | 危机解除 | 表情凝固到松弛 |
| 团聚之喜 | 在一起就是幸福 | 群像眼神交汇 |
| 童真之喜 | 简单纯粹 | 全身参与 |
| 偷偷的喜 | 不想被看见 | 嘴角压不住 |
| 胜利狂喜 | 终于成功 | 全身释放 |
| 释怀之喜 | 卸下重担 | 长舒一口气 |
| 顿悟之喜 | 突然想通 | 静默微笑 |

递进：平静 -> 信号 -> 犹疑 -> 相信 -> 释放。

镜头：先留出确认时间，再给眼睛变亮和身体松开的瞬间。

## 乐戏 Delight

核心：玩乐由共同任务、回应和节奏体现，可以有笑声，也可以故作严肃。喜与乐的划分仅帮助选材，不构成固定情绪强度。

子类型：

| 类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 童趣嬉闹 | 孩童式纯粹 | 全身参与、即兴反应 |
| 友群打闹 | 朋友间玩耍 | 体力消耗、节奏快速 |
| 恶作剧 | 设套捉弄人 | 偷瞄、憋笑 |
| 斗嘴互怼 | 语言玩乐 | 你来我往 |
| 暗语调情 | 含蓄的乐 | 眼神、嘴角、语调 |
| 装傻自嘲 | 自我打趣 | 真接受、不在意 |
| 集体舞动 | 一起动起来 | 群体能量交换 |
| 共享美食 | 围桌子的乐 | 抢夺、笑声、食物 |
| 闹剧失控 | 局面失控 | 节奏加速、连锁反应 |

递进：铺垫 -> 点燃 -> 升级 -> 失控 -> 收束。

镜头：中景/群像优先，允许身体移动和关系互相传染。不要用假笑堆满画面。
