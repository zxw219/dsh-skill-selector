# 接触与器物任务中的人物响应

用于互动接触无反馈、脸与身体各演各的、拿取器物跳变，以及人物近景只有统一笑脸。继承身份、年龄基线、媒介、剧情、声音和动作，不把接触一概解释成亲密、疼痛或同意，也不把普通小任务强改成战斗。

## 接触有位置，反应接当前任务

分清接触者的进入方向/手指、被触部位、压力或牵引、局部结果及双方下一步。局部形变先服从接触位置和当前材质：推颊改变那一侧颊肉和嘴形，拉衣料改变受拉褶皱，碰金属甲不会把它压成软皮肤。人物可以闭眼、移目、缩颈、停下原任务、维持注视或随后回应，按当前剧情和参考选择；不自动串笑、惊、怒三种脸。

接触变化与表情可以重叠，不固定延迟秒数；自然反射可以先发生。触点松开后继承回弹、解除占用与仍存的身体状态，不能只一切脸就回到初始形体。夸张表情可成立，身份结构与刺激仍一致。V04约6.0–10.8秒的可见启发是同一触点的颊部压缩、嘴形改变和目光响应，不据此推断心理或年龄。

手进入前景可以建立参与者，但手数量、来源、接触侧及忙闲状态保持；当前帧出现一个外来手不默认多出完整可行动人物。表演只请求必要读取缺口，摄影职责由原导演决定。

## 小任务也有可接续的事件

拿取、吃、喝、观察和回应可组成有表情的连续任务：目光找到当前物件，空闲手进入，物件进入持有/接触状态，嘴部或另一只手响应，随后继续或改任务。并非每个拿取都要拍五步；决定连续性或笑点的相位须在正文/相邻观察中有依据。

端杯时两手忙，释放一手后才用它遮嘴/指物；食物在手、口或盘中的状态分开，指尖触到碎屑不自动等于拿走整颗。近景裁掉杯不表示杯消失，返回仍接同一持有关系。可见省略与剧情时间跳跃按剪辑意图判，不把每次食物数量变化都判为瞬移。

V06约6.5–7.5秒拿起一颗、9.8–12.2秒口部状态与指向并行，17.5–19.8秒双手持杯后单手遮嘴，20.5–22.0秒指尖接触桌面再到嘴边，支持任务、手中资源和视线共同组织。不能由采样间隙断言完整吞咽、杯中液面或全片食物数量无错。

## 可读性与合法保持

面部局部、接触手和器物口沿要有足够占幅/清晰度；需要读压缩不能让前景手完全遮住触点，需要读物件状态不能只给脸。凝视、品尝、接收和克制表面可有作用地保持，不套快战零停顿要求。战斗接触只迁移适用的受力/身体响应和资源关系，不把挤脸、饮食或角色造型复制进去。
