# 表演演练与反例

供维护、比较演法或诊断时读取，不逐次附在成品里。以下为修改者文本演练，检验规则能否写成连贯行为；不等于演员试听、独立盲测或实际成片。

| 条件与常见坏写法 | 改写的表演证据 | 核对与相邻反例 |
|---|---|---|
| 对峙中仅写“愤怒地大吼”；锁词：你先坐下。 | 说话者站在桌侧，用原声线的较低音区与清晰咬字落在“坐下”，音量只够近处对方听清；对方未动时不无因再次提高音量 | “低沉”有音域/共鸣，“低声”有距离；远处呼救需大声，不能套低声 |
| 哭戏每镜刷新泪珠，鼻涕突然出现；人物已有旧疤 | 起态已有泪痕与鼻部湿润；新泪接续旧轨迹，空闲手擦过鼻下，袖口带湿；眉间原纹随收紧加深，右颊旧疤换镜仍在右颊 | 湿痕有来源、擦拭和残留；微量流泪不强制挂鼻涕 |
| 右肋伤者全身随机抖且同时奔跑、说长句 | 转身牵拉伤侧，躯干短促收紧带右肩轻抖，左手维持桌面支撑；暂停转身、换气后说原句 | 不受控反应先于意图；角色下一步重组支撑才是策略；不从颤抖诊断疾病 |
| 说话全程抿紧嘴、持续吸气还念台词 | 句前完成短换气，开口时下颌解除紧咬；只在既有意群交界处理气息，原词连续 | 口型与气息不互斥；无声固定镜头中不可偷偷补哽咽音 |
| 喜极而泣硬套“悲伤→崩溃” | 对方确实回来后，角色原本攥紧门把的手放开，让出门口；确认对方回应时才笑，已有眼泪仍沿脸滑下 | 泪是表达通道，目标是确认与接纳；允许初见就笑，不强制先发愣 |
| 突然疼痛要求“先理解、再决定、再抽搐” | 被触碰痛处立即局部回缩，随后认出帮助者，允许他继续扶稳 | 反射可以先于意识处理；不自动把回缩解释为拒绝亲近 |
| 二维动画远景堆毛孔、睑缘积泪、微鼻涕 | 用当前风格的姿态与表情落点保留行动，若细节是硬需求向导演回报此景别不可读 | 不能宣称远景已拍清微表情，也不能未经授权暗切特写 |
| 痛后下一镜恢复光洁干脸和全体力 | 起态承接湿痕、伤侧保护和声音力度，情绪缓和时身体状态仍保留；擦拭/休息后再发生相应改变 | 情绪恢复、气息恢复、伤痛减轻与液体消失分开，非同步复位 |

## 自主倾听与同词异演

同一句“你先坐下。”试演安抚、制止离开、怕惊醒旁人和痛中求助，见[台词参考](voice-dialogue.md)。比较时保持身份、原词与场景硬条件，再检查策略、可见行为和声音是否真的有区别；不能只换“温柔/愤怒”等标签。

倾听者可以不动。锁定对方应答需要被听清时，保持目光和任务控制，由随后明确回应建立理解；别为证明倾听强制每个词都抿嘴/皱眉/转头。

## 复核方法

按具体时段追踪：角色能否获得刺激；面部/支撑/手中任务是否相容；台词在当前身体状态下是否有可行说法；关键细节能否被当前画面读到；跨镜是否偷换湿痕、伤侧、疤痕或声线。发现冲突就修正文中的动作或状态，不用规则词命中数证明质量。

对白文本契约与时间轴检查只能证明这些文本属性；未经实际视频/声音生成，不给“演技通过”“语气自然”“微表情成功”的结论。
