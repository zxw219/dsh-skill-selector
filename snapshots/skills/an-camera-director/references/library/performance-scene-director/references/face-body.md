# 面部、身体与身份细节

用来精化本场需要读清的行为，不逐项塞满角色。先继承表演锁、姿态、媒介与景别。

## 微表情与眼神

微表情在创作中写为短促的局部变化，交代触发、控制/泄露和落点；不把它当读心或测谎依据，不硬指定未经素材验证的毫秒数。例如听到熟悉的称呼，下唇刚要张开又轻合，目光仍留在对方身上；不是“瞬间闪过悲伤、愤怒、恐惧三种微表情”。

视线有对象：先在物件、对方脸或出口的哪个位置，因什么改点。头转向与眼球方向分别描述；可以头不动而视线先移，也可维持注视。失焦、回避、眨眼不能单独证明角色撒谎、无情或某种病症。沉默倾听可以保持表面稳定，用随后明确回应体现理解。

## 局部变化与皮肤结果

以下是可选择的外观变化，不是情绪对应表；按角色脸型、年龄基线与当前动作调整。

| 区域 | 可见变化与连接 |
|---|---|
| 额头/眉间 | 眉头靠拢时既有眉间褶皱变深，放松后回到原基线；不凭空刻出固定老年纹 |
| 眼睑/眼周 | 睑缘收紧、短促眨眼、目光停点；眼周挤压可改变原有细纹，眼球不夸张鼓出 |
| 鼻/鼻唇区 | 鼻翼随实际气息轻动；皱鼻时局部折痕与上唇相关，不能把每次吸气写成整鼻变形 |
| 嘴/下颌 | 嘴角松开或被压住、下唇局部颤、咬紧后放开；说话时让位于口型，不同时长期紧闭双唇又完整念词 |
| 颊/颏 | 笑、抿嘴或努力控制哭泣时出现局部挤压/牵拉；不要自动每帧加酒窝和颏纹 |

可按参考精控某部位；普通提示词优先可见结果，FACS用于理解局部运动，不虚构AU编号或宣称已做专业编码。左右不对称要有参考或动作原因，不把不对称当“高级表演”必选项。

## 静态纹理、动态褶皱与事件变化

分开三类：身份的旧疤/旧纹/痣；肌肉动作暂时形成或加深的褶皱；有事件来源的泪、水、汗、灰和新损伤。

旧疤的位置、长度、形状与角色自身左右保持连续；可随皮肤形变和光照改变可见度，不换边、不突然伸长、渗血或愈合。疤痕不要求必须狰狞，不因人物难过自动添旧伤。面部皱纹随动作深化或松开，不把年龄变化当情绪转折。泪痕经过疤痕/纹理时保留底层结构，不用液体重塑五官。

保留参考中的皮肤质感，避免一边要求真实细纹，一边无条件磨皮。红眼、鼻尖变红、汗和鼻涕都是可选状态；用户指定时给出来源与可见窗口，没指定不自动全量加入。相机看不到的微纹理不能承担剧情关键证据。

## 身体是一项正在做的事

先锁支撑、身体朝向、负重、可用手脚和道具，再写动作变化：重心准备向哪侧移动、哪个接触维持、动作在哪里止住。例：想留住对方，向门侧迈步却给对方留出通路；想掩饰疼痛，依靠桌边起身而非突然挺直。

身体张力可以局部：肩颈防护但手继续工作，或躯干撑住而下唇泄露。不能把“全身僵硬”和无阻力的柔顺动作同时锁死。蜷缩、后退、伸手、握拳都有对象与终点，不因情绪名称每次采用同一姿势。

疼痛颤抖不破坏负重逻辑，支撑手不能同时擦脸；增加动作前先转移支撑。姿态、接触与动作速度产生气息影响，声音与身体联用[身体状态](embodied-states.md)及[台词](voice-dialogue.md)。

## 媒介与可读范围

被触部位、压力/牵引、材料结果和脸/身体反应要接当前任务；拿取、端杯与遮嘴按忙闲手和物件状态继续。具体接续见[接触与器物任务](contact-task-response.md)，不把所有接触判作亲密或疼痛，也不让安静品尝/凝视套快战无停顿要求。

真人/写实CG近景：局部皮肤、泪线、下唇与声画呼吸可细化。中景：肩颈、重心、手中任务与交流距离更承重。远景：姿态轮廓和关系路线，不要求读毛孔和泪膜。

2.5D和手绘动画使用该风格已有的纹理、表情落点和姿态幅度；可以风格化眼泪或夸张身体，但不把写实肌肉目录硬塞进去。漫画疤痕标记也须身份连续。镜头由导演决定；如果关键鼻涕/微表情不可读，回报具体缺口，在获准取景内解决，而非偷偷切特写。
