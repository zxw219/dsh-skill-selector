# 台词功底与声音表演

先继承原词、语言、对象、声线身份、声音政策和身体状态。为台词决定“用这句话让对方做什么”，再选择可听处理，不把每句话变成一个情绪标签。

## 意群、重音与回应

按语义分意群，找真正改变意思的关键词。重音可由清楚咬字、略延长、节奏前后关系或音量/音高变化体现，不全靠突然放大声。句尾要完成当时的行动，不能所有句子都下沉收尾。停顿用于找词、观察回应、改变策略或处理身体限制，不按标点统一加秒数。

说话时仍在听：对方靠近、回避或改变表情，可以使后半句从逼问转为确认；不必等台词结束才开始反应。需要一气呵成时保留连贯，不为展示“功底”每个词都停。未听过录音只给可演节奏，不宣称精确时长或配音已成功。

## 分开声音维度

| 维度 | 设计问题 | 避免混同 |
|---|---|---|
| 音量 | 对方多远、是否需要别人听到、是收小还是投向远处？ | 小声不必低音；响亮不必愤怒 |
| 音高与走向 | 在角色既定音域内，哪段抬起/落下/保持？ | 低沉不等于所有字单调低平 |
| 共鸣/声质 | 需要饱满、清亮、偏薄、气息外漏或既有沙哑？ | 沙哑不等于悲伤，也不改变说话者身份 |
| 速度/节奏 | 哪个意群急于推进，哪个需要让对方接收？ | 紧迫不等于全句加速；克制不等于慢读 |
| 咬字/重音 | 哪个关键词要清楚，口型与身体能否完成？ | 含泪不能默认吞字或逐字颤音 |
| 气息/停连 | 句前、句中何处受哭泣/运动/痛感影响？ | 连续吸气与持续发声不能同时锁定 |

选择改变意义的维度；其余继承基线。声音可以强烈变化，但变化要有对象或触发，不把上表变成每句六项表格。

## 低声、低沉、耳语与气声

- **压低声音**：收小音量、缩短传递范围，仍可清楚咬字并维持原本音高；明确是避免惊扰、隐藏信息、拉近关系还是失去力气。
- **低沉**：在人物既有音域内使用较低且有共鸣的有声音色，可有句内起伏；不是强改成陌生的“男低音”或一直压喉。
- **耳语**：轻声传递、接近听者，声质与普通有声低语有区别；不能同时要求饱满低音共鸣和完全无声带振动的耳语，也不规定医学发声机制。
- **气声/沙哑**：作为既定声质或本场有原因的变化，按必要程度使用；不用来给所有悲伤台词贴同一种声音。

同一句“你先坐下。”可这样处理，原词保持不变：

| 行动意图 | 声音与身体配合 |
|---|---|
| 安抚受惊的人 | 中低音量、平稳气息，语义重心在“先”；向椅子让出位置，等对方动作，不压迫靠近 |
| 阻止对方离开 | 不提高音量但清楚落在“坐下”；站在既定位置，留出能走的路，观察对方是否接受，而非一律凑近耳语 |
| 害怕惊醒旁人 | 收小音量，保持本来的音色和字音，靠近接收者的可听范围；不因小声自动降低到阴沉声线 |
| 痛中请求支撑 | 在完成换气后短句说清，声音力度比基线弱，身体保留支点；不把全部字写成呻吟 |

这些是同词异演的候选，不套入每场。公开呼救、远距离指令、彻底失控或夸张喜剧可大声；用户需要吼叫就保留其触发、对象与余波，不用“高级克制”覆盖要求。

## 身体、口型与声音同一时间

面部任务让位于语音口型：不能紧闭嘴完整说句子，不能大口吸气同时连续念长句。身体在承重、哭泣或快速行动时，安排能完成的意群；气息限制可以成为表演，但不凭空改词和偷加间投词。

逐字台词只放引号内；旁边写说话者、实际声源、允许的语气/换气处理。原有标点不为表演改成省略号，断句不漏词或重复。切镜仍按声轨连续拼接；人物表演音量低而成片可听可由获准混音处理，不让混音自动等于人物提高音量。

严格静音时不写可听事件；仅原对白的契约下不额外加哭声、吸鼻或喘息音。仅禁环境音不自动禁止人物非词声音，是否保留按用户实际声音政策决定。未锁定非词声音且剧情确实需要时可按声音政策设计，不把音效、背景音乐或字幕当台词功底。

不同语言的重音和语调不能直接套中文；保留目标语言和词语，以交流意图与必要变化描述，缺少试听或母语复核就不宣称语言表演已验证。

## 同词异演的策略与呼吸

保留原词与说话对象，先改行动策略再选择重音、意群和声质。例如同一句请求，可用留出回应的间隙邀请，也可把关键词落稳以制止离开；不是只把“温柔”换成“愤怒”。语气标注在引号外，不额外插词。

话中接收、犹豫和换气服从身体任务及原句容量；吸气、咬紧嘴与完整发声不能同时持续。音高、音量和气声分别决定，疲劳不自动变耳语。文字演法与实听声音分别验收。
