# Complex Emotion Profiles

本文件补充恐惧、焦虑、羞耻、嫉妒、厌恶和惊讶。先识别触发事件与角色目标，再选择表演行为；不要为了覆盖清单而一次加载多个画像。

以下是创作候选，不是心理/医学分类或诊断依据；行为与镜头不固定对应情绪，曲线不必逐步完成。颤抖、失焦和气息变化须结合已知状态；疼痛等不受控反应按[身体状态](embodied-states.md)处理。

## 恐惧 Fear

核心：恐惧来自“威胁已经逼近，而角色不知道能否控制”。重点不是瞪大眼睛，而是身体在战、逃、僵住或讨好之间做选择。

| 子类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 隐约不安 | 威胁尚未被确认 | 停下动作、重新听、视线搜索 |
| 突发惊恐 | 危险瞬间出现 | 吸气中断、重心后撤、保护要害 |
| 冻结恐惧 | 大脑短暂失去行动方案 | 身体僵住、呼吸变浅、视线锁定 |
| 强装镇定 | 不能让对方发现害怕 | 声音刻意平稳，手部泄露控制失败 |
| 生存性恐惧 | 必须立刻逃跑或反击 | 快速判断出口、距离和障碍 |

常见曲线：异样 -> 确认 -> 身体先反应 -> 选择战/逃/僵/讨好 -> 后怕或行动。

镜头：先让观众感知角色正在寻找什么，再决定是否展示威胁。不要只用快速推镜和夸张尖叫代替恐惧判断。

## 焦虑 Anxiety

核心：焦虑是对尚未发生之事的持续预演。它不像恐惧那样有明确、即时的威胁，更依赖重复、自我检查和注意力漂移。

| 子类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 等待性焦虑 | 结果迟迟不来 | 反复看时间、手机或门口 |
| 社交焦虑 | 害怕被评价 | 预演措辞、整理衣物、避开视线 |
| 失控焦虑 | 无法掌握局面 | 同时处理多件事却不断返回原点 |
| 隐性焦虑 | 表面正常，身体持续报警 | 浅呼吸、脚尖用力、手指重复摩擦 |
| 惊恐发作 | 身体反应被误判为更大危险 | 呼吸失序、空间变窄、急于寻找支撑 |

常见曲线：预想 -> 自我安抚 -> 新信号 -> 循环加速 -> 中断、崩溃或暂时恢复。

镜头：允许重复构图、细小跳切或空间压缩，但不要把所有焦虑都处理成惊恐发作。

## 羞耻 Shame

核心：羞耻不是单纯难过，而是“我被看见了，而且我认为自己不该是这样”。表演重心通常从外界撤回自身。

| 子类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 被揭穿 | 秘密或失败暴露 | 视线失去落点、身体缩小 |
| 公开难堪 | 在群体中被评价 | 假笑、整理物件、寻找退出路径 |
| 内疚型羞耻 | 认为自己伤害了别人 | 想靠近又停下、不敢接受安慰 |
| 愤怒防御 | 用攻击阻止他人继续看见 | 语速变硬、打断、突然抬高姿态 |
| 被接纳后的羞耻 | 最害怕的部分仍被理解 | 先不相信，再松开防御 |

常见曲线：暴露 -> 否认或遮掩 -> 自我收缩 -> 防御/逃离 -> 接纳或余痛。

镜头：关注视线关系和身体空间，不必持续特写脸部；环境中“其他人的存在”经常是关键压力。

## 嫉妒 Jealousy

核心：嫉妒来自比较、失去位置的威胁以及“不愿承认自己在意”。它往往混合欲望、羞耻、愤怒和自我贬低。

| 子类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 隐性比较 | 不断衡量自己与他人 | 观察细节、快速移开视线 |
| 关系嫉妒 | 害怕被取代 | 关注两人距离、插入谈话或突然沉默 |
| 成就嫉妒 | 他人的成功照见自己的缺口 | 祝贺慢半拍、笑容停留不自然 |
| 敌意嫉妒 | 想降低对方价值 | 礼貌贬低、挑错、夺回话题中心 |
| 自觉型嫉妒 | 知道情绪不体面 | 压住反应、主动退开、事后反刍 |

常见曲线：比较信号 -> 否认 -> 注意力黏住 -> 泄露或攻击 -> 掩饰、后悔或行动。

镜头：让观众看到“角色看见了什么”以及之后的微小反应；不要只用阴沉表情概括嫉妒。

## 厌恶 Disgust

核心：厌恶驱使角色建立距离，既可以针对气味、触感等身体刺激，也可以针对道德行为或关系背叛。

| 子类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 感官厌恶 | 身体拒绝接触 | 鼻翼、上唇、头部后撤、减少呼吸 |
| 道德厌恶 | 认为行为越过底线 | 视线变冷、停止争辩、拉开距离 |
| 自我厌恶 | 无法接受自己的行为或状态 | 回避镜子、擦拭、反复否定动作 |
| 厌恶转愤怒 | 拒绝升级为对抗 | 先撤离，随后重新逼近或发问 |
| 厌恶转悲哀 | 关系价值突然坍塌 | 身体后撤后失去力量 |

常见曲线：接触 -> 身体拒绝 -> 判断来源 -> 拉开距离 -> 清除、对抗或断开关系。

镜头：同时交代刺激来源与身体撤离方向，避免把厌恶简化成夸张鬼脸。

## 惊讶 Surprise

核心：惊讶是信息更新，不天然等于喜悦或恐惧。关键在极短的认知停顿以及随后由哪种情绪接管。

| 子类型 | 情绪内核 | 表演关键 |
|---|---|---|
| 轻微意外 | 结果偏离预期 | 动作停半拍、重新确认 |
| 重大震惊 | 旧认知被推翻 | 呼吸停住、语言中断、身体定格 |
| 惊喜 | 意外迅速转为喜悦 | 先确认真实，再放松或靠近 |
| 惊吓 | 意外迅速转为恐惧 | 防御动作先于理解 |
| 反转认知 | 新信息改变关系判断 | 回看人物或物件，重新组织距离 |

常见曲线：正常预期 -> 信息撞入 -> 短暂停顿 -> 确认 -> 被后续情绪接管。

镜头：给“认知空白”留出可见时间。惊讶通常很短，后续情绪才决定场景走向。

## 混合与转折组合

组合时明确每种情绪控制的行为，不要把多个标签堆在同一张脸上：

- 恐惧转愤怒：身体先后撤，确认退无可退后重新逼近。
- 羞耻转防御性愤怒：先回避视线，再用打断和攻击夺回控制。
- 嫉妒混合喜爱：祝福动作真实，但注意力不断回到被比较的关系。
- 惊喜转怀疑：眼睛先亮，随后停止靠近并重新确认信息。
- 厌恶混合悲哀：先拉开身体距离，再因关系破裂失去力量。
