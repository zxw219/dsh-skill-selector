# 场面调度、摄影、表演与声音

导演信息的目的，是让关键事件在正确的距离、方向和时间里被看见与听见。只写能改变可见结果的控制，不用术语数量证明专业性。

## 一、场面先于镜头

每场先确定：

- 谁想从谁或环境中得到什么；
- 阻力在哪里，失败会改变什么；
- 人物开始时正在做什么，而不是等待剧情启动；
- 关键道具、出口、障碍和光源的世界位置；
- 哪个刺激迫使人物换策略；
- 片尾空间、关系或对象状态如何不同。

走位必须改变距离、权力、视线、遮挡、任务、逃生路线、信息归属或空间控制中的至少一项。若人物移动后什么都没变，删去走位或赋予它明确作用。

多人场面给每人一个低负荷事务，指定主行动者、直接承受者和次级反应者。群体反应按距离、视线、声音传播和身份形成先后，不让所有人同时转头、退后或完成相同表情。

## 二、空间和连续

场内使用固定锚点描述位置，例如门内侧、桌左端、台阶下方或车辆后方。记录人物世界位置、身体朝向、视线目标、持物手和运动方向。屏幕左右是机位投影结果，不能代替世界位置。

关系轴和运动轴用于维持可读性，不是不可触碰的装饰规则。若观察方向改变，使用宽镜、中性机位、人物可见横越、地标或完整摄影机移动重新建立关系。用户有意选择跳切、越轴或主观混乱时，保留选择，同时确保观众能把它读成有意表达而非连续错误。

相邻镜头不必为变化而变化。只有当新的景别、角度或焦点提供了空间、反应、证据或后果时才切；若同景别承接能保持压力或动作完整，就不强制改换。

## 三、摄影机职责

先问“观众此刻必须知道什么”，再选择景别：

- 远景或宽镜：空间、路线、尺度、群体关系、完整动作和环境后果；
- 中景：身体行动、双方关系、手部事务和距离变化；
- 近景：判断、操作、微反应、接触和关键证据；
- 特写细节：只在该细节改变理解或行动时使用。

摄影描述优先写可见结果：主体在画面中的比例、前中后景、透视、景深、焦点对象、机位高度和运动路径。焦段、光圈或设备名称只有在它们帮助稳定这些结果时才加入，不能与可见要求冲突。

运镜要有触发和终点：跟随位移、靠近决定、揭示空间、转向声源、被遮挡或在事件后退出。一个阶段保留一个主要摄影行为；复合运动必须属于同一因果链。不要同时要求复杂人物动作、快速切换和多轴运镜。

## 四、动作和受力

动作按以下链条写：

`准备与支撑 → 启动方向 → 接近或作用 → 接触/避开 → 对象与身体反馈 → 结束位置和余波`

力量通过重心、速度变化、接触点、形变、反作用、声音和环境反馈呈现。高速通过视差、风压、衣物或碎屑惯性和障碍掠过表现。不要用“猛烈、丝滑、震撼”代替过程。

多人动作每一时段只保留一个主要关系：谁对谁做什么，第三人是干预、躲避、观察还是准备。武器、产品、手部操作和细小机关需要选择能看清接触的景别；大范围位移则用能确认路线和终点的镜头。

连续追踪人数、持物、伤势、破坏、湿度、烟尘、火焰、弹药或能量消耗。状态变化一旦发生，后镜不得无故恢复。

## 五、表演和反应

不要直接要求人物“展示某种情绪”。把转折编译成：

`前态和手上事务 → 刺激到达 → 第一无意识反射 → 评估对象 → 掩饰或泄露 → 新策略 → 跨镜余波`

按景别选择可见行为。远景用路线、姿态和停顿；中景用重心、距离、肩颈和手部；近景才使用眼神、呼吸、吞咽、唇压或肌肉变化。一个镜头只安排一个主要情绪转折，避免连续堆叠多种表情。

对话场中听者持续生活。反应可以从关键词到达时开始，不必等整句结束。回答前给一次可观察判断；说话者看到对方反应后可以改变音量、速度、距离或策略。重要信息的重量常由承受者证明，但镜头归属仍应服从当前叙事视点。

## 六、光线、材质和风格

先锁定可见光源及方向，再描述冷暖、软硬、明暗关系和材质响应。反打、换机位和连续生成中，世界光源方向不随摄影机翻转。人物移动经过光区时，面部亮度和色温应按路径变化。

风格词必须落到可观察维度：

`构图密度｜镜头稳定性｜透视与景深｜光比与色彩关系｜材质和空气｜表演尺度｜剪辑节奏｜声音空间`

品牌、镜头型号、胶片名称或泛化的“电影感”只能作为次级意图。若它们没有对应的画面结果，删除。

## 七、对白和声音

每句对白绑定：

`说话人｜出现时段｜原文｜身体状态｜音量与速度｜口型或画外声源｜听者反应`

保持用户锁定台词，不擅自补写、交换说话人或让所有角色同时开口。奔跑、受伤、寒冷、哭泣、遮挡和距离会改变呼吸、响度、清晰度和节奏；声线身份本身不应无故变化。

声音分为环境底床、中远距离活动、前景拟音、叙事音效、对白和空间响应。只选与事件有关的层。每个重要音效要有声源、方向、距离、材质和人物反应。切镜不自动重置声场；需要声桥时写明它何时进入、跨过哪个切点、何时衰减或显露来源。

音乐、旁白、字幕和画面文字按用户要求处理，不预设必须出现或必须排除。若画面中的文字不是任务重点，说明不生成额外可读信息，避免无关内容争夺注意力。

## 八、特效和环境交互

特效至少说明：起点、运动方向、尺度、速度变化、遮挡层级、受光、与人物或场景的接触、同步声音和结束残留。烟、尘、水、火、碎片和能量不能只悬浮在画面上；它们应影响能见度、衣物、地面、人物动作或后续状态。

镜头若无法同时看清触发、主体和后果，调整机位或拆成两个阶段。精彩内容可以保留，但要让每个阶段只承担模型有机会完成的一条主要因果。
