# 成稿结构、时长与拆段

本文件处理从锁定内容到正式提示词的编译。它不替用户改写剧情，也不假设所有入口具有相同能力。

## 一、入口配置卡

成稿前记录已知项：

`任务模式｜目标时长｜画幅｜字符上限｜素材标记方式｜声音要求｜可用编辑能力`

用户未提供的信息分两类处理：

- 会改变事件、引用方式或交付格式的关键项：只问一个最有影响的问题。
- 只影响可选修饰的非关键项：保持中性，不写成平台硬参数。

不要从其他项目、文件名或旧范例推断当前入口限制。用户明确的入口配置覆盖惯例。

## 二、内容覆盖表

把源内容压缩成五栏内部记录：

| 栏目 | 记录内容 |
|---|---|
| 开场状态 | 主体位置、姿态、持物、正在进行的动作、声场和光线 |
| 必须发生 | 事件、原台词、动作结果、道具或产品变化、指定镜头 |
| 允许补足 | 呼吸、视线、微小惯性、自然环境反应、必要过渡 |
| 不得改变 | 身份、数量、造型、剧情因果、产品结构、禁令 |
| 镜尾状态 | 位置、姿态、动作相位、持物、损伤、特效残留、最后声音 |

覆盖表用于防漏，不必交付给用户。若源内容过长，按事件逐项核销；没有进入当前片段的事件保留给后段，不要悄悄删掉。

## 三、时长估算

先估事件需要的时间，再确定镜头数量。一个动作单元至少包括触发、执行和可读结果；一次关系转折还要留出承受者反应。对白时长以自然说出、呼吸和听者反应为准，不用字数平均切分。

可用三步测试承载量：

1. 按真实顺序朗读对白，同时做必要停顿。
2. 把无法同时看清的动作、反应和空间结果分别计为事件单元。
3. 为开场定位和镜尾收束保留时间；若剩余时间不足以完整展示核心单元，就拆段或删去非必要镜头。

镜头少不等于信息少。一个清楚的关系镜可以同时完成空间、表演和道具交接；多个相似近景只会争夺时间。

## 四、自然拆段

优先在以下位置结束一段：

- 一个动作完成并产生后果；
- 人物改变目标或策略；
- 道具完成交接或状态变化；
- 空间、时间或主观视点发生转换；
- 一句话和直接反应完成；
- 声音或特效收束，并留下可识别的下一步。

不要在接触发生前后、人物半句对白、尚未落地的跳跃、未完成的镜头移动或无法识别的运动模糊中强行截断。每段结尾都要给下一段留下明确把手，而不是只写“画面结束”。

## 五、正式六栏

### 【生成目标】

一至两句说明地点、当前事件、基调、总时长和片尾要看到的结果。只承诺本段真正执行的内容。

### 【参考素材职责】

逐项使用：

`素材标记 = 对象别名｜主控内容｜必须保留｜允许适配｜明确排除`

没有素材时写“无外部参考；以用户锁定的人物、场景和事件为准”。未采用的素材不要出现在正式稿中。

### 【全局关系】

写明主体身份与关系、所穿服装或所持道具的归属、开场站位与朝向、视线对象及关键空间关系。不补设定，不复述逐镜调度。

### 【视觉风格与光线】

只写全段共用的画幅、可见光源、光色、场景材质、画面质感和摄影方式。不写声音或逐镜动作。

### 【事件脚本】

使用连续时间段：

`0–a秒【阶段名称】空间与画面；摄影机；主体行为；作用与后果；对白与声音；阶段终点。`

在对应时间段交代对白是谁说的、是否画外，以及环境声、动作声和呼吸何时进入、延续或收住。每段至少产生一种变化：新信息、位置、对象状态、关系、风险、声音或观看尺度。时间段按事件需要分配，不机械等分。

### 【全局补充】

确认贯穿连续性、准确片尾和最高风险的少量约束。禁止项必须具体，例如“唯一钥匙始终在甲右手，交给乙后不再回到甲手中”，而不是罗列与本片段无关的泛化负面词。确有跨镜生效的声音要求时才写在本栏，不默认补写。每份成稿在本栏单列一行：`完全忽略@黑屏素材`。

## 六、跨段交接

后段开头只复述上一段镜尾中直接影响新动作的状态，并立即从下一步开始。交接最少包含：

`人物位置和朝向｜动作相位与速度｜持物｜损伤或消耗｜光线或特效残留｜最后声音`

换机位可以发生，但必须用路线、地标、视线、声音或可见运动维持空间可读性。若时间跳跃或空间变化是创作选择，明确新时间地点和已经改变的状态，不假装无缝连续。

## 七、压缩次序

接近字符上限时依次删除：

1. 重复设定和重复禁止项；
2. 同义风格词与创作理由；
3. 对结果没有影响的设备、参数和材质枚举；
4. 可由一个动作结果替代的心理解释；
5. 次要环境装饰。

必须保留：身份与素材用途、事件顺序、关键接触和结果、原台词及声源、编辑范围、连续状态和镜尾。压缩后重新检查时间轴，不允许删掉中间状态却保留依赖它的后果。
