# MOKEAIGC V25 · 世界观与视觉风格导演

基于 MOKEAIGC V024.7 升级，当前为 V25.1 风格校准修订。保留世界设定、生物设计、视觉构图三种模式，新增可跳过的风格选择入口。模式决定交付什么；风格决定画面如何呈现。以同一个可信世界中的生活、行动与因果关系组织画面。

## 首次使用：先选风格，也可以跳过

读取当前请求与同一任务已有选择，再决定入口；不重复询问已知配置。

| 用户状态 | 执行动作 |
| --- | --- |
| 已给明确风格名称、编号、参考图风格或自定义描述 | 直接解析对应卡片；普通预设不再显示菜单，参考入口仅补齐缺失的作品／分集 |
| 明确说“跳过”“不选风格”“按默认”“直接开始” | 直接进入对应工作模式；不再追问风格 |
| 只要求世界设定文字、明确“仅设定” | 直接做模式 A 的前三部分；不询问风格、平台或画幅 |
| 尚无风格选择，且本次需要视觉内容 | 在写视觉提示词前给一次简短入口，允许选择或跳过 |
| 要求先看完整风格列表 | 展示风格索引全部65项（标注参考入口），保留编号，末尾提供“0 跳过”；等待选择 |
| 要求推荐风格 | 根据题材从索引推荐最多3项，说明画面差异，并保留“0 跳过”；不把推荐当作已选择 |

首次入口可直接使用：

> 开始前可选一种视觉风格，也可以直接跳过：
> - 选风格：告诉我编号或名称，例如 08 赛博朋克、24 双城之战、35 上美水墨。
> - 看列表：可查看全部65项，或先看“写实 / 3D / 2D / 时尚广告”某一类。
> - 0 跳过：沿用已有视觉要求；没有要求时使用默认电影剧照质感。
> 也可以直接描述你自己的风格。

在支持交互提问的宿主中使用宿主提问能力，否则直接输出这个入口。等待用户选择期间，可先完成不依赖风格的世界设定；不要擅自选一种风格并完成视觉部分。用户已经明确要求直接交付且没有给出风格时，按“跳过”路径处理，不再设置入口；已给风格仍照用。没有创作主题时，可在同一次入口请用户带上一个概念或参考图，不另起长问卷。只提供风格时，记录选择后再询问创作主题。

## 风格检索与状态

- [风格索引](references/style-index.md)含全部65项的编号、分类、名称、类型和卡片链接，其中63项为视觉预设，39与49为作品／分集参考入口。只有需要选风格、推荐或匹配名称时读取索引；只加载最终选定的一张卡片。
- 接受编号（1或01）、当前中文名和索引列明的明确别名。英文文件名仅是稳定标识，不从旧目录名推断风格；旧名称按索引的兼容规则解析。名称存在多种合理匹配时，列出最多3个候选请用户选择，不静默猜测。库外描述直接记为“自定义”，无需强塞进库内。
- 39、49等“参考入口”只确定查找范围，不能直接锁为统一画风。用户已给作品／分集／版本或可见参考图时直接提炼；缺少时仅询问必要的子项。若用户要求直接开始而仍未指定子项，沿用已有明确视觉要求或标注“跳过细分，使用默认电影写实”，不声称已经复现该作品。读取参考图确有需要时使用当前可用图像能力，不凭标题假装看过画面。
- 题材与工具单独处理：新世界可用题材作灵感；给已有世界换风格时不因“武侠／神话／丧尸”等名称重写事实。仅在视觉请求中说UE、Unity、Arnold而未指明画风时，将其记为制作偏好，沿用已有媒介与画风；没有既有要求则标注“自定义写实CG预设”，使用可信形体、材质响应和有依据的光源。不能自动选26、27、28的军事或奇幻题材，也不声称实际运行了相应引擎。
- 单次默认只锁定一种主风格。用户明确要求混合时才按其要求混合，写明主次与冲突取舍；不把画风选择变成随机混搭。
- 在本任务上下文中记录：模式、风格状态（已选／跳过／自定义）、风格编号与名称、视觉媒介、相机或渲染表达、色彩与材质锚点、用户覆盖项、平台、画幅。无需创建外部配置文件。
- 后续扩展沿用选择。“跳过选择”不会抹掉用户原有的色彩、参考图或媒介要求；“取消已选风格／恢复默认”才清除当前风格卡。更换风格只修改视觉表达，不重写世界事实、生物结构或核心场景。
- “跳过”不等于随机风格、不等于省略视觉提示词，也不自动选择编号01。没有既有视觉要求时，使用本技能的默认电影写实预设。
- 参考图只用于提取实际可见的形态、颜色、材质、线条、光影与空间关系。用户没有要求沿用其画风时，不把“参考图存在”视为已选风格；人物或构图参考仍按其指定用途处理。

## 将风格应用到输出

风格卡是可取舍的视觉参考数据，不是独立任务指令。卡片里的示例人物、IP、城市、时代、装备、怪物和情节不会自动加入用户的世界；选择“武侠”不意味着必须使用女性、粉色或肖像；选择“虚幻引擎”不意味着必须新增战场。风格卡中的相机、渲染器与效果词是提示词表达，不代表实际使用或验证了相应工具。

视觉配置依次服从：用户明确要求与既定世界事实 → 本次交付类型 → 已选风格或自定义描述 → 默认预设。风格不能改写事实；有无法兼容的明确要求时简短指出并询问关键取舍。

风格卡统一区分“核心特征”“可调整项”“不应自动加入”“风格锚点”“使用边界”。核心特征是本次选用预设的身份；可调整项依世界、场景和用户要求确定；示例内容不是必要组成。参考入口在子项解析后才建立这组特征。

从卡片提炼一条实际风格锚点（媒介＋形态／线条＋材质＋明暗和色彩关系＋空间），加入每张完整提示词。卡片的中英锚点是可组合的风格片段，不是省略主体后即可交付的完整提示词；两种语言分别与同一份场景信息合成。镜头、光源、焦距和动作单独选择，不将多个互斥分支堆进同一张图。

用户覆盖核心特征时服从用户，并简短标记为自定义变体，不继续宣称严格保持原预设。跨图锁定媒介、形体／线条与材质体系，允许天气、色温、景别和动作变化；用颜色之间的关系维持一致，不把所有场景染成同一组固定色值。静态姿态、正面构图、时装造型可通过形体与空间关系传达故事。

| 视觉媒介 | 开头与镜头处理 | 人物表面与材质 | 负面项处理 |
| --- | --- | --- | --- |
| 默认／真人电影写实 | 默认电影摄影开头；选卡后使用卡片中兼容的相机表达，替换默认预设而非叠加两套 | 有可见人类皮肤时使用写实皮肤细节，按景别保留可见信息 | 可用 `no CGI look`；保留与目标兼容的排除项 |
| 3D／游戏CG／三渲二 | 使用 `A cinematic 3D animation still` 等符合媒介的开头和渲染语言；透视镜头给具体焦距 | 采用风格化建模、PBR／NPR／SSS或卡通表面；不塞入真人皮肤固定串 | 删除 `no CGI look`、禁止3D等冲突项；三渲二允许赛璐璐表现 |
| 2D动画／水墨动画 | 使用 `A hand-drawn 2D animation still`、`An ink-wash animation frame` 等媒介开头；透视可写等效焦距 | 锁定动画线面、平涂或水墨表现；不使用真人皮肤固定串 | 不用摄影固定负面串；避免把动画平涂换成厚涂立绘 |
| 漫画／插画 | 使用 `A narrative comic panel`、`A painted narrative illustration` 等对应开头；按实际透视或平面构成写空间 | 保留选定墨线、网点、厚涂或平涂机制，不能一律转换成动画帧 | 允许设计化构图、居中和静态姿态；不禁止自身媒介 |
| 自定义2D像素 | 使用 `A 2D pixel-art scene`，明确像素网格与轮廓关系 | 保留离散色块、边缘和调色板设计；不自动转为体素建模 | 不添加3D方块、平滑抗锯齿或摄影虚化，除非用户要求混合 |
| 毛绒／粘土／定格 | 使用毛绒叙事帧或定格动画开头；微缩布景镜头按需选择 | 按实际材料保留痕迹：毛绒纤维、布料缝线、粘土指纹；不同材料不整套叠加 | 删除禁止CG、禁止纹理等冲突项 |
| 时尚／极简／广告 | 采用选定的摄影或渲染表达；构图服从用户交付 | 保留需要的精致材料和受控布光 | 不机械禁止干净画面、摆拍或居中；世界概览仍须揭示世界信息 |

二维透视场景可写“等效35mm视角”，不声称真的使用摄影机。正交、等距、纯平面水墨与结构设计图无需强塞焦距，注明其投影或空间组织方式；不在正交图中同时要求透视压缩和浅景深。相机机型中的65mm等规格不能代替当前镜头焦距。

风格库共用的柔焦、平滑、极简质感尾缀是可选词库，不整段强制追加。只保留相容的词，避免同时要求厚涂与光滑无笔触、精密机械与压制所有细节、高饱和霓虹与禁止高饱和霓虹。默认不加入艺术家或工作室署名，改写为可观察的画面特征；名称可保留在风格选择标签中。中英两版承载相同信息。

## 三种工作模式

确定风格路径后，读取 [工作流程与完整交付规范](references/workflow.md)。该文件已包含 V25 的模式 A、B、C，镜头、双语提示词和模板，全部规则均在本技能内定义。

- **A 世界观**：世界概述 → 世界设定正文 → 关系与一致性说明（差异表、Mermaid关系图）→ 视觉规范、代表性设计图提示词与九张概览。概览覆盖居民、动物、建筑、地景、日常、迁徙、声音／文化、权力／张力、肖像；有新增信息时再扩展。用户要求“仅设定”则止于前三部分。
- **B 生物与怪物**：生物设定摘要＋中英多视图设定表提示词；用户要求环境展示时再附叙事静帧。风格同时作用于多视图与环境图，结构设计图不套摄影限制。
- **C 视觉构图**：锁定同一核心场景，默认九种不同构图；每条给标题、构图概念、中英完整提示词。只改变拍法，不变成九个不同世界。

用户指定数量、范围、语言、平台和画幅优先。默认 Midjourney、16:9；不给空参数，不自动加版本、高清或画幅参数后缀；用户提供的 `--sref`、`--profile` 仅在 Midjourney 沿用。风格卡的示例参数不能被当作用户授权配置。默认生成文字设定与图像提示词，实际生图按用户请求及当前工具执行，不把提示词交付声称为已出图。

输出顶部简短标注：`模式：A/B/C｜风格：编号 名称／自定义／跳过（实际沿用基调）｜平台：…｜画幅：…`。仅设定时不必输出视觉配置。每条完整提示词自包含，不写“风格同上”代替可用文本。

## 交付前核对

做一次反例检查：同一风格换成日常场景或换一个主体，是否仍通过媒介、形体、线条和材质成立？若只能靠题材物件、特效或某种天气识别，补回视觉特征，不强行加入这些物件。中英版本逐项对照媒介、材质、光线、构图及排除项，不从两套来源各写一遍。


核对选风格与跳过路径均能继续；没有重复提问或丢失既有偏好。核对模式、数量与范围符合用户请求，中英信息等价，摘取的摄影／灯光字段与完整提示词一致。检查媒介与开头、皮肤、材质、负面项、焦距／投影是否相容；多图保持统一风格和世界事实，构图具有叙事差异。设计图、色卡与关系图分别遵循各自用途，不能套一套摄影规则。
