# 42 · 鬼灭之刃参考·二维动画

- 分类：2D / 作品参考视觉预设
- 媒介：清晰线面与层次背景结合的2D动画观感
- 类型：视觉预设
- 旧名称：鬼灭之刃

## 核心特征

- 角色和物体轮廓清楚，线条粗细有所变化，姿态和表情易读。
- 主要明暗采用清楚的色面和阴影边界，高光与阴影方向协调。
- 背景具有较完整的空间层次与细节，主体的线面语言不被背景吞没。
- 发光效果需要有明确边缘、内部色阶和周边受光，不等于整幅泛光。
- 动作画面可使用方向鲜明、形状经过设计的图形化效果，但基础形体始终可辨。

## 可调整项

- 具体篇章、参考帧、人物比例、背景密度、色板和光照对比。
- 是否出现动态效果、其密度与图形形态，由实际动作与世界规则决定。
- 日常、夜景或安静场景保持线面身份，无需战斗强化。

## 不应自动加入

- “热血运动番”、汗水飞溅、速度线或冲击帧作为默认画面。
- 自动加入刀剑、鬼、呼吸法效果、服装纹样或原作人物。
- 将特效词堆砌当作作品识别锚点，或宣称使用其真实制作管线。

## 风格锚点

**EN：** Expressive 2D animation imagery with clear variable-weight contours, readable designed color and shadow shapes, detailed spatially layered backgrounds, coordinated highlights and directional effects only when the action requires them, while preserving structural clarity.

**中文：** 富于表现力的2D动画画面，轮廓清楚且线重变化，经过设计的色形与阴影形可读，背景细致并具有空间层次，高光关系协调，仅在动作需要时使用有方向的效果，同时保持结构清晰。

## 使用边界

- 这是用于参考提炼的视觉预设，不声称覆盖作品所有篇章。用户已有具体参考帧时优先其可见形态与光色；没有动作时删除方向特效。不得再次使用旧卡“热血运动作画”的误标签。

风格锚点用于与当前主体、动作、环境及构图组合，不是完整出图提示词。执行模式、用户覆盖项与平台格式见 [V25主入口](../../SKILL.md)。
