# greatwall生图新

独立调用 `https://api.gwlink.cc/v1`。所有运行代码都在本技能的 `scripts/` 中，只读取专用密钥变量 `GATEWAY_IMAGE_NEW_API_KEY`（进程环境或 Windows 用户环境变量），不得向其他技能、脚本或密钥变量回退。

## 每次生成前先判断模式

按用户本次的明确要求选择模式，不沿用上次模式，也不因历史消息或附件里有图片就自动使用图生图。

| 本次意图 | 模式与实际调用 |
| --- | --- |
| 仅根据文字创建新图片；或明确要求纯文生图、参考图只用于观察和提炼描述 | `generate`：向 `/images/generations` 发送 JSON 文字请求，不上传参考图。提示词须是独立描述，不写“编辑原图”或“保留输入图”。 |
| 明确要求基于原图修改、换衣、换背景、去除物品、提取服装、保留人物身份或画面细节；或用一张/多张图片作为实际生成参考 | `edit`：向 `/images/edits` 上传图片和文字指令，采用 `multipart/form-data`。 |
| 无法判断参考图只供分析还是要上传参与生成；“照这个做一张”等表述缺少明确意图 | 先问“这次要仅根据文字重新生成，还是上传参考图进行修改/生成？”，等待回答，不能自行默认一种模式。 |

- 用户明确指定文生图或图生图时优先遵从；模式已经明确时不用重复询问模式。
- 模式不明确时，可把模式选择和四个模型的选择放在同一轮提问中；两项都确定后才可提交请求。
- 图生图必须有可读取的本地输入图片。缺少图片或有多张候选但不清楚用哪张时，先请用户提供或指定原图，不能偷偷改成文生图。
- 每次实际提交前，简短说明本次采用“文生图”或“图生图”；图生图还要说明使用哪张/哪些图片，再按下一节询问模型。
- 不因服务端报错或模型编辑不支持就自动切换模式、模型或重新提交。

## 每次生成前必须询问模型

- 每次准备生成一张新图或修改一张图片前，先展示下列四个模型及各自简介，询问“本次使用哪个模型？”。等待用户回答后才可提交请求。
- 无论使用文字列表还是选项面板，每个选项都必须同时包含完整模型名称和简介，不能只显示模型名或省略未推荐模型。
- 没有默认模型，不沿用历史选择，不读取模型环境变量。即使用户在当前需求中写了模型，也要询问确认本次选择。未回答、超时或预选项都不算选择。
- 批量任务中的每次实际提交也分别询问模型，不把一次选择延续到下一次生成。
- 仅编写提示词、查看配置、离线检查时不提交生成请求，不需要询问模型。
- 若发生失败，不自动重发请求；再次生成仍需重新询问本次模型。可下载同一已生成图片的链接，不必重生成。

仅保留以下四个模型，模型名称必须逐字使用。简介采用用户提供的 Gateway 渠道说明：

| 模型 | 每次询问时展示的简介 |
| --- | --- |
| `gpt-image-2-高质量4k` | 固定出4K大图，价格较高、速度较慢。 |
| `gpt-image-2.5-exact` | 2.5精准尺寸路由，保证精确像素。 |
| `gpt-image-2.5-flare` | 官方快车道，最快，日常推荐选择。 |
| `gpt-image-2.5-sunburst` | 官方精修道，编辑最强，出图较慢。 |

`flare` 的“日常推荐”仅用于帮助选择，不是自动默认值；仍必须等待用户明确选择。不要自行增加其他模型或补充未经提供的性能比较。具体编辑、蒙版、尺寸和质量参数支持以服务端结果为准，不擅自换模型。

## 工作方式

1. 按“每次生成前先判断模式”确定本次模式，意图不明确时先询问并等待回答。
2. 图生图时查看并确认实际上传的原图，明确每张图的角色；多图时在提示词中按上传顺序写清图1、图2的用途。文生图的观察用参考图只用于提炼描述，不上传。已有本地图片无需上传公开图床。
3. 整理提示词，保留用户指定主体、构图、材质、风格与限制，不默认固定风格。复杂中文提示词保存为 UTF-8 文件，通过 `--prompt-file` 传入，避免 shell 转义。
4. 说明已确定的本次模式，列出四个模型名称和简介，询问并等待用户选择本次模型；只有模式、所需原图和模型都明确后，才运行本技能对应的 `generate` 或 `edit` 命令。生成请求会使用网关额度；密钥缺失时告知用户配置专用变量，不在聊天里索要完整密钥。
5. 保存一张 PNG 到当前工作区 `output/greatwall生图新/` 或用户指定位置。使用新文件名，不覆盖现有图片。查看生成结果，报告实际结果并内嵌展示图片及绝对路径。

## 调用

从本技能目录运行以下命令。示例中的模型必须先由用户选择，不能把示例当默认值。

```powershell
python .\scripts\generate_image.py generate --model "用户本次选择的完整模型名" --prompt-file "C:\路径\提示词.txt" --out "C:\路径\新图片.png"

python .\scripts\generate_image.py edit --model "用户本次选择的完整模型名" --prompt-file "C:\路径\修改要求.txt" --image "C:\路径\原图.png" --out "C:\路径\修改版.png"
```

- 多张输入：重复 `--image`；实际请求重复 `image` 文件字段。
- 局部修改：添加 `--mask`，须为与第一张原图同尺寸的 PNG；蒙版是否生效取决于模型。
- 短提示词也可用 `--prompt`，与 `--prompt-file` 二选一。
- `--size` 可省略；填写时必须是所选模型已确认支持的尺寸。`--quality` 为 `auto/low/medium/high`，默认 `auto`。
- `--response-format` 为 `url/b64_json`，默认 `url`，会实际发送给接口。
- 脚本依赖已安装的 `httpx` 和 `Pillow`；同步调用，不使用流式响应，不自动重试生成。

## 结果与错误

文生图调用 `/images/generations` 的 JSON 接口；图生图调用 `/images/edits` 的 multipart 文件上传接口。

仅当 API 返回真实图片并成功保存后，报告已生成。401/403、参数错误、额度不足、超时等应报告实际失败，不切换模型或自动重发；生成超时可能已经提交，请先查看平台图片任务日志。

下载失败时保留返回链接，只处理该结果或重新下载，不重新提交生图。文档说明图片链接默认公开且保存约24小时，成功后及时保存本地。不要自动上传本地输入到公开图床。

不得输出密钥、请求认证头或把密钥写入本技能、提示词、日志、项目文件。正常验证 TLS，不因证书错误关闭校验。

接口依据：[Gateway 图片 API 文档](https://gwlink.wiki/docs/image-video/image-api)。价格及支持尺寸以模型广场为准，四个模型的具体编辑参数支持以服务端为准。

离线验证：`python .\scripts\test_generate_image.py`，使用假密钥和模拟服务，不会调用付费接口。
