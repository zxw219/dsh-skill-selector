The official contract distinguishes five input modes: T2VA, I2VA, FL2VA, L2VA, and Ref2VA. Base text/keyframe modes use `integrated_multimodal_description`, `overall_soundscape`, and `non_diegetic_music`; Ref2VA uses `subject_definitions`, `summary`, `retention_analysis`, `detailed_description`, `overall_soundscape`, and `non_diegetic_music`. Field order, first-line keyframe alignment, shot/timing syntax, reference labels, and English rewrite language are protocol requirements rather than optional style preferences.

Treat [h3-interoperability-guide.md](h3-interoperability-guide.md) as the local model-facing serialization owner. The controlled findings below remain the owner for task fit, density defaults, failure boundaries, asset remedies, and review targets. An official capability claim does not become a locally validated strength without inspected output, while a local recipe does not override the official prompt schema.

## Official capability baseline — checked 2026-08-02

Primary sources:

- MiniMax API documentation, H3 examples: <https://platform.minimaxi.com/docs/guides/video-prompt>
- MiniMax API documentation, video generation: <https://platform.minimaxi.com/docs/guides/video-generation>
- MiniMax H3 launch article: <https://www.minimax.io/blog/minimax-h3>

Current official facts:

- H3 accepts unified text, image, video, and audio context and supports generation, generalized reference, and editing.
- Current video modes include text-to-video, first/last-frame generation, and omni-reference input.
- Current output is 2K, with integer duration from 4 through 15 seconds.
- Omni-reference currently accepts up to 9 images, up to 3 video segments totaling at most 15 seconds, and up to 3 audio segments; audio accompanies image/video input. Total files are limited to 12.
- The current official guide gives first/last-frame images a width and height range of 256–5760 pixels and an allowed aspect-ratio range from 5:2 through 2:5. Its omni-reference table states the same dimension range for images but does not explicitly publish an image aspect-ratio range there, so the active UI/API route must be checked rather than inferred.
- The prompt field currently allows up to 7000 characters.
- An earlier API guide explicitly suggested adding `[运镜]` after a key description. The current official `h3-prompt-writing` Skill instead writes camera movement as natural English inside each shot; use that current serialization for generation-ready prompts and treat `[运镜]` as a legacy or surface-specific cue until the active route confirms it.
- MiniMax highlights instruction following, accurate text and brand rendering, V2V motion transfer, native stereo audio, and commercial use cases such as film titles, product websites, animated posters, advertising, e-commerce, branding, UI/UX, gaming, and product design.
- The launch article says H3 still has room to improve in multimodal understanding, model scale, and visual detail.

Treat all limits and availability as current facts that require rechecking after a model/API update.

Review authorized text, glyph accuracy, full exposure, hierarchy, beat alignment, and vocal accuracy as separate surfaces.
- The hand-drawn 2.0 post supplies a concrete causal mechanism: establish the real object, grow an imperfect drawn outline from the pen tip, convert only the traced area, add color stroke by stroke, and preserve the surrounding live-action layer plus the target's position, scale, and motion. Treat this localized reality rewrite as officially showcased but locally unverified for this exact mechanism; do not generalize it to whole-scene style transfer.
- The manual separately documents `音色克隆与迁移` and demonstrates mapping a spoken target line to a numbered reference audio. It also lists dialogue, timbre, and related sound modification under editing. This confirms audio-role routing and timbre-reference syntax, not a quantitative reliability guarantee. A timbre-only role does not import the source words.
- An official staff reply in the manual recommends reinforcing a synchronized sound once beside its owning action and again in `overall_soundscape`, placing score entry/exit in `non_diegetic_music`, and using relative mix language rather than percentages or dB. Treat this as prompt-writing guidance; timing and loudness remain output-review surfaces.
- The motion-design showcase includes prompt-level `4K` and `60fps` wording, while the current published H3 capability baseline above states 2K output. Keep resolution and frame rate as active-route settings and do not convert showcase wording into a platform guarantee.

Propagation result: update task discovery, guided recipes, evidence labels, and preflight only. Keep the five official input modes and [h3-interoperability-guide.md](h3-interoperability-guide.md) unchanged because these showcases add task patterns rather than a new serialization schema.

Across these bounded tests, H3 followed one continuous subject/state chain more literally than several independent physical mechanisms. It was consistently strong at exact short copy, intact-line/card typography motion, graphic and object transitions, visual packaging, product/material presentation, one-chain VFX/material state changes, and compact visual storytelling. Exact custom-symbol geometry and exact UI state logic require reference-owned structures rather than prose-only instructions. Dense action remained weak in separate practical tests. Preserve these boundaries until later evidence changes them. Node count is not the only density variable: the clean eleven-node lower limit applies to short isolated cards with one local job, while multiple subordinate material/depth responses consume the same temporal and causal bandwidth. For richly transformational 15-second sequences, reduce the node count or enrich only selected anchor nodes rather than every node.

## Cross-model design transfer — competing decision density, checked 2026-08-11

Prior inspected SD2.5 failures supplied a model-agnostic design lesson: a 15-second finishing chain that combined wing growth, high-speed orbiting, blade insertion, a large magic-circle reveal, scale change, resistance, closure, and disappearance collapsed toward a polished static ritual image. Several independent visual centers and serial causal systems competed inside the same interval, so the visible physical order weakened. The case-specific repair was to split the chain or retain only three unmistakable result states, with one dominant effect system at a time; three states is not an H3 quantity rule.

The transferable rule is **not** an SD2.5 timing threshold or workflow rule. Audit overload by competing decision density rather than raw prompt length or cut count. One node may contain several causally linked actions when they serve one visible state change; independent mechanisms that can succeed or fail separately should be reduced, separated, or assigned to stronger structural references. The H3 controlled suite above independently supports this direction: eleven isolated short-card nodes can survive, while eleven richly transformational nodes overload. Therefore H3 node counts remain bounded planning heuristics rather than universal ceilings, and descriptive compression should remove competing centers and serial obligations before merely removing words.

The second inspected product film reinforces the distinction between **product visualization** and **engineering proof**. H3 can preserve an exterior identity, render premium materials, execute short function callouts, and integrate text with product motion. Detailed internal hierarchy remains reference-dependent: without a CAD/exploded/structure board, use a few macro modules and avoid claiming exact internal semantics. When a breakdown hands off to an in-use shot, reassemble to a complete stable exterior before the transition; an intermediate exploded state is not a reliable continuity owner for the worn product.

The no-reference trailer and pure-motion tests add two bounded distinctions. A stable recurring carrier can coordinate either compact narrative information or an abstract material chain without supplied assets, but it does not guarantee that every written micro-proof survives. For pure motion, count **visible states**, **material fidelity**, and **editorial blocks** separately: H3 may preserve the macro state order while substituting an intermediate material and fusing several planned nodes into one continuous transition.

The inspected graphic-anime PV adds a user-confirmed target distinction: intentional sensory overload should not be repaired by the same compression used for accidental causal overload. Keep the macro action chain simple, but budget editorial microshots, viewpoint/scale changes, graphic recomposition and sound attacks as a separate presentation layer. In the tested result, eight written rich nodes became roughly four perceptual macro blocks and the final five seconds lost shot density. One result only supports the next test—explicit hard-cut cadence with many single-job microshots—not a guaranteed H3 cut count.

The inspected text-flash PV adds a typography-specific distinction: **semantic copy states**, **beat-level microshots**, **detected editorial blocks**, and **perceived speed density** are separate budgets. Eight short authorized strings can support many half-second operations because successive operations elaborate the same copy state instead of introducing new information, but accurate copy and many written microbeats do not by themselves create an ultra-fast flash feel. Long clean holds, black gaps, repeated settled landings, fused continuous transforms, and an early final lockup reduce perceived density. This does not raise the general information-node limit, and a requested microshot count does not guarantee the same number of hard cuts. The successful all-Chinese prompt also shows that Chinese prose is viable on the tested Hailuo T2VA surface for this lane; it does not replace the official English serialization contract used by [h3-interoperability-guide.md](h3-interoperability-guide.md) on routes that require that contract.

The single inspected MV result supports the existing **controlled MV-packaging** lane, not a broader claim that H3 owns every MV type. A compact recipe that worked was one performer, one stage, one recurring graphic carrier, and one live/graphic/live state chain. Exact displayed lyrics still need occurrence-by-occurrence inspection, and decision-critical sung wording should be owned by supplied audio or verified after generation rather than inferred from on-screen text.

The visual-kei multi-camera result shows that explicit shot-role variety and a cut-count contract can broaden H3's coverage, but one output does not establish a general camera-control rule. Review **cut density** and **in-shot camera travel** as separate surfaces: several distinct viewpoints can still contain little completed camera movement inside each shot. Keep this as evidence until another controlled output confirms a reusable H3-specific instruction.

The hand-drawn PV result reinforces the existing kinetic-typography and visual-packaging lane: one recurring graphic carrier can successfully coordinate character motion, paper depth, camera travel and several exact short strings. It also shows why review must separate **correct glyphs**, **a fully exposed readable state**, and **information hierarchy**. One long phrase hidden behind a performer is not a clean typography pass even when its visible fragments are correctly styled.

The cast/title result validates the film-title lane with a bounded recipe: short bilingual cards, one material per card, isolated negative space, and a final spatial pullback. It also reinforces a separate continuity check: repeated palette and props can unify a sequence even when the declared transition carrier is not visibly continuous. Review **system-level visual unity** and **carrier-level causal continuity** as different surfaces.

The six-panel reference-atlas result separates **graphic fidelity after selection** from **deterministic panel selection**. A multi-panel atlas can transfer typography style, hierarchy and individual card appearance, but positional panel names do not reliably bind six panels to six timed beats. For decision-critical ordered credits, make each required card independently addressable as its own input/shot, or add the exact copy in post; otherwise treat the atlas as a visual vocabulary rather than a literal timeline source.

The seven-node stress test established the first controlled lower bound rather than a universal ceiling. The matched nine-node retry kept nine information states distinct, rendered every short multi-line card exactly, completed eight readable handoffs, and preserved one recurring red carrier through an active ending. The first eleven-node rung kept all states and handoffs distinct but partly blocked its final English director credit. A matched cross-style eleven-node test then changed the complete palette, material and carrier family while rendering all eleven cards exactly and cleanly. The thirteen-node non-cast botanical rung rendered every fixed label correctly and kept all states distinct, but squeezed the reverse node below its clean-exposure promise and compressed several reverse phases into one collage. The enabling conditions remain isolated short labels, one local action per node, no dependent dialogue, combat, exact UI-state burden or competing causal system. Evidence therefore establishes a bounded clean eleven-node lower limit and a thirteen-node boundary; the next controlled rung is twelve nodes. Do not generalize this ladder to longer copy or other task classes.

The planned fish V2V/multimodal-edit test did not return an output. Therefore H3 multimodal editing and V2V motion transfer remain official capabilities but are not yet validated strengths in this controlled test set.

## Reference-submission isolation — aspect-ratio confound, 2026-08-03

A later control disproved the provisional conclusion that text-dominant reference cards were being rejected: the earlier 2560×1440 typography master containing six Chinese/English credit cards uploaded successfully and produced `h3_tv_opening_reference_text_test_27_v002.mp4`. The successful colored-icon control was also 512×512. By contrast, the rejected original lockup was 1792×448 (4:1), and every derived wordmark, neutral-text, and single-character card was 1344×448 (3:1).

The failed set therefore shared out-of-range ultra-wide geometry, while the known successful set used 1:1 or 16:9. The official first/last-frame input range is 5:2 through 2:5; the current omni-reference guide does not explicitly state an image-ratio range, so applying the same validator there began as an inference. The unchanged full lockup was then composited onto a 1920×1080 opaque RGB canvas and resubmitted with the same neutral prompt; it generated successfully. In this controlled setup, bringing the artwork into an accepted 16:9 canvas was sufficient to clear the submission failure; the earlier brand, typography and moderation conclusions are retracted. Keep the broader platform rule bounded to the tested route and continue validating current input specifications for other entry modes.
