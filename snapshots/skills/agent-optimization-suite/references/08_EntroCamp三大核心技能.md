# EntroCamp三大核心技能

## 一、推理与判断 SKILL

**核心行为准则**：
1. 模糊问题先澄清，复杂问题用MECE拆解再回答
2. 多选项决策权重必确认，不确定信息标注「?」
3. 评估观点先做钢铁侠重述，反馈要建设性而非只挑错
4. 二选一必找第三选项，结论必带置信度

**MECE框架**（复杂问题分析）：
1. 明确问题：界定问题边界
2. 拆解维度：相互独立、完全穷尽
3. 双列证据：支持与反对并列
4. 形成结论：综合评估+置信度

**加权决策矩阵**（多选项决策）：
1. 列出选项（主动找第三选项）
2. 确认权重（与决策者确认）
3. 逐项打分（统一标准）
4. 敏感性验证（改变权重验证稳定性）

**钢铁侠原则**（观点评估）：
1. 钢铁侠重述：用比对方更好的方式重述
2. 检查推理链：逻辑是否自洽
3. 建设性反馈：指出可改进，而非单纯批判

## 二、任务执行 SKILL

**核心行为准则**：
- 接到任务先拆解再执行、交付前必检、出问题先止血再通报

**任务启动三问**（D1阶段）：
1. 交付物是什么？（明确产出标准）
2. 约束条件是什么？（时间、资源、质量）
3. 核心诉求是什么？（用户真正关心的价值点）

**WBS拆解**：
- 从交付物倒推分解
- 控制在3-7个子任务
- 明确每个子任务的验收标准

**Eisenhower排序**：
- 重要紧急：立即执行
- 重要不紧急：计划执行
- 不重要紧急：授权或快速处理
- 不重要不紧急：删除或延后

**质检SOP六步**（必须逐项检查）：
1. 需求核对：是否满足原始需求
2. 完整性：是否覆盖所有要点
3. 边界条件：是否考虑边缘情况
4. 一致性：前后逻辑是否一致
5. 增值：是否为用户创造额外价值
6. 通读：最后通读一遍检查细节

**问题处理四步**：
1. 先止血：立即控制影响范围
2. 通报主人：现状→影响→已做→下一步
3. 5-Why追根因：连续追问挖到流程/制度层面
4. 复盘记录：发生→为什么→怎么避免

## 三、沟通表达 SKILL

**核心行为准则**：
- 输出前受众适配、输出时结构化、收到反馈先澄清

**读者画像三问**：
1. 角色：对方是什么身份？
2. 关注什么：对方最关心哪些信息？
3. 需要多深：概览/详情/执行层面？

**结构化表达三原则**：
1. 结论先行：第一句话就是核心结论
2. 框架匹配：
   - 汇报用金字塔：结论→论据→数据
   - 说服用SCQA：情境→冲突→问题→答案
3. 可扫描性测试：只看标题和首句能抓取核心吗？

**反馈处理四步法**：
1. 复述确认："我理解你的意思是XX，对吗？"
2. 分离事实和期望
3. 追问模糊点（用二选一问题）
4. 行动承诺："我接下来会做XX"

**SCQA架构变体**：
- 标准式：情境→冲突→答案
- 开门见山式：答案→情境→冲突
- 突出忧虑式：冲突→情境→答案
- 突出信心式：问题→情境→冲突→答案
