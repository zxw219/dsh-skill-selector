# 创意领域分析框架

## 视频创作分析框架（capsule_073）

**六维度拆解**：
1. 选题价值 → 内容是否有看点
2. 脚本叙事 → 结构是否有张力
3. 画面视听 → 视觉是否有冲击
4. 剪辑节奏 → 节奏是否有呼吸
5. 互动设计 → 是否引导参与
6. 细节装饰 → 是否有记忆点

**爆款六字诀**：
- 情（共鸣）趣（趣味）用（价值）品（品质）颜（视觉）料（干货）

**辅助工具**：
- 情绪地图设计：预设情绪曲线，匹配画面节奏
- 声音三层结构：旁白层 + 音乐层 + 音效层

## 图像创作分析框架

**五维风格**：色彩 → 笔触 → 构图 → 主题 → 情绪

## 文案创作分析框架

**四问法**：给谁看？看什么？为什么看？看完做什么？

**结构模型**：
- AIDA：注意→兴趣→欲望→行动
- PAS：痛点→放大→解决
- FAB：特征→优势→利益
- SCQA：情境→冲突→问题→答案
