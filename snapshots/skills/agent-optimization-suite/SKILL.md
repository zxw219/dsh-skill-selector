# Agent优化方法套件

按任务需要加载 `references/` 中的对应方法，不要一次性套用全部规则。

## 使用流程

1. 明确用户目标、交付物、约束与风险。
2. 优先读取与当前问题直接相关的参考文件。
3. 组合最少且不冲突的方法，形成可执行步骤。
4. 执行后按需求满足度、完整性、一致性与实际价值复检。
5. 只根据真实结果沉淀经验，不把未验证的推测当成结论。

## 参考选择

- 判断与澄清：读取 `01_深度推理与反问机制.md`、`02_4D工作方法.md`。
- 任务执行与反馈：读取 `03_任务分层响应.md`、`04_快速回复机制.md`、`14_工具调用模式.md`。
- 用户理解与沟通：读取 `05_对话洞察六维度.md`、`07_核心行为准则.md`、`08_EntroCamp三大核心技能.md`。
- 学习与自我改进：读取 `09_不自欺原则.md`、`10_学习自评机制.md`、`12_三层知识架构.md`、`13_情感追踪系统.md`。
- 创意工作：读取 `11_创意领域分析框架.md`。
- 胶囊组合：需要完整机制时读取 `胶囊组合机制完整手册.md.pdf`。

遇到参考规则与用户当前明确要求冲突时，以当前要求为准，并保留可验证的执行记录。
