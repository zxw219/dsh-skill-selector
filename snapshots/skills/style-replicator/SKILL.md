# Style Replicator · 参考图风格复刻引擎

这是一个**与具体风格无关**的引擎。它不预设任何画风,而是教 AI 如何"看懂"用户放进 `references/` 文件夹的参考图、提炼出它们共有的视觉风格,再结合用户的一句话需求,产出一条**既复刻该风格、又满足用户内容要求**的完整提示词(语言跟随用户输入,默认中文)。

风格由用户决定:用户往 `references/` 放什么风格的图,就复刻什么风格。本文件只规定**方法**,不规定**风格内容**。

---

## 运行流程(每次被触发时严格按此执行)

### 第 0 步:检查 references 文件夹

查看本技能目录下的 `references/` 文件夹里有多少张图片(常见格式:png/jpg/jpeg/webp)。

- **如果一张图都没有**:停下,不要编造风格。直接回复用户:「请先在本技能的 references 文件夹里放入 3~8 张你想复刻的同一风格的参考图,再告诉我你想生成的画面。」然后结束。
- **如果只有 1 张**:照常分析这一张,基于它提炼风格(只是样本少,风格判断以这一张为准)。
- **如果有多张(理想是 3~8 张)**:逐张查看,提炼它们**共有的**视觉特征(共性才是"风格",个别差异是"内容")。

### 第 1 步:逐张查看参考图(必须真正用看图工具读取图片)

用看图能力**逐张实际查看** `references/` 里的每一张图(不要只凭文件名猜)。看图时,沿下面**六大维度**做系统观察,并在心里记录每张图在各维度的表现,最后归纳共性:

**维度一 · 镜头**
画幅比例(16:9/竖构图/方形…)、拍摄角度(平视/俯视/仰视/低机位贴地…)、景别(大远景/远景/中景/近景/特写)、景深(大景深全清晰/浅景深虚化背景)。

**维度二 · 主体描述**
- 核心身份/物种(人/动物/物体/建筑…)
- 体型/外貌特征(大小、比例、五官、形态)
- 材质/纹理/服饰(衣着、表面质感、颜色)
- 动作/姿态(站/走/坐/动态)
注意:主体的"具体内容"会被用户需求替换,但主体的"呈现方式"(在画面中多大、清晰还是剪影、占比多少)属于风格,要提炼。

**维度三 · 环境描述与构图**
- 核心地理位置/场景(雪原/城市/沙漠/室内…)
- 天气与氛围(晴/阴/雾/雨/尘…)
- 空间层次(前景/中景/远景各是什么、如何分层、有无大气透视)
- 构图(主体位置、留白多少、引导线、对称or失衡、视觉重量分布)

**维度四 · 光线**
- 主光源/方向(顶光/侧光/逆光/来自画面哪个方位)
- 光线软硬质感(硬光锐利投影 / 柔光无影 / 半硬)
- 辅光源/互动光(反弹光、补光、环境光)
- 特效光/气氛光(丁达尔光、辉光、雾中透光…有则记,无则记"无")
- 明暗对比度(高反差/低反差/中等)

**维度五 · 色彩**
- 色温(冷/暖/中性,偏蓝or偏黄)
- 主色 / 辅色 / 点缀色(画面靠哪几个颜色构成,哪个是点睛色)
- 饱和度(高/中/低)
- 色彩对比度(冷暖对比/互补色对比/同类色)
- 高光与阴影倾向(高光偏什么色、阴影偏什么色)

**维度六 · 质感 + 氛围意图**
- 写实 or 风格化(照片级写实/CG/插画/油画/手绘…)
- 纹理粗细(细腻精致/粗粝/简洁概括)
- 颗粒(胶片颗粒/干净无颗粒/噪点)
- 整体氛围与情绪意图(孤寂/壮丽/温馨/压抑/神秘…这张图想让人"感觉"到什么)

### 第 2 步(可选,仅在有代码执行环境时):量化校准

如果当前环境能运行代码(如可用 Python/PIL),对参考图做一次快速量化,让色彩与影调的描述更精准、避免凭感觉出错:

```python
from PIL import Image
import numpy as np, os
folder = 'references'  # 相对本技能目录
for f in sorted(os.listdir(folder)):
    if not f.lower().endswith(('png','jpg','jpeg','webp')): continue
    im = np.asarray(Image.open(os.path.join(folder,f)).convert('RGB'), dtype=np.float32)
    L = im.mean(2)
    r,g,b = im[:,:,0].mean(), im[:,:,1].mean(), im[:,:,2].mean()
    print(f, f'| 亮度 mean{L.mean():.0f} std{L.std():.0f} | RGB({r:.0f},{g:.0f},{b:.0f}) R-B={r-b:+.0f}(负=偏冷)',
          f'| 纯黑<10:{(L<10).mean()*100:.1f}% 亮>220:{(L>220).mean()*100:.1f}%')
```

读数解读要点:`R-B` 为负=偏冷、为正=偏暖;`亮度mean` 高=亮调、低=暗调;`std` 高=高对比、低=低对比;`纯黑%` 大=有重黑块、`亮>220%` 大=高光多甚至过曝。把这些数据写进色彩/影调的描述,比纯肉眼更准。
**普通对话环境无代码能力时,跳过本步,纯靠看图判断即可。**

### 第 3 步:归纳"风格画像"

综合第 1(和第 2)步,在心里形成一份该参考集的**风格画像**——即六大维度里**反复出现的共性**。区分清楚:
- **属于风格的**(每张图都有、需要复刻):如统一的冷色调、统一的低机位大远景、统一的胶片颗粒、统一的留白习惯。→ 这些要写死进提示词。
- **属于内容的**(随图不同、会被用户需求替换):如这张是城墙那张是塔楼、这张人在左那张人在右。→ 这些让位给用户输入。

### 第 4 步:结合用户需求,生成正向提示词

把用户输入的"画面需求"作为**主体内容**,套进第 3 步提炼的**风格画像**里,产出一条**自然语言**提示词(连贯段落式,不是关键词堆砌;语言按第 6 步的语言规则,默认中文)。要求:

- **结构**:按"画面总览 → 主体 → 环境与构图 → 光线 → 色彩 → 质感氛围"的顺序组织成通顺的描述。
- **风格部分照搬画像**(色温、光线、构图习惯、质感、颗粒、氛围等共性),**内容部分用用户的需求**。
- 用户需求与参考风格冲突时(如用户要"明亮欢快"但参考图是"阴郁冷调"):以**用户的内容需求为主体**,但**尽量保留参考图的风格手法**;若硬冲突,优先满足用户明确指定的,并在提示词里自然融合,不要生硬。
- 若参考图有明显的"构图铁律"(如人物极小+大留白、主体偏置+对角),作为风格的一部分保留,并据用户主体合理安放。

### 第 5 步:推导"该风格要避免什么"——并内化进正向提示词(不单独输出)

参考风格不仅决定"要什么",也决定"要避免什么"。这一步**只在内部进行**,用来反推避免项,然后把**最关键的几条**用自然语言**嵌进正向提示词内部**(例如"……绝非梦幻仙气、绝非CG插画……""……冷青色调,绝不泛黄泛暖……")。**不要在输出里单列一段"负向提示词"。**

**A. 通用画质硬伤(任何风格都要避开,作为底线意识,不必每条都写进提示词,挑相关的融入即可):**
低质量、模糊、失焦、变形、畸变、多余肢体、比例错误、水印、文字、过度锐化、AI痕迹。

**B. 风格专属避免项(从参考图风格的"反面"推导,挑最关键的 2~4 条嵌进正向提示词):**
依据参考图在各维度的取向,把它的**对立面**作为要避免的:
- 参考图**冷调** → 提示词里点明"绝不泛暖泛金"(反之亦然)。
- 参考图**低饱和** → 点明"克制不艳俗"(反之"避免灰暗")。
- 参考图**写实** → 点明"绝非CG、塑料、插画、卡通"(反之若参考是插画风,则点明"非写实照片")。
- 参考图**大留白/极简** → 点明"大量留白、避免杂乱拥挤"。
- 参考图**人小景大** → 点明"主体极小、避免主体过大或居中"。
- 参考图**柔光/低反差** → 点明"柔和无硬投影"(反之亦然)。
- 参考图**干净无颗粒** → 点明"纯净无噪点脏块"(反之点明要颗粒)。
- 参考图**孤寂克制** → 点明"克制内敛、避免戏剧化夸张奇观"。

**做法**:只挑出对**当前这个风格最致命、最容易被模型搞错**的 2~4 条避免项,用"绝不/避免/而非/非……"的自然语言**写进正向提示词的相应位置**(色彩部分写色彩避免项,质感部分写质感避免项),让它们成为正文的有机组成,而不是末尾附加的清单。

### 第 6 步:输出

只输出**一段正向提示词**(自然语言、连贯段落、放在代码块里方便复制),其中已自然包含第 5 步挑出的关键避免项。**不要单独输出负向提示词清单。**

**输出语言规则**:跟随用户输入的语言——用户用中文提需求就输出中文,用英文提需求就输出英文;用户明确要求某种语言时,用该语言;**未指明任何语言时,默认输出中文**。

输出前用一句话点明:本提示词基于 references 中 N 张图提炼的风格 + 你的需求生成。不要长篇解释分析过程(除非用户明确问"为什么/讲讲分析")。

## 关键原则(务必遵守)

1. **必须真看图**:一定用看图工具实际查看 references 里的每张图,绝不能只凭文件名或想象编造风格。
2. **风格来自图,内容来自用户**:六大维度里的共性=风格(复刻),用户输入=内容(主体)。不要把某张图的个别内容当成风格强加。
3. **本技能不预设任何风格**:不要默认"冷色/雪景/电影感"等任何具体风格——一切以当前 references 里的图为准。换了图就换了风格。
4. **避免项是推导出来并内化的**:不单独输出负向清单;从参考风格的反面推导出关键避免项,用自然语言嵌进正向提示词内部。
5. **不啰嗦**:默认只给提示词成品,不展开分析,除非用户要求。
6. **不问多余问题**:用户给了需求和图就直接做;只有在 references 为空时才回去要图。
