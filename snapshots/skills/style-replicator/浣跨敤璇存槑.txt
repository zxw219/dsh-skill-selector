【这个工具是什么】

这是一个"看参考图、复刻画风"的提示词生成工具。
你把想模仿的同一风格的参考图放进 references 文件夹,再写一句你想要的画面,
它就会分析这些参考图的风格,
再结合你的需求,生成一段既复刻该风格、又符合你要求的完整提示词,
你可以拿这段提示词去生图软件出图,也可以直接结合具有生图能力的工具直接生图。

它与具体风格无关:放雪景图就复刻雪景,放赛博朋克图就复刻赛博朋克,
放油画、动漫、产品摄影……都可以。换风格,只需换 references 里的图。


----------------------------------------
【怎么安装 / 在哪用】
----------------------------------------

方式一(最简单):
  直接把这个压缩包拖进能读取压缩包的大模型对话框使用,
  比如 Claude 或 ChatGPT 的对话窗口。

方式二:
  把整个压缩包(解压后的文件夹)放进 Claude Code、Codex,
  或任何支持技能/文件的 agent 里使用。


----------------------------------------
【怎么用 · 两步】
----------------------------------------

第一步:放参考图
  打开 references 文件夹,放入 3~8 张同一种风格的参考图。
  (内容可以不一样,但风格要统一,这样才能准确提炼出共同的画风)

第二步:写需求,拿提示词 / 出图
  按你的想法写一句画面需求,例如"一个红衣女子走向城墙"。
  然后有两种用法,任选:
    A. 直接让 ChatGPT / agent 出图;
    B. 先让它生成提示词,你确认或修改满意后,
       再把提示词粘贴到生图软件出图
       (即梦 / Nano banana / Midjourney / image2 等)。


----------------------------------------
【放参考图的小提示】
----------------------------------------

· 数量:建议 3~8 张,多张才能提炼出稳定的"共同风格"。
· 风格要统一:同一画风的图放一起;风格越一致,复刻越准。
· 内容可不同:人物、场景、构图可以各异,工具会自动区分
  "什么是风格(要复刻)"和"什么是内容(听你的需求)"。
· 支持格式:png / jpg / jpeg / webp。
· 换风格:想做另一种风格时,清空 references,换一批新图即可。
· 只放 1 张也能用,但样本少、风格判断不如多张稳。
· 图片也不宜过多,超过 8 张容易掺入杂质、风格反而被稀释、提炼变混乱;
  3~8 张是最佳区间。
· references 为空时,工具会提醒你先放图。


----------------------------------------
【输出语言】
----------------------------------------

· 你用中文提需求 → 输出中文提示词。
· 你用英文提需求 → 输出英文提示词。
· 你明确指定语言 → 按你指定的来。
· 没说语言时 → 默认输出中文。


----------------------------------------
【示例】
----------------------------------------

示例一:复刻雪域古风电影感
  1) references 放入 3~8 张"雪山 + 孤独红衣人 + 巨大中式建筑"的同风格图。
  2) 输入:一个红衣女子牵马走在城墙下。
  3) 得到:一段描述"冷青色调、低机位大远景、人小景大留白、
     半硬方向光、写实胶片质感"的完整中文提示词,
     主体则是你要的"红衣女子牵马走在城墙下"。
  4) 复制去生图软件出图。

示例二:复刻赛博朋克都市
  1) references 换成 3~8 张霓虹、雨夜、高饱和的赛博朋克图。
  2) 输入:一个孤独的侦探站在霓虹小巷里。
  3) 得到:一段提示词,复刻参考图的霓虹高饱和、潮湿反光、
     高对比夜景风格,主体是你要的侦探与霓虹小巷。

(同一个工具,换了 references 里的图,产出的风格完全不同——这就是它的用法。)
