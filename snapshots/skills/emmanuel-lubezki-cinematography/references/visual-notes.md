## 卢贝兹基十大核心技法

### 1. ☀️ 自然光哲学（Natural Light as Religion）

**卢贝兹基的第一信条。** 自然光不是限制，而是神圣的叙事材料。一切人工光只在万不得已时使用，且必须融入自然光体系中"消失"。

| 关键特征 | 说明 |
|---------|------|
| **拒绝人工填充光** | 几乎不使用标准的三点打光，阴影原样保留 |
| **黄金时段崇拜** | 日出日落时的橙金光线是最常用的光源（Magic Hour） |
| **白昼漫射光** | 阴天的均匀漫射光提供无方向感的神圣氛围 |
| **窗光纯粹主义** | 室内几乎只用窗口自然光，不补光 |
| **极限条件拍摄** | 《荒野猎人》中整片只用自然光拍摄，每天黄金时段仅 90 分钟 |
| **烛火与火光** | 用真实的火焰作为唯一人工光源（《荒野猎人》晚间场景） |

**代表场景**：
- 《荒野猎人》— 全片自然光，黄金时段的森林宛如油画燃烧
- 《生命之树》— 院落中漫射的早晨光线，时间感模糊
- 《鸟人》— 后台走廊的荧光灯与舞台追光，均是场景内可信光源

**提示词核心词**：
```
natural light only, magic hour warm golden light, diffused overcast daylight,
window light casting soft shadows, no artificial fill, candlelight as only interior light,
harsh shadows preserved, ambient light photography, available light cinematography
```

---

### 2. 🌀 超广角亲密感（Ultra-Wide Intimacy）

**用极短焦距接近人物，创造一种"被宇宙包围"的存在感。** 卢贝兹基标志性的鱼眼/超广角近拍，让人物同时渺小又巨大。

| 关键特征 | 说明 |
|---------|------|
| **12–18mm 极端广角** | 常用 Zeiss 12mm、14mm 等超广镜头 |
| **夸张透视** | 前景人物放大，背景空间被压缩拉深 |
| **边缘变形** | 轻微的桶形畸变成为风格特征 |
| **人物与宇宙共存** | 宽阔视角同时呈现主体与宏大环境 |
| **破坏第四堵墙** | 广角镜头常接近到角色几乎填满画面 |
| **IMAX 扩展帧** | 《地心引力》部分片段用 IMAX 格式扩展至正方形，增加宇宙感 |

**代表场景**：
- 《地心引力》— 宇航员的面罩特写，背后是整个地球
- 《荒野猎人》— 熊攻击场景的超广角——痛苦与森林同框
- 《鸟人》— 走廊追逐镜头中演员几乎撞进摄影机

**提示词核心词**：
```
ultra-wide angle lens, extreme wide angle 14mm or 12mm lens,
distorted perspective with wide angle, figure close to lens with vast environment behind,
barrel distortion, immersive wide angle framing, subject filling frame with world visible around them
```

### 3. 🌊 流体运镜（Liquid Camera Movement）

**摄影机如同有生命的生物，它呼吸、漂浮、追逐，永不停歇。** 卢贝兹基的运镜具有独特的有机感，拒绝机械的固定镜头。

| 关键特征 | 说明 |
|---------|------|
| **斯坦尼康主导** | 手持斯坦尼康是主要运动方式，创造呼吸感 |
| **连续弧线运动** | 镜头持续绕人物弧形移动，不停歇 |
| **垂直到水平切换** | 单个镜头内完成从仰拍到俯拍的角度变换 |
| **穿越性运镜** | 摄影机"穿过"物体、人群、空间 |
| **宇宙视角** | 《地心引力》中模拟零重力的六轴运动系统（Light Box） |
| **吸附-脱离节奏** | 镜头靠近、离开、再靠近主体，如同呼吸 |

**代表场景**：
- 《鸟人》— 假装"一镜到底"穿越整栋剧院大楼
- 《荒野猎人》— 斗熊场景的混乱与有机感
- 《地心引力》— 太空中 "如果摄影机本身就是宇航员" 的 POV 运动

**提示词核心词**：
```
fluid Steadicam movement, organic camera breathing, continuous curving camera motion,
camera orbiting subject, immersive POV tracking shot, camera movement as character emotion,
no locked-off static frame, living breathing camera
```

---

### 4. 🎭 一镜到底沉浸（Long Take Immersion）

**长镜头不是炫技，而是时间本身的呈现。** 卢贝兹基用不剪辑制造一种无法逃脱的在场感。

| 关键特征 | 说明 |
|---------|------|
| **《鸟人》式全片连接** | 与剪辑师设计"隐形剪辑点"，全片如同一镜 |
| **时间连续性** | 长镜头传达时间未经剪辑的真实压迫感 |
| **摄影机即意识流** | 镜头随意识漂移而非剧情逻辑 |
| **演员配合运镜** | 演员动作和位置精确配合摄影机路径 |

**代表场景**：
- 《鸟人》— 后台到舞台再到屋顶，时间在镜头中流动
- 《地心引力》— 开场 17 分钟固定镜头的太空灾难
- 《生命之树》— 宇宙起源段落的连续意识流影像

**提示词核心词**：
```
single continuous take aesthetic, long take immersion, time flowing uninterrupted,
consciousness stream cinematography, single uncut scene feeling, temporal continuity
```

### 5. 🌿 环境融合美学（Environmental Integration）

**角色不是站在背景前，而是从环境中"生长"出来。** 卢贝兹基的镜头让人与自然、人与城市、人与宇宙融为一体。

| 关键特征 | 说明 |
|---------|------|
| **自然作为角色** | 树木、水流、风、光线都有叙事功能 |
| **人在环境中渺小** | 人物常被宏大的自然/宇宙景观淹没 |
| **仰拍天际** | 大量仰拍展示树冠、天空、宇宙，创造神性感 |
| **水面与倒影** | 水面反光是常见的视觉元素 |
| **树冠的光斑** | 阳光穿越叶片的 bokeh 是标志性视觉 |

**代表场景**：
- 《生命之树》— 仰望树冠，光斑从叶间洒落
- 《荒野猎人》— 主角在雪地中渺小如一粒尘土
- 《新世界》— 北美原始自然中的人与土地融合

**提示词核心词**：
```
human figure dwarfed by nature, environmental immersion, looking up through tree canopy,
sun flares through leaves, nature as character, water surface reflections,
figure merged with landscape, cosmic scale human presence, tree canopy bokeh
```

### 6. 🎨 去饱和的宝石色（Desaturated Jewel Tones）

**卢贝兹基的色彩策略：去除过度饱和，保留宝石般的色彩内核。** 画面不艳丽，却令人难忘。

| 影片 | 色彩策略 | 情感意图 |
|------|---------|---------|
| 《荒野猎人》 | 冰蓝灰 + 橙金黄金时段 | 生存的冷酷 vs 记忆的温暖 |
| 《地心引力》 | 深太空黑 + 地球宝石蓝绿 | 宇宙虚空与生命渴望的对比 |
| 《生命之树》 | 温暖琥珀 + 白昼漫射光 | 记忆的柔软与时间的流逝 |
| 《鸟人》 | 暖昏黄后台 + 冷蓝夜空 | 幻觉与现实的边界 |
| 《新世界》 | 饱满翠绿 + 金色阳光 | 伊甸园时代的失落纯真 |
| 《圣杯骑士》 | 加州暖光 + 冷调建筑疏离感 | 现代文明的精神空洞 |

**提示词核心词**：
```
desaturated jewel tones, muted color palette with retained color depth,
golden hour warm amber, cold blue-grey winter light, naturalistic color grading,
color temperature as emotional guide, no oversaturation, organic film-like color
```

### 7. 🙏 仰拍神性（Upward Gaze & Divine Perspective）

**仰望是卢贝兹基最具哲学性的摄影动作。** 从地面向天空/树冠/宇宙的仰拍，赋予画面超越性和神圣感。

| 关键特征 | 说明 |
|---------|------|
| **仰拍天空** | 极度仰拍让天空充满画面，人物化为剪影 |
| **树冠透视** | 镜头穿越树冠向上，光线破碎如星系 |
| **宇宙俯瞰** | 《地心引力》中地球的上帝视角 |
| **地平线缺失** | 仰拍构图中地平线消失，人物飘浮于光与影中 |
| **Malick 式天顶** | Terrence Malick 影片中天空作为上帝意志的视觉显现 |

**代表场景**：
- 《生命之树》— 仰望教堂穹顶，光线从高处倾泻
- 《新世界》— 印第安少女在旷野中仰望天空
- 《荒野猎人》— 垂死的 Glass 望向树冠，光斑弥漫

**提示词核心词**：
```
extreme low angle looking up at sky, figure silhouetted against bright sky,
looking up through tree canopy with light flares, divine upward perspective,
sky as infinite space above figure, celestial overhead framing, Malick-style upward gaze
```

### 8. 💨 意识流剪辑（Stream of Consciousness Editing）

**卢贝兹基的镜头语言与意识流叙事深度绑定。** 尤其在与 Terrence Malick 合作中，影像追随内心而非事件。

| 关键特征 | 说明 |
|---------|------|
| **非线性跳切** | 镜头按情感逻辑而非时间顺序切换 |
| **凝视与漂移** | 镜头停留在人物表情上直到情感流尽 |
| **手持的脆弱感** | 轻微抖动传递内心的不安定 |
| **跳轴** | 故意违反 180° 规则，制造迷失感 |

**代表场景**：
- 《生命之树》— 童年记忆以意识流方式跳切
- 《新世界》— 恋人间的凝视镜头随情感漂移
- 《圣杯骑士》— 好莱坞的疏离感以碎片化影像呈现

**提示词核心词**：
```
consciousness stream imagery, emotionally-driven framing, handheld fragile intimacy,
lingering close-up on face lost in thought, dream-like transitional imagery,
memory and present blending, non-linear visual narrative
```

### 9. ⚡ 数字与胶片的边界（Digital-Film Hybrid Aesthetic）

**卢贝兹基横跨胶片与数字时代，他对两种媒介都有极度敏感的触觉。** 他的数字影像往往具有强烈的"胶片感"。

| 关键特征 | 说明 |
|---------|------|
| **高感光度噪点** | 《荒野猎人》使用 ISO 2500-3200，保留自然噪点 |
| **无处理质感** | 避免过度后期，保留原始光影的质感 |
| **胶片颗粒倾向** | 数字影像中模拟胶片颗粒的有机质感 |
| **宽容度优先** | 选择动态范围最大的设备以保留高光和暗部细节 |

**设备演变**：

| 时期 | 主力设备 | 代表作 |
|------|---------|-------|
| 1991–2003 | 35mm 胶片（Arriflex、Panavision） | 《睡眠》《你妈妈也一样》《人类之子》 |
| 2006–2012 | 35mm + 数字混合 | 《新世界》《生命之树》 |
| 2013–2014 | ARRI ALEXA + 自定义光学系统 | 《地心引力》（Light Box 特制系统） |
| 2014–2015 | ARRI ALEXA 65 + Leica Summicron-C | 《鸟人》（假一镜到底） |
| 2015–2016 | ARRI ALEXA 65 + Ultra Prime | 《荒野猎人》（ISO 2500+ 自然光） |

**提示词核心词**：
```
ARRI Alexa digital cinematography, natural film grain texture, high ISO noise preserved,
wide dynamic range capture, no over-processed look, organic sensor quality,
cinematic texture with digital clarity, film-like color response
```

### 10. 🌍 宇宙人文主义（Cosmic Humanism）

**卢贝兹基的摄影有一种罕见的哲学维度。** 他的镜头始终在问：人类在宇宙中是什么？在自然中是什么？

| 关键特征 | 说明 |
|---------|------|
| **人与宇宙的尺度对比** | 单个人类渺小于星球、森林、海洋 |
| **神圣感的视觉化** | 光线、仰角、空间感共同创造超验体验 |
| **存在主义构图** | 角色被存在本身的宏大所包围 |
| **无声的宇宙问题** | 画面提问但不回答 |

**代表场景**：
- 《地心引力》— 孤独宇航员在地球前的宇宙尺度
- 《生命之树》— 人类诞生在宇宙大爆炸的画面序列中
- 《荒野猎人》— 玻璃在雪原冰雾中奄奄一息，宇宙毫不在意

**提示词核心词**：
```
cosmic scale human figure, solitary human against vast universe, existential framing,
divine light quality, transcendent atmosphere, humanity dwarfed by creation,
philosophical visual question, figure against infinite space or nature
```

## 工作流程

### 当用户需要卢贝兹基风格图像时：

1. **确认场景**：了解场景类型（室内/室外、时间、情绪、是否有自然光条件）
2. **匹配影片**：从卢贝兹基作品中找到最匹配的视觉参照（读取 `references/filmography-analysis.md`）
3. **确定技法**：选择 2-3 个核心技法作为画面支柱
4. **组装提示词**：从 `references/style-prompts.md` 中选取基础模板，根据需求调整
5. **适配模型**：根据目标 AI 模型做微调

### 当用户需要自然光打光方案时：

1. **分析环境光源**：找出场景中现有的自然光条件（时间、天气、位置）
2. **评估黄金时段可用性**：卢贝兹基最优先考虑魔幻时刻
3. **确定不补光原则**：先考虑不使用任何人工光
4. **最低限度人工辅助**：如必须补光，用最小、最自然的方式
5. **输出方案**：描述自然光角度、质感、色温、场景调度建议

### 当用户需要运镜建议时：

1. **理解场景情感**：卢贝兹基的运镜永远追随情感
2. **选择运镜工具**：斯坦尼康（有机感）、长臂（弧线）、手持（脆弱）
3. **设计弧线路径**：运镜路径通常是弯曲的，不走直线
4. **考虑长镜头可能性**：能不剪就不剪
5. **参照影片**：引用具体影片中类似运镜的参照

```
**Scene（画面）：**
[完整的英文画面提示词 — 涵盖构图、主体、环境、角度]

[Style + Scene 合并]

💡 打光笔记：[简要说明自然光逻辑]
🎨 色彩笔记：[简要说明色彩意图]
📷 镜头笔记：[焦段与运镜建议]
```

---

## 重要原则

- **所有提示词必须是英文**：AI 图像生成工具对英文效果最佳
- **Style 与 Scene 分离**：用户可保持 Style 不变，只改 Scene
- **自然光优先**：在任何情况下，提示词中优先强调自然光/环境光
- **超广角为默认**：卢贝兹基默认用 14–21mm 区间，除非有特殊原因
- **保留噪点和不完美**：卢贝兹基的美是原始的，不要过度"完美化"提示词
- **强调人与环境的尺度关系**：这是卢贝兹基最核心的视觉命题
- **禁止三点打光**：绝对不在提示词中加入 three-point lighting
- **技术准确性**：设备型号、镜头焦段、拍摄条件必须准确

## 模型适配提示

### Midjourney
- 加 `--raw` 获得更真实的自然光质感
- 用 `--ar 239:100` 模拟宽银幕，或 `--ar 1:1` 模拟 IMAX 格式
