# 四维内容规范

### 场景

描述具体空间、时间、前置事件、人物关系和关键环境声。将建立空间与氛围所需的视听设计整合在本维度：

- 指定有叙事意义的景别、机位、构图和镜头运动，如远景建立环境、低机位制造压迫、缓慢推近逼近情绪、手持轻晃表现失控。
- 指定主光方向、光质、明暗对比、色温或环境光源，如冷色窗光切过侧脸、暖色台灯保留最后一点安全感。
- 说明镜头和灯光为什么适合这一瞬间，但用成片式描述表达，不写理论讲解。
- 只选能被画面执行且推动叙事的细节，避免堆砌摄影术语。

### 人物状态

描述人物此刻的身体状态、心理状态、说话目的和不能直说的阻碍。将揭示人物变化的视听设计整合在本维度：

- 写出可见反应，如肩膀绷紧、目光躲闪、手指攥住衣角、呼吸压在胸口。
- 必须写清“想通过这句话达到什么”以及“为何不能直接表达”。
- 需要时描述焦点、构图或光影随人物状态发生的变化，如焦点由手中的信移到湿润的眼睛，人物从画面边缘走入半明半暗的交界。
- 不虚构无关身世、额外角色、剧情反转或世界观。

### 发声方式

把情绪转成配音模型可执行的声音动作，并让声音变化与镜头节奏相互配合：

- 从音量、语速、气息、稳定度、颤抖、咬字、重音、停顿、音高和尾音中选择必要项。
- 明确变化过程，例如“开头气声压低，中段因急切略微加速，到关键词前突然停半拍”。
- 可写声音与镜头的同步关系，如“镜头推近时音量不升反降”“焦点落到眼睛时尾音开始发颤”。
- 避免互相矛盾或过载的指令；优先使用少量、精准、可执行的动作。

### 台词

给出最终可直接朗读的台词，并用标点塑造表演节奏：

- 保留用户原台词和原意，仅在能改善表演时轻调标点；除非用户要求改写，否则不要擅改措辞。
- 用户未给出台词时，根据说话目的生成一句简短、自然、可说出口的台词。
- 逗号用于短分句，省略号用于犹豫或思绪中断，破折号用于突然转折；问号和感叹号仅在情绪确实需要时使用。
- 台词本身不要夹入摄影、灯光、动作说明；这些信息应留在前三维。
