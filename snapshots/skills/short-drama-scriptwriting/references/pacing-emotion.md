## 1. 核心情绪与剧情变奏

先锁定一条带矛盾的情绪内核：

```text
主角渴望____，却因为____反复遭到____；
全剧最终要用____证明他/她真正需要的是____。
```

围绕同一内核安排不同剧情，不围绕同一桥段循环。每个序列选择不同的情绪功能：

| 阶段 | 情绪功能 | 典型作用 |
|---|---|---|
| 建立 | 第一次展示缺口 | 让观众明确主角最痛或最渴望什么 |
| 否定 | 外界拒绝这份渴望 | 建立不公、误解或关系裂缝 |
| 加深 | 换一个场域再次验证 | 说明问题不是偶然，而是角色模式 |
| 暂时满足 | 给主角一口真正的甜或胜利 | 让观众知道理想状态的滋味 |
| 污染 | 满足附带条件、谎言或代价 | 让旧方法暴露问题 |
| 反转 | 主角改变对情绪缺口的理解 | 从等待别人给予，转向主动选择 |
| 证明 | 高潮行动完成内核 | 用行为而非台词给出最终情绪回报 |

每次变奏至少更换两个维度：场域、关系对象、策略、信息差、代价或结果。让不同剧情像同一旋律的不同编曲，而不是同一个片段反复播放。

## 2. 双轨节奏

分别标记每集和关键场次：

- **外部轨**：事件、冲突、信息的密度；
- **内部轨**：关系与情绪变化的重量。

不要把“快”理解成不停争吵、追杀和揭底牌。高密度之后需要短暂呼吸，才能让下一次高点可感。至少设计一处有意义的错位：情节松但情感重，或情节紧但情感轻。

## 3. 场景机制与情绪呼吸

节奏不只由字数、场数和反转数量决定，也由“戏以什么方式发生”决定。连续场次都让人物站着对骂，即使台词很短也会显得单调。

为每个核心场景标记一个主要机制：现实任务被阻挠、公开场合维持体面、隐瞒与试探、被迫合作、物件/位置争夺、第三人误读、离开与挽留、沉默者用行动改局等。相邻场次至少改变场域、机制、胜负方式或情绪落点中的一项。

控制一个场景的呼吸形状：

```text
处境先成立 → 人物采取策略 → 对方反应或误读
→ 情绪转向 / 权力变化 → 选择或动作落地 → 余震
```

这不是固定拍表。冲击场可以在动作落地后立即切断；重关系戏可以把重点放在误读、改口和余震。重大揭示后先给一个可表演反应，再决定是否补解释。用户反馈对白僵硬或“太 AI”时，读取 `human-dialogue-emotional-rhythm.md`。

## 4. 关系线推进

若 CP/搭档/宿敌关系是核心卖点，让双方在前段尽早发生有后果的正面互动。

每场关键关系戏至少改变一项：

- 信任；
- 权力；
- 距离；
- 共同秘密；
- 欠债或承诺；
- 对彼此的判断；
- 下一次选择的成本。

不强制所有关系都写成“双强博弈”。一方可以暂时弱势，但必须拥有能改变局势的欲望、秘密、选择或拒绝权。删除任一方后，若主线完全不受影响，说明该关系角色仍是工具。

“宿命感”要通过可回收细节建立：下意识动作、重复物件、错误称呼、身体记忆或双方不同解释的共同事件。不要只靠设定宣告命中注定。

感情线的具体写法（双人发动机、推拉、亲密度阶梯、强势方软肋外显、藏漏明、物件回收）见 `romance-tension.md`。每条主要感情线在中段应有亲密等级的升降，不能只靠斗嘴、吃醋和倒追重复；感情高点后不立即被外部信息、系统提示或玩笑拆台。

## 5. 爆点与反转

把爆点定义为“观众对目标、关系、规则或代价的理解发生变化”，而不是音量更大或突然来人。

有效升级包括：

- 主角的策略被看穿；
- 局部胜利附带更高代价；
- 对手掌握新资源或合法性；
- 盟友目标与主角冲突；
- 世界规则暴露隐藏边界；
- 关系中的善意被误读，或敌意显露保护功能；
- 观众领先角色半步，等待角色发现真相。

不要按固定场数机械插反转。先建立清楚预期，再在预期即将完成或失效的位置换挡。反转后必须改变角色行动，否则只是信息烟花。

## 6. 虐爽甜的因果

### 虐

让虐点来自人物选择、对手策略和既有规则，不让角色靠降智受苦。虐点必须改变代价或关系。

### 爽

让爽点来自主角行动、前置布局、能力边界内的反制或伏笔回收。不要让外援突然解决一切。

### 甜

让甜点成为关系表现：为对方承担具体成本、看穿伪装、尊重选择、共享秘密、改变计划。不要只靠“我爱你”和偶然肢体接触。

虐后需要情绪出口，但出口不必固定在 3–4 场内。依据单集时长、受众承受度与付费节点安排；持续压抑时至少给观众信息优势、小胜、关系确认或反击预告。

## 7. 集末拉力

集末钩子优先使用：

- **动作未完成**：门打开了，但观众还没看到门后；
- **不可逆决定**：角色说出或执行改变关系的选择；
- **期限启动**：一个可验证倒计时开始；
- **身份/证据揭示**：揭示立刻改变下一集行动；
- **关系改写**：称呼、站队、背叛、保护或拒绝改变双方位置；
- **局部答案 + 更大问题**：回答本集问题，同时暴露更深层因果。

让钩子绑定人物命运或行动。仅展示一个神秘物件、陌生脸或新设定，而未说明其为何重要，拉力通常不足。

钩子形态要有变化。可以落在一句关系改写的对白、一个完成到一半的动作、一个让人物来不及消化的反应，或一个已经启动的选择。爆点出现后不要继续用台词总结意义；让观众停在“生活已经被改变”的瞬间。

## 8. 对白烈度与情绪后果

对白烈度由“具体伤口 + 对手筹码 + 当下代价 + 被迫选择”产生，不由音量、感叹号或连续辱骂产生。按 `dialogue-conflict-density.md` 标记 1–5 级情绪值：让场景从边界被碰逐步升级到核心伤口暴露或不可逆选择，并在峰值后保留一个动作或短句承接余震。

检查情绪是否改变剧情：一句话若只让角色更生气，却没有改变信息、关系、权力、计划或行动，仍属于空转。强情绪场必须同时拥有具体交锋目标和场尾代价。

情绪高点后至少检查一次余震：称呼是否改变、习惯动作是否被拒绝、谁停止替谁做事、谁从房间或关系位置退出。余震不是解释“我受伤了”，而是让刚才的事件改变下一件日常小事。

## 9. 自检

- [ ] 本集外部轨和内部轨分别处于什么强度？与上一集是否变化？
- [ ] 本集服务哪条核心情绪，承担建立、否定、加深、满足、污染、反转或证明中的哪一种功能？
- [ ] 与上一次触碰同一情绪相比，是否至少更换两个剧情维度？
- [ ] 关系戏是否改变信任、权力、距离或选择成本？
- [ ] 感情线是否有推与拉、可拍表现，强势方是否露出软肋，亲密等级是否升降？（详见 `romance-tension.md`）
- [ ] 爆点之后，角色是否采取了不同动作？
- [ ] 虐点是否有因果，爽点是否由主角挣得，甜点是否有具体成本？
- [ ] 本集是否给出阶段性回报，而非只挖坑？
- [ ] 集末钩子是否自然启动下一集，而非强行中断？
- [ ] 相邻核心场景是否更换了冲突机制、胜负方式或情绪落点？
- [ ] 关键揭示后是否留有反应与余震，而不是立刻解释干净？
