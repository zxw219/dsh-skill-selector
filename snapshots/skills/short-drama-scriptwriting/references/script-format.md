# 剧本正文格式（场景 + 动作 + 台词 + 情绪）

本 skill 的剧本格式综合两份样本：《短剧剧本格式规范》提供行业通行的整体结构、场景标注、情绪提示、钩子表和“前 3 秒 / 强情绪 / 口语短句”要求；《格式范文》提供可直接交稿的正文写法（场次编号、人物行、△ 动作、OS / VO / 闪回、体量限制）。两者互补，不冲突处合并使用，写法不同处按本文件取舍。用户给出样例或另行指定格式时，以用户格式为准。

## 1. 整体结构

一份完整剧本按下表四个部分组织。各阶段按需输出，不要求一次写全。

| 部分 | 内容 | 要求 |
|---|---|---|
| 封面页 / 剧本信息 | 剧名、题材类型、总集数、免费集数（一般 8–10 集）、单集时长（通常 1–3 分钟）、预估总时长、一句话简介、对标作品（勿抄袭）、备案号（平台要求时） | 参数以用户或平台为准，未给定时写明假设 |
| 故事大纲 | 完整主线，500–2000 字，可按起承转合 | 写清主线、关键反转、结局情绪 |
| 人物小传 | 至少覆盖前 10 集出场的主角、主要反派、重要配角 | 姓名、性别、年龄、身份、外表、成长经历与性格、动机与目标，并标明人物关系 |
| 分集大纲 | 每集一句话梗概 + 本集钩子 | 每集结尾留强钩子；可另附冲突钩子表（见第 9 节） |
| 正文剧本 | 场景 + 动作 + 台词 + 情绪 | 见第 2–7 节 |

## 2. 正文逐场格式

```text
第 X 集（片长约 X 分钟）

场X-Y 【内·夜】 地点
人物：角色甲（女，28 岁），角色乙
△ 动作或环境描写。
角色甲（情绪 / 动作）：台词
角色乙（情绪）：台词
—— 镜头、音效或转场提示。
```

| 要素 | 写法 |
|---|---|
| 集标题 | `第 X 集` 单独成行；可加集级片长，如 `（片长约 2 分 10 秒）`。片长只写在集标题上 |
| 场次行 | `场X-Y 【内/外·日/夜/傍晚】 具体地点`，X 为集号，Y 为本集场序，从 1 起按时间顺序排列。紧接上一场时在末尾加“（紧接上场）”；跨越时间时加一个简短标注，如“（次日）”“（三日后）”，不与地点混写在同一括号里 |
| 人物行 | `人物：` 列出本场出场或发声的全部角色。首次出场标性别与年龄，之后只写名字；电话音、画外音角色也列入并注明。纯屏幕信息场（手机截图、监控画面等无实体人物出镜）写作 `人物：（无出场人物，屏幕信息）`，地点写成“内·手机屏幕画面”这类明确载体 |
| 动作行 | 以 `△` 开头，单独成行，写人物动作、环境和可见事件，见第 3 节 |
| 台词行 | `角色名（情绪 / 动作）：台词`，单独成行，不加引号；不同人物的台词各自成行，见第 4 节 |
| 镜头 / 音效 / 转场 | 以 `——` 开头，单独成行，如运镜、切景、音效、特效、黑场、片名 |
| 内心独白 / 旁白 | `角色名（情绪）OS：…`、`VO（语气）：…`，见第 5 节 |
| 闪回 | `【闪回】` … `【闪回结束】`（或 `【闪出】`），见第 5 节 |

场次行不得追加逐场秒数或预计时长。若用户要求时长分析，另列，不写入剧本正文。

每场围绕一个主要争夺目标，场尾必须落在一个钩子、反转点或递交给下一场的动作上（第 7 节）。

## 3. 动作与镜头提示

`△` 动作行只承担“看得见、听得见”的内容：

- 一个 `△` 行写一个连续的动作节拍或一条信息，可连续使用多个 `△`；不把“端起、喝、放下”拆成三行，也不在一行里塞三个不同动作；
- 每场第一个 `△` 交代环境并点出在场人物的名字；新出现的物件、服装、伤势写清关键外观，保证前后一致；多人同框时点名，不靠“他”“她”指代；
- 不写“她很绝望”“他内心愧疚”等抽象心理，改写为眼神、手部、物件和距离；情绪提示交给台词括号（第 4 节）；
- 禁用意图与推断词：企图、试图、想要、显然没料到、以为；凡是摄像机拍不到的意图判断都不写；
- 禁用偷懒的极端副词与叠词：死死、狠狠、紧紧、疯狂、极度、极其、万分、拼命、歇斯底里。台词、括号情绪词、弹幕不受此限；
- 允许正常人能读懂的情绪词，如“满脸焦急”“眼眶通红”；禁止为回避心理词造出解剖式描写，如“嘴角肌肉向两侧拉伸”“喉结连续吞咽两次”。不写抽象心理，也不写病理式拆解；
- 纯氛围动作行（无人物动作，只有环境或光线）每场不超过 1 行，且必须承担 `text-quality-originality-check.md` 第 6 节允许的四种功能之一（交代空间机制、承载情绪、埋伏笔、制造压迫）；
- 不为凑体量给角色硬加动作（如无缘无故砸东西）；体量靠实质冲突、配角反应和道具互动补足；
- 特效、系统界面等需要说明时，写在 `△` 行末尾的括号里，如 `（特效：金光环绕）`。

`——` 镜头提示只在服务节奏或情绪时使用，每场建议不超过 2–3 条：

- 常用：切近景、切特写、慢镜头、快切、逆光剪影、黑场、转场、音效（雷声、心跳声）、片名出现；
- 情绪高点用特写或慢镜头承载；信息与转场用中景、快切；
- 每条提示要有叙事理由，禁止为“镜头感”堆砌术语；
- 台词内容不写进镜头提示，镜头提示里只写画面或声音的处理。

## 4. 台词与情绪

台词行承担“情绪”这一要素：

- 格式：`角色名（情绪 / 动作）：台词`。括号写给演员和导演，用强而具体的情绪词，如震惊、怒、冷笑、哽咽、决绝、嗤笑、慌乱；需要时写成“情绪 + 动作”，如 `（转身，决绝）`；
- 括号保持简短，通常不超过 10 个字；情绪没变的连续台词可省略括号。不要每句台词前都加同一种情绪括号，也不要用“低吼”“嘶哑地”“咬牙切齿”之类花哨标签批量替换，那会变成另一种模板；
- 括号写情绪与表演方向，`△` 行写可见证据，台词写口语。重要的情绪转折最好三者呼应：括号标出情绪，动作给出证据，台词说出人物肯说的那部分，说不出的留给潜台词；
- 台词口语化、短句、大白话，适配竖屏快速刷看。超过 35 字的台词若没有内部转折、旧账或逼迫，拆开并插入对方反制；
- 不同人物的台词不得合并在同一行；多人同声说同一句话时，可写 `甲 / 乙 / 丙（低语诅咒）：台词`；
- 每集台词（含旁白）默认不超过 300 字，用户或平台另有标准时从其标准；
- 强情绪词服务于人物，不等于全程吼叫、辱骂或堆叠感叹号；感情场的克制写法见 `romance-tension.md`。

## 5. 声音、内心独白与闪回

| 标记 | 用法 |
|---|---|
| `角色名（情绪）OS：…` | 人物内心独白，观众真实听到的声音 |
| `VO（语气）：…` | 旁白（上帝视角交代背景）、画外音（人未到声先到）、电话另一端、人物不出镜的声音 |
| `（电话音）` `（系统音）` `（广播）` | 标注非现场可见声源，放在角色名之后 |
| `【闪回】` … `【闪回结束】` | 回忆开始与结束成对使用，注意控制时长；闪回内部沿用同一场次格式 |
| 字幕 | 仅在界面、时间地点或项目明确需要时使用，写成动作行，如 `△ 屏幕浮现字幕：三年后。` |

交付 Word 文档时，旁白可按范文习惯居中、标红；纯文本交付时保持 `VO：` 行即可。

不要把普通心理描写全部改成 OS。只有当声音提供新信息、与画面形成错位或属于项目固定形式时使用；能用一个动作行证明的情绪，优先写动作。OS / VO 不得变成大段说明书。

示例：

```text
△ 林妍的拇指悬在“删除聊天记录”的确认键上，屏幕微光映在她眼底。
林妍（压低声音）OS：这次是真的。
△ 她按下“取消”，肩膀松下来。
```

画面与声音互相矛盾，才产生增量。

## 6. 写作规则

- 让动作与对白交替改变局势，避免连续多行只是环境或说明；
- 让一场戏围绕一个主要争夺目标展开；
- 写正文前按 `dialogue-conflict-density.md` 列出双方目标、筹码、伤口和有效信息单元；交锋梯按场景需要使用，不固定拍数；
- 用户反馈僵硬、无聊或“太 AI”时，按 `human-dialogue-emotional-rhythm.md` 先建立人物声纹、不能直说的话、场景机制和情绪转向；
- 让人物以策略说话：试探、诱骗、威胁、安抚、讨价还价或回避；让对方反击、转攻、加价、半答或用动作拒绝；
- 每轮交锋整体产生增量；多数实质对白至少推进一项，允许少量能完成情绪转向或给下一击蓄力的短反应；
- 关键揭示后 1–3 拍内必须发生策略、关系、权力或动作后果；
- 删除角色互相复述已知设定、直接解释主题和重复动作含义的对白；
- 用物件、空间距离、称呼、视线、停顿和选择表达潜台词；
- 避免所有角色使用同样的完整论证、对称金句、反问和主题总结；用人物的体面、禁区与说话习惯限制表达；
- 在场尾完成价值变化或递交下一场动作；
- 单集场景默认不超过 3 个，同场人数和转场也要控制，给服化道和群演成本留余地；
- 按单集时长估算场次和台词量。中文对白与动作的成片速度受表演、停顿和剪辑影响，不能只按字数机械换算。

## 7. 节奏与钩子

- **前 3 秒定生死**：每集开场的第一个 `△` 或第一句台词就抛出冲突或悬念，不用环境铺垫和人物介绍开场；
- 每集必须有阶段性回答和向前拉力，且只设一个主钩子；
- 每场场尾落在钩子、反转点或递交给下一场的动作上，写在该场最后 1–2 行里，不另加标签；
- 每集末尾在正文之后加一行 `【集末钩子】一句话写明悬念或反转`，方便与分集大纲和冲突钩子表对照。用户不需要标签时可省略，钩子本身仍由末场最后 1–2 行完成；
- 断点靠前：停在动作落下、宝物现世、大门被推开的一瞬，全场的反应留给下一集开头，不在同一集结尾把众人的反应台词写完；
- 钩子必须是本集已经戏剧化呈现的未完成动作、秘密揭示、不可逆决定、更大危险或关系反转，与本集人物目标和因果链直接相关；
- 禁止用“未完待续”“新的危机即将到来”等没有具体人物、行动或代价的空泛收尾；
- 情绪高点用特写、慢镜头或静默承载；感情场用耳根、手指、物件、距离、停顿承载“漏”，见 `romance-tension.md`；
- 里程碑之后至少留一个余震动作行或反应台词，再进入下一场；
- **体量核对**：默认单集 500–700 字、不超过 3 个场景、台词（含旁白）不超过 300 字，单集时长通常 1–3 分钟；用户或平台给定标准时以其为准，未给定时写明假设。交付时报告每集字数、场景数、台词字数（含旁白）；体量明显不足时先补实质冲突和反应拍，不用环境描写注水；偏厚时删复述和重复情绪宣告。

## 8. 自伤与极端情节

涉及自杀、自伤或暴力的情节：不展示方法细节和过程，不美化，不作为解决办法；优先用黑场、声音、事后画面处理，把重点放在人物与后果上。平台规则可能变化，写“待核实”。

## 9. 各阶段输出

| 阶段 | 最低输出 |
|---|---|
| 概念 | Logline、核心卖点、受众回报、升级空间、名场面候选 |
| 梗概 | 主角、激励事件、主要升级、高潮选择、结局情绪 |
| 立项书 | 按 `pitch-document.md` 输出项目参数、大纲、人物；封面页 / 剧本信息字段见第 1 节 |
| 分集大纲 | 集号、本集一句话梗概、核心冲突、观看问题、升级、阶段回答、结尾钩子、情绪峰值、时长 |
| 冲突钩子表（可选） | 集数 / 本集冲突 / 结尾钩子 / 情绪峰值，用于整体把控每集冲突与悬念 |
| 剧本正文 | 完整分场正文，使用本文件格式；每集以钩子收尾 |
| 终审 | 结论、定位到集 / 场 / 行的问题、影响、修改动作、必要短示例 |

冲突钩子表示例（原创）：

| 集数 | 本集冲突 | 结尾钩子 | 情绪峰值 |
|---|---|---|---|
| 1 | 女主在婚宴上被当众撤掉名牌 | 她拆开信封，里面是新郎父亲的亲笔字据 | 震惊 |
| 2 | 新郎当众否认字据 | 字据背面的日期比婚约早三年 | 反转 |

## 10. 示例（原创，仅示范格式）

```text
第 1 集（片长约 2 分钟）

场1-1 【内·夜】 公寓客厅
人物：周叙（男，31 岁），陆宁（女，27 岁）
△ 客厅只剩一盏落地灯，周叙蹲在纸箱旁封箱，陆宁抱着一盆绿萝站在门边。
△ 胶带撕到一半，周叙的手停在半空，目光落在箱口露出的一只旧马克杯上。
周叙（没抬头）：这只杯子，你要带走吗？
陆宁（语气很淡）：你不是一直嫌它丑。
△ 周叙把杯子拿出来，用袖口擦掉杯沿的灰，放到窗台上，没有回答。
—— 镜头切特写：陆宁抱着绿萝的手指收紧，视线落在窗台的杯子上，又移开。
陆宁（压住哽咽）OS：别问。问了我就走不了了。

场1-2 【外·夜】（紧接上场） 公寓楼下
人物：陆宁，周叙，出租车司机（电话音）
△ 陆宁拖着行李箱走出单元门，周叙追到台阶上，手里提着那只旧马克杯。
周叙（喘着气）：杯子，拿着。
陆宁（冷笑）：周叙，你现在才想起它丑不丑？
△ 周叙的手悬在半空，没有再往前递。
△ 陆宁的手机亮起，屏幕上是“尾号 2208 的司机来电”，她接起，背过身去。
出租车司机（电话音）：姑娘，到楼下了，哪栋？
△ 周叙低头，从马克杯底摸出一枚旧戒指，攥进掌心，指节发白。
—— 黑场，雨声起。
【集末钩子】杯底藏着一枚戒指，周叙把它攥进掌心，没有叫住正在离开的陆宁。
```
