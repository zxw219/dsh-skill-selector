## 1. 使用边界

在以下情况读取本文件：

- 用户反馈“剧情又变成破案了”“越写越像悬疑/推理”“老是查线索、取证、对质”；
- 题材不是悬疑/推理，但大纲或正文出现监控、录音、指纹、伪造字条、不在场证明、内鬼、警方介入等成串桥段；
- 审核建议或对标剧节拍链中出现“局中局、设局与破局”，需要判断是否会挤占感情线、家庭线或事业线；
- 立项时选择的题材需要长期保持稳定。

明确选择悬疑、推理、刑侦类题材时，本文件仅用于控制比例，不禁止侦破手段。

## 2. 为什么容易滑向破案

不是某个词触发，而是通用高密度方法本身有一套“信息差机器”，题材没有被锁死时，模型会用它补空：

1. **反转、揭示、秘密、隐瞒、信息差**是全流程的主要动力词，而“靠近、疏远、放下、被看见”这类情感动作词较少；没有明确驱动类型时，信息驱动最容易接手。
2. **对白筹码**常列“钱、身份、证据、关系、生死”，“证据”是其中最具体、最好写的一项，写着写着整场戏变成出示证据与反驳。
3. **对标案例**若是秘密曝光链（隐瞒 → 接近暴露 → 现场曝光），用来学高密度时会带入同一种结构。
4. **对标剧的局中局**（设局、录音、监控、反间、伪造字条）一旦被 1:1 继承，中后段就容易变成取证与破局。
5. **审核报告或改稿建议**常把“逻辑不严”改成“加录音笔、监控盲区、刑侦式套话”，每次修补都会增加一点侦破色彩。
6. 单集需要“集末钩子”，最省力的钩子是“真相即将揭晓”，于是悬念被写成谁做的、证据在哪。

## 3. 先锁驱动类型

立项时选定一个主驱动，其他只做辅助：

| 驱动类型 | 观众追问 | 推进单位 |
|---|---|---|
| 情感关系驱动 | 他们会不会靠近，代价是什么 | 亲密等级升降、推拉、选择 |
| 事业/利益驱动 | 主角能不能赢下资源与地位 | 资源、筹码、规则改变 |
| 家庭/亲情驱动 | 亲人会不会认回、原谅、离开 | 承认、亏欠、修复 |
| 悬疑侦破驱动 | 到底是谁、为什么、真相是什么 | 线索、假设、验证、翻案 |

规则：

- 主驱动之外的类型最多占辅助，同一序列内只用一种作主线。
- 未选择“悬疑侦破驱动”时，不得把一个序列的主要冲突设计成“找线索 → 取证 → 对质 → 还原真相”。
- 需要一个案件外壳时（绑架、构陷、诈骗），让它成为压力场，把情感、事业或家庭选择推到台前，而不是让观众开始推理。

## 4. 信息差的两种用法

- **情感信息差**：观众比角色早知道（他不知道她是谁），乐趣来自“反应”和“隔着屏幕替他们着急”。这是短剧的强项，可以多用。
- **解谜信息差**：观众和角色共同缺少答案，乐趣来自“推理与验证”。这是侦破类的核心，非侦破题材不要当主线。

写法自检：本场结束，观众关心的是“他们之间会怎样”，还是“到底是谁干的”？若是后者且题材不是悬疑，改写。

## 5. 破案外壳清单

出现以下元素成串（同一序列内 3 项以上，或连续 3 集以上）时，提示可能已漂移：

- 监控、摄像头、录音笔、针孔设备、行车记录；
- 指纹、笔迹、字条、伪造文件、钢笔/香水等“物证细节”；
- 不在场证明、时间线核对、口供、当面对质；
- 内鬼、卧底、买通证人、雇佣打手；
- 警方介入、立案、拘留、翻案；
- “局中局”“将计就计”“引蛇出洞”作为连续多集的骨架。

单个元素不成问题。问题是它们占据主要篇幅，且和感情线、家庭线、事业线脱钩。

## 6. 换轨：把侦破手段改成情感、事业或家庭事件

| 侦破写法 | 换轨写法 |
|---|---|
| 主角靠录音/监控反杀 | 主角靠“对方最在意的一个人”的选择反杀，或让对方在自己的价值上败北 |
| 用证据当筹码 | 用关系、自尊、选择权、时间、物件当筹码，证据只做辅助 |
| 揭穿伪造字条 | 让“被信任还是被怀疑”成为选择：谁在没有证据时选择相信他 |
| 绑架/构陷后查凶手 | 危机让各条感情线各自做出选择，谁来救、怎么救、付出什么 |
| 设局—破局连续多集 | 一场设局，多场“设局对关系的后果”：谁受伤、谁看见谁的另一面 |
| 读心/预知一秒看穿 | 金手指带来的知识让主角面对“听到真话之后要不要相信”的两难 |

## 7. 悬念与反转的改写

- 悬念：把“谁干的、证据在哪”改成“她会不能原谅他吗”“他会不会为她放弃”“这次亲人会认出来吗”。
- 反转：把“真相反转”优先改为“关系反转”和“选择反转”：一个人在关键时刻做了与人设预期相反、却成立的选择。
- 集末钩子：不一律停在“真相即将揭晓”，可以停在称呼、物件、选择或余震上。

## 8. 写前问题与写后检测

写前（每个序列）：

```text
本序列主驱动：情感 / 事业 / 家庭 / 悬疑侦破
观众此刻追问的是：
主要推进单位是：
若存在案件外壳，它把哪条关系线推到台前？
```

写后检测（是诊断，不是配额）：

- 破案外壳元素在本序列出现几项，占几集；
- 主要对白筹码是否长期只有“证据 + 反驳”；
- 感情线、家庭线是否因案件外壳被连续搁置；
- 集末钩子是否连续多集是“真相将揭晓/有人闯入”；
- 审稿建议是否把非侦破问题改成了侦破手段。

## 9. 修复流程

1. 标出漂移起点：第一次出现“取证/设局/对质”成串的集数。
2. 回到主驱动：写出这一段要推进的关系、事业或家庭变化。
3. 合并或删减：把连续多集的设局与破局压缩为 1–2 集，把节省的篇幅换成关系事件。
4. 换轨：用第 6 节对照表替换侦破手段。
5. 检查感情线、家庭线、事业线是否在案件外壳期间仍有亲密等级或选择的变化。
6. 收束时给出关系后果，而不是只公布真相。
