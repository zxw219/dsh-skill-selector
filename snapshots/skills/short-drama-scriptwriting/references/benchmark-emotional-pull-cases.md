# 情绪拉扯对标例文拆解（去原文）

## 使用边界

- 与 `benchmark-case-dialogue.md` 并列存放于 `references/`。只在用户明确对标、或感情戏/家庭情绪被反馈"弱、没感觉"时读取。
- 只迁移机制，不复刻台词、人物、情节。迁移时至少更换：身份差类型、秘密性质、关键物件、冲突来源。
- 两份样本类型不同，不要混用：样本 A 用来学男女主拉扯，样本 B 用来学亲情/家庭情绪与扮猪吃虎节奏。

## 1. 样本定位

| | 样本 A：古言双向奔赴（45 集） | 样本 B：现代认亲打脸（40 集） |
|---|---|---|
| 设定 | 女主伪装痴傻乞丐，男主不知其为郡主 | 首富夫妇扮清洁工，考验儿子与未婚妻 |
| 核心情绪 | 被偏爱、被看见、为对方隐忍 | 被认回、被护住、亲情补偿 |
| 观众信息位置 | 观众早于男主知道女主身份 | 观众早于儿子知道父母身份 |
| 男女主拉扯参考价值 | **高**（本文重点） | **低**（CP 线弱，见第 5 节） |
| 家庭情绪参考价值 | 中 | **高** |

## 2. 样本 A：男女主拉扯的六个机制

### A1 信息差让同一句话有两层含义

女主装傻说"脸疼，吹吹"，字面是傻话，观众读到的是心疼。男主的反应（耳根发红、悄悄躲一下、被喂后咬一小口）是给观众的"他动心了"的表现。

迁移要点：让一方持有另一方不知道的秘密，把亲密小动作写成"表层任务 + 底层心意"，并让接收方的身体反应泄露心动，而不是让人物说"我心动了"。

### A2 "推"来自爱，不来自冷漠

男方多次拒绝更亲近：分房睡、说"你清醒之前我绝不碰你，好了以后去留随你"。女方每次"拉"（"不走，一起"）都撞上这层推。拒绝有正当理由，且每次拒绝反而成为爱的表现，所以拉扯不伤感情，反而累积好感。

迁移要点：给"推"的一方一个不得不推的理由（责任、自尊、怕对方吃亏），让"推"本身可爱。

### A3 亲密靠物件与轻动作，不靠表白

包子（第一集口头承诺"每天都有"，后面反复兑现）、吹吹、糖葫芦、糖人、把桂花糕递到嘴边、交出首饰盒（信任的物证）、玉佩（回收旧缘）。每个物件都走"承诺 → 兑现 → 回收"。

迁移要点：为男女主各设 2–3 个可反复出现的小物件，让关系升级体现为物件的用法变化（从被给予，到互相喂，到托付）。

### A4 对称的保护欲，但互相半知

他挡在她身前、说"辱我可以，辱我妻子不行"；她暗中扫清债主、踩碎契书替他挡下跪。双方都在护着对方，但一方不知情，所以观众既甜又期待揭晓。

迁移要点：保护行为要有具体代价和可见动作，不要只写"我会保护你"。

### A5 曝光后的裂痕用称呼、距离、动作，不靠吼

身份曝光后，男主称呼从"绾绾"变成"郡主殿下"，甩开她伸来的手；后面她只谈公事，他签完契书头也不回地走；牢里他说"这地方脏，别污了你的鞋"。裂痕靠称呼、客气和退后一步表达。旁观者（侍卫"负心汉"）用喜剧化吐槽替观众说话，给情绪降压。

迁移要点：关系变冷时，先改称呼与距离，再改台词内容；让一个旁观角色说出观众想说的话。

### A6 "为你好而推开你"是最高级的拉扯

求亲一段：男主不肯让她为嫁给自己放弃郡主身份，她不肯被替自己做决定。双方都为对方着想，却互相伤害，她说"你根本不知道我真正想要的是什么"。冲突来自爱，不来自误会。之后由第三方（父亲亮出婚书）给出口。

迁移要点：让冲突双方都"对"，且都在替对方牺牲，比"一方误会一方隐瞒"更耐看。出口最好也由两人自己的选择带来，而不是外力。

## 3. 样本 A 的短板（不要迁移）

以下几点也可能是感情戏"弱"的常见成因，写作与终审时对照检查：

1. **内心独白替台词说破**：女主全剧约 11 处内心独白，至少 5 处是"不愧是我选中的男人"式宣告，与台词、动作已表达的甜重复，削弱潜台词。男主内心独白只有寥寥几处，且全在商战/复仇场，没有一处写他对她心动。
2. **男主"动心"转折缺失**：前期他对"痴傻的妻子"是责任与怜惜，何时把她当成平等的爱人没有标记场。
3. **中段关系重量单一**：第 12–28 集以商战为主，男女主同场多是"她撒娇、他无奈"，缺少让关系升一级的对手戏。
4. **冲突和出口都偏外部**：身份由第三人揭穿，和解与求亲出口靠证人和父亲，两人之间的主动选择占比偏低。
5. **亲密阶梯不清晰**：从"吹吹"到拥抱之间没有明确的关系等级跳跃。

## 4. 样本 B：可迁移的家庭情绪机制

- **B1 第三方观看视角**：父母在监控室或角落里看儿子，边看边评论，替观众放大情绪，也制造"他不知道被爱着"的甜。
- **B2 冲动与克制的周期**：母亲一再催"亮身份"，父亲一再压"再等等"，每次冲动被压下，形成可预期的期待与释放。
- **B3 嘴硬心软**：嘴上说"打人解决不了问题"，转身吩咐"别让他吃了亏"。此机制可直接用于男女主：嘴上冷淡，行动护短。
- **B4 具体生活细节承载情绪**：出租屋里做饭、"逢年过节听别人家鞭炮"，比"我从小孤独"有效。
- **B5 二选一带代价**：踹长辈两脚或离婚，逐轮升级，选择本身塑造人物。
- **B6 重复梗做情绪呼吸**：如"看监控"，在高压场之间给一个笑点，再回到情绪。

## 5. 样本 B 的 CP 线：不是拉扯范本

- 女方第 19 集才首次出场，此前约一半篇幅 CP 缺席。
- 出场后主要功能是"帮腔"和"被长辈撮合"，缺少自己的内心障碍，也没有和男主之间的推拉。
- 长辈助攻替代了两人的互动。

可参考的只有两点：她在公共场合为他站队的**初遇方式**，以及整理领带这类**轻亲密动作**。

## 6. 已写入 `romance-tension.md` 的规则（对照）

1. 拉扯 = 两股力：想靠近的力 + 不能靠近的理由。写前先各写一句"不能靠近的理由"。
2. 每场感情戏至少一个可拍的"在意表现"：物件、称呼、距离、身体反应。
3. 内心独白不复述台词和动作已表达的情绪；感情线内心独白只写"角色不愿让对方知道"的部分。
4. 单集卡新增：本集亲密等级（按 `romance-tension.md` 第 5 节的 0–6 级阶梯，写“前 X 级 → 后 Y 级”）与本集推/拉各一次。
5. 关系变冷先改称呼与距离，再改台词内容。
6. 至少一次冲突让双方都"对"，且都在替对方着想。
7. 男主/女主各有一场"开始在意"的标记场，不允许感情从责任直接跳到爱。
8. 出口尽量由两人的选择完成，外部事件只提供条件。

## 7. 对标自检清单

- [ ] 感情场景里是否有"表层任务 + 底层心意"，而非直接表白？
- [ ] "推"是否有让观众理解甚至喜欢的理由？
- [ ] 是否有物件完成"承诺 → 兑现 → 回收"？
- [ ] 关系变冷是否先体现在称呼、距离、动作？
- [ ] 内心独白是否只补充不外露的部分，而不是重复台词？
- [ ] 男女主各自"开始在意"的标记场是否存在？
- [ ] 中段是否每隔几集有一场让关系升一级的对手戏？
- [ ] 至少一次冲突是否双方都有理、都在替对方着想？
- [ ] 是否更换了身份差、秘密、物件、冲突来源，避免复刻样本？
