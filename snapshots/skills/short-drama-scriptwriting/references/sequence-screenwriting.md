## 1. 序列原则

把长故事拆成一组“小电影”。一个序列可覆盖一集或数集，但必须完成：

```text
局部目标 → 阻碍升级 → 小高潮 → 局部结果 → 更大的下一问题
```

不要把序列写成同类事件集合。序列结束时，角色的策略、关系、资源、规则或认知至少换一层。

## 2. 八序列功能

按项目自由缩放和合并，不机械对应固定集数。

| 序列 | 功能 | 短剧应用 |
|---|---|---|
| A | 建立失衡与引爆事件 | 开篇证明卖点，提出必须行动的问题 |
| B | 锁定困境与第一选择 | 主角无法退回原状，正式进局 |
| C | 第一次主动策略 | 旧办法短暂奏效，建立希望与能力边界 |
| D | 第一次大换挡 | 假胜利/假失败，提高代价或改写目标 |
| E | 新规则与反击 | 新资源、关系或对手层级进入 |
| F | 旧方法崩塌 | 最大失败、底牌暴露或关系破裂 |
| G | 最终计划与汇线 | 主线、关系线、伏笔收束成明确行动 |
| H | 高潮选择与新常态 | 关键选择落地，兑现情绪和类型承诺 |

中段最易塌陷。让 D 或 E 改变游戏规则，不能只把同一困难变大。

## 3. 注意力工具

每个序列主动选择 1–2 种：

- **预告**：让观众提前知道一个期限、承诺或危险，等待兑现；
- **悬而未决**：暂缓解释一个重要异常，但持续提醒其存在；
- **戏剧反讽**：让观众比角色领先半步，等待角色发现；
- **目标张力**：让观众关心角色能否达成当下目标；
- **信息差交锋**：双方掌握不同信息，并用策略试探；
- **伏笔回收**：旧信息获得新含义并改变行动。

工具必须服务当前目标，不能只为了神秘感挖坑。

## 4. 单集结构缩放

### 30–60 秒

```text
前 1–3 秒：异常 / 目标 / 危机
前段：主角采取策略
中段：阻碍或信息升级
后段：阶段性回答与代价
结尾：启动更重要的新问题
```

### 60–120 秒

```text
前 3–8 秒：开场承诺与当集问题
约前 25%：目标明确、压力锁定
约中间 50%：两次推进或一次推进 + 一次换挡
约后 20%：局部结果、关系/信息变化
最后窗口：自然递交下一集
```

### 2–5 分钟

允许更多关系和呼吸，但仍要拥有完整的目标—升级—结果。时间比例为创作参照，以项目实测语速、表演与动作时长为准。

每集最低具备：

1. 一个具体观看问题；
2. 主角的一次可见行动；
3. 适配时长的有效信息单元；
4. 至少一次策略或权力变化；
5. 一个阶段性回报；
6. 一个由结果生成的下一问题。

## 5. 序列卡

| 字段 | 内容 |
|---|---|
| 序列范围 | 集数 / 预计时长 |
| 行动主角 | 谁承担选择与后果 |
| 局部目标 | 可验证的目标 |
| 外部阻碍 | 人、规则、环境、时间、关系 |
| 内部阻碍 | 恐惧、误判、执念、旧策略 |
| 观众问题 | 本序列等待什么答案 |
| 注意力工具 | 预告 / 悬念 / 反讽 / 信息差 / 回收 |
| 升级链 | 至少两次不同质升级 |
| 小高潮 | 压力最高点与关键选择 |
| 局部结果 | 回答了什么 |
| 新问题 | 为什么必须进入下一序列 |
| 双轨节奏 | 外部与内部强度变化 |

## 6. 单集卡

| 字段 | 内容 |
|---|---|
| 本集观看问题 | 观众等待的具体答案 |
| 开场动作 | 第一个可见异常、目标或冲突 |
| 主角目标 | 本集必须完成什么 |
| 立即代价 | 为什么必须现在行动 |
| 最大阻碍 | 谁或什么阻止 |
| 中段换挡 | 新信息、关系变化或策略被看穿 |
| 有效信息单元 | 哪些新事实会改变角色行动；60–120 秒高密度项目通常 4–6 个 |
| 交锋与权力 | 核心对手戏双方目标、筹码、伤口；至少两次策略/权力变化 |
| 反转等级 | 普通推进 R1；关键场 R2；付费卡点或强集末优先 R3；感情场不按此栏衡量，见 `romance-tension.md` 第 13 节 |
| 阶段性回答 | 本集兑现什么 |
| 集末拉力 | 新决定、期限、揭示、关系或危险 |
| 下一集启动 | 下一集第一场从哪个动作接 |
| 时长与双轨 | 预计时长；外部 / 内部强度 |

## 7. 九问自检

1. 谁在承担本序列/本集的行动？
2. 他现在具体想完成什么？
3. 为什么必须现在做？
4. 什么力量直接阻止他？
5. 他采取了什么策略？
6. 阻碍如何升级或换层？
7. 观众新知道或重新理解了什么？
8. 结尾回答了哪个局部问题？
9. 这个答案为什么自然制造了更大的下一问题？

若第 8 问答不出，说明本集只挖坑没有回报；若第 9 问答不出，说明钩子只是强行中断。
