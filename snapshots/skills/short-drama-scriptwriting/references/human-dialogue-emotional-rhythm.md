## 1. 使用边界

在以下任务中读取本文件：

- 用户反馈剧情无聊、对白僵硬、情绪不真或“太 AI”；
- 需要写、改或终审剧本正文、关键关系戏、家庭冲突、追妻/追夫或女频强情绪戏；
- 剧情信息很多，但人物没有生活感、潜台词或可表演余地；
- 每场都在正面争吵、解释、亮底牌，导致节奏看似很快却没有起伏。

本文件优先解决自然度、情绪传递和场景活性。`dialogue-conflict-density.md` 的比例与反转指标只用于定位问题，不得压过人物逻辑与口语真实。

## 2. 《疯狂主妇的秘密》案例观察

本参考根据用户提供的 41 集定稿批注版提炼，不收录原文全文，不复刻原句、人物组合或独特情节。文档含大量修订痕迹；以下数值只描述最终中文正文，不是平台标准：

- 41 集约 66 场，平均每集约 1.6 场；
- 约 710 行中文对白、534 行动作；
- 中文对白中位长度约 12 个字，约 81% 不超过 22 个字；
- 集末既有对白落点，也有动作、反应和卡点落点，没有只靠同一种问句收尾。

值得迁移的是以下机制：

### 2.1 先给处境，再让人物说话

重要情绪先由可见处境成立：异常仪式、家庭日常失控、物件被占用、公共场合失面子、身体状态或关系站位发生变化。人物不是先解释“我为什么难过”，而是先被迫应对眼前局面。

### 2.2 用生活物件承载关系旧账

早餐、酒、钥匙、银行卡、纪念物、协议、手机消息等物件同时承担生活感、权力和情绪。它们让“你不尊重我”“你把我当外人”变成可以拿走、摔碎、冻结、归还或拒签的动作。

### 2.3 短台词与动作轮流接棒

有效节奏常是：一句推进或刺伤 → 一个反应 → 一句转攻 → 一个改变局势的动作。简单的惊讶、停顿或半句话可以保留，只要它给演员反应空间，或让下一击更重。不要为了追求信息率把所有反应都删掉。

### 2.4 情绪来自关系位置变化

同一句普通话在不同关系位置会有不同重量。称呼改变、谁替谁说话、谁挡在谁前面、谁拿到钥匙、谁被排除在家庭仪式之外，往往比一段情绪宣言更有力。

### 2.5 集末停在“刚刚改局”的一刻

结尾优先停在决定落地、秘密将被看到、关系公开改写、反击动作完成或人物来不及消化的反应上。不要在爆点后继续总结意义。

迁移时至少更换人物关系、现实物件、冲突场域和结局后果。案例中的夸张表达属于特定项目口味，不自动成为所有项目的台词标尺。

## 3. 无聊与 AI 腔的根因

先辨认问题类型，不要一律“加狠话、加反转”：

| 症状 | 常见根因 | 修改方向 |
|---|---|---|
| 每场都很吵却无聊 | 场景机制只有正面争吵，胜负方式重复 | 更换公开/私密场域、第三方压力、物件争夺、隐瞒、合作或撤退机制 |
| 台词句句正确却像 AI | 人人说完整逻辑，作者观点压过人物即时目的 | 只让人物说此刻敢说、愿说和来得及说的部分 |
| 情绪靠括号和形容词 | 动作不改变关系，表演提示代替了戏 | 用距离、称呼、物件和选择制造可见情绪表现 |
| 角色同声同气 | 大家都用同样的句长、反问、金句和价值判断 | 为主要人物建立声纹、禁区和惯用策略 |
| 信息很多但没有感觉 | 揭示没有反应和余震，下一句立刻解释新设定 | 给关键揭示留下反应拍，并让人物换策略 |
| 反转密集仍可预测 | 每次都靠闯入、偷听、打脸或亮身份 | 改变反转来源：选择、误读、代价、关系站队、规则边界 |
| 对话像采访 | 一问一答都正面回应 | 使用半答、转题、装听不懂、反问夺权、动作拒绝和沉默 |

特别警惕以下 AI 痕迹：

- 所有人都能立即、完整、准确地总结自己的感受和关系；
- 连续使用“你以为……其实……”“不是……而是……”“从今天开始……”等对称句式；
- 每句都是可摘抄金句，没有口误、回避、停顿、俗语、重复或生活废料；
- 同一场里反复叫全名，或反复说对方已经知道的前因；
- 动作只剩“握拳、冷笑、眼神一沉、泪水滑落、震惊后退”；
- 每个揭示后都有一段解释，人物没有先做事；
- 每场都按同样的 5—8 拍整齐升级，角色像在执行模板。

## 4. 人物声纹卡

写关键对白前，为主要人物各填一张短卡。只记录会改变台词的项目：

```text
公开身份 / 必须维持的体面：
此刻最想让对方做什么：
真正害怕暴露什么：
敢说到哪一步 / 绝不会直说什么：
常用策略：命令 / 讲理 / 装可怜 / 讽刺 / 讨好 / 转移 / 沉默 / 开玩笑：
句子节奏：短促 / 绕弯 / 先铺垫后落刀 / 常省略主语 / 爱用具体数字：
惯用称呼与称呼变化：
受压时的语言破绽：重复 / 口误 / 改口 / 说一半 / 突然客气 / 突然叫全名：
攻击方式：抓事实 / 翻旧账 / 否定资格 / 制造羞耻 / 设条件：
退让方式：转身做事 / 换话题 / 降低音量 / 让第三人传话 / 假装不在乎：
```

遮住角色名朗读时，不要求每句都带口头禅；应能从信息选择、句长、礼貌程度、回避方式和攻击位置辨认人物。声纹来自稳定选择，不来自机械重复一句标志性口头禅。

## 5. 潜台词与反应拍

### 5.1 先写不能说的话

关键对话先内部写两行：

```text
A 不能直说：____
B 不能直说：____
```

正文让他们围绕生活任务、钱、门、食物、工作、孩子、伤口或第三人说话。潜台词不是故意含糊，而是人物为了体面、关系风险或现实利益不能把真正目的全说出来。

### 5.2 允许有用的“不增量”

“什么”“你再说一遍”“行”“随你”这类短反应不一定增加新信息，但在以下情况可以保留：

- 给演员完成情绪转向；
- 暴露角色没听懂、装没听懂或需要争取时间；
- 改变称呼、音量、距离或下一句的攻击角度；
- 让观众先感到冲击，再接收解释；
- 形成停顿，使下一动作成为回答。

反应拍不能连续堆积。若删掉后情绪重量、表演节奏和下一步策略都不变，就删。

### 5.3 一句话只说人物来得及说的部分

高压时，人通常不会完成论证。可适量使用：

- 被动作或第三人打断；
- 说一半改口；
- 回答旁边的问题，避开真正问题；
- 重复对方的关键词而非完整回答；
- 先处理物件，再给一句短回应；
- 突然从亲昵称呼改为全名，或从全名改成职务。

不要随机添加结巴、省略号和语气词。语言破碎必须来自人物压力和关系位置。

## 6. 场景机制与情绪转向

### 6.1 先更换“戏怎么发生”

连续场次不要都靠两个人站着争论。可选择不同场景机制：

- 一方必须完成现实任务，另一方故意让任务无法完成；
- 公共场合要维持体面，私下诉求只能借题发挥；
- 双方被迫合作，但对成功的定义相反；
- 一方隐瞒，另一方已经知道却假装不知道；
- 双方争夺同一物件、位置、称呼、签字或第三人的站队；
- 一方想离开，另一方只能用关系资格、规则或现实代价留人；
- 第三人误读现场，使双方必须临时改口或站队；
- 沉默的人通过做事、拒绝做事或把东西归位改变局面。

每一集至少确认核心场景的“机制”与相邻集不同；不是强制每集发明新形式，而是避免连续依赖同一种吵架、闯入、打脸或误会。

### 6.2 每场只锁一个情绪转向

情绪转向写成前后关系：

```text
忍耐 → 公开拒绝
占上风 → 暴露心虚
讨好 → 设条件
愤怒 → 害怕失去
假装不在乎 → 失手泄露旧情
同盟 → 被迫站队
```

场景不必走固定拍数。冲击场可以 2—4 拍结束；谈判或关系戏可以更长；高峰后可以只留动作和静默。用“点火—反应—转攻—失手—选择—余震”作为可选模块，按人物行为取舍，不要每场全用。

### 6.3 余震也是节奏

重大揭示或决裂后，不要马上进入下一轮解释。给一个会改变关系的余震：

- 对方仍按旧习惯递东西，却被拒绝；
- 角色改了称呼；
- 第三人撤回站队；
- 一件日常小事突然无人去做；
- 人物把准备好的话咽回去，转而执行决定。

余震不是拖慢，而是让观众真正感到“刚才发生的事已经改变生活”。

## 7. 三遍自然化改稿

### 第一遍：去作者解释

- 删掉角色替作者总结主题、关系和前史的句子；
- 把双方都知道的内容改成指向具体证据的半句，或直接用动作；
- 长台词只保留人物此刻用来争取目标的部分；
- 删掉括号里与动作、台词重复的情绪形容词。

### 第二遍：做人声分化

- 对照声纹卡，改每个人的信息选择、句长和攻击方式；
- 把过分工整的书面句改成能一口说出的口语；
- 只在压力有来源时加入打断、改口、重复、突然客气或突然叫全名；
- 搜索同一套句式是否被多个角色共用，尤其是反问、总结和金句。

### 第三遍：补反应、动作与余震

- 在关键揭示后留出反应拍，再决定是否需要解释；
- 让至少一个动作真正改变话题、距离、筹码或去留；
- 高峰后删掉总结句，尽量停在选择、动作或无法掩饰的反应上；
- 朗读整场，遇到需要换气两次却没有内部转折的台词就拆；遇到每句都很“漂亮”的段落，保留最锋利的一句，其余恢复生活口吻。

三遍顺序不要颠倒。场景目标和关系位置不成立时，润色语气词不会让台词变真。

## 8. 验收清单

- [ ] 本场除了“争吵”，还有清楚的现实任务、物件、第三方或空间机制吗？
- [ ] 双方各有一句不能直说的话，正文是否让潜台词通过回避和动作泄露？
- [ ] 主要人物的句长、礼貌、称呼、回避和攻击方式能否区分？
- [ ] 是否保留了少量有表演价值的反应拍，而不是把每句都写成信息炸弹？
- [ ] 关键揭示后是否先出现人物反应或策略改变，再决定要不要解释？
- [ ] 是否删除了对称金句、完整自我分析、主题宣言和万能狠话？
- [ ] 动作是否改变关系、距离、筹码或下一句，而非只写握拳、冷笑和落泪？
- [ ] 本场情绪是否发生一个清楚转向，且高峰后留有余震？
- [ ] 与相邻场次相比，冲突机制、胜负方式和结尾形态是否有变化？
- [ ] 朗读时是否像人物在当下说话，而不是作者借角色写总结？

## 9. 去 AI 腔与感情表达

去 AI 腔是删掉作者替人物总结的话，不是删掉感情。心意有三档表达（详见 `romance-tension.md` 第 7 节）：

- **藏**：台词回避，动作反向；
- **漏**：称呼变化、停顿、手抖、记得对方随口说的一句话、无意识让座；
- **明**：只在里程碑场，且必须付出代价，之后要有后果。

补充规则：

- 内心独白只写角色不愿让对方知道、且台词与动作没表达的部分；不要用独白反复问“他是不是在意我”。
- 感情高点（告白、道歉、决裂、和解）不使用网络梗、流行语和系统腔；铺垫与降压可以用。
- 自然度检查时，若发现所有角色的感情台词都是同一种吐槽腔，先分化声纹，再谈加强情绪。
- 情感戏不要因为“简洁”而删光反应拍和余震：关系里程碑后的一个称呼变化、一次沉默，往往比一句台词更重。
