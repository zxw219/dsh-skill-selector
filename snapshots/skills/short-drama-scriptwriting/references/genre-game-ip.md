# 游戏IP衍生改编题材结构参考

> 仅在授权范围明确时使用。将以下内容当作改编方向参考，不复刻受保护台词、独特场面或剧情表达；同时设计原作粉丝回报与新观众入口。标志性台词与场景的直接使用范围以授权协议为准；授权范围之外，只做功能层呼应，不复刻。

## 核心情绪
利用原IP的世界观/角色关系/名场面自带的粉丝粘性，核心卖点是"还原感"+"意难平弥补/新故事延展"，既要满足原著粉丝的情怀点，又要让新观众无门槛看懂。

## 常见结构套路
1. **开局**：快速锚定IP识别度——用观众熟悉的核心场景/标志性台词/角色标志性能力开场，1集内建立"这是XX游戏的故事"的认知
2. **改编方向选择**（需与用户确认具体走向）：
   - **补完线**：填补原作剧情空白、支线角色的"没讲透"的故事
   - **意难平弥补线**：原著中的遗憾CP/悲剧结局，改编给出HE
   - **平行/if线**：如果某个关键选择不同，故事会如何发展
   - **前传/后续线**：角色成名前的经历，或原作结局之后的故事
3. **发展**：
   - 还原原作角色的性格设定和标志性互动模式（人设不能崩，这是粉丝最敏感的点）
   - 保留/致敬原作的标志性场景、台词、招式，作为"名场面"钩子
   - 新增剧情要服务于粉丝期待（如CP线、角色弧光），不要偏离原作精神内核
4. **高潮**：原作粉丝期待的名场面高光时刻（决战/关键台词/身份揭晓）
5. **结局**：呼应IP精神内核，给出情绪满足（HE、意难平被填补、角色高光落幕）

## 常用钩子设计
- 每集结尾卡在原作粉丝熟悉的经典场景变奏/名场面即将上演
- "如果当初选择不同"式悬念（if线专用）
- 角色标志性技能/台词的高光复现

## 避雷点
- 严格核对人设是否符合原IP设定，避免角色OOC（人设跑偏）引发粉丝反感
- 涉及具体游戏IP的版权/授权问题需用户自行确认，剧本创作前先明确改编授权范围
- 新观众友好度：世界观说明要自然融入剧情，不能大段说明文拖慢节奏
