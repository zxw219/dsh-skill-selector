## 1. 开场承诺

开场的任务不是完整说明背景，而是让观众立刻知道“这里有一件值得继续看的事”。优先使用：

- **异常画面**：熟悉场景里有一个不该存在的细节；
- **进行中的危机**：角色已经在应对危险、期限或暴露；
- **关系裂缝**：一个动作或称呼立刻显示权力差与旧账；
- **结果先行**：先给离奇结果，再让故事回答如何发生；
- **卖点证明**：主角底牌、世界规则或关系悖论第一次可视化。

让第一场同时给出主角状态与类型气质。不要用旁白、字幕或角色互相解释代替行动。

## 2. 按单集时长缩放

| 单集时长 | 建议开场窗口 | 要求 |
|---|---|---|
| 30–60 秒 | 前 1–3 秒 | 直接出现异常、动作目标或冲突结果 |
| 60–120 秒 | 前 3–8 秒 | 给出异常 + 当集问题，尽快进入行动 |
| 2–5 分钟 | 前 10–20 秒 | 允许短暂定场，但定场本身必须有张力 |

这些是创作参照，不是平台现行政策。用户或平台有明确规则时，以项目规则为准。

## 3. 黄金前三集

最迟到第三集结束，让观众能回答：

1. 主角此刻要达成什么；
2. 谁或什么在阻止主角；
3. 核心关系是什么状态；
4. 作品承诺持续提供哪类回报；
5. 免费窗口或第一付费卡点前，观众正在等待什么具体事件。

不同集数承担不同功能：

```text
第 1 集：证明卖点，打破平衡，提出当下问题
第 2 集：迫使主角选择策略，展示核心关系或对手的反制
第 3 集：扩大代价，锁定主线方向，把期待递交给第一卡点
```

不要让前三集只做人物依次登场。新角色必须通过争夺目标、改变信息或制造选择进入故事。

## 4. 前三集节奏

- 让每场至少推进剧情状态、关系或情绪中的一项；
- 让关键转折和卖点画面获得足够篇幅，压缩纯过渡；
- 让首轮对白直接进入索取、拒绝、威胁、交易、质问或试探；先显露双方目标和权力差，不用寒暄填时长；
- 让台词同时承担策略、有效信息和情绪攻击；关键揭示出现后立即改变动作或选择；
- 按 `dialogue-conflict-density.md` 检查前三集的有效信息单元、权力换位与反转等级；
- 让第 1–2 集尽早出现核心关系的有后果互动；
- 让每集有阶段性回答，不把所有信息都拖到钩子；
- 让三个结尾形成递进链，而不是三次互不相关的事故。

## 5. 自检

- [ ] 第一场单独截出是否仍有具体观看问题？
- [ ] 开场是否证明核心卖点，而非只展示高强度画面？
- [ ] 第 1 集是否出现主角的可执行目标或不可回避压力？
- [ ] 三集内是否建立主线、对手、核心关系与情绪承诺？
- [ ] 第 3 集结尾是否自然递交第一付费卡点？
- [ ] 是否删除了先解释、后行动的场次？
