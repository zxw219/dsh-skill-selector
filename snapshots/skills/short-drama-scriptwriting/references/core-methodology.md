## 1. 故事横截面

先建立角色前史、关系旧账和世界规则，再从压力最强的时刻切入。第一场不是角色人生的第一天，而是“今天再不行动就会失去什么”的那一天。

让开场同时完成两件事：

- 给出一个可见的异常、冲突、期限或关系裂缝；
- 承诺作品的类型、情绪和核心卖点。

不要先解释世界，再启动事件。让观众通过角色应对规则的动作反推背景。

## 2. 戏剧动作与因果升级

最小戏剧单元：

```text
目标 Goal + 阻碍 Conflict + 策略 Action + 结果 Outcome
```

结果应改变下一步，形成“因为……所以……但是……”的因果链，而不是“然后又发生……”。

检查升级是否有效：

- 新阻碍是否改变了性质、代价或时间压力，而非换皮重复；
- 主角是否改换策略，而非连续承受；
- 实际结果是否偏离主角预期，形成新的局面；
- 每次局部胜利是否附带代价，每次失败是否产生新信息或新选择。

场景结束时至少改变一项核心价值：

- 信任 ↔ 怀疑；
- 掌控 ↔ 失控；
- 隐藏 ↔ 暴露；
- 接近 ↔ 疏离；
- 安全 ↔ 危险；
- 希望 ↔ 绝望；
- 资源增加 ↔ 资源损失。

不要求机械正负翻转，但必须让故事状态发生可感知变化。

## 3. 人物发动机

长线人物使用：

```text
Ghost：过去的关键创伤或压力
→ Lie：角色由此相信的错误规则
→ Flaw：错误规则外化成的重复行为
→ Want：角色自觉追求的具体目标
↔ Need：角色尚未承认的真正需求
→ Crisis Choice：继续相信 Lie，还是承担改变的代价
→ New Normal：选择之后可见的新状态
```

短剧不必一次展示全部前史，只需让前史持续解释角色为什么做出当下选择。

### XY 轴：把内心执念转化为外化行为

用于把 Ghost/Lie/Flaw 落到可写的具体动作，也用于任何角色（不限主角、不限感情线）的日常行为设计，是第 5 节“只写画面能证明的内容”的前置推导步骤。

```text
X 轴（核心情绪锚点，内心执念/欲望/恐惧/心结）：只存在于角色心里，正文不直接写出，不当作独白或旁白甩出来。
Y 轴（外化行为，全部写进正文，角色说的话、做的选择、下意识反应、回避的事）：
  Y 向上（同一个 X 催生的正向、主动行为，人物的闪光点）：
    1.
    2.
  Y 向下（同一个 X 催生的负面、委屈、拧巴行为，对应 Flaw，人物的缺点与伤痛）：
    1.
    2.
```

规则：

- 向上不等于“好人”，向下不等于“坏人”；两组行为来自同一个根源 X，缺一组人物就会失真：只写向上是完美假人，只写向下是纯反派。
- 写正文时只输出 Y，不写 X；X 留在写作者手里做推导依据，不写成“他心里想要被偏爱”这类直接说破的句子。让读者从 Y 的两组行为里自己拼出 X。
- 一个角色至少各写 2 条向上、2 条向下的具体场景化行为（谁、在什么场合、做什么），不要停留在“善良”“敏感”这类形容词。
- 同一 X 的向上与向下行为最好能在正文里前后呼应，形成同一根源的两次不同表现，而不是各自孤立的设定说明。
- CP 双人发动机（`romance-tension.md`）中每人的“最怕被对方看见什么”常与其 Y 向下行为对应，可直接引用本表。

示例（X 不写入正文，仅供设计参考）：X = 渴望被偏爱。Y 向上：家庭聚会主动讲笑话活跃气氛；朋友遇难处主动出力陪伴。Y 向下：分东西永远拿不到最好的一份，却不当众争取，默默压下情绪；别人对自己稍好一点，就加倍回馈讨好，害怕这点好会消失。正文只写“她捏着自己那份最小的，依旧扯着笑脸把话题接过去”，不写“她渴望被偏爱”。

### 现实处境卡：社会身份决定资源与限制

写心理发动机之前，先锁定人物的现实处境。不要只列身份标签，每一项都要落到“这个身份让他接触什么人、拥有什么资源、限制他什么”：

```text
年龄 / 家庭背景 / 财富状况 / 教育程度 / 社会阶层：
职业 / 职场位置：
社会关系（能调用谁、被谁调用）：
家庭关系（结构、亏欠、期待）：
朋友关系：
情感关系：
与本剧其他关键人物的身份差（资源差、话语权差、认知差）：
这个身份带来的资源：
这个身份带来的限制：
```

处于不同社会位置的人物，不应共享同一套生活环境、人际圈和解决问题的方式。检查：换掉这张卡里的任何一项，人物的可选行动、说话方式和能调用的资源是否也应该跟着变——如果不变，说明处境还没真正限定人物。

### 主导性人格特质与换人测试

人物可以有很多性格侧面，但不要平均分配。为每个核心人物选定**一个**最鲜明的主导性人格特质（如极度自尊、控制欲强、多疑、极度缺乏安全感、极度渴望被认可），并让它反过来限制人物的选择——包括对人物不利的时候：

```text
主导性人格特质：
这个特质会让人物在明明对自己有利时，仍然拒绝做什么：
这个特质会让人物在明明是好意时，仍然造成什么新冲突：
```

**换人测试**：检查关键剧情时，不要只问“这一幕发生了什么”，要问“为什么偏偏是这个人物会这样选”。如果把这场戏的人物换成剧中任何其他人，剧情走向不会变，说明人物个性还没有真正参与剧情，优先重写这一场，让选择从主导性人格特质里长出来，而不是从剧情需要里长出来。

这个测试和 XY 轴是同一件事的两个检查角度：XY 轴保证性格“有画面呈现”，换人测试保证性格“真正影响了选择”。两者都不满足时，人物就是工具人。

### 反派卡

反派不是“单纯作恶的功能”，要能持续和主角的生活产生交集，并推动主角改变：

```text
反派的目标：他想得到什么，为什么？
自我合理化：他如何向自己解释这个行为是合理的？
行动路线：目标 → 想法 → 行动 → 后果，写清他自己的因果链，不是只在主角需要冲突时才出现
筹码/资源：他能调用什么
最怕失去什么：他的软肋
他如何持续阻碍主角：制造困境 / 加剧关系 / 迫使选择 / 推动剧情进入下一阶段（至少写清两项）
人性面（不是为了洗白）：他自己的欲望、利益或价值观，让观众能理解“不认同但明白他为什么这样做”
```

反派若只在主角需要冲突时出现、平时没有自己的行动路线，判定为功能不全，需要补上他自己的目标驱动的独立情节线。

### 配角卡

每个重要配角逐一回答，答不出两条以上就考虑合并、删减或重新赋予功能：

```text
为什么需要这个人物？
他与主角是什么关系？
他对主线有什么作用？他推动了什么剧情、改变了哪个人物、制造了什么冲突、提供了什么信息？
他是否体现了主角性格的某个侧面（镜像功能）？
```

### 平凡人物的辨识度

人物不必设定成能力逆天或经历传奇；普通人的职业、家庭和困境同样是好素材，但平凡不等于没有特点。在日常行为里找辨识度，不要靠人物介绍宣布："说话习惯、做事方式、对钱的态度、对家人的态度、遇到冲突的第一反应、对陌生人/强者/弱者的态度、某个固定小动作、某种只有这个人物会做出的选择"——挑 2–3 项写成具体行为，通过日常行为+选择+对话+反应让观众自己感受性格，不用大段介绍宣布。这与 XY 轴的写法是同一套操作，此处提供更细的行为切入点清单。

### 人物闭环自检

修改或设计完成后，逐一核对是否形成闭环，缺一环就回补，不是继续加背景介绍：

```text
人物身份（社会位置）→ 人物处境（现实问题）→ 人物心理（想什么/怕什么/渴望什么）
→ 核心性格（主导性人格特质）→ 人物目标（现在最想要什么）
→ 人物行动（因为性格和目标，他会做什么）→ 剧情结果（选择造成了什么后果）
→ 新冲突（后果如何推动下一段剧情）
```

若某个人物的行为和已定的主导性人格特质、处境或目标对不上，不要直接改性格去迁就剧情，先按顺序排查：前置动机是否交代清楚 → 当前处境是否真的允许这个行为 → 人物目标是否被中途改写却没有铺垫 → 已知信息（他此刻知道什么）是否支持这个选择 → 与其他人物的关系是否构成了限制。找到最合理的断点再修，而不是让人物为了剧情需要临时"性情大变"或降智。

人物设计最低要求：

| 人物 | 必须明确 |
|---|---|
| 主角 | 现实处境卡、Ghost/Lie/Flaw/Want/Need、主导性人格特质、XY 轴、核心恐惧、筹码、底线、惯用策略、最终变化 |
| 对手/反派 | 反派卡（目标、自我合理化、行动路线、筹码、软肋、人性面）|
| CP/关键关系角色 | 独立目标、与主角目标的冲突点、能看见主角哪一面、关系如何改变双方选择；感情线是卖点时另填双人发动机（见 `romance-tension.md`） |
| 主要配角 | 配角卡（为什么需要、与主角关系、对主线作用、是否镜像主角侧面）|
| 次要配角 | 至少承担镜像、催化、主题、节奏或信息中的一种功能，并有自己的即时目标 |

让配角成为压力来源或选择诱因，不要只在需要递信息时出现。

## 4. 情绪内核与剧情变奏

正常短剧通常不是围绕一串孤立爆点展开，而是围绕一条核心情绪持续变奏。

付费钩子和反转负责让观众点开下一集，情绪内核负责让观众持续在乎这些人物。不能用留存技巧替代情感统一性。

区分三个概念：

- **主题**：作品最终对某个问题作出的判断；
- **情绪内核**：角色与观众反复体验的情感张力；
- **局部情绪**：某一集的惊、喜、虐、爽、甜、怕。

把情绪内核写成带矛盾的句子，而不是单个词：

- 不是“爱”，而是“渴望被坚定选择，却总被当作可以牺牲的人”；
- 不是“复仇”，而是“尊严被夺走后，必须亲手证明自己不再任人定义”；
- 不是“亲情”，而是“越想保护家人，越用控制把家人推远”；
- 不是“逆袭”，而是“只有证明有用才配被爱，最终学会先承认自己的价值”。

情绪推进链：

```text
建立缺口 → 第一次否定 → 不同处境再次刺痛
→ 短暂满足 → 满足被污染或收回 → 关系/自我认知崩塌
→ 主角改变选择 → 高潮用行动完成最终证明
```

每条主要剧情都应承担一种情绪功能：建立、否定、加深、暂时满足、污染、反转或最终证明。围绕同一内核，但至少更换以下两项：

- 冲突场域：家庭 / 爱情 / 事业 / 公众 / 生死；
- 关系对象：恋人 / 父母 / 孩子 / 伙伴 / 对手 / 自己；
- 主角策略：讨好 / 隐瞒 / 对抗 / 交换 / 离开 / 承担；
- 叙事机制：信息差 / 资源争夺 / 身份误认 / 道德选择 / 规则限制；
- 结果：被否定 / 小胜 / 假满足 / 付出代价 / 主动拒绝 / 真正获得。

如果连续两段剧情只是换了人物名字，却仍是“被羞辱—亮身份—打脸”，这不是变奏，而是重复。

| 集/序列 | 剧情事件 | 情绪功能 | 与上次不同的机制 | 角色内在状态变化 | 可拍表现 |

## 5. 可拍摄写作与高密度对白

只写画面、声音和表演能证明的内容。

| 抽象写法 | 转化方向 |
|---|---|
| 她意识到他撒谎 | 她把合照翻过去，继续给他倒茶 |
| 他仍然深爱她 | 他删除号码，却把旧语音又听了一遍 |
| 她很害怕 | 她抓错三次门把，仍盯着门缝 |
| 他终于接受父亲 | 他把父亲那双旧鞋放进自己的鞋柜 |

让台词成为策略：试探、回避、威胁、安抚、诱骗、讨价还价、转移话题。角色说出口的是表面目的，真正目的通过动作、停顿、称呼和距离泄露。人物不必句句完整、锋利或正确；体面、恐惧、关系风险和当下任务会限制他能说多少。

把每场文戏写成争夺：双方有相反即时目标、不同筹码和不能被戳中的伤口。每一轮交锋整体都要推进目标、信息、关系、筹码、理解或行动；允许少量有表演价值的短反应、改口和沉默。关键句可以同时承担两项功能，但不能为了效率牺牲人物声纹和口语真实。详细执行 `dialogue-conflict-density.md` 的逐句功能、交锋梯、反转分级与验收门槛；用户反馈“太 AI”、僵硬或无聊时，再读 `human-dialogue-emotional-rhythm.md`。

删除以下对白：

- 双方都知道、只为观众解释的设定；
- 直接说出主题和人物弧光；
- 与动作重复的信息；
- 可以用一个反应动作替代的长解释。

“情绪拉满”不等于音量拉满。用更具体的证据、更致命的关系旧账、更可执行的威胁和更不可逆的选择提高烈度。让关键揭示在后续 1–3 拍内改变行动，否则它只是资料。

画外音、电话音、系统音等声音标签（见 `script-format.md` 第 5 节）只能作为观众真实听到的声音设计使用，不能把普通心理描写改个标签继续堆砌。让声音与画面产生增量或错位。

## 6. 双轨节奏

同时标记：

- **外部情节轨**：事件、冲突与信息的密度，分为松 / 中 / 紧；
- **内部情感轨**：关系与情绪的重量，分为轻 / 中 / 重。

四种组合：

| 外部 | 内部 | 用途 |
|---|---|---|
| 紧 | 重 | 高潮、崩塌；控制持续时间 |
| 紧 | 轻 | 爽感、喜剧化危险、动作中的调侃 |
| 松 | 重 | 克制情感、关系余震、安静但重要的选择 |
| 松 | 轻 | 呼吸、铺设好感、高潮前后缓冲 |

让两条线有波浪。短剧追求高密度，但不等于所有场次都双高；没有呼吸，高潮会失去区别度。

## 7. 场景卡与删场标准

感情场（关系里程碑、暧昧、拉扯、和解、决裂）改用 `romance-tension.md` 第 13 节的写前卡，不套用本节场景卡。其余场景写正文前内部填写：

```text
场次 / 日夜 / 内外 / 地点：
视角角色：
本场目标：
直接阻碍：
角色策略：
结果 / 转折：
价值从____变为____：
可见的情绪表现：
本场场景机制：现实任务 / 公开体面 / 隐瞒试探 / 被迫合作 / 物件争夺 / 离开挽留 / 第三人误读 / 其他：
本场唯一情绪转向：从____到____：
新增信息 / 伏笔 / 回扣：
双方相反目标 / 各自筹码 / 核心伤口：
双方不能直说的话：
交锋梯与有效信息单元：
权力从____转为____：
反转等级：R0 / R1 / R2 / R3 / R4
情节节奏：松 / 中 / 紧
情感节奏：轻 / 中 / 重
进入本场的压力：
递交下一场的问题或动作：
场尾余震：
```

满足以下任意两项，就删除、合并或重写这一场戏：

- 没有角色目标或阻碍；
- 没有价值变化；
- 只重复已知信息或情绪；
- 删除后因果链仍完整；
- 没有为后续埋下必须的信息、关系或行动。

## 8. 世界观信息释放

复杂设定按三层规划：

```text
表层规则：观众先看到怎样运行
→ 运行逻辑：通过角色试错理解为什么这样
→ 底层真相：重新定义此前规则与事件
```

每次释放信息都要改变角色的可选行动或观众对旧信息的理解。世界观越复杂，单集当下任务越要简单。
