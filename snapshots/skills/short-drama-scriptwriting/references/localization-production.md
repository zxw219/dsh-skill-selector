# 海外本地化与可生产性

> 仅在项目确认目标市场为海外时读取本文件；国内项目不适用。

## 目录

1. 本地化不是换名字
2. 文化与制度检查
3. 对白本地化
4. 竖屏真人短剧
5. 漫剧与动态漫画
6. 制作预算检查

## 1. 本地化不是换名字

先确认目标国家/语言、分发平台、受众年龄与题材接受度。不要把中文网文关系和制度只换成英文名、美元金额就称为海外短剧。

保持“情绪功能”，重建“当地因果”：

```text
原情节的情绪目的
→ 当地观众理解的关系、制度和风险
→ 能在当地场景中自然发生的行为
→ 目标语言中像真人说话的对白
```

例如“豪门家法”“户口”“高考保送”“彩礼”等不能直接平移；先识别其权力与情绪功能，再寻找目标市场中等效的家庭、法律、教育或财务压力。

## 2. 文化与制度检查

逐项核实或标注待核实：

- 婚姻、离婚、继承、监护、公司治理与司法程序；
- 医院、学校、警察、军队、宗教和社区的实际运作；
- 称呼、亲密边界、家庭决策权和职场等级；
- 货币、生活成本、距离、交通与时间；
- 种族、阶层、性别、宗教和移民议题的语境；
- 平台内容限制、年龄评级、广告与付费规则。

事实不确定时不要编造权威细节。用占位符或提醒用户核实，必要时再查证当前规则。

## 3. 对白本地化

- 先按目标语言的交谈习惯重写，不逐字翻译中文句式；
- 让称呼、礼貌程度、讽刺方式和情绪外露程度符合人物背景；
- 删除中文网文式身份宣告和长句威胁，改成当地可表演的短策略；
- 保留信息差和潜台词，不把隐含关系全部翻译成解释；
- 为不同角色建立词汇、句长、语速和禁用表达表。

若最终交付仍是中文，明确这是“面向目标市场的中文开发稿”，并标注后续需要母语编剧或文化顾问复核。

## 4. 竖屏真人短剧

- 优先少量可复用场景、清楚的前后景和人物距离变化；
- 让关键动作在近中景仍可读，避免依赖大远景才能理解；
- 控制同场人数和频繁转场，给服化道、群演和夜戏标注成本风险；
- 用进入/退出、遮挡、物件递交和站位变化制造画面推进；
- 剧本按 `script-format.md` 的 `△` 动作行写法，每行只承担一个动作节拍或信息，关键动作在近中景即可读。

## 5. 漫剧与动态漫画

- 把卖点写成清晰画面状态：人物姿态、表情、道具、空间关系和特效规则；
- 控制同一画面中的动作数量，一个画面只承担一个主要信息；
- 提前登记角色外观、服装、道具和场景连续性；
- 设计可复用资产与画面模板，但让关键高光拥有独特构图；
- 对变身、战斗、系统界面和群像场面标注资产或特效复杂度；
- 避免只有旁白推动、画面长期静止的“有声小说式漫剧”。

## 6. 制作预算检查

对每集或每序列标注：

| 项目 | 检查 |
|---|---|
| 场景 | 新建 / 可复用 / 外景 / 夜景 |
| 人物 | 主演 / 配角 / 群演数量 |
| 道具与服装 | 一次性 / 连续性 / 特殊制作 |
| 特效 | 简单合成 / 复杂变身 / 群体效果 |
| 动作 | 普通调度 / 特技 / 亲密 / 儿童 / 动物 |
| 声音 | 现场对白 / 画外音 / 系统音 / 特殊音效 |

预算受限时，优先保留能证明核心卖点、改变人物选择或承担付费卡点的场面；压缩纯展示型奇观。
