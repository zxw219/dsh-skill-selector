## 1. 对标结论

把“爆款感”拆成可执行结构，不把它理解成全程吼叫、辱骂、猎奇或堆叠感叹号。

参考样本（见 `benchmark-case-dialogue.md`，六集）约为每集 660–790 个中文字符，对白为 8–17 行，单句对白平均约 11–20 个字符（该样本与 `script-format.md` 的动作行加台词行写法同类，可作参考；单集体量以用户或平台标准为准）。它的主要效率来自：

- 开场先给危险关系或非常规交易，再补前因；
- 每集连续释放身份、债务、背叛、目的或关系连接等有效信息；
- 信息一出现就改变人物的选择、筹码或危险，而不是停留在说明；
- 对白短，动作承担回答、压迫、拒绝和权力展示；
- 每次局部答案都会抬高下一问题，反转持续改写关系位置。

只学习上述信息结构和交锋效率，不复制样本的台词、人物、场面或独特情节。把数值当作本次样本基准，不冒充平台统一标准。用户明确要求对标该例文或需要女频强情绪六集参考时，再读取 `benchmark-case-dialogue.md`；不要默认套用案例结构。

### 自然度优先门

高密度是“删掉无后果的重复”，不是让每个人都像编剧一样高效。百分比、功能代码、拍数和句长只用于写后诊断，不作为逐句填配额的写前模板。若一句简单反应、停顿或动作能给演员完成情绪转向、暴露关系位置或加重下一击，可以保留；若一句同时承担三项功能却不符合人物身份和口语习惯，必须重写。

用户反馈“太 AI”、对白僵硬或剧情无聊时，同时读取 `human-dialogue-emotional-rhythm.md`。先修人物声纹、潜台词和场景机制，再计算密度；自然度门不通过时，不得用更狠的词或更多反转掩盖问题。

## 2. 先建场景争夺

写对白前先填：

```text
场景表面议题：双方正在谈什么？
A 的即时目标：他要对方现在做什么？
B 的即时目标：她要对方现在做什么？
A 的筹码 / 不能说的信息：
B 的筹码 / 不能说的信息：
双方最怕被戳中的伤口：
本场期限或第三方压力：
开场权力位：谁更强，凭什么？
场尾权力位：谁更强，凭什么改变？
不可逆结果：承诺 / 决裂 / 交易 / 暴露 / 失去 / 站队：
```

若双方目标一致、没有稀缺资源、没有不能退让的条件，这不是交锋场。先制造利益冲突、信息差、规则差或关系旧账，再写台词。

## 3. 计算有效信息

把“有效信息单元”定义为：**观众新知道或重新理解一件事，并因此能预测角色下一步会改变。**

有效信息包括：

- 新目标：角色真正要什么；
- 新代价：失败会具体失去什么；
- 新筹码：谁能决定钱、身份、证据、关系或生死；
- 新限制：期限、规则、能力边界、法律或社会后果；
- 新关系：亲疏、背叛、结盟、隶属、血缘或承诺被改写；
- 旧信息翻义：同一事实获得相反含义；
- 新计划：角色因此采取不同策略。

下列内容不计为有效信息：

- 角色重复观众已经知道的事实；
- 只有形容词强度，没有新因果；
- 新设定出现后无人改变行动；
- 可以删除而不影响选择、权力和下场的说明。

每次释放信息都执行：

```text
信息出现 → 对方反应或利用 → 筹码/关系/计划改变
```

揭示之后 1–3 个节拍内必须出现后果。否则信息只是资料，不是戏。

## 4. 逐句设计对白功能

给每句对白或关键动作标记功能：

| 代码 | 功能 | 判断问题 |
|---|---|---|
| G | 夺取目标 | 这句要求、诱导或迫使对方做什么？ |
| I | 释放/套取信息 | 观众或对手新知道什么？ |
| L | 改变筹码 | 谁因此更有控制权？ |
| W | 精准刺伤 | 是否击中身份、亏欠、欲望、羞耻或恐惧？ |
| C | 迫使选择 | 对方是否必须答应、拒绝、撒谎或付代价？ |
| R | 改写理解 | 这句是否让前文、关系或目标获得新含义？ |
| A | 触发行动 | 下一拍是否发生可见动作或决定？ |

正文默认要求：

- 每一轮交锋整体必须推进目标、信息、关系、筹码、理解或行动；多数实质对白至少承担 1 项功能，关键句可承担 2 项以上；
- 优先让一句同时完成“信息 + 攻击”“威胁 + 期限”“示弱 + 诱骗”“拒绝 + 夺权”；
- 不让角色直接宣告“我很痛苦/我很愤怒”，让他指出造成痛苦的具体事实并逼对方承担后果；
- 让角色说自己此刻会说的话，不替作者总结剧情或主题。

允许少量反应拍，如半句、改口、重复关键词、沉默或简单回应，但它必须改变表演节奏、称呼、距离、情绪温度或下一句的攻击方式。不得连续堆积无后果的惊叹、问句和“你听我解释”。

对白不是问答采访。对方每次回应至少使用一种反制：

- 正面回击并转攻对方伤口；
- 回避问题但夺走议题；
- 承认事实却提高交换价格；
- 只回答一半，留下更危险的信息差；
- 用动作拒绝、羞辱、保护或站队；
- 抛出证据、期限或第三方，迫使对手换策略。

禁止“你怎么能这样—我就是这样—你太过分了”的情绪复读。

## 5. 搭建交锋梯

下面的 5–8 拍交锋梯只是一种适合完整谈判或正面冲突的结构，不是所有场景的固定模板。冲击场可以 2–4 拍结束，克制关系戏可以由动作、回避和余震组成；按人物策略自然增减：

```text
试探/索取
→ 回避或设门槛
→ 点破软肋
→ 第一次反击
→ 新筹码或证据出现
→ 关系/权力换位
→ 迫使不可逆选择
→ 场尾留下代价或更大问题
```

每个实质节拍必须改变策略、信息、关系或压力。不要连续使用同一种威胁、同一种否认或同一种羞辱，也不要让每场都完整套用同一条梯子。允许动作代替台词，例如撕毁文件、改称呼、关门、转账、删除号码、把座位让给第三人；动作必须改变局势，不只是装饰情绪。

让强势角色也受到反制。弱势角色可以缺钱、缺身份或被控制，但必须至少拥有一种有效武器：拒绝权、秘密、证据、第三方关系、道德制高点、时间优势、不可替代能力或自毁式底线。

## 6. 管理情绪烈度

把对白情绪值标为 1–5，不用音量代替烈度：

| 值 | 状态 | 写作要求 |
|---|---|---|
| 1 | 表面正常 | 有隐瞒、戒备或未说出口的目的 |
| 2 | 边界被碰 | 出现拒绝、试探、讽刺或条件 |
| 3 | 利益受损 | 出现明确威胁、羞辱、背叛证据或代价 |
| 4 | 核心伤口暴露 | 关系真相、身份尊严或最怕失去之物被击中 |
| 5 | 不可逆 | 决裂、牺牲、公开暴露、失去、站队或生死选择落地 |

“拉满”指攻击更精准、后果更具体、选择更残酷，不指每句都在 5。单场通常从 2–3 起步，经过反制升到 4–5；峰值后用一个短动作、静默或低声句承接余震。若全场都在最高音量，观众无法感知升级。

角色攻击必须对准三项之一：

- 当前目标：让对方此刻失败；
- 核心伤口：让对方最想掩饰的缺口被看见；
- 关系资格：否定对方的爱、忠诚、身份、承诺或选择权。

## 7. 标定反转力度

| 等级 | 定义 | 最低后果 |
|---|---|---|
| R0 | 只有惊讶，没有改局 | 删除或改写 |
| R1 | 新事实补充 | 角色调整判断 |
| R2 | 筹码/权力换位 | 角色必须换策略 |
| R3 | 关系或目标被重定义 | 此前互动获得新含义，下一步目标改变 |
| R4 | 故事前提被改写 | 主线规则、身份或最终对手改变，旧计划失效 |

普通推进至少达到 R1；关键场景至少达到 R2；付费卡点、序列转折或强集末优先达到 R3。R4 只用于已有充分前置的重大换挡，不能频繁空降。

反转必须同时满足：

1. 前文存在可回看线索；
2. 观众原先形成了清楚预期；
3. 新信息推翻或重定义预期；
4. 角色立刻改变行动、关系或代价。

## 8. 正文写作流程

按以下顺序写每场：

1. 填写场景争夺，锁定双方目标、筹码、伤口和场尾换位；
2. 为主要人物写简短声纹卡，并各写一句“此刻不能直说的话”；需要详细规则时读取 `human-dialogue-emotional-rhythm.md`；
3. 先列有效信息单元，不写完整对白；
4. 选择适合本场的场景机制与节拍形状；只有完整交锋需要时才使用 5–8 拍梯，标出关键换位与反转等级；
5. 写动作与对白，让人物围绕眼前任务和物件说话，让动作也承担回应；
6. 写完后再用 G/I/L/W/C/R/A 诊断实质对白，删除无功能的解释和复述，同时保留有表演价值的短反应与余震；
7. 压缩过长台词，删掉全名复读、完整自我分析、情绪复述和过度工整的金句；
8. 朗读区分人声：遮住角色名，仍应通过词汇、句长、礼貌程度、称呼变化、回避方式和攻击位置辨认人物；
9. 检查新信息是否在 1–3 拍内产生后果，检查场尾是否真正改局；
10. 执行一次去 AI 改稿：打断过完整的论证，删除主题总结，让关键揭示先有反应，再决定是否解释。

改写任务先保留原场目标与关键事实，再逐句压缩和升级。不要为追求“狠”而添加与人物目标无关的恶毒台词。

## 9. 硬性验收门槛

用户明确要求高信息密度、强对白或爆款节奏时，用以下数值做写后诊断；平台或用户给出更具体标准时，以项目标准为准。不得为了达标把自然反应改成信息句，也不得在最终正文展示标签。以下门槛均不适用于感情场，感情场按第 12 节和 `romance-tension.md` 第 13 节单独诊断：

- 场景争夺清晰率：100%，每场都能说清双方相反目标和场尾权力变化；
- 有效对白率：实质对白中至少 85% 具备 G/I/L/W/C/R/A 中至少一项；有表演价值的反应拍单列，不作为无效句惩罚；
- 双功能对白率：关键交锋中以 60% 为高密度案例参考，不是所有题材的硬配额；若人物自然度下降，优先保留最准确的单功能句；
- 空转上限：不得连续两句都既无新信息、无反制、无筹码变化、无情绪/称呼/距离变化，也不触发动作；
- 句长基准：多数中文对白控制在 6–22 字；超过 35 字的台词必须包含内部转折、具体细节、旧账或明确逼迫，否则拆句；
- 60–120 秒单集：通常配置 4–6 个有效信息单元、至少 2 次策略/权力变化、至少 1 个 R2 以上转折；集末落到不可逆选择、关系改写或更高代价；
- 30–60 秒单集：按篇幅缩减信息数量，但保留“目标—换挡—结果—新问题”；
- 2–5 分钟单集：增加呼吸和余震，不机械倍增反转；每场仍需独立争夺与价值变化；
- 新信息后果率：关键揭示 100% 在后续 1–3 拍内改变反应、策略或局势；
- 人声区分：主要角色不能使用同一套句式、攻击方式和价值判断。

数值是改稿门槛，不是让正文展示标签。最终剧本只输出自然动作与对白。

自然度是前置门槛。若主要人物同声同气、连续出现作者式总结、每句都过度完整或同一场景机制反复出现，即使数值达标也判定不通过。

## 10. 常见失效与改写

### 只有情绪，没有攻击对象

弱：`你怎么能这样？我真的很难过。`

改：`戒指摘了。戴着它去见她，嫌我还不够难看？`

改后同时完成：具体证据、关系羞辱、命令和伤口暴露。

### 只有威胁，没有筹码

弱：`你最好听我的，否则后果自负。`

改：`十二点前不到账，我先停掉你唯一舍不得的那张卡。`

改后同时完成：期限、筹码和可验证后果。根据项目内容边界替换具体筹码。

### 只有信息，没有改局

弱：`其实她是公司真正的老板。`

改写方法：先让角色以为自己能辞退她，再由第三方改称呼、交出权限或撤走资源；让身份信息当场造成权力换位。

### 只有反问，没有反击

弱：`你凭什么这么说？`

改写方法：用证据、条件或对方旧账夺回议题，例如先指出对方没有资格，再抛出会让其付代价的选择。

### 每句都太有效，反而不像人

弱：每个人都立即说清立场、证据、伤口和结论，句式完整对称，没有回避、反应和失手。

改写方法：保留本轮最锋利的一句；让另一方先处理眼前物件、只答一半或改称呼；把剩余信息递延到动作后。自然不是随机加“呃”和省略号，而是让人物受体面、恐惧和即时目标限制。

## 11. 终审输出

对白专项诊断使用：

```text
【位置】第__集 / __场 / 第__轮交锋
【原句/原段功能】当前只完成什么
【失效类型】复述 / 空泛情绪 / 无筹码威胁 / 无后果信息 / 同声同气 / 反转不足
【缺失增量】信息 / 权力 / 关系 / 选择 / 行动
【改写策略】删减 / 合并 / 转攻 / 加筹码 / 加期限 / 动作回应 / 提升反转等级
【短示例】只改关键 1–3 轮，不无边界重写整场
```

审核时报告有效对白率、双功能对白率、有效信息单元、权力变化次数、最高反转等级和连续空转位置。先修场景争夺与信息顺序，再修句子锋利度。

## 12. 感情场例外

感情场（关系里程碑、暧昧、拉扯、和解、决裂）不按筹码交锋写，也不用反转等级衡量。诊断时改用以下规则：

- 新增功能码：**T** 推拉（一次靠近或退开）、**H** 泄露（称呼、物件、动作暴露心意）、**Y** 余震（改变称呼、距离或习惯）。感情场的实质对白只要承担 T、H、Y 或前文 G/I/L/W/C/R/A 之一即计为有效，不要求双功能。
- 有功能的沉默、日常闲聊、并肩做事可以保留，前提是它服务当前亲密等级的升级、降级或积累；写前卡中要能说出它服务哪一级。
- 关系里程碑用亲密等级和标记场衡量，不用 R1–R4；不得为了达到反转等级，给感情戏硬加新情报或第三方闯入。
- 空转上限仍然适用，但“有表演价值的反应、物件动作、停顿”不算空转。
- 感情场的具体写法见 `romance-tension.md`。

## 13. 筹码去侦破化

“证据”是最好写的筹码，长期只用它，对白会变成出示与反驳，整部剧滑向破案。规则：

- 筹码轮换：同一段对手戏里，相邻两轮不要都靠证据；轮流使用关系、自尊、选择权、时间、物件、第三方评价、旧账。
- 非悬疑题材中，证据只作辅助筹码，不承担一场戏的主要推进；一场戏的赢家应由“谁更在意什么”决定，而不是“谁手里有物证”。
- “必须包含内部转折、证据或明确逼迫”中的证据可以替换为“具体细节、旧账或代价”，不要理解为必须亮证据。
- 连续三场以上出现“亮证据 → 对方反驳 → 再亮证据”，视为漂移，参考 `genre-drift-guard.md` 换轨。
