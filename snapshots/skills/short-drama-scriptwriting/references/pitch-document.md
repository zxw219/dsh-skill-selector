# 项目立项书模板

在概念、九问骨架和结局方向成立后使用。平台字段与免费窗口必须以用户或当前平台要求为准；未知项标注“待确认”。

## 一、项目参数

```text
项目名：
载体：真人短剧 / 漫剧 / 动态漫画 / 其他
目标市场与平台：
主类型 / 辅助类型：
目标受众与主情绪：
核心情绪内核：（用带矛盾的句子表达，不写单个“爱/爽/虐”标签）
总集数 / 单集时长 / 预计总时长：
免费窗口 / 付费节点：
制作限制：主要场景数、角色规模、特效等级、内容边界
一句话 Logline：
核心卖点：用一个可见画面证明
对标方向：仅说明受众、节奏或类型定位，不复制具体表达
```

若涉及 IP，增加：授权范围、可改角色与不可改设定、原作粉丝承诺、新观众入口。

## 二、故事大纲

用 500–2000 字或用户指定长度写完整因果走向，覆盖：

1. **开局与引爆**：主角的失衡状态、开场卖点、不可回避事件；
2. **第一次策略与进局**：主角如何行动，核心关系和对手如何形成；
3. **递进与中段换挡**：至少两次异质升级；不同剧情怎样变奏同一情绪内核；中点怎样改变规则、关系或目标；
4. **旧方法崩塌**：主角失去什么，哪条错误信念或策略被证明无效；
5. **高潮选择**：主角必须在什么不可兼得的选项中选择；
6. **结局与新常态**：主线结果、关系结果、观众最终情绪以及续作空间。

让 A 主线、关系线和暗线在高潮汇合。不要只写设定和前十集，必须写清终局方向。

## 三、人物小传

只写会影响行为的资料：

```text
姓名 / 年龄 / 身份：
可见反差与标志性细节：
Want（具体目标）：
Need（尚未承认的需求）：
Ghost / 关键前史：
Lie / 错误信念：
Flaw / 惯用错误策略：
筹码、边界与底线：
与主角的目标冲突：
关键选择与预期变化：
说话与行动习惯：
现实处境（身份带来的资源与限制）：
主导性人格特质（及它让人物拒绝或造成的后果）：
```

主角使用完整模板。反派至少写清目标、资源、自我合理化和最怕失去的东西。配角可缩减，但必须有即时目标和剧情功能。

## 四、留存架构

```text
开篇承诺：
前三集主线与关系承诺：
卡点 1：位置 / 兑现 / 新缺口
卡点 2：位置 / 规则或关系换挡 / 与卡点 1 的因果
卡点 3：位置 / 汇线 / 高潮前最大缺口
结局回报：
```

若用户只要求传统三段式立项书，可仅输出“项目参数 / 故事大纲 / 人物小传”；留存架构仍在内部确认。
