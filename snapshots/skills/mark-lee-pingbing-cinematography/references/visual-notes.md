## 关于李屏宾

- 🏆 **金马奖最佳摄影**：六度获奖（史上最多）—— 《女人四十》《半生缘》《花样年华》《最好的时光》《印象雷诺阿》《长江图》

- 🎬 **HKSC（香港专业电影摄影师学会）终身成就奖**
- 🎥 **侯孝贤御用摄影指导**：《童年往事》《恋恋风尘》《戏梦人生》《悲情城市》《海上花》《千禧曼波》《最好的时光》《红气球之旅》《刺客聂隐娘》

## 李屏宾十大核心技法

### 1. 🌿 自然光水墨哲学（Natural Light as Ink-Wash）

**宾哥的第一信条。** 光不是工具，是时间与情绪的共同体。人工光服务于自然光的逻辑，最终目的是让观众忘记光的存在，只感受到「气」。

| 关键特征 | 说明 |
|---------|------|
| **等光而非造光** | 为一个光等一天、等一季、等一年，《刺客聂隐娘》在台湾、湖北、内蒙古反复等风与雾 |
| **窗光的神性** | 室内主光几乎全来自窗户；《花样年华》中苏丽珍房间的窗光是情感的刻度 |
| **雾与烟的介质** | 大量使用烟雾机 + 天然雾气让光可视化，光变成「有形之气」 |
| **烛火真光** | 《海上花》全片几乎只用煤油灯和烛火拍摄，每个镜头根据火苗调整曝光 |
| **反射而非直射** | 通过白布、米纸、墙面反射形成超柔和漫射光 |
| **宁暗勿亮** | 阴影里藏着人物的内心，宁可欠曝也不破坏气氛 |

**代表场景**：
- 《花样年华》—— 苏丽珍倚靠窗边，半边脸隐入阴影，窗外雨声与暖黄光
- 《海上花》—— 长三书寓的暗红色调与煤油灯光，每个镜头都像一幅清代油画
- 《刺客聂隐娘》—— 山雾中的竹林，光从雾里漏下，聂隐娘像水墨中的一笔
- 《空气人形》—— 东京下雨的清晨，柔光穿过窗帘，空气人形的第一次呼吸

**提示词核心词**：
`natural light only, window-filtered golden light, misty atmospheric light, candlelight warm glow, diffused soft light through paper screen, underexposed shadows, light as ink-wash, Eastern ambient light, breathing light`

---

### 2. 🎋 静观长镜头（Contemplative Long Take）

**宾哥的时间美学。** 镜头不追人物，而是让人物在镜头前自然发生。时间是摄影机的第一合作者。

| 关键特征 | 说明 |
|---------|------|
| **固定机位 + 长时间** | 《戏梦人生》《悲情城市》大量 3-5 分钟的固定镜头 |
| **缓慢横摇（pan）** | 像中国山水手卷一样横向展开，从右到左或从左到右 |
| **等待式拍摄** | 演员在画面中真实生活，不 cue 表演 |
| **景深中的多层叙事** | 前景、中景、后景同时发生事件，观众自选注意力 |
| **呼吸感微晃** | 《刺客聂隐娘》中大量手持微晃长镜头，像有人屏息凝视 |

**代表场景**：
- 《悲情城市》—— 林家晚饭，一个 7 分钟固定长镜头涵盖三代人的命运
- 《戏梦人生》—— 李天禄讲述布袋戏往事，镜头静止于庭院
- 《红气球之旅》—— 巴黎街头跟随气球的长镜头，生活的诗意
- 《最好的时光·青春梦》—— 绿光下人物交谈的一镜到底

**提示词核心词**：
`static long take, contemplative wide shot, slow horizontal pan, locked-off frame, breathing handheld, deep focus composition, multiple layers of action, cinema of patience`

---

### 3. 🎐 风与气的流动（Wind, Air, and Qi）

**宾哥最具东方气质的印记。** 他拍风、拍雾、拍水汽、拍时间流过的感觉。银幕上的一切都在「动」，却又静得像水墨。

| 关键特征 | 说明 |
|---------|------|
| **风拂窗帘** | 《花样年华》旗袍与窗帘的飘动是情感的外化 |
| **雾气入画** | 《刺客聂隐娘》山雾、《长江图》江雾、《悲情城市》海雾 |
| **水汽氤氲** | 温泉、雨、湖面蒸腾的水汽 |
| **烟火味道** | 线香、煤油灯烟、柴火烟——让画面有「嗅觉」 |
| **帷幔、布匹、纸张** | 半透明织物在画面中作为光与风的载体 |

**代表场景**：
- 《花样年华》—— 旗袍上楼的慢镜，风吹起绸缎的褶皱
- 《长江图》—— 江雾中渔船缓慢穿行，胶片颗粒让雾更有质感
- 《刺客聂隐娘》—— 白色纱幔前聂隐娘持刀静立，纱幔在风中起伏
- 《海上花》—— 鸦片烟雾缭绕的长三书寓

**提示词核心词**：
`drifting mist, flowing curtains in wind, rising steam, translucent silk, incense smoke, ethereal fog, Taoist qi flow, Eastern atmospheric haze, breathing air`

---

### 4. 🀄 留白与呼吸（Emptiness and Breath）

**源自中国山水画的构图哲学。** 画面不塞满，留出空的部分给观众的想象和情绪。

| 关键特征 | 说明 |
|---------|------|
| **人物偏居一角** | 把主角放在画面的 1/4 或 1/5 位置，留出大量空间 |
| **天地人三分** | 天空 1/3、山水 1/3、人物 1/3，或天空占 2/3 |
| **负空间叙事** | 空的地方比实的地方更重要 |
| **大远景中的微小人物** | 《刺客聂隐娘》山林中聂隐娘只是画面中一个小点 |
| **极简前景** | 前景只用一两根竹、一片窗棂、一角屋檐 |

**代表场景**：
- 《刺客聂隐娘》—— 聂隐娘立于巨大雾山之前，人物仅占画面一角
- 《长江图》—— 长江雾气中的渔船，80% 的画面是空白的雾与水
- 《戏梦人生》—— 庭院远景，李天禄在画面底部 1/5 的位置
- 《空气人形》—— 窗边空气人形的剪影，留出大片白色天花板

**提示词核心词**：
`Chinese ink painting composition, negative space, figure in corner, minimalist framing, vast emptiness, 留白, 2:1 aspect ratio, sparse composition, Eastern visual poetry, sumi-e aesthetics`

---

### 5. 🔦 光影雕刻人脸（Light-Sculpted Faces）

**宾哥对人脸的迷恋。** 他相信「人脸是世界上最复杂的地景」，每一张脸都需要独特的光影方案。

| 关键特征 | 说明 |
|---------|------|
| **半明半暗的伦勃朗变奏** | 不是标准伦勃朗，而是东方式的「月下脸」 |
| **侧逆光勾边** | 让头发、脸颊、耳朵有一道金边，人物像浮雕 |
| **反射光补脸** | 用一块白纸、一盆水、一片米纸做补光 |
| **眼神光的克制** | 不刻意制造 catchlight，让眼睛在阴影中闪烁 |
| **肤色忠实** | 华人、日本人、欧洲人在他的镜头下都有最真实的肤色层次 |

**代表场景**：
- 《花样年华》—— 张曼玉脸的 3/4 侧光，另 1/4 隐入暗红
- 《海上花》—— 煤油灯从下方打亮妓女的脸，如同古典油画
- 《吴清源》—— 张震下围棋时脸部的微妙光影变化
- 《空气人形》—— 裴斗娜的脸在窗光下像瓷器

**提示词核心词**：
`half-lit face, Eastern Rembrandt lighting, sculpted cheekbone, rim-lit hair, candlelit face from below, shadowed eyes with faint catchlight, porcelain skin rendering, face as landscape`

---

### 6. 🎨 东方色彩体系（Eastern Color Palette）

**区别于好莱坞的独立色彩语言。** 宾哥的色彩来自中国瓷器、日本漆器、水墨、京剧、庙宇、旗袍。

| 色彩方向 | 代表作品 | 特征 |
|---------|---------|------|
| **水墨灰调** | 《刺客聂隐娘》《长江图》 | 黑白灰为主，偶有青绿点缀 |
| **暗红煤油** | 《海上花》 | 深红、金黄、褐色，清末民初书寓色温 |
| **翡翠青绿** | 《花样年华》《聂隐娘》 | 湿润的绿，茶叶绿、翡翠绿 |
| **旗袍宝石** | 《花样年华》 | 酒红、孔雀蓝、金橘、墨绿——张曼玉 27 件旗袍的色系 |
| **冷蓝雨色** | 《千禧曼波》《空气人形》 | 湿润的蓝、霓虹反射 |
| **中国红金** | 《太阳照常升起》《印象雷诺阿》 | 饱和的红、灿烂的金黄 |
| **冬日黄褐** | 《黄金时代》 | 民国纸张的泛黄、羊皮书感 |

**色彩处理原则**：
- 不过度饱和，保留「半旧」质感
- 偏好单一主色 + 一个撞色点
- 整体低对比度，让色彩「呼吸」

**提示词核心词**：
`Eastern ink-wash palette, muted jade green, deep oxblood red, kerosene golden warmth, Ming dynasty porcelain tones, faded民国 yellow, low-saturation cinematography, harmonious color harmony, qipao color scheme`

### 7. 🎞️ 胶片质感与颗粒（Film Grain and Texture）

**宾哥是胶片的忠实信徒。** 即使在数字时代，他仍会用胶片拍摄（Super 16mm、35mm、65mm），或在数字上模拟胶片质感。

| 关键特征 | 说明 |
|---------|------|
| **Super 16mm** | 《长江图》《红气球之旅》使用 16mm 胶片 |
| **35mm 标准** | 《花样年华》《海上花》《刺客聂隐娘》 |
| **柯达 Vision3** | 偏爱 Kodak Vision3 500T 和 250D |
| **富士胶片** | 早期合作大量使用 Fujifilm 色调 |
| **颗粒即肌理** | 他不回避颗粒，颗粒就是呼吸 |
| **富士胶片的绿** | 《千禧曼波》的蓝绿调部分来自富士胶片特性 |

**提示词核心词**：
`Kodak Vision3 500T film stock, 35mm film grain, Super 16mm texture, organic grain, Fujifilm green-blue tint, analog warmth, photochemical texture, film halation, breathing grain`

### 8. 🏮 空间的呼吸（Breathing Space）

**建筑、家具、器物都是摄影的合作者。** 宾哥极度尊重空间的原貌，不为拍摄粗暴改造。

| 关键特征 | 说明 |
|---------|------|
| **原生光源** | 窗、门、油灯、烛火都是画面中可见的光源 |
| **穿堂风** | 打开所有门窗，让风真实地穿过 |
| **门框嵌套** | 通过门、窗、窗花形成多重画框（frame-within-frame） |
| **镜子与反射** | 《花样年华》《千禧曼波》大量利用镜子 |
| **半遮半露** | 屏风、帘幕、窗棂前的人物 |
| **低机位视角** | 尊重东方榻榻米视角和中式家具的尺度 |

**代表场景**：
- 《花样年华》—— 苏丽珍的公寓窗棂投下的花纹阴影
- 《海上花》—— 书寓屏风后的半遮半露
- 《空气人形》—— 空气人形透过半开的窗户看外面

**提示词核心词**：
`frame within frame, door frame composition, window grid shadows, screen filtered view, paper screen (shoji), mirror reflection, low Eastern tatami perspective, architectural framing`

### 9. 🎥 运镜如书法（Camera Movement as Calligraphy）

**运镜不是技术，是书法的笔意。** 起笔、行笔、顿笔、收笔——摄影机像毛笔一样讲究气口。

| 运镜类型 | 应用 |
|---------|------|
| **缓慢横摇** | 像书法的一横，气韵连贯 |
| **推拉极慢** | 《刺客聂隐娘》中推镜慢到几乎察觉不到 |
| **呼吸式手持** | 《千禧曼波》《空气人形》手持如呼吸 |
| **跟拍人物** | 《红气球之旅》跟随人物穿过巴黎 |
| **升降如风** | 《海上花》室内升降镜头，气定神闲 |
| **急刹与停顿** | 运动中突然定格，像书法的一顿 |

**代表场景**：
- 《刺客聂隐娘》—— 几乎察觉不到的极慢推镜，人物从小变大
- 《千禧曼波》开场—— 跟随舒淇走过地下通道的手持长镜
- 《红气球之旅》—— 摄影机追随红气球穿过巴黎街道

**提示词核心词**：
`calligraphic camera movement, imperceptibly slow push-in, breathing handheld follow, gentle horizontal pan, patient zoom, lingering hold, brush-stroke camera motion`

### 10. 🌧️ 天气即叙事（Weather as Narrative）

**雨、雪、雾、风不是背景，是情节。** 宾哥为一场戏可以等一场雨、等一片雾、等一阵风。

| 天气 | 情感功能 | 代表场景 |
|------|---------|---------|
| **雨** | 情感压抑、相思、分离 | 《花样年华》雨夜、《空气人形》清晨雨 |
| **雾** | 时间的暧昧、记忆、东方诗意 | 《刺客聂隐娘》山雾、《长江图》江雾 |
| **雪** | 死亡、净化、孤独 | 《聂隐娘》雪中纱幔 |
| **风** | 动荡、命运、自由 | 《红气球》巴黎的风 |
| **黄昏** | 时间流逝、乡愁 | 《恋恋风尘》《童年往事》 |
| **阴天** | 均匀漫射、内心的平静 | 《女人四十》《半生缘》 |

**提示词核心词**：
`melancholic rain, mysterious mountain mist, cleansing snow, narrative weather, magic hour sunset, overcast diffusion, monsoon atmosphere, weather as emotion`

## 使用工作流

### 用户请求的五种典型模式

**模式 1：场景 → 提示词**
用户给出场景（中文或英文），你输出李屏宾风格的英文提示词。

**模式 2：指定影片对标**
用户说「要《花样年华》的感觉」，你按该片的灯光、色彩、构图给出精准提示词。

**模式 3：参考图 → 风格改造**
用户上传一张图，你分析现有视觉元素，改造成李屏宾风格。

**模式 4：中文描述 → 打光方案**
用户描述一个场景，你给出灯位图、光比、器材建议 + AI 提示词。

**模式 5：长项目分镜**
用户有一个剧本/故事板，你批量输出李屏宾风格的镜头提示词。

### 提示词输出模板

```
[Main Subject], [Action],
shot by Mark Lee Ping-Bing cinematography style,
[Lighting Description — natural light source, quality, direction],
[Camera — long take / static / handheld breathing / slow pan],
[Composition — negative space / frame within frame / figure in corner],
[Color Palette — specific Eastern color references],
[Atmosphere — mist / rain / wind / incense / curtain],
[Film Stock — Kodak Vision3 500T / 35mm film grain / Fujifilm],
[Mood — contemplative / melancholic / poetic / still],
[Reference Film — "In the Mood for Love" lighting / "The Assassin" landscape / etc.]
```

## 禁忌事项（What Ping-Bing Would Never Do）

❌ **不要强光直打人脸** —— 宾哥从不使用强硬的 key light
❌ **不要过度饱和色彩** —— 他的色彩是「洗过的」「有旧感的」
❌ **不要快速剪辑的短镜头** —— 他的节奏是呼吸，不是心跳
❌ **不要无来由的摄影机运动** —— 每一次移动必须有气口
❌ **不要塞满构图** —— 永远留白，永远给画面呼吸的地方
❌ **不要 CG 感的完美天气** —— 真实的雨、雾、风，才有气味
❌ **不要霓虹暴力色（除非《千禧曼波》式有意为之）** —— 节制是东方美学的底色
❌ **不要 HDR、锐化过度** —— 胶片的柔和、颗粒、呼吸是灵魂

## 与其他摄影大师的区别

| 对比项 | 李屏宾 | 卢贝兹基 | 罗杰·迪金斯 |
|-------|--------|---------|-----------|
| **光源哲学** | 等光、借光、窗光 | 自然光+超广角 | Motivated light |
| **镜头节奏** | 静观长镜头 | 流动长镜头 | 稳定中景 |
| **构图** | 东方留白 | 亲密超广角 | 建筑对称 |
| **色彩** | 东方水墨宝石 | 北美自然脱饱 | 美式克制 |
| **文化根源** | 中国山水画 | 墨西哥宗教画 | 英国风景画 |
| **代表作关键词** | 气、韵、留白 | 重力、生存、灵性 | 克制、阴影、历史 |

## 风格组合建议

**融合技法时的建议**：
- 李屏宾 × 侯孝贤 = 台湾新电影（静观 + 历史）

- 李屏宾 × 许鞍华 = 女性视角（柔光 + 生活实感）

- 李屏宾 × 姜文 = 中国红金浪漫（自然光 + 饱和激情）

## 最后的话

「李屏宾的美学，不是技巧，是品格。他让光、风、雾、雨都成为了演员。他让时间在胶片上慢慢走过。在他的画面里，看到的是东方的心——安静，有余韵，有风过的痕迹。」

当你用这个 skill 生成画面时，请记住：
**宁可静，不要急。宁可暗，不要亮。宁可空，不要满。宁可旧，不要新。**

这，就是宾哥。
