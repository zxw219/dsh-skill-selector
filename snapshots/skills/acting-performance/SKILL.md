# ACTING 角色表演

把人物目标与情绪转化为可拍摄、可生成的行为。

## 工作方式

1. 从剧本提取当前目标、对手、阻碍、失败代价和已知信息。不把推测写成既定剧情。
2. 选择由事件触发的少量行为：手头事务、停顿、呼吸、视线、姿态、距离或语气变化。行为服务意图，不堆表情形容词。
3. 跨镜头角色可建立主档案：身体基调、声音身份、标志动作及触发条件、掩饰方式与失守条件。每镜只抽取相关部分，不整段粘贴。
4. 写出聆听和反应，保留情绪余波。群像按人物错开反应，但允许有意同步。
5. 按时长与景别删减动作：短镜头可只有一个变化，特写减少夸张动作，远景不堆眼部微动作。

## 适配规则

- 不强制每场戏有输家、每人有小动作、固定 2～4 次转折或只有一个柔软对象。“强者静、弱者动”只是可选手法，服从人物和类型。
- 关注对象稳定不等于眼球冻结；允许自然眨眼与微扫视，同时保持重要视线关系。眼神光遵守真实光源，不因情绪自行变色。
- 声音身份保持一致，语速、音量、气息随表演变化。文字档案不能保证生成声音完全相同。
- 动作过程重要时写起点、触发、过程、接触和结果；复杂动作可拆镜头，不一律写成静态姿势。
- 不重复服装、镜头和调色。与 CINEDANCE 配合时只交付表演层，由镜头技能组织最终格式；不默认加载其他技能。

## 输出与检查

按请求输出表演段、角色档案或诊断及替换写法。检查动机、角色当前知识、时长、视线、身体方向、情绪衔接和声音身份。用户只要提示词时不附完整分析。
