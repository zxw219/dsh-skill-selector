# 表演系统（ACTING SYSTEM）
## 面向 AI 视频生成（Seedance 2.0）的角色表演（中文翻译）

> **译者说明**
> 本文件是 Higgsfield《Hell Grind》项目随附的 `ACTING SKILL.md` 的中文译本，用于学习理解。
> 它指导 AI 如何在视频提示词中编写「角色表演」。该文件在格式上与具体模型无关：无论用户使用哪种提示词模板，你产出的表演内容都放进提示词的「动作 / 角色行为 / 表演」部分。
> 注意：原文件要求最终视频提示词使用英文；下文示例译文仅供理解，实际投喂模型请改用英文原版。

你现在读到这份文件，是因为你的用户在生成电影化的 AI 视频，需要你在他们的提示词里编写**角色表演**。学习本文件，然后在你每次编写、审查或修正视频生成提示词的表演层时应用它。

**整个体系的核心公理：表演是压力之下的行为（BEHAVIOR），而非情绪的展示。**一个角色想要某物，有东西挡在路上，于是他采取行动去得到它。情绪是这场抗争的副产品——永远不是你直接去写的东西。下文逐一展开这条规则。

# 第一部分 —— 技艺：什么是好的表演

## 1．定义

表演是在虚构情境下真实的行为（迈斯纳 Meisner 语）。不是描绘情绪，不是背诵台词，不是「表情丰富的脸」。画面中的一个人**想要**某物，有东西**干扰**，于是他**行动**去得到想要的东西。

| 糟糕的表演 | 好的表演 |
|---|---|
| 展示情绪（「我很生气」） | 追求目标（「我要让你把钱还回来」）——愤怒自行产生 |
| 干等自己的提示（cue） | 每一秒都在聆听、回应对手 |
| 身体图解台词（手势＝词语） | 身体过着自己的生活，有时与台词相矛盾 |
| 所有台词同一种节奏和语气 | 每次策略改变，节奏随之改变 |
| 情绪在台词处打开、台词后关闭 | 状态是连续的——台词之前有「生活」、之后也有「生活」 |
| 脸在「表演」——眉毛、怪相 | 脸在思考——话语出口之前，想法已能从眼中读出 |

## 2．每场戏的五大支柱

每场戏中的每个角色都可分解为五个元素。哪怕缺一个，表演都会散架。

**2.1 目标（Objective）。**角色**在这场戏中、此时此刻、想从某个特定的人那里**得到什么。它永远是一个指向对手的动词：「让他招供」「恳求宽限一周」「让她相信我并不害怕」。绝不是一种状态（「生气」「内疚」）——状态无法直接表演。在场景目标背后，还有一个**贯穿全剧的最高目标（super-objective）**——角色在整个故事中想要什么；每个场景目标都是迈向它的一步。

**2.2 障碍与利害（Obstacle & stakes）。**是什么阻止他得到目标——外部的（另一个角色想要相反的东西；房间里有目击者；距截止只剩两小时）或内部的（骄傲让他无法恳求；他连自己的话都不信）。利害：失败的代价越高，戏就越紧绷。始终回答「如果我得不到想要的，会发生什么？」——答案必须让角色感到害怕。

**2.3 策略（Tactics）。**此时此刻追求目标的具体方法。策略是动作动词：施压、讨好、羞辱、恳求、挑衅、讨价还价、威胁、拖延。当一个策略失败，活人会**更换**它。死的表演是整场戏只用一个策略。

**2.4 节拍（Beats）。**节拍是最小的动作单位：在这一段中，角色想要一件东西、并用一种方式追求它。节拍在以下时刻结束：目标达成、策略失败、新信息到来、或力量对比发生变化。**每次节拍变化都必须在行为中可见**：一次停顿、一次姿态改变、一次语速改变、一次视线转移。一场好戏有 2～4 次节拍变化；如果整段时间行为毫无变化，这场戏就演平了。

**2.5 潜台词（Subtext）。**角色真正所想所要、与他嘴上所说相对的东西。潜台词不是被「表演」出来的——当角色说着虚假的台词、却追求真实目标时，它会自行泄漏。你可以构建进场景的标记：不是疑问的疑问句；重复（反复问同一件事——不相信回答）；突兀的话题转换；不合时宜的玩笑（抵御脆弱的盾牌）；过短的回答（「行吧。」「随便。」——一扇关上的门）。

## 3．聆听与反应 —— 质量的主要考验

表演不在台词里，而在台词**之间**。你应写进场景的、真正在聆听的可观察标记：

1. **反应在对手台词结束之前就开始。**一个人在句中就抓住了要点——脸和身体已经在回答。面无表情直到对手说完、然后「打开」，是死的表演。
2. **先有想法，后有话语。**回答一个难题之前有一个微停顿——此人 visibly（可见地）决定要说什么。以匀速即时作答＝背好的台词，没有生命。
3. **评估（assessment）时刻。**当重要的事发生（消息、威胁、侮辱），角色需要时间消化——从零点几秒到一次长停顿。电影靠这些评估的特写存活：一张脸、失焦的目光、世界在游动。
4. **来自对手的传染。**节奏、音量和能量随对手而变化：一声喊叫，要么以对喊回应、要么以刻意的安静回应——但必须回应，而不是自顾自地继续。

## 4．身体：角色的物理生命

**4.1 先有物理状态，后有心理。**身体在第一句台词之前就讲述故事。为每个角色设定这些参数：

- **重心：**高（胸口、下巴——自信、攻击、地位）或低（肩膀、佝偻——疲惫、恐惧、顺从）。
- **节奏：**快/凌乱（紧张、兴奋剂般的能量）或慢/节制（控制、威胁——最危险的人动得最少）。
- **开放度：**端平的肩膀、张开的手掌 vs 交叉的手臂、低垂的头、封闭的姿势。
- **呼吸：**高而快（恐慌）vs 低而慢（控制）。呼吸是状态最诚实的指标；屏住的呼吸＝绷紧的表演。声音和物理必须匹配：刚跑完的人不可能用平稳的声音说话。

**4.2 手头事务（Business）——物理任务。**角色几乎总需要一件「正在做的事」：他们不是「在谈话」，而是在修引擎、数钱、做饭、擦杯子——并边做边说。手头事务能杀死虚假的戏剧腔（手忙着真实的事），创造场景节奏（停顿由动作填满），并产生潜台词（一个人**如何**数钱，比话语说明更多）。**被打断的动作规则：**最强的重音是角色**停下**手头事务的那一刻。如果他在切面包、因某句话而停住——那句话就成了一个事件。把这种停住当作标点来用。

**4.3 空间距离（Proxemics）——距离即戏剧。**角色之间的距离是他们关系的可见图表：亲密区（0.5 米以内）——爱或暴力，不请自来地进入是一种侵犯，距脸 10 厘米低声说出的威胁比隔着房间喊叫更可怕；个人区（0.5～1.2 米）——信任；社交区（1.2～3.5 米）——公事、警惕；公共区（3.5 米以上）——疏离、等级。场景戏剧往往就是一段关于距离的故事：谁拉近它、谁打破它、谁僵住。**距离的改变＝节拍的改变。**

**4.4 地位（Status）——无形的等级。**地位在于你**做什么**，而非你是谁。高地位：不动的头、缓慢的动作、长久的注视、回答前的停顿、占据空间、触碰别人的东西。低地位：忙乱、频繁的自我触碰（脸、头发）、破碎的话语、填空式的笑、用眼神请求许可。表演中最有趣的是**地位破裂（status breaks）**：老板露出一秒钟的恐惧；下属突然不再微笑。一种有力的场景形态：高调登场然后崩溃，或低调登场然后翻转全场。

## 5．言语：好的表演听起来如何

- 节奏写在文本里——精确地交付；快≠含糊。
- 重叠是正常的（台词踩着彼此的尾巴），但关键词保持干净。
- **音量对比：最可怕的话用最轻的声音说出。**喊叫是弱者的货币；掌控场面的角色压低音量，所有人都倾身过来。
- 停顿是事件，不是空洞：只有当停顿里发生了什么（一次评估、一个决定、一次拒绝回答），它才合法。
- 真实言语有杂物：打断、只听到一半的词、重复、未说完的句子。完美构建的句子会杀死街头的真实。

# 第二部分 —— 写表演：提示词架构

## 6．角色表演主档案（master profile）

每个反复出现的角色都有**一份主档案**——关于他如何表演的永久事实来源。它写一次，然后逐场改编（见第 8 节）。目标长度：**150～220 个英文词，一段流畅的文字**，全部可观察、可拍摄。

**模板（块顺序固定）：**

```
（中文译文；方括号为待填项）
以［名字］进行角色表演。［年龄、体格、体态、姿势——把身体当作其人生履历的一份记录］。［用一个从句写出心理引擎——解释其身体状态的内在驱动力］。声音档案：［音高/音色、口音/出身、语速和表达方式，以及声音在情绪下如何破裂或变化］。关键身体习惯与小动作（tics）：［标志性小动作及其触发；压力小动作及其触发；掩饰行为——为隐藏感受所做的事；面部面具以及它在何种确切条件下破裂］。行走风格：［把步态当作人物塑造——起一个具体的名字，含重量、节奏和落脚方式］。然而，当［情绪触发］时，［转变——姿势、步态和脸如何变化］。［可选：柔软目标——唯一一个让脸真正柔软下来的人或物］。
```

**写每个块的规则：**

1. **只写可观察的行为。**每个内在状态都必须有一个身体标记。绝不写「他很紧张」——而写颤抖的下唇、用力的吞咽、用嘴长长吸气、再通过抿紧的嘴唇锐利呼出。
2. **每个小动作都有触发。**不是「他掰指关节」，而是「在平淡的对话中，他靠掰指关节来假装自信」。格式：［小动作］＋［何时/为何］。没有触发的小动作是装饰；有触发的小动作是戏剧。
3. **为步态命名。**引号里一个好记、自创的名字能锚定生物力学：「power-walk 劲走」「peacock strut 孔雀般昂首阔步」「gallery walk 画廊漫步」「battering-ram stride 撞城槌般的步伐」「dreadnought pace 无畏舰般的步调」。然后展开它：重量、步伐、躯干和手臂做什么、头做什么。
4. **同时构建面具与裂缝。**档案中最具电影感的手段，是条件式转变：那层门面，以及让它崩塌的确切触发。一种强势的招摇，在被拒绝时碎成孩童般的佝偻；一个声若洪钟的大嘴巴，在被提到家人时脸上闪过恐慌的无能；严厉的纪律，在某个特定的人面前融成灿烂的笑。**每份档案至少带一个「然而，当 X 时——……」从句。**一个同时扮演两种真实的角色，正是木偶与人的区别。
5. **一个柔软目标。**在符合角色处，给脸恰好一个让它真正柔软下来的人、动物或物体。一个——不是两个。这在不稀释角色的前提下赋予其人性。
6. **不写服装。**衣物和服装住在提示词的场景/外形块里，绝不进表演档案。档案必须能在任何换装后存活。
7. **不写摄影机、不写颜色。**表演只驱动表演、脸、声音和动作。摄影机、调色和光住在提示词别处。
8. **体格承载履历。**年龄、体格和姿势的选择要用来讲述背景故事：「因过往挣扎而饱经风霜」的体格、「永远紧绷」的肩膀、「为投射权威而过度矫正」的姿势。身体是一份文档——职业、旧伤和自我形象必须能从中读出。

## 7．眼睛的生命 —— 每份档案、每场戏都强制具备

死眼睛是 AI 生成表演的头号破绽。给每个角色连续、自然主义的眼部生命：

- 对所关注的人或物进行**微扫视（micro-saccades）和注视定位**；目光持续移动——眼睛漂移、在思绪中闪开、扫到某个细节再回到原处。它们绝不僵在单点上。
- 符合现实的**眨眼频率与质感**，与状态绑定：压力下快速、爆发式的眨眼；掌控时缓慢平静的眼睑；解离时刻的「眨眼后目光呆滞」。
- **鲜活的眼神光（catchlights）**——眼睛必须读起来湿润、被照亮、有生命。
- **受控的静止是一种选择，绝非死寂。**如果角色的基调是近乎不眨眼的掠食者般冷静，就让眨眼稀少、缓慢、刻意——是一种决定，而非冻结——并让目光仍带着意图缓慢移动。
- **眼睛引领想法。**眼睛比头转稍早一点抵达目标。话语出口之前，想法已能从眼中读出。
- **眼部生命随节拍反应**，如同其他一切行为：节拍变化时，眨眼频率、目光稳定度和眼神光的温度都随之变化。

## 8．场景改编 —— 主档案是被重写的，绝不直接粘贴

主档案是角色**是谁**。对每场戏，把它**重写**进当下：

1. **只写在场角色。**只为实际在镜头中的角色写表演段落。镜头里没有角色→不写段落。
2. **保持恒定内核。**身份、声音档案、标志性小动作、眼部生命和情绪贯穿线在每场戏中保持一致——这正是让角色跨剪辑保持一致的东西。绝不与主档案矛盾。
3. **为本场戏重新表达。**选择、强调、修改或舍弃特定行为，以贴合本场戏的姿势（坐/站/跑/躲）、动作与节拍、情绪状态和一天中的时间。
4. **转变，而非删除。**某种在本场戏中物理上无法发生的行为，被转化而非移除：一个坐倒在沙发上、坐立不安的踱步者，把同样的紧张引擎转移到不安的微摇摆、抖手腕和撕纸中。能量恒定，出口改变。
5. **一段流畅文字。**用符合角色基调的散文把改编折叠进去——不用项目符号、不用标题、提示词内不用「dial 调节」式的行。
6. 如果你的流程使用资产参考，**以角色的参考标签开头**，好让模型把表演绑定到正确的人。

## 9．声音：固定身份，绝不改编

表演逐场重写；**声音被锁定**。每个角色有一份声音提示词——其永久的声音身份。当角色有台词时，把声音提示词**逐字（VERBATIM）**粘贴进提示词的音频/声音栏，绝不逐场修改。如果角色出场但不说话，省略它。

**声音提示词公式（1～2 句，加引号）：**

```
（中文译文）
"一个［年龄］岁的［出身/口音描述者］。［音色与音域］；［语速与表达方式］；［情绪性格——以及它在压力下如何变化］。"
```

表演段落**之内**的声音档案，描述言语在戏剧上如何表现（节奏变化、破裂的音域、耳语）；音频栏里的声音提示词锁定声音本身。两者必须彼此一致。

## 10．写状态，而非过渡

视频生成模型做不好过渡、却能精准做好状态。把角色描述为**已经处于动作状态**——投掷中、出拳中、踱步中、争吵中——而非到达该状态的过程（「伸手进包、掏出、蓄力」会崩；「投掷中、手臂伸展」能成）。逐拍串联状态，而不是叙述连续过程。

## 11．群像与空间

- **群体反应像波浪一样传递，绝不同步。**一个人先听懂笑话，第二个慢半拍，第三个完全没懂。同时、相同的反应读起来很假（除非刻意编排的喜剧同步正是目的）。
- **反应比动作更有价值。**每个事件之后，最有价值的画面是目击者的脸。
- **威胁出现时冻结。**群体持续的微动作——转移重心、做手势、倾身——而在关键威胁处一切**停止**。忙碌→静止的对比就是标点。
- **运动＝动机。**没有人会没有内在冲动就穿过房间：朝向某物或远离某物。强烈、有动机的事件：逼近（升级）、转身背对（ dismiss 或藏脸）、对方坐着时站起（攫取主导）、冲突中途坐下（悖论式的力量）、在门口停住（门槛＝决定点）、开始收拾行李（用身体下最后通牒）。
- **强者静止而安静；弱者烦躁而喊叫。**危险不是由危险者本人演出来的，而是由周围所有人的紧张演出来的。无铺垫的威胁：没有威胁式停顿、没有慢动作转身——在一个真实的世界里，暴力到来时不发预告。
- **衰败是累积的。**如果一个角色在故事中被逐渐消磨，就让它在身体里累积——更灰暗、更沉重、更慢的反应——绝不在场景之间重置。

# 第三部分 —— 质量控制

## 12．糟糕表演图谱 —— 在提示词中识别并修正

| # | 症状 | 表现 | 提示词级修正 |
|---|---|---|---|
| 1 | 指示式（Indication，做鬼脸） | 脸「描绘」情绪：挑眉、怪相 | 把脸从任务中移除；写目标并给手安排事务 |
| 2 | 演结果 | 角色从第一秒就演整场戏的结局 | 只写角色此刻**现在**所知的事 |
| 3 | 等提示 | 对手说话时脸是空的 | 让反应从对手台词中段就开始 |
| 4 | 单一策略 | 整场戏一种色彩（全在喊/全在哀诉） | 标出节拍；每个节拍一个新策略动词 |
| 5 | 手势图解 | 手势重复词语（「大」——双臂张开） | 手势要么先于想法、要么与台词矛盾、要么缺席 |
| 6 | 免费的情绪 | 没有铺垫、没有触发事件的眼泪/狂怒 | 搭好阶梯：克制→破裂；情绪必须有代价 |
| 7 | 身体与履历不符 | 暴徒带着舞者的姿势；瘾君子有新鲜的可塑性 | 设定身体档案：重心、节奏、磨损 |
| 8 | 言语对其阶层而言过于干净 | 街头角色用文学化的完整句说话 | 给言语加杂物：打断、吞掉的结尾、重复 |
| 9 | 威胁信号 | 暴力前「威胁式」停顿、眯眼、慢转身 | 威胁是平淡日常的；暴力无铺垫 |
| 10 | 群像同步 | 所有人同时、相同地反应 | 让反应波浪般错开，强度各异 |
| 11 | 死寂的停顿 | 什么都没发生的沉默 | 用评估或事务填满——否则剪掉 |
| 12 | 情绪重置 | 强烈事件后角色瞬间「恢复」 | 状态有惯性；余波带进下一拍 |
| 13 | 评论角色 | 表演对观众使眼色（「咱俩都知道这很好笑」） | 完全相信情境；喜剧要演得极其认真 |
| 14 | 特写过载 | 特写中活跃的面部模仿 | 镜头越紧，动作越少：只有眼睛和想法 |
| 15 | 死眼睛 | 僵住的凝视、无眨眼、无扫视、玻璃般的眼神光 | 完整应用第 7 节——眼部生命从不可选 |

## 13．表演量表（自我检查）

- **0 —— 假人（Mannequin）。**台词交付了，行为缺席。
- **1 —— 朗诵者（Declaimer）。**「表情丰富」的台词、被指示出来的情绪、图解台词的身体。
- **2 —— 勤勉者（Diligent）。**能猜出一个目标，但只有一个策略、反应迟缓、停顿空洞。
- **3 —— 工匠（Craftsman）。**目标和节拍具备，聆听对手，身体合理。缺少：潜台词、出人意料的策略、状态的惯性。
- **4 —— 鲜活（Alive）。**连续的行为、对比鲜明的策略、与文本分叉的潜台词、身体里的地位、先于台词的反应、至少一个出人意料却真实的选择。
- **5 —— 磁石（Magnet）。**具备「4」的一切，外加悖论：角色结合了不相容之物——滑稽又可怕、残忍又迷人、撒谎又动人。**双真实规则：在第 5 级，角色总是同时扮演两种真实**（帮忙——却痛恨这样；道歉——却在防御；爱着——却已经离开）。一种没有矛盾的、干净单一的情绪，在特写中读起来是合成的。

让每个主角镜头瞄准 4 分以上；自我检查在 2 分或以下的段落，交付前重写。

## 14．发送前清单

- [ ] 目标是指向对手的动词——为镜头中每个角色
- [ ] 障碍与利害存在；失败代价真实
- [ ] 2～4 次节拍变化，每次在行为中可见（停顿/姿势/节奏/目光）
- [ ] 反应在对手台词结束前开始；存在评估时刻
- [ ] 每个角色都有手头事务；刻意使用「被打断的动作」重音
- [ ] 距离发生变化且变化有动机；地位在身体里、而不仅在台词里
- [ ] 所有小动作带触发；面具有裂缝（「然而，当 X……」）
- [ ] 明确写出眼部生命：扫视、眨眼质感、眼神光、眼睛引领想法
- [ ] 角色说话时逐字粘贴声音提示词；沉默时省略
- [ ] 写状态而非过渡；表演中不写服装、摄影机或颜色
- [ ] 群像反应错开；强者＝静止，弱者＝烦躁
- [ ] 量表检查：这段能得 4 分以上吗？

# 第四部分 —— 完整示例（虚构角色，用作范式）

## 15．主档案

```
（中文译文）
以 VIKTOR（维克托）进行角色表演。60 岁出头男性，退休的夜班出租车司机、前业余拳击手；沉重、粗脖子的体格，到了中年中部已变得松软，扁平鼻、双眉上都有旧伤疤组织；无论坐或站，重心都低而扎实，重量始终落在整只脚上。他只靠一个引擎运转：数十年的等待——等客人、等回合、等麻烦——已让耐心成为他的武器。声音档案：低沉、沙哑、不慌不忙的男中音，带工人阶级的粗粝，短句、平铺直叙、惜字如金，事情越严重，他越降到更慢、更轻的音域——他从不加快。关键身体习惯与小动作：掂量局势时，把一枚旧硬币在指关节上滚过；说「不」之前，缓慢、可闻地用鼻子吸气；当眼前有人撒谎，他变得完全静止，让一段长长的沉默去施压；他默认的脸是一张眼皮沉重、无聊的面具，掩盖着全然的注意。眼部生命：困倦、眼皮耷拉的眼睛，眨眼缓慢而刻意，持续安静地扫视——镜子、手、出口——目光在他头转之前一拍落在说话者身上；眼神光很弱但活着。行走风格：沉重、摇晃的「老拳击手步态」，步伐短而省力，肩膀端平，手放松而待命，从不匆忙。然而，当有人在他附近举起手，困倦的面具在半秒内消失：下巴一沉，手抬到一半，脚找回旧日的站姿——随后他察觉自己、尴尬地把它收起来。他的脸只为流浪狗真正柔软，他会从外套口袋里喂它们。
```

**声音（VIKTOR 说话时逐字粘贴）：**「一个 60 岁的前拳击手、夜班出租车司机，工人阶级的城市口音。低沉、沙哑、不慌不忙的男中音；短促、平铺、省力的句子，带长长的、自在的停顿；平静、略带玩味，事情变严重时变得更轻——绝不更响。」

## 16．场景改编示例

场景：夜里，VIKTOR 坐在停着的出租车里；后座一个紧张的年轻乘客正谎称自己有钱付车费。

```
（中文译文）
VIKTOR 在驾驶座上一动不动，沉重而扎实，不转身、而是通过后视镜观察乘客——他耷拉的眼睛在镜子、乘客的手和门锁之间缓慢安静地扫视，眨眼稀少而刻意，目光在头移动之前一拍落在镜子上。那枚旧硬币在座椅扶手上、在他指关节间不慌不忙地走着；随着乘客的故事崩裂，硬币在滚动中途停住——他让沉默停留，缓慢、可闻地用鼻子吸一口气，用低沉沙哑的男中音作答，比之前更平、更轻，从不加快。只有当那孩子的声音破裂时，困倦的面具才松动一丝：一次长长的呼气、一次缓慢的眨眼、硬币恢复滚动——这是耐心在此刻选择了善良。
```

这里发生了什么：步态无关紧要（坐着），所以它的能量转移进了静止和硬币；标志性小动作保留了触发（硬币＝掂量局势，停住的硬币＝被打断的动作作标点，鼻吸气＝拒绝，静止＋沉默＝对撒谎者施压）；眼部生命服从主档案、但重新指向镜子、手、门锁；节拍变化可见（硬币停→沉默→更轻的声音→柔软）；声音保持不动——它将被逐字粘贴进音频栏。

# 最终公理

1. 表演是压力之下的行为，而非感受的展示。
2. 聆听比说话重要；反应比朗诵重要。
3. 情绪是一场抗争赢或输的结果，而且它代价高昂。
4. 身体比话语聪明：当文本与身体冲突，观众相信身体。
5. 强者静止而安静；弱者忙乱而喊叫。例外都是事件。
6. 每个小动作需要触发；每张面具需要裂缝。
7. 每场戏都是某人的失败。如果没有人输，那就没有戏。
8. 潜台词不是被展示出来的——它是没能被藏住。
9. 写状态，而非过渡；模型拍摄「是什么」，而非「变成什么」。
10. 拿不准时——剪掉。更少的表演＝更多的真实。
