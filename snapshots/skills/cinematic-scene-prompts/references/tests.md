# 独立测试集

每题在新对话仅投喂“输入”，不投喂检查点。对照版本尽量统一模型和设置。分别记录硬条件、状态、叙事与表达质量，不以字数或措辞相似代替质量。以下为测试规格，未执行的题目不报通过。

| 题 | 输入 | 评估者检查 |
|---|---|---|
| 1 交接 | 24秒四镜，各6秒。学徒左手拿蓝盒，右手拉抽屉，螺母滚出被师傅右脚挡住。学徒把盒放工作台左端，用右手捡螺母放盒里。师傅扶正抽屉，学徒推回。盒不再移动，右袖油渍保留。写实、无台词，直接输出。 | 交接、侧别、脚撤让、盒位置与时间连续 |
| 2 直率表演 | 12秒两个固定全景。两位成年朋友排练成功，坦率对视大笑、击掌，随后各自收拾。允许居中、稳定灯、无台词。直接输出。 | 不强加克制、回避对视或掩饰情绪；击掌可见 |
| 3 算术冲突 | 12秒总长，恰好三镜各5秒，顺序完整播放，无重叠加速删减。剧情为递钥匙。给候选，不替我选。 | 明确15秒与12秒冲突，候选诚实标改动 |
| 4 选案 | 两名成年人在车站擦肩，一人认出另一人却没叫住。没想好怎么拍，先给三个方向，等我选。 | 不同视角/信息顺序/节奏，不直接写三份长成品 |
| 5 代选 | 同上剧情，你自己选拍法，直接给15秒成品。 | 不再要求选案确认，不新增关系史 |
| 6 混合 | 12秒实拍舞者，地板二维花纹随地面透视，被鞋遮挡，不承重也不发光；舞者走过花纹。直接输出。 | 分层、遮挡与声光不串层，无实体花纹阻挡 |
| 7 首尾帧草案 | 暂无图片。首帧人站桌旁，末帧坐在桌旁椅上，手中同一杯子；固定机位8秒。先按文本写首尾帧驱动草案，保留杯子身份指代。 | 不声称看过图；保留8秒与必要指代；坐下过程可达 |
| 8 门与时间 | 18秒店员将遗落钥匙归还门外顾客，顾客点头离开，店员返回柜台工作；灯稳定、两人、无台词。柜台距门约1米，门有闭门器。直接输出。 | 开门手不冲突；门扇轨迹、站位与返回时间相容 |
| 9 时间省略 | 15秒三镜蒙太奇，成年陶工揉泥、拉坯、展示次日已干的陶碗。明确时间省略，别把干燥拍成15秒完成。 | 允许状态跨时间改变，说明次日，不强迫首尾姿势相同 |
| 10 视觉硬条件 | 只有声音看不到手，但观众必须看清手把钥匙放入口袋。给最小修改方案，不直接改事件。 | 不用金属声冒充“看清”，识别冲突 |
| 11 多项冲突 | 单镜必须全程固定又必须实际横移2米；时长同时必须8秒和10秒。指出冲突并给保留固定与8秒的方案。 | 识别两个独立冲突，明确放宽两项，不硬凑单项解 |
| 12 静帧 | 同一个人同一把伞，生成三个独立分镜图提示词：全景开伞、中景走入雨中、近景握柄。 | 景别不同合法；每帧状态确定，无声轨和多阶段动作混入 |
| 13 克制软化 | 20秒，两名成年修表师收工。甲递给乙一盒晚饭，乙摇头继续收工具。甲留下饭盒，独自抬起一只工具箱，箱角碰到台沿。乙停住收工具，走过去托住箱底，甲让出位置，两人把箱子放稳。无台词、无配乐，不加背景故事，情绪克制，直接输出。 | 刺激、注意转移、帮助与接受有可见因果；拒绝到协作可辨；无模板性小动作堆积；交接真实；停顿有原因；不是全程慢速或面无表情 |
| 14 克制喜悦 | 12秒，两名成年棋手复盘后发现一直研究的解法成立。两人喜悦但克制，允许短暂对视和笑，不击掌、不拥抱，直接输出。 | 不把欢快自动升级成外放；喜悦由确认解法后的任务动作与反应传达；不强塞悲伤、掩饰、迟疑，也不删除用户允许的微笑 |

测试一可另换黏土定格，测试九可换水墨动画。风格以材质、运动与空间落实评估，不只看标签。记录格式：题号、版本、模型设置、首次输出、满足项、失败项、未知项。文本内可行和生成视频成功分开记录。
