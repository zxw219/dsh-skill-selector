# 状态与预算（B；账本定位来自C）

只对受约束或决定动作的元素记录状态。复杂任务可用表，简单任务用短记录即可。内部规划不默认作为输出附件。

## 状态字段

| 对象 | 需要时记录 |
|---|---|
| 空间 | 工作面、边界、出入口、人物起点、可走路径、相机可站位置；影响动作的尺寸与距离 |
| 道具与痕迹 | 身份、位置、朝向、持有与接触者、可见性、锁定起点、伤痕侧别 |
| 人物 | 姿态、身体与视线朝向、支撑、左右手占用、所在区域 |
| 时间 | 动作依赖、可并行部分、反应与辨认时间、机械耗时、结尾落点 |
| 声光 | 光源与声源的位置、工作状态，运动造成的反射、遮挡与距离变化 |

场景中的左右与画幅左右分开记录。换机位后重新投影关系，不靠一句“越轴已解释”保证看懂。布局有多个可行解，自拟东西方向不是任务唯一必要条件。

## 交接与镜头接口

先接触 → 接手者承重 → 原持有者松手 → 最终持有者移动或放置，服从用户具体剧情。检查接触点与手的占用，避免一只手同时持物、开门和撑地。

连续动作镜头衔接到同一状态或同一动作的相容阶段。反应镜头期间主动作可以合理继续；必要时在返回镜头写明推进后的状态。用户要求的完整交接保留可见证据。明确省略时间时可以跳过非关键过程，在镜头说明里标"时间省略"及新状态，不凭空改变道具归属或损伤。跨镜或分段clip提交时，每镜末尾默认附"下一镜必须继承"状态短块，把起点状态显式化；后一clip的首帧承接前一clip的末帧。

## 通路机械

涉及门等装置时确定铰链/轨道、开启方向、操作者与手、运动范围和人物区域。支持关闭、半开、开启中、打开、关闭中、暂停或反向等实际状态，不强迫每次完整开关一轮。

开门时人物避开门扇轨迹；交接写清脚、手、物在边界哪侧。玻璃反射作为发现依据时必须有合理视线；简短的转身或检查动作可补原因，但不能改掉用户指定的触发。

移动门上的反射可随门角变化。灯光稳定和反射固定不是同一个条件。门改变声音遮挡；同一声源持续不等于从所有机位听来音量相同。

## 时长推演

路径距离与步速采用合理近似，机械回位需时间；不同人物动作可以并行，等待条件须显式算入。升格与慢动作按渲染后画面时长计入，事件真实时长不等于画面时长，两秒装不下升格的倒地。不能把"点头、离开、等待门关、回到数米外柜台、继续工作"笼统塞进短收尾。

先给关键落点足够辨认时间，再安排前置动作。增加镜头本身不会增加总时长；只有重新分配预算、允许省略、减少次要动作或调整未锁定路径才会降低负担。确实无法满足时按入口冲突规则给方案。

判断只来自文字时说“存在超预算风险”，不要在距离和速度未知时声称已经证明不可能。
