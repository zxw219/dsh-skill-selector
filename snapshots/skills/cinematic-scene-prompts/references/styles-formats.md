# 风格与交付

## 风格适配（A：三风格样例；C：扩展定位；B：具体路由）

锁定用户事件、角色和道具身份，再调整造型、材质、空间表示、运动、明暗与声音。未锁定的布局可以按媒介重设，但关系和因果仍需成立。

| 家族 | 可选实现与关注点 |
|---|---|
| 实拍 | 自然材质与摄影空间；胶片、纪录手持、黑白年代、广告棚拍按观众体验调整，不强制脏旧、固定灯或无配乐 |
| 黏土定格 | 手工痕迹、实体微缩、姿态更新与保持；可细密流畅或明显停格，不固定12格，不必露骨架与制作棚 |
| 二维水墨 | 笔锋、墨色、纸纹、留白和层次；可有限动画、重绘或长卷移动，不禁止所有闭合轮廓与渐变 |
| 赛璐璐、剪纸、绘本、油画等 | 明确所选的分色、描线、纸层、透光、笔触和运动方案；媒介惯例是选择，不是不可变物理定律 |
| 混合与超现实 | 明确底层世界、叠加元素、遮挡、透视、接触、受光及时间关系，异常有范围 |

风格化形变可以成立，但不能把“拨开树枝”无意变成“折断树枝”。二维画面用取景、层次、缩放和移动表达摄影意图；需要时可类比焦段，不强套真实景深。

混合媒介先决定叠加层贴屏幕、贴表面还是存在世界空间；它是否发光、投影、承重、发声，各自说明必要部分。例如地面插画箭头随地面透视、被鞋遮挡，却不承重。若转为实体，标明转变时刻及新规则。用户未指定时采用不改核心剧情的简单方案；关键选择改变故事含义才询问。

超现实允许偏离现实物理，维持已设规则。例如仅一张纸反重力不自动让杯子漂浮。负向词按当前风格选择，不向三维卡通套“禁止CG”。

## 交付格式（C/B）

| 交付 | 重点 |
|---|---|
| 导演稿 | 人可审阅的镜头、空间、状态与必要取舍；用户需要时才展示规划 |
| 独立单镜视频 | 当前镜头的身份、初态、动作与终态，必要声光；连贯表达，不附内部评审 |
| 首尾帧 | 先确认实际图片与文本一致，过程可到达；用必要对象指代和属性锁定连接首尾，不重复整幅图、不禁绝有用复述 |
| 参考图驱动 | 按每张实际输入标身份、服装、场景或构图等用途；按用户指定决定是否继承姿势、机位、光线 |
| 分镜静帧 | 每帧选一个确切状态，移除音频指令与时间过程；同一帧不可既接触又悬空，可保留该时刻合理运动痕迹 |

处理图片前先检查图片；只有文本描述时说明依据文本，不能声称已经看到参考图或验证首尾可达。尚未提供图片但要求先写草案时可使用清楚标注的素材位。

首尾帧可采用不同机位，只要用户要运镜、透视转换与动作可达；固定机位方案才锁定相同机位。用户指定秒数时保留，不因首尾帧格式擅自改成只有比例。

静帧允许不同景别和机位；锁定的是人物、道具和世界关系，不是所有帧同一机位。一次一张生成时每帧独立完整；多帧统一请求可共享设定。参考链是可用工具之一，也可使用固定人物图、场景图或锚定首帧，按目标工具能力选择，注意误差累积。

输出语言服从用户，不默认静帧必须英文。目标模型参数、音频与负向支持未知时不编造限制，也不把本技能的经验写作偏好说成平台规格。
