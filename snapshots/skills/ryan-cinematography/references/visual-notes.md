## 瑞恩十大核心技法

### 1. 🐟 超广角鱼眼凝视（Ultra-Wide Fisheye Gaze）

**瑞恩与 Lanthimos 合作的标志性武器。** 用 4–6mm 的超广角鱼眼镜头靠近人脸，将人物的存在扭曲为怪奇、不适、荒诞的舞台化凝视。

| 关键特征 | 说明 |
|---------|------|
| **极端广角焦段** | 4mm / 6mm / 8mm 鱼眼，或 10–14mm 超广角矩形 |
| **距离感的暴力** | 镜头极近人脸，但鱼眼失真让人物"退远"，制造心理疏离 |
| **宫廷场景的畸变** | 《宠儿》中用鱼眼吞下整个宫廷走廊，墙壁弯曲如梦 |
| **低角度仰拍** | 常配合低机位，让天花板、烛台、贵族裙摆压入画面 |
| **不眨眼的注视** | 鱼眼配合长镜头，逼观众正视主角的脆弱或荒谬 |

**代表场景**：
- 《宠儿》— Olivia Colman 在烛光宫廷中被鱼眼吞噬的凝视
- 《可怜的东西》— Bella 初次睁眼的鱼眼全景
- 《圣鹿之死》— 手术室天花板如教堂穹顶般弯曲

**提示词核心词**：
```
ultra-wide 4mm fisheye lens, extreme barrel distortion,
walls curving into frame edges, low angle fisheye gaze,
curved ceiling looming overhead, candlelit palace corridor warping,
uncomfortable intimate distance, Yorgos Lanthimos signature fisheye
```

---

### 2. 📺 4:3 学院画幅复古（Academy Ratio 4:3 Revival）

**瑞恩是当代 4:3 画幅复兴的关键推手。** 将接近正方形的学院比例（1.37:1 / 1.33:1）作为叙事压迫或亲密性的手段。

| 关键特征 | 说明 |
|---------|------|
| **幽闭的正方画框** | 画面被"挤"成方形，上下多空间、左右紧贴 |
| **古典绘画感** | 与 17–18 世纪油画比例接近，强化时代感 |
| **头顶大空间** | 常给天花板、烛台、头顶留大量留白 |
| **现代题材的异化** | 用学院比例拍现代故事，制造时代错位感 |
| **黑白的强化** | 4:3 + 黑白（《婚姻故事》局部、《美国甜心》部分段落）强化情感密度 |

**代表场景**：
- 《宠儿》— 全片 1.66:1 偏方画幅，配合鱼眼
- 《美国甜心》— 全片 1.37:1 学院比例，与手持配合制造 Sasha Lane 的青春困境
- 《婚姻故事》— 关键独白段落接近方画幅的亲密感
- 《呼啸山庄》（2011）— 1.37:1 幽闭荒原

**提示词核心词**：
```
Academy ratio 1.37:1, square-ish boxy frame, 4:3 aspect ratio,
vintage classical painting proportions, headroom above subject,
claustrophobic narrow width, old photograph framing, tight vertical composition
```

### 3. 🎞️ 35mm 胶片的灵魂（35mm Film Soul）

**瑞恩是当代最坚定的胶片拥护者之一。** 几乎所有他主导的重大项目（《宠儿》《可怜的东西》《鱼缸》《美国甜心》《婚姻故事》）都坚持 35mm 胶片拍摄。

| 关键特征 | 说明 |
|---------|------|
| **天然颗粒** | Kodak Vision3 500T / 250D 的自然颗粒，不依赖后期 |
| **肤色的血色感** | 胶片对红色/琥珀色的化学反应，肤色温润有血丝 |
| **高光压缩** | 胶片对高光的软截断，避免数字的硬切 |
| **阴影层次** | 暗部保留绒毛般的细腻，不沉为死黑 |
| **有机的呼吸** | 每一帧都在微微颤动，画面"活"着 |

**提示词核心词**：
```
shot on Kodak 35mm film, Kodak Vision3 500T, organic film grain,
natural silver halide texture, warm skin tones with blood undertones,
soft highlight rolloff, velvety shadow detail, analog breathing image,
Panavision Panaflex Millennium XL2, 35mm anamorphic or spherical
```

### 4. ☁️ 自然光实景（Available Light, Real Locations）

**瑞恩的第二原则。** 几乎不动用大灯阵列——能用窗光、阴天、烛光、实景灯就绝不人造补光。这是他与 Andrea Arnold、Ken Loach 合作的美学根基。

| 关键特征 | 说明 |
|---------|------|
| **只用窗户当主光** | 《宠儿》整个宫廷夜戏只用数百根真蜡烛 |
| **阴天是上帝** | 英国阴天的无影散射光作为默认 |
| **烛光宫廷** | 《宠儿》夜戏全部烛光拍摄（配合高感胶片） |
| **拒绝补光** | 让阴影黑下去，让高光烧过去，全凭胶片宽容度 |
| **实景优先** | 几乎全实景拍摄，拒绝影棚布光 |

**代表场景**：
- 《宠儿》— Hatfield House 真实宫殿，250+ 根蜡烛照明
- 《鱼缸》— Essex 廉租房公寓的真实窗光
- 《I, Daniel Blake》— Newcastle 真实社会住房的阴天散射光

**提示词核心词**：
```
available natural light only, candlelit palace with 250 real candles,
overcast British sky as key light, window light through dirty glass,
no artificial fill, ambient ambient realism, practical lamps only,
Kodak high-speed film pushed one stop, embraces natural shadows
```

### 5. 📱 Andrea Arnold 式手持现实主义（Arnold Handheld Realism）

**与 Andrea Arnold 合作的六部作品（Red Road、Fish Tank、Wuthering Heights、American Honey、Cow、Bird）形成了一套独立美学语言。** 手持 + 近距离 + 追随演员 + 未经排练的真实。

| 关键特征 | 说明 |
|---------|------|
| **肩头紧贴** | 摄影机像第二个演员，贴在主角身边 |
| **追随不引导** | 摄影机被动追演员，不预判走位 |
| **4:3 + 手持** | 学院画幅的压迫 + 手持的躁动，制造青春困境感 |
| **长镜头凝视** | 不剪切，让尴尬、沉默、欲望自然展开 |
| **动物与人同权** | 《Cow》用这套语言拍奶牛的一生，把牲畜当主角 |

**代表场景**：
- 《鱼缸》— 15 岁 Mia 在廉租房游廊上的焦躁追随
- 《美国甜心》— Star 在面包车里跨越美国的公路肖像
- 《呼啸山庄》— Heathcliff 在约克郡荒原奔跑的狂野跟随

**提示词核心词**：
```
handheld Andrea Arnold realism, intimate shoulder-close camera,
following protagonist without anticipation, 4:3 handheld boxy frame,
unrehearsed natural performance, long take observation,
raw youth kitchen-sink realism, camera as second character
```

### 6. 🌧️ 英伦阴雨青绿（British Overcast Blue-Green）

**瑞恩的灵魂色板。** 爱尔兰与英国天空的永恒阴天，配合潮湿的青绿植被，形成他最常用的冷色调。

| 关键特征 | 说明 |
|---------|------|
| **铅灰天空** | 低压、无影、平光、潮湿 |
| **青绿植被** | Essex 沼泽、约克郡荒原、爱尔兰乡村的湿冷植物 |
| **皮肤的青白** | 低饱和的青白肤色，贫血感 |
| **水泥与砖** | 廉租房、工人阶级居所的冷灰砖墙 |
| **偶尔一束暖光** | 在无尽冷色中插入一盏暖色台灯作为情感锚点 |

**代表场景**：
- 《呼啸山庄》— 约克郡荒原的铅灰天空与湿漉漉的泥炭
- 《I, Daniel Blake》— Newcastle 的阴天街道与冷色公共机构
- 《Fish Tank》— Essex 社会住房区的冷色系青春

**提示词核心词**：
```
British overcast gray-blue sky, lead-colored heavy clouds,
damp emerald green moors and moss, pale bluish skin tones,
cold concrete and red brick of council estates, no shadows only gradients,
humid Yorkshire / Essex / Irish countryside palette, single warm lamp as emotional anchor
```

### 7. 🍭 《可怜的东西》怪奇彩色梦境（Poor Things Surreal Color Dream）

**瑞恩最大胆的色彩实验。** 与 Lanthimos 和美术 James Price、Shona Heath 共创一个维多利亚蒸汽朋克 + 糖果色 + 黑白 + 鱼眼的超现实世界。

| 关键特征 | 说明 |
|---------|------|
| **黑白 → 彩色的苏醒** | Bella 初期黑白，游历世界后逐渐染上饱和彩色 |
| **糖果色天空** | 紫红、青绿、鹅黄的非自然人工天空 |
| **蒸汽朋克黄铜** | 暖黄铜、奶油白、珊瑚粉的怪奇实验室 |
| **里斯本黄 + 巴黎蓝** | 每个城市一套主色——里斯本柠檬黄、巴黎钴蓝、亚历山大血红 |
| **鱼眼+彩色** | 鱼眼畸变下的超饱和色彩，像孩童梦境 |

**提示词核心词**：
```
Poor Things surreal color dream, candy-colored artificial sky,
Lisbon lemon yellow facades, Parisian cobalt blue, Alexandria blood red,
steampunk brass and cream interiors, fisheye distorted saturated world,
Victorian sci-fi storybook palette, shifting from black-and-white to vibrant color,
whimsical painted backdrop skies
```

### 8. 🏚️ 约克郡阴郁荒野（Yorkshire Moor Bleakness）

**《呼啸山庄》（Andrea Arnold 2011）建立的视觉语言。** 将艾米莉·勃朗特的原著从哥特浪漫主义重写为泥土、血、皮肤、动物性的原始影像。

| 关键特征 | 说明 |
|---------|------|
| **低色温泥炭色** | 棕褐、烟灰、苔绿的大地色板 |
| **动物特写** | 死鸟、兔子、蛾子、蠕虫的微观血肉 |
| **雨中的皮肤** | 湿漉漉的头发、睫毛上的水珠、冻红的耳朵 |
| **手持+学院画幅** | 4:3 + 肩扛，让荒野逼近角色 |
| **肤色族裔** | 黑人演员饰演 Heathcliff，皮肤在冷光中的质感 |

**提示词核心词**：
```
Wuthering Heights moor bleakness, peat-brown and ash-gray earth tones,
rain-soaked dark hair, water droplets on eyelashes, frostbitten red ears,
close-up of dead birds and moor insects, 4:3 handheld following Heathcliff,
raw Yorkshire primal nature, flesh-and-blood gothic, Andrea Arnold realism
```

### 9. 👷 Loach 工人阶级写实（Loach Kitchen-Sink Realism）

**与 Ken Loach 晚期合作的两部作品（I, Daniel Blake、Sorry We Missed You）将瑞恩的自然主义推到极致。** 摄影必须"看不见"，服务于工人阶级的尊严与愤怒。

| 关键特征 | 说明 |
|---------|------|
| **摄影机消失** | 平视、眼平机位、几乎不移动 |
| **Newcastle 灰** | 英国东北部的冷色、社会住房的红砖 |
| **真实面孔** | 非职业演员的皮肤、皱纹、疲惫 |
| **无配乐的沉默** | 镜头让沉默自己说话 |
| **现实主义正面注视** | 不美化、不批判、平等观察 |

**代表场景**：
- 《I, Daniel Blake》— 木匠 Daniel 在失业援助中心的静默注视
- 《Sorry We Missed You》— 送货司机 Ricky 在面包车驾驶室的疲惫

**提示词核心词**：
```
Ken Loach kitchen-sink realism, invisible camera observation,
Newcastle council estate red brick, non-professional working-class faces,
natural worn skin with real wrinkles, eye-level dignified perspective,
flat Northern English overcast, no music no stylization,
social realism documentary honesty
```

### 10. 💔 Baumbach 婚姻低对比（Baumbach Marriage Low Contrast）

**《婚姻故事》(Marriage Story, 2019) 展示了瑞恩极少数"城市室内"作品的一面。** 与 Noah Baumbach 合作，用柔和低对比 + 略带米色暖调 + 偶尔的黑白，拍摄一对离婚夫妇的日常崩解。

| 关键特征 | 说明 |
|---------|------|
| **柔和低对比** | 室内光比控制在 2:1 以内，没有戏剧性阴影 |
| **米色暖调** | 纽约公寓的木地板、米色沙发、暖色台灯 |
| **洛杉矶 vs 纽约** | 洛杉矶阳光明亮偏白，纽约柔和偏暖 |
| **对话长镜头** | 不剪切，让两人的情感自然爆发 |
| **4:3 情绪局部** | 关键独白接近方画幅的亲密 |

**提示词核心词**：
```
Marriage Story low contrast warmth, beige and cream Manhattan apartment,
soft tungsten practical lamps, 2:1 lighting ratio, warm wooden floors,
intimate dialogue long take, New York autumn golden window light,
Los Angeles bright white sun contrast, gentle emotional honesty,
Noah Baumbach domestic realism
```

## 工作流程

### 当用户需要瑞恩风格图像时：

1. **确认场景**：了解场景类型（宫廷/廉租房/荒原/公路/城市公寓）
2. **匹配影片**：从瑞恩作品中找到最匹配的视觉参照
3. **确定导演**：Lanthimos 的鱼眼怪奇？Arnold 的手持现实？Loach 的工人写实？Baumbach 的婚姻温暖？
4. **确定技法**：选择 2–3 个核心技法（鱼眼 / 4:3 / 胶片 / 自然光 / 手持 / 青绿 / 糖果色 / 泥炭荒野）
5. **组装提示词**：从 `references/style-prompts.md` 中选取基础模板，根据需求调整
6. **适配模型**：根据目标 AI 模型做微调

### 当用户需要打光方案时：

1. **分析场景光源**：找出场景中可能的自然/实景光源
2. **确定主光**：窗光？阴天？烛光？台灯？
3. **拒绝补光**：提醒用户"瑞恩几乎从不用人造补光"
4. **设计阴影**：让阴影自然黑下去
5. **参照影片**：引用瑞恩具体影片中类似场景的打光方案

### 当用户需要构图建议时：

1. **识别情感**：理解场景要传达的情感
2. **选择画幅**：1.37:1（压迫/亲密）or 1.85:1（叙事）
3. **选择镜头**：鱼眼（怪奇）/ 超广角（环境）/ 标准（现实）
4. **确定视角**：低角度仰拍？眼平手持？
5. **参照影片**：匹配具体代表场景

## 提示词输出格式

```
🎬 场景标题

📽️ 影片参照：[最接近的瑞恩作品 + 场景]
🎞️ 导演合作：[Lanthimos / Arnold / Loach / Baumbach / Newell]

**Style（风格）：**
[完整的英文风格提示词 — 涵盖打光、色调、氛围、胶片/画幅]

**Scene（画面）：**
[完整的英文画面提示词 — 涵盖构图、主体、环境]

**完整提示词：**
[Style + Scene 合并]

💡 打光笔记：[简要说明打光逻辑——优先自然光]
🎨 色彩笔记：[简要说明色彩意图]
📐 画幅建议：[1.37:1 / 1.66:1 / 1.85:1]
🐟 镜头建议：[鱼眼 / 超广角 / 标准]
```

---

## 重要原则

- **所有提示词必须是英文**：AI 图像生成工具对英文效果最佳
- **Style 与 Scene 分离**：用户可保持 Style 不变，只改 Scene
- **胶片优先**：瑞恩的灵魂是 35mm 胶片，提示词必须强调颗粒感
- **拥抱瑕疵**：与迪金斯相反——瑞恩欢迎炫光、鱼眼畸变、手持晃动
- **自然光第一**：不主动加补光、不加影棚打光
- **画幅要明确**：1.37:1 是瑞恩的标志之一
- **导演上下文**：区分 Lanthimos（怪奇）/ Arnold（现实）/ Loach（工人）/ Baumbach（城市）
- **爱尔兰+英国灵魂**：湿冷、阴天、青绿是底色
- **引用影片**：推荐风格时，始终引用具体影片和场景作为参照

## 模型适配提示

### Midjourney
- 加 `--raw` 获得写实胶片质感；`--ar 4:3` 模拟学院画幅；强调 `35mm film, Kodak grain, fisheye lens`

### Stable Diffusion / FLUX
- 负面：`digital clean, sharp modern lens, CGI perfect, HDR, teal and orange, anamorphic widescreen`
- 正面：`Robbie Ryan cinematography, shot on 35mm Kodak film, Academy ratio 4:3, fisheye distortion, available light`

### DALL-E / GPT Image
- 自然语言描述："shot on 35mm film with a fisheye lens, in the style of Robbie Ryan's Poor Things"

### Nano Banana Pro / ZenStudio
- 中英混合有效，核心术语用英文：`cinematic, Robbie Ryan, 35mm film grain, Academy 4:3, fisheye, available light`

## 与其他摄影师风格对照

| 维度 | Robbie Ryan | Roger Deakins | Lubezki |
|------|-------------|----------------|------------------|
| **光源** | 自然光 + 实景 | 动机光 + 精雕 | 自然光长镜头 |
| **镜头** | 拥抱鱼眼/畸变 | 球面无瑕 | 超广角 Master Prime |
| **画幅** | 1.37:1 复古 | 2.39:1 宽银幕 | 1.85/2.39 |
| **载体** | 35mm 胶片 | ARRI 数字 | ARRI 数字 |
| **运镜** | 手持躁动 | 稳定克制 | 流畅长镜头 |
| **色彩** | 青绿蓝灰 / 糖果色 | 分区单色 | 自然温暖 |
