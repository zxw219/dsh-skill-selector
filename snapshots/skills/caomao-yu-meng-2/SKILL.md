# 草帽与梦2.0

把剧情转换成能直接使用的自然语言分镜提示词。沿用原版的视觉节拍、空间与体态衔接、光影、景深和现场声方法，吸收长期修改中反复确认的使用习惯。

本文件是一份独立可读、可复用的规范。默认服务真人实拍风格的视频生成，不绑定某个模型版本；用户指定模型、格式或用途时按实际要求调整。

## 〇、先读这些核心规则

1. **改一镜，默认完整回传当前整组。**保留其他镜头和历次已确认要求，不用“其余同上”省略。只有用户明确要求本次仅输出局部时才局部交付。
2. **自然拍摄呼吸感默认保留，幅度由对标和剧情校准。**常规镜头有克制、不规则的漂移、起伏与细小修正；纪录片、行走或紧张场面可加强肩扛视感。只有对标明确以极度稳定为核心，或用户指定完全固定／绝对平稳时，才关闭这层运动。不能全部套成剧烈手持，具体见第八章。
3. **人物与场景依资产，文字负责调度。**已有资产不重复设计外貌、服装或建筑细节；多人图只调用人物身份，不搬进整张图、站队或背景。
4. **先算时间，再分镜。**用户指定的总时长、镜头数量和停顿必须守住；旁白只用于估时的，成品提示词里不出现旁白。
5. **每镜写清现场声。**默认只有画面世界内的环境、动作、呼吸、对白等声音；无BGM、无额外情绪音效。电音BPM可只用于动作和剪辑节拍。
6. **真人感要有证据。**真实重心、接触、惯性、皮肤与衣料、焦点变化、光线和遮挡；不能只写一句“真人实拍”。
7. **光源有依据，天气有接触。**环境光照人物；下雨要打到脸和身体，风要影响衣料与环境，不能只留背景装饰。
8. **连续性优先。**位置、朝向、道具、伤痕、湿衣、群体数量和特效阶段跨镜继承；用户修订某个设定后，整组同步更新。
9. **自然语言，少而准确。**一镜一个主事件，保留必要的光影与声音。默认整组提示词尽量控制在3000字以内；更短的用户上限优先，放宽须有明确依据。
10. **区分长期习惯与本场设定。**某场的10米装置、某次的300mm、无其他人、某件衣服或特定舞风，不能变成以后所有镜头的默认内容。
11. **拍法写成画幅变化，不把幕后人员或器材写成场内主体。**内部可以推算操作方式，交付的生成提示词只描述取景、运动、颠动和焦点结果，具体执行见第八章。
12. **200mm及以上统一执行本工作流的浅景深约定。**200—300mm为长焦，300—500mm为超长焦；使用超大光圈、极浅景深，远景背景只剩强烈焦外色块。环境参考不能被还原成清楚背景，具体执行见第五、十章。
13. **先写对标状态，再写情绪总控。**具体作品、片段或参考方向由用户提供或确认，未指定就写未指定，不擅自替用户选片。研究适用于本场的视听方法后再设计镜头，不仅在提示词里加一个片名。

## 一、适用范围与交付边界

处理剧情拆镜、动作口述、访谈、微表情、群像、快闪蒙太奇、动作场面、成长变身、动态特效、一镜到底、首尾帧以及构图图片提示词。

用户让“设计”时，可以选择焦段、机位、剪辑节拍，并补足完成既定情节所需的呼吸、重心、视线和操作衔接。不得擅自改变人物关系、剧情因果、台词、结果或增加重要人物与事件。用户只让修改某处时，不顺手改写已经认可的其他部分。

用户只要分析、估时、舞蹈肢体或一个图片提示词时，只交付该层内容，不强塞整套分镜。用户明确要几个方向时再给方案，不为常规任务先增加一轮确认。

收到“跑出来不对”时，先找出画面缺少的可见证据或文字冲突，直接修正并完整交付。没有实际查看视频时，不声称已经看过或准确复盘。

## 二、约束优先级与修改记忆

执行顺序：用户最新明确要求 → 历次仍有效的已确认要求 → 参考材料指定职责 → 时长与空间连续性 → 叙事、情绪与动作 → 摄影及风格默认。

指定对标后，经过核实、适用于本场的镜头语言优先于一般拍法偏好；自然呼吸感按第八章的默认与例外执行。对标不能自动取消明确的资产、时长、受光、道具或景深约定。

内部保留当前段落的简短约束清单：

- 输出类型、时长、镜头数量、字数上限、语言和声音限制。
- 对标对象与参考范围、可用研究依据、本场借鉴的方法、呼吸感强弱及明确保留的个人要求。
- 图一、图二等分别是什么；哪些仅供身份、布局、意境、姿态或首尾帧参考。
- 人数、场内位置、禁入区域、行动方向、观察位置允许经过的区域及移动范围。
- 必须发生的事件、事件顺序、表演转折与结尾状态。
- 哪些原要求被新要求替换，哪些仍须保留。

局部修改后检查整组的关联关系。例如蘑菇从圈内改成圈外生长，人物视线、反应、采摘位置和取景路径都要一起修正；不能只换一处名词。

### 对标来源、研究与适配

**分清三者职责：剧本决定事件、因果与情绪；本 skill 规定执行与质量要求；对标作品提供适用的表达方法。具体分镜仍须针对用户剧本重新设计。**

**来源与缺省处理：**口述、文字片名、图片或视频片段均可作为用户指定的对标来源，不要求用户先讲全技术参数。没有提供时，【对标状态】写“未指定”，沿用已确认方向与本 skill 默认，不自行挑选作品；用户明确要求推荐时才提供方向供选择。只给片名时，先根据剧本判断相关场面与适用维度；仅在版本、段落或借鉴范围的歧义会明显改变设计时简短澄清，不每场强制增加确认步骤。

**先理解剧本，再有针对性地研究对标：**明确本场事件、人物关系、情绪转折、关键视觉信息和时长；检索对应作品的导演、摄影、剪辑等创作资料，优先一手访谈、正式幕后资料及实际片段。能实际查看相关片段时，再观察景别组合、空间调度、取景路径、剪辑节奏、表演与视效关系。不用整部电影的泛泛标签代替对本场的判断，也不把原片镜头表硬套到另一段剧情。

**证据与设计分开：**内部区分创作资料明确支持、实际片段可观察、为本场提出的设计推断。搜索到资料不等于已经逐镜看过原片；未实际核实的焦段、平均镜长、剪辑结构或拍法频率不能写成原片事实。“未找到某手法的资料”不等于“整部电影没有这种手法”；“某一镜使用过”也不等于全片惯用或适合本场。无法检索或没有片段时，说明依据范围，只在可支持的维度参考，不虚构研究结论。已有同作品、同参考范围的可靠研究可复用，不无谓重复搜索。

**把研究转为本场方案：**先选与当前情节相近的参考场面，再提炼适用的构图、景别、空间揭示、取景运动、剪辑、表演或视效方法，重新分配用户剧本的视觉节拍与时间。对标不是给每镜贴片名，也不增加原片人物、服装、道具或剧情。情绪总控仍来自用户这场戏，不能被原片情绪替换。

**保留工作规范，按对标调整拍法：**完整回传、时长与字数、资产分工、空间与道具连续性、自然表演、环境受光、现场声以及避免幕后实体误入画等规则继续执行。景别分配、观察角度、镜头运动、剪辑密度及晃动幅度由本场剧情与研究结果选择，不能把过去某种肩扛或快剪习惯强加到所有作品。夸张晃动、复杂环绕、特殊变速等手法缺乏本场依据时不自动加入；克制的自然呼吸感是个人默认审美，不需要先证明原片某镜采用肩扛才可使用。

对标决定是否选用某种焦段；一旦使用200mm及以上，仍执行本 skill 的超大光圈、极浅景深约定，除非用户本次明确另改。需要空间信息时可另选合适景别，不自动把长焦背景变清楚。同理，电影光色参考不能覆盖用户已锁定的环境光源或继承人设图布光。确有难以兼容的明确要求，先指出具体冲突与取舍，不暗中删除旧要求，也不声称两种相反结果同时实现。

**研究结果的交付：**在【对标状态】用简短自然语言写明对象、采用的维度、呼吸感处理及本场须保留的要求。只有相关时才说明舍弃哪些不适用拍法。检索来源、证据范围或必要的推断说明放在可投喂提示词之外，避免把链接、研究过程或幕后器材名称塞进画面描述。

## 三、自然语言输出格式

默认按下面形式交付，不加逐镜文学标题，不使用JSON或冗长字段表：

```text
【对标状态】
用户指定的作品／片段／参考方向；本场借鉴的视听方法；自然呼吸感如何处理；必要的个人要求与适配边界。未提供对标时写“未指定”，不虚构作品。

【本组情绪总控】
真人实拍质感；总时长与镜头数；资产职责；核心情绪变化；摄影方式；持续天气及声音限制。只写本组真正需要的共通约束。

镜头1（0:00–0:02.0，2.0秒）
焦段、景别、观察高度与构图。人物起始状态、关键动作、视线与情绪；画幅如何跟随、颠动或改变取景及结束状态。光影：本镜实际受光。现场声：本镜真实声源。

镜头2（0:02.0–0:04.0，2.0秒）
……
```

【对标状态】回答“借鉴谁、借鉴什么、怎样适配”，【本组情绪总控】回答“本场要表达什么情绪、如何变化”。前者固定放在后者上方，不合并成一句片名加情绪，也不把整段研究重复写进逐镜正文。此格式用于常规视频分镜；用户只要估时、局部动作或简短运镜时，仍服从该次交付范围。

不同输出类型分别处理：

- **一镜到底：**只写一个镜头，可以用时间段标动作与运镜节拍，时间段不代表剪辑。统一写一条连续现场声，点明关键动作发生时的声音。
- **首帧生成：**先继承首帧的位置、姿态、构图、光线与景深，再写新增运动、表演与对白。只改变用户指定的变量。用户本次指定长焦与强虚化时，原背景清晰度属于需要改动的变量，不能用“完全继承首帧”抵消新要求；若输入首帧像素固定且清晰背景无法改变，应先解决首帧素材与目标景深的冲突，不声称仅靠提示词就能改写固定的首帧。
- **尾帧生成：**说明运动如何在结尾落到资产画面，给足最后稳定时间，不能最后一帧突然换成参考图。
- **图片提示词：**只写单幅的身份、姿态、取景、透视、焦点和光线，不写时间码与运动过程。
- **动作专用：**用户只要肢体时不加环境和镜头；用户要逐秒复刻时按实际视频时长与可见动作写，不能凭印象编秒数。

输出前合计时长、检查时间码是否连续。相邻镜头接同一动作时，不在下一镜重演已经完成的起始过程。

## 四、时长、语速与快剪

### 1. 估时方法

只统计真正会读出的台词；去掉中文翻译、角色名、场次标题和给创作用的旁白说明。同一段英文只算一次，符号和破折号不算额外单词，专有名词按实际发音估算。

基础口播秒数＝英文词数÷每分钟词数×60，再加入明确停顿、呼吸和必须独立呈现的动作时间。旁白可覆盖的画面与旁白并行，不把同一段画面时长重复相加。

用户说“偏快的BBC纪录片口播”时，可先以180—210词/分钟作为这次估算的工作假设，给合理区间；这不是BBC固定标准。有音频或实际试读时以实测优先。商业精英、痛苦呐喊、低声呢喃分别按其表演调整，不共用一个语速。

停顿写在指定位置：句末沉默不能提前插进句中；“完整说完才停顿”必须保留。不能把每个标点都扩成一秒。

### 2. 快剪与长短节拍

用户给总时长或最短镜长时据此排节奏。0.3—0.8秒快闪只承担一个可辨动作或印象；1—2秒可给关键动作；反应、空间建立和情绪落点适当停留。范围是设计参考，不是固定模板。

快切通过截取动作关键段压缩时间，不让全体人物加速。按剧情需要穿插一两处较长观察，避免每镜等长、每镜同一种正面构图。

用户既指定时长又给大量事件时，先删重复描述、压缩过渡和镜头负担，不擅自删除剧情或缩短总时长。确有无法兼容的硬要求，指出具体冲突；其余可完成部分继续推进。

### 3. 字数

默认整组生成提示词尽量≤3000字，用户指定300字、200词等更严格限制时按相应单位执行。用实际字符或词数核对，不用字节数。优先删除重复技术说明和无用形容词，保住动作因果、空间、表演转折、台词、时间、光影与现场声。

不为压字数自动改成另一段时长。也不为凑镜头数反复切同一张脸或同一动作。

## 五、参考材料的职责

| 材料 | 如何使用 |
|---|---|
| 面部图 | 锁定同一身份、年龄和脸；不带入照片背景、原构图和原布光 |
| 全身／服装图 | 锁定身体与装造；按当前动作自然变形，不再设计一套新衣服 |
| 多人资产图 | 分别调用人物身份；按剧情重新错落站位，不整张贴进视频 |
| 场景布局图 | 锁定建筑、地形、出入口及固定装置的位置；拍摄角度按当前机位重取 |
| 仅供氛围的环境图 | 只参考色调、气候与空间感；不复刻具体建筑、树木或图中构图 |
| 特效图 | 参考指定的形状、质感与意境；效果在当前空间重新生成、运动与受光 |
| 首尾帧 | 继承用户指定的构图、姿态、眼神及光影；中间运动连续到达该状态 |
| 参考视频 | 继承指定的动作、节奏、站位或镜头；换人换景只改对应部分 |
| 对标作品／片段 | 依据研究借鉴本场适用的视听方法；不直接搬入原片人物、环境、剧情或布光，不宣称未核实的拍法 |

同一人的两张参考不增加角色数量。资产中已有的外貌、头盔、衣服和装置造型不逐项重述。必须补写的是当前镜头里的**比例、位置、取景范围、姿态、朝向、动作与光线适配**。

若参考图过度支配生成，只保留其必要职责。例如长焦人像不要求把完整环境、地面与所有建筑都显现出来；只留下该机位能看到的焦外大色块。

**200mm及以上的环境图使用限制：**布局图仍用于内部判断人物位置、视线与世界坐标，但在交付提示词里，背景只继承该处的光源方向、色温和大面积明暗／色彩关系。背景必须失去可辨的建筑、地形、人物面孔与物件结构；不列出参考图里有哪些建筑和道具，不要求“完整还原环境”“背景清晰可见”或“通过间隙清楚交代远处装置”。已经由其他镜头建立的空间关系无需在长焦特写里再次证明。按当前焦平面只让主体或关键局部清楚，其余背景作为不可辨认的焦外色块存在。

换脸、换人图片：场景图负责原姿态、视线、构图与受光，人物图负责身份和装造。不要把人物图原有的光一起搬过来。

## 六、先定空间，再拍人物

内部先明确：固定装置位置、地形边界、出入口、人物与观察位置各在哪边、人与物的距离、朝向和行动路径。全局只声明维持连续性必需的关系，不要求每镜把所有元素同时拍进来。内部空间推算与交付文字分开；远景布局不能覆盖长焦浅景深约定。

画面左右与真实位置分开记录。人物换到画面另一侧，可能来自机位变化，不等于瞬移。连续拍摄尽量守同一观察侧；需换轴时用可见环绕、人物转向或中性角度交代。仅称“反打”不能自动证明没有越轴。

边界事件要有画面证据：从草地踏到沙土、经过两件实体之间的间隙、从门内跑到门外。指定只有一个人进入时，其他角色留在外侧，观察位置是否越过边界也按用户要求维持。空旷场地不能因为需要照明就自动加人、车灯或火堆。

大圆场地不缩成小围栏：用足够的尺度关系与局部弧度说明。近侧边界的局部观察看不到远侧时，不把对侧摆进背景。根据剧情选一个清楚关系，不逐镜罗列整场地图。

巨型装置的绝对尺寸，应再用人物作比例锚：人物远小于装置，近处长焦取景只能容纳局部。用户要求“拍不全”时保留出画部分，不能为交代场景把物件缩小。

## 七、体态、道具与事件连续性

逐镜检查五项：体态／朝向与视线／手和道具／伤痕湿度破损／接触与负重。

连续动作的下一镜从上一镜结束状态接起。躺、坐、蹲、跪、站之间，需要在镜内有必要的撑地、移重心或屈伸过程。明确的时间跳跃、成长蒙太奇可以省略中间过程，不因此强加过渡镜头。

道具的持有手、背带、挂靠和重量要连续。例如卷轴从接住、转到背后到背带承重，后镜已斜背好就双手自由；不能重新拿回手里。角色背着鼓时跑、跪和转身，鼓的位置随身体变化。

群演不能一切镜就重排或消失。哥哥跑远后弟弟才出现，就先完成哥哥离开与距离拉开，禁止改成哥哥从弟弟面前经过。采摘发生在哪里，所有发现、视线与靠近都指向同一位置。

同一冲击波、火焰、烟尘或生长事件跨镜继续演化，不从每镜中心重新开始。痕迹一旦出现，后镜保留。高潮可以连续下摇追踪滴落或倒地，用户要求不断镜时不能擅自拆成插入特写。

## 八、自然拍摄呼吸与肩扛视感：只交付可见画幅变化

### 0. 默认自然呼吸，先校准强弱与例外

**用户的默认审美是带自然呼吸感的真实电影拍摄触感。**除明确极稳或完全固定的要求外，保留克制、不规则的微幅漂移、自然起伏和细小构图修正，不把普通的平稳镜头一律写成机械锁死。此为个人风格约定，不据此推断所有电影都采用肩扛。

研究对标时，判断相关场面的运动节奏、呼吸强弱及是否确实以极稳为核心；不能因为资料没提肩扛，就自动取消自然呼吸。若明确的创作资料、实际片段或用户要求表明本场应极度稳定，则按该方向处理；用户指定全固定或绝对平稳时也不擅自加入漂移。固定位置但允许摇跟的镜头，只在允许的运动范围内工作。

常规场面用细微、非匀速的漂移与修正；行走、追拍和紧张场面按情节与对标逐渐增强颠动、侧倾和跟随滞后。安静场面仍可有克制呼吸，不必加成明显震动。不要把剧烈晃动、失焦、甩镜或自然裁切捆绑为每镜必选套餐；它们是否使用及幅度各有依据。

这里的“呼吸感”指可见的画幅变化，不是新增声音要求；不能因此自动添加喘息、呼吸声或幕后声源。

### 1. 把内部拍摄推算与生成正文隔开

**这是本工作流的核心修正规则。**内部可以推算摄影师怎样操作、摄影机怎样移动，但这些幕后主语不能直接复制进生成提示词。写“某人扛着器材跑、蹲下、围绕演员拍摄”容易让它们成为场景内容。默认交付正文不使用摄影师、摄像师、拍摄者、摄影机、摄像机、相机、三脚架、稳定器或无人机等实体名词来讲述动作，也不描述其外形、肩背、手脚、影子、倒影或持握过程。

技术意图用“肩扛式纪实视感、手持颠动、固定机位、航拍视角、观察高度、画幅、取景、焦点、前推、后撤、横移、摇摄”等描述。**内部知道动作从哪里来，正文只写画面怎么变。**默认仅呈现剧情中的人物与物件，不自动给幕后人员分配角色。

不要在可直接投喂的正文里反复列“无摄影师、无摄影机、无三脚架”等否定清单；同样会反复引入不需要的实体。优先正向描述画幅内由谁与什么占据，以及取景的实际变化。只有用户明确要求幕后人物或器材作为剧情主体入画时，才按该次要求写入。

口述中疑似把肩扛拍法说成“监控摄像机”等转写错误，内部按上下文判断，交付时统一落实为对应的纪实画幅表现，不复述错误实体词。无法辨认且影响拍法时再简短澄清。

### 2. 按剧情分配颠动，正文不另造操作者

下表用于已经选择相应观察方式的镜头，不要求每镜采用肩高机位，也不覆盖明确的极稳例外。对标校准这些表现的强弱与节奏，不机械照抄整行。

| 剧情与观察状态 | 可直接采用的画幅表现 |
|---|---|
| 站立观察、等待 | 取景保持成年人肩高，画幅不规则漂移、轻微侧倾、小幅修正，保留观察时间 |
| 正常行走、倒退跟随 | 画幅随移动产生不均匀上下颠动和侧摆，主体距离变化，构图修正略迟 |
| 远距离长焦观察 | 小幅取景变化被放大，主体偏离、边缘裁切，偶有短促跟焦偏差；背景持续强虚化 |
| 奔跑、紧迫追拍 | 剧烈上下颠动和侧倾、前景掠过，主体短暂出画，随即急促摇回找回主体 |
| 突发痛苦、跌倒、意外出血 | 事件发生后画幅突然加重晃动，急摇或下摇过冲、焦点短暂丢失，再修正 |
| 已获明确要求的近前求助或拉扯 | 角色逼近至画外近处，画幅突然后撤、主体猛然变大，接触节奏带出有方向的摇晃；对方保持画外 |
| 事件结束、死寂或凝视 | 位移停下，画幅退回肩扛式余颤与不规则漂移；安静仍有生命感 |

晃动强度对应事件与位移，不等于整段地震。用户明确要求剧烈时要达到可见幅度，但在关键眼神、接触或因果发生的一瞬留出辨认机会。不能所有镜头用同一句“轻微晃动”，也不每镜都完整丢焦再找回。

**高度与俯仰分开写：**“成年人肩高，取景向下摇，高度不变”与“观察高度连续降至孩子眼高”是两种动作。原地摇跟写“观察位置固定，仅横摇跟随主体”，不能误写成向前位移。高度降低只呈现高度变化，不需要写谁蹲下。

### 3. 改写示例与画外互动

可直接使用的正向写法：

- 追跑：“肩扛式纪实视感，侧后方快速跟随，画幅剧烈颠动、侧倾，主体短暂滑出右缘后被急促找回。”
- 降低观察高度：“观察高度从成年人肩高连续降至男孩眼高，俯视逐渐变为平视，取景保留不规则晃动。”
- 已指定的画外近前互动：“男孩逼近画外近处，双手向画幅下缘外伸出；画幅骤然后撤，随着男孩手臂牵动连续左右摇晃。”
- 固定位置上摇：“固定机位，高度与位置全程不变；人物站起后，取景慢半拍向上摇，重新容纳面部。”

画外求助可以保留直视与伸手，人物注视的是画外对象，默认不显示对方。不要因拉扯、纪实或POV就添加手持器材、幕后肩背或镜中倒影。普通剧情角色之间的手部动作与接触照常写。

## 九、构图与景别：变化来自观察关系

默认避免连续多个正面、水平、居中胸像。按剧情交替选择侧前方、侧后方、过肩、斜俯、贴地、遮挡、人物局部与远距离观察。

这些是未指定风格时的设计建议。用户明确构图或对标中适用于本场的构图方法优先，不为制造变化破坏刻意的对称、重复或空间秩序。

用偏置、视线空间、自然遮挡和裁切建立纪实感。脸不必每时每刻完整，额头、下巴或半张脸可因手持与动作自然出画；不能裁得关键表演始终看不见。手势需要可读时给手留位置，半身取景的下缘不要生硬卡住关节。

右侧黄金分割线可写为面部中心约在横向61.8%，左侧约38.2%；运动镜头允许自然偏移和修正，不把演员机械锁在一条线上。人物看向哪边，通常给那边留视线空间，用户另有构图意图时照做。

不强制每镜左右交替，也不为填一侧凭空增加路人。中心构图可用于仪式、强烈对峙、俯拍几何和用户指定镜头。景别应有变化，同级或相邻景别可以因反应、动作匹配和主体切换而成立，不把“跳一级”当绝对禁令。

过肩镜同时交代前景遮挡与远处视觉主体，景别按叙事主体描述；不要因为近处有肩膀，就把远处全身观察误写成近景。

## 十、焦段、景深与对焦

焦距默认全画幅等效。下面是用户在本工作流中的命名与画面约定，不把长焦必然浅景深当成普遍光学定律。选定这些焦段时，应通过光圈、拍摄距离与焦平面配置落实用户要求的成像结果，不能仅报一个数字。

- **10—24mm：**贴地、近大远小、空间与巨大尺度。大幅仰拍时明确是否允许地面、地平线进入画面。
- **28—50mm：**人物环境关系、肩扛跟拍、双人和群体互动。
- **70—135mm：**胸像、面部、过肩、手势与局部反应。
- **200—300mm，长焦：**远距离观察、强空间压缩、纯侧方运动、局部特写；视野有限，手持变化显著，配超大光圈、极浅景深。
- **300—500mm，超长焦：**更强的远距离压缩与局部观察，取景变化更显著；同样配超大光圈、极浅景深。300mm为两档交界，用户当次有称谓就沿用，未指定时按超长焦标注；200mm端点也执行下面的强虚化规则。
- **微距：**近侧眼睛、嘴唇、手、物件接触与细小变化；明确可见的局部。

### 1. 200mm及以上：强制写出背景强虚化结果

**从200mm开始，包括200—300mm长焦、300—500mm超长焦及更长焦段，默认每镜都写“超大光圈、极浅景深”，并落实以下结果：主体所在薄焦平面清楚，后方环境完全处于焦外，只剩不能辨认细节和轮廓的柔和大色块。**远处建筑、地形、装置和人物不能同时清楚，不能为交代参考环境自动收小光圈、扩大景深或做成前后全清。

环境参考只提供当前世界位置和光色依据。交付文字不逐项列出背景建筑与道具，不要求清晰复现背景图，也不把参考图直接作为清楚的场景底板。将“远处能看清某建筑／某装置”改写为“后方仅保留该处的冷暖色块与模糊明暗层次”；远物身份应由其他合适焦段的镜头交代。

可复用短句：“250mm长焦，超大光圈、极浅景深。焦点落在主体近侧眼睛，后方空间被压缩成完全无法辨认结构的焦外色块，仅延续环境参考的光向、色温与明暗关系。”特写需要眼清耳虚时再补耳部和远侧眼睛柔化，不强求全身远距离镜头也出现同样的面部景深分离。

长焦压缩同时体现在距离和画面结果上：后方层次视觉上被拉近、相互叠合，但仍保持强虚化。不要用清晰背景结构来证明压缩。该约定持续覆盖运动、甩镜落幅和失焦再合焦之后；合焦只找回指定主体，不自动把整个环境变清楚。只有用户针对该镜明确要求深景深或背景可辨时才覆盖本条，不为一般空间说明自行破例。

### 2. 其他焦段、转焦与跟焦

大光圈与极浅景深不能同时保证前后所有人物、手和道具都清楚。按这一刻的主信息选择焦点。对焦可以稳定、跟随、转移或短暂偏差，不预设每镜必抽焦。

**“推焦”先理解画面意图：**主体在构图中迅速放大，写快速变焦及起止焦段；主体尺寸不变、清楚对象变了，写转焦；观察位置走近，写画幅前推及视差。不要混为同一动作。变焦不产生穿过空间的视差。普通200mm以上镜头不主动转焦去拍清远背景；用户明确指定这种焦点揭示时，按最新要求处理且只让当前目标所在焦平面清楚。

失焦要有原因和时点，例如跑动、突然前倾、长焦追摇后跟焦迟到。需要半秒合焦才给半秒；快闪镜头不能把大部分时间耗在虚焦。焦点回到近侧眼睛或关键接触位置，不机械在眼、耳之间反复抽动。

## 十一、运镜、一镜到底与固定采访

### 1. 运镜要有动作原因

写起始观察位置、主方向、速度、跟随对象和结束构图。画幅横移、环绕、观察高度升降、推拉、摇摄、变焦与转焦分别说明。只保留完成当前揭示所需的路径，不强加复杂环绕，也不写幕后人物执行这些操作。

已指定对标时，从本场适用的研究结果选择主运镜，再按第八章校准自然呼吸感；不要为展示技术清单而塞入不相关的拍法。

高速感可选用前景快速掠过、主体重心与步频、背景拖影、落脚颠动和衣料惯性，不能为“速度证据”无端加碎屑。纯侧方长焦也能快速有力，用户指定侧拍时不能擅自改成纵深追拍。

### 2. 一镜到底

同一观察视点连续经历整条过程。时间段仅标节拍，不重新起镜、不在每段重置人物站位。甩镜、快变焦、升格、停顿都可以在同一镜中发生；不能为了防切强迫恒速。

重点交代连续的锚：同一人物动作接续、同一道具的位置、遮挡前后的身份、变焦前后的场内关系。两次变焦往返应明确拍哪一部分、谁被裁掉、拉回后谁仍在原处。

### 3. 固定采访

本节用于已指定固定取景的采访，不代表所有采访默认全固定；未指定拍法时，依本场对标与第八章处理自然呼吸感。

严格承接首帧。固定取景时，表演仍可前倾、后靠、转头、动肩、换重心和做手势。视线默认落在画外采访者所在的固定方向，不能擅自对观众说话。访谈关系可写清，但不借此描写现场器材或幕后人员。

固定机位的位置不动与取景完全不摇是两种要求：用户允许人物站起后上摇，就写“固定机位，高度与位置不变，取景稍慢半拍上摇追随”，不写器材实体。用户要求全固定则靠构图容纳动作。

### 4. 升空与俯拍几何

升空写成“观察高度连续增加，视点向场地上方移动，取景逐渐转为向下俯视”，呈现真实空间位移，不写飞行器实体。最终垂直俯拍指观察方向与地面垂直，不是原地抬镜拍天空。

设计几何揭示时先锁最终图案、人数和比例，再倒推起幅与升空路径。升高后人物只是缩小、被遮挡或移出画幅，不能凭空消失或重新排队。松散群体仍可形成可辨的大形，不要求每个人整齐同步。远距离俯拍的人物只占很小时，不同时要求看清脸、手指和微表情。

## 十二、光影与真人实拍感

每镜保留简短“光影：”。先说明光源依据，再写人物或环境怎样受光。连续时刻的方向、色温、曝光与明暗关系不因切镜重置。

**纪录片默认按现场光照人物。**不要自动增加主光、补光、轮廓光或眼神光；夜景可以低曝光、局部剪影，室内开口以外可以深暗。用户另要电影布光、梦幻MV或柔光时再针对该组调整。

光不必每镜变化。火焰、车灯、云层、树叶、衣料或人物转动产生合理变化时再写。清晨暖红的时刻不能下一镜变成正午；取景位置变化不等于世界光源改变方向。

逆光按光源与背景实际关系描述：暗面、轮廓可读程度、是否保留五官。需要看清眼睛就给合理角度或环境反射，不同时要求全黑剪影和清楚表情。镜面材质的反射随观察角度改变，但建筑本身不变形。

用皮肤细纹、自然色差、真实接触阴影、布料重量与褶皱、头发惯性和适量运动模糊支撑实拍感，避免塑料皮肤、均匀发亮轮廓、悬浮动作和全画面过度锐利。汗水、雨水、丝绸和金属反射可以按剧情真实描写，不把正常材质词一律禁掉。

胶片风格可按用户指定加入，例如柯达100VS的色彩倾向与颗粒感；作用于同一画面的人物和环境，不靠厚重滤镜掩盖身份与动作，也不把一个段落的胶片型号永久固定。

## 十三、风、雨、雪及运动接触

持续天气写进总控，并在最容易丢失的近景再补关键接触证据。

- **暴雨：**近景失焦雨线，中景雨滴持续打到头发、眉骨、脸颊和肩部，远处雨幕；发丝湿贴，衣料吸水变重、贴附，水从发梢与下巴滴落，地面积水被雨和脚步不断打破。第二、第三个面部特写不能只剩干脸与背景雨丝。
- **风与阵风：**同一次风影响草叶、头发、衣摆、绑结外的松散布料和烟尘；强弱自然变化。系牢的位置稳定，松散部分抖动回落。头发在头盔内时不让头发凭空飘出。
- **雪与遮挡：**近、中、远景的雪粒大小、焦外和速度不同；风、落地或冲击驱动扬雪。镜头被雪尘填满应是实际遮挡，不是无因白闪。
- **高速下落：**人物尝试找平衡，周围形成相应方向的拖影；下方树林因下降逐步进入并遮满画幅，不能凭空生成黑色幕布。

天气转变后保留既有结果：雨停转晴，头发、衣服和地面积水仍湿。大风不等于任何取景都猛烈抖动，区分环境运动与画幅运动。

## 十四、表演、视线和情绪推进

情绪必须能从动作与关系看出来。先明确起点、触发、转折和结尾，再选少量动作承载；不把“自然”“悲伤”“很帅”当全部表演指令。

访谈可借一两个词安排抬手、指向自己再指向采访者、推动眼镜、肩部起伏、前倾或后靠。动作与话意相连，不每句都安排完整手势组合，也不整段锁成念稿姿势。眼神方向固定不等于头颈不能自然变化。

沉默中仍有呼吸、注视松开、思考和回神。用户要说完后才沉默，就完整说完再进入停顿。最后礼貌微笑、愣住、绝望或歇斯底里按指定落点，不自动加点头和笑容。

情绪递进有时间：求救时先抓住对方注意，再因无回应变绝望，随后升级为失控；不是第一帧就最大强度。已明确要求画外近前求助时，角色逼近、伸手至画幅下缘外，画幅随之骤然后撤并持续摇晃；受求助对象保持画外，不能另切一条干净正面或增加一个入画对象。

亲密、舞蹈和动作场面同样保留关系变化。悲伤中的突然拥抱可以先僵住半拍，再主动回应；不能前面写悲痛、表演却一直开心。

群像反应先后错落，各人动作不同；只有用户明确要同步时才齐。微表情镜头不堆眨眼、挑眉、吞咽、咬唇等一串表演。自然裁切可以增强观察感，但不能替代表演本身。

## 十五、舞蹈、动作与升格的专用规则

用户要舞蹈风格时，给节奏、能量、身体重心、姿态差异和情绪，不写死每根手指的编舞。用户要逐秒姿态时才拆具体动作，并以实际视频为依据。

多人跳舞不默认镜像或齐舞。明确各人不同的方向、手臂高度、重心和动作类型，例如一人抬臂弹跳、另一人低重心侧移；差异贯穿动作，不是只在开头摆两种姿势。用户限两人或三人时不添背景舞者。

180 BPM以上是运动与剪辑参考，不代表人人一直高速摆动。一个人可慢而从容，其他人围绕快跳。用户要帅气就用有重量的迈步、转肩、视线和风，不因“电音”自动写夸张搞笑社会摇。用户要滑稽时再走相应风格。

动作招式写出重心、脚步、转体和发力关系。向前突进打拳不等于跑步打直拳；用户要招式感时考虑格挡、转体、短打等既定语境。局部快切覆盖脚、肘、肩、手与眼神，避免连续重复拳头特写。

升格明确发生的段落和持续时间，保留服装与头发的惯性。穿袍时可先一只袖子已穿好、另一只手再伸入带起衣摆，结合继续走路的重心；不要改成站定双手同时伸袖摆拍。正常速度段和升格段的接续需可读，不擅自把整组放慢。

## 十六、视效与实拍空间融合

先锁效果位置、起因、方向、尺度与持续状态，再写光、遮挡和环境反馈。视效参考只供形态与意境，不能把整张参考图当静止贴片。

- **动态花、烟和粒子：**分别写花瓣开合、独立缓慢转动、烟丝流动、颗粒散出与重聚、前后错位；缓慢运动不等于冻结。效果与机位环绕产生正确视差。
- **生长与变身：**写清起始、过程和落点。身体长大要改变身高、四肢比例与面孔身份，不靠人物走近假装成长；衣服款式与颜色分别变化。植物生长不让背景全体加速。
- **声波与沙纹：**方向来自声源。远处声源在画外时，局部波前可从一角推进到对角，不能每镜凭空从画面中心产生同心圆。沙仍是干颗粒，不变成水。
- **冲击、火与粒子：**持续传播、重力和受风方向一致。发光的效果才产生相应环境照明，不给所有透明气浪加霓虹。
- **人物化花瓣：**近、中、远不同距离的行人都从各自位置转化，保留原运动方向和遮挡关系；不要全在远处统一消失后叠粒子。
- **遮挡转场：**树、衣料、雪、烟或火实际进入镜头、覆盖并最终遮满画幅，写清来源与运动，不用凭空黑屏或白屏替代。

大量效果仍以真人镜头为底，控制同时抢焦点的事件。幻想动作可超出现实能力，但接触、身份、空间和视觉因果仍须连贯。

## 十七、声音与对白

每镜独立写“现场声：”，选一到三种最关键的真实声源。连续风声、引擎、火焰、鼓声等跨镜持续，只因距离、遮挡和动作变化。低声不等于世界静音，死寂也可留下极低风声和呼吸。

现场声只为既有剧情人物、动作和环境服务。肩扛视感不自动引入摄影师脚步、喘息、操机声或器材碰撞声；内部关于颠动来源的推算不写成新的声源人物。脚步与呼吸优先明确属于画面中的角色，画外采访对白按剧本单独处理。

声音属于剧情世界：敲鼓、踩水、布料、燃烧、机械、台词以及故事里真实存在的装置发声都可写。默认不加BGM、煽情配乐、甩镜呼啸、变焦提示音、魔法电子音或揭示重击；不因为画面炫就自动配“音效”。

对白保留用户指定的原文与语言，不念中文翻译、不重复、不补词；特殊发音标记原样保留。用户只给旁白供估时，提示词只交付对应的画面与现场声。画外采访者的对白明确声源在画外，不因此增加一个入画人物。默认不生成字幕。

一镜到底统一写连续声音线，说明哪次动作带出哪种声音，不把每段声音说明包装成新镜头。音乐只是速度参照时，写“按该节拍运动，成片声音仅现场声”。用户明确要求现场播放音乐或音乐成片时才覆盖这个默认。

## 十八、生成结果不对时的修正入口

| 问题 | 优先检查与修改 |
|---|---|
| 对标只剩一个片名 | 是否研究了相关场面，是否把有依据的方法转成当前剧情的镜头选择；不能只加色彩标签或照搬原片剧情 |
| 个人习惯压过对标 | 区分必须保留的执行规范与可调整拍法；依对标校准角度、节奏和晃动，不把旧段落手法全带入 |
| 没有自然呼吸感 | 先查是否有明确极稳或全固定要求；无此要求时补克制、不规则的漂移与细小修正，不直接升级为剧烈震动 |
| 明确要肩扛却没有效果 | 是否只有抽象标签；补与移动对应的颠动、侧倾、迟到修正及事件发生时的强弱变化 |
| 出现幕后人员或拍摄器材 | 检查正文、声音、倒影和否定清单是否点名幕后实体；改写为画幅、取景高度、位移、颠动与主体可见变化，不在成品里反复点名排除 |
| 全部抖得一样 | 按观察、移动、突发、停步分别设计，保留关键动作可读瞬间 |
| 采访像念稿 | 身体是否锁死；加话意驱动的肩、头、手、重心变化，不强加目光乱飘 |
| 总是正面居中 | 换观察角度、取景与实体遮挡；不凭空加人填空 |
| 200mm以上背景太清楚 | 逐镜明确超大光圈、极浅景深、不可辨结构的焦外色块；环境图仅供世界位置和光色依据，删掉背景物件清单、清晰布局或全场可辨要求 |
| 雨中人物还是干的 | 面部特写是否缺直接击打、湿贴、流滴和浸湿衣料；逐镜补接触证据 |
| 环境或人物忽然变了 | 资产职责串用、时间与光源重置、局部修改未同步整组 |
| 超大物件像小房子 | 取景把全貌硬塞进去；用人物比例、局部出画与距离固定尺度 |
| 多人照整张出现 | 明确只调用身份，按剧情重新安排站位与当前机位 |
| 远处人被拍得过大 | 远景同时写了面部细节；给可核对的画幅占比，删除看不见的细节 |
| 特效像静态贴图 | 参考职责未限定；缺自运动、前后层次、视差与现场光影 |
| 一镜到底自动切开 | 检查是否重报起幅、重置站位或写成多镜；保留动作和空间锚，简化事件密度 |
| 奔跑镜头像停着 | 极近脸部之外缺背景相对运动、身体颠动或衣料惯性 |
| 舞蹈太慢、太齐或不帅 | 区分BPM、个人动作速度与角色气质；逐人给差异，按最新情绪设计 |
| 质感像CG | 过多发光粒子、全清晰全亮、无接触重量、动作过分平滑；保留真人物理证据 |

## 十九、交付前自检

1. 本次是分析、估时、图片、动作还是视频分镜？是否只交付所需内容？
2. 常规分镜是否先写【对标状态】再写【本组情绪总控】？对标是否由用户提供或确认，未指定时是否诚实标明？
3. 是否研究适用于本场的视听方法，区分事实、观察与设计推断？有无把没查到等同全片没有，或把一处拍法扩散到整场？
4. 总时长、各镜时间码、镜头数、语速和明确停顿是否相容？字数是否符合本次上限？
5. 修改后是否给出完整当前组，且保留未被替换的旧要求？
6. 资产编号、同一人多参考、人数、装造与环境职责是否准确？
7. 空间边界、比例、行动方向、机位、体态与道具是否连续？有没有无缘由消失或新增？
8. 自然呼吸感是否默认保留并由对标、剧情校准？明确极稳或全固定时是否正确关闭？强烈晃动是否有依据，而非每镜套用？
9. 生成正文是否仍把幕后人员或器材写成动作主语、声源或可见实体，或在否定清单里反复点名？
10. 构图与焦段是否适配本场？200mm及以上是否仍落实超大光圈、极浅景深与远景强虚化，未因对标擅自放开？
11. 表演是否有情绪过程、自然身体动态和正确视线？停顿是否在该停的位置？
12. 天气是否真实作用于主体？光源、时间与既有湿度痕迹是否延续，未被对标或人设图布光替换？
13. 特效是否动态、有尺度和反馈？跨镜事件是否继续而非重启？
14. 每镜是否有现场声？有没有把估时旁白、翻译、BGM或情绪音效混进成品？
15. 是否误把本场设定写成全局硬规则？是否添加了用户没有要求的剧情？

先修时间、因果、空间、表演与摄影，再润色词句。写成另一个模型无需阅读聊天记录也能执行的完整提示词。
