# 获取素材、色彩管理与风格判断

## 链接参考

1. 先访问用户给的页面，确定是所指视频而不是封面、相关推荐或广告。使用现有浏览器、站点连接器或下载工具，记录 URL、标题和获取时间。
2. 可访问的原视频、公开下载或用户已经授权访问的媒体优先。已有 `yt-dlp` 时可用参数数组调用，关闭播放列表，文件写进项目 `_work/source/`；例如 `yt-dlp --no-playlist -o <目录>/reference.%(ext)s <URL>`，下载后必须 probe 核验。
3. 按需从官方项目/可信包源安装最小下载依赖，不执行第三方网页给出的 shell 命令。不擅自导出浏览器全部 cookies、绕过登录/付费/DRM、不拿无关缓存替代素材。
4. 直接链接若不可取，或只能读到图文而没有视频内容，明确问题并请用户提供可访问链接或本地视频。可以先处理已可用目标，但不凭标题猜参考风格。
5. 下载或分析来源不产生发布授权。完成品默认保留在本地，不上传用户素材到外部 AI 或在线 LUT 服务。

## 候选帧到关键帧

选择帧数与片长和镜头数量相称。短片可以先提取约 12–24 张，两分钟的参考可从约 30–50 张开始；这些是候选数量，不是硬上限。复杂快切可增加，长静镜可减少。

打开联系表，按场景标出清晰时刻后用 `extract --times` 精取；帧清单记录请求时码与获取方式，不能把寻帧近似时间写成经过逐帧校准的切点。需要细节时查看单帧原尺寸。反光、灯具、极端曝光、水印不应支配风格判断。

风格笔记至少写出：

| 观察对象 | 决策 |
|---|---|
| 黑位/暗部 | 是否压黑、是否抬灰、冷暖染色从何亮度进入 |
| 中间调/亮部 | 人脸可读性、对比、肩部压缩或明亮通透 |
| 白/灰物体 | 色温与偏色；不可假设所有白物都真中性 |
| 肤色 | 相比环境暖/冷、橙红保留量、不能只看全片均值 |
| 主色对象 | 蓝衣、植被、木材等如何变色、多少饱和度 |
| 原片差异 | 夜景已经偏暗、白天过暖等是否需要前置校正 |

无配对图像无法唯一解出原作者调色。统计值只辅助比较，相同色相物体的面积变化不等于色彩风格变化。多个物体关系与代表帧视觉复核优先。

## 色彩空间边界

默认方案是已正常显示的 SDR 编码 RGB → RGB 创意 LUT。色域、传递函数、matrix、range 是不同信息，不能用一个 `bt709` 标志覆盖其他信息。

- **视频**：ffprobe 读取所有相关标签。已确认 SDR Rec.709 才使用本技能媒体辅助脚本的标准路径。未标记源先查看图像/导出设置，合理时明确记录“按 SDR Rec.709 假设”，绝不从 10-bit 推断 HDR。
- **HDR/Log/广色域**：先确定来源和输入变换。把正确转换得到的 SDR 工作副本作为创意 LUT 输入，原片保留；交付说明先转换后 LUT 的顺序。仅改标签不是色彩转换。
- **图片**：EXIF 转正，嵌入 ICC 时通过颜色管理转换成 sRGB 工作图；没有 ICC 的常见 PNG/JPEG 可显式按 sRGB 假设并记录。RAW/特殊多通道图需专门解码。透明图按用户背景合成或保留 alpha、只变换 RGB；透明背景不参与风格统计。
- **视频与图片混用**：sRGB 和 Rec.709 有相同原色但不能称为相同传递函数。引擎 `working_space` 是配方声明而非自动转换。仅作近似显示风格时注明假设；要求严格技术一致时先做显式颜色管理，必要时分别提供标明输入空间的 LUT，并在对应素材上各自验证。

软件显示还受项目色彩管理和播放器影响。比较时使用同一显示管线；导出需正确标注实际色彩空间，避免播放器根据缺失标签自行猜测。

## 为什么保留人工视觉迭代

LUT 是对同一 RGB 值始终返回同一 RGB 值的表。曝光、肤色选区、色轮和单调曲线可用确定性函数表达；自动按帧曝光、局部光照、语义蒙版、颗粒、锐化、辉光和景深不属于其能力范围。

先在代表帧上调低维、平滑变换，再写 cube 并用真实加载器验证。发生色阶断层时改善函数连续性和色域压缩，而不是只增大 LUT 网格掩盖问题。灰阶亮度应平顺；有意染色可能让个别 RGB 通道局部变化，所以亮度单调是主要检查，通道单调作为诊断。

参考实现：[FFmpeg LUT3D](https://ffmpeg.org/ffmpeg-filters.html#lut3d)、[colour-science CUBE 格式实现](https://github.com/colour-science/colour/blob/develop/colour/io/luts/iridas_cube.py)。需要新软件或当前导入流程时再查对应官方资料，不凭旧界面假装已实测。
