## 四、打光方案模板

### 方案 A：单窗光实景（最经典寇塔尔）

```
LIGHTING SETUP — Coutard Single Window Natural:

• KEY: Actual Paris apartment window, afternoon daylight
• FILL: NONE (Coutard refused fill light in New Wave years)
• PRACTICAL: Table lamp or ceiling fixture as visible source
• AMBIENT: Dark corners embraced, no lift
• SHADOW: Hard natural shadows preserved
• COLOR TEMP: Window 5600K, practical 2700K, no correction
• FILM: Ilford HP5 pushed to 800 (B&W) or Ektachrome (color)
• MOOD: Documentary truth, no movie magic
```

### 方案 B：咖啡馆吊灯（Parisian Café）

```
LIGHTING SETUP — Coutard Café Pendant Light:

• KEY: Actual brass pendant lights hanging over tables
• FILL: Mirror walls providing natural bounce
• PRACTICAL: Entire café lighting system as-is
• AMBIENT: Cigarette smoke diffusing light beautifully
• SHADOW: Soft from mirrors, hard from pendants
• COLOR TEMP: Tungsten 2700K (in color), undefined (in B&W)
• FILM: HP5 pushed 800
• MOOD: Intellectual conversation, 1960s Left Bank
```

### 方案 C：手持街拍自然（Street Handheld）

```
LIGHTING SETUP — Coutard Street Natural:

• KEY: Sun or overcast sky
• FILL: Building walls bounce, concrete reflection
• PRACTICAL: Shop windows, streetlights at night
• AMBIENT: Atmospheric Paris weather (fog, rain, haze)
• SHADOW: Hard sun shadows or completely diffused overcast
• COLOR TEMP: 5600K (day) to 3200K (night streetlight)
• FILM: HP5 800 for most scenarios
• MOOD: Authentic, unposed, alive
```

### 方案 D：Pop Art 原色室内（Saturated Color）

```
LIGHTING SETUP — Coutard Pop Art Primary Colors:

• KEY: Mix of window daylight + colored practicals
• FILL: Bounce off saturated colored walls (red/blue/yellow)
• PRACTICAL: Lamps with colored shades, neon signs
• AMBIENT: Color bouncing everywhere creating color spill
• SHADOW: Colored shadows accepted
• COLOR TEMP: Mixed intentionally, no correction
• FILM: Ektachrome reversal for maximum saturation
• MOOD: Theatrical, anarchic, Pop Art joy
```

### 方案 E：单灯泡表现主义（Alphaville）

```
LIGHTING SETUP — Coutard Single Bulb Expressionism:

• KEY: Single bare bulb hanging from ceiling
• FILL: NONE — darkness surrounds
• PRACTICAL: The bulb IS the practical
• AMBIENT: Pitch black beyond light pool
• SHADOW: Deep, moving (if bulb swings), dramatic
• COLOR TEMP: 2700K tungsten bulb
• FILM: HP5 pushed to 1600 for extreme grain
• MOOD: Interrogation, paranoia, noir sci-fi
```

### 方案 F：Mediterranean 过曝（Côte d'Azur）

LIGHTING SETUP — Coutard Mediterranean High-Key:

## 七、Ektachrome vs HP5 选择速查

### 使用 Ilford HP5（黑白）当：
- 场景是巴黎街头 / 咖啡馆 / 公寓日常
- 情绪是存在主义 / 纪实 / 忧郁 / 知识分子辩论
- 影片参照：《精疲力尽》《祖与占》《阿尔法城》《柔肤》《男性女性》
- 光线条件：阴天 / 低照度 / 夜间 / 需要高感光

### 使用 Ektachrome（浓饱和彩色）当：
- 场景是地中海海岸 / 公寓原色内景 / 海边旅行
- 情绪是 Pop Art / 政治 / 爱情狂喜 / 反乌托邦
- 影片参照：《狂人皮埃罗》《轻蔑》《女人就是女人》《周末》
- 光线条件：明亮自然光 / 需要色彩喷发

### 边缘情况（两者都试）：
- 现代政治片（《Z》用彩色，但可试黑白版本）
- Schoendoerffer 战争片（早期黑白，晚期彩色）
- 戈达尔 1980s 复出（多格式实验）

## 十、寇塔尔 vs 当代 AI 图像陷阱

使用 AI 工具生成寇塔尔风格时，**这些常见 AI 默认值必须避免**：

| AI 默认倾向 | 寇塔尔的反向 |
|------------|--------------|
| 清晰锐利 | **胶片颗粒必须明显** |
| 柔焦浪漫 | 寇塔尔不用柔焦 |
| 三点布光 | **只用自然光** |
| 色彩分级 teal/orange | **原色或真黑白** |
| 稳定器平滑 | **手持呼吸感必须保留** |
| 完美构图 | 即兴松散允许 |
| 美颜皮肤 | **真实肤质胶片粒感** |
| 阳光金色滤镜 | 真实阴天或硬光 |
| HDR 高动态范围 | 高对比丢失暗部细节正常 |
| 棚拍背景 | **必须巴黎实景** |

在提示词中明确加入：`film grain, no color grade, no digital smoothing, handheld authentic, 1960s archival quality, no modern polish`

## 结语：寇塔尔提示词黄金法则

1. **指定胶片**：HP5 或 Ektachrome，二选一
2. **明确手持**：除非特殊理由，默认手持
3. **拒绝补光**：强调"available natural light only"
4. **地理锚定**：1960s Paris / Mediterranean / Indochina
5. **引用影片**：Breathless / Pierrot le Fou / Alphaville / Jules et Jim
6. **允许不完美**：film grain / imperfect / raw / authentic
7. **导演合作者**：Godard / Truffaut / Demy / Schoendoerffer / Costa-Gavras
8. **时代关键词**：French New Wave / Nouvelle Vague / 1960s / Left Bank
9. **设备关键词**：Eclair Cameflex / Mitchell BNC / Kinoptik
10. **拒绝棚拍**：on location / real streets / real apartments

遵循这些法则，AI 生成的图像将真正捕捉寇塔尔的革命精神——**一场让摄影机第一次走上街头的革命**。
