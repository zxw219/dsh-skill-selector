# image-portrait-3x4 · 3:4 肖像创造器

**从零创造**一张 3:4 竖版肖像的**出图提示词**。只出提示词，不调用任何出图工具。

## 这个技能解决什么

漫剧与短剧的角色资产，最麻烦的不是"画好看"，而是**画得不一样、还留得住**：AI 默认给的是一张"审美平均值"的脸，同一个角色的脸又会在不同图里漂走。本技能把这两件事拆成两道工序：

- **不趋同** → 用随包的 220 型脸型库选型：骨相、五官、识别锚点（痣／疤／不对称，毫米级）逐项写死。
- **不漂移** → `[骨相]` `[五官]` `[识别]` `[气质]` 列为**身份四定值**，写入即固定；风格层只留 `[光]` 与 `[画风]` 两个开关。

## 安装

本地安装（无需仓库）：把本目录整体复制到 `~/.workbuddy/skills/` 下即可被识别。

## 你可以直接这样说

- 「帮我从零创造一个 3:4 角色肖像的提示词」
- 「按 220 脸型库给这个角色生成 3:4 肖像提示词，用 F021 那股清冷劲」
- 「出一版 3:4 头像提示词，中性灰影棚背景，服饰不要」
- 「从无到有生成一个人物肖像 prompt，画风用三渲二」
- 「帮我做一张纯灰底的人像提示词」

## 硬口径速查

| 项 | 取值 |
|---|---|
| 比例 | **3:4** 竖版（「锁定」只用于比例） |
| 取景 | 头部 + 全部发型与头顶 + 颈项双肩，充满画面（正向描述，不做边缘声明） |
| 服饰 | **绝对不要** |
| 背景 | **#808080**（18% 中性灰）纯净影棚背景板 |
| 光 | 默认**漫射柔光 + 平光铺照**，光比极小 |
| 身份 | `[骨相]` `[五官]` `[识别]` `[气质]` 四项定值，写入即固定 |
| 措辞 | 正向为主；禁裁切锁死语义；负向词非必要不用 |
| 画风 | 用户指定优先，未指定默认中式写实 |
| 交付 | 中英双版提示词，默认不出图 |

## 验证

```bash
python scripts/lint_prompt.py --text "【肖像设定】……【背景】……#808080……"
```

七条规则：禁用裁切锁死语义／「锁定」只能指向比例／必须声明 3:4／必须有 #808080 或中性灰／身份四定值至少 3 项／必须有漫射柔光·平光·铺照之一／负向块只允许一行。

## Troubleshooting

| 现象 | 原因与处理 |
|---|---|
| 出的图是侧脸／半张脸 | 构图句权重不足。把「面部正面朝向镜头，目光平视镜头」**提到提示词最前**；**不要去改气质词**（气质是定值，改了就不是同一个角色）。 |
| 头顶被切掉 | 正向加「完整呈现头顶与全部发型」并前置；或改为先出 4:5／1:1 稍远景别，再自行裁到 3:4。 |
| 画面里冒出衣领、肩带 | 用 §6 的按需负向块，只补「任何衣物、领口、肩带、布料」一行，用完即撤。 |
| 皮肤像蜡像、被磨平 | 正向补「可见毛孔、细纹与自然色差，半哑光」；再按需补一行「蜡像皮肤、塑料皮肤、油光、磨皮」。 |
| 背景发灰不均匀或有渐变 | 正向写「均匀单一色值」；#808080 是无纹理背景，必要时后期替换极干净。 |
| 女脸出成男脸 | 提示词里补上 `[性别]` 与 `[妆容]` 两行；唇色必须写具体色相，不能写"淡／灰／裸"。 |
| 自检器报 R5 | 身份四定值少于三项，回到库条目补齐 `[骨相]` `[五官]` `[识别]` `[气质]`。 |

## 边界

本技能**不做**：参考图重拍、三视图／四视图人物卡、全身人物设定卡、跨镜头身份锁定——这些分别属于 `character-casting-studio` 与 `character-continuity-bible` / `entity-continuity-system`。
