# 3:4 肖像创造器（只出提示词）

把「一个角色设定」变成「一份可直接投喂的 3:4 肖像出图提示词」。**从零创造**，不是拿参考图重拍。

## 硬口径（八条，逐条不可省）

1. **比例锁定 3:4** 竖版。「锁定」只允许用于**比例**，不得用于画面边缘或构图范围。
2. **取景**：头部、全部发型与头顶，加颈项与双肩；头部与肩部充满整个画面。**用正向描述**，不做边缘声明。
3. **服饰绝对不要**：画面主体是头部、颈项与双肩的皮肤；除头饰与耳饰外不出现其他物件。
4. **背景**：标准 18% 中性灰影棚背景板 **#808080**，均匀单一色值、纯净无瑕疵。
5. **光**：默认**漫射柔光 + 平光铺照**，光线分布均匀柔和、光比极小、无硬阴影方向。
6. **身份四定值**：`[骨相]` `[五官]` `[识别]` `[气质]` **写入即固定**，生成与后续复用中都不漂移。气质属定值——**不可为了救构图去改气质词**。
7. **措辞纪律**：正向为主；**禁止裁切锁死语义**（不写"下缘止于／不入画／不得被切断／锁定边界"）；**负向词非必要不用**，默认不含负向块。
8. **只出提示词**：默认不调用任何出图工具；出图须由用户逐次明确授权。

## 工作流（五步）

1. **定画风**：用户已给则直接用；未给则问一句，或默认「中式写实」。
2. **定角色设定**：按「性别＋年龄＋气质」从脸型库选编号（`F001`–`F120` / `M001`–`M100`），或接住用户的自然语言 brief。库中 `[性别]`／`[妆容]`（男为 `[面部]`）两行必须带上，否则会漂成男脸。
3. **组装修辞**：按 `references/portrait-spec.md` 的固定段落顺序写（肖像设定 → 构图与比例 → 着装 → 光 → 背景 → 画风 → 质感），`[发型]` 行追加「含发际线、额前碎发、发丝走向与体积」。
4. **自检**：跑 `python scripts/lint_prompt.py --text "<提示词>"`，7 条规则必须全过。
5. **交付**：中英双版提示词 + 该角色的设定来源（库编号／brief）与假定项。

## 输出契约

- 交付**中文版与英文版**两段可直接复制的完整提示词（不要只给片段）。
- 段落顺序固定，缺段即视为未完成。
- 末尾附三行元信息：**设定来源**（库编号或 brief）、**光型取值**、**画风取值**；凡我替你补定的项，标注「假定」。
- 默认不含负向块；只有当出现衣物残留、蜡像／磨皮、第二人物、文字水印四类现象时，才按 §6 只补对应一行。

## 边界（触发隔离）

| 用户真正想要的 | 应走哪条路 |
|---|---|
| **从零创造 3:4 肖像提示词** | **本技能** |
| 拿一张已有图重拍／换背景／改画幅 | 不走本技能（本技能不产参考图重拍提示词） |
| 三视图／四视图／全身人物卡 | `character-casting-studio` |
| 已定角色跨镜头、跨集的形象锁定 | `character-continuity-bible` / `entity-continuity-system` |
| 竖屏视频分镜与出片提示词 | `video-seedance25-portrait-director` 等视频技能 |
