# image-portrait-4d · 人像摄影四维导演

## 这是什么

给它一个人或一个主题，它给你一条能直接投喂图像模型的完整人像提示词。

核心不是"选风格"，是**定坐标**。

普通做法是挑一个风格词——杂志感、街拍感、胶片感——然后往提示词里堆。风格词是最没用的控制手段，因为它不告诉你画面里到底发生什么。

这套方法问的是另一个问题：**这张照片是怎么被拍出来的。** 答案由四个同时成立的物理事实决定：

| 维 | 管什么 | 取值 |
|---|---|---|
| **R 摄影者关系** | 画面的伦理温度，可控程度 | 受邀 / 在场未摆 / 未察觉 / 已察觉 |
| **O 光学距离** | 空间压缩，观众的位置感 | 标准 35–50 / 中长焦 85–135 / 超长焦 150–200 / 广角 24–35，另配遮挡层 |
| **M 瞬间相位** | 时间感，摆拍感的真正开关 | 定格 / 将动 / 进行中 / 余韵 |
| **D 成片介质** | 质感与色彩 | 数码棚拍 / 胶片 / 手机计算 / 长焦纪实 |

四维相互独立，可以任意交叉。256 个格子里，每一格都是一个具体画面。

## 为什么要拆成维度

单一风格的做法，各自只覆盖坐标空间的一小段：

- 编辑精修那一套，几乎全在 **R1/R2 + M1 + D1**
- 偷拍抓拍那一套，几乎全在 **R3 + M3 + D3/D4**

它们被当成两种互斥的"风格"，所以「有杂志质感、但像被抓拍」这类需求，在任一套里都只能靠折中——写出来就是四不像。

拆成维度以后，这种需求有了确切地址：**R3 + O2 + M3 + D1**。画质用棚拍级的干净，光线叙事用现场光，摄影者是隐形的。三个维度各自负责一件事，不互相妥协。

没有任何单一风格覆盖的格子，就是这套坐标系的产出增量：

| 坐标 | 效果 |
|---|---|
| R2 + M4 + D1 | 知道镜头在、动作刚结束、棚拍级画质。成品感最强 |
| R1 + M3 + D3 | 受邀配合，但用手机计算摄影的质感。网红内容主力 |
| R4 + O4 + D2 | 广角贴近的「被抓到」，胶片质感。极强不安感 |
| R3 + O2 + M1 + D1 | 「停驻」而非摆姿 + 棚拍画质。极度克制的高级感 |

## 怎么用

直接说需求，不用记参数。

**杂志封面**

> 35 岁女性建筑师，深色高领毛衣，行业杂志封面，16:9

它给出 `R1 / O2 无遮挡 / M1 / D1`，选 E8 作锚点（负空间的分配与材质处理最接近），写契约，出提示词。

**街拍偷拍**

> 同一个角色，地铁站台，长焦偷拍感，一组 6 张

给出 `R3 / O3 主 + O2 / M3 / D3`，锚点取机位 2，然后给维度矩阵。

**要质感又不要摆拍感**

> 街头时尚品牌广告，但机位要像路人偷拍

给出 `R3 / O2 重遮挡 / M3 / D1`——这就是原来做不到的那一格。

**换一个维度微调**

它每次都会在首行写出坐标。想改方向，直接说「R 改 R2」「遮挡降到轻」「M 换 M4」，不用重写需求。

## 输出长什么样

1. **坐标**：`R? / O?+遮挡 / M? / D?`，附一句为什么
2. **冲突检查**：命中六条矛盾时说明调了什么
3. **锚点**：1 个，说明继承哪几维
4. **契约**：Preserve（按四维记录）/ Replace / Avoid
5. **提示词**：八段骨架，按顺序
6. **负面约束**
7. **验证清单**

## 八段骨架

顺序不要打乱，模型是按这个顺序理解画面的：

```
① 主体：身份、年龄感、识别特征、当前动作与身体状态
② 摄影者关系：谁在拍、从哪拍、隔着什么        ← R 维
③ 光学：焦段、机位高度、距离、构图与裁切       ← O 维
④ 瞬间：动作停在哪个相位、有无运动痕迹         ← M 维
⑤ 光线：来源、方向、性质、色温
⑥ 材质：皮肤、发丝、织物、道具表面
⑦ 环境：场景元素、环境动态、其他人物
⑧ 介质：画质、色彩、颗粒／锐化／暗角          ← D 维
```

②③④ 来自抓拍那一套，⑤⑥⑧ 来自编辑那一套。原来各缺一半，这里八段都要写实——只写②③④得到随手拍，只写⑤⑥⑧得到没有现场感的影棚照。

## 组图的正确扫法

**变 R／O／M，锁 D。**

D 一跳，整组图就散了，看起来像不同人的作品。所以质感固定一到两个值，其余三维铺开扫。

n=10 时给维度矩阵，任意两张至少 2 维不同。只改场景不算差异化。
