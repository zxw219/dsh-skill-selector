制作日期：2026-09-28　|　版本 1.1.1　|　模式：Production

---

## 1. 这个包解决什么

把一段**约 700 字自然语言提示词**，变成**可判断、可修补、可选参数**的操作单元：

- 每一段锁什么、删掉会怎样 → `references/01-prompt-template.md` 九层拆解
- 该用哪个模型、什么分辨率、什么质量档 → `references/02-model-adaptation.md`
- 好在哪、依据是什么 → `references/03-visual-anatomy.md` ＋ `examples/visual-check.md`
- 错了怎么定位、怎么修 → `references/04-failure-modes.md`

**产出物**：一条完整、可直接复制的生图提示词（＋ 模型 / 分辨率 / 画幅 / 质量档四项建议）。

## 3. 有意拒绝的东西

| 拒绝项 | 理由 |
|---|---|
| **拒绝采纳示例图中的品牌元素** | 成片中带有品牌签名与相关标记。**按主任指示，这类内容不进入本技能的规则或模板**；`SKILL.md` 与 `01-prompt-template.md` 反而明确要求「不添加 logo、水印、品牌标记」 |
| **拒绝改写成「出图执行型」技能** | 主任定的是**输出完整可复制提示词**；本包不调工具、不代出图 |
| **拒绝对示例图中的角色做 IP 层面的改动或约束** | 按主任指示，这几张图**不做品牌或 IP 约束**，原样保留 |
| **拒绝在无对照实验的情况下声称「质量更好」** | 未做横向生成对照，任何优势声明都无证据 |
| **拒绝把「文字自动生成」保留为默认** | 源模板让模型自动生成画面文字，这是**最高的失败率来源**；改为显式列出 |

## 4. 本包原创贡献与证据等级

| # | 贡献 | 等级 |
|---|---|---|
| 1 | **九层功能拆解表**（含"删掉会怎样"） | **design advantage** —— 让"能不能删某段"从感觉变成判断 |
| 2 | **10 类失败模式 + 可直接追加的修法补句** | **design advantage** —— 源材料完全没有；每条末句可直接复制进提示词 |
| 3 | **版式配方与字号尺度比 20 : 6 : 2 : 1** | **validated advantage** —— 由 4 张成片实测归纳，4/4 命中 |
| 4 | **「强调色取自角色自身元素」的可操作取色优先级** | **validated advantage** —— 4/4 成片验证（发色 / 机体色 / 围巾 / 上衣） |
| 5 | **锁定强调色的写法** | **design advantage** —— 源模板只说"自动提取"，本包给出显式指定方式 |
| 6 | **锁定画面文字的写法** | **design advantage** —— 直击 F2 伪文字风险 |
| 7 | **GPT Image 2 / 2.5 参数建议与换模型退化预期** | **hypothesis** —— 参数来自第三方平台登记，**非官方文档**；退化预期为推理，**未实测** |
| 8 | **9:16 画幅的判定** | **validated advantage** —— 实测 577×1024 = 1.7747，与 9:16（1.7778）几乎重合 |
| 9 | **示例图视觉核对台账** | **validated advantage** —— 4 张逐项核对，结论见 `examples/visual-check.md` |
