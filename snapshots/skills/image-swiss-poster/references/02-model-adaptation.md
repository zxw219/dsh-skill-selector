# 02 · 模型适配：GPT Image 2 与 GPT Image 2.5

> **为什么单独写这一份**：这套模板的命门是**画面内文字渲染**——「字体本身成为主要图形元素」，字写错整张就废。换一个文字渲染弱的模型，同样的提示词产出质量会断崖式下跌。所以模型不是随便选的。

---

## 1. 为什么必须用这两个模型

| 本模板的要求 | 对模型的能力要求 |
|---|---|
| 巨大无衬线标题跨越画面、被裁切、被遮挡 | **长串文字准确渲染**，且能处理被遮挡后的局部完整性 |
| 中文名 + 日文名 + 英文标题同框 | **多语言混排**，含 CJK 字形正确 |
| 坐标、编号、小字号短句做次级层 | **小字号文字不糊成噪点** |
| 严格网格、精确对齐 | **版式遵守能力**，不是自由绘画 |

GPT Image 2 与 2.5 是目前画面内文字最可靠的两代 OpenAI 图像模型；2.5 在其上进一步强化。

---

## 2. 两代模型能力对照

> ⚠️ **说明**：以下参数来自第三方公开登记与自测（检索日 2026-09-28）。可信度**中等**；其中「参考图数量」在不同口径之间存在矛盾（5 张 / 16 张），已如实标注分歧，**未经官方核实**。用于选型参考足够，用于计费与合规请以官方文档为准。

| 维度 | GPT Image 2 | GPT Image 2.5（2026-09-08 发布） |
|---|---|---|
| **变体** | 单一 | **Flare**（默认，低延迟，质量 ≈ 或 > GPT Image 2）／ **Sunburst**（质量优先，保留精细纹理） |
| **分辨率** | 4K | **1K / 2K / 4K**（4K 短边 2880px） |
| **最大边长** | 4K | **3840px** |
| **质量档** | 依分辨率与质量 | **Low / Medium（默认）/ High / xHigh / Max** |
| **画幅** | Auto + 8 预设 + 自定义像素 | Auto + 8 预设（1:1 → 21:9） |
| **自定义尺寸约束** | 支持自定义像素 | 长宽均为 16 的倍数 · 最大边 3840px · 长宽比 ≤ 3:1 · 像素总量 65.5 万 – 829.4 万 |
| **画面内文字** | 第三方测评评为「其页面上最可靠」 | **最强**——菜单 / 海报 / 图表均正确，含图表几何；支持 40+ 语言含 CJK |
| **单次出图量** | 最多 10 张 | **1 张**（批量需多次调用） |
| **参考图** | 最多 16 张（每张计费） | 5 张 ／ 另一口径称 16 张 —— **分歧，未核实** |
| **透明背景** | 支持 | 支持（PNG / WebP 带 Alpha） |
| **提示词长度上限** | — | **20,000 字符** |
| **溯源** | — | C2PA 元数据 + 隐形水印（源侧） |

## 3. 本风格推荐参数（可照用）

### 3.1 画幅

**竖版即可；9:16 与 3:4 均已由成片验证**：

| 画幅 | 实测依据 | 推荐落点 |
|---|---|---|
| **9:16**（高宽比 1.7778） | A 批 4 张：577×1024（实测 1.7747） | `1080×1920`（交付）／`2160×3840`（印刷或大屏） |
| **3:4**（高宽比 1.3333） | B 批 9 张：1440×1920（实测 1.3333） | `1080×1440` ／ `1440×1920` |

**怎么选**：偏杂志封面 / 手机全屏 → 9:16；偏书籍开本 / 社媒图文 → 3:4。两者在本风格下均成立，**不必固定**。

> 注意：GPT Image 2.5 的自定义尺寸要求**长宽均为 16 的倍数**——1080 不是 16 的倍数，1920 与 1440 是。若要严格自定尺寸，用 `1088×1920` 或直接用预设比例。

### 3.2 按用途选档

| 用途 | 模型变体 | 分辨率 | 质量档 |
|---|---|---|---|
| 试风格、试强调色、试构图 | Flare | 1K | Low 或 Medium |
| **正式交付（推荐默认）** | Flare | 2K | Medium |
| 印刷、大屏、封面主图 | **Sunburst** | 4K | High 及以上 |

**成本提示**：GPT Image 2.5 的计费由**分辨率 × 质量档**共同决定（第三方登记：Medium 在 1K / 2K / 4K 分别约 40 / 70 / 110 credits）；Flare 与 Sunburst **同价**。因此**加质量档比加分辨率更省钱**这条经验在此不成立——两者都贵，按需选。

### 3.3 参考图怎么用（可选）

若用户提供了角色参考图：

- GPT Image 2 / 2.5 **均支持参考图**，可保留角色面部与服装识别
- 建议搭配明确分工：**图 1 作角色主体**，其余位留给配色参考或场景碎片
- 但要留意：**参考图会影响「半写实日漫肖像」这一层**。若参考图是写实照片，产出会偏写实；是二次元图，产出会偏插画。**风格优先还是还原优先，先问用户。**

### 3.4 提示词长度

本模板正文约 **700 字符**，加上 3.3 文字锁定块与角色描述，通常落在 1,000–1,500 字符——**远低于 GPT Image 2.5 的 20,000 字符上限**。不必为长度压缩。

## 4. 换其他模型的退化预期

| 模型 | 预期表现 |
|---|---|
| **Nano Banana 2** | 标题字尚可，**小字号会飘**；次级信息层容易糊成噪点 |
| **Qwen Image 3 Pro** | 双语标题正确，**图表类不可靠**；网格精度一般 |
| **Seedream 5 Pro** | 保真度高、细节强，但文字排版不是其强项 |
| 其他通用模型 | 大概率出现**伪英文**（形似英文但拼错），标题一垮整张报废 |

**判断规则**：交付前**逐字核对画面内所有文字**。发现伪文字，不要靠「再加一句『文字要正确』」硬修——**改成显式列出全部文字**（见 `01-prompt-template.md` §3.3），并考虑升级到 Sunburst + High。

---

## 5. 与本机工具的关系

本包**只输出提示词**，不代为出图。若要在本机执行，使用宿主内置的 `ImageGen` 能力；本机是否等价于 gpt-image-2 / 2.5 **未经验证**，需实测确认后再声明。
