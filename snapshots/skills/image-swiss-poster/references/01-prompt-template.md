# 01 · 提示词模板与分层拆解

> **本包新增内容**均为本机推导，已逐条标注「本机新增」。

## 1. 完整模板（逐字原文，可直接复制）

把 `【角色】` 替换成你的角色描述即可。文中 `【角色】` 共出现 3 处。

```
【角色】，保留角色最核心的身份识别、发型轮廓、代表色、服装特征与气质，重新设计为现代瑞士主义角色海报。

Modern Swiss Style × International Typographic Style × Oversized Typography × Asymmetric Grid × Editorial Character Poster。

以【角色】的大幅近景肖像作为核心视觉，人物占据画面一侧或从边缘切入，不使用传统居中立绘。采用近距离视角、轻微仰拍或非常规裁切，让头部、肩线与服装形成强烈几何轮廓。

画面由超尺度无衬线字体、大面积留白、严格网格、非对称布局和极少量信息共同构成。巨大英文字母或角色相关文字跨越画面，可被边缘裁切、被人物遮挡，字体本身成为主要图形元素，而不是普通标题。

整体以黑、白、米白、深灰为基础，只保留一种根据角色自动提取的高饱和强调色，用于巨大字体、几何色块或极少量视觉锚点。

人物表现偏高级 Editorial 插画 / 半写实日漫肖像，细节克制，避免复杂背景。允许加入极少量城市建筑摄影碎片、坐标、编号、短句、小字号信息和细线作为次级信息层，但保持大量负空间。

版式强调尺度反差：巨大字体 × 微型文字，人物局部特写 × 大面积空白，纯色色块 × 黑白人物。整体干净、锐利、理性、具有国际主义平面设计和当代文化杂志封面的视觉张力。

文字内容根据【角色】的身份、世界观、能力或性格自动生成，不固定文案。

竖版海报，单人角色。
```

## 2. 九层功能拆解

模板不是风格词堆砌，每一段锁一件事。编译时不要打乱顺序，也不要删层。

| # | 段落 | 锁住什么 | 删掉会怎样 |
|---|---|---|---|
| ① | 首句「保留…重新设计为…」 | **身份保真边界** | 角色被风格吃掉，只剩一个穿黑衣服的陌生人 |
| ② | `Modern Swiss Style × …` | **风格锚定串**（英文关键词包） | 模型不知道你要哪种现代主义，会退化成普通极简 |
| ③ | 「大幅近景肖像…边缘切入…不使用传统居中立绘」 | **构图宪法** | 出现正面居中大头照，整张变证件照 |
| ④ | 「超尺度无衬线字体…字体本身成为主要图形元素」 | **字体即图形** | 字体退化成普通标题栏，画面变成「人物 + 一行字」 |
| ⑤ | 「黑白米白深灰…**只保留一种**高饱和强调色」 | **色彩秩序** | 出现多色，画面瞬间变杂 |
| ⑥ | 「高级 Editorial 插画 / 半写实日漫肖像，细节克制」 | **人物表现方式** | 可能退成纯扁平矢量插画，或做成厚涂写实照片 |
| ⑦ | 「允许加入极少量城市建筑摄影碎片、坐标、编号…」 | **次级信息层** | 画面变成纯人物 + 大字，缺杂志感 |
| ⑧ | 「尺度反差：巨大字体 × 微型文字…」 | **张力来源** | 所有元素一个尺度，画面平掉 |
| ⑨ | 「竖版海报，单人角色」 | **交付形态** | 出成横版或多人，不可用 |

## 3. 填空指引

### 3.1 `【角色】` 该写多细

三个位置各出现一次，**同一份角色描述填三处**。建议 30–60 字，依此顺序：

```
角色名（或代称），年龄/性别，发型与发色，服装主结构与主色，标志性道具或配饰，气质关键词
```

**示例**：

```
夜巡人「墨鸦」，男性，黑长发束成高马尾，深灰立领长风衣配金属扣具，佩一把无鞘直刀，沉静寡言
```

### 3.2 强调色怎么定（关键决策）

模板只让模型「自动提取」，但**你最好主动指定**，否则模型可能选到与角色无关的颜色。

**取色优先级**：

1. 角色**最具代表性的服装主色**（示例中的红围巾、黄上衣、蓝龙袍都属此类）
2. 角色**发色**（示例中的紫色短发）
3. 角色的**标志性道具色**（机甲配色、武器配色、法宝配色）
4. 以上都无强辨识度时，用世界观阵营色

#### 强调色的 6 种用法（实测自 13 张成片）

选完颜色，还要决定**它落在哪里**。以下 6 种都有成片依据，任选其一：

| 用法 | 怎么写 | 适用 |
|---|---|---|
| ① **附着角色自身元素** | `强调色仅出现在角色的围巾与腰带处` | 最稳，默认选它 |
| ② **只染标题的个别字母** | `标题中仅字母 A 使用强调色，其余字母保持纯黑` | 想要精致克制 |
| ③ **整组标题字着色** | `底部标题「LOTUS CAVE」整体使用强调色` | 想要更强视觉冲击 |
| ④ **纯几何色块** | `画面右上放一个纯色圆，直径约为画面宽的 1/8，作为全图唯一强调色` | 角色本身无色可提 |
| ⑤ **摄影碎片充当** | `摄影碎片保留单一色彩，并作为全图唯一强调色` | 有可用素材时 |
| ⑥ **完全不用** | `全图仅使用黑、白、米白、深灰，不使用任何强调色` | 追求极致冷峻 |

#### 写进提示词的方式（本机新增）

在第五段末尾补一句，例如：

```
整体以黑、白、米白、深灰为基础，只保留一种根据角色自动提取的高饱和强调色……
强调色固定为 #B32E2E 这一档的深红，取自角色的围巾。全图仅此一处使用该色。
```

> ⚠️ **要守住的不是「必须有一个色」，而是「饱和度克制」**——整张画面里高饱和色只出现在一处，面积要小。
> **「零强调色」已被成片验证成立**（见 `03-visual-anatomy.md` §3）。

### 3.3 画面文字怎么写

模板说「文字内容根据角色身份自动生成，不固定文案」——**这会把文字的准确度交给模型，有风险**。

**建议做法（本机新增）**：把你要出现的文字**直接列进提示词**，并加上这句：

```
画面内文字仅使用以下内容，逐字正确，不得增删改写：
主标题「MIKASA」（顶部超大，允许被裁切）
副标题「ACKERMAN」（底部超大，允许被裁切）
中文名「三笠·阿克曼」　日文名「ミカサ・アッカーマン」
三行短句「STRENGTH / SILENCE / PROTECTION」　
坐标「50.8503°N 4.3517°E」　编号「104TH TRAINING CORPS」
```

不指定文字时，模型容易生成**看似英文但拼错**的伪文字（见 `04-failure-modes.md` F2）。

#### 中文元素体系（做「东方变体」时必须四件齐备）

只把标题换成中文，会变成「英文海报的中译版」，**不是**这个体系。要有东方感，需**同时**指定四件：

```
中文书法竖排大字：角色名，置于人物对侧的留白区，竖排
中文短句 2–4 行：文言或对句，紧贴书法字
篆刻印章 1 枚：朱红或金色，方寸大小，置于画面角落
中英对译：上述中文旁配英文意译
```

完整写法示例：

```
画面内文字仅使用以下内容，逐字正确，不得增删改写：
主标题「BULL DEMON KING」（顶部超大，允许被牛角遮挡局部笔画）
底部标题「FLAT HEAVEN」（底部超大，整体使用强调色）
中文书法竖排大字「牛魔王」，置于画面左侧留白区
中文小字「平天大聖」
中文短句「力可拔山，气可吞天」＋ 英文对译「MOUNTAINS BOW, EVEN HEAVEN FEARS HIS HORNS」
篆刻印章「赤霄」一枚，朱红，置于右下角
坐标「34.3220°N 108.0293°E」　编号「No. 72」
```

## 4. 可选增强块（本机新增·非源包内容）

按需追加，不要默认全加。

| 增强项 | 什么时候加 | 追加文本 |
|---|---|---|
| **锁定强调色** | 角色色相明确时 | 见 3.2 的补句 |
| **锁定画面文字** | 需要文字绝对正确时 | 见 3.3 的补句 |
| **指定标题字** | 想控制裁切位置 | `顶部标题字从画面顶端裁断，底部标题字从画面底端裁断。` |
| **要求遮挡关系** | 想让字更有层次 | `允许人物头发、肩线遮挡标题字的局部笔画。` |
| **控制次级层密度** | 担心画面变乱 | `次级信息层总量不超过画面的 8%，其余保持留白。` |
| **指定输出尺寸** | 用于印刷或大屏 | 见 `02-model-adaptation.md` |
| **中文书法层** | 做东方变体时 | 见 3.3 的「中文元素体系」 |
| **标题明度分层** | 想让两组标题分出主次 | `顶部标题使用纯黑，底部标题使用浅灰并降低对比，融入背景。` |
| **金属 / 描边标题** | 想要材质感 | `底部标题使用金属质感描边空心字，不做实心填充。` |
| **彩色摄影碎片** | 碎片要充当强调色 | `摄影碎片保留单一色彩，并作为全图唯一强调色。` |
| **条形码与放大编号** | 想要杂志物料的实感 | `画面左下放置条形码与编号「NO.001」，编号字号约为标题字的 1/8。` |
| **道具清单** | 角色有多件法宝/装备 | `右侧信息列逐条列出：七星剑、紫金红葫芦、芭蕉扇。` |
