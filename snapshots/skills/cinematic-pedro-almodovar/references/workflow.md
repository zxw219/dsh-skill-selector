# 单帧执行流程

默认生成一张原创电影静帧，视觉语言强度85/100；用户只要提示词时不生成。尊重用户指定的主体人数、年代、场景、天气、黑白或色彩与尺寸。2.35:1是本技能默认输出格式，不是导演全部作品的历史画幅；用户明确指定其他比例时以用户为准。

## 选择与编译

1. 读取 `director-profile.md`，将当前场景映射到构图、镜头距离、光源、材料和人物行为。资料是创作启发，不是所有作品的固定法则；精确焦段均为全画幅等效创作建议，不是已核实的实拍器材。用户要求历史考据时先核查访谈、摄影指导或制作方资料，并标注出处。
2. 默认85/100；轻度40，强烈90，极致100。强度通过空间结构、机位、表演和材料增强，不以强行加色或特效计量。轻度40要求至少三项一致的可见线索，85及以上至少五项；具体强化按 `amplification.md` 执行；静止机位和持续时间只能通过画面迹象推断，不算直接可见的运动证据。
3. 选择一个主构图、一个主情绪动作和一个次线索；规划主体尺度、水平线、眼线、主次锚点及负空间用途。按需查 `composition.md` 的几何定义和裁切边界。用户明确人数优先，不为强调风格自动增添群众。
4. 读取 `optics.md` 的光学约束，从本导演镜头阶梯中选一个焦段和合理的机位距离，写清对焦对象及景深。特写与远景不能在一个镜头同时声称不同焦段。运动、摇镜、推轨和拉焦在静帧里只能写当前取景或单个对焦端点；仅有动作依据时使用局部运动痕迹。
5. 选一个色彩配方，根据季节、时间、地点调整。比例仅为近似构图预算，若使用数字须整理成不重叠、合计100%的区域，不直接相加原配方的区间上下限。色彩来自布景、衣料、物件与合理光源。黑白请求改用明度分区、纹理和局部对比，不同时要求彩色点缀。
6. 按需读 `materials.md`，指定建筑、表面、衣料、一个关键物件、环境介质和合理磨损。没有剧情原因时不必加入英雄道具、雾气、潮湿或破旧。
7. 读取 `frame-controls.md` 的构图、变化、色彩验收与镜头卡规则；90或100强度读取 `amplification.md`。编写五段紧凑提示词：①比例、原创地点、一个可见瞬间；②人物位置、主次线索、空间与材质；③机位、一个等效焦段、焦点和景深；④实际光源、色彩或明度、捕捉质感；⑤微表情与必须避免的内容。导演姓名只留在镜头卡，最终生图提示词全部转换成可见特征。无装饰黑边、标题、水印或宣传海报布局。保留用户授权的素材编辑意图，不自行导入已知角色、演员或电影布景。

## 生成与交付

使用当前可用的图像生成工具执行，遵守工具支持的尺寸和参考图传入方式。工具不可用时交付提示词并明确未生成；不能把已有参考图当作新生成结果。保存用户交付文件到当前工作区的输出目录。

生成后观察人数、动作、构图、光源、肤色、材质、文字、解剖结构与风格线索。优先修正影响故事或主体的失败；必要时针对具体问题重生成一次。用户若仅要提示词，这些是待生成后的验收条件，不能称已通过。

实际读出像素宽高。默认2.35:1必须满足 `width * 20 == height * 47`；提示词或肉眼不能证明精确比例。局部工具只返回内联图、未给文件时，先从工具正规返回结果取得可保存文件；若无法获得，说明精确比例尚未验证。不可编造路径。

需要裁切时定位当前技能根目录，使用脚本绝对路径（需Pillow）。此安装路径的示例：
`python "/Users/moke/.codex/skills/cinematic-pedro-almodovar/scripts/crop_to_scope.py" INPUT OUTPUT --anchor-x 0.5 --anchor-y 0.5`
若技能被移动或在别的机器安装，以实际技能根目录替换路径，不能依赖聊天工作目录。
锚点0偏向左/上，1偏向右/下；它是可移动裁切范围的比例，不是把主体精确映射到画面坐标。裁切会略损失像素，不拉伸、不加黑边；保护脸、手、线索与主体关系，裁后再检查一次。用户选其他比例时不使用47:20裁切脚本。

输出新画面、简洁镜头卡、实际使用的五段提示词与一句剧情解读。镜头卡写明导演、强度、场景适配、构图锚点、单一等效焦段及景深、光源、色彩/明度、材料、实际像素和比例验证状态；避免声称静帧能证明相机运动或镜头时长。

仅在比较或诊断时查看 `../assets/reference-frame.png`：它是原项目生成的视觉示例，不是真实电影剧照或器材证据；未经用户要求不作为生图输入，也不复制其人物与构图。

## 统一光学建议

以专属资料中的镜头阶梯选择典型焦段；视觉语言正文中的其他焦段及其范围是兼容扩展。全部是创作建议，不是固定器材记录。表内列出的空间广角、人文常规与压缩细节只是叙事用途，不等同于摄影器材的行业分类。
