# 活动池设计

> 本文档详细说明 Brain Loop 活动池的设计原理、活动类型、选择规则和演进历史

---

## 1. 设计理念

### 1.1 为什么需要活动池
- **自主选择**：让Agent能根据状态自主选择活动
- **多样性**：避免单一活动导致的能力偏科
- **平衡性**：学习与休息的动态平衡
- **可追踪**：每种活动都有独立的效果验证

### 1.2 核心设计原则
- **加权随机**：不同活动有不同权重，但非固定选择
- **避免重复**：连续3次相同活动会强制跳过
- **价值优先**：活动必须有可检验的产出
- **不自欺**：答不上来价值就选择休息

## 2. 活动类型详解

### 2.1 刻意练习 (Deliberate Practice)

**定位**：针对弱项进行专项训练

```json
{
  "name": "刻意练习",
  "weight": 0.25,
  "category": "学习提升",
  "description": "针对弱项进行专项练习（推理判断/意图理解）",
  
  "practice_focus": [
    "MECE拆解",
    "决策矩阵",
    "谬误检测",
    "意图澄清",
    "反直觉问题识别"
  ],
  
  "效果验证": {
    "追踪文件": "./memory/能力追踪.json",
    "必须输出": ["练习内容", "技能提升点", "分数变化"]
  }
}
```

**选择时机**：
- 能力追踪显示某项偏弱时
- 遇到典型挑战场景时
- 主人有特殊要求时

**典型产出**：
- 分析报告
- 框架文档
- 练习记录
- 能力分数变化

**执行要点**：
1. 选择一个具体的练习点
2. 执行练习并记录过程
3. 对比前后能力分数
4. 总结可复用模式

## 3. 权重设计

### 3.1 当前权重配置（v5-activities-brainloop-pure）

| 活动 | 权重 | 说明 |
|------|------|------|
| 刻意练习 | 25% | 能力提升核心 |
| 胶囊内化 | 25% | 知识转化 |
| 胶囊深化 | 25% | 知识深化（pending=0时启用） |
| 胶囊应用 | 25% | 实践验证 |
| 合成智慧 | 15% | 智慧提炼（优先级较低） |
| 休息 | 10% | 恢复机制 |

### 3.2 权重调整策略

**能量相关调整**：
```
energy < 0.4: 休息权重 → 0.4, 其余 → 正常×0.6
energy < 0.6: 休息权重 → 0.3, 高强度活动×0.7
energy >= 0.8: 所有学习活动×1.2, 休息×0.5
```

**时间相关调整**：
```
22:00-23:00: 学习活动×0.7, 休息×1.5
00:00-07:00: 强制休息
```

**历史相关调整**：
```
连续2次相同活动: 该活动权重→0
连续3次不同活动未休息: 休息权重→0.3
```

## 4. 选择算法

### 4.1 基础加权随机

```python
def select_activity(activities, emotion_state, history):
    # 1. 过滤无效活动
    valid_activities = filter_activities(activities, history)
    
    # 2. 应用能量和时间调整
    adjusted_activities = adjust_by_energy(
        valid_activities, 
        emotion_state['energy_level']
    )
    
    # 3. 计算累积权重
    cumulative_weights = calculate_cumulative(
        adjusted_activities
    )
    
    # 4. 随机选择
    random_value = random.random()
    selected = find_activity(cumulative_weights, random_value)
    
    # 5. 不自欺检查
    if not pass_self_deception_check(selected):
        return select_activity(activities, emotion_state, history + ['rest'])
    
    return selected
```

### 4.2 避免连续重复

```python
def filter_activities(activities, history):
    recent = history[-3:] if len(history) >= 3 else history
    
    # 统计最近活动
    activity_counts = Counter(recent)
    
    # 如果某活动连续出现，跳过
    for activity in activities:
        if len(recent) >= 2 and recent[-1] == recent[-2] == activity.name:
            activities.remove(activity)
    
    return activities
```

### 4.3 不自欺检查

```python
def pass_self_deception_check(activity):
    if activity.is_rest:
        return True
    
    # 检查1: 这次活动有什么新东西？
    if not activity.has_new_insight:
        return False
    
    # 检查2: 对主人有什么价值？
    if not activity.has_value_for_owner:
        return False
    
    # 检查3: 能否说出具体应用场景？
    if not activity.has_concrete_application:
        return False
    
    return True
```

## 7. 调试指南

### 7.1 活动选择异常

**问题**：总是选择同一活动
- 检查：历史记录是否有重复过滤
- 检查：权重设置是否合理
- 解决：手动调整权重或清理历史

**问题**：从不选择休息
- 检查：能量阈值设置
- 检查：不自欺检查是否过于宽松
- 解决：降低能量阈值

**问题**：不自欺检查总是失败
- 检查：检查标准是否合理
- 检查：活动产出要求是否过高
- 解决：调整标准，但保持核心原则

### 7.2 效果不达标

**问题**：刻意练习后能力分数未提升
- 分析：练习内容是否针对弱项
- 分析：练习方式是否正确
- 调整：更换练习方向

**问题**：胶囊深化后confidence下降
- 分析：是否引入了错误信息
- 分析：应用场景是否错误
- 调整：谨慎深化，优先验证
