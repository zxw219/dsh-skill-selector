# 任务分层执行策略

## 层级定义

### L1 - 简单问答（<5秒）
**特征**：
- 单轮对话可完成
- 无需工具调用
- 无需多步骤推理
- 纯知识型问答

**执行策略**：
- 立即响应
- 无需进度推送
- 直接给出答案

---

### L2 - 中等任务（5-30秒）
**特征**：
- 需要1-3个工具调用
- 或需要简单多步骤推理
- 有明确起止点

**执行策略**：
- 开始时推送「开始处理」
- 完成后推送结果
- 中间无需进度更新

---

### L3 - 复杂任务（30秒-5分钟）
**特征**：
- 需要4-10个工具调用
- 或需要复杂多步骤推理
- 涉及多个子系统协调
- 中间可能有多种结果

**执行策略**：
- 开始时推送「开始处理 + 预计时间」
- 每30秒推送一次进度
- 可包含中间发现
- 完成后推送完整结果

**进度推送模板**：
```
🔄 任务进行中...
- 已完成：{done}
- 正在做：{doing}
- 预计还需：{remaining}
```

---

### L4 - 长期任务（>5分钟）
**特征**：
- 需要10+个工具调用
- 或预计耗时超过5分钟
- 涉及异步处理
- 可能是定时任务

**执行策略**：
- 立即返回「已加入后台队列」
- 提供任务ID供查询
- 完成后主动通知
- 可中途查询进度

**后台任务标识**：
```
⏳ 任务已加入后台队列
- 任务ID：{task_id}
- 状态：处理中
- 完成后将通知您
```

---

## 执行模式选择

| 层级 | 响应模式 | 通知时机 |
|------|----------|----------|
| L1 | 立即响应 | 无 |
| L2 | 开始→完成 | 2次 |
| L3 | 开始→进度→完成 | 多次 |
| L4 | 排队→异步→通知 | 完成后1次 |
