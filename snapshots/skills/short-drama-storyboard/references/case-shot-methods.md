# 从镜头案例提炼的导演方法

本文件用于内部设计复杂镜头，不改变最终输出模板。最终必须使用 `[分镜N]`、`【分镜规格】`、`光学/构图/角度/调度`、`【画面要求】`、`【音效】`、`【BGM】`、`【其它】` 的固定格式。

适用于仪式亮相、强烈悲恸、门内外反差、临近危险和复杂动作转场。学习案例的因果、调度、构图和声音接力，不照抄人物、时长、品牌、暗调或一长串负向词。

## 1. 运镜先有动作触发，再有物理路径

把关键镜头设计成四段关系：

**起幅锚点：** 观众先看见哪一只手、哪个道具、谁的脸或哪个空间入口。  
**触发动作：** 抽牌、落牌、开门、转头、起身或前倾出画。  
**相机响应：** 后退跟步、弧线推升、绕开门框、随动作下沉、追随视线反打等。  
**落幅状态：** 画面最后停在哪个表情/证据/人物关系，主体怎样留给下一镜。

一条复合轨迹服务一个核心事件。“抽牌→落桌→升到脸”可以是一条仪式揭示；“开门→室内全景→蛋糕→父母大笑”应拆为多个信息落点。

需要强调动力学时给相机的惯性和刹停：人物前倾时跟上，出画后短促回稳；相机靠近证据时减速；危机急推开镜即运动，在最后结果前截断。没有动机的5厘米推进不必硬加。

**数字要有参照且能完成。**

- 偏左/右几度要说明相对人物正面、桌边或轴线；俯仰角与相机高度是不同信息。
- 直线移轨速度用m/s，摇摄角速度用度/秒，加速度用m/s²。不能把0.12m/s写成单纯云台横摇速度，也不能称2.8m/s为“加速度”。
- 路径、时间和速度要相容。写不准就用明确的加速/减速段，不用假精确数字。
- 固定相机可以移焦；跟随主体锁焦时相机可以移动。Rack Focus不是Zoom，也不自动改变景深厚度。
- 极低机位不能只靠轻微上摇就从脚拍到高处脸部；根据距离补足升镜、后退或合理俯仰幅度。主观机位必须对应观察者/车辆上的明确位置。

## 2. 五种可以迁移的镜头链

### A. 仪式人物入场与权威建立

选择有效环节：脚步或衣摆带出方向 → 后退跟步并上摇见脸 → 观察者的紧张反应 → 随落座下沉 → 手部启动动作 → 关键道具/异象 → 正面宣判。

先让人物进入空间，再让空间回应人物。门板、烛台和桌边可作前景，但不能把所有物件都拍一遍。若剧本没有法阵或超自然效果，止于实际仪式动作，不移植新增事件。

出场的气势来自从容与他人紧张的对照。主角脸部要有清晰落点；不能只拍腿、背影、戒指和牌而一直不见脸。

### B. 手部操作引出脸部与预言

起幅锁定桌面手部。手腕抽牌时沿桌缘短弧跟随；落牌声响起，摄影机升高并微仰，在人物脸部减速收住。下一镜独立展示两张牌的名称和并列关系；随后才切人物念出对应预言。

同一次抽牌和翻面不可在相邻镜头重复执行。内部先锁定牌的身份、左右位置、正反面与哪只手持有；反向机位导致画面左右变化时说明观察方向，不能让道具自己交换。

两张牌都需要可读时让牌面处于同一清晰平面。之后的牌角火焰→人物眼神拉焦，把注意力从证据交给说话者；要吹灭火苗，应给完整台词后的动作时间，或另分一镜。

### C. 悲恸的“运动—触觉—脸—对照”

正面看到崩溃 → 捂嘴向一侧出画 → 下一镜按同一运动方向入画并抵达孩子 → 指尖轻抚的触觉特写 → 母亲哭诉的脸 → 邻近另一孩子的反应。

情绪先由大幅动作释放，再收进战栗手指和哭诉的眼神。可在两辆已经建立相邻位置的婴儿车之间拉焦，强化健康/病弱对照；不能把关系镜省掉，让孩子凭空出现在母亲身后。

人物跪在车旁地面，或伏在车沿，要明确支撑位置，不写含混动作。婴儿姿态依资产年龄和发育状态成立；没有依据时，不让襁褓婴儿突然扶栏站起。

### D. 门槛与群体反差

门外人物与病历建立 → 右手操作门把、左手持报告 → 开门带出冷暖分区 → 穿过或绕过门框揭示室内关系 → 蛋糕细节 → 父母/伴侣等有信息的反应。

报告单、门把、脸是不同焦点；选择当前关键对象，避免一镜极浅景深却要求三个平面同时锐利。穿门镜先保住空间可读性，再强调速度；2秒内既微距看清长文、又甩镜穿门、又逐个看清七人通常太挤，需删掉无作用的步骤或合理拆镜，而非压缩必要信息。

群体采用前后错层或半弧布置。人数限制必须区分室内人物与门外前景人物；不能误删剧情主角。

### E. 危险的“刺激—视线—威胁—主观逼近”

过街方向先成立 → 画外灯光/喇叭到达 → 人物停步、转头 → 视线反打揭示来车 → 来车方向的低位主观急推 → 人物本能保护 → 按剧本给出冲击、遮白或剪辑落点。

先锁女主过街方向、来车车道和灯光来源，再设计反打。人物坐标中的“左侧”切到另一个摄影机后，不一定仍是画面左侧；用斑马线、道路纵深和视线把方向连接起来。

主观急推需要写起始距离、终止构图与截止时刻；近距离广角可以制造危险夸张，但不能意外改变演员身份。手里有琴和琴弓时，护头动作必须交代如何持握与抬臂，不让道具消失或变成空手。

强光吞白或撞击前切黑只是一种叙事截断；原剧本需要交代碰撞结果时，仍应在后续镜头呈现，不能借特效省略结果。

## 3. 复杂动作的镜头信息拆分

复杂动作按以下层次判断是否需要拆镜：

1. **动作关系建立：** 让观众看懂两个人的位置、方向、距离和动作发起者。
2. **动作触发：** 用手部、脚步、眼神或身体重心表现动作起点。
3. **动作过程：** 跟拍、侧拍或局部特写呈现关键接触、移动或物体变化。
4. **即时反应：** 切到动作承受者的脸、身体或手部反应。
5. **动作结果：** 明确道具最终位置、人物最终姿态和空间关系。

不是每个动作都需要五个镜头；按信息密度选择。关键动作不允许只用一个中景概括，普通动作也不必拆成无意义的逐帧碎切。

## 4. 案例的时间表必须重新核算

学习表演和镜头关系，不自动采用案例给出的局部配音窗口。按自然英语估算：

- “The twins are fated for opposite paths.”为7词，约2.5–3.2秒；若要求缓慢催眠式宣判，需更多时间。
- “One will be blessed by the sun, while the other will be claimed by death.”为15词，约5.3–6.9秒。2.5秒读完约360词/分钟，与“空灵慢速”矛盾；引火、说完、吹灭还可能需要额外时间。
- “My Evan... my poor baby. Why does it have to be him?”为12词，正常约4.2–5.5秒，哽咽哭诉通常更长。不能同时标注气短哭腔、长停顿和3.4秒完成。

可把整句连续铺在证据特写与脸部反应之间，或让动作和说话合理重叠；不能截短原台词。每组总时长按当前用户要求执行，当前默认不超过30秒；不沿用旧案例或旧PDF的15秒硬限制。

## 5. 把强限制缩到正确作用范围

先写正向可见状态；只对关键失误加局部排除。负向限制不是默认必填长清单。

| 要保护的内容 | 合理限制 | 避免的冲突 |
|---|---|---|
| 口型 | 现场说话者对应口型；OS人物不跟旁白念词；其他人可自然呼吸 | “全员闭唇”同时要求某人哭喊/说话 |
| 皮肤与眼睛 | 沿用角色资产，排除无依据的异色、红斑和发光眼 | 全局禁止哭后合理潮红，或把全部角色改成同一眼色 |
| 可读文字 | 只显示指定的牌名、文件标题或消息，不额外加字幕水印 | 全局禁止text却要求“THE SUN”“DEATH”可读 |
| 景深和运动 | 指定主体清晰，允许有设计的背景虚化或运动拖影 | 全局禁止blur却要求极浅景深或慢门 |
| 人数与道具 | 绑定具体分镜、房间范围、左右手与状态 | 引用不存在的镜号，误删门外主角，或让同一只手承担互斥动作 |
| 光线与特效 | 指定时点局部炫光、切黑、剧情法阵，保留其余镜头层次 | 小火苗熄灭就让日光消失；既要法阵又无条件禁所有特效 |

只有用户指定平台确认支持加权括号时才使用相应语法。审美和戏剧张力主要来自正向镜头设计，不能用更多“死锁”弥补矛盾。
