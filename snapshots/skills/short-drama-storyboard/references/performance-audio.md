# 表演与连续声音

本文件规定如何把人物情绪写成可见、可听、可生成的表演，并与新的逐镜模板配合。最终台词放在每镜 `【画面要求】` 中；音效、BGM和其它限制分别使用独立字段。

## 一、把情绪写成会发生的表演

每个角色先明确此刻想得到什么、在防备谁、受到什么刺激。镜头里只写实际可见、可听的落点，按“初始状态 → 刺激 → 可见变化 → 动作落点”组织。

例：

- **畏惧但高度警觉：** 坐在椅面前缘，脊背僵直，双膝收紧；抬眼偷看主位的人，一对上视线便缩下巴，指尖压住颤抖的手背。
- **傲慢与不屑：** 深靠主位椅背，二郎腿占据松弛空间，悬空鞋尖轻晃；眼皮半垂，先从对方手里的材料扫到脸，再掀起一侧嘴角。
- **受辱后强忍崩溃：** 原先讨好的笑停在脸上，嘴唇颤着想辩解却没有说出口；低头时泪水才落下，肩背随压抑的呼吸抽动。
- **从委屈到反击：** 收回求助的手，呼吸由急转稳，抬眼直视对方；道具动作必须有资产依据。
- **沉浸幸福被打断：** 先用单人近景表现看手机时眼尾放松、忍不住抿笑；再切主管起身和接近。按照剧本完成持杯起身、走到身后、拍椅背、惊缩的因果，不用一个双人镜头同时抢演。
- **现实与线上反差：** 现实中占据空间、目光审视、语尾刻薄；看见恋人消息后，眼神先软下来，身体不自觉前倾，嘴角忍笑，回复时出现期待。仍是同一张脸、同一基础声线。

“更夸张”优先放大姿态差异、表情转折和反应可读性。不能把愤怒自动升级为摔杯、拽衣领、扇耳光或新冲突。剧本写了明确肢体行为就完整表现，不能因简化提示词省略。

主角优先，次要人物只给必要反应。不能让一屋子群演同时挤眉弄眼；一两处相互交换眼神或避开目光足以传达群体态度。

## 二、微表情和身体动作的细化

重要表演不能只写“她看向他”“他很生气”“她很暧昧”。选择镜头能够看见的身体细节：

- 眼睛：视线先落在哪里，再移动到哪里；眼睑收紧或放松；眨眼频率；眼神停留和躲闪。
- 眉眼：眉心轻收、眉峰抬起、眼尾绷紧、睫毛短暂颤动；只选择符合当前情绪的变化。
- 嘴部：唇角上提或压平、嘴唇抿紧、唇缝微张、吞咽、说话前短暂停顿。
- 下颌和颈部：下颌收紧、喉结滚动、颈部绷紧或舒展。
- 呼吸：短促吸气、屏息半拍、鼻息变重、缓慢呼出；要与动作节奏对应。
- 手部：指尖停顿、指节收紧、掌心松开、抓住衣料、手腕被按住、手指在道具边缘犹豫。
- 身体：肩膀抬起或松下、重心前移或后撤、身体靠近、背部贴住椅背、膝盖和脚尖方向。

镜头描述通常挑选最能表达当前变化的1–3项，不把所有身体部位堆在一个短镜头里。近景只写画面能看到的部位；脚步和面部反应需要分别切镜或合理扩大景别。

亲密戏要把动作关系拍清：谁主动靠近、谁回应、手落在哪里、身体距离怎样变化、对方如何反应。用眼神、指尖、呼吸、衣料、肩颈、腰侧和身体重心建立暧昧；动作必须服从剧本、人物关系和用户指定的尺度。不要用一个中景笼统概括所有细节，也不要为增加特写擅自增加剧本没有的行为。

## 三、台词的固定写法（放在【画面要求】内）

新模板中不再单独使用“音频配置（无BGM）”字段。台词写在【画面要求】中，紧跟对应人物的表演描述：

~~~text
【画面要求】：

Elena 抬眼看着 Damian，眉心轻轻收拢，原本柔和的神情变得清醒。她没有松开他的手腕，目光坚定，轻声说出一个词。

Elena【声音柔软但态度明确，短句干脆】：
“Don't.”
~~~

台词是声音，不是画面字幕。不得写成“画面出现 Elena 的台词文字”，也不得把对白提示误写成画面内文字。

角色台词标签按实际场景标注：

- 现场说话：`Elena【语气、音色、情绪】：`
- 现场画外对白：`Damian（画外）【语气、音色、情绪】：`
- 内心独白：`Elena（OS）【声线、情绪】：`
- 叙述旁白：`Elena（VO）【声线、情绪】：`
- 电话、语音消息、视频播放等设备声音，注明设备来源和声音质感。

角色年龄和口音在已知且有助于声音执行时写入；不虚构剧本没有给出的精确年龄。已有声音资产优先沿用，不因情绪变化而改变基本音色。

## 四、台词以完整语流设计

**切画面，不切语气。** 先把完整原句或一轮说话读顺，再分配到说话者、听者反应、证据特写和环境落点。画面切换不是重新吸气、重新起调的理由。

1. 内部保留整句原文及其镜头覆盖范围。
2. 每镜只放该镜实际播放的连续原文片段；按镜头顺序拼接，必须还原原句，不补逗号、句号或省略号。
3. 后镜明确同一语流继续，保持音色、语速和情绪，不重新起调；但不要只写“承接上一组”，必须在当前组中写出模型需要知道的声音与画面状态。
4. 优先在完整句、问答结束或情绪转折处分组。不得为了凑时长在一个词中间或半句里强制断开。
5. 实际制作配音时，优先整句或整轮录制，再让同一音轨跨镜；只交提示词时，写清连续播放与情绪弧线，不声称已经合成音频。

原稿多个短句可以组成一段连贯表达。句点保留，语气向前走；只留语言需要的换气，不让每句都变成“说一句—长停—再说一句”。不能为快节奏吃字或抹掉必要的犹豫、哽咽与重点停顿。

例：原文为：

> This afternoon, he threw my proposal in my face in front of everyone. Humiliated me. I can't stand him.

可让前镜说到“my face”，后镜从“in front of everyone.”无缝承接。后两句由受伤转为厌恶，语气接着前一句向前推进；不能在每个镜头重播“This afternoon”或另添“……”。

## 五、声音的稳定与情绪变化

同一角色保持同一年龄感、口音、基本音高和音色，不随情绪突然变成另一个人。声音资产优先；没给年龄就写合理年龄段，不虚构精确年龄。

“清脆”落实为字头利落、辅音干净、元音通透、字尾可辨，声音贴近且有存在感；中高频有清晰度但不尖、不齿音刺耳，保留真实气息和胸腔支撑。不要把所有角色都改成高音，也不要用闷糊、气声淹字、持续低吼来冒充磁性。

- 年轻女声可清亮、有弹性、有自然鼻腔共鸣；害怕时语尾轻颤，反击时字头更实，亲昵时亮度上扬而非整段耳语。
- 男声可中低音、有胸腔共鸣、颗粒适量但咬字锐利；嚣张时干脆掷词，失控时声压和语速变化，温柔时放松硬起音。低沉不等于浑浊。
- 配角保持可辨识的声线差异，不抢主角声场。群体议论不能盖住关键原台词。

每条情绪说明通常抓住1–2个具体变化：**当前状态 + 本句意图 + 语速/声压/音高/气息中的有效变化 + 关键词重音与收尾**。不要只写“生气、温柔、悲伤”，也不堆五六种互相矛盾的情绪。

| 情境 | 可执行的声音变化 |
|---|---|
| 当众羞辱 | 句头硬、重词砸实，轻蔑尾音压低；需要怒骂时声压明显升高，仍听清每个词。 |
| 惊恐哀求 | 起音偏紧，呼吸短，关键词更急；整句往对方推，末尾失去一点支撑。 |
| 强忍委屈 | 前半句努力说稳，关键处气息卡住，后一小段带鼻音和颤音收回。 |
| 恋爱调侃 | 字头变轻亮，语速自然黏连，问句尾音带期待；笑意在声音里，不额外添加笑声台词。 |
| 傲慢转慌乱 | 前句底气足、语尾斩断；看见证据后抢起下一句，音高上移，呼吸变浅。 |
| 英雄反击 | 吸气后稳稳起音，重音有分量，句尾收准；不是靠全句喊到最大声制造气势。 |
| 哭着道歉 | 起句急于抓住对方，长句中短换气、渐哽；请求部分减轻声压但提高迫切感。 |

## 六、音效、BGM和其它字段

每镜必须明确填写：

~~~text
【音效】 开启：脚步声、衣料摩擦声、近距离呼吸声。
【BGM】 关闭。
【其它】 无字幕、无任何文字。
~~~

- `【音效】`只写画面和环境能产生的声音：脚步、衣料、呼吸、纸张、门、杯子、抽屉、床垫、雨声、车辆、环境底噪等。无音效时写关闭，不机械增加拟音。
- `【BGM】`默认关闭。只有用户明确要求时才开启，并写清音乐风格、进入点、退出点和音量关系。
- `【其它】`写字幕、水印、画面文字、人物数量、道具、口型、局部效果等必要限制。限制必须与当前镜头内容一致。
- 无对白镜头只写音效，不添加空白台词条目或额外呼喊。
- OS人物不对口型，但可以自然呼吸、哭笑或完成剧情动作；“不对口型”不等于全员闭唇不动。
- 原文没有人声时不编台词；非语言的真实呼吸、哭泣或笑声只有在剧情和表演成立时才写。

## 七、声音先行、延续与画外反应

- **J-cut**：下一场声音先到，带出新空间或即将来的人；必须有明确来源。
- **L-cut**：当前说话声继续覆盖听者反应或证据特写；画面切换不让语气重启。
- 当前镜头拍听者时，对方现场对白可标注“画外”继续；不要让听者对口型。
- 手机语音、电话、录音和视频播放要写清声音来自哪个设备，必要时说明轻微扬声器压缩质感。
- 声音和动作要互相支撑：脚步先到引发转头，落牌声触发升镜，抽屉声对应手部动作，抽泣可覆盖抚摸特写。
- 冲击声可以短暂抬升后收紧或骤断，但保持人声可懂、层次可辨；不把“刺破耳膜、推至失真”当混音标准。
