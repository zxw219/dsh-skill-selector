# 输出模板与字段约束

本文件定义唯一的最终提示词格式。最终输出以逐镜条目为主，不用大表格、JSON或旧版镜头格式代替。用户没有要求解释时，只输出可直接复制使用的分镜提示词。

## 一、分镜组外层结构

每个独立分镜组使用以下顺序：

1. 分镜组标题及本组总时长。
2. 人物资产。
3. 场景资产。
4. 必要道具资产。
5. 完整影调光影全局设定。
6. 本组第一帧空间与轴线。
7. 按 `[分镜1]`、`[分镜2]`……编号的具体镜头。

## 二、人物、场景和道具前缀

- 每组只列本组实际出场的人物、场景和关键道具，不列全剧资产清单。
- 优先沿用用户给出的名称和资产绑定，例如 `Elena：@C01 Elena；`、`初次酒店卧室：@S03 初次酒店卧室；`。不改写成无法对应的别名，不编造资产 ID。
- 用户提供服装参考图后，已确定且未变化的服装细节不重复描述；资产引用本身足以锁定。若人物在本组已脱外套、换装、衣物敞开、湿透、破损或出现剧情伤妆，则在本组的空间与轴线或对应画面要求中写清变化后的状态。
- 脱下的外套、鞋、饰品、道具必须写清落点、持有人和后续状态，防止 AI 生成时复位或消失。
- 关键道具可在“道具”栏列出；没有额外道具时省略整栏。

## 三、影调光影与全局设定

每组必须写一段独立、完整的：`影调光影：【全局设定】……`。

- 长度参照用户给出的酒店卧室示例，通常约220–300个汉字，写成一个完整段落；允许根据场景复杂度适度浮动。
- 必须把题材与实拍/媒介质感、整体美学与情绪、主色和辅助色、主光来源与方向、环境补光/轮廓光、反差与暗部层次、肤色/皮肤细节、关键材质表现组织成自然语言。
- 影调随当前剧本、场景、时间和情绪变化。不得把酒店暧昧风格套到医院、办公室、豪宅对峙或动作场面。
- 每组重新完整写，不得写“参考上一组”“延续上一组光影”“同前”“光影同上”。即使同一场景同一时间，也重新写清光源方向和色彩关系。
- 设备与品牌名称是视觉参考，不代表实际拍摄设备；ARRI Alexa 65、胶片质感、8K等不作为每组必填关键词。

## 四、空间与轴线

`空间与轴线：`只写本组第一帧已经成立的状态，不预演后续动作。

必须明确：

- 场景布局和方向：门、窗、床、桌、吧台、通道、楼梯等实际位置。
- 人物初始站位：画面左/中/右、前景/中景/后景、门内/门外、桌前/桌后等。
- 人物初始姿态、身体朝向、视线方向和情绪状态。
- 服装变化状态、手中物、关键道具的初始位置和开合状态。
- 摄影机主轴和反打关系；反打时应有真实合理的背景。

空间与轴线中不写后续走近、转身、入画、出画、摔倒、伸手、开门等动作，这些放入具体分镜的【画面要求】。

每组独立生成，必须重新写完整首帧状态。禁止“接上一组”“沿用上一组站位”“状态同前”等上下文引用。可以写出人物此刻真实的连续状态，例如“Damian 已脱掉白西装外套，只穿黑衬衫，外套放在床边”，不能让模型猜测。

## 五、单镜头固定格式

每个镜头必须使用完全一致的字段名称和顺序：

~~~text
[分镜1]

【分镜规格】：

光学：85mm / 光圈 f/2.0

构图：面部近景 / 三分法构图

角度：视平线 + 人物3/4侧面

调度：Slow Push-in，镜头从人物正前方略偏左的位置缓慢推进，最终停在近侧眼睛的特写。

【画面要求】：

描述当前镜头实际可见的背景、主体、动作起因、动作过程、动作落点和人物反应。重要情绪写具体眼神、嘴角、呼吸、手指、下颌或重心变化。复杂动作拆成多个分镜，不用一个中景概括。

角色名【语气、音色、情绪、语速、停顿和重音】：
“逐字保留的原文台词。”

【音效】 开启：与当前画面对应的环境声和动作声。

【BGM】 关闭。

【其它】 无字幕、无任何文字。
~~~

### 字段定义

- **光学：** 必须明确焦段和光圈，如 `35mm / 光圈 f/4.0`、`85mm / 光圈 f/2.0`、`100mm / 光圈 f/2.8`。参数服务当前景别和焦点，不机械堆叠。
- **构图：** 写清景别和构图方式，如“中景 / 前景遮挡构图”“面部近景 / 负空间构图”“手腕极近特写 / 中心构图”。
- **角度：** 写清摄影机高度、俯仰角度、相对人物方向及观察视角，如“视平线 + Elena 3/4侧面”“床头侧上方俯拍”“低机位仰拍”。
- **调度：** 只写摄影机运动。写清固定/移动、起点、轨迹、方向、速度变化、移焦和落幅。人物自身的走位和动作写在【画面要求】。
- **画面要求：** 直接描述模型要生成的可见画面，不写抽象导演分析。动作要有起点、过程和落点；微表情和肢体细节要与景别相容。台词写在本栏，不作为画面文字。
- **音效：** 只写本镜真实存在的环境声、动作声、脚步、衣料、呼吸、物体碰撞等。没有音效时写“关闭”。
- **BGM：** 明确写“关闭”或按用户要求写“开启：具体音乐风格及进入/退出点”。默认关闭。
- **其它：** 明确字幕、文字、水印、额外人物、道具和特效限制。需要可读文字时写出准确原文，不可同时禁止文字和要求文字可读。

## 六、人物台词写法

台词属于声音，不等于字幕。人物台词放在【画面要求】里，直接跟在该人物的表演描述之后：

~~~text
Elena【声音柔软但态度明确，短句干脆】：
“Don't.”
~~~

- 现场说话者正常对口型；画外对白注明“画外”；内心独白标注“OS”；叙述旁白标注“VO”。OS/VO人物不跟随旁白念口型。
- 情绪提示写可执行的声音表现，不只写“生气”“温柔”“悲伤”。根据人物稳定音色，说明音高、音量、语速、气息、停顿、重音和收尾。
- 不擅自添加括号内动作变成新台词，不把音效或语气提示塞进引号。
- 一句台词跨镜时，每镜只写该镜实际播放的连续原文片段；跨镜语气连续，不重播前文、不漏词、不擅自增加省略号或句号。

## 七、镜头时长与分组

- 本组总时长写在标题中，例如 `｜28秒`；默认不在每个分镜编号后加时长。
- 每组不超过30秒。普通镜头以1.5–4秒为主，完整对白、长镜头和复杂动作可按真实需要延长。
- 分镜数量由动作、对白、反应和信息密度决定，不固定为1–4镜，也不为了增加镜头数无意义碎切。
- 组内时长在内部核算，确保动作和台词能完成；若用户明确要求逐镜时长，再按其要求在每个 `[分镜N]` 后标注。

## 八、明确禁止的旧格式

除非用户明确要求恢复旧版格式，否则不得使用：

- `【镜头编号】/【剧本文本】/【提示词】` 三栏包装。
- `镜头 1：时长 3s` 或 `镜头01｜3s`。
- `【摄影机位】`、`运镜：`、`画面表演：`、`音频配置（无BGM）：`。
- 把光学、构图、角度、调度合并成一个长括号参数串。
- 把人物台词单独放入“音频配置”而不写在【画面要求】中。
- 用大表格代替逐镜提示词。

## 九、交付检查

- 组标题有本组时长且不超过30秒。
- 每组有完整人物、场景、影调光影和空间与轴线。
- 每镜都严格包含【分镜规格】四项、【画面要求】、【音效】、【BGM】和【其它】。
- 没有“参考上一组”等依赖上下文的省略词。
- 台词逐字正确，情绪提示不替代台词；OS/VO口型正确。
- 动作、视线、道具、服装和空间连续；重要动作有细节镜头。
