# 摄影、人物亮相与场景切换

本文件提供镜头设计方法。最终输出字段必须服从 `references/output-template.md`，不得恢复旧版“摄影机位/运镜/画面表演”格式。

## 一、【分镜规格】四项分工

每个镜头固定写：

~~~text
【分镜规格】：

光学：85mm / 光圈 f/2.0

构图：人物近景 / 三分法构图

角度：正面略偏右平拍 + 人物3/4侧面

调度：Slow Push-in，摄影机从人物正前方略偏右的位置缓慢推进，最后停在近侧眼睛的特写。
~~~

四项不能混写：

1. **光学：** 焦段和光圈，如24mm / f/4.0、50mm / f/2.8、85mm / f/2.0、100mm / f/2.8。镜头类型可在需要时补充“长焦”“微距”。
2. **构图：** 景别和构图方式，如中景/前景遮挡、近景/负空间、手部极近特写/中心构图、双人关系/对角线构图。
3. **角度：** 摄影机的具体位置、高度、俯仰角度，以及相对人物的正面、侧面、3/4侧面、正反打或主观视角。
4. **调度：** 只写摄影机实际运动：起点、方向、路径、速度变化、触发动作、焦点变化和结束构图。人物自身的走位和动作写在【画面要求】。

固定机位可写“固定机位，构图不变，焦点锁定近侧眼睛”。不能为了显得专业而给固定镜头编造细小横移。升降是摄影机位置变化，上下摇是俯仰角变化，变焦是焦段变化，三者不能混称。

## 二、调度必须简洁、具体、有落点

一个镜头只保留一个主要运镜意图；允许围绕同一叙事目标的连续复合轨迹，如弧线环绕并下降。复杂动作可在调度中分两三个阶段，说明动作触发、加减速和落幅。

- **起幅锚点：** 先让观众看见哪只手、哪个道具、谁的脸或哪个空间入口。
- **触发动作：** 抽牌、落牌、开门、转头、起身、前倾或人物出画。
- **相机响应：** 后退跟步、弧线推升、绕开门框、随动作下沉、追随视线反打等。
- **落幅状态：** 最后停在哪个表情、证据或人物关系上。

例如：`调度：从杯沿的低机位仰拍起幅，沿杯壁反光缓慢上摇并小幅推进，酒液落在冰球表面时焦点停在冰球折射，最后收在杯后人物的模糊倒影。`

运镜不能只写“镜头从侧面拍”“镜头跟着人物”；这些没有明确相机路径。也不要在一镜硬塞推进、甩镜、变焦、绕圈、升降五个独立花招。

## 三、焦段与景深选择

| 拍摄任务 | 建议设计 |
|---|---|
| 场景建立、空间穿行、低机位强调纵深 | 24–35mm；中等至较深景深，入口、通道和人物位置清楚。超近距离广角会夸大脸部，不拿来无意变形角色。 |
| 双人关系、动作路径、跟随 | 35–50mm；中等景深，让主要动作从起点到落点可读。 |
| 单人表演、对话近景 | 50–85mm；浅景深或中等景深按手势范围选择。 |
| 情绪特写、眼神、细小反应 | 85mm；浅景深，锁近侧眼或指定细节。 |
| 手机、文件、伤痕、关键道具 | 85mm近摄或100mm微距；足够景深保证关键信息可读。 |

光圈必须服务当前画面，不机械地每镜写f/1.4。脸与伸向镜头的手处于不同平面时，适当加深景深或拆镜，不同时要求极浅景深和多层对象全清楚。焦点要明确锁定眼睛、手指、道具文字或需要转移的具体对象。

## 四、景别变化与避免舞台剧式拍摄

- 不要连续多个镜头都使用相同中景、相同方向和相同高度。
- 人物出场可从鞋尖、手部、服装细节、眼神特写逐步揭示，但不能机械套用四步流程；最终要给足脸部识别和人物性格落点。
- 关键动作要有局部特写：手指、杯沿、抽屉把手、领带、衣袖、门把、道具接触点等。动作复杂时先建立身体关系，再切动作细节，最后给反应或结果。
- 亲密对手戏要交替使用双人关系镜头、面部反应、手部/肩颈/腰部局部和对方反应；具体尺度服从剧本和用户要求。
- 对话场景要有正打、反打、听者反应和必要双人关系镜头。不要让人物始终朝同一方向像舞台剧表演。
- 用户给的场景图只有一面时，仍可设计合理反打。依据门窗、家具、通道和场景风格补出反向可见空间，不把原图同一面墙复制到所有机位，也不随意新增改变房间结构的门窗。
- 玻璃隔板、镜面、酒杯、车窗和金属表面可形成前景遮挡或倒影层次，但反射必须来自真实空间位置，不能遮住关键表演信息。

## 五、开场与人物亮相

开场应快速建立有吸引力的视觉信息、场景气质和人物中心。可以采用：

- 商业广告式物件开场：低机位仰拍杯体、液体、冰球、玻璃反射、慢动作液体飞溅或抽帧拖影；随后通过手部动作和倒影揭示人物。
- 环境穿行：FPV Fly-through从入口沿实际通道穿过，在主角前减速并落到面部；路径绕开家具和人物，不穿过墙体或人体。
- 细节揭示人物：脚步、手部、服装细节、侧脸、正面眼神，按剧情挑选必要环节。
- 角色关系亮相：先给主角独立特写，再给其视线所见和空间关系；对手/男主可以先给局部或背影，再逐步揭脸，制造期待。

开场的每个镜头都必须提供新信息，不为炫技停留在无关物件。用户指定的开场动作和场景必须优先，不能用模板替换。

## 六、常用运镜方法

这些是有叙事用途的方案，不是每场必须集齐的清单。

### FPV Fly-through：空间穿行

从入口沿真实通道前进，掠过近景遮挡，在人物或关键动作前减速并落幅。适合空间交代和主角发现，不用于无意义绕场。

### Bay-style Hero Arc + Pedestal Up：英雄亮相

从人物侧前方较低位置起，以24–35mm沿人物周围短弧环绕，同时升高到胸口或脸部高度，停在正面偏轴的英雄中近景。需明确环绕方向、轴心和收镜位置；脸部更重要时另切85mm特写。

### Arc Dolly + Pedestal Down：压迫式揭示

摄影机沿人物侧后方弧线转向正面，同时下降到低机位，收在人物正面中景或中近景。路径不得无意越过对话轴线；如需越轴，先建立清楚的双人关系。

### Tracking / Side Tracking：动作跟随

先明确人物运动方向，再同向或侧向跟随。镜头保留动作起点、路径和落点；手持晃动要有演员运动来源，不能无意义乱晃。

### Slow Push-in / Short Push-in：情绪推进

Slow Push-in适合隐忍、压迫和逐渐意识到真相；Short Push-in适合突然反应或一句关键台词。写清推进终点和焦点，不每镜象征性推几厘米。

### Rack Focus：注意力转移

写清起焦对象与终点，例如从前景杯沿倒影拉到人物眼睛。Rack Focus是移焦，不是Zoom，也不自动改变景深厚度。

### Whip Pan / Occlusion Wipe：快速转场

甩镜应由人物急转视线或运动触发，甩后立即落稳。前景遮挡转场沿柱子、门框或人物背后横移，遮满画面时接下一镜同方向揭示。

### Bullet-time / Slow-motion Arc：关键瞬间

只用于动作临界、身份揭露或胜负瞬间。写清人物动作的慢放范围、摄影机短弧路径和恢复实时速度的落点；普通对白不能整体慢放变调。

## 七、场景切换与转场

转场写在具体镜头的“调度”中，不额外增加一段泛泛的转场说明。可用：

- Crane Down / Jib Down：从建筑、天际线或高处下降到入口与人物。
- Tilt Up + Restrained Zoom：从桌面或辨识度高的陈设上摇到人物，轻度变焦收紧表情；变焦和升降分清。
- Lateral Tracking + Occlusion Wipe：沿前景横移，遮满画面后接同方向揭示。
- Motivated Whip Pan：由人物急转视线或快速动作触发，甩镜后迅速落稳。
- Match Cut / Match on Action：同方向的开门、放杯、伸手或相似构图衔接；不同物件不能制造错误的物理连续。
- 闪回：用眼神/道具匹配、声音桥或明确光色差提示时态；回到现实落在原人物反应或原道具。

用户要求闪回大场景切换时，可使用横移、下降、前景上移、局部特写匹配、声音先行等，但每个镜头只服务一个主要信息点。不能把整段转场写成抽象“画面变化”。

## 八、正反打与轴线

- 对话双方分别标明机位角度和视线方向；一方看画外右，另一方通常看画外左，坐者看站者适当抬眼，站者看坐者适当垂眼。
- 正反打背景必须不同且符合场景布局。例如拍桌后人物时出现其身后的柜体/墙面，反打桌前人物时出现其身后的门/访客区。
- 反打不等于“正面”。必须写清人物面向、摄影机方向、真实背景和观察角度。
- 默认遵守180°轴线。确需越轴时，用连续可见的运动或双人关系镜头重新建立空间方向。
- Rack Focus写明起点和终点；不为每句对白都拉焦。

## 九、打戏与物理动作

只执行剧本已有动作强度和结果，不凭空增加殴打。用清晰动作链组织：

**起：** 交代双方距离、攻守方向和退路。  
**承：** 动作主体起势，摄影机沿动作方向跟随；切镜落在动作接点。  
**转：** 闪避、格挡、换位或反击用适当角度强调。  
**合：** 给接触或躲开后的真实反应、身体重心和落点，重新建立双方位置。

24–35mm可强调速度与空间，35–50mm帮助看清接触关系，85mm插入特写突出关键细节。手持跟随的惯性来自人物运动；不要靠连续乱晃、跳轴和特写堆砌掩盖动作设计不足。


## 十、经典戏剧场景的专业导演调度法则

拒绝“为了运镜而运镜”的监控式旁观视角（如生硬地从窗帘摇到床上坐起），一切运镜与焦点变化必须服务于人物的主观感知与戏剧揭示：

1. **宿醉清晨/床戏初醒发现身边有人（Morning-After / Stranger Reveal）**：
   - **枕上平视浅景深 + 移焦揭示（Pillow-Level Shallow DOF + Rack Focus）**：摄影机贴近枕头高度（85mm 大光圈），用打在人物眼睑/脸上的刺眼晨光光带直接交代“光透过窗帘”（避开直接拍窗外夜景底图导致的天色穿帮）；人物眯眼揉额坐起转头时，通过快速移焦（Rack Focus）或镜头后拉（Pull-back），将身旁原本处于浅景深虚化中的另一人瞬间拉清晰，让观众与主角同步体验惊吓。
   - **地面罪证前景上摇（Evidence Foreground Tilt-Up）**：从洒着晨光的地板/地毯上散乱交缠的衣物、鞋履起幅（无声交代昨夜激烈程度并为后续捡衣埋伏笔），随后镜头平稳上摇（Tilt Up）越过床沿，接床上主角恍惚坐起。
   - **垂直上帝视角俯拍（Top-Down Bird's-Eye Two-Shot）**：机位架在床正上方垂直俯拍，利用床品与两人睡袍/睡裙的色彩反差及斜劈床面的晨光构图，拍主角坐起转头瞬间石化。
2. **情绪主导的焦点转移（MasterClass Rack Focus 三原则）**：
   - **改变叙事重心**：双人或多人同框时，从说话者移焦至前景/后景暗中偷听或表情突变的人。
   - **揭示关键证据/新信息**：随人物视线定格，从人物眼部快速移焦至桌面协议、婚戒、伤痕或门口闯入者。
   - **外化内心顿悟（Dawning Comprehension）**：在人物意识到真相的瞬间，配合短促推镜将焦点死死锁在瞳孔与微表情上。
