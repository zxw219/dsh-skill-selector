# Nuwa Distillation Lanes

Use this reference when adapting outside methods or refactoring skills.

## Lane 1: Distill

Extract:

- the actual mechanism;
- its input signal;
- its output decision;
- its boundaries.

Ignore branding, rhetoric, and local repo ceremony.

## Lane 2: Reframe

Translate the mechanism into the target skill system:

- the active global operating posture;
- concise execution and reporting;
- formal long-term docs for cross-thread rules;
- capsule routing for validated reusable knowledge;
- audit routing for recurring drift.

## Lane 3: Merge

Decide whether the mechanism belongs in:

- an existing skill;
- a new skill;
- a reference file;
- a capsule;
- a global policy document.

Prefer merge over proliferation.

## Lane 4: Preserve Tension

If the source method contains a useful contradiction, keep it explicit:

- flexible but guarded;
- concise but evidence-based;
- proactive but not bloated;
- evolving but reversible.

Do not flatten these tensions into generic optimism.

## Lane 5: Compress

After adaptation, remove anything that does not change behavior.
