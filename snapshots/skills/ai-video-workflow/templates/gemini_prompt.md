# Gemini文案提示词模板

## 基础模板
```
请为[主题]类型的视频创作脚本，要求：
1. 时长：[X]秒
2. 风格：[风格描述]
3. 目标受众：[受众描述]
4. 需要包含[数量]个分镜

请输出：
- 每个分镜的画面描述
- 配音稿
- 字幕要点
```

## 分镜脚本格式
```
## 分镜1: [分镜名称]
- 画面：[详细画面描述]
- 配音：[配音文字]
- 时长：[X]秒
- 情绪：[情绪关键词]
```

## 示例
```
请为"AI改变生活"主题创作一个60秒的科普视频脚本。
风格：科技感、温暖、未来感
受众：都市白领、25-40岁
需要包含5个分镜。
```
