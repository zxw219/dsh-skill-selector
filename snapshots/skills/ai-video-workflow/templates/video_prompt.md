# 视频生成提示词模板

## 基础模板
```
[动作描述], smooth motion, cinematic, high quality
```

## 动作类型
| 动作类型 | 提示词示例 |
|----------|-----------|
| 运镜 | slow zoom in, dolly shot, pan left |
| 人物动作 | person walking, hand gesture, turning head |
| 环境 | leaves swaying, water flowing, clouds moving |
| 特效 | light rays, particles, sparks |

## 示例
```
A person slowly walking through a futuristic city,
looking up at the neon lights, cinematic, smooth motion
```

## 质量要点
1. 描述主体动作而非静态画面
2. 使用逗号分隔多个动作
3. 加上质量关键词
4. 避免过于复杂的动作
