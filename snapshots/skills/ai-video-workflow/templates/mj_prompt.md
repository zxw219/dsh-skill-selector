# Midjourney绘图提示词模板

## 基础模板
```
[画面描述], cinematic, high detail, 4K, professional lighting, 
[风格描述], --ar 16:9 --s 750 --q 2
```

## 参数说明
- `--ar 16:9`: 宽高比（视频常用16:9）
- `--s 750`: 风格化参数
- `--q 2`: 高质量模式

## 风格关键词
| 风格 | 关键词 |
|------|--------|
| 电影感 | cinematic, film grain |
| 科技感 | futuristic, holographic, neon |
| 温暖治愈 | warm lighting, soft colors |
| 赛博朋克 | cyberpunk, neon lights, rain |
| 写实 | photorealistic, 8k |

## 示例
```
未来城市天际线，高耸的摩天大楼，霓虹灯光，
赛博朋克风格，cinematic, 4K, --ar 16:9 --s 750
```
