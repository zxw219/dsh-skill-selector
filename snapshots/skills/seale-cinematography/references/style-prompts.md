## 七、模型适配建议

### Midjourney 8.2

- 使用 `--raw` 获得更写实的胶片质感
- 画幅：`--ar 239:100`（Anamorphic）/ `--ar 11:5`（70mm）/ `--ar 37:20`（Academic）
- Fury Road 特殊：`--chaos 25 --stylize 500` 增加调色与动感
- 黄金时刻：加 `--weird 0` 确保写实
- 参考：`--sref [英国病人/狂暴之路剧照URL]`

**示例完整 MJ 提示词：**
```
John Seale Mad Max Fury Road cinematography, ARRI Alexa M multi-camera,
burning crimson orange desert, war rig convoy center-framed,
red sandstorm approaching, 150 degree shutter action crispness,
--raw --ar 239:100 --stylize 500 --chaos 15
--no flat lighting, neutral grade, studio light
```

### Stable Diffusion / FLUX

- 正面必备：`John Seale cinematography, available light, magic hour, anamorphic lens flare, Panavision`
- 负面必备：`flat lighting, neutral grade, polite color, mid-day overcast hard, modern digital flat, studio floodlight`
- LoRA 建议：搭配胶片模拟 LoRA（Kodak Vision3 500T / Fuji Eterna）
- Sampler：DPM++ 2M Karras, 30–40 steps
- CFG：6–8（过高会破坏自然光柔和感）

### DALL-E 3 / GPT Image

- 使用自然语言详细描述：
  - 太阳位置（"sun just above horizon to camera left"）
  - 反射光源（"silver reflector bounces warm light onto figure's face"）
  - 画幅（"shot in Panavision 70mm widescreen 2.20:1 format"）
  - 影片参照（"in the style of John Seale's English Patient"）

### Nano Banana Pro / Gemini 2.5 / 3 Pro Image

- 中英混合提示词有效，但核心光影术语必须英文
- 强调：`cinematic, John Seale, magic hour available light, anamorphic Panavision`
- 可上传西尔剧照作为参考图进行风格迁移
- 结构化 JSON 推荐：

## 八、Seale → Fraser 澳洲摄影谱系对照表

**澳大利亚电影摄影师协会（ACS）** 出身的两代宗师在好莱坞确立的视觉哲学对照：

| 维度 | John Seale (1942–) | Greig Fraser (1975–) |
|------|-------------------|---------------------|
| **协会身份** | ACS, ASC | ACS, ASC |
| **澳洲根脉** | 澳大利亚电影委员会出身 → Peter Weir 御用 | 维多利亚州出身 → 澳洲新一代 |
| **沙漠美学** | 《狂暴之路》定义橙青对比 | 《Dune》《Furiosa》延续并升级沙漠语言 |
| **史诗规模** | 70mm《英国病人》《冷山》 | IMAX《Dune Part One/Two》 |
| **自然光哲学** | Available light + 反光板传统 | 红外摄影 + 单光源极简打光 |
| **技术冒险** | 多机阵列、电池摄影机、72 岁复出 | StageCraft LED Volume 虚拟制片 |
| **色彩勇气** | "让颜色咬住观众" | 沙漠单色画派 |
| **代表作交集** | 《狂暴之路》(2015) | 《Furiosa》(2024) |
| **共同导演** | George Miller | George Miller |
| **传承事件** | 西尔《狂暴之路》启发 21 世纪沙漠电影 | 弗莱瑟《Furiosa》延续 Wasteland 视觉语法 |
| **AI 提示词识别关键词** | `John Seale, available light, Fury Road orange teal, 70mm Panavision, Academy Award English Patient` | `Greig Fraser, infrared desert, single source, Dune IMAX, StageCraft LED Volume` |

### 两位的共通哲学

> 澳洲的土地教会了我们尊重光、尊重风、尊重距离。
> 我们不与自然对抗，我们让自然告诉我们怎么拍。

## 使用建议

1. **先选场景模板** → 从上述 10 个模板中选最接近的
2. **替换 Scene 部分** → 保留 Style 不变，改写具体画面
3. **加影片参照** → 明确引用「in the style of [具体影片]」
4. **加负面提示词** → 避免平板打光、中性调色、现代数码感
5. **适配画幅** → 根据目标情绪选 2.39:1 / 2.20:1 / 1.85:1
6. **迭代优化** → 生成后观察光线方向、色彩、构图是否符合西尔逻辑

**核心提醒：西尔的灵魂是「available light + 澳洲骨血 + 让色彩咬住观众」——提示词必须体现这三要素中的至少一个。**
