## 普列托十大核心技法

### 1. 🌎 拉丁美洲手持纪实美学（Latin American Handheld Documentary Aesthetic）

**普列托的第一母语。** 从墨西哥电影学院（CCC）成长起来的他，将拉美纪录片的"见证者视角"注入剧情片——摄影机是观察者，不是操控者。

| 关键特征 | 说明 |
|---------|------|
| **手持即呼吸** | 手持运镜如同人的呼吸节奏，有机、活着 |
| **肩扛近身** | 贴近人物的情感距离，不躲在远处 |
| **让位真实** | 构图可以不"完美"，真实感优先 |
| **墨西哥学派** | 延续 Gabriel Figueroa / Emmanuel Lubezki 的墨西哥摄影传统 |
| **纪录片渗透** | 将纪录片语汇（粗颗粒、追拍、失焦瞬间）合法化 |

**代表场景**：
- 《爱情是狗娘》— 墨西哥城车祸前后的手持追拍
- 《21克》— 三条叙事线的贴身肩扛
- 《通天塔》— 摩洛哥沙漠、墨西哥婚礼、东京新宿的三文化手持

**提示词核心词**：
```
Latin American handheld documentary aesthetic, shoulder-mounted intimate camera,
organic breathing movement, witness-perspective framing, Mexico City street reality,
imperfect composition for emotional truth, CCC school cinematography,
Gabriel Figueroa lineage, observational rawness
```

### 2. 🎞️ 多胶片格式拼贴（Mixed Film Format Collage）

**普列托最具签名性的技法。** 在同一部电影内混合使用 35mm、16mm、Super 8、甚至 iPhone，让每种格式承载不同的时间性与情感真实。

| 格式 | 情感语义 | 代表应用 |
|-----|---------|---------|
| **35mm 胶片** | 主时间线、客观现实、电影感 | 《通天塔》摩洛哥线、《爱尔兰人》现在时 |
| **16mm 胶片** | 记忆、家庭、亲密、粗粝情感 | 《通天塔》墨西哥婚礼、《华尔街之狼》部分 |
| **Super 8 / 8mm** | 童年、梦境、破碎记忆 | 《爱情是狗娘》闪回、《巴比伦》片段 |
| **数字 ARRI Alexa** | 冷峻当下、黑帮的干净、科技感 | 《沃尔特·米蒂的秘密生活》冰岛 |
| **VistaVision / 65mm** | 史诗、仪式、不朽 | 《花月杀手》部分场景 |

**著名案例**：
- 《通天塔》三大洲三种胶片：摩洛哥 35mm 沙漠干燥 / 墨西哥 16mm 婚礼温暖 / 东京 35mm 冷调高反差
- 《华尔街之狼》在数字与胶片间切换，对应清醒/磕药状态
- 《爱尔兰人》用三种不同胶片 stock 对应 Frank Sheeran 三个年龄段

**提示词核心词**：
```
mixed film format aesthetic, 16mm Super 8 grainy intercut, 35mm Kodak film stock,
format-based emotional memory, handheld 16mm home movie intimacy,
Super 8 childhood dream fragments, film grain as narrative device,
Kodak Vision3 emulsion texture
```

### 3. ☀️ 自然光暖调（Natural Warm Light）

**普列托热爱光的"诚实"。** 偏好自然光、金时段、实景光源的温暖，很少使用冷白硬光。他的暖色不是糖果甜，而是土地、皮肤、血液、灰尘的暖。

| 关键特征 | 说明 |
|---------|------|
| **金时段崇拜** | 日出日落的斜光是他最爱 |
| **窗光为主** | 室内依赖窗户的自然天光 |
| **实景灯光** | 保留吊灯、台灯、路灯等场景内光源 |
| **暖色偏置** | 白平衡倾向 4000–5600K，偏暖而非偏冷 |
| **肤色温度** | 人脸总带一点红土色的温度 |

**代表场景**：
- 《断背山》怀俄明日落下的两人篝火
- 《花月杀手》俄克拉荷马夕阳中的奥塞奇原住民
- 《爱尔兰人》纽约公寓柔和的钨丝灯

**提示词核心词**：
```
natural warm sunlight, golden hour low-angle sun, motivated practical lamps,
tungsten bulb warm glow, skin-toned earthy warmth,
4000K warm white balance, sun-kissed golden light,
window light as primary source, no cold fluorescent
```

### 4. 🏜️ 墨西哥黄褐色（Dust Gold / Tierra Dorada）

**普列托的母题色彩。** 来自墨西哥高原的土地——干燥的黄褐、赭石、烤陶——这个色调贯穿他从《爱情是狗娘》到《花月杀手》的整个职业生涯。

| 关键特征 | 说明 |
|---------|------|
| **赭石基底** | 土色、铁锈色、烤陶色作为主基调 |
| **尘埃质感** | 空气中永远有可见的尘埃颗粒 |
| **低饱和暖** | 暖但不艳，像褪色的老照片 |
| **阳光烘烤感** | 画面有"被太阳晒过"的物质感 |
| **血与土** | 在暴力场景中，血色与土色融为一体 |

**代表场景**：
- 《通天塔》摩洛哥山区的赭色荒原
- 《花月杀手》奥克拉荷马油田的黄褐夕阳
- 《爱情是狗娘》墨西哥城街区的尘土感

**提示词核心词**：
```
Mexican dust gold palette, ochre earth tones, terracotta baked warmth,
tierra dorada, sun-scorched desaturated amber, dust particles in golden air,
Oaxacan desert color, faded sepia-amber like old Mexican photograph,
blood and earth merging, bronze sunburn tone
```

### 5. 🏔️ 怀俄明高地蓝绿（Brokeback High-Country Blue-Green）

**《断背山》独创的色彩词汇。** 高海拔牧场的冷蓝晨雾 + 松针的墨绿 + 暖橙篝火——这三色系对应情感的压抑、自然的广袤、爱的燃烧。

| 关键特征 | 说明 |
|---------|------|
| **晨雾蓝** | 高海拔清晨的冷青蓝 |
| **松墨绿** | 深绿森林的凝重 |
| **篝火暖橙** | 夜晚小小的橙色温暖对抗巨大的冷 |
| **风景压迫** | 山脉让人物渺小，如西部绘画 |
| **含蓄情感** | 颜色克制，像 Ang Lee 的克制爱情 |

**代表场景**：
- 《断背山》两人初次在山上的放羊场景
- 《断背山》河中洗澡的午后暖光
- 《断背山》篝火旁相视的蓝橙对比

**提示词核心词**：
```
Brokeback high-country palette, cold alpine morning blue mist,
deep pine evergreen green, warm orange campfire contrast,
Wyoming ranchland vastness, restrained emotional color,
figures dwarfed by mountain landscape, Ang Lee contemplative wide shot,
Rodrigo Prieto Brokeback style

### 7. ⛩️ 东方静观 — 《沉默》日本水墨拟态（Oriental Contemplation — Silence Sumi-e Mimetic）

**《沉默》中普列托创造的独特东方视觉语法。** 模拟日本水墨画的灰银调、低饱和、以留白与雾气包裹人物——不是西方凝视下的东方奇观，而是从内部生长的禅意。

| 关键特征 | 说明 |
|---------|------|
| **灰银色温** | 接近黑白但保留极低饱和的色彩 |
| **雾海留白** | 大量海雾、山雾作为构图的留白 |
| **静止长镜** | 几乎不动的摄影机，如禅坐 |
| **苦难仪式化** | 用构图把折磨仪式化为宗教画 |
| **殉道光** | 偶然的神圣侧光照在受刑者身上 |

**代表场景**：
- 《沉默》日本海岸殉道者被绑十字架的海雾画面
- 《沉默》神父跋涉山道的灰绿密林
- 《沉默》密室审讯的单烛光

**提示词核心词**：
```
sumi-e ink painting mimetic, silver-gray low saturation,

### 10. 📸 定焦广角近拍 + 自然主义肤色（Wide-Angle Close with Honest Skin）

**普列托的"近且广"哲学。** 与迪金斯相似地偏爱定焦，但比迪金斯更近、更广，创造被包围感。对肤色的处理追求"真实的人"，不磨皮、不美化、保留毛孔、皱纹、油光、尘土。

| 关键特征 | 说明 |
|---------|------|
| **21–35mm 近拍** | 用广角镜头贴近脸部，展示环境 |
| **毛孔真实** | 保留肤质细节，不过度柔化 |
| **肤色温度** | 肤色偏暖，有血液流动感 |
| **汗与土** | 脸上可见汗珠、灰尘、疲惫 |
| **不均光** | 脸部光不均匀，一侧可能接近阴影 |
| **广角变形拥抱** | 用广角的透视畸变强化拥抱感 |

**提示词核心词**：
```
wide-angle close-up 21mm 27mm, face filling frame with environment,
honest skin texture with pores and wrinkles, visible sweat and dust,
naturalistic warm skin tone with blood circulation,
uneven asymmetric face lighting, wide-angle embracing perspective,
no skin smoothing, dignified unglamorized human face
```

## 工作流程

### 当用户需要普列托风格图像时：

1. **确认文化背景**：场景属于哪个文化地理——墨西哥 / 美国西部 / 纽约 / 日本 / 奥塞奇 / 其他
2. **匹配色彩系统**：从普列托的跨文化色板中选对应系统
3. **选胶片格式**：根据情感需要选 35mm / 16mm / Super 8 / 数字
4. **确定技法**：手持 vs 稳定、广角 vs 中景、窗光 vs 金时段
5. **组装提示词**：从 `references/style-prompts.md` 中选取基础模板
6. **适配模型**：根据目标 AI 模型做微调

### 当用户需要打光方案时：

1. **寻找自然光源**：优先窗户、天光、金时段
2. **确定实景灯**：钨丝灯、蜡烛、路灯、篝火的分布
3. **设计肤色温度**：人脸上的温度偏向（暖土色 / 灰银 / 琥珀）
4. **参照影片**：引用具体影片中类似场景
5. **输出方案**：描述光源位置、色温、质感、肤色处理

### 当用户需要构图/运镜建议时：

1. **识别情感强度**：温和 → 静态 / 中等 → 缓慢滑行 / 强烈 → 手持
2. **选镜头焦段**：近身广角优先
3. **决定格式**：长镜头（Iñárritu 风）or 剪辑密集（Scorsese 风）
4. **参照影片**：匹配具体代表场景
5. **描述构图**：贴近人脸 + 环境入框

## 提示词输出格式

```
🎬 场景标题

📽️ 影片参照：[最接近的普列托作品 + 场景]
🎞️ 格式选择：[35mm / 16mm / Super 8 / 数字 理由]
🌍 文化色板：[对应的跨文化色彩系统]

**Style（风格）：**
[完整的英文风格提示词 — 涵盖胶片、打光、色调、氛围]

**Scene（画面）：**
[完整的英文画面提示词 — 涵盖构图、主体、环境]

**完整提示词：**
[Style + Scene 合并]

💡 打光笔记：[简要说明打光逻辑]
🎨 色彩笔记：[简要说明跨文化色彩意图]
🎞️ 格式笔记：[为何选此胶片/数字格式]
```

---

## 重要原则

- **所有提示词必须是英文**：AI 图像生成工具对英文效果最佳
- **Style 与 Scene 分离**：用户可保持 Style 不变，只改 Scene
- **文化敏感**：普列托的力量在于尊重每种文化的独特视觉，提示词要避免"异域风情化"
- **胶片感优先**：大多数情况下加入 `Kodak film grain` / `16mm emulsion texture`
- **手持作为选项**：不是所有场景都手持——斯科塞斯片子经常很稳
- **肤色诚实**：不要 `flawless skin, smooth`，要 `honest skin, pores visible, sweat`
- **跨文化色板**：明确选定对应色彩系统，不要混用
- **金时段优先**：当允许时，默认金时段自然光
- **引用影片**：推荐风格时，始终引用具体影片和场景作为参照

## 模型适配提示

### Midjourney
- 加 `--raw` 获得更真实的普列托胶片质感
- 用 `--ar 239:100` 模拟 anamorphic 宽银幕（《断背山》《花月杀手》）
- 用 `--ar 37:20` 模拟标准院线（《爱尔兰人》部分）
- 加入 `Kodak 500T, film grain` 强化胶片感

### Stable Diffusion / FLUX
- 负面提示词：`digital sharpness, HDR, oversaturated, skin smoothing, beauty filter, instagram style, flat even lighting`
- 正面强调：`Rodrigo Prieto cinematography, Kodak Vision3 film, ARRI Alexa, anamorphic 2.39:1, naturalistic skin tone with pores, honest documentary feel`

### DALL-E / GPT Image
- 用自然语言描述文化背景和胶片选择
- 例："a scene shot on 16mm Kodak film, Rodrigo Prieto style, Mexican handheld documentary feel, ochre earth tones"
- 强调 `shot on film, not digital` 以避免 AI 过度光滑化

### Nano Banana Pro / ZenStudio
- 中英混合有效，但胶片/色彩/光线术语用英文
- 强调 `cinematic, Rodrigo Prieto, Kodak film, handheld, natural warm light, honest skin`
- 多格式拼贴场景可在描述中加入 `film format collage with 35mm main and 16mm insert`

## 常见错误避免

1. ❌ **勿用"电影感"代替具体技法** → ✅ 用 `handheld 16mm Kodak, golden hour natural light`
2. ❌ **勿用完美对称构图** → ✅ 用 `imperfect documentary framing, off-balance for truth`
3. ❌ **勿过度美化肤色** → ✅ 用 `honest skin with pores, sweat, uneven lighting`
4. ❌ **勿混淆文化色板** → ✅ 选定对应系统，如 Osage palette 或 Brokeback palette
5. ❌ **勿忽略胶片颗粒** → ✅ 明确 `Kodak film grain emulsion texture`
6. ❌ **勿用硬白冷光** → ✅ 普列托几乎不用荧光冷光，用 `warm tungsten or natural window light`
