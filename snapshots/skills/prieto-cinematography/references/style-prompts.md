## 四、胶片格式选择指南

### 选 35mm Kodak Vision3 500T 5219 当：
- 主时间线、室内夜戏、餐厅、办公室
- 需要"电影感"权威
- 例：《爱尔兰人》纽约夜景、《华尔街之狼》办公室

```
shot on Kodak Vision3 500T 5219, 35mm film, cinematic authority, tungsten-balanced
```

### 选 35mm Kodak Vision3 250D 5207 当：
- 日戏、外景、自然光
- 花月杀手夕阳、断背山日戏
```
shot on Kodak Vision3 250D 5207, 35mm daylight film, natural sun
```

### 选 16mm Aaton XTR 当：
- 家庭、亲密、情感真实
- 婚礼、餐桌、闪回回忆
- 例：《通天塔》墨西哥婚礼、《爱情是狗娘》部分段

```
shot on 16mm Aaton XTR, intimate handheld home movie feel, grainy warmth
```

### 选 Super 8 Kodak Tri-X 当：
- 童年闪回、破碎记忆、梦境
- 极端情感片段

```
shot on Super 8 Kodak Tri-X, dreamy memory fragment, heavy grain, dreamlike
```

### 选 ARRI Alexa LF 当：
- 需要 CGI 去老化（爱尔兰人）
- 现代时间线、冰岛冒险
- 需要极度清晰

```
shot on ARRI Alexa LF, digital clarity, modern or CGI-integrated
```

### 选 65mm / VistaVision 当：
- 史诗仪式、庄严时刻
- 花月杀手部落仪式、巴比伦片场

```
shot on Panavision 65mm Sphero, epic ceremonial grandeur, large format depth
```

## 使用指南总结

1. **先定文化地理**：场景属于哪种文化色板
2. **再选情绪强度**：温和/中等/强烈 决定手持还是稳定
3. **选胶片格式**：主时间线 35mm、亲密 16mm、记忆 Super 8、现代数字
4. **匹配影片参照**：找到最接近的普列托作品
5. **组装七层提示词**：签名 + 格式 + 设备 + 光 + 色 + 构图 + 场景
6. **加负面提示词**：防止 AI 过度数字化、过度美化
7. **选模型适配**：MJ 用 `--raw`，SD 用长负面，DALL-E 用自然语言

记住普列托的核心哲学：**"The camera is a witness, not a master."** 所有提示词应服务真实的情感与文化尊重，而非炫技。
