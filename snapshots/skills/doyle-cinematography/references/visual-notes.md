## 关于杜可风

**Christopher Doyle / 杜可风**（1952— ），出生于澳大利亚悉尼，1970 年代在以色列、泰国、中国大陆游历、当水手、读中医，后于 1980 年代定居香港，自取中文名「杜可风」——取"清风可作老师（古汉语 风者，教也）"之意，意为"杜门隐居，与风为师"。他是华语电影走向世界的视觉缔造者之一，与李屏宾并称「华语电影摄影双璧」。

- 🏆 **香港电影金像奖最佳摄影**：6 次（《阿飞正传》《东邪西毒》《堕落天使》《花样年华》《2046》《一代宗师》——后者与潘耀明合作）
- 🎬 **金马奖最佳摄影**：3 次
- 🥇 **戛纳电影节技术大奖（Grand Prix Technique）**：2002 年凭《英雄》获奖
- 🏅 **威尼斯电影节最佳摄影**（OEuvre）、芝加哥影评人协会终身成就奖
- 🤝 与 **王家卫**合作 10+ 部（《阿飞正传》《重庆森林》《东邪西毒》《堕落天使》《春光乍泄》《花样年华》《2046》《蓝莓之夜》《一代宗师》局部）
- 🌏 与 **张艺谋**（《英雄》）、**Gus Van Sant**（《大象》《心灵驿站》《迷幻公园》）、**M. Night Shyamalan**（《灵异第六感》）、**Pen-ek Ratanaruang**（《无烟的爱情》《晚娘》）、**Jim Jarmusch**（《极限控制》）、**Phillip Noyce**（《宁静的美国人》）、**奉俊昊**、**许鞍华**、**陈可辛**等深度合作

## 杜可风十大核心技法

### 1. 🌃 霓虹夜街美学（Neon Asian Nightscape）

**杜可风的视觉签名。** 香港、东京、曼谷的午夜街道，霓虹光在湿润的空气与玻璃反射中变成情绪本身。

| 关键特征 | 说明 |
|---------|------|
| **多色霓虹混光** | 洋红 + 青绿 + 钴蓝同框，不和谐却致命迷人 |
| **湿润反射** | 雨后柏油路、玻璃窗、不锈钢，让一盏霓虹变成三盏 |
| **从下打的招牌光** | 巨大中文/日文招牌从角色头顶或下方倾洒 |
| **蒸汽与雾气** | 街边小食摊、地下通道蒸汽、车尾排气 |
| **失焦霓虹散景** | 前景或背景中故意失焦的霓虹色斑（bokeh balls） |
| **24/7 不夜街** | 招牌永远亮着，时间感被消解 |

**代表场景**：
- 《重庆森林》—— 旺角金钟扶手电梯下的霓虹拖影、夜店红绿光中的林青霞
- 《堕落天使》—— 重庆大厦的迷幻夜街、黎明前金黄路灯下的金城武
- 《春光乍泄》—— 布宜诺斯艾利斯肉店红灯、探戈酒吧霓虹
- 《2046》—— 未来列车上的红蓝霓虹与王菲

**提示词核心词**：
```
Hong Kong neon nightscape, Christopher Doyle neon style,
magenta-cyan-cobalt mixed neon glow, wet reflective asphalt,
overhead Chinese signage casting colored light,
steam from street stalls, out-of-focus neon bokeh,
dripping humidity, 4am Kowloon insomnia
```

### 2. 🎞️ Step-Printing 印片机叠帧拖影（Step-Printing Smear）

**杜可风最具辨识度的技术发明。** 用印片机将每一帧曝光多次（通常 1 帧拍 3 次），形成印象派油画般的运动模糊与时间分层。

| 关键特征 | 说明 |
|---------|------|
| **慢快门 + 高帧叠加** | 1/8s 快门 + 印片机重复曝光，运动主体拖出色彩残影 |
| **静止人物清晰、运动模糊** | 人海中的角色保持锐利，背景行人化为彩色光带 |
| **色彩拖尾** | 红色衣服拖出红色尾巴，黄色出租车拖出金色河流 |
| **印象派城市** | 城市变成莫奈式的色彩涂抹 |
| **时间被拉长** | 一秒变成五秒，孤独被放大 |

**代表场景**：
- 《重庆森林》—— 警员 223（金城武）在快餐店等女友，周围人海化为彩色拖影；旺角追逐戏中林青霞的金发拖影
- 《堕落天使》—— 杀手李嘉欣在酒吧的拖影、黎明在街头的运动模糊
- 《春光乍泄》—— 黎耀辉在布宜诺斯艾利斯街头的拖影
- 《2046》—— 列车上时间流逝的视觉化

**提示词核心词**：
```
step-printing motion blur, multi-exposure smear,
impressionist movement trails, frozen subject in flowing crowd,
streaks of color trailing behind moving figures,
1/8 second shutter blur, painterly motion smear,
time-stretched cinematography, Wong Kar-Wai signature blur
```

### 3. 🌧️ 湿润色彩心理学（Humid Color Psychology）

**亚洲城市的湿热感。** 杜可风的色彩永远像刚下完雨——饱和、潮湿、有粘性。

| 色彩方向 | 代表作品 | 情感意图 |
|---------|---------|---------|
| **怀旧老金黄** | 《花样年华》《2046》 | 60 年代香港的记忆温度 |
| **湿润洋红 + 青绿** | 《重庆森林》《堕落天使》 | 90 年代都市孤独的迷幻 |
| **病态酸黄 + 钴蓝** | 《2046》未来部分 | 失忆与未来的冷感 |
| **饱和血红** | 《英雄》「红」段落 | 欲望、嫉妒、复仇 |
| **翡翠青绿 + 白雪** | 《英雄》「绿」「白」段落 | 平静与殉情 |
| **沙土橘红** | 《英雄》「黑」段落 | 沙漠决斗的宿命 |
| **病房苍白绿** | 《灵异第六感》 | 死亡与超自然 |

**色彩处理原则**：
- 饱和但不刺眼，用湿气与雾气稀释
- 一个主色统治画面，另一个撞色作为「呼吸口」
- 拒绝低饱和的好莱坞写实，拥抱亚洲的浓烈

**提示词核心词**：
```
humid saturated colors, magenta-jade dichromatic palette,
nostalgic 1960s amber gold, sticky tropical humidity in color,
Wong Kar-Wai color signature, oversaturated yet diffused,
color as emotional weather, Asian metropolitan chromatic mood
```

### 4. 🤳 广角畸变贴脸（Wide-Angle Face Distortion）

**杜可风的「酒醉视角」。** 用 9.8mm / 14mm / 18mm 超广角镜头贴近人脸 30cm 拍摄，鼻子被拉长、空间被弯曲、墙壁倾斜。

| 关键特征 | 说明 |
|---------|------|
| **超广角近距人脸** | 距脸 30cm 以内，鼻子放大、五官扭曲 |
| **空间弯曲** | 房间四壁倾斜，天花板压下来 |
| **酒醉视角** | 模拟醉酒、迷恋、失神状态 |
| **手持微晃** | 不用斯坦尼康，让画面有真实呼吸 |
| **荷兰角混合** | 经常配合 5–15 度倾斜 |

**代表场景**：
- 《堕落天使》—— 大量 9.8mm 鱼眼贴脸金城武、李嘉欣
- 《重庆森林》—— 王菲在快餐店内 14mm 广角
- 《春光乍泄》—— 布宜诺斯艾利斯小公寓里的张国荣、梁朝伟
- 《英雄》—— 棋馆决斗的近距张力

**提示词核心词**：
```
extreme wide-angle close-up portrait, 9.8mm fisheye-adjacent distortion,
14mm wide-angle face distortion, exaggerated nose perspective,
warped room geometry, drunken intimate framing,
Christopher Doyle wide-angle signature, claustrophobic intimate distortion,
Dutch angle plus wide-angle, handheld breathing intimacy
```

### 5. 🎲 即兴主义（Improvisational Cinematography）

**没有分镜表也是分镜表。** 杜可风以「不预先 planning」著称——王家卫片场永远没有完整剧本，杜可风带着摄影机在拍摄现场即兴反应。

| 关键特征 | 说明 |
|---------|------|
| **不打灯只布场景实用光** | 用现场霓虹、台灯、窗光，少打灯 |
| **手持优先** | 大量手持镜头，跟随演员而非预设走位 |
| **试错次数极多** | 一场戏可以拍 30 个不同角度 |
| **happy accident** | 故障、意外、误曝光全部保留进成片 |
| **酒精与音乐** | 杜可风喜欢边拍边喝酒、放音乐找节奏 |
| **导演=合作伙伴** | 王家卫给一句话氛围，杜可风给一整套视觉解释 |

**代表场景**：
- 《重庆森林》全片 23 天用「便利店突袭」方式拍出
- 《堕落天使》大量在凌晨 3 点的真实街头偷拍
- 《春光乍泄》布宜诺斯艾利斯外景全部即兴

**提示词核心词**：
```
improvisational handheld cinematography, available practical light only,
documentary-style intimate observation, 4am street snatch shot,
no key light, only neon and incandescent practicals,
spontaneous camera positioning, happy-accident aesthetic
```

### 6. 🪟 窗框、镜面、玻璃反射（Frames, Mirrors & Glass）

**香港狭窄空间的诗意。** 杜可风把香港的小公寓、电梯、地铁、玻璃柜变成嵌套的画框，反射、折射、半透明叠加。

| 关键特征 | 说明 |
|---------|------|
| **镜面叠加** | 化妆镜、车后视镜、商店橱窗，让一个角色变成 2-3 个 |
| **玻璃门窗反射** | 街灯、霓虹、对面行人在玻璃上叠加 |
| **窗棂阴影** | 百叶窗、铁艺窗花投在角色脸上 |
| **半透明帘幕** | 旗袍、纱帘、塑料门帘的半遮半露 |
| **画中画** | 通过门洞、走廊看进另一个空间 |

**代表场景**：
- 《花样年华》—— 苏丽珍在窗棂阴影下抹胭脂
- 《2046》—— 王菲透过玻璃看周慕云
- 《重庆森林》—— 王菲在快餐店玻璃后偷看金城武
- 《堕落天使》—— 镜中反射的双重人物

**提示词核心词**：
```
mirror reflection doubling subject, glass window neon reflection,
venetian blind shadow stripes, frame within frame architecture,
translucent curtain veiling figure, shop window streetlight overlay,
Hong Kong narrow apartment claustrophobia
```

### 7. 🕒 慢门拖影 + 长曝光（Long Exposure & Drag Shutter）

**让光本身变成笔触。** 与 step-printing 不同，慢门是拍摄阶段直接降低快门速度，让光迹拉成线条。

| 关键特征 | 说明 |
|---------|------|
| **车灯拖成河流** | 街道车流的红黄白光带 |
| **霓虹拉成色块** | 移动的招牌光斑变成色彩条 |
| **人物虚化成幽灵** | 经过镜头的行人化为半透明影子 |
| **手持长曝** | 不用三脚架的故意抖动长曝 |
| **zoom 拖焦** | 曝光中变焦，光点变成放射状线条 |

**代表场景**：
- 《重庆森林》—— 旺角扶手电梯流光
- 《堕落天使》—— 摩托车夜驰的车灯长拖
- 《2046》—— 列车窗外的星光拉线
- 《春光乍泄》—— 伊瓜苏瀑布的长曝光

**提示词核心词**：
```
long exposure light trails, drag shutter motion,
red-white car light streaks, neon sign light smear,
ghost-like passing pedestrians, handheld long exposure,
zoom-during-exposure light burst, time-painted with light
```

### 8. 💋 怀旧黄 + 60 年代香港（Nostalgic Amber & 1960s Hong Kong）

**王家卫宇宙的标志色。** 一种特殊的「老照片黄」——介于琥珀、铜锈、香槟、烟草之间，让 90 年代拍的画面看起来像 60 年代的回忆。

| 关键特征 | 说明 |
|---------|------|
| **钨丝灯主色** | 全部用 3200K 暖光，把白衣服染成米黄 |
| **窗外蓝调对比** | 室内暖橙 + 窗外冷蓝，温差感 |
| **旗袍宝石撞色** | 张曼玉的酒红、孔雀蓝、墨绿旗袍 vs 暖黄环境 |
| **半曝光的脸** | 窗光只照亮半边脸，另一边沉入棕黑 |
| **老式装饰花纹** | 壁纸花纹、地毯花纹、旗袍刺绣的密集纹理 |
| **柔焦慢镜头** | Maggie Cheung 走过走廊的标志性慢镜 |

**代表场景**：
- 《花样年华》—— 全片教科书级的怀旧黄美学
- 《2046》—— 周慕云的 2046 房间走廊慢镜
- 《阿飞正传》—— 90 年代香港老房间
- 《一代宗师》—— 民国武馆的暖黄昏光

**提示词核心词**：
```
nostalgic 1960s Hong Kong amber, tungsten-lit interior 3200K warm,
```

### 9. 🎭 双重曝光与梦境层（Double Exposure & Dream Layers）

**梦与现实在同一帧。** 杜可风频繁使用机内双重曝光、慢化叠化、镜头前的玻璃透叠，让记忆与现实重合。

| 关键特征 | 说明 |
|---------|------|
| **In-Camera Double Exposure** | 机内一次拍摄两次曝光 |
| **半透明叠化** | 后期半透明叠加两个镜头 |
| **玻璃透叠** | 镜头前放半透明玻璃，反射另一个空间 |
| **梦境段落** | 主动进入超现实色彩与构图 |
| **时间错位** | 一个角色同时出现在过去与现在 |

**代表场景**：
- 《2046》—— 周慕云写小说时未来与过去叠化
- 《阿飞正传》—— 张国荣的镜面叠加
- 《心灵驿站》—— 火车窗外的世界叠加
- 《堕落天使》—— 杀手与天使在同一帧

**提示词核心词**：
```
in-camera double exposure, ghostly memory layer overlay,
translucent dream dissolve, two times in one frame,
surreal layered cinematography, glass-reflected double image,
mnemonic visual hauntology
```

### 10. 🐉 东方武侠的色彩分章（Wuxia Color Chapters）

**《英雄》的革命性贡献。** 杜可风把武侠片做成色彩诗——「红、蓝、白、绿、黑」五个段落，每个段落统一一个主色，让色彩成为叙事章节。

| 章节 | 主色 | 含义 |
|------|------|------|
| **黑（秦宫）** | 玄黑 + 沙金 | 秦王的肃杀、宿命 |
| **红（书馆）** | 血红 + 漆红 | 嫉妒、欲望、谎言 |
| **蓝（棋馆）** | 钴蓝 + 银白 | 真相的冷峻 |
| **绿（书院）** | 翡翠 + 竹青 | 平静、回忆、和平 |
| **白（沙漠）** | 雪白 + 金沙 | 殉情、纯净、终极 |

**技术亮点**：
- 中国胡杨林的金黄飞叶（红章节）
- 九寨沟湖面的镜面棋盘（蓝章节）
- 戈壁滩飞檐走壁（白章节）
- 张曼玉、章子怡、梁朝伟、李连杰、甄子丹的色彩造型

**提示词核心词**：
```
Wuxia color-chapter cinematography, monochromatic palette per scene,
blood-red qipao Hero style, cobalt blue silk wuxia duel,
emerald jade bamboo forest fight, white sand desert death,
Christopher Doyle Hero color philosophy, color-as-narrative wuxia
```

### 镜头偏好

| 类型 | 首选 | 说明 |
|------|------|------|
| **超广角** | Zeiss / Cooke 9.8mm、14mm、18mm、21mm | 杜可风的人脸贴近变形签名 |
| **变形宽银幕** | 偶尔使用（《英雄》《2046》） | 比迪金斯更愿意拥抱光学瑕疵 |
| **球面广角** | 21mm、25mm、27mm | 王家卫片的标准工作焦段 |
| **老旧镜头** | 故意用刮花/有油渍/低对比度的旧镜头 | 追求「不完美的浪漫」 |
| **滤镜** | 黑色柔焦丝袜（black pro-mist）、玻璃前涂凡士林 | 制造梦幻/怀旧晕染 |

### 常用焦段

| 焦段 | 用途 | 杜可风偏好 |
|------|------|-----------|
| 9.8–18mm | 贴脸畸变特写 | 《堕落天使》签名 |
| 21–27mm | 王家卫式中景 | 香港小公寓的工作焦段 |
| 35–50mm | 标准叙事 | 较少使用 |
| 75mm+ | 几乎不用 | 杜可风讨厌长焦的「窥视感」 |

### 滤镜与后期

- **印片机叠帧（Step-Printing）**：1 帧曝光 2-3 次
- **化学过冲（Push Processing）**：胶片冲洗时增感 1-2 档，提升颗粒与饱和
- **黑色柔焦**：Tiffen Black Pro-Mist 1/4 ~ 1/2 减低高光锐度
- **机内双曝**：Arri 525 的可重复曝光功能

## 工作流程

### 当用户需要杜可风风格图像时：

1. **确认情绪基调**：是「重庆森林孤独迷幻」还是「花样年华怀旧暧昧」还是「英雄武侠色彩诗」？
2. **匹配影片**：从 25+ 部代表作中选定最贴近的一部
3. **确定 2-3 个核心技法**：例如「霓虹夜街 + step-printing + 广角畸变」
4. **组装提示词**：从 `references/style-prompts.md` 中选取模板
5. **适配 AI 模型**：根据目标模型微调

### 当用户需要打光方案时：

1. **拒绝硬光**：杜可风极少用硬 key light
2. **找现场实用光**：霓虹、台灯、烛光、街灯、电视机光
3. **添加湿气与雾**：让光「可见」
4. **混色策略**：洋红 + 青绿、暖橙 + 冷蓝
5. **手持质感**：模拟人在场的呼吸感

### 当用户需要构图建议时：

1. **是否需要广角畸变**：讨论是否要 9.8mm / 14mm 贴脸
2. **是否需要镜面/玻璃反射**：增加层次
3. **是否使用荷兰角**：5–15 度倾斜模拟酒醉
4. **画框嵌套**：通过窗、门、镜子做 frame within frame
5. **运动主体的处理**：是否拖影、是否慢门

```
🎬 场景标题

📽️ 影片参照：[最接近的杜可风作品 + 场景，如「《重庆森林》午夜快餐店」]

**Style（风格）：**
[完整的英文风格提示词 — 涵盖打光、色调、氛围、运动质感]

**Scene（画面）：**
[完整的英文画面提示词 — 涵盖构图、主体、环境、广角畸变]

**完整提示词：**
[Style + Scene 合并]

💡 打光笔记：[简要说明实景光源、湿气、霓虹混色逻辑]
🎨 色彩笔记：[湿润洋红/青绿/怀旧黄等情感意图]
🎞️ 技术备注：[是否 step-printing、是否广角畸变、是否慢门]
```

---

## 重要原则

- **所有提示词必须是英文**：AI 图像生成工具对英文响应最准确
- **拥抱不完美**：杜可风风格的核心是「美好意外」，不要过度精致
- **饱和但不暴力**：色彩浓烈，但用湿气、雾气、柔焦稀释
- **拒绝写实主义**：杜可风不追求真实，他追求「比真实更真实的感受」
- **手持优先**：除非影片明确稳定（如《英雄》部分场景），默认 handheld
- **实景光优先**：提示词中要明确 "no key light, practical lights only"
- **怀旧不是滤镜**：怀旧来自钨丝灯色温 + 暖墙纸 + 旗袍配色，不是橙黄滤镜
- **引用具体影片**：每个提示词都要带 reference film 标签

## 模型适配提示

### Midjourney
- 加 `--raw --stylize 750` 获得杜可风的湿润质感
- 用 `--ar 37:20` 模拟 35mm 学院宽银幕、`--ar 239:100` 模拟变形宽银幕
- 关键词权重：`Christopher Doyle::2 Wong Kar-Wai::1.5 neon::1.5`

### Stable Diffusion / FLUX
- LoRA 推荐：Wong Kar-Wai LoRA、Hong Kong neon LoRA、Film grain LoRA
- 负面提示词：`clean studio lighting, HDR, sharp digital, sterile, modern Hollywood, lens correction, anti-shake, perfectly framed`
- 正面强调：`Christopher Doyle cinematography, step-printing motion blur, 9.8mm wide-angle distortion, neon humid Hong Kong, Kodak Vision3 push-processed`

### DALL-E / GPT Image
- 用「电影场景」叙事风格："A 1994 Hong Kong neon-lit late night convenience store, Christopher Doyle style, magenta and cyan light bleeding through wet glass, handheld 14mm wide-angle, motion-smeared crowd"
- 强调时间感："4am, drunken, lonely, lovesick"

### Nano Banana Pro / ZenStudio
- 中英混合有效，但核心技法用英文：`step-printing`, `wide-angle distortion`, `neon humid`
- 强调：`cinematic, Christopher Doyle, Wong Kar-Wai, In the Mood for Love palette, Hong Kong 1960s/1990s`

### Kling / Runway / Sora（视频）
- 强调 motion：`step-printing motion blur, drag shutter, slow-motion crowd, frozen subject in flowing time`
- 时长建议：3-6 秒，最适合杜可风的「时间凝固」感

## 禁忌事项（What Doyle Would Never Do）

❌ **不要使用 Steadicam 或斯坦尼康** —— 杜可风讨厌过度稳定
❌ **不要 HDR / 锐化过度** —— 杜可风的画面要有胶片柔和与颗粒
❌ **不要标准三点布光** —— 拒绝好莱坞工业光，要实景光
❌ **不要饱和度全开的卡通色** —— 饱和需要被湿气稀释
❌ **不要冷调写实主义** —— 杜可风的世界永远「湿润、暧昧、孤独」
❌ **不要长焦窥视镜头** —— 杜可风偏爱贴近的广角
❌ **不要完美对称构图** —— 倾斜、偏移、即兴才是他的语言
❌ **不要清晰锐利的运动** —— 运动要有拖影、有时间、有诗意

## 杜可风 vs 李屏宾 ——「华语摄影双壁」对照表

杜可风（澳籍香港）与李屏宾（台湾），同为华语电影走向世界的关键摄影师，常被并称「华语摄影双壁」，但他们的视觉哲学几乎完全相反，构成华语电影美学的两极。

| 对比维度 | 杜可风 Christopher Doyle | 李屏宾 Mark Lee Ping-Bing |
|---------|------------------------|--------------------------|
| **文化根源** | 西方印象派 + 亚洲都市流浪 | 中国山水画 + 东方禅意 |
| **美学母题** | 都市孤独、迷幻情欲、时间错位 | 自然气韵、家国乡愁、岁月静好 |
| **光的哲学** | 「光是动词」—— 让光运动、漫流、混色 | 「等光不打光」—— 让光自然降临 |
| **核心光源** | 霓虹、街灯、台灯、霓虹反射 | 窗光、月光、雾光、烛火 |
| **饱和度** | 高饱和（湿润洋红/青绿） | 低饱和（水墨灰、茶褐） |
| **代表色** | 怀旧黄 / 霓虹紫 / 血红 / 病态酸黄 | 翡翠青 / 暗红煤油 / 民国黄褐 / 水墨灰 |
| **构图** | 倾斜、偏移、广角畸变、镜面叠加 | 对称、留白、东方山水画三分 |
| **运镜** | 手持即兴、step-printing、慢门拖影 | 静观长镜头、缓慢横摇、呼吸式微晃 |
| **镜头偏好** | 9.8mm / 14mm 超广角贴脸 | 35mm / 50mm 中焦距，敬畏空间 |
| **节奏** | 4am 醉酒心跳、闪烁、断裂 | 一呼一吸、潮汐、四季 |
| **时间观** | 都市加速、时间被压扁拖长 | 时间是合作者，等花开等雾散 |
| **核心搭档** | 王家卫、张艺谋、Gus Van Sant | 侯孝贤、王家卫、许鞍华、是枝裕和 |
| **代表作风** | 《重庆森林》《堕落天使》《英雄》 | 《悲情城市》《刺客聂隐娘》《长江图》 |
| **共同合作** | 《花样年华》前期 | 《花样年华》接力完成、后期 |
| **空间观** | 香港狭窄公寓的迷宫 | 台湾山水/中国大地的开阔 |
| **女性影像** | 张曼玉的旗袍宝石色、林青霞的金发拖影 | 张曼玉的窗光半脸、舒淇的雾中身影 |
| **拍摄方式** | 凌晨 3 点街头偷拍、即兴 | 等待与守候，一场雾等三周 |
| **设备态度** | 拥抱故障、刮花、过曝 | 严控胶片化学、呼吸式手持 |
| **摄影机视角** | 「醉酒、爱着、有点迷路」 | 「学会呼吸、屏息凝视」 |
| **国际合作** | Gus Van Sant、奉俊昊、Jarmusch、Shyamalan | 是枝裕和、Olivier Assayas、Tran Anh Hung |
| **AI 提示词关键词** | `step-printing, neon humid, wide-angle distortion, Wong Kar-Wai amber` | `natural window light, ink-wash composition, contemplative long take, Eastern negative space` |

### 何时选杜可风、何时选李屏宾？

**选杜可风**：
- 想拍都市夜街、霓虹、孤独、爱情、迷幻
- 需要拖影、广角畸变、酒醉视角
- 角色：失眠者、追爱者、杀手、舞女、警察
- 空间：香港、东京、曼谷、布宜诺斯艾利斯
- 情绪：4am 的湿热、孤独、心碎

**选李屏宾**：
- 想拍家庭、历史、自然、乡愁、东方
- 需要长镜头、留白、自然光、雾气
- 角色：父亲、母亲、农民、武者、漂泊者
- 空间：台湾乡间、中国山水、日本胡同、上海弄堂
- 情绪：黄昏的安宁、季节流转、命运的承受

**两者皆可（化学反应）**：
- 王家卫宇宙：《花样年华》《2046》同时由两人合作
- 旗袍 + 窗光 + 怀旧黄：两位大师共同的母题
- 张曼玉的脸：在杜可风镜头下是欲望的浮雕，在李屏宾镜头下是岁月的容器
