## 四、打光方案模板

### 方案 A：单窗光（霍特玛室内经典）

```
LIGHTING SETUP — Hoytema Single Window:

• KEY: Large soft window light (camera-left or camera-right), real diffused daylight
• FILL: NONE — embrace deep preserved shadows
• PRACTICAL: One period-accurate table lamp providing warm accent (visible in frame)
• AMBIENT: Low — room naturally dark except window area
• SHADOW: Deep, graduated, detail preserved, NO artificial lift
• COLOR TEMP: Window = cool daylight (5600K), Practical = warm tungsten (2700K)
• MEDIUM: 35mm Kodak Vision3 5219 or IMAX 65mm
• MOOD: Intimate, contemplative, period-truthful
```

### 方案 B：单台灯欠曝（Tinker Tailor 式）

```
LIGHTING SETUP — Hoytema Tungsten Underexposure:

• KEY: Single tungsten desk lamp (visible in frame, warm 2700K)
• FILL: NONE
• AMBIENT: Extremely low — darkness surrounds pool of light
• EXPOSURE: Underexpose 1-2 stops from meter reading
• ISO: Push Kodak Vision3 5219 to 800-1600
• ATMOSPHERE: Cigarette smoke for sculptural light
• SHADOW: Deep, nearly black, only highlights visible
• MEDIUM: 35mm film, heavy grain
• MOOD: Paranoid Cold War espionage intimacy
```

### 方案 C：IMAX 单舷窗（Interstellar 太空）

```
LIGHTING SETUP — Hoytema IMAX Cockpit:

• KEY: Single window of real spacecraft interior, sun-position dependent
• FILL: NONE — space is truly dark
• PRACTICAL: Real working instrument panel tungsten glow (2200-2700K)
• AMBIENT: Pure black void outside cockpit
• EXPOSURE: Wide dynamic range allowing both sun blast and panel detail
• MEDIUM: IMAX 65mm 15-perf, Kodak Vision3 5219
• ASPECT RATIO: 1.43:1 IMAX
• MOOD: Tactile real-space isolation
```

### 方案 D：水平海平线（Dunkirk）

```
LIGHTING SETUP — Hoytema Horizontal Horizon:

• KEY: Natural overcast sky as omnidirectional source
• FILL: Natural — sky and sand bounce
• PRACTICAL: None in exterior; flares/explosions for night
• HORIZON: Place sea-sky line at exact center or 70/30 division
• COLOR TEMP: Cool overcast daylight (6500-7500K), beach warm 4500K
```
