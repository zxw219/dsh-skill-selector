## Timbre/Characteristics (音色特征) (31)

| Suno 标签 | 中文 | 备注 |
|----------|------|------|
| `Deep` | / | 音色具有深沉饱满的共振，能够感知出明显的低频震动感。 音高通常较低，低频充足。发声位置较低。 |
| `Warm` | / | 音色饱满平滑暗淡，没有尖锐或刺耳的元素，给人一种舒适温暖的感觉。 低频饱满，中频圆润，高频不刺耳。 |
| `Round` | / | 音色深厚温暖饱满，动态较小。比明亮的中低频更饱满，比温暖的高频更丰富。 |
| `Bright` | / | 音色不容易被埋没。音色细节和清晰度高。高频相对突出。 |
| `Sharp` | / | 声音具有刺激性的感觉，会有一些攻击性的锐利元素。大多数鸭嗓的唱法就属于锐利的音色。 |
| `Smooth ` | / | 指声音质感没有粗糙的颗粒感或尖锐的棱角，音符之间的连接非常流畅 |
| `Silky` | / | 指声音不仅顺滑，还带有一种精致的高级质感，通常伴有细腻的高频泛音 |
| `Soulful` | / | 指声音充满了深层的情感张力，通常包含丰富的动态变化和装饰音技巧，能直击人心 |
| `Sexy` | / | 能唤起亲密感和吸引力的音色 |
| `Smoky` | / | 音色略沙哑，但是没有到特别沙哑。沙哑质感的颗粒较小。音色爆发性通常不会太强所以适应多种风格。 |
| `Gritty` | / | 音色大气略感沙哑。音色较为直白有一定爆发性。沙哑颗粒介于烟嗓和沙哑之间。 |
| `Husky` | / | 音色较为粗糙，像被沙子摩擦过一样。声音波动较大。胸声为主导，没到极端的沙哑。和smoky相比沙哑质感的颗粒较大。 |
| `Extreme` | / | 具有极强的穿透力。多存在于金属等爆发性强的唱法中，或存在于一些试验性唱法当中 |
| `Enthusiastic` | / | 音色给人极大积极情绪感染力 |
| `Sassy` | / | 叛逆，直率，音色通常唱腔比较直，有流行朋克的感觉。 |
| `Energetic` | / | 情绪积极，极富感染力。比如热血日漫主题曲的演唱风格大多是这种特点 |
| `Loud And Sonorous` | / | 音色能够表达出强烈的情感，具有极强的穿透力，即使在大合唱或乐器声中，也能清晰地听到。音高通常较高，动态极大，高频共振丰富… |
| `Powerful` | / | 包含丰富的低频和中频成分，共振强。与低沉的区别在于厚嗓也可以诠释较高音高的歌曲。与高亢，铿锵有力的区别是厚嗓穿透性不一定… |
| `Ethereal` | / | 音色清澈，平滑和谐，具有梦幻的悬浮感。 高频突出，通常来说高频会有回声和混响，空间感足，音域跨度通常较大。 |
| `Refreshing` | / | 音色轻盈舒适 |
