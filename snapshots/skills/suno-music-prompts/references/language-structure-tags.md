## 曲式结构 Structure Tags

| Suno 结构标记 | 中文 | 说明 |
|--------------|------|------|
| `[intro]` | 前奏 | 指歌曲最开始的一段音乐，也称为序曲，引子等。 |
| `[verse]` | 主歌 | 指歌曲中Chorus或Pre-Chorus之前的部分，在歌曲中主要以叙述、情绪表达等形式出现。 |
| `[pre-chorus]` | 连副段 | 一般存在于Chorus之前，是有别于Verse的一个独立片段。 |
| `[chorus]` | 副歌 | 出现于Verse或Pre-Chorus之后，Interlude、Bridge或Outro之前的乐段，是歌曲传唱度最高的部分。 |
| `[post-chorus]` | 副歌后段 | 紧接在chorus之后，延续副歌能量或记忆点。 |
| `[interlude]` | 间奏 | 通常以器乐为主，出现在Chorus和第二次Verse之间。 |
| `[bridge]` | 过渡段 | 也称为桥段或桥梁，通常出现在歌曲中后半段。 |
| `[outro]` | 尾奏 | 与Intro相对，是指歌曲最后的一段音乐。 |
| `[hook]` | 记忆点 | 歌曲中最具有辨识度和特征的一个段落。有一个易于辨识的旋律动机或节奏pattern，通常重复度较高，构成单位较短。 |
| `[breakdown]` | 衔接段 | 多出现在电子音乐中非高能量部分的段落类型。段落整体能量和前一段相比有显著突然降低与抽离的反差，用来为下一次的高潮做铺垫。但prechorus或buidlup等衔… |
| `[build-up]` | 渐进段 | 与Pop中的Pre-Chorus功能类似，通常在Breakdown之后，Drop之前出现。 |
| `[drop]` | 高潮 | 与Pop中的Chorus功能类似，具有最丰满的音响效果和最高的听觉能量层级（爽感）。 |
| `[head in]` | 主题进入 | 指歌曲主题旋律第一次出现的部分，head通常习惯性用于指爵士乐的主题部分 |
| `[solo]` | 即兴演奏 | 指一段音乐中，单一乐器突出，进行即兴或略有编排的演奏。 |
| `[head out]` | 主题再现 | 主题旋律再现的部分，通常用于爵士乐。 |
| `[exposition]` | 呈示部 | 呈示部通常位于作品的开头，主要职责是引入和展示主题材料。 |
| `[development]` | 发展部 | 发展部主要功能是对前面呈示部所呈现的主题进行深化和探索。 |
| `[recapitulation]` | 再现部 | 重新呈现前面呈示部所引入的主题，但这次通常会有所改变，以产生音乐形式的统一感。 |
| `[cadenza]` | 华彩 | 华彩段落是古典音乐中的一个特殊部分，通常在协奏曲或者重奏曲的乐章末尾出现。它充分展示了音乐家的即兴创作和技巧演奏。 |
| `[coda]` | 尾声 | 整首作品结构和气氛的落定。 |
