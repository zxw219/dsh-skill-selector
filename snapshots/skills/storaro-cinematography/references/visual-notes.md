## 关于维托里奥·斯托拉罗

**维托里奥·斯托拉罗**（Vittorio Storaro，1940–），意大利电影摄影师，被誉为"色彩与光的诗人"。

- 🏆 **3 次奥斯卡最佳摄影**（《现代启示录》1979、《赤色分子》1981、《末代皇帝》1987）
- 🎯 **多次戛纳、威尼斯、ASC 终身成就奖**
- 📚 出版三部曲专著《Writing With Light》（用光书写）：第一卷 *Light*、第二卷 *Colors*、第三卷 *Elements*
- 🎬 **黄金搭档**：与 **Bernardo Bertolucci**（贝托鲁奇）合作 10 部、与 **Francis Ford Coppola**（科波拉）合作 4 部、与 **Warren Beatty**（沃伦·比蒂）合作 3 部、与 **Carlos Saura** 合作 4 部、与 **Woody Allen**（伍迪·艾伦）合作 4 部
- 💡 创立 **Univisium 2:1** 画幅标准（电视与电影统一画幅）
- 🌈 提出 **色彩光谱情感论**：将可见光的 7 种颜色与人类意识的 7 个阶段对应

**核心哲学**：
> "Cinematography means *writing with light* — not just lighting, but writing."
> （电影摄影的本意是"用光书写"——不是打光，而是书写。）
>
> "Each color has its own meaning, its own psychology, its own connection to a stage of human life."
> （每一种色彩都有它自己的含义、自己的心理学、自己与人生某个阶段的连接。）
>
> "Light, shadow and color are the three primary energies of cinema, like the three primary forces of the universe."

## 斯托拉罗十大核心技法

### 1. 🌈 色彩心理学（Color Psychology / Symbolic Color）

**斯托拉罗的第一原则。** 每一种颜色都不是装饰，而是潜意识的语言。他建立了一套从《巴黎最后的探戈》开始、在《末代皇帝》集大成的**色彩象征系统**。

| 颜色 | 象征意义 | 代表影片 |
|------|---------|---------|
| **红 Red** | 生命、激情、革命、母体 | 《赤色分子》《巴黎最后的探戈》 |
| **橙 Orange** | 家庭、温暖、安全感 | 《末代皇帝》宫廷 |
| **黄 Yellow** | 知识、太阳、皇权 | 《末代皇帝》登基 |
| **绿 Green** | 知性、自然、成长、丛林 | 《现代启示录》丛林 |
| **蓝 Blue** | 智慧、清醒、纯净、阴性 | 《巴黎最后的探戈》冷调段落 |
| **靛 Indigo** | 直觉、夜空、潜意识 | 《意乱情迷》 |
| **紫 / 品红 Violet/Magenta** | 灵性、矛盾、超越 | 《迪克·崔西》 |
| **白 White** | 觉醒、空灵、起点 | 《末代皇帝》出宫 |

**代表场景**：
- 《末代皇帝》— 溥仪的人生用色彩光谱推进：橙黄（童年宫廷）→ 红（青年权力）→ 绿（成年觉醒）→ 蓝（监狱反思）
- 《赤色分子》— 红色在每一场革命戏中弥漫，从围巾、旗帜到天空
- 《巴黎最后的探戈》— Francis Bacon 启发的橙黄与冷蓝，对应肉体与孤独

**提示词核心词**：
```
Storaro color psychology, symbolic color palette, color as language,
amber-orange and deep red dominant tones, color representing emotional state,
psychological color storytelling, Bacon-inspired flesh tones,
each color meaningful and intentional
```

---

### 2. 💡 用光书写（Writing With Light / Motivated Light）

**Cinematography = Writing With Light.** 斯托拉罗坚持每一束光都必须有"书写"的目的——它不仅照明，更叙事。光源必须可信（动机光），但光的"情感真相"高于物理真相。

| 关键特征 | 说明 |
|---------|------|
| **动机光（Motivated Light）** | 来自窗户、烛火、灯笼、霓虹、太阳等可信光源 |
| **戏剧化强调（Dramatic Emphasis）** | 但与迪金斯不同，斯托拉罗会"夸张"动机光使其成为情感符号 |
| **光的能量（Light as Energy）** | 光不是工具，是宇宙的原始力量 |
| **意识的隐喻（Light = Consciousness）** | 从黑暗走向光，对应角色的觉醒过程 |
| **温度叙事** | 冷暖光对照表达内外世界的冲突 |

**代表场景**：
- 《现代启示录》— 黄色火光中库尔兹上校的雕塑感半脸
- 《末代皇帝》— 阳光从紫禁城屋檐倾泻，既是物理光也是历史光
- 《巴黎最后的探戈》— 巴黎清晨从大窗户射入的金色冬日光

**提示词核心词**：
```
writing with light, motivated dramatic lighting, theatrical practical light,
light as narrative energy, exaggerated key light source, sun shafts through architecture,
firelight sculpting face, single dramatic source defining the scene,
Storaro signature lighting design
```

### 3. 🗿 雕塑感打光（Sculptural / Painterly Lighting）

**斯托拉罗把摄影机当作雕塑刀。** 他用光在脸上和空间里"雕刻"形体，致敬卡拉瓦乔（Caravaggio）和文艺复兴绘画。

| 关键特征 | 说明 |
|---------|------|
| **强烈侧光与顶光** | 从一侧或上方切入，造出明暗强反差 |
| **半脸与暗面（Half-Light）** | 一半光辉，一半隐入黑暗——人物的双重性 |
| **油画质感（Painterly Quality）** | 画面的明暗过渡如同油画 |
| **空间体积感（Volumetric Space）** | 光通过雾、尘、烟形成可见体积 |
| **致敬大师** | 卡拉瓦乔的明暗对照、维米尔的窗光、伦勃朗的金色暗调 |

**代表场景**：
- 《现代启示录》— Marlon Brando 半脸沉入黑暗的特写
- 《末代皇帝》— 慈禧临终床榻前蜡烛雕刻出的肖像
- 《巴黎最后的探戈》— Brando 与 Schneider 的卡拉瓦乔式肉体光

**提示词核心词**：
```
sculptural chiaroscuro lighting, Caravaggio-inspired light and shadow,
painterly Renaissance illumination, half-lit face emerging from darkness,
volumetric light through atmosphere, Rembrandt golden shadows,
oil painting tonal transitions, sculpted facial topography
```

### 4. 🌡️ 温度对比（Temperature Contrast / Hot vs Cold）

**冷与暖的并置，是斯托拉罗最常用的二元结构。** 他几乎从不让画面只有一种色温——总有一处冷光对抗一处暖光，或反之。

| 关键特征 | 说明 |
|---------|------|
| **暖前 / 冷后** | 前景人物暖光，背景冷调——突出人物 |
| **冷外 / 暖内** | 室外冷蓝月光 + 室内橙黄烛光 |
| **能量对决** | 冷暖代表两种意识形态、两种角色立场 |
| **过渡的诗意** | 角色穿越色温分界线，象征心理跨越 |

**代表场景**：
- 《赤色分子》— 室外的革命寒冷（蓝） vs 室内的爱情温暖（橙）
- 《末代皇帝》— 紫禁城的金黄 vs 监狱的青蓝
- 《现代启示录》— 战火橙红 vs 河流的午夜蓝绿

**提示词核心词**：
```
hot-cold color temperature contrast, warm amber foreground vs cool blue background,
duality of color temperature, character bridging warm and cold zones,
emotional temperature shift, simultaneous warm and cool light,
ideological color temperature dichotomy
```

**斯托拉罗是文化色彩学家。** 拍每一部影片前，他都研究该文化、该时代、该地理的色彩传统，用色彩成为文化的镜子。

|------|---------|---------|

| 《赤色分子》 | 共产红、布尔什维克黄昏蓝 | 俄国革命色彩学 |
| 《现代启示录》 | 越南丛林绿、燃烧弹橙、原始紫 | 东南亚战争意象 |
| 《探戈》 | 阿根廷国旗蓝白 + 探戈红 | 拉美激情色彩 |
| 《卡里加里博士》 | 表现主义紫、黄、红 | 德国表现主义致敬 |
| 《迪克·崔西》 | 红/绿/蓝/黄四原色 | 漫画印刷三原色 |
| 《一九〇〇》 | 大地棕、麦黄、共产红 | 意大利乡土与历史 |

**提示词核心词**：

```
culturally symbolic color palette, regional traditional colors,

historically grounded color design, color as cultural memory
```

### 6. 📺 Univisium 2:1 画幅（Universal Aspect Ratio）

**斯托拉罗在 1990s 末倡导 2:1 画幅作为电影/电视统一标准。** 既保留电影感的宽广，又适应未来电视/数字屏幕。它现在已被 Netflix、Apple TV+ 广泛采用。

| 关键特征 | 说明 |
|---------|------|
| **2:1 比例** | 介于 1.85:1 与 2.39:1 之间，斯托拉罗认为是"最普世"的画幅 |
| **垂直信息保留** | 比 2.39:1 多保留垂直信息——天空、屋顶、建筑高度 |
| **构图哲学** | 适合人物与建筑共存的画面 |
| **代表作** | 《探戈》《意乱情迷》《魔法时刻》《Cafe Society》以后的伍迪·艾伦影片 |

**提示词核心词**：
```
Univisium 2:1 aspect ratio, balanced cinematic frame,
both human and architectural scale visible, vertical information preserved,
Storaro's universal frame, --ar 2:1
```

### 7. 🪟 自然光源仿真（Practicals as Architecture）

**每一个场景都"内置"光源。** 斯托拉罗将灯笼、烛台、街灯、霓虹、窗户等视为场景的"建筑组件"，让光源同时是道具、是叙事者、是构图焦点。

| 关键特征 | 说明 |
|---------|------|
| **实景灯具** | 大量使用故事内的灯笼/吊灯/烛台/霓虹 |
| **灯具即角色** | 灯具的造型、密度、布局本身参与叙事 |
| **光源入画** | 故意让光源出现在画框内，形成发光锚点 |
| **历史考据** | 灯具风格严格符合年代——煤油灯、烛台、煤气灯、电灯 |

**代表场景**：
- 《末代皇帝》— 紫禁城的红色宫灯阵列
- 《巴黎最后的探戈》— 巴黎公寓的吊灯与暖黄实景灯
- 《Cafe Society》— 1930s 好莱坞泳池派对灯串与酒吧吊灯
- 《探戈》— 舞厅顶部的环形灯阵

**提示词核心词**：
```
practical lights as architecture, period-accurate lamps and lanterns,
visible light sources as compositional anchors, red Chinese lanterns in frame,
glowing chandelier hanging in shot, gas-lamp era warmth,
neon practicals defining the space, lights as characters
```

### 8. 🔄 能量流动（Energy & Movement of Light）

**光是动的。** 斯托拉罗经常让光在场景中"运动"——通过摄影机移动、光源闪烁、烟雾流动、色彩渐变，让画面像活物般呼吸。

| 关键特征 | 说明 |
|---------|------|
| **缓慢推拉** | 推镜头中光的角度逐渐变化 |
| **光的渐变（Gradient）** | 从一种色彩"漫"到另一种色彩 |
| **烟雾与体积** | 烟、雾、光柱让光的流动可见 |
| **节奏感** | 闪烁、舞步、火焰让光产生节拍 |
| **舞蹈感** | 摄影机如舞者，与角色共舞（《探戈》、《意乱情迷》） |

**代表场景**：
- 《探戈》— 摄影机随舞步在红蓝光场中盘旋
- 《现代启示录》— 直升机攻击场景中橙红火光的脉冲
- 《意乱情迷》— Madonna 表演中聚光灯的彩色脉动

**提示词核心词**：
```
flowing energy of light, color gradient transition across frame,
volumetric smoke revealing light movement, dancing camera with subject,
pulsating practical lights, rhythmic chiaroscuro,
light as living energy, dynamic luminous atmosphere
```

### 9. 🏛️ 仪式感构图（Ritualistic / Symmetric Composition）

**斯托拉罗的构图带有古典仪式的庄严。** 对称、纵深、消失点、画框中的画框——这些经典手法被他用来强化"神性瞬间"。

| 关键特征 | 说明 |
|---------|------|
| **中央对称** | 关键时刻人物正中，强调权力或孤独 |
| **建筑纵深** | 长廊、宫殿轴线、林荫大道的延伸 |
| **画中画** | 门洞、窗框、屏风形成嵌套 |
| **仪式时刻** | 加冕、婚礼、革命、死亡——用构图"圣化" |
| **天地人三分** | 上(天)/中(人)/下(地) 的三段式 |

**代表场景**：
- 《末代皇帝》— 三岁溥仪登基的全景中央对称
- 《赤色分子》— John Reed 演讲场景的众人朝向中央
- 《一九〇〇》— 田野中平民列队的史诗大全景

**提示词核心词**：
```
ritualistic centered symmetry, ceremonial composition,
deep architectural perspective with vanishing point, nested frames within frames,
sacred geometry of cinema, character at center of cosmic axis,
heaven-man-earth three-tiered composition, epic ceremonial wide shot
```

### 10. 🎞️ 染印技术致敬（Technicolor Tribute / Saturated Filmic Texture）

**斯托拉罗钟爱浓郁的胶片色彩。** 即使在数字时代，他也极力还原 Technicolor 三色染印（Three-strip Technicolor）的厚重质感——色彩饱和而不刺眼、暗部依旧有色。

| 关键特征 | 说明 |
|---------|------|
| **饱和但不刺眼** | 色彩浓郁而柔和，不是 HDR 的尖锐 |
| **暗部有色** | 阴影中也保留色相，黑色不死黑 |
| **胶片颗粒** | 保留细腻颗粒感，拒绝塑料感清晰 |
| **染印致敬** | 《迪克·崔西》《卡里加里博士》直接致敬染印年代 |
| **数字时代** | 转向 Sony F65 / VENICE 后仍坚持染印调色逻辑 |

**提示词核心词**：
```
Technicolor three-strip homage, saturated yet velvety colors,
shadows holding chromatic information, fine film grain texture,
rich filmic color depth, no plastic digital sharpness,
classical Hollywood color science, Storaro's painterly digital grade
```

## 工作流程

### 当用户需要斯托拉罗风格图像时：

1. **确认主题**：场景的情感主题是什么？（爱、革命、觉醒、堕落、权力……）
2. **匹配色彩心理学**：从斯托拉罗的色谱中找出对应象征色（红=激情、绿=知性等）
3. **匹配影片**：从其作品中找到最匹配的视觉参照
4. **确定技法**：选择 2-3 个核心技法（如：色彩心理学 + 雕塑光 + 仪式构图）
5. **组装提示词**：从 `references/style-prompts.md` 中选取基础模板，根据需求调整
6. **适配模型**：根据目标 AI 模型做微调

### 当用户需要打光方案时：

1. **分析场景动机光**：找出场景中可信的光源（窗、烛、灯笼、火）
2. **强化为戏剧化**：将动机光"夸张"成情感符号
3. **设计冷暖对比**：决定哪边冷、哪边暖
4. **雕塑面部**：决定主角脸的明暗分界（卡拉瓦乔法）
5. **加入实景灯具**：让灯具入画作为锚点
6. **参照影片**：引用具体影片中类似场景

### 当用户需要色彩方案时：

1. **识别情感**：场景的核心情绪
2. **查色谱**：从色彩心理学表对应象征色
3. **选择主色 + 对比色**：定 1 主色 + 1 互补色
4. **设计渐变**：色彩在画面中如何流动/对比
5. **文化考据**：核对该时代/地理的真实色彩
6. **参照影片**：匹配代表作

### 当用户需要构图建议时：

1. **判断场景仪式感**：是日常还是神圣瞬间？
2. **选择构图法**：仪式对称 / 建筑纵深 / 画中画 / 三段式
3. **确定画幅**：默认 Univisium 2:1
4. **加入实景光源**：让灯具/窗户成为构图锚点
5. **参照影片**：匹配代表场景

## 提示词输出格式

```
🎨 场景标题

📽️ 影片参照：[最接近的斯托拉罗作品 + 场景]
🌈 色彩心理学：[主色 + 象征意义]

**Style（风格）：**
[完整的英文风格提示词 — 涵盖打光、色彩心理学、染印质感、画幅]

**Scene（画面）：**
[完整的英文画面提示词 — 涵盖构图、主体、文化符号、实景光源]

**完整提示词：**
[Style + Scene 合并]

💡 打光笔记：[简要说明动机光与雕塑光逻辑]
🎨 色彩笔记：[简要说明色彩象征与冷暖对比]
🏛️ 构图笔记：[简要说明仪式感/纵深/对称]
```

---

## 重要原则

- **所有提示词必须是英文**：AI 图像生成工具对英文效果最佳
- **Style 与 Scene 分离**：用户可保持 Style 不变，只改 Scene
- **色彩永远有意义**：拒绝随意配色，每个色彩都对应象征
- **冷暖必须共存**：除非极端场景，画面应有冷暖二元
- **动机光为底，戏剧光为表**：先有可信光源，再强化情感
- **暗部要有色**：避免 "pure black"，多用 "deep amber shadow"、"violet shadow"
- **致敬胶片**：保留 grain、Technicolor 饱和、染印质感
- **文化考据**：拍东方就要东方色，拍革命就要革命色
- **画幅默认 2:1（Univisium）**：除非用户指定其它
- **引用影片**：推荐风格时始终引用具体影片和场景

## 模型适配提示

### Midjourney
- 加 `--raw` 获得更厚重的染印质感
- 用 `--ar 2:1` 模拟 Univisium 画幅；`--ar 239:100` 模拟《末代皇帝》宽幅
- 用 `--s 250` 提升风格化以呼应斯托拉罗的浓郁色彩
- 强调 `painterly, Caravaggio lighting, Technicolor` 触发其训练中的绘画感

### Stable Diffusion / FLUX
- 负面提示词：`flat lighting, HDR, plastic digital, dead black shadows, washed out, gray monotone, modern Netflix flat grade, lens flare`
- 正面强调：`Vittorio Storaro cinematography, Technicolor saturation, motivated dramatic lighting, color psychology, painterly chiaroscuro, Univisium 2:1`
- LoRA 推荐：使用 Technicolor / Painterly / Renaissance Lighting 类 LoRA

### DALL-E / GPT Image
- 用自然语言描述色彩象征："a scene where deep red represents revolution and warm amber represents intimacy, in the style of Vittorio Storaro"
- 强调"painted by light"、"each color carries meaning"

### Nano Banana Pro / ZenStudio
- 中英混合有效，但核心打光与色彩术语用英文
- 强调 `cinematic, Vittorio Storaro, sculptural lighting, color psychology, Technicolor saturation, motivated practicals`

### Sora / Kling / Runway（视频）
- 加入 `slow rotating dolly, light gradient transition, smoke revealing light volume, ritualistic camera movement` 触发斯托拉罗式动态
- 时长建议 5–10s 以保留色彩节奏感
