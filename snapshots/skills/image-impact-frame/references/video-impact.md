# 视频击点与连招 · Video Impact

单张图只取「释放」那一瞬；视频要管前后。这份文件解决三件事：**逐秒怎么排、镜头之间怎么接、时间数字给多少**。

## 一、一次命中的五个阶段

| 阶段 | 观众看到什么 | 写提示词时的作用 |
|---|---|---|
| **可预见** | 威胁在建立（刀锋接近防线、拳头后拉） | 给这一击定价 |
| **空当** | 节奏突然变（对手停住、呼吸一顿） | 悬念的来源 |
| **释放** | 有效动作越过防线，发生可见接触 | **单张图只取这一步** |
| **强调** | 最重要的几帧做成视觉重音 | 只盖这几帧，不铺满全程 |
| **余力** | 身体、武器、衣物、地面继续承受 | 重量落地的位置 |

4 秒短片可以在一个稳定镜头里走完五个阶段。**缺「余力」的一击，看起来像没打中。**

## 二、三种节奏型（先选一种）

- **突然逆转**：普通招架 → 破绽 → 一击改变双方空间关系。强效果只给逆转那一下。适合拳击、刀战、动漫格斗。
- **重物延迟**：大质量启动 → 接触、结构压陷 → 远端物体滞后反应。重点在**看得见的传导**。适合机甲、巨兽、车辆、建筑。
- **极静极动**：画面安静、动作很小 → 一次极快位移 → 余势在布料、尘埃、对手身上显现。快速位移也要有终点，不能像瞬移。适合拔刀、居合、高速剑术。

## 三、逐秒时间轴怎么写（本技能默认交付格式）

把整段拆成 0.5–1 秒一格，每格写三样：**镜头在做什么 / 主体在做什么 / 有没有视觉效果**。

```text
0.0–1.0s  中景固定。甲右直拳被乙交叉护臂接下，拳面压进护臂，双方身形一沉。
1.0–2.0s  乙反手肘横扫，甲侧头避开，肘尖擦过护额，护额边缘凹进一小块。
2.0–3.0s  甲重心前移，镜头降到贴地仰角。膝撞顶进乙腹前护甲——
          【命中】护甲边缘翘起，碎片从缝隙射出，地面裂纹向镜头方向爬。
          这一帧做 1 帧黑白硬对比，随后恢复原画面。
3.0–4.0s  乙被推离原位半步，鞋底在湿地擦出水痕，护甲碎片继续落地。
```

三条硬规则：

1. **一个片段只安排一次主命中。** 其余接触压到 L1，否则观众分不清哪一下重要。
2. **命中那一刻的视觉变化必须写「随后恢复原画面」。** 不写，模型会把闪白/反相拖到片尾。
3. **时间轴里不写「第几帧顿」这种帧级指令。** 视频模型执行不了，交给第 6 节的数字与后期工具。

## 四、三联卡：画面 A → B → C

需要跟前后镜头衔接时，先写三个时间状态，再合成一条提示词。一上来就写塞满所有镜头的超长提示，最容易崩。

**A：接触前的最后可读状态**
- 谁在左、谁在右、是否跨越摄影机运动轴线
- 主攻肢体起始位置、武器指向、距离、支撑脚
- 关键背景元素（柱子、墙洞、起火位置）

**B：唯一的冲击状态**
- 是命中 / 格挡 / 落空 / 破坏 中的哪一种
- 需要保留的两三个图像证据（双人轮廓、接触位置、刀刃方向）
- 一种主要视觉变化（瞬时剪影、局部高亮）

**C：恢复后的第一个状态**
- 受体怎样后退、旋转、形变或失衡
- 主体怎样收招或因后坐力移动
- 场景状态怎样继承（地面裂缝、崩出的砖、仍在下落的雨）

**一致性测试**：在纸上把 A 和 C 的人物脚下站位各画一个圆点，用箭头连。若角色穿过对方身体、或前后武器突然换手，先修卡片再生成。

**转成提示词时**：把三联卡内容合成清楚的动作语句。不要把这些标签原样堆进提示词（「A、B、C、连续性保证」模型读不懂）。只有用户要分镜板时才保留结构化卡片。

**需要两次生成时**：第一段终止姿态尽量接近第二段第一帧；有首尾帧功能就写明两张图各自职责；不要求模型记住没提交的素材。

## 五、连招：从三联卡到击点表

一场打斗里，每个击点各写一张三联卡，再排成档位曲线（见 `intensity-ladder.md`）。

| 镜号 | 击点 | 档位 | 力学式 | 视频提示词要点 | 后期配方 |
|---|---|---|---|---|---|
| 1 | 甲直拳被格挡 | L1 | — | 侧面中景，格挡清楚 | 不加 |
| 2 | 乙反手肘擦过 | L2 | 爆点 | 甲侧头避开，肘尖擦过护额 | `light` |
| 3 | 乙膝撞腹（破绽） | L4 | 爆点 | 单独成片段，贴地仰拍 | `anime` |
| 4 | 乙终结踢 | L5 | 贯穿 | 单独成片段，踢腿轨迹贯穿画面 | `crit` |
| 5 | 甲跪地，尘落 | L1 | — | 余波，静止镜头 | 无 |

剪完之后，把每个击点的**实际秒数**填进击点表（格式见 `../examples/cues-example.json`），交给后期工具一次渲染。

## 六、时间数字（做视频和后期时直接用）

| 手段 | 建议时长 | 说明 |
|---|---|---|
| **顿帧**（命中定格） | 轻击 0–30 ms · 重击 50–80 ms · 暴击 100–150 ms | 24 fps 下约 1–4 帧。定格在**动作最可读的姿态**上；格斗游戏常让双方同时冻结并轻微抖动 |
| **冲击帧**（闪白/墨色/反相） | **1–2 帧** | 2 帧以上容易刺眼且盖住动作 |
| **抹帧/拖影** | 1–2 帧 | 夸张拉长主体衔接两个关键姿态；用多了画面会乱 |
| **震屏** | 轻 100–150 ms · 重 200–350 ms | 从强到弱衰减；方向跟着力：横斩横震、下砸竖震（`shake` 的 `direction`：h／v／both） |
| **推近** | 150–300 ms | 冲击瞬间推到最近，再缓缓退回 |
| **连击间隔** | 30 fps 下**至少 8 帧** | 少于约 8 帧难分辨，少于约 5 帧会糊成一下；要更密，每一下都给自己的火花或闪光 |

三条经验：**重武器先慢后快**（前几下故意慢，后几下加速）；**超重武器可以不顿**（让挥砍穿过接触点继续走，惯性本身就是重量）；**慢动作留给终结技前**（让高潮动作看得清）。

这些是剪辑起点，按画风、动作速度、画面反差再调。

## 七、选对击点

格挡改变战局，击点就是格挡；反击改变战局，击点就是反击；爆炸真正的故事是桥梁断裂，重音就落在「承重梁失稳」，不必落在火光最大的那一刻。

**别让「最亮的光」抢走「最重要的事」。**

## 八、光敏安全（硬约束）

**WCAG 2.3.1：任意 1 秒内闪烁不超过 3 次**，或面积与强度低于阈值（一次「一般闪烁」＝一对相反的亮度变化，幅度达最大亮度 10% 以上且暗态低于 0.8；饱和红另有「红闪」标准）。

- 一场戏里闪光类效果**稀疏使用**；密集连击改用顿帧、震屏、推近这类不闪的手段。
- 后期工具会拦截每秒超过 3 次的闪烁效果，并在输出后做全画面亮度近似扫描；**它不计算面积与红闪，正式播出仍要用专业检测**。
- 公开发布建议同时提供柔和版本。

## 九、观看检查

关掉声音原速看一遍：不慢放能否判断哪一击最重要？只听音轨：撞击声是否落在正确时刻？带声音正常播放：画面峰值与声音峰值是否互相加强，还是反而盖住动作？
