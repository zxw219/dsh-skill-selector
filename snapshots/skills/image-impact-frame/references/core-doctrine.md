# 核心口径 · Core Doctrine

## 一、三口径

### 1. 写在「那一瞬」，不是「一个状态」

| 失效写法 | 有效写法 |
|---|---|
| 谁都没退 | 交界面还没稳、能量刚炸开、两侧刚开始互相穿透 |
| 他很生气 | 憋住的那口气刚刚炸出嘴 |
| 他举着刀 | 刃刚刚劈过空气 |
| 两人对峙 | 两股力刚碰上，冲击环还在开 |

**判定方法**：如果这句话换成一张静态海报也成立，那它是状态，不是瞬间。瞬间必须**只能存在一帧**。

### 2. 炸满画面

**满 ＝ 画面没有空场**，笔触、碎片、被推开的空气顶到画框四角。

**必须同时写一句**：`the strokes cover the whole frame, but never as filled areas` —— 把"满"和"实"当场拆开，否则模型二选一，通常选"实"。

### 3. 色值分层：每个值一个职责

画面里的每个色值承担**一个**职责，值与值之间界线干净。

**判据是职责是否重叠，不是色有多少**——多种颜色各自管一件事不算混；两种颜色抢同一件事才叫混。

**两层配置**

| 值 | 职责 |
|---|---|
| 底 | 地。**只出现在笔缝里，不做大面积色块——所以它不算第三个值** |
| 笔 | 主体形、发光、飞散物 |

这是"两层"能成立的原因。适合单色系、极简、追求绝对干净的画面。

**四层配置**（画面里同时有「运动线」和「飞散物」时）

| 值 | 职责 |
|---|---|
| 黑 | 地 ＋ 主体形 |
| 白 | **发光核心**——画面最亮 |
| 黄 | **高速线 · 运动本身** |
| 红 | **飞散物质 · 碎屑** |

把「运动」与「物质」拆成两种颜色——黄专跑线、红专飞块，两种信息互不干扰，观众不用去猜哪根线是速度、哪一块是碎屑。

**三条配套约束**

- **白只给最亮处。** 白一旦扩散到「运动」或「物质」层，画面就没有最亮点了。
- **黄与红不要互换职责。** 黄去飞块、红去跑线，观众立刻读不懂。
- **两股力对撞时必须是强对比色**；两侧同色＝没有对撞感。若受限于单色系（如全红），**靠明度与温度拉开**：一暗一亮、一冷一暖，并显式声明「差别由明度与温度承担，不由第三种颜色承担」。

四色可整体替换为其它配色组，**分工结构不变**（配色组见 `deconstruction-and-palette.md`）。

## 二、推论 A：满 ≠ 实

**「满」是画面没有空场；「实」是笔触并成没有缝的色块。** 炸满画面指画面被笔触铺满，不是被色块填实。

| 会抹掉笔刷感的措辞 | 正确措辞 |
|---|---|
| `packed so tight that it reads as almost solid` | `the narrow gaps between those strokes stay open all the way through` |
| `hairline gaps between them never close`（发丝缝＝等于要求实体） | `narrow gaps ... never close`（窄，但始终开着） |
| `nothing filled flat` + `flat black silhouette`（同一个 flat 两义并用） | 禁填实的表述改为 `nothing laid in as a coloured area`；剪影去掉 `silhouette` 一词 |

**密度负责暗，缝隙负责质。** 允许局部并实，但并实的部分在边界上必须重新裂回拉丝。

**这条只管「线」。碎片是另一回事**——飞散的物质本来就是实心尖楔，用「缝隙」去要求它是无效指令。线层与碎片层的要求必须分开写，详见 `air-and-marks.md`。

## 三、推论 B：不实 ≠ 晕

把「不要实」理解成「改写意留白」是**方向性错误**——那会让多个值互相渗透、边缘水墨化。

| 概念 | 含义 | 要吗 |
|---|---|---|
| **实** | 笔触并成没有缝的色块 | 不要 |
| **晕** | 水墨渗开、笔画糊掉 | 更不要 |
| **清爽的疏** | 笔触一根根看得见、边缘干净、窄缝始终开着、不成实块、不渗不混 | **要这个** |

两句硬约束直接写进提示词，不是只写在文档里：

```text
The brush never bleeds: no wash, no spreading, no softening between marks.
The two values never blend: wherever they meet, the boundary is a clean hard edge.
```

**凡写意／留白类改法，先确认用户是否真要，不得自行推广。**

## 四、同句自相矛盾清单

以下六条都是在实际出图中被验证过的自毁句，编译前逐条排除。

| # | 症状 | 例子 |
|---|---|---|
| C1 | 同一个词两义并用 | `nothing filled flat` ↔ `flat black silhouette` |
| C2 | 用「极窄」形容缝隙 | `hairline gaps` —— 等于要求整幅读作实体 |
| C3 | 用剪影／色块描述形体 | `silhouette` / `black mass` —— 闭合轮廓＋实心内部＝实体感 |
| C4 | 全画笔触统一方向 | `all of them toward the vanishing point` —— 机械规整，反松脱 |
| C5 | 用几何体描述光 | `a bounded sphere whose edge is a visible shape` —— 球＝体积；与"空气由笔触构成"两套逻辑并存 |
| C6 | 残留的旧措辞 | `stiff` 与"松／枯"相反；跨版本搬运时最容易被忘掉 |

**方法**：读完后**逐句比对**——凡一句要"虚"、另一句要"实"，必查。

## 五、编译前自检

- [ ] 是瞬间，不是状态／版式
- [ ] 无空场，且明写「不是平涂填色」
- [ ] **每个色值一个职责，没有两层抢同一件事**
- [ ] **线层与碎片层的要求分开写**（线层不许并实／碎片层是实心块）
- [ ] 单色系时两值在明度与温度上拉得够远
- [ ] 笔触模块在前三分之一
- [ ] 所有笔触句都说「缝始终开着、任何部分不成实心块」
- [ ] 全篇无同句自相矛盾
- [ ] 无解剖词（`face` / `eye` / `skin` / `teeth` / `vein` / `sweat`）
- [ ] 灭点唯一且已命名
- [ ] `--no` 短、具体、无多词否定
