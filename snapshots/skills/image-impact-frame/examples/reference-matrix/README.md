# 参考图矩阵 · Reference Matrix

一组 9 张的**同风格矩阵**，用来同时回答两件事：这套画法长什么样，以及同一张构图能挂多少种配色。

**画面规格统一**：内容区 **2.39:1** 宽银幕（1868×770，外套 16:9 黑边）；底**纯平**，无渐变、无噪点、无环境光、无投影。

## 二、这组图确立的六条

1. **主体剪影是实心平涂，内部零肌理。** 崩解**只发生在边缘**。与笔触模块那句「任何部分都不成实心块」不冲突——那句管的是**线层**。见 `references/air-and-marks.md` 的「三类笔」。
2. **崩解分三档**：道具（伞／兵器）**零崩解**，是全画唯一的完整几何形；躯干实心、边缘轻微毛糙；头发与衣摆**完全化成丝**。同一张画里三档并存，才不像"整体糊掉"。
3. **两种放射不能混**：A 组是**连接式芒刺**——笔触从爆心连出去、根根相接；B 组是**散落式笔触**——独立的柳叶形条，方向各异，不与主体相连，像被风卷起的墨。
4. **爆心有两处**：A 组在**接触点**，B 组在**脚下**。后者附带**地面同心椭圆涟漪**——冲击波在平面上的可视化。B 组主体**完全静止**，画面却是爆点强度：**静与爆可以并存，静止不削弱爆发**。
5. **接触点两个形会并成一个。** A 组里拳与身体在命中处**连成一片、不分彼此**，没有轮廓线把它们分开。这是"打进去了"的直接证据，比任何飞溅都有效。
6. **这套是印刷三色，不是纯黑白红**：黑 `#131210`、米白 `#EFE7DA`、砖红 `#D15533`——全部**低饱和、偏暖**。报纯 `#000000`／`#FFFFFF`／`#FF0000` 会把它做成数码高反差，纸感／印刷感当场丢。

## 三、S 组为什么放在这里

两张实拍（`s1`／`s2`）是这七张抽象图的**源素材**：机位、动作关系、光源位置都来自实拍，抽象版只是把材质抽掉、换成剪影与笔触。

推论：这套风格是**风格迁移**，不是凭空造形。要做同款，**先有实拍或写实底图定机位与动作，再抽离成双色剪影**，比直接从零描述稳定得多。

## 四、怎么用

- **当临摹目标**：选一组配色 → 按 `references/deconstruction-and-palette.md` 的形语法写主体 → 按 `references/air-and-marks.md` 分三层写笔。
- **当验收标准**：出图后回到本表逐项比——剪影是否实心？崩解是否只发生在边缘？三档崩解是否都在？放射是连接式还是散落式？底色是否纯平？
- **当配色表**：底色与笔色互换即成反相，A／B 两组各已给出实证版本，不必重新试错。
