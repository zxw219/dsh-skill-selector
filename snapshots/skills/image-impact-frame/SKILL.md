## 触发边界（防竞争）

> 多句话同时命中多个技能时，按此边界分流。

- **本技能负责**：「冲击帧」关键瞬间的生图/生视频提示词
- **不用于**：长情绪流程；该场景请改用 `performance-scene-director`
- **同组技能**：`acting-system`、`performance-scene-director`
- **所属竞争域**：表演/情绪戏

# 冲击帧导演 2.1 · Impact Frame Director

把「一口气、一瞬间、一下打实」变成**可直接粘贴的提示词**。默认交付一整段可复制的生图或生视频提示词，不交问卷、不交长方案。

## 0｜两套体系怎么合在一起（先看这一节）

画面层是硬口径，管这一帧成不成立；强度层是档位刻度，管这一下狠到什么程度。两者**正交**，不是二选一：

| 层 | 管什么 | 对应文档 | 什么时候用 |
|---|---|---|---|
| **画面层（宪法）** | 这一帧**成立不成立** | 六条硬口径 → `references/core-doctrine.md` | 永远 |
| **强度层（旋钮）** | 狠到**什么程度** | L1–L5 → `references/intensity-ladder.md` | 每次定一档 |
| **结构层（骨架）** | 力**怎么走**、画面里**有什么** | 五帧型 × 力学四式 → `references/force-architectures.md` | 每次定一帧型一式 |

**关键**：升档只新增手段，不豁免口径。L4 的画面**依然**必须写在那一瞬、依然炸满但不并实、依然一值一职。用特效掩盖「打空了」是本技能第一条死罪。

## 1｜硬口径（六条，逐条不可省）

1. **写在「那一瞬」，不是「一个状态」。** 判定：这句话若换成静态海报也成立，它就是状态。瞬间只能存在一帧。
2. **炸满画面。** 画面没有空场，笔触、碎片、被推开的空气顶到四角。**必须同时写一句**：`the strokes cover the whole frame, but never as filled areas`——把「满」和「实」当场拆开，否则模型二选一，通常选「实」。
3. **每个色值一个职责。** 判据是**职责是否重叠**，不是色有多少。两层：底只走笔缝、不算第三个值。四层：黑白黄红 → 黑=地＋形、白=最亮核心、黄=运动线、红=飞散物。对撞时两侧必须是**强对比色**，同色即无对撞。
4. **满 ≠ 实，实 ≠ 晕。** 要的是「清爽的疏」：一根根看得见、边缘干净、窄缝始终开着、不成实块、不渗不混。两句写进提示词：`The brush never bleeds` / `The two values never blend: wherever they meet, the boundary is a clean hard edge`。**这一条只管线层**——主体剪影本身就是**实心平涂**，崩解只发生在边缘；剪影、碎片、线是三类笔，要求各不相同，见 `references/air-and-marks.md`。
5. **参考图留形不画物。** 只取机位、构成、空气、光、形语法；身份、服装、具体道具、场景文字、原图配色一律不取，除非用户点名要。
6. **零解剖词。** `face` `eye` `skin` `teeth` `vein` `sweat` 会激活写实先验，主体写实度必爆。改用形描述（「脸的轮廓由尖三角构成」）。

同句自相矛盾清单（C1–C6）与逐句比对法见 `references/core-doctrine.md`。

## 2｜档位（用户说「再狠一点」就升一档）

| 档 | 名称 | 画面做到什么 | 后期配方 |
|---|---|---|---|
| L1 | 清楚命中 | 稳定机位，两人轮廓分开，接触点明确，少量碎屑 | 不加 / `cinema` |
| L2 | 有分量 | 加受力反应：重心下沉、脚下滑步、护具压陷、衣摆甩出 | `light` |
| L3 | 爆发 | 加机位压迫：低机位或近前压迫；环境开裂或集中线；1 帧明暗冲击 | `heavy` / `manga` |
| L4 | 炸裂 | 加极端透视与尺度落差；背景抽象掉；色彩收到三色（对撞四色） | `anime` / `energy` |
| L5 | 极限 | 加画风短暂断裂：反相、墨色剪影、背景化为速度线 | `crit` |

**一场戏最多一次 L5。** 冲击力来自档位落差，不来自每一下都 L5。
逐档写法的中文、英文现成句、档位曲线排法见 `references/intensity-ladder.md`。

## 3｜帧型 × 力学四式（先定帧型，再选力学，最后定灭点）

| 帧型 | 力学式 | 灭点 | 核心要点 |
|---|---|---|---|
| 命中帧 | 爆点 | 打击点 | 主体压到角落；碎片从**封闭空间**（指缝、裂口）被逼出 |
| 斩击横贯帧 | 对撞（单侧） | 无（线横穿全画） | 一条高速线贯穿全画，把画面切两半 |
| 纯爆发帧 | 爆点（无主体） | 爆心 | 没有主体，集中线本身当主体 |
| 站场帧 | 压伏（静压） | 主体脚下 | 人不动、空气先动；「要爆还没爆」 |
| 碎裂帧 | 爆点／对撞 | 碎心 | 物质中央粉碎，碎片密度全画最高 |

力学四式：**爆点**（因小果大）·**压伏**（环境整体屈服）·**贯穿**（错位，用「笔触的缺席」画线）·**对撞**（势均力敌，交界面压到最窄）。
选式速查、每式的英文现成句见 `references/force-architectures.md`。一次只用一式，不混。

## 4｜透视与灭点（L3 以上必用）

- **灭点唯一**，放在最该盯的地方：接触点／相撞处／武器握柄一端／脚下／巨物背后的光。斩击横贯帧可不设。
- **巨物只露局部**：露出的四面都碰画框，观众自动想得更大。
- **刻度**：借熟悉物比大小（「她站着还没那颗铆钉高」）。
- **近前压迫**：拳或刃尖贴近镜头，近大远小拉到夸张。
- 用户锁了真实比例时，改机位，不拉变形。详见 `references/perspective-and-scale.md`。

## 5｜A：单张冲击帧（最常用）

**交付格式（固定三段）**

```text
① 本次设计      一两句话：取了什么、弃了什么、定了哪档、哪一式
② 可复制提示词   一整段，中间不分行不留空，直接可粘贴
③ 验收三条      最多三条可观察条件
```

**提示词内部顺序（照此写，别乱）**

```text
画风与媒介 → 主体与身份锁定 → 接触瞬间（动词＋部位＋方向）→ 力的结构与机位
→ 主冲击表达＋物理证据 → 介质与光 → 色彩分工 → 必须保持的条件
```

- **笔触模块放前三分之一**——提示词权重前倾，写晚了会被压掉。
- 只写**一个**时间瞬间，前后动作不进同一张图。
- 排除项优先用**正面描述**（写「背景只剩几道斜向速度线」，少写一串「不要…」）；平台有负面参数时按 `references/model-adapters.md` 用。
- 用户给参考图时，先跑第 8 节，再动笔。

## 6｜B：视频击点（逐秒时间轴）

**交付格式（固定三段）**

```text
① 动作路线      起始 → 发起 → 接触/避让 → 结果 → 收尾，一行写完
② 逐秒时间轴    0.0–1.0s / 1.0–2.0s / …，每段写：镜头在做什么 + 主体在做什么 + 命中在第几秒
③ 可复制提示词   一整段视频提示词，含镜头方向、左右关系、脚下接触、命中后恢复原画面
```

硬要求：

- **一个片段只安排一次主命中**，其余接触压到 L1。要最稳，主命中单独成段。
- **命中那一刻的视觉效果必须写「结束后恢复原画面」**，否则模型会把闪白/反相拖到结尾。
- 帧级精度（第几帧顿、顿几帧）**不要交给视频模型**，交给第 10 节的后期工具。
- 动画风格要写具体手段（赛璐璐平涂、粗描边、速度线、冲击闪）；只写「动漫风」会被拉向写实。
- 闪烁类效果**每秒不超过 3 次**（WCAG 光敏标准），工具会拦截。

节奏数字、连击间隔、顿帧时长、首尾帧写法见 `references/video-impact.md`。

## 7｜C：连招与多镜

先排节奏再写提示词：普通攻防 → 破绽 → 转折一击 → 余波。每镜写清**左右位置、朝向、武器在哪只手、上一镜终止姿态、本镜第一个可见动作、结尾姿态**。

产出：交接卡 ＋ 每镜可复制提示词 ＋ 一张击点表（可直接喂给后期工具）。格式见 `references/video-impact.md` 与 `examples/cues-example.json`。

## 8｜D：参考图拆解

1. **先分配职责**：每张图只取一到两项（身份 / 动作 / 构图 / 画风 / 光色）。
2. **再拆可迁移项**：机位、力的结构、灭点、尺度关系、介质、碎片、形语法、明度温度分级。
3. **不取**：原图的人物身份、服装、具体道具、画面文字、整体配色（用户点名要才用）。

形语法（束、负形、缺口、锯齿剪影、零解剖）与配色分级见 `references/deconstruction-and-palette.md`。

## 9｜E：修复

先判断问题出在**哪一层**，一次只修一层：

```text
空间与接触 → 动作与受力 → 视觉效果 → 剪辑与时间
```

只改出错的那个变量，已经对的场景、服装、动作原样保留。输出三样：一句诊断 ＋ 完整替换提示词（或后期命令）＋ 怎样算修好了。故障树见 `references/repair-guide.md`。

## 10｜F：现成视频后期（framecraft）

本技能自带工具，**原文件永远不动，只输出新文件**：

```bash
python scripts/framecraft.py info   --input fight.mp4   # 看信息
python scripts/framecraft.py detect --input fight.mp4   # 自动找候选击点
python scripts/framecraft.py sheet  --input fight.mp4 --at 3.4 --output hit-sheet.png
python scripts/framecraft.py apply  --input fight.mp4 --at 3.4 --recipe heavy \
        --focus 0.58,0.42 --output fight_hit.mp4        # 加效果
python scripts/framecraft.py apply  --input fight.mp4 --cues cues.json --output all.mp4
python scripts/framecraft.py menu                       # 中文数字菜单
```

- 配方 8 个：`cinema` `light` `heavy` `manga` `anime` `energy` `blackout` `crit`。
- 图层 9 种可自由组合：`hitstop` `flash` `invert` `ink` `punch` `rgbsplit` `shake` `zoom` `still`。
- **`--output` 不能已存在、不能等于输入**——工具会直接拒绝，这是保护原片的机制，不是 bug。
- 没有视频文件时**不要声称已编辑**，先给方案和需要的素材。
- 全参数见 `references/post-production.md`。

## 11｜输出契约（默认交付习惯）

- **默认中文**；投喂 Midjourney / Nano Banana / Veo 时自动改英文，即梦 / 可灵 / Seedance 用中文。
- 图像提示词交付形态：**一整段可复制英文提示词 ＋ 结构化参数行（`--ar` / `--no`）＋ 争议项说明**。纯文本，中间不截断。
- 视频提示词交付形态：**逐秒时间轴 ＋ 一整段可复制提示词**，分层清楚，可直接粘贴。
- 默认**不出评分表、不出多套长方案**；用户要「导演方案 / 分镜」时才展开交接卡、档位曲线、击点表。
- **默认只出提示词，不调用出图工具**；用户明确说「出图」才调。
- 画面锚 **MOOD 不锚 FRAME**；涉及知名 IP 时负面写 `no recognizable film character`。

## 12｜交付前自查（内部做，不输出）

- [ ] 是瞬间，不是状态／版式？
- [ ] 无空场，且明写「不是平涂填色」？
- [ ] 每个色值一个职责，没有两层抢同一件事？
- [ ] 线层与碎片层的要求**分开写**（线层不许并实／碎片层是实心块）？
- [ ] 主体剪影写成**实心平涂、只在边缘崩解**？崩解三档（道具零崩／躯干实心／发摆化丝）是否都在？
- [ ] 全篇无同句自相矛盾（逐句比对）？
- [ ] 无解剖词？
- [ ] 灭点唯一且已命名？
- [ ] 档位与用户要的狠度一致？一场戏是否只有一次 L5？
- [ ] 视频里的闪光/反相写了「恢复原画面」？闪烁是否 ≤3 次/秒？
- [ ] 角色、服装、武器、画风是否与用户素材一致？
- [ ] 用户拿到的是**能直接复制**的东西吗？
