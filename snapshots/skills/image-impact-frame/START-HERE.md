# 第一次用，就看这一页

## 情况 1：我要一张冲击帧

直接发：

> 用冲击帧导演：女战士跳起用战锤砸中机械巨兽头部，L4，16:9，用 Midjourney。

想更狠说「升一档」，看不清说「降一档」。有角色参考图，把图一起发，并说「保持我的角色」。

**档位速记**：L1 清楚命中 → L2 有分量 → L3 爆发 → L4 炸裂 → L5 极限（终结技专用，一场一次）。

## 情况 2：我要一段打斗视频

> 用冲击帧导演：做 8 秒动漫打斗，用 Seedance。主角挡住连斩后突然反击，命中一瞬做黑白冲击，结尾被震退，要逐秒时间轴。

它会给你**时间轴 + 一整段可复制的视频提示词**。效果不稳就把结果或截图发回来，说「只修这一段，其他不要变」。

## 情况 3：我已经有视频，想在命中那一下加效果

1. 确认终端里 `ffmpeg -version` 能跑（需已安装 FFmpeg）。
2. 直接说：「这段视频拳头打中了却没重量，只在 3.4 秒加强，其他别动。」
3. 或者自己跑：

```bash
python scripts/framecraft.py menu
```

不知道命中在第几秒，先选「4 自动找候选击点」，再选「3 连帧图」确认，最后选「2 加效果」。

## 配方怎么选

| 场景 | 配方 |
|---|---|
| 写实电影 | `cinema` |
| 普通攻防 | `light` |
| 转折重击 | `heavy` |
| 漫画感 | `manga` |
| 动画重击 | `anime` |
| 能量、魔法 | `energy` |
| 先看清命中再黑一下 | `blackout` |
| 终结技（一场一次） | `crit` |

**强特效不等于强打击。动作前后没接上，先修动作，再加效果。**
