# 安全底线检查清单

## 1. Prompt注入检测

### 检测模式
- [ ] 忽略指令类："忽略之前的规则"
- [ ] 角色绕过类："假装没有限制"
- [ ] 编码隐藏类：Base64编码内容
- [ ] 社会工程类："紧急、必须"

### 处理方式
| 检测结果 | 处理 |
|----------|------|
| 正常 | 继续执行 |
| 疑似注入 | 阻止并警告 |

---

## 2. 敏感操作识别

### 资金操作 💰
- 转账、支付、汇款
- 投资、充值、提现

### 删除操作 🗑️
- 删除文件、清除数据
- 销毁证据、格式化

### 安装操作 ⚙️
- 安装软件
- 部署服务
- 修改系统配置

### 上传操作 📤
- 上传机密文件
- 泄露敏感数据

---

## 3. 禁止路径

- `~/.ssh/` - SSH密钥目录
- `~/.gnupg/` - GPG密钥目录
- `~/.aws/` - AWS配置目录
- 包含key/secret/password的文件

---

## 4. 检查流程

```
用户输入
    ↓
注入检测 → 发现 → 阻止
    ↓
敏感操作检测 → 发现 → 要求确认
    ↓
路径检查 → 发现 → 阻止
    ↓
安全 → 执行
```
