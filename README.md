# DSH 技能选择器

当前版本：0.9.0。新对话默认关闭手动技能模式，技能按宿主原生规则调用；需要限制时在右侧选择页开启。适配并在 DeepSeek Harness 0.2.2-rc.3 上验证了插件注册、目录读取、组合草稿和记录保存；尚未完成全部界面交互验收。

## 安装与开发

这是 DSH 插件源码，不是独立网页，也不会把你的全部个人技能复制进仓库。已有技能从当前对话的生效目录动态读取，中文卡片与使用说明由插件提供。

1. 克隆本仓库，使用 Node.js 22 或更高版本和 pnpm。
2. 在仓库目录运行 `pnpm install --ignore-scripts` 安装根项目依赖。
3. 运行 `node --check client.js` 和 `node verify.mjs` 进行语法与功能验证。首次完整库检查可能联网更新 YouMind 数据。
4. 运行 `pnpm pack`，通过 DSH 的插件管理器安装生成的 `.tgz` 文件。已有旧版时从插件管理器替换；Host 代码更新受运行时模块缓存影响时可能需要重启 DSH。

网页原版入口当前通过 Windows 已安装的 Google Chrome 打开。聊天、评分、收藏和组合历史保存在 DSH 的本地存储中，不随源码上传。

仓库内包含上游资源，相关许可证及来源见 `packs/ATTRIBUTION.md`、`packs/licenses/` 和 `full/youmind` 内的原版 LICENSE。上游的许可证仅适用于其各自内容；原站样图为远程链接。

“技能内容更新提醒、按版本提示重新测试、自动校对中文卡片”尚未实现。技能本身更新与中文说明维护的边界见下文。

在当前对话说“打开技能选择器”“我要使用 MJ 提示词”或“打开提示词工作台”，AI 调用 `prompt_workbench action=open`，在该对话右侧展开技能选择页。也可点击对话标题栏入口。不再手动选择对话。只有点击需要网页的技能后才打开 Chrome 新窗口；Chrome 未运行时直接启动。通过已安装的 Chrome 执行 `--new-window`，不改变系统默认浏览器。

## 界面与操作

技能卡片默认展示名称、简短用途与评分，详细说明按需展开。选中卡片有勾选和边框反馈；底部操作栏保持可见，便于浏览长目录后直接使用。单独使用与组合使用采用按钮切换，组合分工只在对应模式展示。使用记录支持点选1～5颗星、可选备注和明确保存反馈。界面沿用DSH明暗主题：普通边框带淡蓝灰，选中项为蓝色，组合主技能为紫色，收藏与评分星为金色，成功/错误分别为绿/红，底栏以淡蓝分隔。颜色由主题令牌混合生成；短暂颜色过渡遵循系统减少动态效果设置，不会因界面动画调用模型。

总入口与小技能按分组折叠展示：真实工具箱、工作流关联和用途分类分别标注；总入口在组内置顶，没有明确总入口的分类不会虚构父技能。展开状态保存在本地存储，下次打开沿用。展开只浏览，不选择成员或扩大调用权限。搜索按空格分词，多个词需同时命中，结果按相关度排序（标题优先于 ID、关键词、分类和描述），最匹配的分组浮到前面，命中词在原位高亮。分类可按用途多选，筛选区常驻显示并有“只看白名单”开关；收藏和筛选继续按单个技能生效；未知新技能保留独立显示。分组关系与核对依据保存在 `skill-families.json`，只是选择器展示信息，不改原技能。

## 每个对话独立开关与自动调用白名单

新对话默认关闭手动模式，技能按宿主原生规则调用，不会因为没有加入白名单而被拦。手动开启后：白名单技能可被模型自动加载，名单外 `skill` 加载（包括嵌套调用）会被守卫拒绝；但用户从选择器选过、或在消息开头发过独立 `/技能名` 的技能本轮直接放行，不需要先去改白名单。开启后的目录包含白名单技能与本轮已选技能，模型不会因为目录里看不到而造成误判。不需要限制时在右侧选择页关闭，关闭后恢复原生调用规则。原生技能自身仍须允许模型调用，加入名单不会提升原技能权限。技能卡片的“详细说明”提供本对话和未来默认两个独立复选框；标题下的名单管理可查看或移除条目，包括已离开目录的技能。技能包与仅用户可调用技能不能加入自动白名单，仍可手动使用。

默认白名单初始为空。在某个对话首次解析策略时复制一份到本对话，之后两者独立；修改默认名单不覆盖已初始化对话。这里的“未来对话”按首次使用此策略计算，已存在但尚未初始化策略的对话也会取得当时默认值。设置按对话 ID 保存，分支/新对话有新 ID 时独立初始化，不继承来源对话的开关或名单。关闭模式时白名单暂不限制调用，但名单仍保存，以便再次开启。

选择、生成预览都不执行。用户直接发送带记录标识的使用草稿后，在该轮注入所选完整技能，支持单独、主辅组合、仅模型可调用技能和内置方法包，即使它们不在自动白名单中。草稿允许在发送前编辑正文：只要开头的记录标识完整、草稿属于本对话、标识之后有实际内容，就照常注入。标识被删除、草稿来自其他对话或记录已失效时不注入，并在对话里说明原因，不再静默失败。也可在消息开头用独立 `/技能名` 行明确调用原生用户可调用技能。涉及名单外额外技能时需补选。

开关和两份名单仅通过用户界面命令修改，模型工具不能修改权限。新策略保存在 `skill_selector_sessions`，旧全配置 `skill_selector_policy` 数据保留但不再控制调用；评分与历史继续使用原 `prompt_workbench`。升级后新建对话默认关闭手动模式；已存在但尚未初始化策略的对话也按关闭初始化，已初始化并自行开启的对话保持开启。下一步明确撤销可见历史中的旧全配置手动限制。关闭后必要时按当前作用域重新发布目录。策略/目录仅在首次进入、模式/名单或可用目录变化时发布；每一步仍过滤未授权注入，重启从可见历史恢复发布状态。不修改原技能文件，已进入聊天的技能内容不从历史删除。草稿授权按对话内可见消息计算，已发送并保留在历史里的草稿在后续轮次继续有效；消息被删除或换到其他对话后失效，旧版草稿不带标识时请重新生成。

这是原生技能入口控制，不是通用文件或命令行沙箱；消息会明确禁止绕过入口读取其他技能。任意文件工具与外部脚本仍遵循宿主本身的权限。尚未承诺在任意第三方插件的私有执行接口上实现权限隔离。

## 三个完整项目

- **AI Image Prompts**：完整原版技能和11个分类均在 `full/youmind`。固定 revision 39c0c0033904de9c164df3ec2245d3b44526df04 的25个上游文件均经Git blob哈希验证；15306个去重提示词、23069个分类条目。manifest 的15848为作者CMS输入口径，不能当导出条数。原版推荐最多3条原始模板、每条带样图和来源，选中后再改写，保留YouMind归属说明。技能注册名 `ai-image-prompts-skill`。侧栏按钮将启动说明填入当前草稿，不自动发送；对话也可直接调用。原版样图为远程URL。
- **AI Visual Prompt Cookbook**：点击后在 Chrome 新窗口打开 https://prompts.vigocreativeai.com/site/ 。作者完整186套风格、372张标准预览；按原流程看图、复制完整JSON、替换变量，或选纯文本。不是本插件重建的精简画廊。
- **Prompt Fill**：点击后在Chrome 新窗口打开 https://www.aipromptfill.com/ 。作者当前完整编辑器App1.1.6/Data1.2.3，248模板、290词库、2291选项，支持变量编辑/预览/导入导出。用户最初给出的4xiaxia仓库是旧fork，使用其推荐的TanShilongMario原作者网站。用户数据由原网站浏览器存储管理；清除网站数据前自行导出JSON。

上面网页与计数是在2026-11-13核对的，后续随作者更新。网页完整功能仍以作者提供的服务为准；第三方云功能不包含免费的生图额度。实际网站渲染、剪贴板及导出需要有已连接浏览器时验收，HTTP200不等同功能全部验证。

## 数据更新

每次使用YouMind先运行原版setup检查。原版 `--check` 存在旧文件仍跳过的问题，因此过24小时后本插件使用作者的 `--force` 真正刷新，并检查全部分类的JSON和计数；“更新完整库”按钮也强制刷新。同步仅更新references，不擅自升级技能指令。固定原版来源与哈希报告保留在 `full/youmind`，同步后references会不同于最初固定快照。上游脚本失败可能退出0，因此不靠退出码判断成功。

## 组合使用

使用模式只有“单独使用”和“组合使用”。组合至少选择两个技能，不限制数量，指定一个主技能，辅助技能可调整顺序并填写职责。主技能统一方案和最终格式，辅助技能按职责补充，最后整合成一份结果。点“生成组合草稿预览”只保存草稿和组合记录；检查后再点“加入当前草稿”，由用户自行发送。不代表多代理并行，也不保证任意技能组合都能兼容；实质冲突需说明或澄清，辅助默认流程不得扩大用户任务范围。

组合历史保存主技能、全部成员、职责、辅助顺序和完整提示词。评价针对组合整体，不计入成员的独立平均分；组合评价不能修改主技能的收藏或隐藏状态。单个技能状态在卡片单独管理。旧单用记录、历史测试记录和评分保持兼容。

## 已有技能与评价

默认显示当前对话全部可用技能，可按任务分类、搜索和收藏筛选。输入想做的事，点“帮我挑技能”按用途与关键词返回全部匹配项，不设三条上限，不调用额外模型，也不是质量评分。普通使用一次选择一个，点“使用这个技能”将明确技能调用和需求填入当前草稿，检查后自己发送；不自动执行。手动模式开启时由受控草稿注入完整技能；关闭时用户可调用的技能采用原生 /技能名，其他技能通过 skill 工具加载，方法包读取本地入口。插件不再提供对比测试模式或批量准备测试稿。需要比较时由用户自行分支对话，在各个对话选择不同技能；当前上下文可能影响结果。输入参考素材后自行发送。用后评分、备注，收藏好用项，隐藏不适合项；隐藏仅在选择器中排除和阻止新使用，不删除原技能或更改DSH全局开关。

英文简介技能的中文名称、用途与关键词保存在插件的 `skill-localizations.json` 中，展示、搜索和推荐共用；保留英文 ID 与原版简介，原技能文件不改。新增未覆盖技能仍显示原简介。

目录由当前对话生效技能决定。发现不完整会提醒；每次使用重新检查加载能力。历史记录和评价沿用原来的 storageDomain `prompt_workbench`，可导出JSON，不自动抓取生成结果。两套逆向方法包仍按需读取，视频依赖未自动安装。

旧44条样本仅留作旧API兼容，不在新选择页当作完整版展示。`resources/compose` 是旧样本；`library/refresh/activate` 是完整YouMind流程，`originals` 返回完整原版入口。Host命令与工具共用业务实现，所有注册通过生命周期清理。
